# 面向检测与视频身份恢复的遮挡预训练：文献调研与实施建议

日期：2026-10-19。性质：文献证据与下一阶段设计建议；没有启动新训练，没有替换既有冻结协议。研究对象是毕业论文的通用检测、分割与视频身份研究线，动物是应用对象，不把小论文的原型—系数约束移植到此处。

## 1. 主判断与当前项目依据

**我主张利用已有自建三维场景，训练“目标证据与遮挡物证据分离”的对象条件化表征，再检验它向 YOLO 和跨遮挡身份匹配的迁移。** 数据生成采用现有 Blender；训练以 SAM 2.1 Hiera-small 为首个可控底座，SAM 3.1 是更强现成参照。单帧空间能力先验收，再加入因果视频记忆。暂不投入大型视频扩散模型的重新训练。

用户已明确：场景自己建模，数据已有。**合成训练标签不需要人工标注，也不需要先人工补一套真实视频才能开始合成预训练。** 当前应做的是复用和组织已有监督，缺失的渲染层由程序补导出。真实视频的作用是独立检查迁移；可优先复用已有公开标注，不把生成器已经知道的事实重新交给人工。

已有完整实验见 [REPORT](../../experiments/dense_video_occlusion_transfer_20261019/REPORT.md)：72 段、2,304 帧、9,216 条几何标签；冻结 ResNet 特征后训练四状态与可见比例头，合成测试 macro-F1 为 0.904537。真实 11 段留出上的新增 FULL−C 为 +0.262926 IDF1 点，95% 区间 [0, 0.499987]，且打乱对象权重不更差；BoT-SORT 仍高于 FULL。**这支持“可学习合成遮挡状态”，不支持“当前标量权重已得到稳定任务收益”。** 既有结果不足以独立证明域差异或特征污染是哪一个主因。

因此，不推荐把唯一目标继续定成四分类准确率。新优先问题是：**相同遮挡外观下，模型能否保留目标自身的可辨认信息，并排除遮挡物和相似个体的干扰？** 这是待检验假说，而不是已经证实的创新。

## 3. 数据怎么利用和生成：从已有场景自动出监督

### 3.1 当前已有字段可以直接复用

只读检查 [generate.py](../../shared/dense_video_occlusion/generate.py) 的 `geometry` 和写出路径，确认下面字段已实现；没有在本轮重新跑生成器。

| 已有数据 | 可以自动得到的训练监督 |
|---|---|
| 每帧 `instance_id` | 当前可见像素属于谁；每个目标的可见掩码和可见框 |
| 每个目标 `amodal_i` | 同相机下、移除其它物体遮挡后的完整投影轮廓；这是投影，不是所有三维表面的并集 |
| `track_id` 与序列 | 同一个体跨帧正对；同时出现的其它个体负对；再出现对应关系 |
| `visible_pixels / in_frame_pixels` | 可见比例；遮挡严重程度连续值 |
| `full_pixels` 与 `truncation` | 视野裁切比例，与被其它物体挡住分开 |
| `occluder_pixels` | 哪个前方实例挡住目标，以及挡住多少像素 |
| 场景种子、资产、姿态和相机 | 可复现同场景变体及按资产/场景拆分 |

像素级遮挡物归属不必重新人工制作：在目标 `amodal_i` 内，取 `instance_id != i` 的像素，其前方实例 ID 就是当前渲染定义下的遮挡者。当前环境未逐一编号的几何体共同使用 0，障碍物也可能共享 100；若要区分不同障碍物，需要给它们独立编号。对“目标可见/被其它物体遮挡”这一层监督，现有字段已经有用。

令可见掩码为 V，画面内完整投影为 A，同一投影在足够大 overscan 画布内的掩码为 A*：

- 遮挡比例 `o = 1 − |V| / |A|`，仅在 `|A| > 0` 时有定义。
- 出画比例 `r = 1 − |A| / |A*|`，overscan 必须确认没有截断目标。
- 画面内隐藏区域 `H = A \ V`；阻挡该区域的前方 ID 来自完整场景 ID 图。
- `|A|=0` 表示不在当前视野，不把“分母为空”解释为 100% 遮挡。旧文件的既有编码保留，新数据合同显式增加有效性标志。

这些定义针对外部遮挡；身体背面本来不可见，不计作被其它实例遮挡。半透明物、毛发、运动模糊与抗锯齿涉及不同的可见性定义，首轮先以不透明几何体的中心时刻标签为准。当前 RGB 与标签分辨率不同，边界对齐需统一变换；已有像素核验不自动等于新渲染层已经核验。

### 3.2 最值得生成的不是更多随机帧，而是可比较的事件组

对同一资产、动作、相机和目标外观，自动形成一组场景：

| 变体 | 保持不变 | 改变什么 | 用途 |
|---|---|---|---|
| A：清晰可见 | 目标、姿态、背景、相机 | 移走遮挡物 | 提供完整目标的训练教师视图 |
| B：被部分/完全遮挡 | 同上 | 遮挡物轨迹、距离、尺寸 | 学习可见区域、隐藏区域与时序变化 |
| C：更换遮挡者 | 目标与其可见证据 | 遮挡物纹理/身份，尽量保持遮挡几何 | 检验目标表征是否被遮挡者身份污染 |
| D：更换目标个体 | 场景与遮挡过程 | 同类目标的身份、细微外观 | 防止只学“都是同一类动物”而不能区分个体 |

A/B 是配对教师监督；C/D 是区分机制的受控干预。完整场景数据已经有时，先按现有参数分组，只有缺少的配对视图才补渲染。移走遮挡物会改变投影阴影和反射，因此教师比较应限制在目标对应区域，并把光照变化当独立因素记录，不能假定整幅 RGB 完全一致。

事件至少覆盖：无遮挡；短/长部分遮挡；完全遮挡后原目标返回；相似个体抢先出现；出画后返回；遮挡后不返回；近距离但没有实际遮挡；模糊/低分辨率但没有几何遮挡。后两类非常重要，避免把难看清都学成遮挡。通过几何标签统计实际事件是否发生，而不是只依据场景名字。

连续事件采样要同时控制持续时间、可见比例、竞争个体数量、相机运动、动物互挡与环境物遮挡。不能一味提高完全遮挡比例：从未出现过、完全被挡住的目标没有可识别的当前图像证据。视频任务必须先给到一次可见目标提示，后续才检验记忆与重现。

### 3.3 尚未在当前写出路径看到的层

深度、逐像素运动/对应关系、无外部遮挡的配对 RGB、事件边界表，可以从已有三维场景自动导出；本轮没有验证这些字段已经全部落盘。形变动物的跨帧对应应追踪骨骼变形后的网格表面点/重心坐标，不能仅用根节点矩阵或把同一像素位置当同一身体部位。第一阶段空间学习不依赖把所有层一次补齐。

### 3.4 拆分与泛化

同一场景所有帧、清晰/遮挡配对和外观变体必须同属一个拆分。分别留出资产/身份家族、场景模板、相机与遮挡过程，避免随机分帧造成近重复泄漏。若希望声称通用，测试中要有未见动物和至少一种非动物对象；只在同一渲染器、同几个动物上的高分不能支撑通用主张。已有 23 段真实视频及其历史使用身份继续保留，不重新包装成首次盲测。

## 4. 视频增强：增强外观和观测条件，不破坏身份真值

| 增强层 | 推荐做法 | 标签如何处理 |
|---|---|---|
| 场景/几何 | 相机轨迹、遮挡物移动、目标相交路径、视野进出、骨骼动作 | 在 3D 世界重渲染，重新计算全部监督 |
| 外观 | 材质、背景、光照、天气效果、颜色变化 | 一个片段内保持身份属性连续；阴影等变化记录为干扰因素 |
| 成像退化 | 视频压缩、噪声、模糊、分辨率变化 | 几何遮挡标签不随模糊变成“遮挡”；强退化单独记录可观测质量 |
| 时间采样 | 不同帧率、步长、跳帧、不同长度窗口 | 同步更新时间间隔、事件长度和运动对应；真实速度信息不能丢掉 |
| 检测输入 | 框偏移、框缩放、漏检、误检、mask 边界误差 | 只扰动模型输入，真值保持；视频漏检时用历史查询继续，而非注入 GT 框 |
| 多目标竞争 | 相同类别、相近外观的个体接近、交叉、轮流出现 | 保留真实 ID，并包括无法仅凭当前画面判定的情形 |

随机裁剪或翻转应对同一短片使用一致变换，图像、掩码、框、运动向量一起变；逐帧乱裁剪会制造不真实的跳动。若使用倒放，它是一个重新定义时间方向的新序列；运动和事件标签重算，在线推理始终只读当前和过去。TCOW 与 SAM2 都使用过视频空间/颜色/时间增强，但这不能代替本项目的因果性检查。[TCOW](https://arxiv.org/abs/2305.03052) · [SAM2](https://arxiv.org/abs/2408.00714)

**生成式视频增强放在第二阶段。** Cosmos Transfer 之类的条件视频生成可以提升视觉多样性，但控制输入不保证所有动物边界、ID 和遮挡顺序都精确不变。官方导航示例复用语义标签，尚不足以替代本项目的实例几何核验。生成内容通过边界/身份/事件一致性检验才继承标签；否则仅作为无标签域适配样本。[官方示例](https://nvidia-cosmos.github.io/cosmos-cookbook/recipes/inference/transfer1/inference-x-mobility/inference.html)

现阶段优先原生三维的纹理、光照、镜头和时序随机化。写实程度和有效监督要分别检验，不能用“看起来真实”替代模型真实迁移结果。

## 5. 模型建议：同一个空间核心，按需要使用视频记忆

### 5.1 选型裁决

首选 **SAM 2.1 Hiera-small（官方约 46M 参数）作为研究底座**，原因是它统一图像与视频，有可复用的提示/分割/记忆接口和公开微调代码，适合做控制变量。第一阶段训练解码头与小适配器，必要时再按预冻结对照局部解冻，不从头重训基础模型。它不是最新模型，也尚未证明是本任务最优选择。[官方仓库](https://github.com/facebookresearch/sam2)

SAM3.1 已有多目标共享记忆，应作为现代强参照。SAM3 官方为 848M 参数，并有较新的依赖和权重访问要求；这使它更适合先作为现成教师/参照，而不是第一组机制消融的唯一底座。其公开多目标指标有升有降，不预设它在本项目必然优于一切方法。[模型说明](https://github.com/facebookresearch/sam3) · [3.1 指标](https://github.com/facebookresearch/sam3/blob/main/RELEASE_SAM3p1.md)

SAMEO/EfficientSAM 是轻量空间参照；TCOW 是遮挡持续存在的任务参照。DiffVAS 官方默认训练约 120 小时/8×A6000，预计算深度可显著缩短；这说明复现成本需单独预算，不把它作为第一轮主干。官方硬件速度/成本都不是本项目已经测得的数字。[DiffVAS 实现](https://github.com/Kaihua-Chen/diffusion-vas)

### 5.2 建议输出和三部分结构

**第一部分：目标条件化空间编码。** 输入整图和一个目标提示，提示来自检测框、已有可见 mask 或首帧目标；编码器保留周围上下文。不要只用紧裁剪，因为遮挡物证据可能在框边缘或外部。推理输入不包含 GT 完整框、GT amodal mask 或渲染器 ID。

**第二部分：证据解码。** 输出目标可见掩码、画面内完整投影的辅助预测、遮挡区域及归属、可见比例，以及用于匹配的目标特征。状态分支要对遮挡变化敏感；身份分支要尽量对遮挡者变化不敏感，同时保留目标间差异。不能要求所有特征在遮挡前后相同，否则会抹掉所需的遮挡信息。隐藏形状是预测，不能把生成的纹理当观测证据。

**第三部分：可选因果记忆与身份决策。** 使用此前可靠可见特征、当前观测和多个候选目标，输出匹配分数与拒绝/暂不决定选项。全遮挡时保留历史查询；再出现时和相似竞争个体共同判断。训练目标直接包含正确恢复和错接风险，最终仍需要与检测器共同评估，不能保证找回根本未被检测到的个体。

SAM2 已经有目标可见性相关输出和记忆机制，不能把“加可见性头/记忆”写作全新机制。这里可研究的是监督组织、表征分工与有针对性的迁移效果，而不是模块名字。

## 6. 怎么训练：从空间证据到时序，再到下游

所有规模和权重下述仅为设计，不是已获通过的正式训练合同。先做资源烟雾测试，再冻结参数、预算、比较口径和停止条件。

| 阶段 | 输入与监督 | 目标 | 通过后才做什么 |
|---|---|---|---|
| 1. 单帧空间预训练 | 现有 RGB、目标提示；自动导出的 V/A/H/比例/遮挡归属 | 学会目标证据和遮挡证据的位置及程度 | 在未见资产/场景上验证，再加配对干预 |
| 2. 配对证据学习 | 同目标清晰/遮挡视图，替换遮挡者，同类其它目标 | 减少遮挡者引起的身份特征变化，同时保留目标身份差异 | 受控干预和实例匹配均有效才增加视频复杂度 |
| 3. 因果视频预训练 | 先可见、后遮挡、再出现的短片；连续 ID；竞争者和无正确候选样本 | 学会跨遮挡对应、拒绝错误恢复；短片训练逐步扩到较长事件 | 独立事件有效后再评估真实任务迁移 |
| 4. 真实视频适配（可选） | 现有未标注真实视频、可靠可见片段及点轨迹伪标签 | 缩小外观和运动域差异 | 几何遮挡头没有可靠标签时不盲目自训练 |
| 5. 下游迁移 | 固定 YOLO 的同初始化/同数据/同预算训练与统一评价 | 检验是否提升遮挡条件下检测/分割或身份区分 | 成功后才扩大训练规模、跨模型确认 |

阶段 1 用可见/完整投影掩码监督和比例回归即可，阶段 2 增加对应区域的教师特征约束与同类身份负对。教师只在训练时看到完整视图，学生使用部署可得输入；真值掩码用于构造损失，不作为测试时的隐藏输入。

建议损失按任务明确分工：`L空间 + λ比例 L比例 + λ配对 L配对 + λ身份 L身份 + λ时序 L时序`。空间损失覆盖 V/A/H 的区域监督；比例只在画面内面积有效时计算；身份损失区分同目标与同类其它目标；时序损失使用真实跨帧对应及候选匹配。系数须在独立合成验证集确定，不按真实测试结果反复调整。先控制可训练参数，再比较是否需要局部解冻编码器。

**对完全遮挡帧，不能强制无历史的单帧模型精确重建唯一身份。** 可训练的是有历史时的身份保持、概率校准和再出现判别；证据不足时允许拒绝。让模型在不可辨场景承认不确定，比训练它硬记渲染器答案更符合泛化目标。

真实视频伪标签只提供其能支持的监督。CoTracker3 在真实伪轨迹训练阶段冻结可见性/置信度头，给出一个相关先例：错误伪标签可能损伤已学会的可见性能力。我们可学习可靠轨迹和外观，但不要用未经核验的漏检直接制作“完全遮挡”标签。[原文](https://arxiv.org/abs/2410.11831)

## 7. 如何给 YOLO 用，以及怎样证明收益来自预训练

优先验证**训练时迁移、推理时保留普通 YOLO**：将遮挡模型输出的空间证据与实例特征，经轻量投影对齐到 YOLO 多尺度特征。合成数据上有几何真值；真实数据上，只对教师可靠区域使用软监督。原生检测和可见分割损失不被替换成隐藏形状损失，常规可见分割评价也不能拿 amodal 输出冒充。若需要完整轮廓，单列输出与评价。

权重不能直接从 SAM 的网络结构复制给 YOLO；“迁移”具体指训练监督/特征蒸馏，或另一个明确测延时的独立模块接口。先选择前者，避免用更重推理成本解释全部收益。仅得到一个可插拔状态分析器，不等于已经改善 YOLO。

推荐的必要对照如下，预训练算力与下游算力分别登记：

| 对照 | 要排除的解释 |
|---|---|
| 同配置原生 YOLO | 是否超过实际部署起点 |
| 同样合成图像/视频量的普通增强训练 | 是否仅仅因为多看了数据 |
| 相同底座、参数、数据、优化步数的普通分割或配对蒸馏预训练 | 是否仅仅因为额外预训练和教师信息 |
| 完整方法移除遮挡物归属监督，保留同容量分支 | 是否真是目标/遮挡物分离起作用 |
| 移除同类竞争身份监督 | 是否主要收益来自身份可分性而非遮挡分类 |
| 视频去历史/打乱时间的受限对照 | 时序信息是否带来额外收益；不把这一组的合成分数单独当最终证明 |

原生 YOLO 是实际效用参照，不天然是预算相等的机制对照。不同架构的 SAM3.1、SAMEO、TCOW 和 BoT-SORT 是已有方法参照，不能拿它们与自己相差的参数量/提示/未来帧信息做纯机制归因。若代码不可获得，应记录不可比或按论文重现的差异。

至少分三层评价：

1. **合成几何能力：** 可见区域/完整投影/隐藏区域分别 IoU，比例 MAE，按可见性和出画状态分层；完全遮挡与长遮挡单列。不只报一个 F1。
2. **证据与身份：** 换遮挡者时目标特征变化，换目标时可分性；固定误接风险下的正确匹配率、拒绝率与校准；按遮挡事件/视频聚类，而不是把相邻帧当独立样本。
3. **真实任务：** 同检测协议的 box/mask AP、遮挡条件下召回、无遮挡损伤；视频 IDF1/HOTA/误接、恢复事件成功率与延迟。已有公开 ID 标注可直接复用；没有物理遮挡事件真值的片段，只支持总体跟踪评价，不把 GT 时间间断命名为完整遮挡。

公开资源可补外部评价，但其字段不能混用：SAIL-VOS 提供合成 amodal；OVIS/MOSE 主要是可见视频 mask；TAO-Amodal 核心是 amodal 框，不能当逐像素隐藏 mask；TAP-Vid/PointOdyssey 是点轨迹标签。详见 [数据资源核验](notes/E_findings.md)。这不要求重新人工标注自建场景。

## 8. 创新主张与可推翻条件

拟检验主张 H：**针对目标与遮挡物的几何归属监督，配合替换遮挡者和同类身份竞争训练，可以学到比普通遮挡增强/一般配对蒸馏更可迁移的目标表征。** 预测是换遮挡者时目标身份特征更稳定，换目标时仍可区分，并且在同预算真实下游评价中获得独立增量。

竞争解释 H_alt：收益主要来自更多合成样本、通用分割预训练或训练计算量；归属分离本身没有额外作用。它预测同数据同容量的普通预训练达到同等结果，移除归属监督不损失收益。另一现实限制是检测缺失，此时匹配模型再好也无法恢复没有候选的个体，需单独报告固定候选与完整系统结果。

| 结果 | 研究决策 |
|---|---|
| 受控干预符合预测，归属消融使相应收益消失，独立真实迁移超过匹配对照且无遮挡损伤受控 | 继续该机制，进入更大规模和跨模型确认 |
| 合成遮挡识别高分，但普通增强/普通蒸馏同样有效，或移除归属监督收益不变 | 停止以“证据分离机制”为核心的投入；保留有效的数据/训练成果，不追加模块追阳性 |
| 身份表征有受控收益，完整系统无收益且检测召回限制明确 | 收窄为表征/固定候选贡献；下一阶段优先验证检测覆盖这一必要条件，不能宣称系统恢复已改善 |
| 方向一致但事件少、区间过宽，或可观测性标签不支持该结论 | 保留不确定，扩大独立评价覆盖，不据此扩大模型容量；具体阈值在新协议冻结 |

**唯一下一步建议：**以现有场景产物建立“同目标、换遮挡者、换同类目标”的自动监督配对清单和隔离拆分，复用现有几何核验；据此冻结一项同预算的“普通配对预训练 vs. 归属分离预训练”小规模试验。此步可直接检验所主张的机制，优先级高于继续扩充四分类器、先搭更复杂跟踪系统或先重训视频扩散模型。本轮仅完成调研和设计，未启动该试验。
