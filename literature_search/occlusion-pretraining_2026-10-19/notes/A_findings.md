# A / arXiv implementation findings

Scope: source bucket A for the six frozen facets in `SEARCH_PLAN.json`; search and reading completed 2026-10-19.  Twenty raw records were retained in `raw/A_arxiv.json`.  Full arXiv HTML was read for TCOW, CoTracker3, SAMEO, SaVos, DiffVAS, TABE and Amodal SAM; other entries are abstract-level checks unless stated otherwise.

## Findings that alter design choices

1. **A physical renderer is useful chiefly because it permits labels that 2D compositing cannot supply.**  TCOW builds visible instance IDs plus every-instance X-ray masks, derives visible/total occlusion fraction, and labels the *frontmost responsible occluder*; it separately derives containment from 3D object relations.  Its training set is 3,600 Kubric random clips, with 200/200 validation/test clips, 36 frames at 480x360.  This supports generating visible mask, amodal mask, occluder mask/ID, depth, optical flow and persistent instance ID together—not merely a scalar occlusion label.  [TCOW, arXiv:2305.03052, full text]

2. **The exact proposed “paired clean/occluded instance” supervision already has close precedents.**  pix2gestalt trains conditional diffusion from synthetic occluded/whole pairs.  SAMEO’s Amodal-LVIS makes original unoccluded and synthetically occluded examples for every instance specifically to avoid an occlusion bias.  Amodal SAM’s 2026 TAOS likewise composites a cropped object from a second image over a target object and retains visible, occlusion and amodal masks.  Pairing alone is therefore not a novelty claim.  [arXiv:2401.14398; 2503.06261; 2604.20748, full text for latter two]

3. **The closest deployable detector interface is already demonstrated.**  SAMEO accepts ordinary modal detector boxes as prompts, freezes EfficientSAM image/prompt encoders and finetunes only its mask decoder using Dice+focal+IoU losses.  It reports that RTMDet-style modal detections can drive amodal masks.  A YOLO box -> external occlusion/amodal head is feasible but cannot by itself be claimed as new.  It is also only a post-detector module: a missed object remains missed.  [SAMEO, arXiv:2503.06261, full text]

4. **There is no separately verified paper called “AmodalSAM2.”**  The closest verified source is *Amodal SAM* (arXiv:2604.20748).  It first adapts SAM with an encoder-side gated Spatial Completion Adapter, TAOS data synthesis, regional-consistency and adversarial topology losses; then extends that design to SAM2 by putting SCA modules at all Hiera stages and feeding the prior frame’s predicted amodal ROI back as current spatial prior.  The paper is an ICLR-2026 submission/preprint, and this search found no official code repository.  A method described as “SAM2 amodal video adaptation using synthetic target-aware occlusions and progressive amodal memory” therefore needs explicit differentiation from it.

5. **Visible-to-hidden representation consistency is also not unclaimed territory.**  Amodal SAM directly minimizes cosine distance between features pooled from visible and occluded regions.  SaVos learns amodal masks and dense amodal motion using warp consistency, but masks loss where the object is occluded.  A new proposal needs a different testable target than simply “make pre/post occlusion features similar.”  [Amodal SAM, arXiv:2604.20748; SaVos, arXiv:2210.12733, full text]

6. **For video, causal identity and amodal mask completion should be separated.**  TCOW is causal and makes occluder/container an explicit output when hidden-target localization is ambiguous.  It also reports a substantial sim-to-real gap.  TABE notes that conventional mask metrics can reward ordinary visible re-identification instead of correctly completing an occluded region; its TABE-51 construction composites independently recorded real target and occluder clips so exact hidden masks are known.  Evaluation needs a real complete-occlusion subset with per-frame hidden mask or post-gap identity ground truth, not only overall tracking scores.  [TCOW, arXiv:2305.03052; TABE, arXiv:2411.19210, full text]

7. **Pseudo-labelled real video should not directly train the occlusion label head.**  CoTracker3 uses frozen synthetic teachers to label real video and supervises trajectory coordinates, but deliberately does not supervise confidence or visibility there; it freezes a separate confidence/visibility head to avoid forgetting.  This is direct evidence for a two-stage plan: exact synthetic visibility supervision first, then real-video adaptation on reliable correspondence/consistency losses only, or with an explicitly adjudicated real visibility subset.  [CoTracker3, arXiv:2410.11831, full text]

8. **Diffusion can improve completion but is a poor first baseline for an efficient YOLO transfer study.**  DiffVAS conditions Stable Video Diffusion on modal masks and pseudo-depth, then separately completes RGB content; authors report about 30 hours on 8 RTX3090 GPUs for their listed setting.  TABE chains SAM2, monocular depth, video-diffusion outpainting and a second SAM2 pass.  These are strong research baselines for hidden-region completion, but do not establish a compact reusable feature model or real-time detector transfer.  [DiffVAS, arXiv:2412.04623 / CVPR 2025; TABE, arXiv:2411.19210, full text]

9. **Motion-only self-supervision is not enough for moving cameras/deformation.**  SaVos requires optical flow and visible masks, uses a CNN+LSTM, and states that permanently unseen pixels need another prior.  EoRaS was proposed explicitly because flow is brittle under camera motion and deformation; it adds object slots/multiview fusion and uses modified Kubric MOVi data.  For animal video, use temporal correspondence as one supervised signal but retain an object-conditioned spatial encoder; do not equate temporal continuity with identity truth.  [SaVos, arXiv:2210.12733; EoRaS, arXiv:2309.13248]

10. **A realistic first pretraining objective suggested by evidence is multi-output occlusion state, not amodal RGB generation.**  Train a target-conditioned encoder on physical video with: (a) visible mask, (b) amodal projection mask, (c) occluder/occluder-ID mask, (d) visibility ratio, (e) same-instance versus similar-individual cross-gap correspondence, and (f) uncertainty/no-evidence state.  Pair this with a matched control that sees the same RGB, objects, epochs and parameter budget but has shuffled target/occluder pairings.  This combines TCOW’s explanatory labels with the project’s actual failure (identity competition), while avoiding an already-covered pure SAM/diffusion amodal-completion claim.  This is a literature-grounded design recommendation, not an established result.

## Limitations and unresolved verification

- This bucket has no verified paper whose evidence shows that an occlusion-pretrained auxiliary head improves a YOLO detector/segmenter after distillation under matched downstream training.  SAMEO demonstrates modular front-end compatibility, not detector-weight transfer.
- Amodal SAM claims strong image/video generalization, but it is a preprint under ICLR-2026 review status and targeted search did not surface an official implementation; code availability is recorded as unverified/unavailable rather than assumed.
- DiffVAS is verified as CVPR 2025 and has a public repository, but its repository still lists parts of the release as TODO; do not treat all training/evaluation code as confirmed released.
- TABE is a 2024 preprint with public code and data-generation code, but its real-composite benchmark construction and custom TAO subset should be independently reproduced before using numerical comparisons.
