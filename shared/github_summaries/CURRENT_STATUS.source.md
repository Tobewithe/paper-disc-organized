# 当前研究状态（2026-09-30）

主线是：**在固定原型下建立系数可恢复空间与原生无 GT 系数预测的差距，再用受控对照研究形成环节。** 当前收敛证据，不自动扩大外挂修正器，不重跑已经完成的全量 raw 能力实验。

本页是现有报告的范围核对与导航，不新增实验或“唯一机制”结论。实验源码和大规模产物留在科研项目；每份导出的报告保留原来源位置及版本。

## 已经完成，不能重复当成新实验

| 问题 | 现有证据 | 本轮理解与限制 |
|---|---|---|
| raw 池、TAL 与最终输出有什么差距？ | [COCO 5000 图 raw 能力实验](experiments/coco_raw_capability_5000_20260916.md) | 已检查约 3083 万 raw 候选、36,335 个普通 GT。24,823 个 GT 存在 raw Mask75 候选，最大一对一匹配 24,822，正常输出匹配 22,767。不能把 raw 存在率称为 AP。 |
| 框好掩码差是否是大量存在的对象？ | 同上 | 6,688 个 GT 在当前 raw 口径下有达标框但没有 Mask75 掩码，占全部 GT 18.41%；不是全部失败状态，也不能把它全部归因于单个模块。 |
| 好系数是否存在且能有限、稳定地求出？ | [7D 有限 oracle](experiments/coefficient_finite_oracle_20260925.md) | 固定原型、GT 与正则后存在可恢复实例；λ=0.003 的失败实例平均 IoU 约 +0.129，位移中位数 4.25。使用 GT，不是可部署方法。不能外推为所有原型能力完全足够。 |
| oracle 只是改变阈值吗？ | [7A 空间分解](experiments/coefficient_oracle_spatial_20260924.md) | 失败实例 AUC 约 0.847→0.958，最佳单阈值只解释约 28.2% oracle 增益。完整 oracle 包含空间排序改变；这不排除阈值解释小幅预测器收益。 |
| 负像素惩罚不够是否主要解释？ | [7B 损失重加权](experiments/coefficient_loss_reweighting_20260924.md) | 负像素加权及 hard-negative 降低 FPR，也降低覆盖率，未建立可靠整体 Mask75/AUC 收益。不能继续把“罚背景不够”当成已证实根因。 |
| 正负梯度冲突代表不存在共同改善吗？ | [7C 梯度几何](experiments/coefficient_gradient_geometry_20260925.md) | 负余弦很普遍，但共同改善方向仍存在；固定原型下的 BCE 对系数是凸目标。不能用负余弦本身证明无共同解或非凸阻碍。 |
| 当前无 GT 表示能预测修正吗？ | [7E 方向预测](experiments/coefficient_direction_predictability_20260925.md)、[7Q 像素方向](experiments/coefficient_pixel_direction_20260927.md) | 部分可预测信息存在，但失败组与正常解码收益有限。已有输入和预算的阴性结果不证明所有共享预测器不可能学习。 |
| “失败”就是“当前修正器能救”吗？ | [7K 失败门控](experiments/coefficient_failure_gated_correction_20260927.md)、[7L 跨折收益预测](experiments/coefficient_expected_benefit_20260927.md) | 失败概率与可修复性不同。7L 可排序部分收益，但没有建立门控超过不门控的可靠整体优势；不自动追加新 gate。 |
| 是否只缺边界或简单归属信息？ | [7O 归属读取](experiments/coefficient_ownership_readout_20260927.md)、[7R 区域分解](experiments/oracle_spatial_decomposition_20260927.md) | 区域依对象而异；既有简单读取对照未建立可靠收益。不把所有失败统一成边界或 ownership 缺失。 |
| big-global 的小收益是否值得作为独立方法？ | [7V 冻结确认](experiments/coefficient_frozen_confirmation_7V_20260929.md) | 504 张有效图、3,560 个官方候选，图片 macro IoU +0.092 pp，95% CI [+0.022,+0.167] pp；相对单阈值仅 +0.006 pp，区间跨零。低于预设 0.2 pp 实用量级；停止该结构扩展。 |

## 最近最关键的协议区分

### 几何候选上的共享末层正结果

[几何阶段 A/B](experiments/coefficient_shared_affine_attainability_20260930.md) 在 196 张 val 图、1,301 个几何匹配候选上报告图片 macro 原图 IoU **+5.48 pp**。但 990 个同 GT 的 raw 位置与官方 TAL 不同，约占 76.1%。这是固定几何候选上的改善，**不是官方 TAL 正样本结果**。没有最优性证书时，剩余目标差距也不能称为共享映射必然不可达。

### 官方 TAL 同域重求解

[官方 TAL 审计全文](reports/coefficient_official_tal_affine_20260930/REPORT.md) 与 [概述](experiments/coefficient_official_tal_affine_20260930.md) 使用 796/197/196 张有效 fit/dev/val 图，对应 6,058/1,402/1,346 个官方 one-to-one 正样本。固定原权重分配、特征、完整原型、框与标签，仅重新求解原生系数末层。

- fit 诊断目标由 **2.562587 降至 2.326778**；独立有限 oracle 为 **1.367635**。这份参考损失与部分早期目标数值不同，不能沿用旧“回收比例”。
- 当前共享数值解在 100 次迭代到达上限，驻点梯度范数 0.00676，**没有精确最优性证书**。
- val 图片 macro 原图 IoU **0.79904→0.78919，−0.985 pp**，95% CI **[−1.353,−0.644] pp**；Mask75 **831→797**，修复 17、损伤 51。
- 同一官方对象的 GT 辅助有限 oracle 仍有 **+5.034 pp** macro IoU，95% CI **[+4.136,+5.885] pp**。

允许保留的判断是：**这次数值精修降低了 fit 目标，但拟合收益没有迁移；固定条件下的实例可恢复空间仍然存在。** 不能把它写成“所有共享末层达不到”“h 必然缺信息”“官方优化器出错”或“BCE 是唯一根因”。该轮已结束，不自动解冻前层、加网络或开展完整 AP。

## 历史路线与独立论文线

- P3 输入干预及局部特征替换曾获得定位恢复证据；[短程蒸馏](experiments/counterfactual_p3_distillation_20260914.md) 有分层改善，但[全 COCO 对照](experiments/counterfactual_p3_fullcoco_20260914.md)未建立明显总体分割 AP 收益。编辑恢复不等于训练后原图收益；历史 P3 草稿不是当前主线的成熟结论。
- [掩码边界校准路线](experiments/mask_boundary_route_20260914.md) 是另一条独立论文线；现有 4,500 图 one-to-one 结果及适用限制见其报告。不能把它的 AP 收益加到当前系数预测主线上。
- 更早的 CCL、密集子集、转换检查和众多版本试跑都在[完整索引](EXPERIMENT_INDEX.md)。部分只有元数据或机器统计，结论保持未知。

## 尚未解决

1. 可恢复的系数方向为何没有由原生预测稳定生成？哪些环节有直接证据，哪些只是某种 probe 的阴性结果？
2. 当前固定样本上，共享映射约束、数值求解精度、跨图泛化与任务效用分别留下多少差距？最新共享解不提供完全的最优性判定。
3. 是否存在能迁移到正常无 GT 输出的针对性干预？目前主线尚未完成该证明。

任何下一步建议都应先定位已有 Study、协议与证据版本，避免换名重复实验。主线不预先绑定 CCL、密集场景、边界、梯度冲突或外挂修正器。


## 最新补充：冻结共享解的同目标最优性证书

[冻结共享解证书](reports/coefficient_official_tal_affine_20260930/FROZEN_SHARED_CERTIFICATE_REPORT.md) 已完成。它只读取已有官方 TAL fit 缓存、共享末层参数和独立 oracle，没有更新参数或重新评价掩码。

- 共享当前值 `U_S=2.3267777974`，同目标误差上界 `epsilon_S=0.0738659169`。
- 独立 oracle `U_I=1.3676346957`，已有平均误差上界 `epsilon_I=3.56e-7`。
- 共享最优与独立 oracle 最优的目标差距区间为 `[0.8852771746, 0.9591434678]`；下界约覆盖当前差距的 92.30%。
- 因而在当前固定官方特征、原型和共享仿射末层范围内，剩余差距不能主要归因于共享求解未充分完成。

该证书是条件于 FP64 舍入与 SVD/梯度余量的数值审计，不证明整个 YOLO 系数头、前级特征或历史训练过程的唯一根因。当前主线在此处收敛，不自动追加新模块或 AP 实验。
