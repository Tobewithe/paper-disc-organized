# 当前研究状态：2026-10-04

**当前主线：从分割失败实例追查实例特征、原型响应、系数生成和掩码形成，再用受控实验检验可迁移的改进。** 不预先绑定密集场景、CCL、边界或某种外挂修正器。目标是修复实际失败，同时控制对原成功实例的误伤。

本页汇总已经完成的证据及已登记的在途工作。数值来自链接报告；除特别注明，近期表格是正常原图解码下固定官方 one-to-one TAL 候选的图片 macro IoU，单位为**百分点（pp）**，不是 COCO AP。

## 目前最主要的成果

1. **区分候选能力与最终输出。** [COCO 5000 图能力诊断](experiments/coco_raw_capability_5000_20260916.md)检查约3083万raw候选、36,335个普通GT：24,823个GT存在raw Mask75候选，最大一对一匹配24,822，正常输出匹配22,767。同一口径下6,688个GT有达标框却没有Mask75掩码。失败不是一种单一问题，候选存在率也不是AP。
2. **固定原型下确有部分可恢复空间。** [有限oracle](experiments/coefficient_finite_oracle_20260925.md)与[空间分解](experiments/coefficient_oracle_spatial_20260924.md)显示，一些失败能通过有限系数改变获得较好掩码，收益包含空间排序变化。这需要GT，不证明原型对全部实例充分，也不是可部署方法。
3. **共享读出有可量化的条件约束。** [官方TAL共享仿射审计与证书](experiments/coefficient_official_tal_affine_20260930.md)给出同目标下共享最优与逐实例oracle最优的差距区间[0.885277,0.959143]。该差距不能主要归因于这次共享求解未完成，但只约束固定特征/原型下的仿射函数类。
4. **任务内集的有限预算证据。** [10月1日可行性证书](experiments/coefficient_mask_task_feasibility_20261001.md)：P3保守下界72.0428超过位移预算45.6735，说明声明的质量安全内集在这一固定共享映射和预算下不能全部达成；不等于所有Mask75解不可达。

这些成果说明“诊断上可以恢复”与“共享预测器能够泛化地生成修正”之间存在需要解释的差距。**目前尚未证明整网唯一根因，也没有建立当前主线的稳定实用方法收益。**

## 最新：候选关系读取已经完成

[完整概述与证据](experiments/candidate_relation_readout_20261004.md)。计划1024fit/256dev，实际1012张训练图、7172个TAL候选，253张开发图、1816候选。单seed，每组3轮、各192次参数更新。固定原型、上游特征、框和原候选，邻居来自冻结的GT-free预测池。

- A：原权重；N：普通系数分支微调。
- S：保留邻居几何，用自身响应替代邻居响应。
- T：真实邻居响应；M：在各邻居支持内错配空间响应。
- S/T/M同结构、同初始化、同训练预算。正常裁切评价，没有借外扩条件制造增益。

| 比较/对象 | 图片macro IoU差 | 95%图片配对区间 |
|---|---:|---|
| T−S，开发全体 | +0.0038pp | [−0.0071,+0.0177]pp |
| T−M，开发全体 | +0.0027pp | [−0.0012,+0.0066]pp |
| T−A，开发全体 | −0.0287pp | [−0.1749,+0.1426]pp |
| T−A，框好掩码差353候选 | +0.0810pp | [−0.5547,+0.7634]pp |

全体T相对A修复18、误伤16，净+2；不能用少数跨阈值修复代替总体掩码质量。T−S在训练抽检也只有+0.0036pp。原始结果保留“未通过预定初筛”。

**新增解释边界：小预算没有表现出有效收益，不足以否定充分训练后的潜力。** T轨迹训练BCE为2.4426→2.3901→2.3238，尚不能确认收敛；这些是训练过程均值，不是收敛证明。当前T/S差异很小，也不能全归因于评价图片少。窄配对区间不覆盖训练规模、不同seed及历史方案选择的不确定性。具体解释已与结果一起收录。

## 最新补充与下一步建议

- [已有证据通路使用审计](experiments/evidence_path_usage_20261004.md)在本次发布期间完成并回传。固定同一均匀64点U参数，完整路径相对关闭额外残差为+0.0096pp（95%区间[+0.0020,+0.0164]）；完整路径相对仅保留证据均值为+0.0026pp（[−0.0002,+0.0059]）。两项区间均落在预设±0.1pp内。额外路径有非零作用，但当前空间变化没有实用量级的任务增益；不由此推断训练不足、梯度竞争或信息不存在。
- **关系读取的扩大训练尚未启动。** 更公平的建议是约1k图增加更新数，与约4k图匹配更新数和step学习率日程对照，并固定更大的开发评价集。分开辨别训练时长、样本多样性与评价精度；不在看过结果后改写原初筛门槛。
- 如果新增信息在充分拟合中形成优势但不能泛化，再追数据/泛化问题；如果在fit中也没有增量，优先检验信息表示和有效学习路径。不能无限追加数据或模块，也不能仅凭短试把整个机制判死。

这些建议尚不是已启动的训练队列。任何正式方法收益最终都需要不借测试GT的完整输出、标准COCO评价和独立确认。

## 10月4日：位置×目标互补判别

[完整报告](experiments/position_objective_complement_20261004.md)完成了官方 TAL 位置／几何匹配位置与官方 ROI 目标／原生目标的 2×2 补格。官方 TAL 位置上的共享修正使 val 图片 macro Mask IoU 下降 **0.692 pp**（95% CI [−1.116, −0.298]）；几何匹配位置上，官方 ROI 目标为 **+5.269 pp**（[+3.863, +6.809]），原生目标为 **+5.483 pp**（[+4.150, +6.960]）。将几何位置学到的修正迁移到官方位置后仅 **+0.086 pp**（[−0.183, +0.366]）。

这组结果支持“原型到系数读出的效果依赖候选位置”，但不等于已找到可部署方法：几何匹配位置不是官方 TAL 监督位置，且跨位置迁移没有收益。donor 交换和低阶空间 affine 的补充检验也未达到继续门槛，因此停止当前配置；后续若继续，只能设计新的、无 GT 的位置条件化读出并进行独立确认。

## 阅读边界

1. oracle、条件数值证书、固定候选诊断和正常完整推理分别回答不同问题。
2. 图片内实例相关，配对统计按图进行；Mask75修复率不是COCO AP。
3. “停止当前配置”不等于“该类方法被证明无效”；“尚未排除”也不等于值得无条件扩训。
4. 当前科研目标仍未达成。保留负结果与未知信息，先查已有证据，再选择针对具体对象的下一步。
