RESEARCH DESIGN

三个模块，沿着真实难点推进

检测决定“有没有看见”，身份表示和时序决策决定“是不是同一个”。

MODULE 01 / 看清个体

分割引导的身份表示

相邻个体挤在一起时，用可见掩码聚合个体特征，再学习同一个体在不同帧中的对应关系。

图像 → YOLO26 分割
→ 个体掩码池化 → 64 维身份特征
  • 检测器与原始特征冻结
  • 仅使用训练视频的真实 ID 监督
  • 为全部外观对照共享同一表示
MODULE 02 / 记住可靠信息

预测“更新有没有帮助”

检测分数高，也可能把邻居或遮挡写进记忆。小网络判断本次写入能否增加后续身份区分能力。

更新收益 = 更新后区分度 − 更新前区分度
预测收益 > 0 才写入记忆
  • 未来帧只用于构造训练目标
  • 运行时只读取当前与历史
  • 与普通重叠冻结做直接对照
MODULE 03 / 谨慎恢复身份

短轨迹竞争确认

遮挡后第一帧可能分不清。汇总几帧重现证据，让旧身份与新片段共同竞争，再决定是否接回。

受保护记忆 × 重现短轨迹
→ 一对一匹配 + 竞争差距 → 确认 / 暂缓
  • 最多等待 6 帧，代价纳入评价
  • 不回写已经输出的历史 ID
  • 不能确认时允许新建身份
创新候选在于收益监督与重现竞争决策；分割、外观特征、记忆冻结和匈牙利匹配本身均有既有研究。是否带来额外收益以对照实验为准。
