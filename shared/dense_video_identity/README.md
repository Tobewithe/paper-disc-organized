## 结构

- `infer.py`：冻结 YOLO26、预测掩码池化、固定检测缓存。
- `learn.py`：身份头 `1024→128→64`（139,456 参数，300 步）与收益头 `8→32→1`（321 参数，200 步）。
- `tracking.py`：共享外观对照、收益记忆、最多 6 帧的竞争确认；不修改过去输出。
- `evaluate.py`：官方 TrackEval、逐视频分量、GT 间断重现事件与冻结门槛。
- `server.py` / `single.py` / `web/index.html`：离线系统与真实导入分析。
- `showcase.py` / `render.py`：从真实输出绘图、制作对照视频，禁止手工美化轨迹。
- `audit.py` / `test_invariants.py` / `verify_delivery.py`：评价器、因果状态、期限、检测身份、修复影响与视频核验。
