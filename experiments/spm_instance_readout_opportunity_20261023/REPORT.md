# 实例均值原型读出实验结案

432 张真实 dev、2863 个可见 GT 的零训练实验已完成，Slurm221 运行成功，Slurm222 独立 CPU 复算通过。**训练确实改善了特征区分能力，但现有均值原型无法产生实用的实例掩码；不再扩大这个配置。** 用户随后将研究重点明确为对象本身的形成，后继设计为 [V5 猪对象原型](../../paper/manuscripts/spm_yoloseg/OBJECT_PROTOTYPE_DESIGN_V5_20261023.md)，新训练尚未启动。

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | V4.1 的原型 F 相对同预算 B 仅 +0.0417pp，关原型仅 −0.0565pp。需要检验现有嵌入能否通过实例条件均值读出真正有效的 Mask，避免只靠 loss 下降判断原型学好了。 |
| **机制假说** | H_readout 预测：若主要缺口是全局压缩而现有坐标已有可用实例信息，则换成 GT 实例支持应改善同一检测的 Mask。竞争解释为：现有训练目标与稀疏采样未形成适合此种稠密读出的表示。该对照能检验有限读出机会，不能独立确定所有失败原因。 |
| **针对性方法** | 冻结 B 最终输出身份与权重；T 为训练 128D，U 为同结构随机 128D，R 为原始 512D。先完成仅 RGB/预测支持的部署输出，再读 GT 做同一官方 Box75 检测的实例均值、leave-one-out 与其他实例/背景竞争。全量 2385 对包含失败 305、成功 2080；R 维度不同，存在容量混杂。训练 0 步、原 test 未读、无阈值搜索。 |
| **整体结果** | T 的 GT 支持失败组 IoU 为 0.5660，高于 U 0.4496 与 R 0.5211，说明学到部分信息；但原生为 0.6613，T 下降 0.0952，仅修复 2/305，且将原成功 1410/2080 变为失败。无 GT T AP 为 25.2765，对 B 57.3153 下降 32.0387pp；对既有 G/R 57.2036/57.2395 分别下降 31.9271/31.9630pp。后两者结构不同，不作独立因果归因。训练实例覆盖 8001/14642，不能把未覆盖归因直接当作已证瓶颈。 |
| **研究决策** | 关闭冻结坐标下单均值余弦读出的扩训；保留“训练有部分区分作用”的事实，不把阴性解释成所有对象先验无效。结合用户新命题和动物对象学习文献，优先研究共享体形与部位关系能否帮助局部观察推断对象。唯一后继是 V5 对象学习 v0：成组数据、跨视角/遮挡目标和同信息普通对象分支对照；若这些必要能力不优于对照则不扩大结构模型。该方向尚属待检验假说。 |

差值 AP 单位为绝对百分点；IoU 使用 0–1。T/U/R 的失败修复率为 0.66%/0/0，原协议要求 20%；T 失败组平均 IoU 差要求 +0.05，实际 −0.0952。均未通过。失败对象中 S=142、M=163、L=0，不能给出大目标失败组结论；同一数据上的诊断不声称外部泛化。

**术语更正：** 原始 Run 报告和案例图部分标题使用“GT 上界 / upper-bound”。准确含义是“给定 GT 实例支持的有限均值读出诊断”，不是现有特征在所有读出器下的数学性能上界。原始产物保留，以此说明校正解释。机器裁决中的 `direct_mask_supervised_query_and_basis_learning_with_matched_input_and_capacity` 是当时预注册的未启动建议；其优先级由用户的新对象研究命题及 V5 取代，不修改旧裁决。

验收：五变体各 24 项 bbox/segm 统计共 120 项、2385 条对象 IoU 的独立复算误差均为 0；原生预测重放一致。36 项结果包文件、3 项验收清单文件、2 项验收源码共 41 项本地 SHA 一致。四组图已检查；原覆盖图图例遮住 M 组部分标注，展示修订见 [图集说明](VISUAL_GUIDE.md)。
