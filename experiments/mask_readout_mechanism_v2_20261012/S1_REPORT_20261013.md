# S1 同输出有限系数恢复检查

采用 S2 的 2k adapter pilot。正式 Run `RUN_S1_ORACLE_f35a1399ac244f74aeebf94e4e843949` 对基线 T=6229 中哈希固定的256个GT完成求解，256/256数值收敛，122/256（47.65625%）达到同一最终检测的 MaskIoU≥.75，超过预注册 ≥200样本、≥20%机会门槛。

证据位于该 Run 的 `EVAL_CONTRACT.json`、`ORACLE_CONFIG.json`、`ORACLE_RESULTS.jsonl`、`CONTROLS.json`、`SUMMARY.json` 和 `DECISION.json`。243张相关图片的全部原生检测均通过零残差RLE和已知系数解码核验；解析非零最优点控制通过。`CONFIG_AUDIT.json` 在结案后复核配置、源代码、权重、原始GT、运行时数值开关和每个结果的求解器身份；`LOCAL_TRANSFER_VERIFICATION.json` 验证28个回传文件哈希。

按原GT面积，小/中/大对象分别找到38/148、44/64、40/44个有效恢复。47.66%是这个固定样本上已经找到的机会，不是可部署修复率或AP提升，不外推到全部失败GT。所有GT来自有效原生输出账本，框与掩码匹配分别保留；最终评分使用完整原图GT并集。
