# S2：固定原生输出的 2k adapter pilot 结案

停止当前 B 配置晋级，不进入 S3 或20k扩量。笔记本 YANGLEI 完成 B/C 各2000图×3epoch、1500个优化步；训练及评价配置核验通过，B 的目标效果、总体IoU和成功损伤三项预注册门槛全部失败。

512张固定开发图含655个目标T，分布于257张图；总体IoU护栏覆盖2925个固定配对GT、508张图。bootstrap固定2000次、seed=1729、按图等权、percentile/linear区间；无T图片不以零计入目标均值。B最后checkpoint及推理合同冻结后，一次抽取1024个基线成功GT，覆盖878张图；评价这些图的全部11014个GT，只以抽中的1024个S计损伤。开发集与损伤图并集为1299张，B/C均完整评价。

支持的相对结论是：B 比 C 少损失 **0.9342 pp**，配对95%区间 **[+0.5933,+1.3305] pp**。这为当前设置中保留空间排列的相对贡献提供证据；B、C对原生基线均为负增益，故拒绝把当前配置作为有效的后训练修复方法。C是预定机制对照，不用于事后替换主要方法。S1的122/256有限系数恢复机会结论保留，见[S1报告](S1_REPORT_20261013.md)。

S3全5000图AP验收未启动。Run内的1299图AP是开发/损伤图并集的辅助指标，不能与S0全5000图或官方发表AP直接比较；本轮不产生全量方法AP结论。
