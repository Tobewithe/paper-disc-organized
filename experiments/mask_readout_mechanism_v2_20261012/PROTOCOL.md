## 1. 必须先修正的证据边界

### 1.1 现有 F/R Smoke 不是全链路验收

本次直接核对 `representation_reachability_20261010/scripts/arm_smoke.py`：

- F/R 的 `feature` 来自 `avg_pool2d(fit[:2], kernel_size=8)`，即降采样 RGB，而非实际 YOLO 中间特征。
- `candidate` 来自 `torch.arange(...).reshape(2,32)`；身份检查是候选与其 clone 相等。
- F/R 反向用 `logits.square().mean()`；C 用输出张量均值之和，均不是完整官方 mask 任务损失。
- R 的 Smoke 单独调用 `PrototypeResidual`，没有接上 F 的完整局部系数修正路径。
- `preflight.py` 的 `load_images` 对缺失/无法解码文件使用 continue，不能承担正式固定清单的完整性证明。

因此保留旧结果为“模块级有限性检查”，新 Study 的 G0 必须重新验证真实特征—候选—任务损失—解码—评价链。不能只补一个 COCO evaluator 就宣布全部工程通过。以上是源码审查结果，不是重新执行旧 Run 的结论。

### 1.2 有限 Oracle 未恢复，不等于不可表达

历史复导以 GT 框 BCE + 0.003 位移正则、有限 L-BFGS 求解，报告 4,843/6,456=75.02% 达到 Mask75。这个结果证明已找到的可恢复实例；剩余实例只能叫“该有限 oracle 未恢复”，不能直接叫“25% 原型容量不足”。

BCE 正则目标最优不等于 IoU 最优；数值求解停止也不等于达到所有二值掩码的能力上限。没有支撑上界或可核验证书，不作不可表达判定。

### 1.3 现有四臂不足以独立归因

F−C 同时改变输入结构、参数化与可训练参数；R−F 同时增加参数和空间基。因此本计划新增两个一开始就锁定的必要训练对照，而不是看到阳性后临时补消融。原四臂协议不静默修改，新 Study 明确继承哪些设置、改变哪些设置。

## 5. 六臂矩阵：五个训练臂，两个新增归因对照

令 P 是冻结图像原型，c0 是冻结原生系数，U_i 是依据自身预测框在真实 cv4 输入特征上采样的4×4 ROI。每个分支/金字塔层用真实通道数 D，层路径、shape 和数据指针来源在 G0 记录，禁止用 RGB 替代。

| 臂 | 定义 | 可训练部分 | 能回答的问题 |
|---|---|---|---|
| A | P c0 | 无 | 官方参考 |
| C | P c_theta | 原生 cv4/one2one_cv4；其余冻结 | 该预算下原生系数分支适配 |
| F_mean | P(c0+g_theta(mean_tile(U_i))) | 与F完全相同的ROI MLP | ROI均值信息但没有4×4内部布局 |
| F | P(c0+g_theta(U_i)) | ROI MLP | 保留ROI内部布局的系数读出 |
| R_parallel | P(c0+g_theta(U_i)) + Pi_[P,1] Q_theta d_theta(U_i) | 与R完全相同的所有参数 | 限制回原型系数+全局偏置空间的同容量对照 |
| R | P(c0+g_theta(U_i)) + Q_theta d_theta(U_i) | ROI MLP、4维系数、4通道Q投影 | 完整空间残差干预 |

`mean_tile(U_i)` 在每个通道内取16格均值，再复制回4×4；输入尺寸、MLP参数量、训练顺序、优化器与F相同。它控制“ROI内部布局”，不是证明所有局部信息都只存在于4×4布局，也不等价于证明原生 h 没信息。

F 的 MLP 为 `Linear(D*16,256) -> SiLU -> Linear(256,32)`。R/R_parallel 在相同结构上增加4维 d 输出；Q 从真实原型输出前的冻结特征经1×1投影产生4通道。若特征空间尺寸不同，唯一允许的确定性重采样必须在 G0 前锁定；不能运行中变成高分辨率分支。

R_parallel 与 R 参数数量、初始化及可用输入完全相同。令 P_plus=[P,1]，在原生 prototype 网格上加入固定常数通道；Pi_[P,1] 由P_plus计算，是**无GT的固定投影**。Q先投影到col(P_plus)再走与R相同的loss/decoder。这一控制保留额外网络，也允许整体logit偏置（即相应的全局阈值调整），唯独不给它超出系数+偏置读出的空间自由度。单纯用col(P)作零假设不足：Q的一个常数通道就可能只是在做阈值校准。报告其实际有效秩与梯度，不能假装两者函数类相同。

结构预检先确定Q的源张量是否真的具有超出col([P,1])的方向。若源只是P的线性重参数化，Q仍落在该空间，本构造不能检验空间扩展；必须在正式训练前固定真实的上游张量及其shape，不能训练失败后换hook。只凭通道数大于32也不能宣布新增自由度，需报告拼接矩阵的秩/奇异谱与预测支撑下的有效残差；这是G0结构检查，不是方法有效性证据。

所有残差末层零初始化，Q投影非零初始化；F与R共有参数在同seed中按名称绑定相同初始字节。Q非零、d=0时首步Q梯度为0是链式法则的预期，不是失败；用若干真实任务更新后审计梯度路径。严禁Q与d两侧同时零初始化造成永久断梯度。

新方法作用于全部正常输出，不事后改成first64。RCMC_full为同输出范围强对照；RCMC_first64另保留部署权衡，范围必须明示。训练依旧使用全部合格TAL正样本，不按事后修复能力选样。

### 方法效用Gate（承接旧阈值，作用于新Study自己的同域A）

- G_task：R−A Mask AP点估计至少+0.3，配对整图95% CI下界>0。
- G_increment：R−F至少+0.1 AP点，95% CI下界>0。
- G_safety：AP75及APsmall各自点差不低于−0.1 AP点；另用单侧95%下界检验不劣于−0.1（区间不足不能写已证明安全）。原成功损伤率单侧95%上界≤1%。
- 两个seed都满足上述规则才允许新增第三seed与确认阶段。所有seed的原始点值和区间照实报告，不用均值隐藏反向seed。

损伤率主分母为本次冻结canonical唯一匹配中的A成功实例，另报全部实际修正成功实例的损伤率，防止“不动大量实例”稀释风险；第三表按旧重复关联复放用于历史比较。两套分母不能换用以追通过。这里为新Study预先定义canonical分母，继承的是1%的投资阈值数值，不是把旧重复关联损伤率与新唯一关联率直接等同；旧协议的判定不重算、不覆盖。空mask在IoU中算0；purity无定义记null；无关联图片不人为填0。

若任务Gate不满足，仍完成已预定E3对已有checkpoint的读数以解释本次干预，但**不新增训练、不做外部扩张或改模块补救**。

## 8. E3：机制识别，而非相关性展示

### 8.1 训练期两个关键对照

M_layout = AP(F) − AP(F_mean)：固定完整模型容量与ROI平均内容，检验4×4内部布局是否带来独立效用。门槛：点差≥0.1 AP点，调整后的单侧区间下界>0。

M_space = AP(R) − AP(R_parallel)：固定额外可训练网络，检验开放原型空间外自由度是否带来独立效用。门槛：点差≥0.1 AP点，调整后下界>0。

C−A与F−C只作训练基线与综合结构比较，不能替代上述两个机制对照。R_parallel应报告实际拟合/梯度状态，避免把坏优化器或错误投影当成空间不足。

### 8.2 测量真正被使用的空间外分量

不以Q本身的Frobenius范数比例作主证据：Q可能被d乘成零，尺度重参数化也会改变单独Q的统计。必须针对每个实际预测的有效残差。

令T_i包含真实解码中**第一次二值化之前**的连续变换：插值、逆letterbox、固定预测框支撑等；第一次阈值后的缩放/byte转换不能写进线性T_i。定义：

B_i = T_i P； B_plus_i = [T_i P, T_i 1]； e_i = T_i(Q d_i)。

e_parallel = Pi_{B_plus_i} e_i； e_perp = e_i − e_parallel。

主机制使用B_plus_i，以排除系数变化加全局偏置；纯B_i空间的分解只作次级读数。

rho_i = ||e_perp||² / ||e_i||²（e_i=0时记“不活跃”，不强填某种证据值）。

FP64 SVD，主相对截断1e-6；1e-8/1e-4仅预先锁定的数值敏感性，不能选择最有利版本。报告条件数、有效秩、重构误差、活跃率和实际范数。若rank阈值改变使主要机制结论翻转，机制记 `NUMERICALLY_UNSTABLE`。

rho不是效用指标：非零只能说明连续响应超出当前有效系数+偏置线性空间，不证明更接近GT，也不证明新二值掩码不可能用P的另一组系数表达。

### 8.3 同一已训练R上的定向删除

只在固定D_mech面板运行；不训练新模型，不重新匹配，不重排分数。分别输出：

- R_full：完整输出。
- R_drop_perp：保留原生项、已学Delta-c和e_parallel，只删除e_perp。
- R_drop_parallel：保留e_perp，只删除e_parallel，辅助解释。
- R_amp：将e_i乘以 ||e_parallel||/||e_i||，保持剩余残差总范数与R_drop_perp相同，但保留原方向；e_i=0时恒等。
- R_zero：删除整个Qd，保留R自身学到的Delta-c，不冒充重新训练F。

M_remove = image-macro IoU(R_full) − image-macro IoU(R_drop_perp)。门槛：≥0.10 IoU百分点，调整后下界>0。

M_specific = image-macro IoU(R_amp) − image-macro IoU(R_drop_perp)。门槛：≥0.05 IoU百分点，调整后下界>0。

这里同剩余范数控制针对“只因修正总幅度减小”的解释；它不是所有分布外干预的完美控制。**同参数删除与同预算重新训练R_parallel共同提供证据，任何单项不独立宣布原生历史根因。**

主统计为固定关联全体的image-macro IoU；目标失败组、原成功组、S/M/L、前景占比为预声明次级分层。只改善失败组、同时伤害原成功组，不能替代全体效用和安全Gate。不可用局部面板的AP冒充完整5k AP。

把每个对照从同一R_full独立构造；不同删除的效应一般不可相加。

### 8.4 与历史Oracle相联，但不把它作为新监督

在同一正常候选机制面板上，复用已审计7D有限oracle定义及精确几何，离线求解，不重新选raw、不把GT传给预测器。每个候选记：

- A已经成功；
- 有限oracle找到Mask75见证；
- 有限oracle未找到且数值条件达到；
- 求解未达数值条件、退化或输入缺失（UNKNOWN）。

只要有效有限系数实际解码达标，即是恢复见证，不要求必须达到驻点。未恢复即便达到BCE驻点，仍只称“该oracle未恢复”。

比较R−F在这些预定义组上的效应，并给差中之差作为描述性异质性。组别与基线IoU/尺寸等相关，故该组间差不是随机化因果效应。不得根据哪个组效果最好重写主命题。

方向分析使用同解码空间内的logit变化：空间内分量与P系数oracle对齐，空间外分量单列效用。不能要求空间外分量与空间内oracle方向高度相关——两者由投影构造近似正交。

## 9. E4：二值表示证书，防止把logit空间混同mask空间

这一分析自始预声明，在E2方法Gate与M_space/M_remove均通过后执行；不是看到某个可视化后新增算法。它不新增训练。

目的仅为：判别R产生的**这个特定二值图案**，能否由固定P、以及固定P加全局偏置重新表达。即使不可表达，也不等于P不存在另一张IoU≥0.75的mask。

在固定第一次阈值前网格，使用实际有效矩阵B_i，令Y_R为R在该网格的二值结果。对前景像素约束 B_i(u,:)c ≥ 1，对背景约束 B_i(u,:)c ≤ 0。前景严格>0、背景≤0的有限齐次线性分类，只要前景非空，存在解即可按有限正数缩放使前景最小margin为1；允许背景恰好为0。没有前景时c=0是平凡可行见证。

先对B_i执行上述自由系数线性可行性问题，再对B_plus_i执行允许全局偏置的相同问题。仅前者不可行而后者可行时，分类为“全局偏置足以重新表示”，不算排除了阈值解释。主空间结论只引用B_plus_i的证书。不得用随机梯度下降失败来判断不可行。投影网格和此处证书网格必须相同；若实际阈值不是0或有额外非线性，先推导正确约束，不能直接套用。

固定预算：在D_mech中，按R修复、R损伤、未跨阈值三组各最多80例，组内按预冻结hash选，共最多240例；外加16个原生已知可行对照，总上限256。它是条件分层样本，不将总体占比外推到所有GT。每例每个线性问题求解上限120秒；最多256例×2问题；超时不追加，不改约束。

输出三态：

- `FEASIBLE_WITNESS`：保存c，独立检查所有像素约束并经过实际decoder回放；明确数值margin。
- `CERTIFIED_INFEASIBLE_PATTERN`：保存可独立验证的Farkas对偶证书。单纯solver返回infeasible不算证书；要求在明确的冻结数值线性模型下用精确有理/区间核验，否则降为UNKNOWN。
- `UNKNOWN_NUMERICS_OR_TIMEOUT`：无有效证书；不并入不可表达。

数值模型证书须声明其相对冻结B_i的精度语义，不把实数线性结论冒充所有FP32重排实现的逐bit保证。若阈值后还有非线性缩放，证书仅保证第一次阈值网格图案，不自动证明最终图像二值图案也不可表达。

本分析可加强表示解释，但不是本计划H中“连续输出空间分量有独立效用”的必要条件。没有证书就删去二值容量突破主张，绝不反复扩大求解预算追不可行。

## 11. 统计规范与检验力

### 11.1 指标单位

AP以0–100展示，差值叫AP点；IoU内部0–1，0.001等于0.10 IoU百分点；损伤率是比例/百分比，不能与IoU百分点混写。每张表包含分母、split、branch、checkpoint、source hash。

### 11.2 主比较与多重检验

全量任务Gate用配对整图bootstrap 5000次、95%区间，每seed单列。四个机制比较为F−F_mean、R−R_parallel、R_full−R_drop_perp、R_amp−R_drop_perp，构成一个固定家族。报告普通95%区间，同时以Bonferroni单侧98.75%下置信界>0承担家族判定（0.05/4）。这是bootstrap近似推断，不宣称有限样本精确覆盖。

实际意义点门槛分别为0.1 AP点、0.1 AP点、0.10 IoU百分点、0.05 IoU百分点。点门槛与下界>0是组合投资规则，不等于区间已证明效应大于该实际意义门槛。

所有分层、rho分位数、可视化和Oracle组间分析默认次级/探索性；不以其中任一阳性取代主要比较。主命题要求全部必要证据，因此不能只保留最显著的一项。

### 11.3 重采样实现

同一次draw对所有臂重采样相同图片。COCO AP不是逐图AP的均值：每次必须重新构造被抽中图片的独立副本身份、保留预测/GT/crowd/ignore后做正确匹配/排序/累积，或用已验证等价的缓存算法。必须用若干固定draw对标准COCOeval逐项核对，不能重复image ID导致副本被合并。

包含零GT图片和没有诊断关联的图片参与正常AP；诊断image-macro仅在其定义域统计，不把缺失指标填0。每图多个detection/GT的相关性保留在图像簇里。视频外部集按场景簇。

种子不确定性与图像采样不确定性分开：每seed图像CI、seed间均值/范围全部报告；三个seed仅能提供有限复现证据。可附seed×image层级bootstrap，但不能把三seed×5000图当15000个独立训练实验。

### 11.4 检验力与停止解释

先用历史配对产物估计目标效应下的区间宽度，作为计划检验力说明；不得通过新方法输出选择最有利样本量。机制面板扩展只允许第4节预先规定的基线分母检查，不能“看到CI跨零再补图”。

未过Gate分三种：上界也小于实际意义门槛为“本预算下效应小”；区间覆盖有用效应为“证据不充分”；工程/数值未验收为“无有效科学判定”。三者都可停止当前投资，但不能都写成机制被证明不存在。
