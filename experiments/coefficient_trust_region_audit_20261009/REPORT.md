# 功能空间信赖域读出审计：未达预登记门槛，路线停止

日期：2026-10-09（Asia/Shanghai）。研究线：`neighbor_sensitive_p3`。
协议先行见 [PROTOCOL.md](../PROTOCOL.md)，参数与门槛执行前冻结。本审计不训练、无新前向。

## 结论

机器判定 **`STOP_ROUTE`**：信赖域投影**没有**同时满足“保留 ≥80% oracle 增益”和“保护区扰动降 ≥20%”，
且其保留率**低于随机同规模支持对照**。四项预登记门槛：

| 门槛 | 规则 | 结果 | 数值 |
|---|---|---|---|
| G1 保留 | retention_T ≥ 0.80 且 bootstrap 下界 ≥ 0.75 | **未过** | 0.302，CI [0.269, 0.335] |
| G2 保护 | prot_T ≤ 0.80×prot_U 且 bootstrap 上界 < 0 | 过 | prot_T 0.062 vs prot_U 0.793 |
| G3 结构对照 | retention_T > retention_S，bootstrap 下界 > 0 | **未过** | T−S = −0.286，CI [−0.353, −0.205] |
| G4 成功护栏 | 原生成功子集 iou_T−native ≥ −0.005，下界 ≥ −0.01 | 过 | +0.0111，CI [0.0086, 0.0138] |

## 读数（1,375 候选；1,239 个 oracle 增益为正；663 原生失败 / 712 原生成功）

| 臂 | retention | 保护区 logit 改动（相对 oracle 自身） | ‖d‖ |
|---|---:|---:|---:|
| O 全 oracle | 1（定义） | 1（定义） | 4.19 |
| U 无保护投影（证据区拟合） | 0.555 | 0.793 | 2.09 |
| T 信赖域（证据区+保护，λ_R=10） | **0.302** | **0.062** | 2.15 |
| S 随机同规模支持 | **0.588** | — | — |

分解（读数的读法）：

1. **证据区结构没有价值**：按当前掩码不确定性选像素（U，0.555）与随机同规模像素集（S，0.588）几乎一样，
   U 甚至略低——为“低 margin 处拟合 oracle logit”选择像素不携带可测优势。
2. **保护区惩罚极其有效但代价大**：加入保护区项后，保护区 logit 改动从 oracle 自身改动的 79% 压到 6%，
   但保留率从 0.555 跌到 0.302。保护与保留在此参数化下是强权衡，且在预登记门槛处不可兼得。
3. **敏感性确认稳健失败**：最宽松的 λ_R=1 也仅 retention 0.491 / prot 0.187；λ_R=100 时 0.154 / 0.015。
   无一配置接近 G1 的 0.80。
4. **绝对增益仍存在但非本路线目标**：T 在原生失败候选上 IoU +0.109、原生成功 +0.011（无损伤），
   即受约束修正确实产生“受保护的小幅改善”；但按预登记定义（保留大部分 oracle 增益），路线停止。

## 边界

- 面板为历史复用 dev 图（非盲测）；诊断关联非同 COCO 匹配；无任何 AP 声明。
- 证据区/保护区的边带与阈值（m_E=m_R=1.0）为第一版固定工程选择；结论限于该类构造。
- 停止按预登记门槛执行，不追加扫描/调参/挑子集去追阳性；这不证明所有功能空间方法无效
  （例如不同的约束形式或可学低维证据仍有空间），只证明**这一构造**未达放行条件。
- 与既有阴性（空间 teacher +0.013pp、QCR、ACD、TriFlow valid_negative）并列，均为配置级结论。
