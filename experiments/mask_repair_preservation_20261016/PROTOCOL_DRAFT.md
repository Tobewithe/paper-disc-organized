## 2. 科学准入四问

**M1：主假说 H。** 在固定P的联合像素变化中，既有目标对“错误像素真正越过阈值”和“原正确像素不被推错”的区分不足；显式分工可以找到更有利的修复—保持折中。这里检验的是一个可干预的目标机制，不预设“32维必然存在不可避免冲突”。

**竞争解释 H_alt：** 改善只是修正幅度变小，或者目标干预在同一固定P中不能提供额外的安全收益；已有oracle方向存在而adapter未兑现，更应归入条件读出/优化的后继问题。AMT阴性支持认真保留这个竞争解释，但没有证明输入信息不足。

**M2：不同预测。** 若H获得支持，加入正确像素保护后，在相同有效logit改变量下应少产生TP→FN，同时保留修复，并相对同网格BCE找到实质更好的原图掩码。若只有改动幅度下降，等幅对照应消除优势；若有限目标本身无增益，就不把它投入新的训练。

**M3：匹配条件。** 第一阶段每臂都是同一检测的32个系数变量，固定P、c0、GT、ROI、网格、初始化、正则和求解预算，没有新增网络参数/输入。未来训练阶段固定原167872参数架构、原初始化、原2000图、数据顺序、优化器和每臂1500步；所有差异逐项列白名单。

**M4：机制移除。** 必须比较“错误修复目标”与“同目标加正确像素保护”，另做等幅方向对照。训练目标不能在推理时直接删除，后续必须用同预算移除保护项的训练臂验证，不能把同checkpoint简单缩小Δc伪称为删除了训练机制。

## 3. 下一项唯一实验：有限系数修复—保护干预（拟议）

### 3.1 对象与几何

- 使用原S1固定256条/243图，面板SHA `170676d3017e4be7cd213ff1094ca28065727807c915b7602ecdaec48238cf31`。不只挑100条或122条做主统计，不补样、不换检测；旧122条及L/G/R仅作事前已知分层。
- 固定原最终Box75检测、P/c0、框/类/score/排序、实际batch16/rect缓存几何和原生decoder。所有臂共享同一个**原生首次二值化前的输入尺度logit网格**及相同GT投影、预测框支撑；最终主评分仍为完整原图GT RLE的同检测MaskIoU。
- 原S1的proto尺度BCE oracle仅作历史见证，**不能直接充当本次输入尺度BCE控制臂**。新C臂须在与新方法完全相同的网格、ROI和数值实现上求解；必要计算不属于重复旧S1问题。
- 工程实现须读固定版本的真实`process_mask_native`与后续`scale_masks`路径，核准插值、裁切、阈值顺序。不得将“proto阈值”冒充原生首次阈值，或擅自把原生解码换成“最后在原图0.5阈值”。
- GT只进入离线有限oracle及测量，结果不算无GT部署效果。未找到解是有限求解结果；不作不可表达/不可行性证书。

### 3.2 三臂与一个无求解等幅对照

设监督网格内真实首次阈值前logit为`z`，`s=2y-1`。以**原生c0**一次冻结错误集合E及正确集合K，迭代中不重分组。原生判定为`z>0`。各非空集合内取像素均值；空集合项记0、实例保留在原分母。

| 臂 | 拟议目标/操作 | 要隔离的因素 |
|---|---|---|
| C | 同网格全部ROI像素BCE + `0.003*||Δc||²/2` | 新网格的匹配控制 |
| E | `mean_E(max(0,1-s*z)²)` + 同一正则 | 将修复目标集中到原错误像素；与C的差异是复合目标效应，不单独归因为某一个公式因子 |
| EK | E + `mean_K(max(0,m_keep-s*z)²)`，`m_keep=min(1,s*z0)` | 在E完全不变时加入正确像素保护，保护项权重拟定1，不扫描 |
| E-equal | 只把E得到的Δc乘一个非负标量，使同ROI内实际阈值前`Δz`的RMS与EK相同，然后通过原生decoder评分 | 排除“只是变化幅度更小”；无需新增优化或训练 |

K中`s*z0≥0`，因此拟议保护项在c0处为0；它不奖励已经满足保护间隔的像素继续变得更自信。错误margin拟定1。这里使用有饱和区间的平方hinge并显式分组；**`softplus(-s*z)`在相同归约下就是BCE，不能仅靠改写公式宣称新机制。**这些具体起点值并非已证明最优，正式冻结后不得根据结果调节。

等幅标量由预定RMS比值一次计算，允许大于1，不按GT收益选取。两臂均零时记录零变化；E为零而EK非零时，等幅方向不存在，记录无法支持此例的独立机制归因，保留分母。不能挑选只在等幅对照有利的实例。按原生FP32完整输出形状最终重放，不能以FP64代理目标达标代替实际RLE达标。

### 3.3 预期统计与拟议准入门槛

主统计按图内实例均值、再图等权；固定243图配对bootstrap 2000次、seed1729，区间算法在正式Protocol冻结。该面板已用于开发，区间不具有新盲测确认含义。

拟议门槛是**新机制探索的投资判据**，不是修改原S1/S2/S3 Gate：

1. **实际效用主量：** EK相对同网格C的原图MaskIoU平均增量≥0.005，95%配对区间下界>0。
2. **保护机制护栏：** 在首次阈值网格，`TP→FN/max(1,原TP)`按相同图宏归约；EK相对E-equal平均下降至少25%，下降量95%区间下界>0，同时原图平均IoU不得比E-equal低超过0.001。原TP=0的实例计0并单列数量；E-equal损失为0时不能声称满足相对下降。
3. **有效见证保留：** C臂达到原图Mask75的实例中，EK至少保留95%；列出每个新增与丢失ID。C没有有效成功时不能用空集合声称保留通过。
4. **有效性：** 全256条及预定对照完整、有原生zero-delta/身份/源码核验。数值未收敛仍保留；若影响裁决则记`INCONCLUSIVE_NUMERICAL`，不当作科学阴性或不可达。

主量、机制护栏、保留护栏和有效性均满足，才推荐下一阶段训练；不能只看其中最好的一项。首次阈值TP保护是**同一失败实例内部**的像素保护，不是对全22957个原成功GT的损伤保证。

### 3.4 预算与缺项

拟定单进程、CPU线程1；每臂同一float64 zero-delta有限求解预算，参考原LBFGS `max_iter=120/max_eval=150/history=20/lr=1`，相同正则及收敛判据。三臂最多`3×256=768`次正式有限求解；工程smoke固定最多4个面板外实例、≤600秒，正式总墙钟≤7200秒，新增产物≤2GiB。到预算停止，不能按科学结果追加迭代。**这叫零网络训练，仍有明确的oracle优化计算成本。**

正式冻结前必须补齐：原生首次阈值网格实现与浮点误差合同、三目标的梯度/非零已知解控制、所有输入和缓存SHA、等幅零方向规则、数值失败裁决、运行登记与独立复核脚本、实际设备资源和任务归属。当前未连接笔记本检查这些条件，不把已有清单等同于当前文件可用或设备空闲。

### 3.5 三个结果出口

- **阳性：** 推荐一次同架构目标干预pilot，检验有限系数层面的改善能否被无GT网络学会；oracle阳性本身不放行S2/S3、不复活AMT-v1。
- **阴性：** 关闭本次margin/保护目标配置，停止同类loss的串行尝试；研究重点转到“已知有益方向为何未被条件读出兑现”，保留其存在性证据，先形成输入/读出信息的明确新命题再决定是否立项。不会自动重启181维二分类或追加训练。
- **信息不足/工程无效：** 停止本Run，保存完整错误或区间；只允许另行登记可验证的工程修正，不扩大样本/预算或改阈值来改变科学判定。
