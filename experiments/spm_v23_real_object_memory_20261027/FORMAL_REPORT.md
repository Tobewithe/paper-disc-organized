# V23.4真实对象空间记忆：正式训练与正常验收

本轮在保留实际正收益 V23 的基础上，训练了一个只改变 1346 个记忆参数的真实对象空间记忆。正确对应臂没有超过 V23；固定打乱臂完全复现 V23。因此这条“直接改候选概率”的记忆接入关闭，原 V23 保留。

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | V23.3 的候选身份审计没有支持继续扩大 top1 匹配器，因此把真实 train 的空间特征、task-visible 值和跨实例参考对应写入记忆，检验内容是否能在 V23 接口带来增益。 |
| **机制假说** | H_mem：正确的真实空间特征—对象值对应应比固定值打乱更能改善正常输出；H_capacity：收益只来自新增参数/训练预算；H_data：训练缓存或跨来源泛化不足。正确臂应优于打乱臂且超过 V23，三者由同一完整 dev 评价区分。 |
| **针对性方法** | 固定 V23、C21、原生检测、Box/Class/score/排序、26 动作和 R0；只训练 1346 参数。两臂同初始化、同 1272 real/train 图、8390 查询、4 轮/1272 更新、同损失和顺序，唯一差别是每个参考内部 256 个 task 值固定打乱。正常部署在 432 real/dev、2863 GT、12899 行上评价。 |
| **整体结果** | 正确臂 Mask AP **60.746746**，相对 V23 **−0.006533**；打乱臂 **60.753278**，与 V23 逐字节等价。两臂 Box AP 均 **66.884503**，Mask75 与原生/尺度护栏均通过，正确臂对 V23 的 Mask75 损伤为 0。正确臂有 991/12899 个掩码发生轻微变化，但变化方向近乎平衡（直接 GT-IoU 改善 475、下降 463，均值 ΔIoU −3.28e−5），没有形成整体收益。 |
| **研究决策** | H_mem 在当前“全局标量门控 + 直接改 selected probability + 跨来源正常 dev”接口上未获支持；H_data/接口选择性不足仍是更符合证据的解释。关闭 V23.4 直接概率记忆，不改 V23。下一步聚焦**查询条件的选择性门控**：保留已经训练好的记忆读数，只学习一个零初态、同数据同顺序的查询条件门，验证它能否只在有利实例上启用内容残差；同时保留固定打乱臂作为对应性对照。 |
