# 下一阶段选定：真实可见实例的密集残差读出

这是V15结案后选定的唯一后继设计，**尚未启动新的真实训练**。V15已有6000步权重及阴性归属结果保留，不改变其75%IoU门槛或追加同配置训练。

## 为什么选这一方向

V15在给定实例框的合成开发条件下，全覆盖身体定位89.89%、左右侧卧89.61%/86.30%，且双猪同点仅下降0.61pp；保留规范身体对应已有直接支持。与此同时，完整可见归属IoU只有57.20%，precision78.93%、recall67.52%，可视化呈现漏分、条纹和邻猪误归属。单靠身体点身份正确，并不足以决定哪些像素属于当前实例且可见。

当前最值得优先检验的主张是：**已学到的身体对应可作为结构输入，与强原生Mask及真实像素证据共同学习实例可见边界。** 它比继续改变规范字段或延长合成对应训练更优先，因为对应要求已通过，明确剩余缺口在可见归属；真实Mask已有合法监督，可直接连接目标任务。

## 具体方法原则

1. 保留V13原生纯几何候选的Box/Class/score/排序和强原生P/c0；先核对其冻结上游特征与V15构库坐标一致。固定V15对象的身体对应参数，避免真实Mask训练破坏刚通过的几何能力。
2. 全部真实输入使用原生预测框及实例查询。GT只用于训练关联/Mask监督，不给真实GT框、真实姿态或真实规范坐标作为推理输入。合成GT框能力不能直接迁移成部署结论。
3. 以原生实例logit为起点，训练零初始、可正可负的小型空间残差：

\[
\ell_i=\ell_i^{native}+r_\theta(F,\ell_i^{native},\text{body correspondence}_i,
\text{confidence}_i,\text{predicted instance query}_i).
\]

4. 用已有真实可见实例Mask对图像像素及接触边界作密集监督，明确区分当前猪、其它猪和背景；不把“每身体顶点均衡”的几何采样直接当作可见Mask的面积/边界监督。当前条纹/漏分是实测现象，采样与坐标参数化各自的因果仍待验证。
5. 原生分支与完整方法按用户要求比较；V13作为同配置强原生，原N另列历史参照。Box输出冻结应逐行一致，Mask须在完整正常评价器下超过强原生，并报告修复/损伤和+5绝对百分点目标，不能把V15的PCK改善算作Mask AP。

下一真实Study必须在启动前另行冻结参数白名单、关联/decoder、步数/预算、末点选择、损伤护栏和三出口；本页不代替新执行合同。若正常预测框的实例归属/Mask仍不能优于强原生，保留阴性并关闭该读出配置，不用合成能力分数回避任务效用失败。
