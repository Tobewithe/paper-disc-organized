# V15：实例框条件的跨姿态身体对应训练

研究线`spm_yoloseg`。用户明确要求“继续下一步直到完成实验”，授权本轮在已登记个人服务器完成新对象训练、固定评价、独立核验和可视化。新Study取代V14之后尚未启动的训练建议；V14零优化身份/协议/阴性不改。原型真实Mask+5目标继续保留。

## 主张、预测与归因边界（M1–M4）

1. **实际失效：** V14在576合成dev/147456身体点上，实际学习度量PCK@0.10=38.7465%、平均归一化图测地误差0.215185；左右侧卧16.5527%/19.9422%，尽管6姿态训练图数量均衡。学习度量比初始19.1779%改善、紧阈值有精确点，支持部分信息可学。H：把像素映射到固定几何身份、引入实例上下文和跨姿态配对，能把局部信息转成可靠身体对应。H_alt：当前冻结视觉特征/合成分布不足以支持可泛化对应，新条件预测器仍会失败。
2. **可推翻预测：** 固定6000步末EMA应满足下面全覆盖几何要求；只训练loss降低不算通过。所有姿态、双猪稳健性及实例可见归属分别评价，不用拒绝困难点通过主指标。能力阳性不代替真实分割AP。
3. **混杂：** 新方法有约0.7M参数、实例框、上下文、额外合成干扰和新目标；V14旧字段为历史参照，不能独立归因某个结构/loss。按用户要求不加等容量/额外训练臂，也不把新增输入信息隐瞒。仅本对象能力实验，不改原生检测/Mask、不评价真实COCO AP。
4. **定向接口检查：** 同一末checkpoint在双猪中交换完整实例框/上下文，固定像素及GT实例身份，报告归属变化和几何变化，检查实例条件是否实际起作用。它不能排除容量解释，不宣称已独立证实几何核心机制；正式机制论文另需匹配控制。

## 对象与数据冻结

固定原生N编码器、全部参数/BN、V9标准化/PCA128、实际283顶点/562三角面及图测地距离；不用旧视觉平均字段作新身体代码。新代码由规范网格32个确定性最远点的距离向量及xyz构成，逐列标准化、逐顶点单位归一，作为固定几何身份键。图像头预测该空间的单位向量并检索283身体点；另预测当前实例的可见归属logit。实例上下文来自框内4×4冻结视觉采样；点输入另有框内相对坐标及其固定Fourier特征。推理接口只接RGB、冻结编码器及实例框，不接身体GT、姿态或相机GT。

- 原单体1728train/24家族，576dev/8家族；dev历史重复使用，不称独立test。训练身体点按可见主重心顶点均衡，每顶点取最大主重心权重像素；隐藏/无像素顶点排除，不当背景。
- 新双猪训练仅用train家族：24家族×6姿态×3视角×2邻猪外观=864画布/1728实例；固定左右各16px层叠、家族+1循环、姿态+1循环，另猪在前。输入来自既有clean单体cutout，明确2D受控干扰，不冒称物理3D/真实猪场。
- 每实例256负点：优先128个其它猪像素，若无其它猪则用框内非本体；另128个背景点优先框内、空时用全画布背景。确定性均匀位置采样，数量不足时重复既有合法点，不更换图像。训练实例框由可见Mask包围框作固定小扰动（中心std0.05框宽高、大小log-std0.05，seed冻结）。
- **权限明确：** 本轮合成能力评价给新模型真实可见实例框，属于框条件能力；V14旧字段没有该条件。真值身体点不输入网络。不得把框条件提升宣称同信息几何机制优势或正常部署AP；未来真实接口必须用原生预测框。
- 评价原576图每图256可见点与V14相同；双猪dev96画布/192实例与V14同构造/同保留点。比较新模型在双猪与孤立图**完全相同可见点**的对应。另在双猪整128画布上评价归属Mask IoU/precision/recall，阈值0.5，GT只作框提示与后验评分。
- 各train/dev所有文件、旧模型、字段/统计、源代码/版本SHA在启动前绑定；不读真实train/dev/test，不编造真实规范坐标。

## 训练和选择

单臂正式6000步，batch16实例（8单体+8双猪）；每步另读这8单体同家族、姿态/视角+1、外观/遮挡翻转的配对。原生冻结特征先缓存FP32，不训练YOLO。点头LayerNorm+两层256 SiLU，框上下文2048→256→128；查询输出35维固定几何码，归属独立线性输出，cosine尺度可学且限[1,100]。

目标：可见身体点图测地软标签CE（exp(-d/0.025)归一）＋2×期望图测地风险＋0.5×等权正/负归属BCE＋0.1×同身体顶点跨姿态查询余弦一致性。无合法共同点则该项为0，并记录分母。AdamW lr0.0003、decay0.0001、100步预热、cosine至0.00001、梯度clip5、FP32、EMA0.99；seed231023247。单体/双猪实例均匀抽取，6000步不因dev曲线好坏改预算。

1000/3000/6000保存EMA检查点并全量开发评价，**只以固定6000步末EMA作正式能力裁决**。工程smoke8步独立Run且丢弃，不混入正式步数。无强度/阈值网格，无dev选择最好早停点。

## 冻结能力要求和出口

全576图、等图像权重：PCK@0.10≥70%、平均归一化图测地误差≤0.10、每种姿态PCK≥50%、相对V14特权部位参照误差降低≥20%。双猪同点PCK下降≤10pp；每实例至少32合法点。归属单独要求双猪192实例平均全画布IoU≥0.75，整画布precision/recall同时报告。

- 几何及归属全部通过：保留训练对象，唯一后继为基于原生预测框的真实Mask读出训练方案；本轮不自动扩成另一真实AP Study。
- 几何通过、归属未过：保留规范身体对应，唯一后继聚焦真实可见实例归属；不把这类失败混称身体身份完全没学到。
- 几何未过：关闭本冻结特征/对应头实现的扩训与融合，保留精确/失败事实；下一研究问题转为跨姿态/合成到真实视觉对应的可迁移信息，结合train/dev差异选定具体重点，不盲换loss/加步。
- 输入、配准、资源、数值或执行不足：信息不足，保留失败，仅修工程，不改科学设置重追阳性。
