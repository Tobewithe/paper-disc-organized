# V15结案：训练出可靠的框条件身体对应，可见归属仍不足

本轮已真实完成对象头6000次梯度更新、固定末EMA评价、12次RGB重载及独立核验。**框条件身体对应PCK@0.10达到89.8878%，通过全部五项几何要求；双猪完整可见归属IoU为57.2013%，未达到75%要求。** 保留本轮训练对象，下一重点明确选为真实可见实例的密集归属/Mask读出。该结果是给定真实实例框的合成开发能力，尚无新增真实AP成绩，原型+5点目标仍未完成。

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | V14同576合成dev/147456身体点上，既有字段PCK@0.10只有38.7465%、平均图测地误差0.215185，左右侧卧16.5527%/19.9422%。已有精细点信息，却未形成稳定的全身/跨姿态对应，不能继续以“原型已学好”为融合前提。 |
| **机制假说** | H：直接绑定固定规范几何身份、使用实例上下文与跨姿态配对，可把可学的局部信息形成可靠身体对应；H_alt：冻结视觉特征/合成分布限制导致该条件预测器仍无法泛化。若几何通过而可见归属失败，则下一瓶颈应聚焦实例归属与读出，不能混称身体身份未学到。 |
| **针对性方法** | 固定原生编码器/BN/PCA、283顶点/562面，构造32个图测地锚点距离＋xyz的35维固定几何键；训练707237参数的实例框条件预测器。1728原单体train＋864双猪train画布/1728条件实例，单臂6000步、1000/3000/6000完整评价但只选末EMA。576旧dev每图256身体点、96双猪dev/192实例作同点对应与整128画布归属。原生YOLO更新0，合成评价额外给GT可见框；容量、上下文、信息与目标改变的混杂如实保留。 |
| **整体结果** | 新对象PCK@0.10=89.8878%、PCK@0.05=69.8717%、平均误差0.033416；六姿态86.3037%–91.1011%，五项几何要求全过。相对V14历史字段PCK提高51.1414pp、平均误差降低84.4709%，但这不是同信息或单机制增益。相对特权部位参照误差降低71.6175%，通过≥20%要求。双猪同点90.0818%→89.4714%，下降0.6104pp；可见归属IoU57.2013%、precision78.9323%、recall67.5199%，未过75%IoU要求。正确提示换成邻猪提示后IoU降至6.4102%，表明提示实际影响输出，不能据此排除容量或独立证明几何因果。原生/V13的真实Box/Mask AP本项未新测，不给合成对应改善记AP收益。 |
| **研究决策** | **保留训练好的规范身体对应，优先用真实可见Mask监督实例归属，并以强原生Mask作读出起点。** 几何五项通过为保留对象提供实测依据，完整归属未过说明它尚不宜独立替代分割结果。唯一下一步是[真实可见读出设计](NEXT_MASK_READOUT_PLAN.md)：冻结该对象及原生Box/Class/P/c0，用原生预测框、密集真实监督训练双向Mask残差；不扩大本合成归属头的步数或调阈值追阳性。新真实训练尚未启动，只有正常预测框下真实AP通过才称分割效用。 |

## 两项收益与判定范围

相对同配置原生YOLO：本项没有真实部署AP比较，全部原生权重/BN未更新，V13首选保留；不得把“未测”写成0AP变化。相对协议指定的既有对象V14：同一576图/147456个GT身体点，得到下表能力提升；V15增加GT实例框、上下文和参数/训练，因此报告整套条件对象的开发能力，不独立归因某项新设计。与既有特权部位参照的差异另报，不把其GT权限隐去。
