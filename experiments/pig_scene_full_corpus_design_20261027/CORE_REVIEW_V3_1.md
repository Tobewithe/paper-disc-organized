## 优先实现的核心接口

每条可用于生成的约束至少携带：`source_id / RGB_sha / source_group / factor / value_or_interval / authority / evidence_region / coordinate_frame / observation_operator / annotation_policy / renderer_controls / fit_permission / validator / unknown_reason`。同一个字段若不能可靠观测，就保持区间/unknown或改用有来源的资产先验，不通过语言补齐隐藏几何。

首版闭环优先落到三组可检验关系：

1. **数量—尺度—遮挡关系**：最终输入中的身体尺度、可见面积/相邻距离、设施切割证据及截断共同约束布局和相机。实例数≥15只满足数量条件；实际拥挤/互遮仍需独立几何与图像检查。
2. **身体—姿态—接触关系**：姿态、可见轮廓、支撑面和相邻身体位置绑定到同一个实例；真实腹卧和侧卧需要自然资产/骨架证据，不能由矩形裁剪或向量近邻证明。
3. **表面—光照—采样关系**：在明确的皮肤/地面/设施区域观测对比、反射与频谱；用有来源的材质/灯族产生候选，经相同相机和任务缩放后验收，保留不可识别的物理参数。

这三组同时约束，不能用“每个单项直方图都接近”替代联合检查。生成的精确部位、完整投影、深度和反事实仍保留为合成优势；实际训练是否使用它们由后续同预算合同决定。
