# 固定合成数据集 V4：真实联合约束、几何核心与成对成像

日期：2026-10-28（Asia/Taipei）。状态：**方案已具体化，生成/训练执行合同尚未冻结**。

**我主张优先建设“目标域联合约束的几何核心池 + 成对成像版本 + 单列困难池”。** 先保证自然身体/姿态、拥挤关系、相机尺度和任务标签具有真实支持，再用同一几何的外观对校准成像。这样既接近真实训练域，又保留合成数据独有的精确遮挡、部位和受控反事实。外观影响已有实测支持，几何优先是有依据、仍可推翻的投入顺序，不能等到几何完美后才处理成像。

## 2. 从自动属性到生成器：明确五个接口

```text
已登记TRAIN RGB/标注/来源
  → ObservationLedger：实测、来源标签、候选、未知分列
  → FitManifest：按来源组授权字段，保留审阅隔离
  → JointRecipe：目标联合格、支持区间、困难义务
  → SceneRecipe：资产/姿态/布局/相机/成像的可重放参数
  → Render + TaskExport + 同口径重测
  → AcceptedManifest / RejectionLedger / SupportGap
```

| 接口 | 必须保存 | 不能用来替代的内容 |
|---|---|---|
| `ObservationLedger` | 原图/标注SHA、实例ID、来源组、字段值/区间、单位/坐标、观测算子、证据ROI、authority、unknown原因 | 模型自述observed、同一输出的文本再编码，不是第二份独立证据 |
| `FitManifest` | fit/review/exclude角色、组身份依据、允许字段、来源标签政策SHA、模型字段可靠性凭据 | 全量特征已缓存不等于全部字段获准拟合；review标签不回流同版修订 |
| `JointRecipe` | 目标总体/权重、已知与未知分母、联合格、目标质量区间、合法支持池、缺口、采样种子 | 不在已知病例上归一化后冒充总体姿态频率；公共支持比例不是自然频率 |
| `SceneRecipe` | 每猪asset_parent/姿态/变换、场景与设施父族、相机与坐标单位、材质灯族、成像链、三种ID | 一份Qwen文字不能直接变成三维GT；规范单位不写成米 |
| `AcceptedManifest` | 尝试/拒收/接收身份、精确标签SHA、实测联合格、派生链、配对关系、拆分连通分量 | 不只统计成功渲染，也不把换材质的同几何多次计为独立布局 |

**权限裁决：** 已核来源标注/确定性像素量也须符合字段语义和fit角色才可用。未验证Qwen属性可检索、整理候选资产需求和呈现冲突；不得直接变为目标频率、硬布局约束、训练标签或材质数值。姿态/房型沿用[隔离政策](../pig_scene_auto_all_20261028/FIELD_RELIABILITY_POLICY_V4_1.json)。可靠性缺项只阻断对应字段，不阻断已有合法尺度/数量测量的使用。

既有16图前置、20个来源姿态案例、4个设施开发控制及已参与修订的同来源组，不得再登记为未见的独立review。新的审阅角色先按组冻结；已经查看的开发案例保留回归用途，不因改版本号获得盲审身份。

## 3. 目标分布与采样：先定义总体，再定义困难

### 3.1 原任务与公开支持分别承担职责

原任务fit组定义基础池的目标。至少同时报告两种统计：实际帧等权，以及按已证来源组等权；未知物理场地不冒称独立猪栏。工程冻结前选定主权重，并保存两种权重对联合配额的影响。相邻帧和文件名族只按其真实证据处理，不能按帧数虚增独立性。

公开Faro/Viewpoint提供新增身体/姿态/设施及成像的**支持范围**，单列`external_support`；Viewpoint姿态仅为来源标签，在来源定义和实例归属核过后可作该来源的支持证据。不能据公开1374张占比决定原任务要生成多少侧卧、多少宽栏。

未知字段使用可识别区间。例如目标姿态总权重为W，可信正类权重为P、未知为U，则比例在`[P/W,(P+U)/W]`；这不是置信区间。若仍为[0,1]，只定义“有真实支持的姿态覆盖义务”，频率标为设计配额，不能声称已拟合真实姿态分布。不得为填满联合格而独立均匀随机填未知值。

### 3.2 首版只保留有作用的联合约束

| 联合块 | 真实侧可用量 | 渲染控制与重测 |
|---|---|---|
| 数量 × 尺度 × 画面位置/截断 | 来源实例数、同口径Box尺度/位置、已核画幅映射；未全标则只叫标注数量 | 地面可用域、猪数、身体尺度、相机/裁切；在最终任务输入重算，不用世界坐标密度替代 |
| 身体/姿态 × 视角 × 支撑/接触 | 有来源/核验的姿态、可见轮廓和支撑证据；邻近框仅作候选 | 骨架姿态、体形、支撑面、相邻身体与相机；核自然轮廓/接地和三维穿透 |
| 设施 × 投影宽度 × 身体遮挡关系 | 已核设施ROI/类别、最终输入的窄结构宽度与局部对比 | 栏杆/墙/料槽独立实体、截面与相机；记录遮挡ID和深度层，不把所有相交都叫猪间接触 |
| 表面区域 × 亮度/对比 × 多尺度频谱 | 有效皮肤/地面/设施ROI，画幅/颜色空间和采样定义 | 材质/灯族、曝光与声明的退化模型；同ROI及同预处理重测，PBR多解保持区间 |

分箱边界由fit侧描述和测量精度冻结，不能按生成后的漂亮结果挑格。联合格样本不足时，按预先写明的语义父格合并并记录丢失的区分；不能在未观测高维组合上机械做全笛卡尔积。困难尾部不被p5–p95裁掉。近黑像素仍是描述量，未经核验不裁成无效视野。

### 3.3 几何核心池、外观对和困难池

- **基础几何池：** 合法身体/姿态/场景组成后，以相机与布局候选满足目标联合格；冻结每个`geometry_id`。低密度、正常与拥挤场景均按目标覆盖，整个基础池不强制全部15头。
- **成对成像版本：** 每个合格几何先设计`reference_neutral`与`train_conditioned`两种外观，配对ID、实例、相机和标签规则相同。二者都是完整可训练RGB；中性版是成像对照，不是故意损坏画面。纯外观不改不透明度、位移或几何。二图是相关样本，曝光和独立布局分开计数；“一几何两外观”是判别设计，不是最优数据比例。
- **困难几何池：** 单列实际拥挤、设施切割、小尺度/边缘截断及自然卧姿等有依据的组合。只有标为`dense15`的配方必须最终有至少15头满足可见性条件，且猪间投影遮挡图的最大连通分量至少15；连通分量不等于所有猪两两直接互遮。可见像素与遮挡边阈值在工程预检后、正式渲染前冻结，不能用一像素噪点凑数。真实三维接触、投影遮挡、二维边界邻近分别报告。
- **固定release：** 基础/困难比例、几何数、每几何外观数和训练曝光另列数值合同；现在不把80:20、旧1280或任意万张当默认。先满足受支持的覆盖义务，再按实际资源确定规模。困难池占比是主动覆盖策略，不叫自然概率。

G×A中的A只改变材质、灯光和不改坐标的成像处理；镜头畸变、FOV、几何裁切归入G，在同几何外观对内固定。要改变它们就创建新的geometry_id并同步重投影全部标签，不能将空间不同的两图称为“同标签纯外观对”。猪j→i的投影遮挡边按同栅格`A_i ∩ V_j ∩ {z_j<z_i}`计数并达到预冻像素/面积阈值；dense15连通分量取这些有向边无向化后的分量。它检验可见的猪间投影遮挡，不替代三维接触。

### 3.4 必须校正“拒收后的分布”

候选分布为q0、通过几何/投影验收的概率为a，则接收分布正比于`q0(theta)*a(theta)`。稀有卧姿、密集群和细栏更易被拒收，**生成前配额正确不保证最终数据正确**。

首版采用“有限合法候选池 → 全部重测 → 按接收后联合格受约束重采样”，复用[V3.1有限格接口](system_v3_1/calibration.py)。目标格质量为p(c)、格内有n(c)个合法候选时，候选基础概率为`p(c)/n(c)`；区间约束不伪造唯一p。无合法候选的正质量格明确`support_gap`，不输出合格权重、不静默放宽解剖或混入另一场景。

正式前冻结每格/总尝试上限、权重上限、重复上限、唯一几何最低覆盖、有效样本量及联合误差容差。每次失败保留`candidate_id/parent_id/stage/reason/cost`。达到尝试上限仍不足，交付具体缺资产/缺姿态/不可行相机组合；不无限重采样。重采样后的曝光权重与唯一身份清单共同冻结，不能用一张成功图反复复制假装覆盖。

## 4. 资产、物理和成像的实现选择

**身体先做有来源的可变形资产。** 保存许可证、mesh/rig/SHA、原始父族、形态参数有效域、关节定义及部位映射。真实腹卧核腹侧支撑和屈腿、侧卧核解剖侧别与地面接触、站姿核足部支撑；坐姿只有证据和骨架均支持才启用。各向异性缩放不是独立身体来源。旧单身体可用于接口回归，不能据此宣布多身体泛化；没有合法资产的姿态报缺口，不用Qwen类别替代姿态生成能力。

**碰撞先用代理提速，再核实际几何。** 胶囊/AABB只作广相候选筛查，不把AABB交叠当三角穿透，也不把代理未碰当精确无碰撞。窄相检查实际变形网格、地面/设施及自相交，接触容差随声明单位和网格精度冻结；有疑似不确定接触单列，不能宣称完整解剖证明。正式物理合格不能只继承旧凸包/远端点检查。

**相机和场景联合布局。** 优先拟合最终输入的目标尺度、位置、截断和设施宽度；K/R/t、镜头畸变、有效画幅均留来源与可识别性。未知米制值为null。相机搜索范围与次数先冻，不能只重抽到原生YOLO特别容易的画面。前景可见性和物理条件决定准入，模型是否检测成功仅作描述，不作数据筛选器。

**成像采用显式、有限的第一版链路。** 候选沿已登记Blender 4.2.1实现重新核源码/引擎/资产；本方案没有切换运行环境。渲染、镜头几何映射、曝光/颜色映射、采样与噪声/压缩分别留版本。区分数值渲染噪声与拟合真实传感器的噪声，不用减少采样数冒充真实噪声标定。第一版关闭未制定标签时间规则的运动模糊和透明猪/透明遮挡；几何畸变、裁切/缩放对全部空间标签同步应用。

先在中性几何版本检查标签，再在最终任务输入复核细栏、耳尾脚、阴影边界和实际清晰度。高分辨率抗锯齿若需要按工程收敛检查决定，不先固定“4K即更好”。RGB可滤波，实例ID不得线性插值后取整；标签以声明的中心射线或子像素覆盖规则生成，二值化与微小实例政策另冻。距离图和相机z深度分字段，不混存为一个depth。

## 5. 三层真值与训练导出

对同一场景、相机、采样时刻和栅格：

1. **`physical_visible`（V）：** 首个不透明表面归属；猪、栏杆、墙、料槽都正常遮挡。保存实例/部位、遮挡物ID及其单位明确的z/距离。物理可见部位互斥，部位并集为对应V。
2. **`task_mask`（T）：** 来源目标政策的确定性导出。若某类细金属栏杆获准bridge，仅忽略该类栏杆的遮挡，仍保留其它猪、墙和料槽遮挡；不能直接用单猪完整轮廓替换。原任务有限4点证据保留为`bounded_train_evidence`，完整来源政策核验仍待做。Faro政策未知时不套用原任务约定；Viewpoint没有Mask监督权限。
3. **`amodal_in_frame`（A）：** 同一猪在相同相机/视锥内、移除外部遮挡物后的独立投影轮廓；身体自遮挡仍按表面投影处理。另存部位完整投影/自身可见部位及规范坐标，不能把A描述成超出画幅的完整身体。

对上述不透明、同栅格的bridge政策，应有`V ⊆ T ⊆ A`，严格可见政策则`T=V`。完整部位投影可彼此重叠，不能要求其面积和等于A；物理可见部位才有互斥和守恒约束。深度/部位在task补回栏杆区域保持物理不可见，不将那里的RGB当皮肤纹理。

任务框从同一T及冻结框政策导出，完整投影框另存。RLE为无损栅格主格式，保留断片/孔洞；COCO导出须往返一致，不用一个外接多边形填洞。合成完全不可见实例保留在场景元数据，不作为正常可见检测正例；微小/不确定实例若不参与训练，必须用loader实际支持的ignore/有效域规则，不允许丢标后当背景。

对设施/其它猪的遮挡贡献，保存移除对应遮挡层的受控可见性测量。多类遮挡重叠时增量不可直接相加；猪间投影遮挡图与三维接触图各有定义和阈值。第一版只承诺静态单帧，不因保存三维场景就声称已有运动、跟踪身份或视频GT。

## 6. 拆分与固定版本的实际含义

建立派生关系图，边覆盖：同源视频/相机证据组、精确/核实近重复、身体资产父族、场景父族、共享几何、材质/裁切/反事实派生链。按所声明隔离维度的连通分量分配split，先分组后生成；跨来源身份未知时保守隔离，不凭向量近邻断言同猪栏。

资产很少时，这个图可能只有一个连通分量。此时只可交付train及`qa_replay`，不能伪造资产独立的synthetic-dev/test；QA重放不作泛化成绩。真要声称新身体/新场景泛化，就补相应独立父族。原任务432dev只用于后续真实评价、426test继续封存，公开construction整源不作独立外部测试。

旧训练资产/代码按来源审查复用。**旧dev复刻诊断的图像、场景与拟合参数全部排除**；通用渲染/坐标代码可在去除拟合参数、核许可证与源码SHA后复用。旧1280合成不能因为曾用于训练就自动纳入新release，须核其父链、标签政策和当前准入；不合格保留历史版本，不覆盖旧Run。

一个release冻结四份清单：资产/来源、场景与派生、RGB/三层标签/任务导出、训练暴露/采样。`release_id`对应规范化清单和文件内容摘要；同ID不得换图、修标签或改曝光。发现错误创建新版本并记录继承关系。原生/方法使用同release，特征、预测行、模型得分与旧选择器不属于数据集真值。

## 7. 生成验收与效用裁决

| 阶段 | 通过条件 | 阴性或信息不足出口 |
|---|---|---|
| P0 权限/可识别性 | 来源/拆分/哈希、fit/review、字段授权、标签政策及资产范围齐全；未知保留分母 | 只阻断相应字段/资产；清楚记录缺口，不增加模型调用追填未知 |
| P1 工程小集 | 覆盖实际启用姿态/设施政策、dense15/正常场景、小目标、画幅边缘、两外观；身份/投影/标签不变量、解码重载和实际成本通过 | 留存失败；只修新实现。没有自然资产/合法政策则不进入对应场景量产 |
| P2 有限候选池 | 每次尝试登记；接收后联合覆盖/权重/重复/物理与标签均满足预冻要求 | 支持空缺报`support_gap`，精度不足报`inconclusive`，达到上限即停；不无界换seed |
| P3 数据版本可复现 | 固定文件清单、SHA、拆分、采样暴露、源政策与独立程序复算通过；实际逐图QA有记录 | 只称artifact合格，不称真实效用。未做的独立语义审阅不填通过 |
| U 真实效用 | 在冻结普通原生上，正常RGB完整真实Mask AP增量达到预定数据效用幅度，并满足Box/原成功损伤/尺度护栏；按来源簇重算区间 | 低于幅度与已证损伤分开；区间不足不能当无效。停止该配方扩量，决定保持原生真实训练还是有证据的因素修订 |

P1小集按“每个实际启用状态/政策至少有验收例”的覆盖义务构造，数量由已核资产决定，不在这里虚称已具备32/64个可渲染新场景。RLE/ID精确一致为工程要求；碰撞数值容差、细结构可见阈值、联合分布误差和统计区间分别来自各自定义，不能混作AP科学门槛。

**未来最小效用顺序：** 先比较普通原生`R`（真实训练对照）与`C11`（联合几何校准+成像校准），首要回答新数据是否值得用。冻结时同时写出条件性G×A分解；只有C11显示有实用增量且因素裁决仍会改变下一阶段投入，才规划执行其余`C00/C10/C01`，不自动追加。G=1是支持范围内的联合采样，G=0是同一合法支持范围内的独立采样；所有臂身体解剖/标签合法，不能把假腹卧当G=0。A=1是train条件成像，A=0是中性成像；G变化后标签必须重新生成，A配对仅限不改几何的操作。

真实对照与混合训练具有相同公共真实序列、总图像插槽、优化步数、初始化、增强/选点和评价。差异插槽在R中为预冻真实重放，在C中为合成；**R因此有更多真实曝光，这是数据策略的一部分，须逐项报告**，不虚称“真实曝光与总曝光全部相同”。四个C臂的真实/合成曝光必须完全相同。候选C11只有在数据身份、曝光顺序和训练合同与预冻分解一致时才能复用；否则不能拼成因子效应。

G0/G1还须核共同资产父族、姿态/相机支持及可识别单因素边际；优先在共同合法候选域上构造仅联合关系不同的采样。G0的独立提案经物理拒收后也要重测和校正边际，不能假定筛选后仍独立。若物理限制/支持不足导致边际无法匹配，显式降为“整体几何数据策略效应”，不声称唯一证明联合相关性；不为配平而删掉G1要检验的真实联合变化。

G/A及交互作用用相同真实集合上的完整COCO AP差定义：`ΔG|A1=AP11−AP01`，`ΔA|G1=AP11−AP10`，`I=AP11−AP10−AP01+AP00`；它们是所选两个因素块的效应，不唯一归因某个关节/材质。事先设置数据效用最小幅度与因素投入幅度，按实际来源簇配对重抽并每次完整重跑COCOeval；不能平均分片AP，也不把反复开发的432图叫新盲测。

若只有A有实用增量，优先保留成像校准并停止增加G复杂度；若G有增量，优先补其具体联合支持；若只有交互有效，保留成套配方；若C11无效或伤Box/原成功，停止该配方扩量。估计精度不足只在预冻预算容许、且能够改变决策时规划独立确认，不自动加seed。整个模型+5目标单独保留；数据效用通过不等于对象原型机制成立。

之后比较对象方法时，普通原生和方法须用同release及相同新增优化预算/选点；分别报告`新数据原生−真实对照`和`新数据方法−新数据原生`。V23继续作为历史有收益锚，不能拿其旧数据旧预算直接减新方法，冒称对象机制独立增量。

## 8. 执行前还需冻结什么

当前仍缺：可靠字段的fit/review清单及源标签政策、自然资产/姿态能力表、渲染器/任务预处理锁、联合格与权重/配额、P1数值容差、尝试/重复/资源上限、release实际规模、U的效用幅度与护栏/训练合同。JSON中均明确为`null`或`not_frozen`，它们是**具体执行缺项，不是已通过项**。可用字段能先完成配方编译，不能因此绕过后续渲染/训练冻结。
