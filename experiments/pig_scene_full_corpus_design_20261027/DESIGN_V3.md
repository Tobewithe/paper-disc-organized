# 真实属性约束、保留合成优势的固定数据集设计V3

主判断：建立**由全部真实训练图像约束的联合场景生成器**，产出跨实验复用的数据版本。真实图像决定可观察属性的支持范围、共现关系和困难分层；可控三维生成保留精确实例、遮挡、部位、深度及反事实标签。既不追求逐像素复刻某张照片，也不把各因素独立均匀随机当作真实分布。

用户确认范围为原任务全部真实train加已采集公开train参考。候选2646身份=1272原任务真实+1039 FaroPigSeg+335 Viewpoint；原52参考是1272子集，不重复计数。2552旧训练数是1272真实+1280旧合成。dev432/test426不参与生成器拟合。实际唯一RGB数、原图完整性以全量清点Run为准。

本设计支持统一保存在[理论文件D42](../../paper/manuscripts/spm_yoloseg/SPATIAL_OBJECT_THEORY_SUPPORT_20261025.md#d42-全量真实属性约束的可复用合成数据集)。原始研究目录为[13项来源](../../literature_search/pig_synth_generalization_2026-10-27/sources.json)，PDF/文本/SHA和可视复核页同目录。文献不是本猪群实验的效用结果。

## 1. 优先裁决：先满足可学习任务的真实支持，再校准成像

下表是结合本项目失败与相关原始研究的**投入顺序假说**，不是跨论文得到的普适重要性排名。所有因素均保留，后续同预算实验检验效应大小。

| 层次 | 特别关注的因素 | 从真实图提取什么 | 合成侧如何落实 | 当前可知边界 |
|---|---|---|---|---|
| 准入条件 | 标签语义、拆分与独立性 | 已有Mask/Box/姿态的监督权限、可见/遮挡边界政策、视频/相机/来源身份 | RGB与可见Mask空间变换一致；完整Mask另存；按源视频/场景/资产族划分，派生图不跨拆分 | 未标不等于背景；公开参考整源不作独立测试；文件名族不等于已核实物理猪栏 |
| 第一优先组 | 身体形状与自然姿态 | 正常站立、左右侧卧、真实腹卧、坐姿；可见轮廓/长宽比例；年龄体型混合与可见部位 | 有来源/许可的解剖和骨架资产；用真实自然姿态核验弯曲、足地接触、腹背高度，覆盖身体族 | 一种CAD并非理论上必然无效；本项目具体缺口是代理身体/假腹卧缺真实支持，换随机纹理不能补齐 |
| 第一优先组 | 密集关系与设施遮挡 | 实例数、标注可见面积、相邻/接触图、身体被分段与部位缺失候选、栏杆穿过身体的证据 | 至少15头实际可见/可辨认猪的拥挤群；自然接触与二维遮叠；物理不穿透；栏杆、料槽等独立遮挡层 | 可见面积/Box重叠不是隐藏身体的真实遮挡率；真实amodal面积未知时不填数 |
| 第一优先组 | 相机、目标尺度、裁切 | 目标在最终640输入中的尺寸/位置、视角、长宽比、黑边、截断；已给相机标定 | 联合采样体型—数量—相机—布局；匹配屏幕空间尺度/位置和窄结构投影宽度；验证透视/畸变 | 单RGB不恢复可信米高、焦距或完整深度；作者归一化width=1不自动等于1m |
| 第二优先组 | 栏舍结构与空间背景 | 宽活动栏、贴身限位架、分娩设施证据；地板、围栏、墙、料槽/饮水设施及相对位置 | 有真实共现依据的模块化场景图；群养、限位、分娩分别建场景族；区域材质随结构条件变化 | 空栏/少猪不改固定结构类别；聚类与向量相似不证明同一猪栏 |
| 第二优先组 | 光照、皮肤与地面材质 | 单色/彩色、曝光、阴影、反射、污渍/湿润候选；RGB亮度/色度和局部频谱描述量 | 皮肤/地板/设施材质与灯位联合采样；真实范围内变化及少量已验证困难尾部；PBR参数留来源 | 单图颜色不是独立反照率，亮度不是照度；未知粗糙度/折射等不由VLM猜作PBR真值 |
| 第二优先组 | 边界、高频与相机退化 | 栏杆/漏缝投影宽度、局部边缘/对比、清晰度、运动模糊、噪声、压缩候选 | 高分辨率渲染后模拟镜头/曝光/采样/压缩，Mask使用同一空间变换；保留细栏/耳尾/脚边界 | Laplacian/频谱不是材质或光学标定；真实模糊参数不可唯一识别时用有来源的区间/假说 |

本任务先投入“自然身体/姿态 × 拥挤遮挡 × 相机尺度”的联合覆盖，同时从第一版就校准成像。依据是已有代理身体/腹卧缺口、V20合成内成功但真实退化，以及真实猪遮挡研究对碎片/错归属的观察。该顺序不等于已经证明它们比光照更重要；文献中随机化与PBR研究的主导因素会随任务和场景改变，必须保留竞争解释“主要瓶颈是外观/传感器”。

## 2. 全图一次预计算：每张有记录、按内容缓存

“一次”指对冻结清单完成一次逻辑计算，重复实验读取同一缓存；不是将所有图同时塞入显存，也不是用40代表图替其余图片赋值。

```text
全部原分辨率TRAIN RGB + 合法已有标注 + 来源/相机元数据
  → SHA/尺寸/权限/别名核验（每个源身份保留）
  → 每图确定性像素与标注统计 + 每图Qwen全图编码
  → 每图Qwen3.5结构/身体姿态/关系/成像候选及证据区域
  → 有效局部RGB编码 + 纯结构语义编码
  → 逐图属性账本 / 来源与场景候选 / 联合属性分布
  → 人工与几何核验 → 参数化生成器 → 固定release
```

1. **数据身份层**：1272原图需从登记的train.zip按源SHA恢复，不能用640训练JPEG替代。1039/335公开原train复用已核验字节。完全相同RGB仅计算一次，所有源ID/标注保持别名关联。原图SHA、参数、模型锁、指令、schema、解码器、预处理、软件环境共同进入缓存键。
2. **每图都计算**：全图Embedding；基础结构/占用/姿态与成像候选；CPU图像描述量；合法标注统计。局部通道有证据才编码，缺失显式unknown，不造全图替代或补背景。每图返回completed/failed/unknown_fields及原文，最终2646身份全部对账。
3. **权限分层**：已有来源标注是source_annotation；像素量是measured_image_descriptor；Qwen是model_candidate；人工独立复核是reviewed_evidence；可信几何是calibrated_geometry。模型observed/inferred不自动进入后两层。身体/部位/amodal/世界尺寸未知不编造监督。
4. **可靠结构输出**：旧V2失败原样保留。V3不依赖在加载模型前临时修补Transformers内部重导出；使用lmformatenforcer核心TokenEnforcer的局部适配，避免失效的旧integration import。CPU测试与GPU测试必须复现“实际processor+9B加载后再创建约束器”的真实顺序。约束语法后仍做schema、坐标、引用、未知与语义冲突检查。
5. **每图正常RGB**：训练GT只用于独立统计/覆盖诊断，不传给9B、不替代图像预测；有标注前景的补集不当背景。Viewpoint框覆盖与Mask覆盖分开统计。
6. **统计组织**：按图像、来源/相机证据组、跨来源结构候选三层保存。近重复帧单列，训练数据中真实共现频率以来源/视频权重报告；物理身份未核实不强行合并。未分析或失败不复制多数标签。

7. **全量计算和拟合权限不同**：可以一次提取所有训练图的固定特征，同时预先按来源/视频组冻结fit与review角色。review标签不得用于修订待评价的提示词/阈值/生成器；生成器拟合只取相应版本允许的fit子集。全1272目标域描述表不自动表示每个后续参数都可用全部1272拟合，原train/dev/test身份不改写。

输出最少包含：`INPUT_MANIFEST`、`IMAGE_IDENTITIES`、`ALIAS_INDEX`、每图JSON/原文/权限、四路特征及availability、统计JSON/Parquet、联合分层、缺口/冲突账本、审阅页面、生成草案、协议/源码/模型/环境SHA和Run/Slurm日志。

四路仅是最低场景接口，不把它当最优表示。另维护实例级身体/姿态支持表：可信训练Box/Mask给可见轮廓统计与合法RGB裁剪，必要时用独立任务指令编码身体/姿态候选；不可套用“忽略猪体”的场景指令。该构建分支可使用合法训练标注，但必须标明GT辅助裁剪，不能冒称正常无GT分割结果；裁剪中邻猪/遮挡仍属不确定性。3D隐藏部位、世界尺寸或完整姿态不由向量距离补成GT。

## 3. 实际要估计的真实属性

| 字段组 | 可信输入/运算 | 输出与生成接口 |
|---|---|---|
| 来源与拆分 | 冻结原train ID、SHA、视频/相机元数据、公开许可 | source_group/camera/video hints、归属权限、近重复边；决定统计权重和派生数据隔离 |
| 身体与部位 | 可信Mask轮廓、已有姿态Box标签、RGB候选与人工证据 | 可见轮廓长宽/面积/截断、姿态区间、身体资产族需求；不由单图生成隐藏部位GT |
| 密度/关系 | 实例数、可见Mask并集、归一化中心距离、可见边界邻近、分段/缺失候选 | 条件于体型/姿态/相机的数量与接触图；真实遮挡率unknown，合成后可精确计算 |
| 尺度与相机 | 原图/目标640坐标变换、Box/Mask尺寸、已给K/R/t、视角候选 | projected_body_size、edge_truncation、view family；未知米制值null |
| 场景和遮挡设施 | 固定设施类型、原图证据ROI、开放/限位结构、设施投影宽度 | scene_graph、floor/barrier/fixture modules，设施ID与深度层可单独开关 |
| 外观/高频/退化 | 线性/非线性RGB定义明确的亮度、色度、边缘/频谱；皮肤/地板ROI候选 | 有状态的成像描述分布、材质族/光照族及可证伪的传感器范围，不冒充物理反演 |

近邻距离统一在最终输入像素或以中位身体尺度归一化；原图像素值不直接跨相机当物理长度。分位数只作描述，不把p5–p95以外的有效尾部排除。缺少独立来源时不伪造窄置信区间。

**已实际得到的底表证据（752/753/754）：** 2646唯一RGB/全部SHA尺寸通过；2311图来源Mask、335图Box/姿态；原任务13文件名族/29推导视频ID，非已验证物理场数。标注实例数≥15为原任务674、Faro237、Viewpoint0。统一640输入的`bbox_sqrt_area`中位数分别64.63/132.45/115.17像素；标注数量中位数15/11/7。三源的全图gamma亮度中位数0.319/0.421/0.224；中心tile高频功率占比中位数0.0408/0.00350/0.0173。后两类量受身体/设施内容、黑边、视角与采样共同影响，**不能直接当照度或独立材质差异**。

这些结果已支持将目标域先验与公开支持池分开，并特别核对尺度和密度覆盖；它们尚未证明任何因素对真实Mask AP的效应大小。2311图无来源姿态标签、全部2646图缺真实隐藏遮挡率，后续Qwen/人工/几何证据不能填成已知GT。独立复核核27956个来源Box尺度和15图float64像素量，统计JSON/Parquet2646行一致。

## 4. 生成器的联合设计

令 `theta=(身体B, 姿态Q, 空间接触/遮挡A, 场景S, 相机C, 材质M, 光照L, 传感器D)`，RGB为`I=R(theta)`。真实图仅识别其中一部分；已测量量、区间与未知分别进入约束。主生成分布使用条件场景图，而非独立边缘分布乘积：

`q(theta)=q(S) q(B,Q,A,C | S) q(M,L,D | S,B,C)`。

* **自然身体与姿态**：资产有许可/SHA/原始父族；骨架支持真实侧卧、腹卧、站/坐与部位形变。先核足地/腹地/关节和真实轮廓，再增加变体。不同随机缩放不当独立身体资产。
* **自然拥挤与遮挡**：先在可用地面安置身体与姿态，再计算接触、视角和可见性；允许真实接触，不允许身体/设施穿透。至少15头场景同时核真实可见数量、身体互遮、部位交叠和设施遮挡，不用只凑总数代替。
* **固定结构与占用分离**：宽栏可只有少量猪；限位架由贴身固定栏架决定。设施配置、猪数和体型共现可学习，但不能用占用定义设施类型。
* **相机与尺度**：优先约束最终图像中的身体大小、位置、投影设施宽度与畸变。真实米制未知可在明确的规范单位下做预览，米制字段保持null；未核验相机不冒称标定一致。
* **材质与成像**：结合皮肤/污渍、漏缝/湿地、栏杆反射和真实照明族。区分灯光变化与后处理亮度、反照率与曝光、真实纹理与采样混叠；不从RGB反推出唯一PBR数值。
* **完整成像链**：渲染→镜头/几何畸变→曝光/运动积分→采样/噪声→压缩。与Mask相关的空间变换一致应用；高频结构按最终分辨率验收，不能只看4K预览漂亮。

固定release分成“真实支持的基础池”和“有效困难增强池”。困难池有明确标签、来源范围与物理限制，用来补少见接触/遮挡/成像组合；占比待全量统计和有限同预算验证后冻结，不先宣称80/20或某个图数最优。每对可控反事实共享geometry_id/asset_parent，报告其相关性。

## 5. 保留合成数据优势的标签合同

每张输出RGB、可见实例ID/Mask及对应框，同时另存完整投影Mask、部位/规范坐标、深度/法线、相机和原始场景参数；哪些进入训练由方法协议决定。可见任务GT与完整投影分开，不能将被栏杆遮住的身体直接标为可见像素。不同真实来源的边界政策先审查，再固定对应导出规则。

所有标签来自同一场景几何与渲染状态。设施遮挡、不同灯光或传感器版本可成对生成；保存可重放种子、引擎/资产/代码SHA。拆分按身体资产父族、场景原型、视频/相机来源和几何派生链隔离，不能只按图片seed分。

## 6. 必须能推翻设计的验证

1. **全量计算完整性**：每个源ID均有结果状态，hash/尺寸/模型键一致；对全部失败和unknown报告分母。缓存重放与fresh RGB推理核相同身份，不把“跑完”当识别准确。
2. **独立属性核验**：从训练素材中预先冻结未参与提示词修订的来源/视频单元作盲审。原8例只作开发回归；Macro-F1、区域定位/关系准确性和不确定性校准按独立人标算。unknown真值不作负例。
3. **生成准入**：自然姿态、15+实际拥挤、物理接触、可见/完整标签一致性、相机投影、细边界及来源隔离均过；不通过不得量产。图像描述分布接近只能通过内容覆盖检查，不能替代训练效用。
4. **最小效应实验**：在生成器通过后，预注册几何/互动/相机块G与外观/成像块A的2×2对照，全部解剖/标签合法，等图数、身体/场景家族支持记录、等优化/监督/选点；比较G、A及交互效应。优先解决“结构支持不足”与“成像域差主导”两个竞争解释，不盲增图数或无限PBR采样。此处只是后续设计，未启动训练。
5. **真正终点**：固定数据版本后，原生与对象知识方法使用相同数据、增强、额外微调预算和评价器。分别报告数据策略效用与对象机制增量；最终正常RGB完整真实Mask AP、Box优先/成功损伤/尺度护栏及+5总目标仍需实际训练验收。合成分数、Embedding/FID距离、loss下降或Qwen标签正确均不能替代。

若G相对A无优势，则下调“几何首先”的投入假说；若A主要改善真实结果则优先成像校准；若两者无增益则检查真实错误账本、标签与原生训练口径，不无依据扩大数据或模型。任何结果均保留，冻结后不改指标/阈值追阳性。

## 7. 计算与资源的具体设计

四路2048维FP32对2646图最多约86.7MB（不含索引/可用性），全量向量本身不是显存瓶颈。一次只加载一个Qwen模型；模型耗时主要来自9B逐图生成。复用旧500全图向量必须核相同RGB/指令/模型/预处理与源码，不能混用旧40图属性替V3全图结果。

可选实例身体向量另按`实例数×8192字节`计费/存储，不计进上述86.7MB场景底表；是否编码所有实例由全量标注规模及工程吞吐另冻，不能无声扩大预算。
