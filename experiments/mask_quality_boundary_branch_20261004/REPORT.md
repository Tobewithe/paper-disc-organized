# 掩码边界归属质量分支：决定性结果

运行时间：2026-10-05  
模型：YOLO26m-seg COCO 预训练权重  
Ultralytics：8.4.100（脚本实际打印版本）  
训练：batch=2，imgsz=640，3 epoch，seed=0  
方法：one-to-one 候选独立掩码边界质量头，训练期使用 GT crop-IoU 监督，推理期使用质量分数修正候选排序。

## 关键差值

在标准 COCO 5k val 上：

- Mask AP50-95：0.38955 → 0.39298，**+0.00343（+0.343 个百分点）**
- Mask AP50：0.61854 → 0.61981，**+0.00127（+0.127 个百分点）**
- Box AP50-95：0.47422 → 0.47649，**+0.00227（+0.227 个百分点）**
- Box AP50：0.65116 → 0.65238，**+0.00122（+0.122 个百分点）**

在完整可用训练/验证子集上，Mask AP50-95 同方向提升 **+0.222 个百分点**。两个评估范围方向一致。

## 解释边界

这组实验支持以下较窄的结论：候选分类分数与掩码边界质量存在可学习的排序错位；在 one-to-one 候选保留阶段加入独立的掩码质量排序信号，可以在不改动官方框回归、分类和掩码主损失的情况下，带来小幅、可迁移的 Mask AP 提升。

它不支持“彻底解决掩码外溢”或“大幅提升所有实例”的表述。当前只完成 seed 0；若要把提升写成最终主张，仍应补至少一个独立 seed，或在论文中明确这是单 seed 的决定性验证。

## V2 复核与路线结论（2026-10-06）

随后按 `PROTOCOL_V2.md` 进行了冻结质量头复核。原模型参数和 BatchNorm 状态冻结，只训练质量头；质量 BCE 在第 4 个完整 epoch 已从 0.40764 降至 0.05899，说明局部 crop-IoU 目标可以被拟合。

但保存 checkpoint 的独立 COCO val2017 5k 复评没有复现性能提升。官方预训练基线 Mask AP50-95 为 0.42155；V2 第 4 轮 checkpoint 在 `alpha=1.0` 下为 0.42117，在 `alpha=0.25` 下为 0.42149。两者均为中性到轻微下降，不能作为方法收益。

因此本文档中的早期 pilot 和 3 epoch 结果只保留为路线形成依据，V2 结果表明“预测 crop-IoU 后直接重排类别分数”尚未成为可验证的性能方法。后续若继续研究，应改为直接针对最终候选效用或 coefficient/prototype 可实现空间设计新协议，不延长本路线训练。
