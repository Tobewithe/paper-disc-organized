# 连续接触组件及无交源起点资格：通过，不等于完整物理模拟

私有CPU运行环境与实际几何预检已完成。工具能识别穿越轨迹、检出静态交叉，其势能梯度通过有限差分；V7修复MAMMAL初态被独立工具判为无交，V8腹卧末态有交。这允许构建接触求解器，尚未产生新合格姿态或数据。

| 维度 | 本次实验的整体研究链路 |
|---|---|
| 问题 | 端点平滑没有保证变形过程不穿透；要推进用户要求的挤压形变，必须先有可信的连续接触组件及合法初态。 |
| 机制假说 | 不适用（工程必要条件核验）。要验证起终点都无交但中途穿越能否被CCD拦住，并核实际势能导数与原始猪网格初态；不以接口成功推断自然姿态/生物力学有效。 |
| 针对性方法 | 官方PyPI轮子逐SHA核验，安装在本Study runtime/venv，Python3.12.14、ipctk1.6.1、numpy2.3.5、scipy1.16.3，不改共享或模型环境。固定平行三角形穿越、静态交叉负对照、势能方向导数有限差分，最后读取同一修复rest与prone70全表面进行真实工具核验。 |
| 整体结果 | 两三角形起终点均无交，解析首次接触参数0.5，CCD安全步0.3984375且该步完整连续无交；静态负对照检出。导数FD−5.19532990074e−5、解析−5.19532985002e−5，相对误差9.76e−9。修复rest无交，prone70有交；两者直线构造路径安全步0.5259094，该数不是姿态完成比例或合格部分腹卧。相对仅端点检测，增加了已实测的中途穿越拦截；相对原生模型/已有学习方法AP收益不适用，未运行模型。 |
| 研究决策 | 接受此组件环境与起点资格，优先将连续接触接到**已合格站立的双猪耦合形变**。V12事后必要条件已否决原固定锚点腹卧求解，故不启动该路线；唯一后继V14实际执行，不继续工具包搜索/参数扫查。最终还须独立几何和实际RGB，原source32条边界保留，不能宣称闭合压力/体积或全动物动力学。 |
