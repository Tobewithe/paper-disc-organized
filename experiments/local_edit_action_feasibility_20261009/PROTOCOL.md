# 单区域掩码编辑：工程与有限动作机会

2026-10-09。方案来源为研究线原 `MECHANISM_EXPLORATION_PLAN_20260920.md` 的同日候选；B 负责方法设计与本地纯 CPU 动作核心，A 继续原统一冻结对照，并负责后续真实 native 适配及训练侧面板。用户持续通信、方法设计和全资源授权不替代科学证据；本 Study 不改变既有 TriFlow、RCMC 或 multi_local 的协议、参数和结果。

## 科学问题及限定

在冻结原模型、候选身份、框类分数和原生解码下，单次局部删补是否提供超出现有全局收紧动作的有限修复机会；若存在，真实图像证据能否比已有响应统计更好地选择这种动作。工程通过、GT 选动作的机会以及无 GT 部署收益是三个不同结果。本 Study 首先只执行工程阶段，真实数据机会阶段须在看到结果前补齐下述固定事实；不得把其待补列成已完成实验。

旧 multi_local 已使用全局五动作加响应统计，其固定模型是强对照；本候选不是首次使用多动作、收益预测或局部细化。当前不训练网络，不做风险 cutoff 扫描或修改 TriFlow。

## E：纯 CPU 动作核心工程检查

明确在当前桌面本地 CPU 执行，使用已安装 Python/NumPy，不连接笔记本或租用服务器。输入是同一输入网格上的 bool baseline、正阈值 .25 trial、负阈值 −.25 trial 和预测框支持；真实 native 解码不由本核心实现。源码、解释器、协议和结果在独立工程 Run 保存，失败保留且重试新 ID。

边带使用 8 邻接的 Chebyshev 距离、宽度 4 个输入像素，图外视为背景。内带为 baseline 减四次腐蚀，外带为四次膨胀减 baseline。删除候选为 baseline 中被正阈值 trial 删除、同时位于内带和支持内的像素；添加候选为负阈值 trial 相对 baseline 增加、同时位于外带和支持内的像素。各自作 8 连通分量，按面积降序、稳定行列及索引顺序排序，每个符号最多保留 8 个，不依赖 GT。默认排序及限制只决定有限候选，不按结果修改。

每个非零动作仅翻转一个连通区域，零动作始终存在；不合并、迭代或叠加动作。baseline 不得在声明支持外有前景，负阈值 trial 在支持外产生的填充伪前景必须被过滤。支持由真实适配器按官方 crop 语义提供，不能用向外取整的大框替代。动作以稀疏索引保存，apply 返回副本，输入不原地改变。action_id 不是跨图候选身份，真实适配器必须绑定 image_id/native row/raw 来源和 baseline 摘要；不得跨候选复用动作或批量展开全部候选的全分辨率动作张量。

合格标准为全部确定性工程断言通过：零动作逐位保持、单区域改动及区外不变、增删方向、支持保护、稳定排序和数量上限、图边缘/空满/窄区域处理、输入不可变、非法 shape/dtype 拒绝。小网格检查不是训练、真实图像 native parity、性能、延迟或方法可行性证据；没有实测指标填零。

## F：真实训练面板的有限动作机会

A 后续须固定并回传：来自已有 train2017 的代表性图像清单与 SHA、与风险校准/评价的隔离、候选及 GT 匹配口径和未匹配覆盖、实际设备/路径/解释器、零动作与官方 native 输出逐位 parity、全局动作定义和空动作处理、预先指定的机会门槛/统计单位/结束条件及成本。真实数据没有这些事实之前不执行 F；这属于实验定义未齐，不是重新请求用户权限。

F 的主要机会读数是 best(G_eq+local)−best(G_eq)，只看局部动作相对 baseline 不足以支持新增动作。G_old 为旧 multi_local 的五个全局收紧动作加零动作；G_eq 在 G_old 上仅加入同幅度全局 tau=−.25 扩张，使局部与全局均允许相同的 ±.25 方向。另报 best(G_eq)−best(G_old)，防止把新增扩张方向的收益归因于局部性。这是 F 运行前的设计纠正，未读取机会结果；不将负 tau 输入旧 multi_local 模型，也不改变独立冻结七臂比较。

保留全部成功/失败和未知候选，记录最终原图改动比例、空动作和候选分量截断数；4 像素带可能覆盖小实例全部内部，单连通区域不等于小扰动。GT 不生成动作，也不进入部署输入；GT 最佳动作不称可部署方法或理论上界。没有有意义局部增量则结束本配置，不扩大边带/动作数/阈值寻找阳性。

当前配置只处理 ±.25 阈值附近且位于边带内的有限区域，无法承诺修复高置信错误归属；面积优先与单区域限制也可能漏掉小碎片。即使机会成立，也不证明 RGB 能预测最佳动作。上述限制作为拒绝当前配置的可能原因记录，不据此在见到结果后追加动作。

若机会足够，再独立定义同架构、同标签、同训练预算的有 RGB/无 RGB 与 G_eq/G_eq 加局部四格。方法收益、原成功损伤及实际成本共同决定继续；有希望的方向按项目规范完成代表性 20k 充分训练。每次大实验后 B 作路线判断，不以无限修补维持分支。
