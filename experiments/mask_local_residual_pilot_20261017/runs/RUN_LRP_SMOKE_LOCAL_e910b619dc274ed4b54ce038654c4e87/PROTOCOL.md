## 3. 冻结计算和两个匹配训练臂

所有候选先按原生原图掩码面积≥9216选择输出；其它输出完全复用原生 RLE。原生 decoder 不变：完整同图 N×32 FP32 GEMM、原分块/上采样/裁剪/二值化/原图 byte 路径。必须逐行零残差原生重放。

从原生首次阈值前 input-grid logit 按 pinned `ops.scale_masks`、缓存 ratio_pad 连续缩放到原图得 Z。B 定义与 LEA 完全一致：`abs(Z)≤1.5` 且在原序列化 bbox 半开整数像素支持域内。B 不依赖GT或新模型。只在最终原图 B 内替换，B 外硬拷贝原生 N。

为避免“连续logit缩放”与原生“先二值再缩放”的差异让初始化本身改变掩码，固定锚点 `A=(2N−1)*max(abs(Z),1e−6)`。局部候选为 `N outside B; (A+δz)>0 inside B`；δz=0时逐像素与 N 相等。此锚点是新残差方法的显式解码设计，不冒称原生连续 logit。

逐像素输入68维：原生 P 的32通道、其与本检测 c0 的逐通道乘积32维、连续 Z、原生二值 N、相对预测框归一化 x/y 两维。P 先按原 `native_decode_hw` 用 pinned `scale_masks` 连续插值，再按原 ratio_pad 缩放到原图；Z 单独由原完整 GEMM 路径取得，不用重新求和代替。原图整数(x,y)用 `(x−left)/width*2−1` 和对应y，零宽高分母clamp至1e−6。无RGB、F、邻居、类别标签、GT或教师特征。

网络：Linear(68,32)→GELU→Linear(32,32)→GELU→Linear(32,1)，最后一层权重和bias置零，输出 `δz=2*tanh(raw/2)`，总3297个可训练参数。新架构不能加载旧系数 Adapter 的初始化；两臂均使用 torch seed0 同一全新initial.pt，逐张量哈希一致。

- **LOCAL**：每个 B 像素使用自身预测δz。
- **UNIFORM**：使用同一网络/输入/参数量，在该输出的固定采样像素上预测δz后取均值，将这个标量用于整个B。移除“区域内不同位置可获得不同残差”这一机制；仍保留输入信息、初始化、训练数据、监督和优化预算。它是受限功能控制，不宣称有效函数空间或优化难度完全一致。

每个可编辑输出固定从B无放回选至多512个像素，按 `sha256('lrp-v1|image_id=<id>|rank=<rank>')` 前8字节little-endian为PCG64 seed，用choice后排序。少于512用全部；空B保留原生且记录。采样仅限制训练计算，不改实际推理B。UNIFORM推理使用同一512点定义其标量，LOCAL推理计算全部B像素；不随epoch重采样。完整特征、锚点、目标、像素坐标及GT join预先保存，并逐文件哈希冻结。

训练目标：有join的可编辑实例，在固定采样点上计算 GT BCE(A+δz,Y)，像素均值→图内有join实例均值。保护项在所有可编辑实例上拟合 sigmoid(A) 的 BCE，像素均值→图内实例均值，权重0.1。总loss=GT项+0.1保护项。没有对应分母时该项为连接参数的0；空图不删。对GT未匹配实例只使用保护项，不伪造背景标签。LOCAL和UNIFORM的目标及所有权重一致。保护不是无损保证，最终全1808成功GT核验。
