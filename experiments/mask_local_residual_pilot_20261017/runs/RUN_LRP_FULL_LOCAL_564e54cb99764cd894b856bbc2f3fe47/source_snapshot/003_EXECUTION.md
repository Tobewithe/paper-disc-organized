## 运行链路和身份

执行端为 YANGLEI，`ssh 28358lan`，目录 `D:\coco_wire\baseline_native_20261013`。解释器和所有环境变量由 `scripts/launch.ps1` 显式设置，实际包版本、8项Ultralytics源码、TF32/cuDNN/精度/环境变量必须与继承合同逐项相等。权重、全部2000图和2000缓存、完整预测、两种标注身份、教师及初始化 SHA 复核。

1. `preflight.py`：仅1600拟合图，重放176042个原生输出及2510个教师输出；由拟合教师派生共同幅度a。基础网络/Adapter forward和优化步数均为0。预算1小时。
2. `verify_cld.py <preflight Run>`：以独立NumPy FP64公式重算2510个尺度及中位数；检查原生/教师重放覆盖及全部Run产物哈希。独立脚本不再次执行全部1600图decoder，明确区分生产重放和独立尺度核验。
3. REAL、PERM各自原初始化，在冻结拟合清单前8图各运行2次AdamW更新；每臂15分钟上限。各做8次零初始化forward、8次训练forward、8次结束forward；smoke总计4次更新，checkpoint不进入正式训练。
4. 每臂独立脚本重算8图loss/梯度、以显式AdamW算式复核两步参数、重算8图结束forward，核全部混合掩码、同图行映射、原生重放和身份。独立核验没有额外optimizer.step；总计每臂16次Adapter forward。独立核验上限1小时。

每次模型执行按真实Run登记，独立复核回执归属原Run；保留命令、源码快照、时间、错误、实际配置和退出状态。每阶段串行，前置失败不继续。资源要求无其它Python任务/实验锁，至少4GiB空闲RAM和8GiB磁盘。源码首版冻结于 `EXECUTION_FREEZE.json`，科学11项冻结保持不变；必要工程修正须另存执行冻结版本和失败产物，不改变科学阈值。

## 数学实现和预声明数值核验

新目标、loss、实例置换和幅度算法分别在 `cld_math.py` 实现。`sqrt(clamp(RMS²,min=1))` 与协议 `max(1,RMS)` 等价，同时避免零初始化时sqrt导数的奇异中间量。学生方向不归一化后再算MSE；截断仅用于保护项及正常候选。PERM只重排网络输出向量，接收实例的P/c0/ROI/教师/输出ID不变。

独立实现用NumPy FP64重算目标，显式逐实例BCE及MSE重算loss/autograd；范数/系数另用逐行公式核验。容差在真实Run前固定：尺度绝对/相对2e-10；loss绝对3e-6、相对1e-5；梯度绝对2e-5、相对2e-4；显式AdamW参数绝对2e-6、相对2e-5；幅度/探测系数绝对3e-6、相对2e-5。上述为不同运算顺序的工程核验容差，不能修改科学Gate。原生RLE、混合RLE、保存后forward、输出身份和源码/数据哈希要求精确一致。梯度测试另用double有限差分，eps1e-6、atol1e-5、rtol1e-4。

9项合成测试覆盖零初始化有效梯度、逐实例/图归约、截断两侧梯度、空ROI/无教师、实例置换及单输出、等幅探测/零方向、截断不放大小方向、图宏均值与共享重采样、阳性/阴性/信息不足三个出口及独立统计重算。不用真实留出效果调容差或超参。
