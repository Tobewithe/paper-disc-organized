# 真实场景参考采集 V1（2026-10-27）

用户明确要求先建立可供每次实验复用的高质量合成数据集，并增加真实场景资料来仿造。此轮执行对象是**参考资料与场景标定输入**，不启动模型优化或正式合成量产。后续动作只在 ACTIVE_PLAN 登记。

## 输入、隔离和用途

1. 已有 PigLife 派生真实 **train**：从既有 INPUT_MANIFEST 与 DATA_INDEX 交叉核验 split/source_id/group/image SHA。13 个训练文件名来源族，每族最多 4 张（优先包含该族最多已标实例与分散的原视频/时间），最多 52 张，拷贝原分辨率 RGB 与原标注。文件名族不冒称物理猪栏或动物独立身份。dev/test 图像及 test426 标注不读取，不用于相机/纹理/姿态拟合。加载既有拆分索引以排除 dev 是允许的，不把其中的 dev 行转入参考清单。
2. FaroPigSeg 作者公开数据：留存 README、许可与下载地址快照；只解码/导入原 train 图像和对应 YOLO 多边形，最多 1,200 张。若完整压缩包包含 val/test，只保存档案原字节而不解包、显示或分析这些图像。原论文随机分图不能证明视频/猪栏独立。该来源整体登记为 construction/reference，不能再充当独立外部测试来源。
3. Viewpoint-Aware Pig Posture 作者发布 Hugging Face：锁 repository revision；只读 train.csv 与 train_images，从相机/日期/姿态分层选最多 336 张完整 RGB 帧，附原始训练框/姿态/视角行。seen/unseen test CSV、图像不下载。其姿态/框标签不能充当实例分割标签；未标对象或部位保持 unknown。
4. 其它公开来源只做有来源/许可的候选登记，须先记录实际访问与可用文件，不把网页示意图数或论文样本总数计为已收集。允许在以上范围遇网络失效时改用**同作者、同数据的官方训练样本镜像**，保留失败日志，不悄悄用别的数据替代。

原图用于受控研究参考，不将参考 RGB 当作已校准反射率；只有审核后的皮肤内部/设施区域才能进入将来的纹理资产。所有用于构建的源视频/相机/猪栏及近重复族在未来独立确认中排除。对训练来源之外的公开源，原始分组未知时按整个来源隔离。此轮只建参考清单，**不改旧训练/开发/保留测试拆分**。

## 有限预算与记录

- 本地 CPU，0 GPU、0 模型前向、0 optimizer 更新；至多 4 并发下载，每个 HTTP 请求 45 秒、至多 2 次。总下载原始数据上限 1.5 GiB，已有 train 原图传输上限 0.5 GiB；输出为本地个人工作区。
- 元数据/少量 train 原图的服务器读取使用已登记个人账号，只做轻量 I/O 与 SHA；不在登录节点运行 GPU 或批量图像分析，不启动 Slurm 训练。
- 每次脚本运行独立 runs/RUN_*/run.json，保留失败、重试、命令、脚本 SHA、下载响应/源 revision、逐图/逐标注 SHA。中断不宣称完成。
- 原始文件只写新目录；失败 .part 不改成成功文件。安全解包检查路径，不执行下载代码。不安装作者训练环境。

## 判别与产物

当前主张 H：真实视角/卧姿/设施与光照的支持覆盖是旧合成数据明显缺口，先用真实资料约束生成器比继续随机化旧场景更值得优先。竞争解释是只需旧生成器更多随机种子；参考的实际跨来源差异与新场景复现质量可以检验前置覆盖条件，但**不能单靠图册证明真实训练收益**。

交付源快照、逐图哈希/原标签、分组索引、去重与维度/明暗/尺度描述、可实际查看的场景/姿态图册、据此提出的首个场景参数与尚未辨识的相机/几何量。所有颜色/尺度统计是观测图像统计，不是物理真值。正面出口：资料确有差异且可用，进入带真实证据链接的规范场景；负面出口：重复或条件不符则保留资料但不扩大同类下载；信息不足：来源/许可/分组无法核验的资料隔离，不进入资产/标签管线。

合成首场景另行冻结渲染预算与物理/标签检查。正式 release 与普通原生相同额外微调的真实效用验收仍未完成；此轮不授予 release、最佳训练集或 +5 效用通过身份。
