# 生成阶段执行合同 v1

父协议：[PROTOCOL.md](PROTOCOL.md)。资源预检Run保留其原协议快照；本合同在首次渲染之前冻结，明确标签实现与验收，不改变样本数量、渲染预算或研究结论边界。

实际引擎：官方Blender 4.2.1原生Python/Cycles，OptiX单GPU；未调用BlenderProc/Kubric。两个程序化四足体是工程资产，不能称为真实动物数据或逼真仿真。

RGB使用Cycles 16 samples；标签使用同一场景/相机/网格在像素中心的独立射线投影，属于无材质抗锯齿的几何标签渲染。完整投影通过仅包含该目标全部部件的BVH计算，正常可见图通过全场景BVH计算。相机无运动模糊，所有对象不透明。避免将自身部件间遮挡计为外部遮挡。

标签画幅512×320，完整投影扩展至1024×640，保留相同焦距像素尺度；中心裁剪对应原视野。输出range_to_surface_m是沿单位相机射线到首个表面的距离。背景无交点为NaN，不冒充相机Z坐标。

每帧固定48个像素，通过独立bpy.scene.ray_cast查询遮挡者与距离；要求ID完全一致、距离误差<0.002米。输出可见掩码必须属于完整投影；遮挡者像素总和必须等于被挡像素；不得出现背景解释的遮挡；所有目标投影不得被扩展画幅裁掉。任何断言失败均中止并保留失败Run。

本轮只验证几何、稳定ID、可见性/视野分解与事件覆盖。未来模型推理只能读RGB及历史观测，不能读这些完整投影、真深度和真身份。

Smoke：front_occlusion的第0、12帧；Pilot：六种场景的全部0—23帧。事件覆盖若缺失，记为信息不足；不得事后缩小成功条件。
