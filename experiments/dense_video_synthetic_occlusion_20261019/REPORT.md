# 三维遮挡场景生成与自动标签：有限工程验证

已在算力服务器master-01使用个人账号及Slurm执行。原生Blender/Cycles OptiX路线完成6段、144帧、288条个体观测；生成时6,912个独立几何抽查点通过，随后独立数组核验通过。此阶段完成的是生成和标签工程验证，模型训练0步，尚无真实视频上的模型效用结论。

| 维度 | 本次完整工程实验的研究链路 |
|---|---|
| **问题** | 第三轮11例物理遮挡复核没有可靠完整遮挡金标准；当前需要身份和遮挡原因明确的训练监督，支持后续遮挡状态与关系模型。 |
| **机制假说** | 工程核验不适用模型机制归因。要检验的必要条件是：同一三维场景的稳定身份、完整投影及可见表面足以生成可审计遮挡标签，同时将外部遮挡和视野截断分开。 |
| **针对性方法** | 固定Blender4.2.1、seed20261019、512×320、16samples。两个程序化四足体、挡板与地面分别有稳定ID；六种预定场景各24帧。正常场景与独立目标逐像素射线查询得到可见/完整投影，扩展画幅记录出画。每帧48点通过独立scene.ray_cast核验；前/后挡板成对场景保持目标轨迹相同。 |
| **整体结果** | 144帧全部完成，288条观测包括可见167、部分遮挡85、完全遮挡28、出视野8。掩码子集、遮挡者像素守恒、身份/位姿、视野分解和成对轨迹检查通过。28是帧级个体观测数，不能称为28个独立事件。与原生检测器、BoT-SORT或已有遮挡模型的收益均未测；本轮没有训练或跟踪方法增量。 |
| **研究决策** | **保留Blender原生生成与几何标签路线，优先建设资产和动作独立的“遮挡—重新出现”训练数据。** 本轮证据支持该路线提供监督的工程可行性；六段同资产短片不支持泛化训练结论。唯一下一步是冻结具有多资产/多动作、按资产家族和场景拆分的数据生成协议，再开展遮挡状态模型及真实视频验证；该训练尚未启动。 |

| **合计：288条个体观测** | **167** | **85** | **28** | **8** |

完整投影保留目标自身的三维形状与姿态；自身部件互相挡住不计外部遮挡。每帧输出RGB、可见实例ID、相机射线距离、原视野与扩展画幅中的独立目标投影、可见框、遮挡率、视野截断率、遮挡者覆盖、相机参数、物体位姿和动画场景文件。未来推理只能读RGB及历史观测，真ID/真深度/完整掩码只作监督。

标准格式已导出：144张COCO图像、252条可见分割、280条完整投影分割、252条MOT可见观测及288条遮挡状态。532条RLE全部通过原掩码解码一致性检查。不可见目标保留状态记录，不填入可见COCO/MOT框；完整投影标注独立存放。合同见[EXPORT_CONTRACT.md](EXPORT_CONTRACT.md)。

主查询ID1在前方遮挡场景第9—13帧完全不可见，第14帧重新部分可见；混合场景第3—5帧完全不可见，第6帧重新部分可见。另一目标的两段完全遮挡延续到视频末尾，不能算作已观察到重新出现。视野截断是独立属性，允许与遮挡同时发生。

本批两个四足体是程序化几何素材；外观、姿态和场景多样性有限。真实视频的监督和独立评价仍需补充，本批结果不替代真实遮挡标注，也不证明动物身份恢复或跨类别泛化。
