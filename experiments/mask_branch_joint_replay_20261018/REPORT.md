# 原生掩码分支联合适配：完整三臂实验结案

2026-10-19复核。三组均已完成原定20,000图×3轮、15,000次更新；三组最终checkpoint完成全5000图评价及2000次配对图像bootstrap。Slurm 108—113全部正常退出，最后统计与结案于2026-10-18 16:22（Asia/Taipei）完成。本轮查询没有追加训练、模型前向或新重采样。

**主要结论：联合更新P和系数头的PC未通过冻结门槛；已有适配器在共同20k配方下的G_budget取得本轮最高实测Mask AP，且比旧G损伤更少。** 这是既有方法对照的新收益，不能记为联合微调设计的贡献，也不将对照事后晋升为通过主Gate的新候选。

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | 旧面积门控G在历史全量评价仅增加0.141573 AP；同服务器重放增益为0.138557 AP。有限Oracle已证明部分固定P输出有修复机会，但此前多个新增结构、监督和空间信息方案未兑现足够额外收益。需要回答：直接适配原生掩码分支，能否成为比轻量系数适配器更强的基座？ |
| **机制假说** | H：P生成路径与原生系数头共同调整，能改善二者的配合，兑现更多有效修复。竞争解释是共同训练预算/配方，或只适配原生系数头就足以获得收益。如果H值得投入，PC必须同时超过原生、旧G、同预算G和仅更新系数头的C，并守住损伤与成本要求。PC比C容量大，因此即便阳性也不能独立证明纯协同机制。 |
| **针对性方法** | G_budget、C_native、PC_native共享同20k图、源batch16/有效batch4、3轮15000步、初始化规则、监督与AdamW配方；分别更新既有适配器、原生系数头、原生系数头加Proto。检测与基础网络其余部分冻结。推理统一按原生mask面积≥9216应用修正，门外保持原生；五种方法在同服务器、同5000图/539125个检测上比较完整COCO AP与全22958原成功GT损伤。只用各自最后checkpoint。 |
| **整体结果** | G_budget相对原生+0.251337 AP、相对旧G+0.112780 AP，两项95%区间均全正；损伤81/22958，低于旧G的90/22958。C也有收益，但未证明优于G_budget。PC相对原生仅+0.003867且区间跨0，相对旧G、G_budget、C分别−0.134690/−0.247470/−0.235321 AP，三个区间均全负；四项效用门槛全部未过。PC损伤、检测身份和成本护栏通过，故这是效用失败，非工程失败或损伤超限。 |
| **研究决策** | **选择固定P的轻量系数适配作为当前最有实测依据的可用方案，保留G_budget为最高观察分数的参照，停止本PC配置新增训练投入。** G_budget与C的AP差异尚未分清，但G参数更少、观察损伤更低；当前没有优先投入联合Proto更新的阳性依据。**唯一下一步：把G_budget的新收益和PC/C对照写入既有“可修机会—实际兑现—损伤代价”论文证据与主张表，收束方法贡献边界（尚未启动论文修改）。** 只有另行冻结且有独立支持依据的研究在同配方对照、增量和损伤上通过，才重新考虑联合更新；不能由本结果直接推出“样本量是原因”或“P永远不应更新”。 |
