| 维度 | 本次实验的整体研究链路 |
|---|---|
| 问题 | 旧状态分类收益没有稳定转成真实遮挡恢复；本轮直接训练对应、无对应与可见证据。 |
| 机制假说 | 物理配对相对普通视频监督有额外恢复效用；竞争解释是普通对应训练或隐藏位置监督已解释收益。 |
| 针对性方法 | 同初始权重、参数、数据、8,000总步预算比较 B/P/I/Hpos；独立测试80家族，另含冻结N和P记忆干预。 |
| 整体结果 | 见下表和配对95%区间；总收益 P−N、普通训练 B−N 与新增收益 P−B 分别保留。 |
