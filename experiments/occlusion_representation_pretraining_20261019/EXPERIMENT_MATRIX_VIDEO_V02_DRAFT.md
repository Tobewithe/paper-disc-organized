# 视频遮挡表征对照实验与裁决

版本 v0.2，2026-10-20。与[研究方案](PROTOCOL_VIDEO_V02_DRAFT.md)、[模型和损失](MODEL_AND_LOSS_VIDEO_V02_DRAFT.md)、[数据合同](DATA_CONTRACT_VIDEO_V02_DRAFT.md)共同构成设计。本文件全部为计划，尚无新实验结果；建议数值须在正式 Run 前写入冻结执行协议。

## 1 先回答的科学问题

首轮研究问题是：**同预算视频监督已存在时，物理干预配对能否额外改善跨遮挡对应，并使收益保留在可迁移表征中？** 历史信息有用、当前输出头有效、真实系统改善是三个不同层次。必须分别检验，不能用一个宏平均分类 F1 替代它们。

旧实验已表明状态 F1 可以很高而真实恢复几乎不变。因此首轮主读数落在重现后对应，无遮挡精度与错误确认是护栏；状态 F1 和可见比例误差仅用于解释。

## 2 首轮训练臂和参照

| 代号 | 模型与训练 | 改变的因素 | 作用与局限 |
|---|---|---|---|
| N 原生表征 | 原始 DINOv3 初始点与当前特征最近邻，验证集固定接受阈值，无新增表征训练 | 不含新适配和时序学习 | 报告相对原生的总效用；不是同容量机制对照，也不是强跟踪器 |
| B 常规视频训练 | 与 P 相同模型、视频、对应/无对应、状态、校准监督；内容正对来自同版本可逆增强 | 不使用跨物理干预的内容正对 | 主机制参照；保留合理的视频监督，不能故意做弱 |
| P 提案 | 全部基础监督＋跨干预的可靠可见内容配对 | 新配对约束 | 主要候选，结果无论好坏均报告 |
| I 初始锚点与当前帧 | 与 P 同结构、损失、更新；每个预测时刻重新初始化摘要，用当前帧填满 8 帧缓冲，保留初始可见锚点 | 移除中间历史及历史摘要 | 检验额外视频历史的价值；不是完全无历史的单图模型 |
| Hpos 隐藏位置参照 | 在 P 上加 0.2 权重的画内隐藏位置监督，不增加参数 | 额外运动位置先验 | 与已有文献思路比较，不能只测有利于 P 的消融 |
| R 成熟点跟踪器 | 首选 TAPNext++ 官方因果权重；CoTracker3 作附加参照 | 架构、预训练数据和预算不同 | 方法效用参照，不能作为单项机制归因 |

N 的最近邻尺度与接受规则在验证集冻结。R 的模型版本、官方权重、查询模式、输入尺寸和延迟必须核对；未能运行就报告该参照未完成，不能静默换成更弱模型。CoTracker3 的 online 窗口不自动等于逐帧无未来输入；需要相同因果条件或独立标注非因果结果。

**第一轮训练仅规划 B/P/I/Hpos 四臂。** 建议每臂 2,000 更新、同 seed 和初始化，固定 last checkpoint；原生及成熟参照不重新预训练。所用 8,000 总更新是新设计建议，不是沿用旧实验预算或已经分配的资源。

## 3 配对与容量怎样真正匹配

每次为同一家族选择物理版本 a、b，各自产生两次有效增强 a1/a2/b1/b2。B 与 P 均前向全部四个视图，并对每个视图计算同样的事件监督；B 配 a1↔a2、b1↔b2，P 配 a1↔b2、b1↔a2。计算方向和正负对数相同，采用同一双可见物理支持 Ω，即使 B 本来能使用更多点也不扩大其主对照支持。

所有臂固定数据家族顺序、RGB 和增强种子、query 列表、监督标签池、优化器、学习率、损失归约、梯度累积和输出解码。建议 AdamW lr=1e-4、weight decay=1e-4、有效 batch=4 家族，按显存决定微批并记录；显存预检不允许根据方法测试表现更换配方。

I 在每个输出时刻重置摘要，禁止从上个时刻偷带真实历史。其当前帧作为同长度缓冲输入，查询锚点保留；图像唯一信息被主动削减，不能声称“输入完全相同”。B/P 的有效参数和输入严格匹配，I/Hpos 的主动差异按表报告。额外物理配对关系属于方法监督信息，不谎称已完全排除监督增加。

主损失不得按模型置信度剔除难样本。每臂记录有效参数、梯度非零覆盖、各类有效标签数、Ω 空集率、主干/时序/投影梯度、前向次数、显存和总时间。预算匹配失败属于比较无效，不算新机制阴性。

## 4 完整实验安排

| 完整实验 | 问题与假说 | 方法及必要对照 | 主读数与下一决策 |
|---|---|---|---|
| E0 数据与损失合同 | 工程核验，不主张机制阳性 | 少量完整事件导出；独立射线/表面对应、输入白名单、未来替换、各损失梯度 | 通过才冻结训练；失败修相应数据或接口，不启动正式训练 |
| E1 视频对应预训练 | H 的配对约束是否比普通视频监督带来增量？ | B/P/I/Hpos 匹配训练，N/R 参照；未见资产/场景、线索冲突与输入干预 | 重现首帧正确接受率、误接及无遮挡护栏；决定是否保留新配对机制 |
| E2 冻结表征迁移 | 效果在表征中还是仅训练头中？ | 固定同一 checkpoint，丢弃原投影/预测头；相同新弱读出及训练预算，另报仅 F 与 (F,h) | 真实点对应和实例候选关联；若原头有效而新读出无增量，收窄主张 |
| E3 完整真实跟踪 | 表征改善能否抵抗真实候选噪声并改善身份恢复？ | 固定检测分割输出及关联器，替换表征；与原系统、B、BoT-SORT 同前端比较 | IDF1、遮挡恢复与错误补接，结合候选覆盖；决定实际应用结论 |

E2/E3 是有条件的后续完整实验，不随本次文档更新自动启动。追加 probe 训练、跨 seed 确认和真实标注使用需各自冻结预算，不混入首轮 8,000 步记录。

## 5 对应、遮挡与误接的评价语义

### 5.1 合成再对应

主对象为已创建可见查询、随后至少连续 3 帧因外遮挡不可见、再出现且几何标签有效的表面点事件。自遮挡与出画事件单列，不能填补外遮挡样本数量；对象级完全遮挡另由 A/V 定义，不由点标签代替。

主指标 R1 为重现首帧正确接受率：正确需在归一化到 256×256 坐标后距真值 ≤4 像素、归属一致且通过验证集冻结的接受规则。拒接和错接都计为未恢复。统计先对对象事件内查询平均，再对事件、家族平均，报告独立家族分母及事件数，不把大量表面点当独立样本。

必要护栏：

- 错误确认率 W：被接受但错误的提议 / 全部预先固定评价提议，另报被接受提议中的错误比例和覆盖率，避免靠全部拒接获取低错误率。
- 无遮挡正确率 U：固定连续可见片段上的正确接受率。
- 置信可靠性：Brier、风险—覆盖曲线、严格歧义对的过度自信；不能把准确率等同于校准。

所有方法采用相同事件及提议分母。接受阈值在验证集按同一目标错误率/覆盖规则确定并冻结；测试上同时报告固定规则结果与完整风险—覆盖曲线，不依据测试真值挑有利工作点。

### 5.2 真实点对应

优先选公开 TAP-Vid 数据的 first-query 协议，保留原查询与可见性标注，使用官方 AJ、可见性和定位评价；再采用 TAPNext++ 的 AJ_RD 衡量重现后的跟踪。公式、代码 SHA、数据版本与无重现视频的处理在执行前固定。[TAP-Vid 官方入口](https://tapvid.github.io/)，[TAPNext++](https://arxiv.org/abs/2604.10582)。

公开点的不可见标注未必区分外遮挡、自遮挡与出画，所以该结果叫“重现对应”，不能全部描述成真实外遮挡恢复。TCOW 的专门遮挡视频作为补充，先核其对象/掩码标注权限与事件定义。GT 初始点属于条件任务输入，不等于自动检测系统。

真实测试不参与 loss、checkpoint、阈值和 probe 选择。新读出先在独立合成训练划分拟合，在真实数据零样本测；少量真实有标签微调属于另一个结果，单独报告所用视频和预算。

### 5.3 实例关联和完整跟踪

实例层以固定前端产生的全部候选为对象。候选中没有真实目标时，正确动作可能是暂无匹配；候选缺失不能从全量评价中删除。另报 GT 覆盖条件下的关联能力，不能用它替代整体效用。

完整系统同时比较原生系统 N_sys、普通视频表征 B_sys、P_sys 与预先指定的 BoT-SORT R_sys，冻结同一检测分割输出、候选 ID、motion 特征、关联器、输入分辨率和评价器。BoT-SORT 是现有方法参照，其特征、训练来源与计算量单独记录。[原论文](https://arxiv.org/abs/2206.14651)。

主指标为完整序列聚合的 IDF1，辅以 HOTA 和 ID switches。物理遮挡后严格恢复需有独立有效事件标签：在预定 0.5 秒恢复窗口内找到原实例并连续 3 个可见观测保持原身份，窗口内错接不记成功。视频帧率、可见观测数及截断规则启动前冻结。仅标注消失的普通 MOT 轨迹不自动当作物理遮挡金标准。

现有 11 段已暴露视频只作研发回归；没有 ID GT 的自采视频只作定性展示。新定量集选公开身份/遮挡标注或独立核验后的事件，不以演示清晰度代替效用。

## 6 线索冲突与定向干预

同一 checkpoint 上完成以下预登记检查，不额外训练，不按结果选案例：

| 干预 | 预期变化 | 排除的解释及局限 |
|---|---|---|
| 换背景/遮挡者外观但几何不变 | 对应质量与状态基本稳定 | 检验外观共现依赖，不要求所有特征逐维不变 |
| 改遮挡路径及真实重现位置 | 状态与对应按新真值响应 | 排除固定位置/计时器；需完整重算标签 |
| 同时对视频和标签作合法空间变换 | 对应坐标随变换，身份保持 | 单独看特征距离下降不足以证明可用 |
| 历史顺序置换，当前帧/初始锚点不变 | 在依赖时序的事件上有预期影响 | 置换造成分布移位，只作辅助，不替代重训 I |
| 摘要记忆置换与等范数扰动 | 正确历史应优于其他目标摘要，并优于匹配扰动幅度的控制 | 同时检查不相关事件，避免把任何破坏都叫机制证据 |
| 外观/运动线索冲突 | 可辨时正确取证，不可辨时降低不当确信 | 不能把纯外观或匀速运动当作普遍正确答案 |

线索冲突面板在生成前按“外观可辨性×运动可预测性×遮挡时长”指定。目标自身可辨纹理是合法线索；隐藏期间的合理速度变化使固定惯性失效。纯运动常速度、初始外观最近邻、时间/位置浅层探针作为零训练或极低容量的捷径参照，probe 预算单独登记。单一探针表现差不证明网络完全没有捷径。

严格因果检查采用相同前缀、不同未来续接，要求 t 及以前输出一致；未来替换测试和随机 mask 检查均通过才允许声称无前视。

## 7 建议效用门槛与统计

以下为执行前待冻结的建议，不追溯修改旧 Run，不允许在看过新测试结果后改数字：

| 层次 | 建议效用条件 | 必要护栏 |
|---|---|---|
| E1 新配对效用 | P−B 的 R1 ≥3 个百分点且配对 95% 下界>0；P−I 的差值下界>0 才支持额外时序作用 | W 增量的 95% 上界≤1 个百分点；U 差值下界≥−1 个百分点 |
| Hpos 竞争方案 | Hpos−P 的 R1 ≥3 个百分点且区间下界>0 | 同样的误接和无遮挡护栏；不是事后改选“最强臂” |
| E2 真实表征迁移 | 同预算新读出 P−B 的真实 AJ_RD ≥2 点且区间下界>0 | 全序列 AJ 差值 95% 下界≥−1 点；风险—覆盖与校准共同报告 |
| E3 实际改善 | P_sys−N_sys 及 P_sys−B_sys 的 IDF1 均≥0.5 点且区间下界>0 | 对两参照的错误补接增量 95% 上界≤1 个百分点，HOTA 差值下界≥−0.5 点；相对 R_sys 的额外收益/退化必须独立报告 |

E3 超过原系统而未超过 BoT-SORT，仍可报告改善，但不得说已超过成熟基线。未达到实用幅度、证据显示损伤和区间精度不足分别判定。E2 若仅一个任务成立，跨任务通用性主张不成立。

合成按反事实家族成簇，真实按原视频成簇做配对 bootstrap，建议 2,000 次；官方聚合指标每次重算，不能先平均各视频 IDF1 冒充官方聚合。首轮单 seed 只给定种子条件下的区间；多 seed 稳定性需独立确认，不能由像素级样本量夸大。

正式冻结前只依据标签分母、场景独立性和保守方差做可行性检查，不查看方法测试成绩。若样本量不能支持建议护栏精度，需预先调整研究阶段或标记探索；不能承诺小样本已能证明 1% 风险。

## 8 结果如何改变方向

| 冻结结果 | 结论 | 唯一后继 |
|---|---|---|
| P−B、P−I、护栏和干预均满足预测 | 支持本预算下物理配对增量与时序作用 | 用同一 checkpoint 做冻结迁移 E2 |
| P 好于 N/I，但对 B 的增量上界低于实用门槛 | 普通视频适配有价值，当前新配对贡献不足 | 停止本配对配置投入，优先确认 B 的真实迁移价值 |
| P−B 成立但 P−I 明确不成立 | 配对可能改善静态/锚点匹配，未建立额外时序作用 | 收窄为该对应能力，不以视频记忆机制扩大训练 |
| Hpos 按预定比较优于 P | 隐藏位置先验值得优先，原 P 结论仍保留 | 下一版本选择隐藏先验方向，并补 B＋隐藏先验对照隔离作用；本轮不自动续跑 |
| 合成有效而真实点迁移无实用增量 | 合成机制范围成立，真实泛化不足 | 聚焦合成—真实的对应域差，停止直接扩完整系统 |
| 点对应有效而完整跟踪无增量，且候选覆盖不足 | 关联改进无法弥补前端缺失 | 优先解决固定前端的可见候选覆盖，不追加身份规则 |
| 点对应有效但新实例读出无增量且候选充分 | 局部表征未转成实例可分性 | 聚焦局部到实例的聚合监督，停止“通用身份表征”主张 |
| 区间跨越决策阈值 | 证据不足 | 只完成预冻结上限内的样本；上限后结案未决，不加训追阳性 |
| 几何、泄漏、训练或匹配核验失败 | 工程/比较无效 | 修复具体合同并保留中断 Run，不作科学阴性 |

条件重叠时先裁决有效性和护栏，再裁决预指定 P−B；Hpos 的结果单列，不用于挽救 P。若出现未列出的失效，结案时依据证据收窄结论，后继须在新版本登记。
