# 视频事件与表征接口核验报告

2026-10-20。服务器已完成最小事件包、自动标签及真实特征上的四臂接口核验：8 个家族、24 段视频、1,152 帧。E0 通过，完整 40,320 帧数据准备任务 160 已运行，四臂正式训练与评价任务 161 等待其成功完成。**目前没有正式恢复率、错误补接率或真实视频改善成绩。**

| 维度 | 本次工程实验的整体研究链路 |
|---|---|
| **问题** | 旧管线提供状态/比例标签，缺少骨骼形变后的同一表面对应；不能直接用于视频恢复预训练。新方法还需排除未来输入、无效梯度与不匹配对照。 |
| **机制假说** | 本次是有效性核验，机制证明不适用。后续主张是物理配对在普通视频监督之上改善对应内容保持与证据变化的区分，需由 P−B、P−I 和护栏检验。 |
| **针对性方法** | Blender 渲染同家族三物理版本；固定变形前三角化，逐帧 evaluated mesh 重建重心表面。复核实例/深度/可见性/事件标签；用真实 DINOv2 特征做四臂各4步工程优化、因果输入、校准梯度和指标语义检查。 |
| **整体结果** | 27,648 次独立射线身份检查通过；投影实现一致性最大偏差 0.0000532 RGB 像素。四臂均1,356,043个有效参数，初始化一致、损失有限。未来帧替换前缀误差0，I组历史替换后续误差0，校准梯度未进入表征层。相对基线的科研收益未测，不能以这些通过项替代。 |
| **研究决策** | **优先推进直接面向跨遮挡对应与拒接的物理配对表征训练。**依据是已有状态模型真实增量不足，以及本次可追溯数据/梯度/因果路径成立。唯一下一步为冻结的 B/P/I/Hpos 四臂2,000步对照；E0通过已放行，任务已提交。P−B实用增量或风险护栏不成立时停止该配置，不追加训练追阳性。 |

## 模型接口核验

底座为官方 DINOv2 ViT-S/14，冻结；训练空间残差适配、2层因果查询时序模块、摘要记忆及监督头。草案 DINOv3 因当前没有可用访问权重，在任何新测试前明确替换，四臂保持一致。完整定义见[执行协议](EXECUTION_E1_V02.md)。

- 四臂均1,356,043个参数获得非零梯度，没有以死参数凑容量。
- B与P均使用相同四个真实编码视图，共同可见支持224个点时刻（首工程家族）；改变配对方式。
- 16个工程优化步的权重全部弃用；正式训练从同一个未适配初始张量重新开始。
- 单家族微步约0.26–0.39秒；峰值显存约1.43GB。仅用于估算预算，不作正式速度对比。
- 最终源码对已经通过短训练的模型，在四臂默认前向上最大差为0。
- 更换未来24帧，不改变此前输出；I组更换中间历史，不改变后续输出。
- 单独反传校准目标只更新校准头；校准损失不冒充新增表征贡献。
- 错过第一重现后再找回不获R1信用；隐藏帧错误接受会被计入错误，而不是因“目标仍存在”被免罚。

## 失败与保留

首个渲染 Run 在第3帧发现变形会改变多边形的三角剖分，触发拓扑断言并停止。修复是先对原始网格固定三角化，再施加骨骼形变。失败记录和已生成文件保留；重试采用独立 Run，未放宽拓扑门槛。

当前正式数据 Run 的通用元数据模板把渲染/特征阶段默认关联到 E0 协议；实际正式范围和预算由启动前 `TRAIN_FREEZE.json` 中的 E1 协议 SHA 冻结。此元数据路由说明见[说明记录](server_execution/METADATA_CLARIFICATION.json)，未修改冻结代码、协议、预算或科学判据。
