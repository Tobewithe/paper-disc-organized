# 视频遮挡生成与监督数据合同

版本 v0.2，2026-10-20。服务于[视频主线](PROTOCOL_VIDEO_V02_DRAFT.md)，替代[空间配对草案](DATA_CONTRACT_DRAFT.md)的后续设计用途。全部合成标签从自建三维场景自动导出，无需人工逐帧标注。本文件描述待实现的数据版本，不将旧 72 段视频算作新数据。

## 1 生成单位是完整事件

一个 scene_family 包含同一组物理目标、运动与相机的基础事件，以及受控干预版本。每个版本是一段连续视频，具有目标首次可见、遮挡发生、遮挡持续、再出现或未再出现的时间关系。无永久消失的证据时，片尾仍不可见记录为右删失，不能自动标为离开场景。

| 事件族 | 具体场景 | 要排除的混淆 |
|---|---|---|
| 单次外遮挡与重现 | 目标从障碍物后经过，露出局部、完全隐藏再出现 | 只凭目标变小或轮廓缺失分类 |
| 相似个体交叉 | 相似目标交叉、并行、交换前后关系，含可辨和严格歧义构造 | 最近位置或固定目标顺序决定 ID |
| 多次与长间断 | 同一目标反复遮挡，间断短于和长于近期窗口 | 固定计时器或只记最近一帧 |
| 离开与返回 | 无外遮挡物时出画，随后从不同位置返回 | 把出画与完全遮挡混为一类 |
| 观察质量降低 | 运动模糊、曝光或压缩变化，几何仍可见 | 把模糊、低分辨率当作几何遮挡 |
| 自遮挡与姿态变化 | 转身、肢体运动导致原表面不可见但实例仍可见 | 把局部点消失当作整个实例消失 |
| 无遮挡负例 | 接近但未遮挡、同背景不同目标、静止和相机运动 | 只要邻居靠近就触发遮挡 |

建议按这些主事件族均衡取场景，再独立分层短/长间断、刚体/非刚体、固定/移动相机。事件可以组合，但主分组在生成前指定，不能按模型表现重分类。

## 2 资产和场景

复用现有 Blender 骨骼动物与场景程序，增加程序化刚体、不同形状和运动方式的目标、可独立编号的障碍物。对象种类覆盖刚体和非刚体；猪只是非刚体案例之一。真实程度包含形变连续、接触关系、阴影和相机运动，不只提升贴图清晰度。

生成顺序为：资产及来源清单 → 拆分 → 连续运动与相机 → 干预表 → RGB 与几何导出 → 独立核验 → 事件索引。刚体采用可控物理运动，骨骼对象采用连续姿态；检查穿模、瞬移和错误拓扑。现有 Blender 管线优先扩展，不因 [Kubric](https://github.com/google-research/kubric) 也提供视频标签而立即迁移整套依赖。

保留资产家族、原始资产来源、网格拓扑、绑定、材质和背景来源的 SHA。缩放或换皮不算独立资产家族。同一几何模板变体不能通过改文件名跨训练和测试。

## 3 受控干预及视频增强

每家族建议 3 个版本：基础 A，及从平衡干预表选出的 B、C。每个干预版本只修改一个指定因素；伴随发生的阴影、反射等渲染效应如实记录。全数据覆盖下列干预，不能所有配对都保持像素位置不变。

| 干预 | 保持条件 | 重新计算或核验 |
|---|---|---|
| 遮挡者外观或环境外观 | 目标物理身份、目标运动与几何布局 | 光照/阴影影响；几何状态应保持 |
| 遮挡者运动或前后位置 | 目标轨迹、对象身份、相机 | 可见性、遮挡者、重现时刻全部重算 |
| 相机或整体投影位置 | 同一目标表面与物理运动 | 相机投影、出画、可见性；坐标等变而非固定位置 |

物理干预不能靠给遮挡区粘一块纹理完成。每一版独立渲染，并由实际可见性赋标签。遮挡发生时间、持续时间、方向、目标外观和背景独立抽样；几何可行性筛选后还要审计它们与标签的剩余相关。

预先生成外观可辨性×运动可预测性×遮挡时长的冲突面板：包含外观相似但运动可区分、运动外推失效但外观仍可区分，以及两者都不足的情况。不能把“只靠运动”设为标准答案。若干预引发碰撞从而改变目标轨迹，记录为联合物理变化，不能继续使用保持轨迹的配对标签。

视频增强采用两层：

- 每段一致的裁剪、缩放、颜色/曝光基调与压缩设置，保持合法时间连续性；所有点、框、掩码同步变换。两增强视图的空间变换独立，防止按绝对坐标匹配。
- 按明确相机模型加入随时间变化的运动模糊、噪声和掉帧；变速/抽帧更新真实时间间隔。不得对相邻帧任意换目标纹理或逐帧独立剪贴来伪造运动。

几何可见性与图像可观察质量是不同标签。模糊影响匹配可靠性，但不把射线可见真值改成遮挡。首轮主标签使用曝光中心时刻、固定可核验的渲染设置；有运动模糊的视频作为单列扰动评价，若需要曝光期间的可见比例须另导出时间积分标签。

## 4 监督语义

对象 i 的 V_i 是全场景中最前表面属于 i 的可见区域；A_i 是相同姿态和相机下仅保留该对象的画内投影。A_i 已含自身表面的自遮挡，不是整个三维表面积。

\[
r_i=|V_i|/|A_i|,\quad H_i=A_i\setminus V_i\qquad(|A_i|>0).
\]

| 条件 | 对象标签 | 点标签及对应 |
|---|---|---|
| 对象投影存在，目标表面为最前层 | 实例可见比例有效 | 该表面点可见，有当前位置对应 |
| 对象投影存在，前层是其他对象 | 可能部分或完全外遮挡 | 外遮挡；当前无可见对应，记录遮挡者 |
| 原表面被对象自身其他表面遮住 | 实例可能仍充分可见 | 自遮挡；不把原物理点换成身体另一部位 |
| 对象 A_i 为空或点投影出画 | 对象/点分别标出画 | r_i 无效，不能写成 100% 外遮挡 |
| 网格表面无法稳定追踪 | 数据无效 | 无效原因单列，不赋“隐藏”标签 |

所有外部遮挡者具有独立实例 ID，包括墙、栏杆和其他环境对象；背景不混充某个具体遮挡者。最前层 ID 不能说明所有隐藏层的顺序。需要层间关系时由额外射线生成，不从二维重叠猜测。

查询必须在创建时实际可见；不因它未来会重现才创建查询。对长时间不重现的查询保留无对应监督。完全隐藏且从未被观察的对象可用于场景标签，但不凭其 GT 身份创建隐形查询。

## 5 非刚体表面轨迹与不确定性

每个物理表面查询记录稳定网格身份、三角面、重心坐标，以及每帧形变后顶点和相机投影。骨骼变形后使用 evaluated mesh 重建该表面，不用对象根矩阵代替变形轨迹。会改变拓扑或三角化对应的 modifier 需固定映射；不能固定时，该资产不进入点对应数据，仍可用于独立实例监督。

对严格不可辨的情况，构造“可观测等价对”：初始提示、截至决策时刻的 RGB、时间戳与其他输入完全一致，但不可见区域内的物理身份交换不同。只有学生全部输入的规范化哈希一致，才纳入严格等价集合；视觉上近似不等于严格等价。集合内按已知构造频率生成概率或集合标签，检查模型是否无依据地高置信选一边。

一般相似目标仍做正常困难样本，不由主观认定或预测低置信而排除。若严格等价构造未通过核验，保留普通样本，不把它当作证明不可辨识性的证据。

## 6 文件与数据加载边界

| 层级 | 最少字段 |
|---|---|
| 家族清单 | scene_family_id、split、资产/模板/背景家族、生成种子、事件族、所有版本、文件 SHA |
| 视频版本 | clip_id、intervention_id、改变因素、长度/fps/时间戳、RGB 路径、坐标系、相机和渲染参数 |
| 帧标签 | 实例最前层、深度、对象 A/V、完整投影及截断、独立遮挡者 ID、形变后表面映射 |
| 点轨迹 | surface_id、每帧投影/深度/可见原因、最前遮挡者、有效性、歧义组 |
| 事件 | query_id、进入遮挡/出画时刻、重现时刻、删失、事件级原因；不作为学生输入 |
| 配对 | 两侧表面和坐标、可见支持、patch 纯度、重投影误差、无效原因及独立增强映射 |
| 学生输入合同 | RGB、当前/过去时间、初始观测提示；不含 GT ID、深度、隐藏掩码、未来特征 |

data loader 分别返回 student_inputs 与 supervision；不能把同一个元数据大字典直接传进网络。物理 ID、相机真姿态、表面索引与未来事件表只在标签侧。缓存初始锚点/历史特征时记录最晚源帧，必须 ≤ 输出时刻。

## 7 已有资产可以复用到哪一步

| 现有内容 | 复用方式 | 缺项 |
|---|---|---|
| 旧骨骼资产、Blender 构场景代码 | 资产和生成器基础 | 拆分与运动需按新任务重新审计 |
| RGB、最前层实例、A/V、截断 | 复用导出逻辑和几何核验 | 新数据尺寸和版本需独立登记 |
| 旧 occluder_pixels | 标签统计参考 | 环境物共用 ID 100，不能直接满足逐遮挡者合同 |
| 对象根矩阵 | 位姿检查 | 不提供非刚体稳定表面轨迹 |
| 旧状态 GRU 与真实结果 | 前期证据、历史参照 | 不是新表征权重或新实验成绩 |
| 旧自采连续视频 | 真实域定性演示 | 无完整 ID 真值时不计算严格恢复成绩 |

本地[生成器](../../shared/dense_video_occlusion/generate.py)现有写出是 RGB 384×256、标签 192×128；尚未确认持久化稠密表面轨迹、独立遮挡者编号与成组反事实 RGB。新数据建议 RGB/几何标签同为 512×320；若为效率用低分辨率标签，必须保存完整坐标映射，不能直接索引 RGB。

## 8 拆分和最小规模

建议合同核验包为 8 个家族×3 版本×48 帧，共 1,152 帧，只用于工程核验，不能混入盲测。探索数据建议训练/验证/测试 160/40/80 家族，共 280×3×48=40,320 帧；建议 12 fps。训练含 3–12 帧短间断和 13–24 帧较长间断，同时含无重现、片尾截断和多次间断。真实时间差随变速增强更新。

先划分资产家族、模板与背景来源，再生成所有版本；同家族的帧、增强与干预不会跨 split。资产与模板同时留出属于联合域变化，不声称分别隔离了两种泛化原因。跨类别和跨渲染器若另设测试必须独立命名，同一渲染器的不同材质不能叫跨渲染器泛化。

资产家族数、每类事件可用数和实际渲染代价尚未核定，以上规模不冒充可用清单。真实测试优先采用公开标注的 TAP-Vid 和 TCOW；用现有 11 段历史留出只作已暴露研发集，不重新命名为盲测。

## 9 合同核验与停止条件

核验必须包括：V_i⊆A_i；独立射线与最前层归属一致；形变轨迹重投影误差；RGB/标签/特征坐标转换；每个标签分母与无效原因；配对确实改变指定因素；拆分交叉为零；未来输入替换不影响过去输出；点与区域状态语义一致。

建议非边界有效表面重投影误差 ≤0.5 个 RGB 像素，具体数值在实现预检后冻结；边界和抗锯齿单独统计，不能通过大面积排除边界让核验虚假通过。全部修复、筛除与生成失败保留清单。

若稳定表面映射、输入因果性或有效监督不能成立，先修对应导出/输入合同，停止正式训练；若标签有效但没有足够完整事件或各臂支持集无法匹配，修生成设计并重建未冻结版本，不能在训练后按性能挑样。合同通过仅表明可执行，不表明新表征有效。
