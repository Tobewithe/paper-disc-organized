# 遮挡表征预训练研究协议草案

版本 v0.1，2026-10-19。研究线为 `occlusion_representation_pretraining`。本草案定义候选机制、数据接口和判别设计，尚未冻结数据清单、权重、数值门槛与训练预算，未启动新 Run。[主线入口](../../paper/manuscripts/occlusion_representation_pretraining/README.md)与[Study 状态](study.json)分别提供研究范围和真实执行记录。

## 1 具体问题和主张

前期 Run `RUN_OCC_TRAIN_20261019T103219_d68f927f` 与 `RUN_OCC_EVALUATE_20261019T103747_e09ab314` 获得合成 macro-F1 0.904537，但 11 段历史留出的 FULL−C 仅 +0.262926 IDF1 点，区间下界为 0，FULL−SHUFFLE 为 −0.107516 点且区间跨 0。旧视觉骨干和下游身份特征未参与新增训练。详见[原报告](../dense_video_occlusion_transfer_20261019/REPORT.md)和[模型说明](../dense_video_occlusion_transfer_20261019/MODEL_AND_NOVELTY.md)。

这些事实未把失败归因于唯一原因，但表明标量状态学习的成功未充分转化为任务效用。新主张不从旧配置失败直接推出，其正面依据是可控三维对应监督、对比表征学习和物理因素控制的已有研究基础，出处见[SOURCE_EVIDENCE](SOURCE_EVIDENCE.json)。

**H：**按可靠可见性选择跨遮挡的物理对应，并联合监督应随遮挡变化的对象关系，可以减少内容表征对遮挡物的依赖，同时保留必要空间信息，从而提高未见场景的表征质量和跨任务迁移。

**H_alt1：**收益主要来自更多图像、预训练底座或额外优化，同预算普通表征学习即可达到相同效果。预测是匹配预算后差异不达到预设效用要求，或移除物理干预仍保留同等收益。

**H_alt2：**表征可能改善，但真实任务仍受检测覆盖、输入不可辨识性或域差异限制。预测是独立对应指标改善而下游没有实用增量；此时只保留有证据的表征结论，不宣称解决身份恢复。

## 2 模型及可用输入

候选共享编码器以 DINOv3 初始化，首轮考察可训练适配层，输出空间特征 F；内容投影 z=g(F) 用于对应学习，对象关系读出 r=h(F,q_i,q_j) 用于监督。参数尺度、适配位置、读出容量、权重 SHA 与依赖需在执行前选定并冻结。所有对照使用相同初始化与可训练白名单。

对象查询来自当前或过去可见观测的点、框或区域特征。训练可按 GT 选择监督对象，但模型不能接收资产 ID、隐藏轮廓或三维真坐标作为隐蔽输入。测试使用部署可得查询；GT 提示条件下的能力评价必须另列，不能冒充自动检测结果。

主线学习对象是下游复用的 F 及其适配层。仅在投影头变好、F 冻结探针不改善的结果不能解释为通用表征提升。第一版空间输入不依赖历史；后续视频分支采用当前与过去，单独冻结延迟与历史窗口。

## 3 数据干预和损失

数据来自同一场景状态的成对渲染：固定目标形态、姿态、相机与时间，只改变遮挡者；另构造几何关系不变的材质、光照、背景变体，以及真实前后关系改变的对照。后者需重新计算标签，不能沿用旧关系。改变遮挡物造成阴影和反射变化时，记录变化来源，不假设 RGB 其余区域严格不变。

详细可见性语义、支持集和导出缺项见[数据合同](DATA_CONTRACT_DRAFT.md)。配对数据与普通表征对照使用同一拆分；不把同场景干预版本分到训练和测试。

### 3.1 对应表征目标

设 p 为同一网格物理表面区域，π_a(p)、π_b(p) 为两个渲染版本的投影。Ω 只包含在两版均可见、几何对应可靠且特征采样区域没有混合其他对象的点。设 z_p^a 为对应位置归一化内容特征，N(p) 是可区分的错误对应：

\[
\mathcal L_{\mathrm{rep}}=-\frac{1}{|\Omega|}\sum_{p\in\Omega}
\log\frac{\exp(\operatorname{sim}(z_p^a,z_p^b)/\tau)}
{\exp(\operatorname{sim}(z_p^a,z_p^b)/\tau)+\sum_{q\in\mathcal N(p)}\exp(\operatorname{sim}(z_p^a,z_q^b)/\tau)}.
\]

此处采用既有 InfoNCE 类对比形式，不宣称公式首创。重复纹理、对称区域和相邻同一表面不得未经核验就作为硬负例；需要排除或采用事先规定的多正例集合。候选、特征分辨率、纯度规则、温度、正负例数量和双向归约均在执行协议冻结。

Ω 为空的样本标记无有效对应，分母如实记录；不得通过预测置信度把困难样本权重全部降为零。完全隐藏且从未观测的点不进入当前图像确定性对应目标。跨帧非刚体对应要使用形变表面，不以根矩阵代替。

### 3.2 遮挡关系目标

定义 y_{i←j}=1 表示视角内对象 i 的完整投影中，存在由 j 占据最前可见层的外部遮挡区域。接触误差、最小面积阈值和无效几何必须先冻结；遮挡关系为有向关系，不强制 y_{i←j} 与 y_{j←i} 互补，非凸对象可能在不同区域互挡。完全不可辨的样本不能被当作确定性空间关系能力证据。

对有有效可见查询的对象关系采用二元交叉熵 L_rel；负例包括接近但不重叠、仅出画、仅模糊等，标签由几何真值确认。关系损失作用于共享空间特征，内容一致性只约束内容投影，避免强迫整幅遮挡图和完整图的全部特征相同。

\[
\mathcal L=\mathcal L_{\mathrm{rep}}+\lambda\mathcal L_{\mathrm{rel}}.
\]

λ 仅由独立训练内验证集确定，不用真实测试选权重。本版不叠加身份分类、完整外观生成和多项时序损失。不确定性不能直接以遮挡比例监督；如后续纳入概率状态预测，需新版本定义评分与校准目标。

## 4 必要参照与机制干预

| 比较 | 共同条件与差异 | 可支持的结论 |
|---|---|---|
| 未适配底座 N | 同初始化的原始编码器；下游采用同探针预算 | 本方案相对原生表征的总效用，包含新增训练影响 |
| 普通对应训练 B | 与候选同编码器、适配层、关系头、输入图像与 L_rel；内容正对来自同一渲染版本的普通可逆增强，对应有效，避免故意使用错误标签 | 相对同容量、同训练预算的普通表征目标的新增效用 |
| 物理干预对应 P | 与 B 相同模型和 RGB 暴露，内容正对改用不同遮挡版本的可靠物理对应 | 物理配对和支持集这一组合设计的效用；不能单独归因于公式形式 |
| 可见性限制消融 U | 保持 P 配对，移除两版共同可见筛选 | 识别错误监督的影响；此臂可能引入错误目标，不能单独用于证明机制优于成熟方法 |

B/P 使用相同图像批次、同次数特征前向和更新；正对数量、面积/难度分层、负例数量及梯度归约匹配。若因共同可见支持集无法匹配，登记覆盖差异并收窄归因，不偷偷增加 P 的数据或训练预算。额外的物理监督本身属于设计的一部分，不能声称独立排除了监督信息增加。

采用同一 checkpoint 的受控输入干预，检验更换遮挡物时的对应质量、外观变体下的关系稳定性，以及前后改变时的关系响应；同时保留未遮挡目标的区分能力。必要时比较适配增量归零及同范数错配，单凭删除模块后掉分不构成独立机制证明。避免只用特征距离下降作为成功，因为常量特征也可能满足不变性。

## 5 主读数和下游验证

第一阶段主读数采用未见资产和场景上的冻结表征局部对应正确率：固定候选集合，按物理对应及预设投影误差容忍范围计分，先按场景归约，再报告场景宏平均和配对场景区间。对应支持集依据 GT 独立固定，对所有方法相同，不允许模型选择评价对象。具体容忍值、最小效应与样本数量在执行前冻结。

必要护栏为：无遮挡下的区分/对应能力、关系方向预测，以及没有有效查询或有效对应的覆盖率。按反事实场景家族成簇统计，不把相关像素或相邻帧当独立样本。

迁移阶段使用同一预训练 checkpoint，分别对静态实例分割和视频对应做同预算读出。冻结编码器的结果与端到端微调结果分开。后续 YOLO 迁移与完整身份恢复单列实验，保持候选和评价配置公平；不把真实检测缺失误归为关联失误。

跨资产、跨场景、跨类别及真实域分别报告，不能用同一渲染器的新资产成绩代表全部泛化。真实评价集、既有对照和任务主指标必须先锁定；本草案不以重命名历史留出集创造盲测。

## 6 决策出口

| 结果 | 决策 |
|---|---|
| P 相对 N 与 B 达到预设实用增量、区间支持且护栏通过；受控干预符合 H | 保留该机制，在同一 checkpoint 上进行跨任务迁移验证；仍不自动扩大预训练 |
| P 优于 N，但未超过 B 或机制干预不符合预测 | 保留普通适配收益，关闭当前物理对应设计的新增机制主张，不换名字继续加训 |
| 对应质量提高但迁移无实用增量 | 收窄为表征能力结论，停止通用任务效用主张；依据固定错误分解选择后续任务，而不直接追加跟踪规则 |
| 估计精度不足 | 仅在预冻结最大预算内补齐约定样本；达到上限后登记未决，不以训练更多或改阈值追阳性 |
| 标签对应、输入泄漏或容量/预算核验失败 | 记为无效/工程问题，先修合同；不把工程失败解释为科学阴性 |
