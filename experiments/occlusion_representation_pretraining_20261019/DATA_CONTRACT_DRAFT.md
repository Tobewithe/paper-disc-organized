# 遮挡表征训练数据合同草案

版本 v0.1，2026-10-19。数据来源为已有自建三维场景及后续程序化导出；本文件定义语义和核验要求，不宣称成对训练数据已经生成。来源文件快照见[SOURCE_EVIDENCE](SOURCE_EVIDENCE.json)，方法使用方式见[协议草案](PROTOCOL_DRAFT.md)。

## 1 可复用项和导出缺项

本次只读检查了[现有生成器](../../shared/dense_video_occlusion/generate.py)的实际写出路径。

| 监督项 | 当前可复用程度 | 新合同要求 |
|---|---|---|
| RGB、实例最前层 `instance_id` | 已有生成实现和既有 Run 证据 | 清单关联原始文件 SHA，保留分辨率和色彩处理 |
| 单目标完整投影 `amodal_i`、可见比例、截断、可见框 | 已有 | 固定定义；不把出画算作完全遮挡 |
| `occluder_pixels` | 已有按最前层实例 ID 汇总 | 环境遮挡物当前共用 ID 100，背景/其他为 0；不能直接声称逐遮挡物身份完备 |
| 相机和对象根节点矩阵 | 已有 | 可做定位核验，不能单独提供骨骼形变的跨帧对应 |
| 同场景成对遮挡 RGB 和干预清单 | 当前写出路径未确认存在 | 自动补渲染，所有干预共享目标状态与可追溯场景种子 |
| 表面索引、重心坐标和变形后对应 | 当前未持久导出 | 需要 mesh/triangle 或稳定表面 ID、重心坐标、对应有效标记 |
| 深度和完整运动字段 | 当前未持久导出 | 按核验需求增加，不能以规划字段冒充已有数据 |

现有 RGB 为 384×256、标签为 192×128。任何新尺寸需显式登记坐标变换与采样方式；不把标签像素直接索引 RGB 或特征图。已有四状态使用的阈值属于旧协议，新表征支持集按几何可见性与特征纯度定义，不隐式继承旧分类阈值。

## 2 几何语义

- V_i：全场景渲染时，最前可见表面属于对象 i 的区域。
- A_i：相同姿态与相机下，只保留对象 i 时在图像内的投影。它包含对象自身的自遮挡效果，不是整个三维表面积。
- H_i=A_i\\V_i：被其他物体遮挡的投影区域。
- 当 |A_i|>0，外部遮挡比例为 1−|V_i|/|A_i|。|A_i|=0 时为出画/无画面内投影，比例记无效，不记 100% 遮挡。
- 画外截断由扩大投影区域单独计算；模糊、低分辨率和照明不改变几何可见标签。
- `y_{i←j}` 的可见遮挡者是 H_i 中的最前层 j；它不代表每条光线上所有隐藏层。若研究全层关系，另加逐层射线标签。

## 3 配对单位与最少字段

每个 `pair_group` 记录 `scene_family_id`、资产来源/家族、时间或状态 ID、相机、场景种子和 `split`。同一组的任何帧、渲染版本和增广继承同一拆分。

每个渲染版本记录 `view_id`、干预类型、改变对象及参数、RGB/标签 SHA、渲染设置、几何版本、坐标约定和有效查询来源。物理 ID 只用于构造监督与检查拆分，不成为网络输入。

每条表面对应至少包含：稳定表面身份、两个投影位置、两边的深度/可见标记、归属、特征采样纯度、重投影残差、有效/无效原因。相邻相似纹理与对称多解记录为歧义集合，不能仅因几何 ID 不同就强行当负例。

第一版可从同相机同姿态的遮挡干预开始，再拓展多视角和非刚体跨帧。拓展不改变已有冻结测试；新增变体需新数据版本。

## 4 反事实与混淆样本

1. 固定目标和相机，只改变遮挡者：用于双可见区域的内容对应。
2. 固定几何，改变材质、光照、背景：用于关系稳定性，内容颜色本身不强制不变。
3. 改变前后关系：重新渲染并重算关系，验证响应方向。
4. 接近但未遮挡、姿态变化、仅出画、仅模糊：检查模型是否把所有难观察情况都当遮挡。
5. 完全隐藏且无历史信息：保留为观测边界，不施加唯一隐藏内容的确定性对应目标。

样本是否发生遮挡由真实几何决定，不根据配置名称赋标签。材质和对象改变后若几何关系也改变，不能保留“关系不变”的配对标签。

## 5 核验与拆分

导出核验要求 V_i⊆A_i；单点最前层归属与独立射线计算一致；稳定表面投影一致；关系变化与干预一致；RGB/标签/特征采样尺度一致。薄边界、抗锯齿与混合 patch 使用固定纯度规则，并公布因此排除的比例。

在资产/场景家族划分后再生成干预版本。划分资产、背景、场景模板与相机配置的留出范围，分别定义跨资产、跨场景与真实域测试。不得用相邻帧随机拆分制造泛化成绩。

训练和推理依赖分离：GT 可生成标签和选择训练查询；推理只读取可用 RGB、观测提示及允许的过去信息。任何 GT 提示评价标记为条件能力评价，独立于正常部署效用。

本线合成监督全部由场景自动产生。真实迁移优先使用可核验的公开标注；既有自采无 ID 视频用于定性展示，不替代真实定量金标准。
