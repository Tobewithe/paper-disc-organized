# h到oracle修正的近邻检验

使用 `coefficient_predictability_20260924` 的固定200个val2017 oracle实例。原型、原系数、官方one2one身份和预测框都固定。对于每实例计算64维末层系数特征h、系数改动`c*−c0`，以及在原预测框归一化16x16网格上的logit变化`P(x)(c*−c0)`。后一表示刻画实际空间响应，不把原型基底中的系数欧氏方向直接等同于掩码方向。

每实例在不同图像、同一P3/P4/P5尺度且GT面积相差不超过2倍的池中找h最近邻；与从相同池随机抽样的候选比较空间修正余弦，同时记录h距离、oracle BCE gap及COCO类别。样本池不足时如实记录、排除；不为凑数放宽匹配。另在有足够同类候选的子集内重复。若h最近邻的空间修正并不比面积/尺度匹配随机候选更相似，才是“h映射歧义”的探索性线索；若显著更相似，则直接削弱该假设。

oracle只在200个平衡抽样实例上计算，近邻是观测关联而非严格因果识别。描述的修正是在各自预测框局部坐标对齐，不比较不同图片的全图位置。此检验不能独立证明共享参数梯度冲突或一定需要改网络。
