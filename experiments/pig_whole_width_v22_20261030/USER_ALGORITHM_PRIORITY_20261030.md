# 用户最新约束：保存和完善生成算法，固定资产仅作验收样例

用户原话：“记住调整的算法而不是记住固定资产，资产固定了的话不是随机的就很难泛化可能”。本条是对完整合成数据目标的执行优先级补充，不撤销原始MAMMAL作为基础表示，也不要求删除已有失败/验收产物。

正式生成入口必须围绕**种子/语义条件 → 参数采样 → 从原始网格与骨架程序化构造 → 物理/几何约束 → 渲染和同像素标签 → 最终RGB及覆盖验收**。保存算法版本、采样范围与分布、依赖/拒绝规则、种子/配方和回放入口。固定候选mesh、缓存接触对、有限姿态样例只能证明某些边界或用于回归/复现，不能代替可变化的生成器，也不能把随机选择几个资产ID说成已解决形状随机化。

各字段分清：能连续采样、只能有限类别、当前无生成能力。形状、关节/姿态、布局、接触、设施、材质与成像要按能力逐步开放参数和联合约束；不支持不能随机乱写。基础提案可以按独立key随机，但物理和语义约束后的接受分布有条件依赖，必须登记提案/拒绝/通过量，不能冒称真实自然频率。

V22两个宽度stand是算法边界的实际审核样例；其离散compiler bridge仅为历史资格阶段，后续改为输入连续width参数并从原始MAMMAL rest/J/骨架即时构造。不由两个端点通过自动推断任意中间pose/contact成立：能数学证明的几何性质明确证明，其余逐样本核验和实际RGB审核。新width不继承旧缓存接触解。原自然姿态/身体部位、真实外观、标签/覆盖/失败账本与首个合格冻结数据版本目标保持，不因算法预检通过提前宣称泛化或目标完成。
