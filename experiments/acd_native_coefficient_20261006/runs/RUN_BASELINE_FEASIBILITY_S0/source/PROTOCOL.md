# ACD native coefficient feasibility protocol

The baseline and method start from the same official COCO-pretrained YOLO26m-seg checkpoint and use Ultralytics 8.4.100. Both arms train only the native `cv4` and `one2one_cv4` mask-coefficient heads. Prototype, backbone, neck, box and class heads are frozen. Every BatchNorm module stays in evaluation mode, with affine parameters and running statistics frozen.

During training only, the current assigned positive mask logits are compared with a fixed tightening action `logit - tau`. If the action improves the GT IoU and the original mask has sufficient target coverage, an auxiliary false-positive suppression term is applied on background pixels inside the assigned GT support box. Ground truth is not used at inference. The action term is applied inside both official loss branches through `v8SegmentationLoss.loss`.

The first run is a one-seed short feasibility screen. It is not a final AP result. The continuation gate is: finite loss, baseline parity, method Mask AP at least 0.3 percentage points above baseline after 3 epochs, AP75/APsmall not both decreasing, and no material damage to baseline-success instances. If the gate fails, retain the run as a negative training-transfer result and do not tune the action loss.
