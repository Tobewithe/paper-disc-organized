# 原型响应投影修正：2026-09-23 两轮筛查结果

结论：本次间接投影与直接训练的投影头均未在选定的 val2017 失败图像上稳定超过普通系数修正。该具体方法暂停扩大训练；不能据此否定“可表示性与可预测性存在差距”。后续按用户指定路线在 `../coefficient_predictability_20260924/` 直接比较原系数头的 h 与 h,P 条件。

## 实验范围

200张val图，从包含“小、低填充率、raw有Box75但无Mask75”的1,080张图片中固定抽样；其中367个预选失败GT。整体AP仅是此富集子集的COCOeval，不是全量COCO AP。GT不进入修正推理。

原模型输出候选/分数/框/原型固定。原型组合和原图解码的重算基线，与旧缓存37,693条原有预测RLE全部一致；重算只多3个分数≤.001549的极小候选，AP与Mask75 GT匹配集合不变。各新方法与同次重算基线比较。

## 决策

这些结果支持保留“修复与误伤要配对评价”的设计，但目前不支持把该投影结构作为主方法。前述普通系数头已读取原型ROI，并非h-only对照，因此尚未完成用户新主线要求的 h→c 对 h,P→c 实验。

2026-09-24补充：库中原生ROI MaskIoU<.75的候选8,241/17,688（46.59%），不能简单宣称训练失败样本极少。后续追共享预测器输入与原型信息的关系，保留本记录作为负结果。
