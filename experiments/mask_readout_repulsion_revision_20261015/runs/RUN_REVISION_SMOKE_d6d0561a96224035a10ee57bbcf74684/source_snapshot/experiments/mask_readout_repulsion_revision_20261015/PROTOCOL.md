# 实验一修订：前景冲突与空间约束排斥

2026-10-15。用户要求“实验一先搞好再说”，本协议新建 E1-R2，替代当前转向实验二的执行路由。E1-R1-v1 的原协议和失败 Run 完整保留。本次只在已授权笔记本 YANGLEI 使用现有原生缓存做零训练评价；实验二、三、四及 S3 暂缓。

## 主张、对照与裁决

旧 Run `RUN_REPULSION_FULL_8b2e19a348d1476fbf05b64aabb10c7f` 正确实现了旧公式，但三项 S2 Gate 失败。signed-logit 正相关可以来自共同负背景；沿邻居系数相减会改变整个输出的响应。这两项是公式的可验证性质，尚不能据此断言它们解释了全部损伤。

H1：排斥应作用于双方实际预测为前景且邻居响应更强的区域，并在求系数时拟合“冲突区压低、其它框内区域保持”这一空间目标。H0：即使排除负背景、降低全框扰动，较高检测 score / 较强局部 logit 仍不足以决定像素归属，排斥会删除目标真前景。两项有区别的预测是：A 相对旧方法是否改善；B 相对 A 是否降低框内非冲突区域响应扰动、固定输出假阳性/假阴性和最终任务损伤。后者的工程目标下降不等于 IoU 上升。

预注册两个版本，均执行完整原 S2 分母，不按结果增加版本或调整参数：

- A：`E1-R2-A-FG`，仅将旧排斥区域替换为前景冲突区域，仍沿原生邻居系数做秩一相减。这是冲突定义的对照；区域替换同时改变是否触发与 alpha，不能解释成只改变行级 gate。
- B：`E1-R2-B-LOCAL`，与 A 相同邻居、区域、alpha，改用整框正则最小二乘拟合局部排斥目标。这是唯一主候选；不将 B-A 差异再拆称分别识别了正则化和空间拟合效应。

主候选 B 三项门槛均通过则列为 E1 的全量效用候选。B 未过而 A 全过，保留 A 为候选并明确 B 的额外约束无效；选择次序 B 优先是预先规定。两个版本均未过，则停止继续投入本次“用高优先级邻居确定归属的解析排斥”方向，不再扫描 alpha/lambda/区域阈值。下一方向优先回到已有面积门控正证据支持的选择性系数修复；不自动启动实验二或 S3。配置/重放/数值核验失败则只判工程阻断，不裁决科研假说。

## 固定方法

从原生 c0 出发；P、F、网络权重、框、类、score、排序、raw_id 和 output_detection_id 均不变。方法端不读取 GT、旧实验效果或成功面板。

邻居选择和几何 Ω 完全继承 E1-R1-v1：同图同类别、不同 raw、按 (-未舍入原生 score, rank) 更优先、BoxIoU>0.1，选择最高 IoU，平分按 score/rank；Ω 为框交集内、目标中心半宽半高核心区外、严格更靠近邻居中心的 proto 格点。仍为独立逐目标 Top-1，多目标可共用同一邻居；所有邻居响应来自原生 c0，同时更新。

实际格点为 x*input_w/proto_w、y*input_h/proto_h；左上包含、右下不含。令 zi=Pᵀci、zj=Pᵀcj，定义 Ω+=Ω∩{zi>0}∩{zj>zi}。至少 4 个格点才触发；无效行原系数逐位不变。这里 zi>0 且 zj>zi 已蕴含 zj>0。它只是无 GT 冲突代理，不是真实遮挡归属。

alpha=mean(zi*zj | Ω+) / [mean(zj² | Ω+)+1e-8]。沿用数值安全条件 mean(zj²)>1e-8、mean(zi*zj)>0，否则不触发。Ω+ 中 0<zi<zj，故精确算术下 0<alpha<1，不需要事后截断。

A：cA=ci-alpha*cj，强度固定 1，不再归一化范数。

B：取目标预测框内实际 proto 格点集合 Bi，目标响应变化 tq=-alpha*zj(q)（q∈Ω+），其余 Bi 内 tq=0。最小化

`J(delta)=mean_Bi[(Pqᵀ delta-tq)^2]+lambda*||delta||²`。

`G=mean_Bi(Pq Pqᵀ)`；`b=mean_Bi(Pq*tq)`；`lambda=max(1e-8, 0.01*trace(G)/K)`，K 为实际原型通道数（真实缓存应为32）。`delta=(G+lambda*I)^(-1)b`，`cB=ci+delta`，不迭代优化、不训练。使用 FP32 torch.linalg.solve，不显式求逆。0.01 为运行前固定的相对对角正则，限制病态方向；不声称是最优值。无额外步长、范数裁剪、面积门控或 adapter。

B 的数学保证仅是上述正则目标的全局最小解；J(B)≤J(A) 和 J(B)≤J(0) 在数值容差内检查。框外没有该惩罚，框内也不是硬约束；插值和二值化后仍可能损伤。逆 Gram 不保证与背景正交、零损伤或置信下界过零。

所有有效解有限，归一化 normal-equation 残差≤5e-5；目标不等式容差为 `5e-5*(1+J(reference))`。违反即工程停止。保存每行门控、原生系数、A/B系数、alpha、正则、残差、目标、框内非冲突区响应 RMS、proto 正负翻转计数；不据这些诊断筛选输出。
