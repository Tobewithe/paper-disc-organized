# 对象原型到真实可见分割：结果导向小预算试验 v1

2026-10-23。用户在讨论“内部编码不影响最终结果就先不管”及真实对象对齐/小预算分割验证后明确回复“试试”。本协议登记该后继试验；不重判对象v0，不追加v0的体形码稳定性优化。

## 主张、依据与范围

已有对象v0在288条遮挡输入、8个留出形变族上相对同容量自由模型减少46.67%完整身体误差，跨视角完整轮廓IoU为0.89934。其体形码稳定性Gate失败保留。真实前驱V4.1中全局字典仅比原生增加0.0417个Mask AP点，实例均值在305条失败仅修复2条。当前优先主张H：把已训练的完整身体几何/表面特征对齐到每条真实预测，能够给可见Mask修正提供普通局部图像特征以外的空间约束。H_alt：普通残差容量与真实Mask监督即可解释收益，身体特征的空间关系没有增量。

这是有限候选对齐与后训练接口的实用初筛。v0依赖已知合成相机；真实相机未标定。本试验不把真实裁剪伪装为有GT相机的v0输入，不声称估计出真实三维姿态。由冻结v0模型从432张合成train干净观察产生预测身体及表面特征，经对应已知相机投影，再做8个平面旋转和镜像，形成有限候选。候选身体投影按其前景外接框归一化到ROI；对真实正常预测框，以原生预测Mask和候选轮廓的16×16 IoU选单一候选。该对齐是像平面代理，允许非等比框归一化；目标是检验其对可见实例Mask的作用，不将它当真实3D重建。**不读取任何真实GT来选择候选、框或应用策略。**

## 输入、对照及白名单（M1–M4）

- 固定已验收continued原生模型及Ultralytics8.4.100、640画布、FP32、O2O、conf>.001、head max_det300。Box/Class/score/检测顺序、原生P/c全部冻结；只增加实例ROI掩码logit残差。先保留原生非空Mask对应的检测行，所有方法使用完全相同的行身份；修正后为空也不静默删行。
- 真实数据沿用1272train/432dev；test不读。全量验证真实图和标签SHA，群组不跨train/dev。可见实例RLE保持原标签，不给遮挡区域伪造完整GT。
- 共同输入：RGB ROI、原生logit、冻结P2/P3的固定随机投影8通道、ROI坐标。对象输入为1通道完整身体轮廓、3通道标准身体坐标、8通道已训练表面特征的固定随机投影。投影随机矩阵固定，不从dev拟合。
- S结构分支：使用对齐后的身体地图。Q同容量受限分支：同样候选与通道，对每个ROI执行固定像素置乱，破坏空间身体布局但保留每通道数值与分布。二者完全相同的有效参数、初始化、样本顺序、监督、优化步数；全部参数需在smoke中有有限且累计非零梯度。Q不是独立无先验模型，因此S−Q仅检验空间布局的增量；原生N是无新增分支的部署参照，不具有相同新增优化预算。
- 仅新增ROI残差CNN可训练，输出初始严格为0，残差上限为4个logit。YOLO及对象模型/候选库/随机投影均冻结。输出残差投回原生160×160网格，沿用原裁框、640双线性上采样和>0阈值，零残差须逐像素重放原生Mask。
- 应用策略仅依据正常预测：score≥.05且框两边≥8像素；其他检测原样。train使用同策略得到的全部对象，无每图永久截断。train-only的GT关联为每检测取最大BoxIoU，≥.5使用对应可见Mask，否则为全背景；它不是TAL也不进入推理。正/负轮转3:1，记录每行曝光。BCE+softDice+0.01残差L2，配置不扫参。
- 同一S固定末步额外评价：关闭对象地图、固定空间置乱对象地图。它们只改变对象输入，RGB/原生特征和残差CNN保留。删除后的退化只能结合重训练Q判读，不能单独证明结构机制。

## 评价、预算与预冻结出口

先用8步/臂工程smoke验证零残差逐像素一致、白名单、有效梯度、候选选择不依赖GT、参数/初始化匹配和实际解码。工程检查点丢弃。原生完整432dev AP须重现57.3152728260±0.00001pp，失败即工程停止、不训练正式模型。

正式S/Q各4000步、batch64、AdamW3e-4、weight_decay1e-4、固定末步，无dev选模。最多1张A6000，通过一次性Slurm；工程≤15分钟，正式含缓存/训练/评价≤105分钟，累计≤120GPU分钟。资源不足或数据/版本/哈希不符不换环境/样本。无续训、网格、多seed、定时器。

唯一主指标为完整432dev、同检测集合的COCO segm AP@[.50:.95]，单位为绝对百分点。与前驱一致：segm评估去掉bbox以使用RLE面积，bbox评估单独使用框；这是本线既有共同配置，不冒称官网native parity。报告AP75、小目标AP、原成功GT Mask75损伤和耗时，作为输出风险说明，不再为潜码建立硬Gate。GT匹配bbox/segm独立，不混用。

预冻结裁决：

1. S−N>0且S−Q>0：本开发集初筛双正收益，优先规划冻结模型在保留test的配对确认。若同S删/乱地图不降低AP，报告接口未显示原型依赖，不宣称机制成立。test确认不在本轮自动执行。
2. S−N>0但S≤Q：收益有实用价值但没有身体布局增量，优先采用较简单局部修正方向，关闭本配置对象接口扩训。
3. S≤N：本配置没有兑现真实分割正收益，关闭扩训；根据N/Q/S共同结果选定局部图像读出或真实对象对齐的具体瓶颈，不改loss/阈值续跑。
4. 输入、身份、梯度、parity或完整性错误：工程无效，保留失败；只修对应工程项，另开真实Run。资源中止记不完整，不作效用结论。

这是开发初筛，正点估计不冒充显著性或独立确认。不因正收益就称+5目标完成；+5按S相对同配置最强原生的绝对Mask AP差验收。v0潜码Gate和旧原始DECISION不改。本协议取代v0后继“潜码/几何漂移独立诊断”作为当前动作，后者不再是进入本轮的前置。
