# Experiment 7Q：有限 oracle 像素 logit 修正的可预测性

## 目标与研究对象
冻结官方 COCO 预训练 YOLO26m-seg、Ultralytics 8.4.100、原型、原框与分数。沿用 7D 的 λ=0.003 唯一有限目标 d*=c*−c0，比较预测 d 与直接预测 Δz*=P d。已有系数唯一性不作为新假设；7O 阴性结果不等于排除归属信息。

本实验是官方 one-to-one GT 条件正样本的表征诊断，候选选择使用 GT，但预测器输入不含 GT；不是完整推理 COCO AP，也不证明任意候选的部署性能。

## 数据（在本实验结果产生前确定）
复用 7L 10000 train2017 fit 图及按图像完全分离的 200 train2017 dev 图；测试复用 7L 2000 val2017 图。后者已被先前实验分析过，明确属于探索性复用测试集，不称新盲测。不得以 test 选 epoch、修正幅度、阈值或增加有利分组。原来的 200 图 val 不进入本实验。
训练 oracle 复用 7L 的收敛目标，开发集复用 7E λ=.003 目标；测试目标按同目标重新求解，不作为输入或选模依据。
fit/dev/test 以 image_id、annotation_id、raw_id 绑定；旧缓存全 raw 数组与已筛选数组分开处理。用 FP32 原权重重放训练/测试原型，核对 h/c 缓存一致性。

## 模型与实验臂
预测框在原生 160×160 prototype 图上 floor/ceil crop，然后面积平均至 16×16。目标 A_i d_i*（A_i 为该 ROI 的 256×32 矩阵）。
五种输入：h；h+原始 ROI logit；h+真实 local P；h+同图错实例 local P；h+错图 local P。
错配只替换输入，不替换用于目标和解码的本实例原型。按预测层级与框面积近似匹配，跨图严格不同 image；同图没有其它候选时回退跨图并计数。不得用 GT 质量筛选 donor。
每种输入比较 coefficient 输出32维与 spatial-logit 输出16×16。两者共同使用功能空间标准化平方误差加0.25方向损失，保持训练样本、批次、优化器和选模规则一致。容量控制在2%以内，报告实际参数量。不是将旧模型不同 loss 的结果当作直接对照。
AdamW lr=.001 wd=.0001，batch=256，至多40epoch，dev loss patience8，包含零修正初始模型。seed=0、1，每个臂/seed 独立Run。主比较先固定 h 的空间/系数差、真实P的空间/系数差，以及真实P空间对 h空间/两种错配空间；不扫超参数。

## 解码与投影
空间输出16×16双线性还原到同一原生预测框 ROI，加到原 logit 后使用相同官方 crop/upsample/scale 流程。
同时将空间修正投影回本实例固定原型在预测支持内可表达的空间：double 精度 Gram 特征分解，截断奇异值相对阈值1e-5（Gram阈值1e-10），由最小范数系数解码。该过程完全不使用GT。
报告投影残差、数值秩及系数范数；同时将 oracle 的16格（实际16×16）表示按相同路径还原/投影，量化降采样导致的恢复上限变化。不能把扩大输出空间的改善直接归因于系数方向更可预测。
正则 oracle 保持原官方 GT-box BCE 定义；评估支持为固定预测框。训练标签沿用官方 overlap-mask，最终原图 IoU 用 COCO 原 annotation 的 annToMask，二者不混称。

## 评价与判定
主方向指标：预测框内原生像素的 cos(Δz_hat,P d*)；辅报16×16目标余弦与标准化误差。
下游：原始 COCO 尺寸 Mask IoU、Mask75净变化/repair/damage；原生 prototype 网格预测框内 AUC（明确报告 GT 栅格化口径）；覆盖率与FPR作辅助。
全体、原Mask75失败、失败且BoxIoU≥.75、原成功组全部报告。每图整组配对bootstrap2000次，区间与seed间方向同时展示；多主比较用Holm校正，探索性分组不包装为独立确认。
只有空间目标在未参与训练图上提高方向且改善mask、并优于同条件系数头，才支持所测参数化/学习路径差异；投影后仍保留收益才支持固定原型内可实现。
真实P优于两类错配才支持实例对应原型提供增量信息。阴性结论只限定当前输入、容量、数据、损失及两seed，不能证明信息不存在或任何函数都不可预测。

## 完成边界
协议、脚本、数据身份、独立Run与失败日志、逐候选指标、聚类统计和结果解释回传主项目。只做此项诊断及结果所需数值审计，不自动追加全网络训练、loss扫描或更大特征搜索。
