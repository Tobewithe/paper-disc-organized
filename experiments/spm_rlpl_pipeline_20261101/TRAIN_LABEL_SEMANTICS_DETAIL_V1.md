# 既有训练标签的定点监督语义复核 V1

936的13组预览已经实际查看。gallery及原尺寸train id11显示较大实例重叠，id12显示设施区域被轮廓填入；不能仅凭缩略合图把它们归为细边噪声。因此固定复核这两个已抽中的train样例，不追加选图、不读取dev/test、混合源COCO或新数据。

读取同一932 train-only manifest中id11/12的原160独立loss masks、原640 owner/overlap和RGB；核SHA。逐实例输出原分辨率叠图与局部原图/Mask对照，以及实际160监督上的每对交集及占较小Mask比例。只核监督语义，不加载神经模型、不改标签、不将图/GT/统计传给生成器。

- 若重叠只来自合图显示且独立训练Mask实际符合可见轮廓，保留原native loss与V1正常合成监督。
- 若独立训练Mask明确填入较大片被其它实例/设施遮挡区域，则**不通过“真实与严格可见合成GT直接同口径”的准入**；不以“所有臂都有”抹平问题，不启动当前B/C/D。保留RLPL核心，优先提出真实GT正常分割监督、合成仅供共视对应辅助的显式V2，而不是据真实GT修改生成配方/标签或恢复后置修补。该改法需单独登记比较口径与正式合同，不能静默当成原B/C/D已执行。
- 若证据仍不能区分，则保持语义资格未决，不把未知写成通过；不追加泛化性能训练来代替这一必要条件。

0GPU/2CPU/8GiB/≤3min，一次有限读取，最多2次明确工程重试。读到的是真实train标签，不能记成“全流程真实GT读取0”。本动作不开放200组生产或正式训练。
