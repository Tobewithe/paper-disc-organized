# RLPL监督路由修订V2：真实任务监督，合成仅供可见对应

**状态：Agent选定的前瞻修订；不是已冻结完整训练合同，不代表开训。** 依据用户已委托完整有限流程、补实现细节及“开始正式的训练”，在相同RLPL核心命题、三臂各2000更新目标、设备和测试封存边界内，明确登记监督/对照口径修订。旧候选正文、设计Study、工程Run与数值Gate不回改；原“直接混用真实与严格可见合成Mask作同口径监督”的未执行配置关闭。本文是该候选监督默认的`superseded_by`，不是旧Run的重判。

## 1. 证据与取舍

[语义报告](TRAINING_REQUEST_REPORT.md)中的936/940表明：真实原训练目标不是严格互斥可见表面标签。train id11两份独立160×160监督Mask交集113像素，占较小Mask231像素的48.9177%；id12三个实例的真实监督跨越栏杆/管道。不能把这个观察扩大为全1272图都是amodal，也没有测定其引起的AP损伤；但不能再宣布原“同口径”必要条件已满足。已有Blender回放也显示设施标注口径会改变效用读数。

**主张：保留训练期原型学习，但将分割目标锚定于原真实train标注，合成几何只提供可见局部对应。** 相比重画真实GT、模仿真实粗标注修改生成器、追加一个学习式修补器或设计多套不确定区域loss，这一调整不新增模块/loss，不要求未知域像素替代真值，也保留了最关键的D对同信息连续C的检验。它只是优先验证的修正方案，未证明真实效用为正。

## 2. 三臂定义（新版本，不能与旧B混称）

共同输入仍为每步2 real + 两个合成几何组的A/B/C共6图，预生成同日程；三臂每步均走同一个8图原生训练前向，Mask专属BN设置相同。

| 臂 | 正常分割目标 | 合成的作用 |
|---|---|---|
| B2 | 仅前2张real的原GT，原生O2M/O2O criterion | 同RGB曝光、同混合批BN/前向；无对应辅助loss |
| C2 | 与B2完全相同 | 既有同容量连续对应学习 |
| D2 | 与B2完全相同 | 既有局部原型分配学习 |

B2不是旧“真实+合成GT普通分割”的B。合成RGB仍能通过混合批BN统计及其梯度影响正常分割训练，**不能称B2纯真实数据训练**。同一影响需三臂匹配并记账。D2−B2包含额外对应监督/辅助正则的作用，不单独证明原型特异性；D2−C2仍是核心增量。

真实GT不进原型分配或生成器；合成owner/valid/confidence/射线资格只供共视采样和QA，不作为正常分割target。不得根据真实GT改合成配方、修改原标签或改目标为amodal重建。部署仍为原生YOLO，不增加Mask后修补/选择/替换网络。

## 3. 必须落实的最小代码改动

- 一次8图前向后，对criterion输入中的**已登记batch轴**取前2张；真实task batch只含它们的原独立Masks、Boxes、class和语义Mask，`batch_idx`只允许0/1。不得按“某个轴碰巧等于8”盲目递归切张量。
- 原版criterion本体不改，分割任务总loss按2张真实图归约；对完整8图O2M空间基底提取合成对应，原O2O detach保持。
- 加硬断言：正常分割target来源集合只能是`real/train`，合成target计数必须为0；错误的合成Mask输入须直接拒绝，不静默忽略未知字段。
- 在最终release上核梯度、白名单、检测行、BN/状态、criterion更新/学习率/优化器、参数容量与实际资源。934是旧8图混合监督工程，**不能当成本版优化循环或任务切片已通过**。

现有源代码中该切片/正式循环尚未实现与验证，不把本说明当成已可训练程序。原建议λC=.05、λD=.1仍须在本版合同显式选择；不看dev调λ。

## 4. 保持的研究问题与决策标准

H仍是：合法合成共视局部的原型分配，能否比同信息、同辅助容量的连续学习增加真实分割效用。竞争解释仍为普通对应正则/容量/数据曝光，而不是已证实的原型知识。

不降低候选筛选的D−B≥.5pp、D−C≥.3pp、检测身份精确不变、Mask75损伤点估计≤1%、S/M/L对B各不低于−1pp建议值；须在新正式Protocol中用B2/C2/D2命名、真实分母和相同432 dev末点评价重新冻结。原生N和V23分别报告，但V23旧训练预算不同，不能冒充同预算对照。旧N+5与test426解封规则不变。

若D2不超过C2，则优先连续学习，不靠加槽/门控/追加步数保原型；若实际损伤超限，则关闭本配置。若样本/区间不足，只记信息不足。机制确认仍须另冻同容量对照、对应错配、固定随机原型、幅度控制及多seed；部署本来删辅助头，不用runtime-off假装机制消融。
