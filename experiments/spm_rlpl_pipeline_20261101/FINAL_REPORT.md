# RLPL完整有限实验：已完成训练与交付，效用筛选阴性

**结论：B2/C2/D2各2000次实际更新、完整432 dev、独立统计、纯原生部署、权重与图表回传均已完成。D2比C2好，但仍损伤原生模型和无辅助B2，不能作为有效新方法采用。** 本轮按冻结规则保留原生N；不扩训、不追调λ、不解封test426。旧V23仍是更高的历史性能参照，不恢复已经撤销的后置Mask修补路线。

## 1. 整项实验的研究链路

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | 旧原型/记忆路线未稳定证明内容必要性；936/940又确认真实原GT与严格可见合成Mask不等价。需要检验：保留真实正常监督、只利用合法共视合成对应，能否在不改变检测且不增加部署模块的情况下改善原生Mask？ |
| **机制假说** | H：同表面可见局部的共享离散原型分配能比同信息连续对应带来额外、可用的真实分割收益。H_alt：差异来自正常任务适配、混合BN曝光或普通正则，离散原型没有净效用。故必须同时检查D2−C2、D2−B2、D2−N及成功实例损伤，不能只看loss或D2−C2。 |
| **针对性方法** | 固定200组合成/1100个体/600图，160训练组/40 QA；1272真实train原独立GT只进入正常loss，合成只供对应。三臂共同2真实+6合成RGB/Mask专属BN、原始权重、日程/坐标、Mask白名单与各2000更新。B2无辅助，C2连续对应，D2原型对应。冻结共享网络、Box/Class/score/排序，末点后一次完整432 dev/2863 GT，重算N与历史V23；独立COCO与簇统计复核，实际原生CLI/成本及固定案例交付。 |
| **整体结果** | 三臂确实完成全部更新，正常输出身份与Box AP精确不变。Mask AP N/B2/C2/D2/V23=57.343500/56.222099/52.357215/54.481384/60.753278。D2−C2=+2.124169pp，但D2−B2=−1.740715pp、D2−N=−2.862116pp、D2−V23=−6.271894pp；D2损伤N成功集113/2126=5.3151%，损伤B2成功集83/2112=3.9299%，均超过1%。D2相对B2的S/M护栏也失败。独立120项COCO统计最大误差0。相对连续分支的排序预测实现了，净效用和保留成功实例的预测没有实现。 |
| **研究决策** | **停止这三配置的继续投入，保留N。本轮原型方法不准入。** 我选定下一研究重点为“原生Mask适配中，权重更新与混合域BN运行统计对既有成功实例的影响”，而不是继续加原型/换loss。依据是无辅助B2已在四来源全部下降，且6/8合成RGB参与专属BN；BN与权重漂移均有计算上的依据，但本轮没有区分其因果作用。**唯一下步是冻结现有N/B2权重×Mask BN运行统计的2×2零训练交换协议**，复用已有两格输出、只规划两格混合模型；若损伤随BN统计转移且恢复原统计能保住效用，优先BN统计隔离；若损伤随权重保持，转向原生函数保持的参数更新；混合/未决则不批准BN单因修复或更多辅助训练。该新核验尚未启动，需另行冻结，不自动续跑。 |
