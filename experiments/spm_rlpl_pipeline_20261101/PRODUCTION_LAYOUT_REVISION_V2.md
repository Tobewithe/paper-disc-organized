# 生产布局V2：保留同一批个体，修正有界贪心摆位的覆盖缺口

## 原V1结果及边界
960在`rlpl_010_pig_06`、966在`rlpl_007_pig_05`出现原1000次贪心摆位耗尽；失败发生在个体均已构建且独立几何合格之后，不是模型/原型阴性。两组都是狭窄bands偏好；“前几头已占位置后，后续放不下”不证明整个栏内不存在合法联合布局。已停止本Study其余四个V1作业，保留全部实际Run和取消记录，不操作其它任务。V1六片分配2436 CPU作业秒、14616 CPU-core-seconds=4.06 core-hours，0GPU。

这是**明确的新布局构造版本**，不是把真实有界失败抹成拼写错误。原V1完整候选发布未通过，不改其结论。用户完整有限委托内选定V2以解决必要的构造覆盖；同200组/1100个体、原recipe/seed/身体/姿态、墙槽边界和≥.08m分离、真实门≥8像素、射线与全日程支持Gate全部不降低。真实GT、dev/test和模型反馈仍禁用。

## 有限算法
先运行原摆位；通过则原样保留。仅遇该明确耗尽错误时，调用`placement_v2.py`：最大256候选/个体，按生成个体凸包面积从大到小，前16个为4方向×4角的确定候选，其余固定独立seed全合法域采样；带回溯的联合搜索最多20000候选检查。候选基于真实生成网格及原边界，分离构造留1e-5数值余量，最终仍以原.08m验收。

fallback明确不强制狭窄bands/clusters的艺术布局偏好，须在Recipe记`requested_style`及`style_bias_not_enforced_in_fallback`，不能冒称原布局分布未变。它不是更换猪/减少实例、扩大栏位、降碰撞阈值或增加网络。之后沿已冻结的整群Y平移前门邻近条件，不改变相对间距。有限搜索仍失败则停止，不再无限加候选。

先用960/966中**原13个合格BODY**核原贪心失败可复现、V2同对象严格约束及独立重放一致；0GPU/2CPU/12GiB/≤5min，不重建个体、不渲染。通过才显式重启六片完整198组，新Run从源码冻结开始，旧失败/中止不覆盖；重复生成的同名身体必须与旧已完成顶点SHA一致，不把重复尝试计新来源。
