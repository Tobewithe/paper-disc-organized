# 质量头方法验证

## 结果

使用 500 张 COCO train2017 的 17,856 个候选样本训练轻量 MLP，并在独立 50 张 val2017 的 336 个 GT 候选组上测试。输入只使用推理可获得的单候选统计（类别分数、层级、框尺度/位置、掩码面积/填充/边缘比例、系数范数/方差）以及候选间关系（同类掩码最大重叠、系数余弦、同类邻框数）。

- 单候选统计回归头：质量排序 Mask IoU 0.7276，原始分数排序 0.7346，差 −0.70 pp；
- 加入候选关系的回归头：质量排序 0.7297，差 −0.49 pp；
- 相邻组关系头差 −0.97 pp，非相邻组差 −0.32 pp。

## 结论

当前特征和训练方式不能在独立图像上恢复官方候选的 mask 质量排序。它保留了候选审计发现的“可挽回空间”，但没有形成可用方法；不能把 oracle 替换增益写成方法增益。下一步若继续，应使用张量化的组内排序损失、候选的完整原型响应/局部支持特征，并在标准 COCO val 推理中验证；在此之前不进入论文主方法。

- 张量化 pairwise 排序复核：总体 −0.09 pp；相邻组 −1.13 pp；非相邻组 +0.29 pp。该 GT-free 后处理路由仍未形成稳定提升。
