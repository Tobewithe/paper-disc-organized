# Experiment 7E: held-out direction predictability

Use the official frozen one-to-one YOLO26m-seg cache: 800 fit and 200 dev train2017 images, followed by 200 val2017 images. Fix `lambda=0.003` from 7D before fitting any predictor; `lambda=0.001` is reserved as a future robustness check, not a validation-set selection arm. Optimize each GT-conditioned target with the strictly convex 7D objective. Targets from val2017 are generated and read only **after** the four predictors and their dev-selected checkpoints are frozen. Never train on validation GT targets.

Compare four equal-parameter MLPs, with identical initialization and image order: `h` plus zero local descriptor, `h` plus true predicted-box-local prototype descriptor, `h` plus a descriptor from another positive candidate in the same image, and `h` plus a descriptor from another image in the same split. Singleton images in the wrong-instance arm use wrong-image fallback, and the fallback rate must be reported. Every descriptor is 32 prototype channels pooled to 4x4 over a **predicted** box, with no GT used in predictor input. Fit normalization is computed on fit only and reused on dev/val. Select each arm's checkpoint with the same dev loss, including an uncorrected epoch-0 control.

Train to predict a coefficient direction and a log-radius separately. Use the predicted-box prototype Gram matrix to score pixel-logit-effect direction, with coefficient-space cosine and radius error as supporting targets. On fit/dev/val report coefficient cosine, functional `P delta` cosine, radius error and actual decoded mask IoU, Mask75, target coverage, FPR and AUC. Also report GT-assisted hybrids (predicted direction with oracle radius, oracle direction with predicted radius) as diagnostics only; they are not deployable results.

The frozen cache has only 800 fit images, and earlier `h`-only probes did not generalize at this budget. A negative 7E result cannot establish intrinsic unidentifiability until sample-size and representation controls are expanded. This is a fixed-candidate diagnostic, not full COCOeval AP.
