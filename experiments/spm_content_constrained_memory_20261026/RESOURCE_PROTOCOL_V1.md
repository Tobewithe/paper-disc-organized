# V23初始化后四卡资源和全链路工程探针V1

一次性Slurm，最多4A6000/10分钟/16CPU/64GiB，0优化（没有optimizer.step或权重更新），最多20个global4图周期、80图曝光，另固定4图正常RGB重放和同4案例梯度等价复核。数据仅原train、初始化必须来自完整准备且10类有支持。源/缓存/权重/环境哈希不变，4 warm周期在测量前固定，随后16周期包含DataLoader/I/O、正常输入准备、loss/backward/DDP，逐周期跨rank取最大时长。

资源通过：`1.2*p95(16)*8000 + warm实际时长 + 60秒保存余量 <= 90分钟`；每卡峰值分配<40GiB。该20%余量覆盖未实际执行的optimizer/EMA和运行波动；正式阶段仍受Slurm90分钟硬限，不据loss追加。若不通过只修数据路径/执行安排，保留失败，不自动扩大正式预算或缩小训练对象。

每组梯度必须有限，跨4案例全部14组非零；DDP平均与同模型单卡顺序4图各loss/4的梯度相对L2误差≤2e−4、余弦≥0.999999（FP32并行归约与grid_sample非确定加和的工程容差，不作数学精确声明）。模型和C21状态不变。

正常合同：训练stream的前4图（2real/2synthetic）重新原生RGB推理，原输出/半精度feature栅格与缓存逐值相同；完整C21 chunk2与原无损缓存同二值/动作/浮点delta，新初始化内容chunk2及16通道风险特征、实际26动作/去重相同，0初始风险头平局保留C21。标签只作cost/gradient目标，不进入正常前向。

同时逐例以完整640目标复核新成本，原生保护GT允许与owner不同；检查有界质量控制可行和整行回退。完成只允许全链路审查和独立正式激活，不算训练/方法收益/完整goal完成。
