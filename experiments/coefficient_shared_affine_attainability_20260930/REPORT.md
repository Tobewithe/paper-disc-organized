# 原生系数头末层共享可达性审计：阶段结果

## 研究问题

固定 YOLO26m-seg 8.4.100 one-to-one 正样本缓存中的末层输入 `h`、prototype 响应 `p`、原系数 `c`、GT 框内标签 `y` 和面积归一化，比较：

1. 原模型的 `Δc=0`；
2. 每个特征金字塔层共享一套 64→32 仿射增量 `Δc=[h;1]A_l` 的最优解；
3. 每个实例独立的有限正则 oracle。

这不是重新训练 YOLO，也不是外挂修正器。共享增量可以直接合并到原生末层的 `W_l,b_l`，其余网络、候选、框、类别和原型全部冻结。

固定目标为 7D 同口径的 GT 框内 mask BCE 加有限位移正则：

\[
J_i(\Delta c)=\frac{\sum_{u\in B_i}\operatorname{BCE}(p_{iu}^{\mathsf T}(c_i+\Delta c),y_{iu})}{area_i}
 +\frac{0.003}{2}\|\Delta c\|_2^2.
\]

因此三者满足理论顺序 `J_ind ≤ J_shared ≤ J_0`；本报告的数值是诊断目标，不是 COCO AP。

## 数据和求解

使用远端缓存 `coefficient_predictability_20260924/runs/RUN_62e3a1994b804eceb03fb8e616a4f946`：fit 5,872 个候选、796 张图；dev 1,375 个候选、197 张图；val 1,301 个候选、196 张图。它是已有冻结缓存，不是新的 10,000 图重建，因此结论范围明确限于这批固定特征。

共享仿射目标先用双精度 L-BFGS 求解，再用解析梯度的 SciPy L-BFGS-B 按层精修。特征按层标准化只改善数值条件，输出仍是同一个共享仿射子空间。逐实例 oracle 以批量双精度 L-BFGS 求解，80 次迭代后最大批次驻点残差为 `1.44e-7`。共享精修后三个层的梯度无穷范数分别为 `5.13e-7`、`8.20e-7`、`3.44e-7`。

## 结果

### fit 上的可达性分解

| 状态 | 目标 `J` | BCE | 正则项 |
|---|---:|---:|---:|
| 原模型 `J0` | 0.419728 | 0.419728 | 0 |
| 共享仿射 `Jshared` | 0.317420 | 0.302903 | 0.014516 |
| 逐实例有限 oracle `Jind` | 0.201276 | 0.168845 | 0.032431 |

由此得到：

\[
J_0-J_{shared}=0.102308,\qquad
J_{shared}-J_{ind}=0.116144,\qquad
J_0-J_{ind}=0.218452.
\]

在这个冻结 fit 集上，共享末层回收了约 `46.8%` 的原模型—逐实例 oracle 目标差距，剩余约 `53.2%` 仍落在共享仿射约束之外。这个比例是当前诊断目标下的可达性分解，不能解释成完整 YOLO 的容量上限。

### 冻结共享参数在未参与求解的图像上

共享参数只在 fit 上求解，随后直接应用到 dev/val。用图片内候选平均后做图片级 bootstrap：

| 分片 | 原 BCE | 共享 BCE | 差值 | 图片 bootstrap 95% CI |
|---|---:|---:|---:|---:|
| dev (197 图) | 0.427350 | 0.341567 | −0.085784 | [−0.121185, −0.079149] |
| val (196 图) | 0.412589 | 0.355134 | −0.057455 | [−0.101531, −0.062318] |

val 的共享目标（含正则）为 0.370454，原模型为 0.412589，差值 −0.042135，图片级目标差值 CI 为 [−0.088876, −0.049950]。这说明共享仿射增量在同一冻结诊断目标上具有跨图像的可重复收益，但仍不能直接推出 Mask IoU、Mask75 或 COCO AP 提升。

### 尺度分解

val 的 BCE 差值按末层尺度为：P3/level 0 `+0.000794`（略差）、P4/level 1 `−0.058646`、P5/level 2 `−0.116241`。当前收益主要来自 P4/P5；P3 没有得到改善。因此不能把本轮结果写成“小目标 P3 机制已经修复”。

### 数值稳定性

标准化共享求解从零初始化的近似目标为 0.317702；随机初始化（尺度 0.01）为 0.317700，差约 `2.3e-6`。两套初始化再用解析梯度精修后分别为 0.3174198098 与 0.3174198101，差约 `2.6e-10`；三个尺度的梯度无穷范数均低于 `8.3e-7`。这支持“共享目标的数值解稳定”，但由于未构造正式的全局最优性证书，表述仍使用“数值精修解”，不写成数学证明的精确全局最优。

## 当前判断

这轮审计把两种解释分开了：

- 固定 `h` 和 `P` 后，原生共享仿射末层**确实还能回收一部分**当前冻结快照上的 mask-BCE 差距；因此不能把原模型当前系数直接当成该共享末层在这些特征上的最佳可达值。
- 逐实例 oracle 仍明显低于共享解；约一半的诊断差距不是一套跨实例、跨图的 64→32 共享仿射映射能够同时回收的。这支持“共享映射约束造成剩余差距”这一**范围受限的诊断结论**。
- val 的收益主要来自 P4/P5，P3 略有损失；它没有支持“P3 小目标失败已被该末层修复”，也没有形成新的完整分割方法。

下一步如果继续，应先把这个共享仿射可达性结果与最终 mask 解码质量对齐，再决定是否值得研究前级特征如何改变；不应直接把本轮 BCE 收益写成 COCO 性能提升。

## 阶段 B 实际掩码确认

阶段 B 已在有 GPU 的远端 `56018` 完成：冻结阶段 A 共享解，合并回原生 one-to-one 系数末层，并使用完整 prototype、预测框和默认双线性原图逆变换解码。结果显示 val 图片级 macro Mask IoU 从 `0.753711` 提升到 `0.808549`，差值 `+0.054838`，95% 图片级 bootstrap CI `[+0.039546,+0.071756]`；coverage 差值 `+0.064702`，连续 logit AUC 差值 `+0.016943`，Mask75 从 `767` 到 `847`（修复 `131`、损伤 `51`）。收益主要集中在 P4/P5 和原输出失败实例，P3/level 0 的 val IoU 差值为 `−0.017023`。

这证明当前固定几何候选上的共享末层数值改善可以传递到正常原图实例掩码，但仍不是完整 COCO AP 或端到端置信度/NMS 结论。完整协议、候选审计、合并误差和分层结果见 [`PHASE_B_REPORT.md`](PHASE_B_REPORT.md)。
