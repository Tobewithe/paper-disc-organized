# 猪对象学习 v0 训练包与工程核验

2026-10-23。对象学习代码、成组数据生成器、同容量普通分支、固定评价及可视化已实现。实际 Pig 资产导出和 CPU 前后向核验通过；**真实优化步数为0，正式2304图未生成，尚无新训练原型或分割收益。**

| 维度 | 本次工程核验的整体链路 |
|---|---|
| **问题** | V5对象定义需要落成可运行的身体表示与图像到对象链路；前驱的原型中心没有显式身体坐标与成组观察监督。 |
| **机制假说** | 本次是工程核验，机制效用不适用。后继正式v0将比较显式身体绑定与同容量自由解码，相关假说和预冻结出口见PROTOCOL_V0。 |
| **针对性方法** | 从真实Pig.blend导出283顶点、24骨骼和六姿态，与Blender逐顶点求值独立对齐；独立射线检验透视栅格；两分支使用相同模型输入/状态/损失，做CPU前向、反向和精确权重重载，无optimizer.step。 |
| **整体结果** | 最终资产Run与实际CPU Run均完成。六姿态蒙皮最大误差6.0981e-8体长；18个姿态/视角组合的2304条独立射线最大深度误差3.7267e-7体长；两臂均453384可训练参数，损失及全部参数梯度有限。零训练、无GPU分配，不产生相对原生YOLO或既有分割方法的AP比较。 |
| **研究决策** | 工程链路可用，优先执行已冻结的v0跨视角/遮挡对象能力比较。唯一下一步为核定远程训练授权后，按2304图、两臂各4000步和固定末次评价执行；未达对象能力条件则关闭当前参数化扩训。工程通过不支持对象机制或+5目标已经成立。 |
