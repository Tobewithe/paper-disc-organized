# 猪对象学习 v0 执行协议

2026-10-23。本协议定义 V5 的第一项有限对象能力试验，源码由 FREEZE_V0.json 锁定。具体输入和数值见 CONFIG_V0.json。当前代码准备、零优化工程核验与正式训练分账；源码冻结不等于已训练或训练授权。

## 研究对象与预期

前驱 V4.1 的全局原型相对同预算 B 仅增加 0.0417 个 Mask AP 点；固定每实例均值读出在 305 个失败对象仅修复 2 个。原型中心的扩训已关闭。V5 根据用户对象形成命题及 MagicPony、3D-Fauna、NeMo 的相关方法依据，检验显式身体绑定能否使局部图像支持跨视角的对象几何预测。文献、前驱 Run 和完整设计见[设计](../../paper/manuscripts/spm_yoloseg/OBJECT_PROTOTYPE_DESIGN_V5_20261023.md)。

H：同一标准身体的骨骼蒙皮绑定，为从部分观察推断完整对象提供有效约束；在等容量、同监督条件下，其隐藏部分与留出视角误差应低于自由解码。H_alt：普通图像编码器与自由解码器同样能利用额外几何监督，显式绑定没有必要增量。若结构分支仍不超过此控制，关闭本参数化扩训，不再扩中心库或为追阳性改损失。

v0 是单资产、已知相机、强合成几何监督的必要能力检查。使用真实 Pig 网格和骨骼导出的几何，但 RGB 为简化 Lambert 着色与三维前景栏杆；不是完整猪场写实渲染。三维身体结构先验和粗部位由人工资产给定；尚未学习真实体形分布，也不宣称自主发现部位、真人认知机制或真实分割效用。

## 数据与标签

唯一资产路径和 SHA 冻结在配置中，Blender 4.2.1 LTS。283 顶点的原网格和完整骨骼权重导出实际维数，按给定映射聚合 8 粗部位。与 Blender 真实求值顶点逐姿态验证线性蒙皮，最大坐标误差必须 <2e-5 个标准体长。v0 的姿态状态为实际求值骨骼仿射矩阵，不将它说成已经实现受关节范围约束的运动学模型。

32 形变参数族 × 6 姿态 × 3 相机 × 2 外观 × 2 遮挡状态 =2304 图，128×128。前 24 族 train（1728），后 8 族 dev（576）；同族全部视角/姿态/外观不跨拆分。形变种子与外观分开，两个外观样式跨全部体形共享，避免用肤色查表识别形变编号。形变基是有限平滑扰动，并不代表独立猪资产。真实 train/dev/test 均不读。

每图保存 RGB、完整投影、外部遮挡后的可见投影、深度、标准坐标、粗部位、三角形与透视重心坐标。完整投影保留身体的自遮挡，不是背面表面全可见。相机内外参、体形码和真实骨骼状态仅按角色使用：模型输入 RGB 和源相机；体形/姿态/几何/部位为监督；目标相机用于请求新视角，目标 RGB、深度、掩码不进入编码器。成对样本固定同体形/姿态/相机，改变外观与遮挡。

标签核验包括：三角形像素中心投影；独立射线参考的透视深度；标准坐标—蒙皮—重投影；跨外观标签一致；遮挡只移除可见区域；族间隔离与逐文件 SHA。完整数据集每项几何重放误差 <2e-5；缺图/错误标签为工程失败，不缩分母重跑科学结果。ASSET_LOCK.json 在实际资产导出通过后锁其字节，数据 MANIFEST 在首个训练前冻结。

## 模型与严格匹配对照

两臂完全相同的 CNN、相机输入、16 维体形码、骨骼仿射状态头、64 维身体表面特征场、逐点残差解码器、稠密标准坐标/部位头。原网格、蒙皮和形变基都向两臂提供；两臂均有相同初始权重与所有监督。

- S：标准体形经固定蒙皮绑定变换，再加可学习逐点残差。
- U：标准体形加同样的自由逐点残差，骨骼状态作为同样的残差输入；不施加显式蒙皮乘法。
- P0：训练集体形/姿态的平均几何，作为不读图像的静态参照，不另训练。

两臂的有效可训练参数总数必须精确相等；所有参数必须在损失图上有有限梯度，不用无效填充参数配平。差别是额外给定的几何计算约束；这一先验本身属于受测干预，不声称模型从无先验数据自行学出骨骼。初始化与优化难度可能不同，不能只凭总增量解释成唯一认知机制。

损失按配置冻结：完整顶点 smooth-L1 1.0，目标视角对应点投影 0.2，体形 0.1、姿态 0.1、可见标准坐标 0.1、稠密及表面部位 CE 合计 0.1、成对体形一致 0.1、不确定性尺度回归 0.01。几何单位为标准体长，投影除图宽，按样本/有效点归约；掩码只用于定义有效监督区域和末次轮廓评价。首版尺度回归只估计误差幅度，不冒充多模态隐藏形状后验。

## 执行与预算

先执行零优化 CPU 工程核验和实际资产导出，二者各独立 Run。单次工程核验只做前向、反向与重载，无 optimizer.step、无 GPU、无训练指标声称。给定数据的 GPU 导出最多 1 张 A6000/30 分钟；S/U 顺序训练各4000步，总8000步，batch16、AdamW 3e-4、weight decay1e-4，最多1张 A6000/60分钟；固定末步，不使用 dev 挑 checkpoint。评价最多1卡/30分钟，不扫阈值。

当前 AGENTS 第5节写明“当前操作只允许修改约定的仓库文件，不远程启动训练”。本轮先完成可审查训练包和零优化工程验证；正式远程训练必须有用户明确覆盖该限制的指令，并登记 EXECUTION_AUTHORIZATION.json。该回执必须绑定当前配置和协议 SHA。未获授权时程序主动拒绝生成正式 GPU 数据或进入训练，不能把“开始做训练包”静默扩大成远程正式训练。

## 评价和三种出口

固定末步模型在全部 576 dev 输入评价，主分母为其中 288 个遮挡输入，统计簇为 8 个体形族。对每个输入从其预测完整对象投影到下一个相机；共同目标由同一已知几何产生，不使用预测后重新挑匹配。主量为逐顶点平均欧氏误差（体长），补充新视角完整投影 IoU、换外观/遮挡后的体形码 RMS 漂移。报告相对 P0 与 U 的收益和损伤；原生 YOLO AP 及真实 5pp 目标在本实验不适用。

晋级必须同时满足：遮挡输入上 S 对 U 的族平均相对顶点误差减少 ≥10%，按族配对 bootstrap 2000 次的95%区间下界>0；S 绝对误差≤0.05体长；新视角完整投影 IoU≥0.80且对U下降不超过0.01；体形码 RMS 漂移≤0.10；同S错误身体绑定后误差增加≥0.01体长。所有数值均在训练前冻结，不按结果改阈值。八族仅代表该资产的形变留出，不作真实域独立确认。

定向干预固定为权重矩阵沿顶点维循环移动1行，保留权重值、数量及通道总质量，破坏其身体位置对应；另加固定种子的等 L2 范数几何噪声作幅度对照。分别报告损伤，不把任何随机扰动带来的退化都算结构证据；错误绑定若未超过等幅噪声，其机制特异解释不成立。U 从头同预算训练与同S干预互补，不能互相代替。

1. 全部通过：支持此范围对象能力，下一步仅规划真实 train 对象对齐；不自动扩大合成规模或启动YOLO联合训练。
