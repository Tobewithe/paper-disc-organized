# Experiment 7N：失败实例的系数方向为何难以从共享特征识别？

## 对象与问题

复用 7L 的 10,000 张 COCO train2017 图像、官方 YOLO26m-seg one-to-one GT 条件正样本、固定预测框与 prototype，以及 λ=0.003 的有限且唯一的 GT 条件系数修正方向。7G 只在 1,346 个验证候选上看到：`h` 近邻在失败实例上的方向迁移很弱。此处用 7L 的 71,269 个方向做五折跨图检索，检验这是否是小样本偶然现象，并寻找更具体的可观测条件。

## 冻结检索

沿用 7L 已固定的图像级五折。每折只能从另外四折寻找近邻，绝不从同一张图检索。诊断匹配池优先限制为相同 **GT 类别、COCO 面积组（小／中／大）、预测金字塔层级**；不足五个时依次退至同类同面积、同类、全池，记录退让。GT 类别和面积仅用于排除类别／尺度混杂，**不进入特征或部署预测器**。这一匹配使检索结果比实际无 GT 推理更乐观。

四个不训练的特征相似度：`h`；`h+basic+raw_detection`；`h+local_summary`；三者全部。各块仅按当前四折拟合均值／方差、单位化，然后等权合并。`basic`、检测分支和局部系数空间摘要均来自未编辑原图，使用当前预测框；局部摘要不是 GT 区域。每个查询从同一匹配池取各输入的前 1／5 个最近邻，并取预先固定随机种子的 8 组随机 1／5 个对照。

把邻居的单位系数方向放入**查询实例自己的原型 Gram**，计算与查询 GT 条件目标的像素 logit 作用余弦。主对象是原 Mask IoU<0.75 且 Box IoU≥0.75 的失败实例；同时报告全体、失败、成功、好框成功及严重／轻度失败。主要比较 `h` 检索相对同池随机的作用余弦，以及新增检测／局部特征相对 `h` 的增量；按图像聚类做 2,000 次重采样区间。报告方向长度和检索池大小。

若失败组的近邻方向显著优于随机，说明 `h` 至少有可迁移信号；若显著弱于成功组且大样本区间稳定，说明**当前表示／检索规则对需要修复的实例尤其不充分**。若加入真实局部特征优于 `h` 和检测输入，才支持局部空间信息是缺失变量。检索关联本身不能证明信息论不可识别，更不能证明 YOLO 端到端训练的唯一失败原因。所有结果仍是 GT 条件候选诊断，不是 COCOeval AP。

## 检索完成后的独立跟进：实际五折修正头的方向与收益

检索只是非参数探针，不能替代实际共享预测器。复用 7L 已完成的五折 OOF `h`-only 修正输出，与同一 71,269 个 oracle target 按图像 ID、annotation ID、原始预测位置三键精确对齐；核验每折被评价图像不在对应修正头训练清单中、原掩码 IoU 重放一致。以**目标实例自身 Gram**测修正头与 oracle 的像素作用余弦，并按原 Mask75 失败、成功、好框失败和严重失败统计方向、IoU 收益、修复及损伤。再看高 `h` 相似但检索方向不一致的对象，实际预测器是否同样难以正确修正。该跟进使用已有结果，不训练或选择新模型；`h` 相似度阈值 0.9 来自检索完成后的描述性分析，须标为探索性。若方向余弦与收益脱钩，不得把全部损失归因于方向识别；若二者一起在失败组降低，才支持方向识别是当前预测器的重要瓶颈。

## 探索性机制分叉：prototype Gram 是否是遗漏的条件？

上述分析仍未说明方向歧义来自实例原型几何 \(P_i^\top P_i\)，还是 GT 像素归属项 \(P_i^\top y_i\)。追加不训练模型的检索对照：在同一五折和匹配池下，比较 `h` 基准、`h+真实预测框内 Gram 上三角`、`h+真实 Gram 对角` 和 `h+同类别／面积／层级错配 Gram`。每个特征块仅用当前四折标准化并单位化，拼接时等权；评价仍使用查询真实 Gram，仅检索输入错配。检验好框失败组真实完整 Gram 相对 `h` 和错配 Gram 的方向作用余弦差。该分析在看完主要 7N 结果后追加，**仅作为探索性分叉**；若不提升，只能说二阶原型统计未补足信息，不能排除完整空间原型或图像特征。

## 探索性损失梯度项分解

官方训练 BCE 对当前实例 GT 框支持区有梯度 \(g_i=s_i-t_i\)，其中 \(s_i=P_i^\top\sigma(P_ic_{0i})/A_i\) 是 GT 框支持区上的模型响应（支持区仍依赖 GT 几何），\(t_i=P_i^\top y_i/A_i\) 还需要真实像素归属。为比较二者，把五折 `h` 相似度≥0.9、原 Box IoU≥0.75、原 Mask IoU<0.75 的查询分为“最近邻 oracle 作用余弦≤0”和“≥0.5”；固定种子各抽 400 个，重建同一匹配池中的真正 `h` 最近邻。用 7L 官方训练缓存的原型、所有权标签、原系数和 GT 框，分别计算查询／邻居的 \(s,t,g\)，比较各自向量余弦和 \(\cos(s_i,s_j)-\cos(t_i,t_j)\)。同时在缓存原型上核验既有 oracle 的最优性残差；缓存原型曾半精度保存，若残差过大，禁止把该分解当成原 FP32 oracle 的精确机制证明。该子集按 oracle 方向极端值选取，**只能解释高相似度的典型一致／冲突实例，不估计全 COCO 人群比例**。若在方向冲突对中 \(s\) 保持相似而 \(t\) 显著分叉，才支持目标像素归属交叉项是这些冲突的主要来源；若两项都分叉，必须保留混合解释。

20 对的小型运行发现 \(s,t\) 跨实例可能都高度相似，因此正式 400+400 对额外登记**相减后的残差条件**：\(\kappa_i=(\|s_i\|+\|t_i\|)/\|s_i-t_i\|\)、同实例 \(\cos(s_i,t_i)\)、跨实例 \(\cos(g_i,g_j)\)。若单看两个大向量的夹角掩盖其差，\(\kappa\) 与梯度方向能揭示是否是近相消导致系数方向对细小归属变化敏感。再用当前点的带岭 Hessian 做一步 Newton 方向，与精确 oracle 比较；若近似一致，可把不稳定性定位在局部梯度／曲率，反之保留非线性路径解释。这些指标在正式 400+400 对之前补入，属于**先导启发的探索性分析**。

## 全量目标项的样本外可预测性检查

配对分解只能解释极端案例。为检验机制是否覆盖完整失败组，复用 7L 的**全部 10,000 图／71,269 候选**，从同一官方缓存计算每个候选的 \(s_{GT},t,g=s_{GT}-t\)，保存图像 ID、原 Box／Mask IoU、`h`、GT-free 检测／局部摘要和预测框内 Gram 对角。**官方的 \(s_{GT}\) 使用 GT 框监督支持区，含标签几何，不允许作预测输入。**另在原预测框内计算可推理获得的 \(s_{pred}\)；下文输入 B–D 的 `s` 均指 \(s_{pred}\)，而误差比较中的真梯度仍是 \(g=s_{GT}-t\)。核验所有 key 唯一、缓存与 oracle 的最优性残差分布，以及无图像跨折。标签仅从 train2017 产生，val2017 结果不参与模型选择。

在原 7L 图像级五折中，用**固定正则的标准化多输出 Ridge（α=100）**预测 \(t\)，不搜索超参数；只比较四个逐级输入：A `h`；B `h+s_pred`；C `h+s_pred+Gram 对角`；D `h+s_pred+Gram 对角+局部系数空间摘要`。\(s_{pred}\)、Gram、局部摘要均从原图预测框取得，GT 不进入输入；D 维度增加，只用于判断该现成摘要是否含有增量信息，不作容量匹配因果结论。每折仅用另外四折拟合标准化器和模型，并在被留出的图像上一次评价。以诊断性的 \(\hat g=s_{GT}-\hat t\) 检查两类误差：\(\|\hat t-t\|/\|t\|\) 与更贴近机制的 \(\|\hat t-t\|/\|g\|\)，再看 \(\cos(\hat g,g)\)，按原失败／成功和好框失败分组。**评价时使用 \(s_{GT}\) 仅用于与官方梯度比较，不构成部署算法。**若 \(t\) 的相对误差看似小，但相对于小残差 \(g\) 仍大、导致梯度方向失真，将直接支持**差分条件数放大目标归属估计误差**；若新增 GT-free 条件显著降低失败组的这个比值，才识别出具体可用信息源。此检验是诊断探针，不代表训练完整 YOLO 头的因果效果。

### 看完目标项探针后的必要对照（探索性）

目标项回归的目标 \(t\) 与模型项 \(s\) 高度相似，回归器可能优先拟合二者的共同大分量，而忽略决定方向的小残差。故追加**同样输入、同样五折、同样标准化 Ridge α=100** 直接预测官方梯度残差 \(g=s_{GT}-t\)；只在训练折使用 GT 梯度标签，留出折输入仍全部 GT-free。报告残差方向余弦、相对误差及直接预测减目标项重建的图像聚类区间。若直接预测显著更好，不能把先前的低方向精度全部归咎于特征信息缺失；还必须检验训练目标是否过度偏向共同大分量。此对照在观察目标项结果后决定，标记探索性，不作为独立预注册证明。

### 全量梯度近邻转移（探索性）

原 400+400 对按 oracle 方向极端值挑选，不能估计梯度方向不一致在完整人群的频率。追加全 71,269 个候选的图像级五折检索：每个查询的近邻只能来自其余四折，沿用原 7N 的标准化 h、同 GT 类别／面积组／预测层级匹配池与回退规则；从同池固定种子随机抽一个不同图像候选作对照。GT 类别和面积只用于诊断匹配，不是推理输入，故结果对实际无 GT 使用仍偏乐观。比较跨实例 \(s_{GT}\)、\(t\)、\(g=s_{GT}-t\) 的 32 维系数空间余弦，分别在全体、失败、好框失败、严重失败和高 h 相似组统计非正比例与近邻减随机差，按查询图像聚类重采样。若两个大项的近邻余弦高而真实梯度的一致性低，且失败组明显弱于成功组，才能把先前极端案例提升为人群级证据；这一比较依然是关联分析，不独立证明缺失由哪个网络层造成。
