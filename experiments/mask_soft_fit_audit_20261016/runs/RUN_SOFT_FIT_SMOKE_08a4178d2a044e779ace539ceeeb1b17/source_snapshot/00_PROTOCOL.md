1. 逐图用完整系数矩阵精确重放原生RLE，然后用现有adapter前向一次，导出无门控U；使用既有 `area_gate.mix_row` 生成G：原生原图二值mask面积>=9216采用U，否则保留原生。两个完整预测都包含所有输出；禁止按GT好坏筛掉预测或缩小评价分母。基础模型forward=0，新增训练/优化/oracle求解=0。
2. U/G分别用原COCO账本代码评价训练全部2000图，bbox与segm独立匹配；检查所有Box75配对身份不变。固定同一原生bbox75检测的原图IoU用于效果；全部原Mask75成功普通GT用于真实任务损伤census。附带训练AP只描述训练集，不能与val AP相减。
3. 统计每图全部输出、Box50原训练join及非空ROI有效监督中，原生面积>=9216的数目/分母、图片数、类别数。有效监督配对保留与Box75配对是否同一输出的字段；它们不混合。训练3轮重复访问不当成3倍独立样本。原loss保持soft-IoU+0.1保真BCE，分别评估固定c0和当前checkpoint的2000图均值及分母，不用在线日志代替。

5. 分组只用原生信息：mask面积S<1024/M<9216/L>=9216、COCO类别、原生固定检测IoU区间[0,.5)/[.5,.75)/[.75,1]。报告对应的效果/修复及损伤；原成功GT分组的面积取其原segm75匹配检测，不能偷换为bbox75检测。

## 事前决策

训练内U/G分别沿用数值要求：T均值>=.005且95%下界>0；全部Box75均值>=-.001；全部成功GT精确损伤<=1%。这些是训练内诊断要求，不称通过原S2抽样Gate。

优先按已进入S3的面积门控G作裁决，U帮助解释门控作用：

- G训练内任一要求未满足：主判断为训练内尚未学成满足效用/保护要求的修复。优先研究训练内可达修复的学习与保护，不据此启动6k富集或缩网络。若只是区间精度不够，明确区分于负效应。
- G训练内全部满足，且上述共同支持充分、标准化train-dev差>=.005且95%下界>0：支持存在实质泛化落差；唯一建议为另行冻结数据量单变量对照，保持分布、目标、架构和评价不变，训练预算差异明确控制。本次不启动该训练，也不称100%坐实小样本过拟合。
- G训练内全部满足，但差距不满足实质性/精度要求：不将小样本认定为当前主瓶颈；优先研究已知可恢复目标的条件修复强度。若共同支持不足，则明确现有比较无法区分泛化，停止本次诊断，不临时放宽分层或补样本。
- 输入/身份/配置或统计无效：保留工程失败，不作科学裁决；仅修已定位的工程问题后登记独立版本/Run，不能改变科学规则追阳性。
