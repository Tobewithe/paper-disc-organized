# V2 输出链归因与采样位置稳定性：零训练冻结协议 v1

2026-10-20。用户授权服务器两张空闲 GPU，分别运行两项独立核验；通过各自 smoke 才运行正式阶段。训练、拟合、阈值搜索均为 0。本文在任何真实 Run 前冻结。两项分析共用输入/实现合同，但科学结论分别判定。

## 1. 来源、身份与冻结范围

基线为 Blender V2 `RUN_YB2_FULL_9154f356ba5f435f8c73db254817abb3`，12 段、576 帧、3 seed、每帧 3 个已知动物，中心 track=1。复用原 RGB、可见 GT、几何记录、预测、输出身份、36 个 16 图批次；不重渲染。现象：中心失败主要是正确检测缺失；NEAR 共同正确配对的混入为 55/132。它们不等于固定 P 不可修复。

采用 V2 原封不动的 PROFILE、8.4.100 源码 pins、官方权重 SHA、FP32/runtime policy、640/rect/batch16、416×672 实际输入、原生序列化与解码。导出 conf=.001；工作点 score>.25。无 NMS 重定义。所有改变仅限本协议明确的诊断干预。GT 只作事后关联和诊断，不能把 GT 辅助候选/混合 P/c 结果当部署收益。既有 G、G_budget、LCF 未在此合成集运行，额外方法收益记“未测”，不拼 COCO AP。

原生复核必须：全部处理批次 input/P/c0/F/框/类别/分数/原始行 SHA 与 V2 完全一致、全部原生 RLE 精确一致、零平移输出 JSON 与原记录完全一致。无容差放宽。原生 process_mask_native 先在输入尺度对 logits 阈值并裁框，随后 scale_masks 将二值掩码映射回原图并转 byte；不替换成“原图概率再 .5 阈值”。

完整输入和程序清单见 FREEZE.json，批次和逐 RGB/GT 哈希见 INPUTS.json。两个作业各单卡、4 CPU、16 GiB、2 小时硬上限、no-requeue。Slurm 不使用抢占，不改其它任务。磁盘增量每项不超过 12 GiB，显存峰值上限 12 GiB。smoke 各取原批次 [0,3,6,9] 共 64 帧（每条件首 16 帧）；不重新组 batch。正式各覆盖 576 原帧；smoke 不计入正式科学分母。

## 2. 实验一：输出链归因

**问题：** 检测断续是在 raw 候选本身、分数/两次 Top-K 还是最终竞争处发生？正确检测的混入主要对 P 变化还是 c 变化敏感？

**H 与竞争解释：** H_out：原始同类几何候选仍在，但选择/置信度使它消失；H_repr：同类候选或几何定位已衰退。另一个条件性问题 H_P/H_c：同一个中心物体的错误连接对 P/c 哪个因子替换更敏感；二者也可能强交互。不能由一个分支的阴性推出另一个为真。

**方法 A：** 前向 hook 记录真实 O2O raw 解码框、80 类分数、两次 Top-K 选中身份；核对实际最终输出框/score/class/系数的索引。对全部 1728 GT：

1. 检查是否存在 BoxIoU≥.5 的 raw；
2. 其中 cow 概率是否>.001；
3. 其中符合者是否进入按 raw 最高类别分数筛选的第一 Top-300；
4. 符合者是否进入第二 raw×class Top-300 的 cow 行并保留到导出；
5. 同类 Box50 最终行是否达到>.25；
6. 按 V2 类别无关最大有效匹配数、再最大 BoxIoU 的一对一匹配是否为 cow。

记录逐级存在性及首个失败处；第6阶段另分错误类竞争/未配对。多个 raw 不能拼成一条“框好掩码好”证据。最佳候选仅保存 GT Box50 内 cow 分数最高的一条作为诊断见证，不能替代正常预测。主量：错误/缺失正确检测中，首先损失于步骤3–6的比例，另列低分步骤2/5及几何步骤1。

**方法 B：** 中心 track=1、同 seed/frame 的 CLEAR→NEAR、REAR→FRONT，仅在两边均原生正确 Box50 配对时进行；报告全部144对的排除数。对象身份由既有 TIMELINE 冻结，不能换成更好 mask/raw。中心投影一致，使用同一压力帧 GT 评价四个组合 `P0c0,P1c0,P0c1,P1c1`；先固定压力检测框，再固定控制检测框重复。矩阵维度和非目标行不变，全部沿原生 decoder 重放。主量为压力帧的 bridge_mass；IoU/coverage 为防止“删光掩码就不混入”的护栏。CLEAR 自身不可能覆盖 NEAR 邻居位置等情境变化，因此还必须结合连续 logit 的精确双因子分解，不能把交换结果单独当自然因果。

连续量在同一原图坐标、共同可见中心 GT 上计算：`ΔP c0`、`P0 Δc`、`ΔP Δc`，验证三者之和等于总 logit 变化（FP32 绝对误差≤1e-4）；记录 RMS 和相互作用，RMS 大小本身不等于错误贡献。四个组合的 IoU/混入全部公布，不挑有利框。

**预先裁决：** 若检测失败≥10条且步骤3–6首失占≥50%，优先研究输出选择/置信度保持；若步骤1–2占≥50%，优先原始实例证据/定位形成（分数门槛步骤5单列而非称容量不足）。条件掩码归因至少60对，某单因子恢复相对 `P1c1` 的平均 bridge_mass≥.01、IoU下降不超过.01，至少2/3 seed同向，且两种固定框方向一致，才推荐该因子的选择性干预；两者均满足则优先较大恢复，但不能宣称另一因素无作用。均不满足/交互主导则不把 P 或 c 独立归罪，优先实例局部输出约束。数值身份失败为工程未决；分母不足或方向不一致为证据不足，停止本轮，不扩大样本或补训。

## 3. 实验二：采样位置稳定性

**问题：** V2 的断续/混入，有多少能在场景内容完全不变时，仅由栅格采样位置移动触发？

**H_phase：** 小整数平移引起内部表示/输出选择变化，逆对齐后仍出现检测或掩码跳变。竞争解释 H_motion：主要是实际邻居/遮挡关系变化；静态平移下变化小。H_decode：连续读出变化小，但符号阈值/预测框裁剪放大成二值变化。它们可并存，不能用不变性测试单独定位某个下采样层。

**干预：** 预固定9个原图整数平移 `(0,0),(1,0),(-1,0),(0,1),(0,-1),(4,0),(-4,0),(0,4),(0,-4)`，新露出条带 RGB=(114,114,114)，不插值、不改变原图尺寸、光照或 GT。每个 offset 保持原36批次、成员和顺序；每批只运行一次。正式 5184 张前向，smoke 576 张前向；零训练、无选幅度。原图 GT 不接触四边8像素的实例为预先有效集（GT决定，不看预测）；所有有效实例都进检测/操作IoU分母，不只保留两边成功者。比较区域固定 `[4:H-4,4:W-4]`，预测与连续场逆平移，原边缘丢失不得当稳定性错误。

**测量：** 所有有效实例相对零位移的正确配对翻转、操作 IoU（错类/未匹配=0）变化、Mask75 状态翻转。逐 offset、条件、seed 全部报告，并将±1四方向平均作为主量，±4为预注册尺度对照。另对共同正确匹配记录逆对齐 mask 一致性IoU、原生拓扑事件变化和连续 logit 的相对 RMS（同一固定 GT bbox 内，原生 logit 先映射至原图；不把它冒充最终 native mask）。连续读出另沿共同原生控制框重放，区分框漂移和读出变化。记录 raw_id/层级/网格变化，跨图 raw_id 不冒充同一实例身份。

**工程对照：** 零平移逐项复现 V2；图像平移后再逆平移在共同内部必须逐像素相同；对既有预测 mask 仅做几何平移/逆平移应恒等。连续读出符号阈值仅作辅助，最终结果仍使用真实原生 binary-resize-byte 流程。

**预先裁决：** 主量为±1条件中，原生正确配对/Mask75状态任一翻转的观测比例（每实例4方向平均后再全实例均值）。达到≥5%且≥2/3 seed≥5%，则支持将平移稳定性作为后续必要约束；低于5%则在本场景/幅度下不把采样位置当主瓶颈，优先实验一识别的输出链环节。若mask明显变化（共同正确匹配中一致性IoU<.95比例≥10%）但连续读出相对RMS中位数<.05，优先阈值/裁剪放大；否则存在表示/系数/输出变化，不凭本实验细分具体层。分母<100或身份/平移对照失败为不足/工程未决；不重调阈值、不追加训练。三个seed不是独立模型/资产，不生成把帧当独立样本的窄置信区间。

## 4. 产物、复核及停止

两个独立 Slurm 作业分别 chain/shift，每项 smoke/full 各独立 Run，锁和状态分离。smoke 只验工程（来源、身份、重放、数值、平移控制、资源），不按科学结果筛选是否正式运行。完整结果、逐对象表、RLE/所需缓存、实际参数、环境、源文件和 SHA 留存；大 P/c 缓存留服务器，哈希与必要读数回本机，明确回传范围。配置前后核验、服务器冻结统计复算与本机独立表级复算通过后结案。每个完整实验按“问题—机制假说—针对性方法—整体结果—研究决策”汇报，相对原生的诊断变化与已有方法未测状态分别说明；合并给出一个有依据的下一步，不自动启动。
