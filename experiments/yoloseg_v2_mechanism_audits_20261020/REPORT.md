# V2 输出链与采样位置核验

本报告待两项独立核验全部完成后统一结案。输出链已完成，采样位置正式 Run 正在运行；未完成项不填科研结论。

## 实验一：输出链归因（已完成）

全部 576 帧、1728 个可见 GT、14704 条原生输出精确重放。100 个正确检测失效都仍存在 Box50 raw，82 个有 cow 候选到达最终导出但未超过固定 .25 工作点，18 个 cow 候选在 raw 层已低于 .001。没有观察到第一/第二 Top-K 截断或最终一对一竞争成为首个失败点。

| 维度 | 本次实验的整体研究链路 |
|---|---|
| 问题 | V2 的中心目标失败主要伴随正确检测缺失；近邻共同正确配对仍有 55/132 实质混入。需要区分输出消失与掩码混入的计算来源。 |
| 机制假说 | 检测可能被 Top-K/工作点删去，也可能在 raw 几何或类别分数处已经衰退。条件掩码可能对 P 或 c 的情境变化敏感，也可能二者共同适应邻域而无法单独归罪。 |
| 针对性方法 | 逐级追踪真实 O2O raw、两次 Top-K、导出和工作点；固定既有配对，在同一压力 GT、两个固定框下重放四个 P/c 组合。模型、数据、批次、解码与阈值保持冻结，训练 0 步。 |
| 整体结果 | 82/100 个检测失败首次发生在 .25 工作点，18/100 在 raw cow 分数≤.001；几何候选均存在。NEAR 132 对中，实际 P1c1 的平均 IoU=.876000、混入质量=.011987；换回 P0 后 IoU−.035948、混入质量+.068098；换回 c0 后 IoU−.001533、混入质量+.009138。两个框锚、三个 seed 均未支持“恢复单因子即可修好”。 |
| 研究决策 | 优先关注已定位实例的类别置信度形成与保持；本数据不支持把断续归于 Top-K，也不支持直接恢复分散场景 P/c。P/c 替换准入未通过，停止此恢复思路，不追加训练。两项实验统一的唯一下一步将在采样位置核验完成后裁决。 |

### 分母与读数

| 场景 | 正确检测 / 全可见GT | 工作点首次失效 | raw cow 分数首次失效 |
|---|---:|---:|---:|
| CLEAR | 430/432 | 2 | 0 |
| NEAR | 395/432 | 32 | 5 |
| REAR | 430/432 | 2 | 0 |
| FRONT | 373/432 | 46 | 13 |
| 合计 | 1628/1728 | 82 | 18 |

中心 GT 独立分母：CLEAR 143/144、NEAR 132/144、REAR 143/144、FRONT 129/144。对应 NEAR/CLEAR 144 对中排除12对、FRONT/REAR中排除15对；仅条件掩码交换排除这些配对，完整检测账本没有排除。

NEAR/压力框四组合（同一压力 GT）：

| 组合 | 平均IoU | 混入像素/目标GT面积均值 | 实质混入比例 |
|---|---:|---:|---:|
| P0c0 | .838567 | .081453 | 61/132 |
| P1c0 | .874467 | .021124 | 57/132 |
| P0c1 | .840052 | .080084 | 61/132 |
| P1c1，原生压力输出 | .876000 | .011987 | 55/132 |

换回 P/c 后混入增加，而不是消失；不能把这种混合重放当作部署方法。分散图的完整物体与近邻图的可见 GT 不同，控制场景的 P0c0 在压力 GT 上不代表控制场景原生精度。两个固定框的结论方向一致，避免把框裁切变化记给 P/c。连续分解最大绝对误差 4.77e−6，小于预先冻结 1e−4；这是浮点恒等式核验，并不证明哪个内部通道具有语义因果作用。

相对原生：上述是 GT 辅助交换读数的退化，没有新增可部署方法收益。相对已有 G/G_budget/LCF：本合成集合未运行这些方法，增量未测；不把其历史 COCO AP 和本处条件 IoU 拼接比较。

边界：只定位到“类别置信度不足”，尚未解释该分数为何下降；不等于只需降低阈值。82条中最佳 cow 候选分数的补充描述性中位数约 .09563，并非都仅略低于 .25。当前 P/c 更适配当前场景的交换结果，也不证明共享原型没有其它结构限制。3个 seed 共用同一资产/渲染体系，不能把1728条观测当独立模型/现实样本生成窄区间。
