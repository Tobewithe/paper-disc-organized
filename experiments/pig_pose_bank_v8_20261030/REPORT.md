# 有限姿态构造与同角度蒙皮对照

完成8个固定姿态的全网格核验和16张双视角实际审核。**站立、左右转头、轻度左侧卧共4项在固定姿态范围准入；腹卧与强侧卧失败，完整姿态库及正式合成数据仍未合格。** 随后对同矩阵DQS的5例对照没有新增合格大屈曲姿态，停止把更换蒙皮作为这批角度的解决方案。

| 维度 | 本次实验的整体研究链路 |
|---|---|
| 问题 | V7仅修复rest，不能证明站/卧有效；原侧滚站立体重复且不足自然，屈腿后身体支撑和表面是否同时合法未核。 |
| 机制假说 | 大屈曲的LBS变换混合可能使关节塌缩；竞争解释为固定关节目标/源rig表面本身不允许该构型，更换插值仍失败。先以真实姿态失败定位，再固定同矩阵比较，属于工程机制判别，不是新模型方法效用实验。 |
| 针对性方法 | 在V7固定修复rest上冻结8矩阵、全网格交叉/面边比/支撑护栏；802渲染8姿态×2视角并全部实际查看。后继V9只换LBS为DQS，5例相同矩阵、源网格/权重/骨架/评价不变；identity、root刚体、one-hot骨权重、反号不变性四夹具先通过。禁止真实标注、旧拟合、训练或事后调角追通过。 |
| 整体结果 | LBS：站立/头±8度/左侧卧15度四项数值及双视角准入；两腹卧各506自交，强左/右侧卧各6自交。腹卧472/506及467/506在各腿自身，另34/39在躯干—后腿；强侧卧均前腿自身。实际腹卧图像呈蜷蹲/蛙状屈腿并有表面凹陷，不能准入。DQS：stand维持0，两腹卧506→492/624、强侧卧6→12/12，四个失败姿态全部仍不合格。夹具最大坐标差1.67e-16，无明显实现错误证据。实际泛化/AP增益、与下游原生/已有模型的收益损伤未测，无训练。 |
| 研究决策 | **保留4个固定姿态，优先求解带末端/躯干接触目标、关节范围与碰撞约束的姿态可行域。** 同角度换DQS没有解除问题，削弱“只换插值就能得到合法卧姿”的解释；不把该阴性外推为所有DQS无效。关闭本批大角度配置与其DQS直接替代，不再扩大平滑或随机角度网格。唯一下一步是锁原蒙皮，在地面支撑目标下检验合法关节构型能否形成腹卧/右侧卧；若预算内不可行，登记该rig缺少卧姿能力，进入明确的姿态纠正资产建设，而不是扩大不合法样本。该受限求解尚未启动。 |
