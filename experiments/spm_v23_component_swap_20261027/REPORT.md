# V23.2：旧/新原型候选与决策器交叉验收

本实验完成432张真实正常输入、2863个GT和12899条相同检测上的完整2×2交叉，0次优化。只换候选的C1R0达到60.846479，较原V23增加.093200点；全部护栏通过，但不足预冻结的+.1替换条件，因此推荐仍为原V23，关闭本次复合重加权扩训。

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | V23.1真实训练后整体AP60.753278→60.738777，AP75提高而AP50和密集源下降，两个既有对角无法判定是哪段更新抵消了收益。实际候选39个state张量与风险器均变化，故不能直接再加训。 |
| **机制假说** | H为一段更新产生有用候选，被另一段或接口分布交互抵消；竞争解释为两段没有达到可保留幅度的条件收益。交叉至少一个比V23高.1点且护栏通过才保留，否则停止本复合训练改法。 |
| **针对性方法** | 固定N/C21/检测身份/26动作及原架构，C0/R0取实际V23，C1/R1取实际V23.1；四组共享确定计算并与四次原部署逐值核验，两个既有对角全432图RLE精确重放。两个交叉只交换实际state，不插值、不增加网络/参数、不读GT部署。完整官方统计与逐GT结果独立复算。 |
| **整体结果** | C1R0较V23+.093200、较N+3.502978、较C21+.429952，损伤17/2126；C0R1较V23−.007035，损伤18；C1R1较V23−.014501，损伤19。全部Box12项/行身份精确、Box75损伤0，Mask75/三尺度及损伤≤21均通过；所有组仍未到N+5。R1在C1下−.107702，交互−.100666，存在确定的条件抵消，但没有交叉达到预冻结替换幅度，不把微小AP差称显著性。 |
| **研究决策** | 保留实际正收益V23，停止此复合重加权方向扩训。我选定优先改善原型候选在正常实例输入下的匹配与训练—部署一致性，保留原R0；依据C1R0的有限正向证据、R1负条件效应及V25/26质量头失败。唯一下一步是用既有train核正常top1与64候选的任务质量/训练责任后验，判断是否有系统性可用候选漏选；有才另冻匹配训练对照，无则停止匹配器扩训并聚焦真实支持的原型内容。该必要条件尚未执行，不宣称新匹配方法有效。 |
