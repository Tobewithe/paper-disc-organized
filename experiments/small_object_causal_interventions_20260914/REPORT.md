# 小目标失败的受控因果干预与 P3 层定位

在同一 384 对小目标失败/成功对照上，GT 辅助干预只用于机制定位。增强目标与局部干净背景的亮度对比，使失败组最佳原始框 IoU 平均增加 0.0700（0.0570--0.0837），恢复 102/384 个 Box50；移除近邻增加 0.0369，恢复 82 个；联合干预增加 0.1022（0.0862--0.1188），恢复 146 个。成功对照的联合变化仅 +0.0067，区间跨零。

对比度剂量 7/14/28/42 对应恢复 46/67/102/141 个失败目标；软边界干预仍恢复 61 个，将同样的掩码平移到邻近背景仅恢复 23 个。近邻模糊和均值化分别恢复 124 和 143 个，而成功对照平均 IoU 为 -0.0005 和 -0.0077。结果支持低目标可分性与近邻干扰是该失败类的致因成分，不能泛化到所有目标。

固定原图其余特征，只把干预图的检测头输入替换到原图：P3 全图/局部分别复现 +0.1009/+0.1005 IoU，恢复 138/135 个；P4 为 +0.0197，P5 为 +0.0045。机制主要通过目标局部的 stride-8 检测特征改变框几何，类别分数变化很小，不涉及 Proto26 原型输出。由此启动训练期反事实视图引导的 P3 定位实验；测试时不得使用 GT 或编辑图。
