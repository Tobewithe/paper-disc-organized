# Blender 场景域诊断：外观放大过删，不能归结为合成无法拟合真实

已完成8个真实参考布局的三维复刻、32张材质/光照对照，以及冻结原生与V18融合模型的64张正常RGB评价，新增训练步数为0。**当前融合读出会删除正确前景，参考外观使这一问题明显加重；栏杆标注口径也影响相对成绩。证据不支持“只因合成无法迁移”，也没有证明合成数据在原则上不能拟合真实场景。** V18完整432张开发集的−9.646437 AP点阴性保留，本次小子集不替代全量结论。

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | V18在固定原生框和检测行时，Mask AP由57.343500降至47.697063，正确前景被误删、漏分增加。它的最后阶段已使用1272张真实train，因此“完全没训练过真实域”不是事实。用户要求用真实布局的Blender对照判断域差距是否解释退化。 |
| **机制假说** | H_domain：旧单猪合成缺少真实栏位、尺度、外观和照明，冻结融合系统会随同布局外观而系统改变相对原生表现。H_readout：当前实例重建/残差与正确前景保护不足，简单合成中也会出现同框IoU下降、FN增加。两者可并存；另检验栏杆扣除与轮廓补全的目标差异。 |
| **针对性方法** | 四个旧dev来源各按固定SHA取2张，8参考/73对象；六姿态各取4张旧clean合成，共24张。新场景为8布局×2材质×2照明，每布局几何、相机和标签完全相同。冻结C30与原生，正常输入只含RGB，两臂每图共享正常检测，GT仅用于搭场景和评价。严格可见GT为主，另用同预测评价仅补回栏杆的辅助GT；材质响应另固定四种外观都检出的41个GT。 |
| **整体结果** | 简单材质/统一光照相对原生+1.811 AP点，参考材质/参考照明−5.681点；共同41GT的等布局材质响应−0.130084 IoU，6/8布局为负，达到预冻结描述标记。**四种新外观的同Box75平均自身Mask IoU全部下降，FN全部增加**，所以简单场景AP阳性不等于实例重建可靠。仅改变栏杆GT口径，简单场景增量由+1.811变为−0.832点。旧24张有383条输出但0/24 Box75匹配，无法据其Mask AP=0判断读出能力。与其它历史融合方法的额外增量未测；本次是诊断，不是新算法效用或独立机制归因。 |
| **研究决策** | **我主张优先研究跨外观稳定、保留正确前景的实例原型读出。** 它同时对应所有外观下的过删和成对材质响应，比单纯扩充库或增加相似渲染更有直接依据。唯一后继是先统一真实/合成的栏杆遮挡目标，并把同实例跨外观的正确前景保留写入下一版准入合同；当前C30关闭加训，本轮结案，后继训练未启动。只有独立冻结的新方案在一致目标下保住原生TP，并通过全量正常输出效用及损伤护栏，才改变当前方法取舍。 |

材质响应定义为：每个布局先对共同GT求“融合IoU−原生IoU”，在两种光照下取平均，再求参考材质减简单材质，最后对8布局等权平均。结果−13.0084 IoU百分点、6/8为负；0.02和6/8是预冻结实用响应标记，**不是独立统计显著性**。布局2/3的栏位母猪响应最强；正常框随外观可以变化，因此这是冻结完整系统的响应，不能唯一归因到记忆库、查询器或细化网络。参考材质同时改变身体、地面和金属，不能单独归因皮肤纹理。

真实GT叠图显示部分人工轮廓包含前景栏杆；这不代表所有标注都如此。辅助GT只去掉三维栏杆，保留猪与猪遮挡；它与严格可见GT的差说明评价/监督目标语义需要统一，**没有单独证明训练退化由标注冲突造成**。真实GT和原冻结成绩完全未改。

三维复刻包含母猪/仔猪尺度、六种姿态、三维栏位、红色漏缝地面、IR圈舍、黑色视野与画布填充，没有使用真实猪RGB贴片。资产仍只有一个283顶点/562三角的风格化模型；相机、隐藏身体和姿态是近似。各布局渲染严格可见轮廓对真实GT的平均IoU依次为.6862/.7048/.7099/.7244/.7690/.7541/.3977/.4346，拥挤布局6/7拟合较差，全部保留。**这些场景足以检验同几何外观响应，不能冒充照片级真实重建，也不能用于宣称合成已达到真实覆盖。**
