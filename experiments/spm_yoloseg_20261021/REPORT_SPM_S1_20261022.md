# SPM-S1 服务器最小接触表征试验：在P0覆盖Gate停止

2026-10-22已在算力服务器真实执行226张PigLife训练图的输入/接触标签核验，Slurm181正常结束，耗时84.42秒。**只有4个推断来源组达到预冻结覆盖要求，未达到8组；因此没有提取模型特征或训练探针。** 该结果说明本轮固定采样不足以回答表征问题，不是YOLO特征或原型方法的阴性结果。

| 维度 | 本次完整试验的研究链路 |
|---|---|
| 问题 | 群养猪的同类接触边界是否具有超过普通像素边缘的冻结特征可读信息？V3提出这个必要条件，但此前没有本线Run。训练前必须先有足够且可追溯的接触来源支持。 |
| 机制假说 | H：P3局部邻域可能包含额外接触线索；竞争解释为像素边缘/位置足够，或C对B只反映背景比例。执行前将C对I设为主任务，两者局部fg占比均≥.98；C对B保留为辅助。没有取得特征/分数，不作机制判定。 |
| 针对性方法 | 固定原train每视频均匀最多6帧，共226图/38视频/2168源标注；历史test排除。原分辨率mask栅格化后共同letterbox至640，在P3网格按同一规则采C/B/I。按文件名相同前缀合并clip/style，17个推断family；只有各类≥16个token的family才eligible，至少8个才允许划train/dev并开后续阶段。YOLO、原型全部0更新。 |
| 整体结果 | 输入逐图与标注SHA通过。55/226图产生C采样位置；最终C/B/I分别212/5424/4813个token（每图每类上限24，**不是接触事件数或原始边界像素总数**）。17个family中仅4个eligible，未形成dev划分。未计算probe AP、COCO AP、相对原生/已有方法增益和损伤：因P0未通过，这些均未测。 |
| 研究决策 | **关闭本轮固定226图probe配置的继续执行，不降低门槛、不换图、不追加训练。当前最应优先解决的是“真实接触来源是否足以支撑分组比较”，依据是接触仅见于55图且合格来源仅4组。唯一下一步建议：对已有原train全部标注做一次零训练接触来源普查，区分均匀6帧漏掉稀有接触与整个来源本就不足；足够则另冻接触覆盖采样合同，不足则优先补有可见实例标注的独立接触来源，暂缓纯外观原型大库。该普查尚未启动。** |
