## 0. 一次实验的科学闭环

| 维度 | 本 Study 要回答的完整问题 |
|---|---|
| 问题 | 群养猪局部遮挡/相似外观下的可见实例 Mask 漏分或黏连，能否通过跨图像视觉记忆缓解？ |
| H | 合成+真实局部特征形成的冻结原型，条件调用能够提高困难场景的可用局部信息。 |
| H_alt | 同量 Blender 训练、普通参数/注意力容量、域随机化或阈值优化足以获得同效收益；合成捷径可能有害。 |
| 针对性方法 | 同数据同预算 YOLO26-Seg 基线 + 动态发现/冻结记忆 + P3/P4 Top-k 检索/残差门控，并匹配无记忆容量对照与置乱干预。 |
| 预测及决策 | 若在预注册真实测试的 Mask/遮挡指标上稳定胜过混合数据基线和无记忆对照，且内存置乱按预期损害对应增益，才晋级完整论文；否则明确归因于数据/容量或停止该机制。 |

## P0. 先做无正式训练的输入/代码审计（唯一下一动作）

- 数据：清点 PigLife、自采及其它公开数据真实文件、许可、bbox/可见 Mask 格式、video/pen/site 身份、漏标与边界标注；生成 `dataset_manifest.json`、`splits.json`、hash 和可视化抽检报告。
- 划分：训练、开发、独立测试按**视频/猪栏/猪场簇**分组；随机逐帧 8:2 不允许替代独立验证。训练/开发之外任何图像不得参与原型或超参选择。
- Blender：核已有 3D 资产、姿态动画、材质变化覆盖、物理遮挡、可见/完整 Mask 与相机标签一致性。先生成小规模实例可见 Mask 验证集（数十张 smoke，非正式训练数据）。
- 模型：选定 YOLO26-Seg 尺度与精确 `ultralytics` commit、权重 SHA、Neck P3/P4 形状和 `Segment26` 真实接口；复算原始基线同输入推理输出，确认 one-to-one、mask 解码与评估器。
- 资源：测单卡显存、batch、渲染时间/图、前向耗时，制定训练步数、预算、运行环境和随机种子；不自行登陆任何远程服务器。
- **Gate P0：** 所有标签和划分合法、模型原生评估可重现、模块插入点与指标口径明确后才冻结 P1；缺失先修，不直接渲染数万张。

## P1. 两个公开可比的原生基线

- **A（REAL）：** 官方原生 YOLO26-Seg，仅用训练部分真实数据。
- **B（MIX）：** 与 A 相同初始化/损失/输入尺度/步数，在相同真实图基础上加入 Blender 合成训练图；需明确训练图数量与抽样调度，使 B 与后续知识模型训练输入保持完全相同。
- Blender 候选首次正式规模 3,000 张（稀疏、中密度、高密度各约 1,000），是**待冻结设计值**。先核视觉真实性/标注与域差后可调整，正式 Run 开始后不得事后改规模挑好结果。
- 在真实独立测试上记录 Box/Mask mAP50–95、AP75、AR/Recall、分组密度和遮挡召回、推理延迟/显存；B 若退化，先检查合成图域差而非直接堆记忆。

## P2. 视觉编码/原型发现（只用训练划分）

1. 冻结 B 的 Backbone/Neck，从训练图提取 P3/P4 特征；编码器锁定到实际 commit 和权重。
2. 各尺度训练 128D 投影，增强视图使用几何对应关系；以前景 Mask 采样猪体 token、背景 Mask 采样环境 token，训练/验证来源均衡。
3. 用 DP-means 风格聚类创建、更新、合并原型，记录 λ、样本上限、遍历顺序、K、簇占比、真实/合成域覆盖；和固定 K-means 结果做初步无训练诊断。
4. 将原型、投影层、数据/权重/代码 SHA 保存并冻结，检查在**未用于构库的真实开发样本**上的原型检索相似度及低支持占比。
5. **Gate P2：** 若原型仅记住渲染纹理、真实域几乎不匹配，先审视 encoder 或采样而非大规模训练增强模型。

## P3. 注入模块工程合法性与小样本 pilot

- 原始 Neck P3 进入 `Segment26` 前做 `F'=F+alpha*g*Wo*retrieved`；启动仅 P3，原 Mask head 不改，P4 仅经 P3 证据支持后扩展。
- **zero-alpha 测试：** 同输入、同 checkpoint、eval 下原始 YOLO 与新模型 Box/Mask 及中间输出在预定容差内数值一致；对训练分支、辅助头、梯度、加载/保存、推理/导出分别做检查。
- **梯度检查：** alpha 非零更新后 gate/query/projection 的有效梯度、原型 buffer 不被修改；解冻 Neck 前后查询空间一致性需要明测。
- 仅有工程 smoke 和有限 pilot 后才评估是否值得正式实验；如零残差不等价、计算爆炸或检索分支从未使用，修复或关闭，不把非正常结果写论文。

## P4. 最小论文实验矩阵（与 B 同数据、更新步数和评估口径）

| 臂 | 输入与原型 | 检验 |
|---|---|---|
| A REAL | 仅真实数据的原生 YOLO | 合成数据的整体效应基础 |
| B MIX | 真实+合成数据的原生 YOLO | **严格主参照** |
| C REAL-MEM | B 相同数据/权重初始化 + 仅真实训练划分构库 | 真实原型是否有效 |
| D SYN-MEM | 同 B + 仅 Blender 构库 | 合成原型跨域是否有效 |
| E DUAL-MEM | 同 B + 合成/真实联合构库；固定训练投影预算 | 两来源是否互补 |
| F GATED-MEM | E 的记忆 + 条件门控/Top-k（目标方法） | 动态调用能否提升 E |
| G CAPACITY | 同 B + 尽量等训练参数/计算量的普通残差/MLP，**无检索记忆** | 排除单纯参数与结构增益 |

若 E 不带条件门控，其融合形式（如固定权重残差）必须在冻结前明确，不能让 E 成为完全不同容量的弱基线。C/D 的原型数不同时，报告 K 及推理 FLOPs，并尽量补充匹配检索预算比较。

**定向干预（固定 F checkpoint，无训练）：** 禁用/置乱检索、随机替换冻结原型、仅 fg / 仅 bg 查询，记录对应 GT 困难子集、总体损益、gate 激活、额外计算。必要时追加固定 K-means 与动态 K、P3 vs P3+P4 消融。不得用不匹配容量的极弱对照宣称因果机制。

### 预冻结主评价

- **主指标建议：** 实际正常推理、真实独立测试集 `Mask mAP50–95`，单位 AP 点；bbox 与 segm COCOeval 各自独立匹配。
- **支持指标：** Box mAP50–95，Mask AP75；按可见面积/遮挡比例或场景密度**在看结果前**定义的困难子集 Recall、AR、误检与实例黏连/分裂诊断。
- **成本/护栏：** 端到端 FPS 与延迟、显存、参数/FLOPs、正常样本损伤及场景变化影响；输入尺度与部署环境一致。
- **统计：** 以独立视频/猪栏/猪场为聚类重抽样单位，开发集调参、最终测试一次性评价。需冻结种子、样本数量、区间方法和最低有价值改善（例如初步目标 +1～2 AP 点仅作讨论，不自动构成期刊录用门槛）。
- **禁止信息泄漏：** 原型学习/聚类/查询不能看到独立测试 GT；无 GT 正常推理不可借用 Blender 的真值可见信息，测试/可视化只用于评价和机制分析。

### 正/负/信息不足与资源退出

- **正向：** F 在冻结的总体/困难子集读数超过 B 与容量对照 G 的预定最低效应，且定向记忆干预产生方向一致的证据、护栏可接受 → 进入独立确认/论文写作。
- **阴性：** 合法比较显示 F 与 B/G 无有意义增益，或增益仅等于 B−A 的合成收益，或记忆置乱不影响表现 → 不扩库、不并行叠加注意力/loss；优先保留有效的合成数据处理线索。
- **信息不足：** 样本簇过少、置信区间大、版本不一致、随机泄漏、域错配或训练失败 → 先修复该具体问题；不能当阳性也不等于理论不可行。
