# 系数oracle空间归因

继承 `coefficient_predictability_20260924` 的官方 one2one 正样本、原型与逐实例有限步 oracle 系数。固定原型和原始预测框，用同一图像的原系数与oracle系数解码，在640方形标签坐标对比阈值0的掩码。

对每个目标只在**原始预测框内部**统计：补回目标真阳性、删除原误报、误删真阳性、新增误报。邻居与背景由官方 `overlap_mask` 标签图区分；实例边界带为目标GT边缘内外各5像素，目标内部和框内GT外区域分别统计。另记录未裁切的全图变化，但不把它解释为可部署掩码收益。像素集合互斥地归于四种修正结果，因此可定量区分“补自身”“去泄漏”“两者兼有”。

主要结果按原Mask75失败/达标、oracle后Mask75修复与否、预测框IoU是否达0.75分层。200个实例是旧实验按100失败+100成功选出的诊断样本，不代表COCO总体发生率。系数oracle由GT优化，以下是机制定位而非推理时可用的方法；推断不自动外推为训练共享头能实现同样修复。
