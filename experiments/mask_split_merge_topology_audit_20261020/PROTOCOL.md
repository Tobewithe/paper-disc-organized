# STA-v1：共享原型—系数的分裂/粘连与拓扑稳定性审计

2026-10-20，用户调整核心问题并授权先复用已有产物。SSR保持用户终止；PLF已准备冻结但未执行科学求解，暂缓。本Study独立，不插入或改写SSR协议，不训练拓扑网络，不新推理、不新求系数、不构建新扰动。执行端为笔记本YANGLEI，CPU分析已有二值RLE。

## 整项研究链路

**问题：**原S1固定256条只找到122个Mask75见证，后续有限C找到159个，但可部署兑现有限。已知IoU收益不能说明局部连通性保持；原RSM已有24方向压力掩码，可复用观察稳定性。新问题是实例内部的空间全局耦合是否妨碍局部连通性的独立稳定控制，不能简化为“32维不够”。

**机制假说H：**Δc改变实例内所有原型响应位置，局部修复可能牵动远处连接/分离关系，产生分裂或粘连。固定P时各实例的c_i仍独立：改c_i不会直接改变另一检测的mask_j；“共享P”不意味着实例系数之间有数学上的直接绑定。H_alt：误差主要是漏覆盖/边界偏差，或二值化/缩放使小像素变化触发拓扑变化；这些现象不需要特定全局耦合解释。

**预测及权限：**若N、G、GT辅助C中存在有实质像素质量的残留分裂/粘连，且有效压力下可出现低像素变化但连接关系翻转，则支持把局部连通控制列为具体科学问题。若主要是漏覆盖或单像素碎屑，削弱用拓扑解释当前主要瓶颈。现有产物没有同质量、同幅度的局部解码匹配干预，没有固定P的拓扑全局最优解，因此本轮最多提供现象/定位/相关性证据，不能证明全局耦合因果、固定P拓扑不可达或转向的新方法有效。

## 2. 错误定义：先匹配GT结构，再谈分裂粘连

主分析8连通，N/S1/C/G端点额外固定4连通作敏感性检查，不择优。无形态学处理、填洞、删小连通域或面积筛选。背景缺口、洞和拓扑同伦均不由本轮指标完整覆盖；本轮只测连通分裂、假连接和跨实例混入。

**分裂：**对GT的每个真实连通部件，统计与之重叠的不同预测连通部件。至少两个才记分裂；完全漏掉的GT部件单列为漏覆盖，不记分裂。分裂像素量为各GT部件内“已覆盖像素数−最大预测部件覆盖像素数”之和，除以完整GT像素面积。GT本身多部件不自动记预测分裂。

**跨实例粘连候选：**先构造目标GT排除所有其他普通GT后的独占核心；邻居区域使用邻居GT排除目标GT后的像素。某同一预测连通部件同时触及目标独占核心和邻居独占像素，记跨实例混入/粘连候选，报告邻居ID。预测在多个GT交叠区内的合法重叠不计。邻居像素取并集避免重复计数，除以目标完整GT面积。目标没有独占核心者标不可判，不能算无粘连。这不是单凭任意mask重叠就断言粘连。

**同实例假连接：**同一预测连通部件连接GT两个原本独立的可见部件，单列；不把可见多部件GT强迫连成一个。另记不触及目标GT的预测孤岛数、GT部件漏覆盖数、覆盖率、IoU、GT/预测部件数。后两项计数相等不能替代对应关系正确。

原始任意像素告警和连续像素量均保留；“实质分裂/混入”仅固定为对应像素量>=GT面积1%，不扫阈值，不称普适拓扑标准。单像素噪声与实质错误分开交付。

## 3. 比较、已有扰动和阶段定位

共同256条上报告N/S1/C/旧G的IoU、分裂量、粘连量、漏覆盖及拓扑告警，C−N、C−G分别交付；S1未找到134、C未找到97、C见证159交叉统计。GT辅助C的收益不是可部署AP，未测原成功GT损伤。输入网格已有N/C及目标GT另算同GT部件分裂；只作“在哪个已保存阶段可见”的读数，目标投影与原图栅格化变化保留，不能仅由阶段差异证明缩放是唯一原因。

6144个既有C压力结果全部保留描述。每个方向独立核C_actual_rms和C_decoded_difference_rms相对原pressure_amplitude的偏差均<=5e-5才进入有效压力子集；同时报告失效数量/分母，不能使用原W失效替代C的精度判定。不得为得到有效子集改幅度或生成新方向。主分析C的24方向，不作W稳定性优越性声称。

与各自无压力C比较：原图IoU差、对称差像素/并集、分裂事件、粘连邻居集合、假连接、孤岛/漏部件事件变化。固定小像素变化为对称差/并集<=1%，报告其中结构告警翻转及连续错误量，不把一次翻转直接当不可学习。另计同时“修正旧错误像素/破坏旧正确像素”的配对，作为空间改动牵连的描述，不能取代局部干预对照。

统计先实例内24方向平均、再图内配对平均、最后243图等权；2000次图像bootstrap，seed1729，不能把6144个方向当独立样本。主结果完整分母并附压力有效分母。敏感性4连通不用于选主结论。

## 4. 执行与决策

先合成测试：GT多部件、漏掉整个部件、真分裂、真跨实例桥、仅GT交叠、同实例假连接、4/8对角差异、空预测。通过后冻结，执行一次正式CPU Run；不需重新模型smoke。资源：CPU两线程以内，RSS<=3GiB，2小时总墙钟，新产物<=1GiB，D盘保留>=12GiB。不训练、不新模型forward、无GPU计算、无定时任务/目标、无自动提交推送。输入身份或IoU复核失败即中止，保存错误。

按实验展示范式交付整体报告、完整逐实例/逐方向记录、bootstrap、配置审计和SHA。审计没有训练效用Gate，不借新阈值回判旧S2/S3/RSM。

**研究决策出口：**若实质分裂/粘连在C失败对象仍存在，且已有小像素变化揭示连接脆弱性，优先设计“同质量与同功能扰动下，全局系数/独立局部编辑”的定向可控性核验；不马上训练拓扑网络。若现象主要是漏覆盖或噪声，停止把拓扑设为首要归因，优先解决有实际像素质量贡献的误差。若邻居/压力精度/数据不足，明确未决并只补决定路线的最小证据。任何结果都不能用“有限oracle没找到”冒充“最优系数也不能”；长期转向表示形成或局部生成需要进一步的任务可达性/匹配干预依据。

连通性实现依据：[SciPy label](https://docs.scipy.org/doc/scipy-1.15.2/reference/generated/scipy.ndimage.label.html)。本轮不采用clDice或其管状结构拓扑假设作为COCO通用GT先验，不引入拓扑loss。
