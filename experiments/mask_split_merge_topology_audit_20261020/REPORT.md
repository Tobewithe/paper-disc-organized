# 分裂—粘连拓扑审计：整体结果与研究决策

2026-10-20，笔记本YANGLEI CPU。正式Run **RUN_STA_FULL_8c945ee7c7e2483483952bb56ebad3cd** 完成原256条/243图及6144个已有C压力掩码；新增训练、模型前向、系数求解均为0。**Mask75达标不保证连接关系可靠，局部连通控制值得成为具体研究问题；本轮尚未证明全局系数耦合是原因，更没有证明固定P的最优解无法保持拓扑。** SSR保持停止，PLF暂缓。

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | 现有IoU评价会遗漏哪些分裂与粘连？原有限C已找到159条Mask75见证，但这些答案是否也保持了GT的可见部件关系和与邻居的分离？原生、旧G、有限Oracle及已有扰动提供了固定配对下的直接可复用证据。 |
| **机制假说** | 全局Δc同时作用于实例内多处空间响应，可能妨碍局部连接的独立保持；竞争解释是漏覆盖/目标函数取舍或阈值与栅格化导致的小像素离散变化。改变一个实例的c不会直接改变另一检测的掩码，不能把共享P误说成实例系数直接绑定。现有产物只能检查必要现象，没有同质量局部干预，不能单独归因。 |
| **针对性方法** | 固定原256条及同最终检测，分析N/S1/C/旧G的原图二值RLE及已有N/C输入网格；GT真实多部件、漏部件、分裂、邻居独占区混入分别计数。8连通为主，4连通端点敏感性；无删碎屑/形态学操作。实质分裂或混入固定为相关像素量≥GT面积1%。复用6144个C压力结果，核原双读数5e-5精度；图等权与2000次图像bootstrap。 |
| **整体结果** | C未找到Mask75的97条中，47条有实质分裂/混入告警；C已达到Mask75的159条中，仍有58条告警，证明IoU成功与连接可靠性应分开报告。全256条实质分裂N/C/G为28/22/25，实质跨实例混入候选106/92/110。C相对N/旧G的原图图宏IoU分别+0.135158/+0.127930，但这是既有GT辅助有限解的收益，不是本审计新增部署效用。C混入像素量显著下降，说明固定P与系数确有改善能力。408个变化像素≤1%的有效压力结果中，63个广义拓扑签名变化、16个分裂/粘连事件变化，仅3个实质告警变化；不能将细碎离散变化夸成普遍主要结构瓶颈。 |
| **研究决策** | **优先研究“局部切断错误桥接时，能否保持目标自身及远处正确部件的连接”，暂不继续调Adapter或启动拓扑网络。** 依据是剩余跨实例混入多于分裂、且IoU达标后仍有告警；这比笼统“32维不够”更贴近实测失效。但C能消除部分错误、低像素变化下实质翻转较少，限制了“已证明结构性不可控”的解释。**唯一下一步：设计并冻结全局系数修正与独立局部编辑的匹配可控性对照**，控制端点质量、编辑预算与扰动尺度，检验去除局部错误连接是否必然伤及其它正确连接；尚未启动。若匹配对照不能显示这种独立性差异，停止把全局耦合当主因；只有充分可达性与因果证据后才决定长期局部解码训练。 |

通俗地说：现在的系统有时“轮廓大体画对了，但该分开的地方还黏着、该连起来的地方断着”。不过，不能因此断言原型机制天生做不到——现有系数优化确实已经修掉部分这类错误。下一步应直接比较局部编辑的可控性，区分“答案做不到”和“现有目标没要求它做好”。

## 扰动与解码阶段

原C的6144/6144个方向都满足本轮复核的C分支原双读数5e-5要求。旧RSM整体数值未决主要包含W分支问题；本轮C有效不撤销旧RSM的任何Gate。

- 同原10% C-logit-RMS压力，C原图图宏IoU变化−0.006725，95%区间[−0.008415,−0.005078]。
- 广义拓扑签名翻转率28.44364%，区间[24.54190%,32.18493%]，包含孤岛/漏部件计数，不能全部叫分裂粘连。
- 分裂/粘连事件翻转率14.55190%，区间[12.16557%,17.00674%]；实质告警翻转率9.16495%，区间[7.20143%,11.41139%]。
- 408个对称差/并集≤1%的方向中，广义签名翻转63/408，分裂/粘连事件16/408，实质告警仅3/408。这些为重复方向的描述性计数，不能当408个独立样本作总体显著性声称。
- 原生输入/原图分裂分别55/55条，其中53条两阶段均有；C分别38/36条，其中35条两阶段均有，只有1条仅原图出现。多数已观察分裂在第一次阈值阶段就存在；输入GT投影与原图栅格化也不同，不能据此证明缩放从不影响拓扑。
- 4连通端点敏感性：实质分裂N/C/G=28/21/25，混入=106/92/110。主判断不依赖选择更有利连通规则。

## 主张与边界

| 主张 | 本轮证据裁决 |
|---|---|
| IoU≥.75保证可靠连接 | 被本审计定义下的58/159个实质告警反例削弱；阈值及GT可见结构范围需明示。 |
| 固定P上的系数没有控制拓扑的能力 | 不支持：C消除17条分裂、28条混入候选，并显著降低混入像素量。 |
| 所有Oracle失败主要是分裂/粘连 | 不支持：C未找到的97条仅47条有已定义实质告警；另5条混入不可判。不能将其余对象都归该因。 |
| 微小像素变化普遍造成实质拓扑灾难 | 当前证据较弱：小变化方向实质告警翻转3/408；应与广义噪声计数分开。 |
| 共享原型的实例内全局耦合造成上述错误 | 待证：缺少相同质量/预算的独立局部干预；现有结果是现象与关联证据。 |
| 固定P的全局最优系数不能稳定保持正确拓扑 | 未证明：现有S1/C/W均为有限求解；未做拓扑可达上界认证。 |
| 应直接训练拓扑网络/采用clDice | 本轮不授权且缺方法证据；COCO可见GT也不能套用单一管状拓扑先验。 |
