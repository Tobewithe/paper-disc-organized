# 框内空间证据与原型投影：固定候选评价

本轮未同时通过固定收益与全体性能守护条件，按有限协议停止。

主对象为val中原Box IoU≥0.75且原图Mask IoU<0.75，共1115张有效图片、3059个候选。主比较S−D图片macro IoU差为+0.1226 [-0.1679, +0.4174]个百分点。
主对象S−D至少+0.5 IoU百分点且95%CI下界>0，同时该组S−A下界>0；全val S−A的95%CI下界须>−0.1百分点，排除更差于预设margin才称守护通过。其它指标全部报告，不要求全部改善。失败即停止，不自动调参或扩训。

冻结官方one-to-one TAL候选、原型、预测框、类别、分数及解码，仅系数变化。固定最后第12轮checkpoint；smoke使用零初始化而非训练checkpoint。本评价不是完整推理COCO AP，也不声称新的盲测。
