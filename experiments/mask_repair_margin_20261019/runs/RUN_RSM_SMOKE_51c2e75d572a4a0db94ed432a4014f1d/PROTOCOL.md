## 4. 唯一干预：同掩码、同尺度的系数重新居中

令 B 为固定 P 按原生第一阈值前几何双线性上采样后、预测框支持内的 FP64 线性算子；z=Bc。H=B^T B/n，若不满秩/数值病态（最小特征值<=最大特征值*1e-12）则本条数值未决、保留 C，不偷偷截断秩或加正则。

使用 H 的对称逆平方根 T，X=BT；u=H^(1/2)c/RMS(Bc)，则 ||u||2=1。C 的实际原生首阈值符号 y 固定。对非零响应行定义 A_u=y_u X_u/||X_u||2；求解：

`max t, subject to A u >= t, ||u||2 <= 1`。

它测量固定符号区域、单位功能 RMS 下的最小像素边界距离，是**线性算子的几何余量**，不是原图 IoU75 的全局鲁棒半径或 FP32 硬件严格证书。求解后恢复到 C 的实际首阈值 ROI logit RMS，禁止靠整体放大 logits 变稳。

Clarabel 固定设置：max_iter=100、tol_gap_abs/rel/tol_feas=1e-8，单次最多30秒；约束生成最多24轮，每轮加入512个最严重违反行，初始512个 C 最小余量行加最多256个等距行。完整约束全检查，最大违反<=2e-7，只有 status=Solved 且完整可行才记收敛。固定有限预算，不因结果补迭代。

候选只做一次实际 RMS 归一，再做一次舍入后 RMS 校正；恢复 FP32。要求首阈值二值掩码、原图 RLE **均与 C 完全相同**，实际功能 RMS 相对差<=5e-5，余量不低于 C（允许2e-7数值容差）。不满足则保存失败候选并退回原 C，整条仍进入统计，不按 GT IoU 挑候选。未收敛/回退过多按第6节数值未决，不称几何阴性。
