本轮已完成8000步对象/候选学习、2568步决策学习、432张真实图完整正常RGB评价及独立复核。Mask AP由57.3435提升到60.4165，**+3.0730点**；框逐值保持，原Mask75成功损伤18/2126（0.8467%），通过本轮护栏。**尚未达到+5目标；也没有证实收益主要来自正确对象内容的匹配。**

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | V20在432真实图上Box/Mask分别退化8.653/5.382点，尽管规范对象可重建，真实正常调用和原生输出保护不足。V18另有过删退化。要解决的是把可解释对象字段转成正常实例掩码收益，并保护已有定位和成功对象。 |
| **机制假说** | H：正常实例匹配、整体—部位空间变形、细尺度读出和显式保留动作能把对象知识转成收益。竞争解释是图像细化支路绕过具体对象内容，或只使用各模板共有的粗形状。若H的“正确内容”部分成立，同权重、固定动作并匹配修正质量后错配内容应产生预冻结的实用退化。 |
| **针对性方法** | 冻结同一强原生的框、类别、分数、排序、身份和原掩码解码；训练64个9部位空间模板的调用/变形/读出及一个KEEP+64×24动作的决策器。1272真实train与1280合成RGB共同学习，固定末EMA及末8epoch决策，不按dev选权重。完整432图官方评价，独立复算48项统计、12张正常RGB严格重载；用完整字段循环错配及实际640正/负质量控制检验最终内容依赖。 |
| **整体结果** | 相对同配置原生Mask AP+3.0730、AP75+1.8132，Box AP差0；原Mask75修复61、损伤18，尺度护栏通过。字段错配在100%有效方向控制覆盖下只降低0.1092点，未达0.5点的预定实用依赖要求。容量64不等于64个有效语义原型：真实top1只用5槽，实际编辑用40槽；两者91.50%不一致。合成部位/姿态能力不能作为真实语义泛化成绩。当前预先指定参照方法只有强原生，不另算不同历史架构的额外机制增益。 |
| **研究决策** | **保留本轮作为有实际收益的固定模型，停止对同配置盲目扩训；优先解决“对象内容能否约束最终重建”这一具体问题。** 依据是正常AP已改善，但正确内容错配几乎保留收益，且最终选用与检索语义明显分离。唯一下一步是在固定末权重上做预注册、质量受控的空间结构破坏，区分“共有形状仍有作用”与“RGB直接修正绕过空间内容”；前者保留共有几何并优先改绑定，后者重做不能绕过内容的读出。该下一核验在本报告生成时未启动。整个+5训练交付目标保持active。 |

## 原型究竟学到和用到了什么

[固定合成能力核验](final_delivery/db838c03da4e/runs/RUN_SPM_SPATIAL_TECHNICAL_AUDIT_V1_f1947b07b2f3/SUMMARY.json)使用64张训练见过的合成图、2147条正常查询/62几何。先查询再几何宏平均：整体IoU0.76063、宏部位IoU0.39186，错误字段时分别0.48008/0.07188；2041条粗姿态已知查询的几何宏平均正确率91.8366%。它表明这些输入上的结构重建对字段有依赖，未验证真实部位语义或未见体形泛化。

规范占用概率平均漂移4.4693e−6、binary翻转0、相对深度平均漂移8.4738e−5。强锚使几何源形状几乎不变；本轮学到的是调用、变形和任务读出，不能把原始形状图当作从大量数据新学出的猪形。资产来自一个Bama身体及三个形态代理，九部位标签来自其几何定义。

[真实调用核验](final_delivery/db838c03da4e/runs/RUN_SPM_SPATIAL_ACTUAL_MEMORY_USAGE_V1_d9c0b6bce1a9/SUMMARY.json)：12899条输出的top1仅5槽，熵有效槽数2.3164、前4占99.9922%；2822条实际编辑使用40槽，熵有效槽数7.2195、前4占78.2424%。全部2822条确有像素改变，KEEP像素违例0。2582/2822（91.4954%）的最终模板不同于top1。相同1151条“实际编辑且粗姿态已知”的合成查询，top1姿态正确89.8349%，最终选用只48.6533%。这是成对同分母描述；没有真实姿态GT，不能外推为真实识别准确率。

[最终任务字段依赖](final_delivery/db838c03da4e/runs/RUN_SPM_SPATIAL_FIELD_DEPENDENCE_EVALUATE_V1_d2339e19e261/SUMMARY.json)首先精确重放全部原输出；循环错配完整字段元组，固定原action/强度/KEEP，并在实际640贴回后匹配正/负修正质量。5421个有效方向全部受控，无回退，最大相对误差6.4627e−8；AP60.4165→60.3073（−0.1092），四组描述性重抽区间[−0.2273,−0.0509]。小效应存在，但不满足事前≤−0.5点的实用幅度。未经质量控制的错配反而+0.2572点，不能据此更换主模型或择优报分。错配仍保留共有猪形，因此目前不能区分共有几何先验与RGB修正绕过；也不能说所有原型无用。
