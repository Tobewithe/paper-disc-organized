# 训练数据姿态/标签工程 v2：中性源参照、线性体形代理与双层可见语义

2026-10-25。仅取代未正式训练的数据工程v1实现，不追改旧Run。基础对象、四姿态、≤256候选/族、每次CPU≤15分钟/模型更新0、train/test边界与留存要求继续按[v1](DATA_PREP_PROTOCOL_V1.md)，具体数字由[执行配置v2](DATA_PREP_CONFIG_V2.json)在启动前冻结。

## 为什么另立v2

v1 Run`531acd5fadba`只接受1个standing，按原Gate失败保留。源参照审计`bed2ab8577ab`显示，原始中性PIG模型本身在该凸支持代理中右前肢占入2.696%，已经超过v1的2%绝对阈值。该代理把源相连部位/凸包近似当成新自碰撞，不能作为精确相交判断。

v2不放宽2%的新增侵入门槛，改为同一线性体形、同一整体方向的中性源参照，检查**原来未被代理判入、现在新判入的远端点**。原有代理交叠不记为此次旋转新增的侵入；原始绝对比例仍报告。局部头/肢非线性体形缩放先关闭，保留全局正定各向异性缩放与整体尺寸；这种可逆线性变换不新造中性网格相交。三角色为形态/尺寸代理，不是三个独立猪体来源。仍不得称完整三角自交证明。

## 姿态/地面合同

保留standing的腹部离地、至少2脚近地；belly_prone必须源腹侧躯干接地且背朝上；左右侧卧分别源+y/-y躯干侧面接地。左右翻转方向须由实际接地顶点的源解剖y符号独立核验。有限地面修正为最小二乘投影`z=max(z_before,0)`，最大改动≤体长3%，超限拒绝；骨长误差≤1e-9。所有原始/修正后表面与关节保留。

## 任务标签与物理观测分别定义

训练样本real/2的四处已人工识别栏杆位置(302,280/300/330/360)，原始640 GT均为instance12；旁侧皮肤点也为12。该结果支持**圆形金属栏杆处的原任务Mask连续**，不是所有遮挡都无视。real/4用于不同栏舍/视角参照；未读test，不更改原始真实标注。

新合成同时保存：

1. `physical_visible`：其它猪与全部不透明设施都遮挡。
2. `task_mask`：其它猪、实心墙/料槽遮挡；细金属笼栏不从猪体轮廓扣除。该策略仅针对所声明设施类，所有几何遮挡仍留在物理辅助标签中。
3. `amodal`及每部位完整/自身可见字段：用于对象内容与证据可见性的独立监督，不能把task_mask里“猪”的栏杆像素当成真实可见猪纹理。

真实域未知部位/物理可见/深度仍unknown，仅按原有task GT监督；不生成伪精确标签。共享图像两种外观/畸变须同几何ID，图像与全部标签作同一几何映射。train实际观察的大母猪/小猪混合、曲线栏杆/边缘所示广角畸变、有效图像边界都纳入后续生成器，具体相机范围另行冻结，不冒称已标定。

## 阳性、阴性及范围

姿态通过后进入实际看图与场景组成/投影互遮准入；本阶段不把生成48姿态当训练完成。若失败则保留当前配置与拒绝依据，换版本前先确认是生成器还是指标不合法，不能把筛查数当真实解剖认证。完整模型训练仍需任务、损失、成本与正式预算合同及两轮全流程审查。
