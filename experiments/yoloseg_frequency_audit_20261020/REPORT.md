# FREQ-v1 完整结果：YOLO26m-seg原型与分割误差频谱

已于2026-10-20 17:17:53（台北）在笔记本YANGLEI完成，全量5,000图原型、4,929图中的28,377条固定Box75配对，CPU耗时42分05秒。复用同次原生推理缓存，新增训练和模型前向均为0。**主要结论：原型以低频为主；分割误差呈明显尺度分化，小目标失败的高频误差多，大目标失败的低频误差多，现有能量证据不支持统一的高频不足解释。**

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | 原生账本已有6,229个同一Box75检测自身MaskIoU<.75且官方Mask75任务失败的GT，但未有频谱证据说明错误来自细节缺失还是粗尺度覆盖/轮廓错配。 |
| **机制假说** | H预测高频错误占主要份额且高频预测能量在S/M/L均低于GT；竞争解释是误差随对象尺度变化，或频段有能量但空间分布不正确。本轮只检验描述性必要条件，不证明空间对齐或原型容量的因果机制。 |
| **针对性方法** | 复用冻结P/c0、原RLE和官方Box75匹配；统一为每640输入像素的周期数，去DC二维频谱，完整原图有符号误差M−G；按自身Mask75和COCO尺度分层，图等权和2000次图簇bootstrap，Hann敏感性。 |
| **整体结果** | P低/中/高为59.85/27.35/12.80%；失败配对误差为18.49/25.27/56.24%，高频95%区间[55.20,57.21]%。但S/M/L高频误差77.40/47.53/17.52%，预测/GT高频能量比1.0317/1.0381/1.4639，未满足各尺度均不足的预测。成功配对的剩余误差高频占66.71%，说明高频误差份额高本身不能识别失败原因。相对原生及已有方法的改善/损伤均不适用：本实验没有干预、没有新方法或AP成绩。 |
| **研究决策** | 我主张优先核验**大目标低频轮廓与覆盖的空间错配**：其失败低频占55.27%，显著高于成功大目标的描述性15.74%；加窗后低频48.96%仍是最大单一频段，且其高频能量并不偏低。相较统一高频增强，这一问题有直接频段和实例证据。唯一下一步建议是冻结同一检测、同改动能量预算的“低频空间纠正／高频增幅”零训练对照，检验空间纠正是否能改善Mask75；若前者没有匹配增益，则撤回该优先方向。**尚未启动**，不改变服务器LCF、视频研究或其它旧Gate。 |

低频为0<q<8（波长>80输入像素）；中频8≤q<32（20<波长≤80）；高频q≥32（波长≤20）；DC单列。这是冻结操作定义，结果随目标尺度和阈值定义解释，不称通用频段标准。

全失败组6,937条/2,650图；自身成功组21,440条/4,834图。这里“失败”指固定Box75检测自身MaskIoU<.75：6,937条中6,229条为官方任务失败、708条官方任务由另一检测成功；自身成功中另有1条官方任务匹配竞争失败。不能将这6,937条称为官方Mask75任务失败总数。36,335个普通GT中7,958个无Box75配对，未进入掩码频谱对照；446个ignored GT不当普通失败。

Hann加窗后失败组总高频为58.57%，S/M/L高频为78.31/51.32/21.52%。中目标“高频是否过半”和大目标“低频是否过半”受窗口影响，**小目标高频最多、大目标低频最多**的频段排序保留。报告主值严格沿用无窗协议。

作为独立于图等权主指标的描述性总量复算，失败配对共37,925,112个错误像素：S/M/L占1.87/8.38/89.74%；大目标低频去DC误差能量为17,828,498.26，占全部失败错误像素平方能量约47.01%。此总量天然偏重较大掩码，不能换成AP收益或实例修复率。小目标占失败配对57.46%，所以本次“大目标低频”的建议是对结构/覆盖可控性的优先定位，不宣称最大化AP已得到证明。来源[ERROR_MASS_BY_SCALE](runs/RUN_FREQ_FULL_666fc3b6b2aa427d80220d4a6956a41a/ERROR_MASS_BY_SCALE.json)。
