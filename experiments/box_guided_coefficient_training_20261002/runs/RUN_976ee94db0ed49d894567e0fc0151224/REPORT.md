# 框引导原生系数分支：固定候选掩码评价

本次主比较区间跨零，额外区域收益仍不确定。

主对象：val中原Box IoU≥0.75、原图Mask IoU<0.75，共1115张有效图片、3059个候选。主比较R−N的图片macro IoU差为+0.0488 [-0.0150, +0.1195]个百分点。
预设有价值量级为该子组+1 IoU百分点；R−P是容量匹配次要对照，全体R−N用于报告性能代价。其余分层不能替代主比较，不因某一分层好看而改写主结论。

|组|含义|
|---|---|
|A|原始冻结模型|
|N|原生系数分支普通微调|
|P|容量匹配的单点对照|
|R|预测框区域引导的原生系数分支|
|RW|同一冻结R参数，仅更换读入区域框；最终解码框保持原样|

模型和统计范围：同一冻结官方one-to-one TAL候选，原型、预测框及解码固定，仅系数不同。runner传入固定最后checkpoint的输出，本模块不选择checkpoint、阈值或assignment。这不是完整推理COCO AP；当前记录不据此声称新盲测。
