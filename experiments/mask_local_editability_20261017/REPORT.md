# LEA-v1 局部可编辑区域核验结案

笔记本完成原256条固定配对/243图的零训练核验，并对完整49,976输出、1,735个原成功GT重新匹配。**低置信区域集中包含可修错误，但当前区域未通过覆盖与局部性门槛；直接限制旧方法也损失了收益。** 不能把“域外不改”说成“不会误伤”。

| 维度 | 本次实验的整体研究链路 |
|---|---|
| 问题 | 已有全局系数教师能修好159/256个目标，但无GT旧方法G只修好12个。局部编辑是否既有足够修复机会，又能降低对原成功实例的损伤，需要在训练前核实。 |
| 机制假说 | H：错误集中在原生低置信区域，限制修改位置可以保留大部分机会并避免域外连带改变。竞争解释：高置信区域也可能错，原生不确定性不等于错误位置；限制区域可能挡住必要修复。若H满足本次必要条件，固定B应保留≥152个C见证、显著优于等面积随机域，且足够局部、完整任务损伤受控。 |
| 针对性方法 | P/c0/框类分数/输出/缓存不变；从实际原生首次阈值前logit构建原图B：绝对值≤1.5且在原序列化框内。最终二值掩码硬合成，域外原样保留。比较GT辅助B内精确二值上界O_B、保存教师的局部版C_B、旧部署方法的局部版G_B，并作8个等面积随机支持域对照。没有训练、新forward、教师优化或阈值搜索。 |
| 整体结果 | O_B相对原生+0.195900 IoU、相对G+0.188672，修好204/256，较随机域+0.095538；说明域内有明确机会。可是C原159个见证只保留132（83.02%），低于152；B平均占ROI32.99%，超过25%。可部署G_B相对原生+0.003457，区间跨零；相对G−0.003772，区间全负。完整原成功GT损伤从G的6/1735降至5/1735，恢复从26降至15。冻结结论为NEGATIVE_CURRENT_REGION。 |
| 研究决策 | 保留“域内有集中修复机会”和“域外可精确保留”的正面证据；拒绝“当前域足够小、保住≥95%旧见证”的主张，不把G_B作为新优胜方法。我选择优先检验**区域内逐像素纠错能否学成**，而不扩大阈值或把原型整体解冻。依据是O_B204条实际机会及其对随机域的明确优势。用户随后明确授权无论门槛如何完成实际训练，因此唯一后继已另行冻结为[LRP-v1探索训练](../mask_local_residual_pilot_20261017/PROTOCOL.md)：同域同预算LOCAL/UNIFORM对照，之后完整400图评价。它不代表本LEA准入通过；是否继续由训练实际收益与损伤决定。 |

主表指标为同256条配对、先图内平均再243图等权，IoU单位0—1；区间是2000次配对图像bootstrap的95%区间。没有新AP。

O_B−随机域均值+0.095538，95% CI [0.087041,0.103974]。O_B是给定支持域内任意最终二值编辑的精确上界，使用GT；不是网络可学性或Δc表达上界。其204条中只保住C原见证的132条，同时找到了另外72条，因此“总机会更多”和“旧见证覆盖不足”同时成立。C_B115条与保留旧C114条也要区分。

全3,610个普通GT的完整匹配中，G/G_B分别恢复26/15个原失败GT；原成功分母固定1735，损伤6（0.3458%）/5（0.2882%）。固定256配对的12/5与完整任务恢复26/15不是同一分母，不互换。原Box匹配与Mask匹配分别核验，所有非Mask字段、顺序与身份不变。

保护边界：1730个原成功GT的原生匹配掩码在B内暴露了正确像素，其中1165个固定匹配掩码在“B内全部改错”的最坏情况下会低于.75。这是固定掩码的描述性最坏界，不是实际COCO任务损伤预测；它足以说明域外硬保留不能保证全任务无损。

冻结后的描述性像素算术发现：丢失的27个C见证全部存在教师在锁定高置信区域修正错误的像素；其中1条还涉及框外修正。这说明高置信不能直接当作正确性标签；该算术不是新增干预或改Gate依据。见[描述回执](LOCKED_ERRORS_DESCRIPTIVE.json)。
