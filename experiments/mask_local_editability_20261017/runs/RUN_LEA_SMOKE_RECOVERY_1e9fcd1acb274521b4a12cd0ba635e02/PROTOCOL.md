## 研究命题与决策用途

现有固定 P 的同检测 C 参照已找到159/256条 Mask75 修复，但现有方法兑现有限；EK只修错会破坏原正确像素，空间分区也出现修复互补及覆盖不足。检验一个具体必要条件：推理可见的低绝对logit区域是否同时足够局部、包含大部分已知修复机会，并允许限制已有方法的改动而不增加真实任务损伤。

H：原生低置信区域富集可修错误；限制可编辑位置后仍能保留至少95%的已知C修复见证，并优于等面积随机支持。H_alt：错误大量位于被锁住的高置信区域，或所谓机会主要来自允许编辑足够多像素，与低置信定位无独立关系。

本实验是支持域的必要条件审查，不证明局部卷积可学习、不证明系数路线不可能，也不证明原型共线、精密相消或极小容错半径。
