# OGPS零训练决策：GT输入可行，现有7O预测未兑现收益

**Gate 0A通过，Gate 0B未通过。本轮完成并停止，不启动ownership训练。**

在笔记本 `28358lan` 的RTX4060上完成196张历史val图、1,346个冻结官方one-to-one TAL候选的13组重放，执行约121秒，训练更新数为0。所有输入、原型、预测框、候选和既有7O头保持不变。完整数字和5,000次整图配对区间见[运行报告](runs/RUN_2210d2acbc58479ab473ef36ea8c7c8a/REPORT.md)；固定定义见[执行协议](PROTOCOL.md)。

## 1. GT粗网格可以通过这个solver得到较好的系数

在预定“框IoU≥.75、原maskIoU<.75”的105张图、257个候选中，图片macro原图IoU：

| 处理 | 相对原模型增益 |
|---|---:|
| GT 8×8 soft ownership→Ridge→完整原型解码 | +10.1621个百分点 |
| 同身份既有有限BCE oracle | +10.8506个百分点 |

增益之比 **93.65%**，95%图片bootstrap区间 **[87.28%,99.69%]**，超过70%的预定门槛。这说明本轮固定的8×8转换与求解流程能够兑现大量既有oracle参照收益；它不是“8×8必然不足”的阴性结果。

该比例比较两个具体流程，既有BCE oracle不是IoU最优解，GT solver也不是严格上界，不能解释为理论信息恢复率。

## 2. 投影改善了7O直接输出，但仍低于原模型

下表均为全部196张图的图片macro原图IoU；这不是COCO AP。

| 方法 | macro IoU |
|---|---:|
| 原模型 | 79.9036% |
| 旧7O真实ROI，直接渲染为mask | 75.2547% |
| 同一7O输出→Ridge→原型mask | 78.8116% |
| 原模型自身概率→相同Ridge | 79.6237% |
| GT8→Ridge→原型mask | 82.9321% |
| 既有有限oracle | 83.3296% |

投影相对7O直接图提高 **3.5569 pp [2.9304,4.2396]**，但相对原模型下降 **1.0920 pp [−1.3415,−0.8399]**。相对原模型，Mask75修复19个、损伤73个，净减少54个。

真实ROI solver相对同图错实例为+0.2530 pp [−0.0258,+0.6744]，相对错图为+0.0284 pp [−0.1387,+0.2169]，都没有建立可靠优势；相对原掩码自投影还下降0.8121 pp。旧wrong组是独立训练的头，不是同一权重上的纯错配干预。

因此，“通过原型投影让粗预测更好”成立于本次直接图对照，但“现有7O提供足够有效的新归属信息，使最终结果超过原模型”没有成立。不能仅凭相对很弱的7O直接图提高，就宣称OGPS方法成功。

## 3. 本轮能定位到哪里

目前应保留的判断是：**该固定solver在得到准确的GT粗网格约束时可用；现有7O预测经同一solver仍未提供净收益。** 这尚不能区分旧预测器的训练、表示、校准和错误空间分布，也不能证明neck中不存在可用信息。

补充对照：GT8直接渲染达到83.7051% macro IoU，高于GT8经solver的82.9321%。因此本轮也没有证明投影对任意ownership都优于直接输出。

概率统一clip到[.01,.99]后转logit，故自投影允许产生校准改变。本轮S_BASE相对A下降约0.280 pp，已单列，不把这种改变归功于新增ownership信息。lambda=.003的Ridge与既有lambda=.003的BCE oracle并非同一个目标。

**执行决定：按用户停止规则，结束本次组合，不训练同类ownership predictor，不调solver参数、不增加gate、不启动下一阶段。** 新的信息源或新的求解目标仍只是未来可另行论证的假设，本轮未检验。

## 后续建议及授权范围（2026-10-02）

以下建议随后经用户“试试，但是不要陷入无限打补丁”授权，已作为一次有界诊断执行。原Gate0结果不变。完整结果见文末及[补充运行报告](runs/RUN_ec575d4cc7a341a0bb98b8b5cff1cf63/ERROR_PROPAGATION_REPORT.md)。

用户询问下一步。建议只考虑一次现有资产上的“ownership误差如何进入完整mask”判别，不恢复OGPS训练。令t_pred、t_GT均经过本协议相同的clipped-logit转换，e=t_pred−t_GT，K=(AᵀA/64+λI)⁻¹Aᵀ/64，则两条solver输出的系数差严格为K e；完整连续logit差为P_full K e。原预测框与解码不变。A K在8×8 logit网格上的谱范数≤1，因此不能预设“Ridge在拟合网格放大噪声”；待检验的是完整空间响应及零阈值附近翻转是否对某些误差位置特别敏感。

先检查空间误差及其经固定算子的作用，再作有限GT替换诊断：固定少量格数，比较高影响格与随机格，并控制修正掉的误差能量，避免“只是改了更大的错误”解释。GT用于诊断，不是部署方法。若少量格的错误控制能明显超过同预算、同误差量对照，才支持研究对任务影响敏感的空间约束；若需要几乎整张GT图或控制组同样有效，则不把solver特殊机制作为投入理由。能够无GT识别这些格仍需单独验证，不能由GT替换收益直接宣称。

这与旧[S046稀疏GT提示](../../project/research_notes/refinements/coco-structure/SPARSE_IDENTITY_RESULTS_20260912.md)不同：旧任务比较从头用不同8点标签拟合，本建议检验已有7O真实误差在固定OGPS算子中的传播；不重做提示区域扫描。[两轮响应投影训练](../response_projected_coeff_20260923/REPORT.md)已做过间接与直接训练，因此不能把“再端到端训练投影”当作尚未尝试的默认下一步。

鲁棒拟合、学习观测不确定性经求解器优化已有文献，例如[Learning Correspondence Uncertainty via Differentiable Nonlinear Least Squares，CVPR 2023](https://openaccess.thecvf.com/content/CVPR2023/html/Muhle_Learning_Correspondence_Uncertainty_via_Differentiable_Nonlinear_Least_Squares_CVPR_2023_paper.html)。仅加权Ridge不是创新声明；需要对象特有的误差传播证据和正常掩码效用。

## 有界补充诊断结案：保留位置作用线索，完整判定未通过

本次在同一Study新增Run `RUN_ec575d4cc7a341a0bb98b8b5cff1cf63`，196图/1346候选全部保留，笔记本完成约210秒，训练更新为0。只进行预先固定的8/64格GT替换，没有扫描格数、正则、学习率或新头。[协议](ERROR_PROPAGATION_PROTOCOL.md)、[完整配对统计](runs/RUN_ec575d4cc7a341a0bb98b8b5cff1cf63/RESULTS_ERROR_GEOMETRY.json)、[固定结案决定](runs/RUN_ec575d4cc7a341a0bb98b8b5cff1cf63/DECISION_ERROR_GEOMETRY.json)均保留。

H8相对T提高3.2893 pp，回收同批候选的(G−T)参考增益79.83%，95%CI [73.12%,90.88%]。此分母是本轮GT8-solver机会，**不是**上一轮有限BCE oracle的93.65%比例。

H8相对E8的图片macro IoU优势为0.3632 pp [0.1615,0.5755]；E8移除了更多输入误差能量（均值132.49，H8为105.87）。因此有“误差大小本身不能完全解释修复效用”的限定线索。但其候选平均优势区间跨零，不能声称每种汇总均稳健或对所有候选普遍有效。

**完整判定不通过的原因是公平对照覆盖不足。**固定4096随机子集池中的能量匹配只有569/1346（42.27%）成功，低于预设90%。虽然H8比EM8的全体macro优势为0.7044 pp，约79.56%的这项优势贡献来自未匹配对象；不能把它全算成相同误差量下的位置作用。匹配569候选子组仍有0.4470 pp [0.1206,0.7997]的正优势，但不能用这个子组替代预先声明的全体判定。

所有纠正格的选择或取值使用GT；H8选格读取全部64格GT误差，8/64只是实际替换数量，不能表述为只需要8格标注或12.5%的GT信息。82.10%不是无需GT的方法性能，更不是AP。本轮有支持性的诊断事实，但没有达到完整预设机制验收，不能借它放行新训练。

空间描述表明相对GT8-solver，旧7O求解结果在GT内部平均响应较低、邻居和剩余负区较高；误差能量并非只集中于边界。实际误差经完整响应传播的MSE与20次等幅度空间排列MSE均值之比，中位数为2.046。该排列是代数扰动，不一定对应合法的clipped ownership；这些描述不代替公平对照，也不证明原生网络根因。区域翻转在640连续诊断口径计算，非原图二值掩码逐像素归因。[区域记录](runs/RUN_ec575d4cc7a341a0bb98b8b5cff1cf63/REGION_SUMMARY.json)。

数值核对通过：A/T/G原图IoU与上轮最大差0，系数差Ke关系最大误差6.42×10⁻¹³，AK最大谱范数0.999851；没有丢候选。六个展示例按固定身份顺序预先选取，位于运行目录figures。30个运行文件已回传并通过SHA256核验。

**结案决定：本轮停止。保留“少数空间位置具有不同任务代价”的限定线索，保持完整判定未通过；不扩大随机池、不补扫格数、不增加gate、不训练新ownership、不自动延长OGPS。**
