# V28 部位可见率标签语义勘误

正式训练、原协议/源码/缓存/权重和原始评价保持冻结，未替换标签重训。本勘误来自完成正常评价后的实际图示与源标签复核，不能用它删除负结果或自动解释全部AP退化。

原实现计数 `(amodal_part_fields & physical_visible_of_same_instance)`，分母为该部位完整投影面积。这里physical_visible只说明当前像素最前方是同一头猪，可能是其躯干，不能说明最前方是该部位。真正的物理部位可见分子还须约束 `physical_parts == part_id`。因此原visibility监督实际是“部位投影与同猪可见区域的重叠代理”，遗漏自身遮挡，不能叫真实部位可见率。

[实际反例](VISIBILITY_TARGET_SEMANTICS.json)来自本轮真实用过的合成train_formal_0008_v0，标签SHA53e0e1a1568dff9fac227fc5debfa21fc032272c1fbb4c279404c2aab6df360b：153个有投影支持的实例—部位，代理平均高估26.5454个百分点，57个超过25点；实例1的第5部位（左前腿），分母230像素，原标签1.0、按真正部位身份的可见率0.0。此样本是定义缺口的实证反例，不估计全数据发生率，也未测其对AP的独立因果影响。

原22_state三图及导出字段visibility_logits均据该旧监督训练。保留原图和SHA，阅读时应使用另附proxy_corrected图；图中数值没有改，只更正标题与解释。真实部位/深度GT仍未知，不能把这些柱形图当真实遮挡能力证据。

该缺口不改变实际8000步、正常432图AP54.575195及损伤203/2126的事实；原Mask监督/RLE和评价统计没有因此替换。它限制的是遮挡机制及完整对象语义的主张。下一轮必须先明确“完整对象、可见实例和部位片段”的对象单位，修部位身份/自身遮挡的监督和真实未知掩码，通过对应的自遮挡反例检查后再训练。当前配置关闭，不补训追阳性。
