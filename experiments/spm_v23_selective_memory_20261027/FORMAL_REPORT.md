# V23.5 查询条件选择性门：正式训练与正常验收

本轮在 V23.4 真实空间记忆读数上增加了一个 99 参数零初态查询门，试图只在有利实例上启用记忆残差。正确对应臂没有超过 V23，固定打乱臂反而略高于 V23，说明这次门的训练信号没有形成可部署的对象对应性；当前保留原 V23，停止这条直接记忆接入。

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | V23.4 的全局标量门使正确记忆臂 Mask AP 下降 0.006533，直接 GT-IoU 改善/下降为 475/463，提示可能需要查询条件选择性。 |
| **机制假说** | H_selective：冻结记忆读数后，查询、confidence 和残差幅度足以学习“何时启用”内容；固定打乱臂应不能复现收益。H_domain：门只学到训练域或残差统计，跨来源 dev 上不具备对象对应性。 |
| **针对性方法** | 冻结 V23、C21、R0、检测身份和 V23.4 正确/打乱记忆，只训练 99 参数零初态 `tanh` 查询门。两臂同 1272 real/train 图、8390 查询、4 轮/1272 更新、同顺序和 BCE+门正则；完整正常评价 432 图、2863 GT、12899 行。概率输出按 V23 合同裁到 [0,1]。 |
| **整体结果** | 正确臂 Mask AP **60.748229**，较 V23 **−0.005049**；固定打乱臂 **60.758496**，较 V23 **+0.005218**。两臂 Box AP 均 66.884503，Mask75/尺度/损伤护栏均通过；正确臂没有超过打乱臂，且打乱臂的微小正差不能归因于正确对应。 |
| **研究决策** | H_selective 未获支持，关闭 V23.5 选择性记忆。保留 V23 作为推荐模型。下一步回到已有正收益证据：V23.2 的 C1 候选在冻结 R0 下为 60.846479（+0.093200），但在 R1 下出现 −0.107702 的条件抵消；优先研究候选—R0 接口兼容性，不再投入当前真实值记忆或新增质量头。 |
