# 当前官方候选的监督—评价域审计

**本轮没有发现“只是训练标签与COCO标签不一致，所以看起来变差”的充分解释。** N、P、PC在开发图的官方目标本身也没有改善；实际误删前景主要位于两套标签一致的前景区。标签冲突区更容易受损，仍是需要保留的风险线索，但不能解释为已经找到主要根因。

2026-10-04（北京时间）完成，无训练。固定256张开发图、253张有效、1816个官方one-to-one TAL候选；原始A、既有epoch3 N/P/PC均未更新。N仅训练过原生系数分支；P仅训练过原生原型；PC两者联合。正式冻结重放128.25秒，smoke及正式Run均已核验回传。

## 3. 标签差异来自什么范围

GT框内COCO前景共23,508,192个候选像素计数，其中1,840,855个在独立polygon里存在、被overlap归属覆盖；9,910个已在独立polygon流程中缺失。另有356,724个官方额外前景像素。重复实例/候选区域按各自监督对象计数，不能当整张数据集的唯一物理像素数。

这里独立polygon不是重新生成的另一套标签：捕获相同官方转换、顶点重采样、几何变换后的polygon，在原overlap函数入口单独栅格化，再按原面积排序绑定annotation。因而能分离overlap覆盖和其它polygon流程差异，但不能继续把后一项独归到某个转换或插值算子。

所有标签比较保持同一连续logit、GT框支持、面积归一化和segmentation gain。原图IoU仍使用原COCO实例mask；640版COCO使用既有nearest映射，不是原图像素的无损替代。原图误删TP另存，不能将640区域归因直接移植到原图逐像素。

## 4. 核验与决定

- 256张计划图、253有效、1816候选完整保留；3张无正样本图片为234138、284128、552870。
- A/N/P/PC全部旧原图IoU、coverage、Mask75及既定AUC/FPR最大复现差为0；标签、图像、annotation顺序、GT框逐图核验。
- smoke独立官方损失核验最大差1.34e−6，满足预定3e−5绝对/相对容差；正式目标恒等式最大残差4.94e−15。正式Run的官方损失字段0表示其没有重复smoke逐算子核对，不将它声称为另一次误差为0的核验。
- 没有更新权重/BN、重跑TAL、筛掉空mask、改变阈值或运行本地桌面模型。实际耗时远低于预定180/1200秒预算。

**决定：当前审计结案，不自动改标签重训。** 三组均未达到预定“官方目标下降、COCO目标上升且冲突解释多数直接误删”的分流条件。降低“标签差异足以解释主要直接损伤”的优先级，保留冲突区脆弱性的事实。

这不排除冲突梯度通过共享参数间接影响一致区域，也不排除其它泛化或目标—效用问题；本轮只分解固定输出的变化，不宣称重建了训练因果。无训练local-view不纳入上述原因解释。历史S031–S033有相关但不同对象的证据，当前结果不是重复发现标签差异。

后续仍沿原型—系数链路寻找新的信息或计算方式，但不能用当前结果为继续加宽、延长训练、换loss或恢复旧反馈提供自动理由。总研究目标尚未实现。
