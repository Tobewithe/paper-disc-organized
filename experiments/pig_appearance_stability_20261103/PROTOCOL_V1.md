## 3. 干预和正常输出身份

真实三条件：原图N；有效原图矩形内逐通道`round(255*(x/255)**gamma)`，gamma为0.65和`1/0.65`，分别记bright／dark；矩形外padding原样保持。gamma=1作为恒等控制。映射是固定数字色调操作，不是物理重照明，也可能改变量化信息。

合成使用原A/B照明图，640×480上下各pad80为114，保持像素尺度。全部输入batch1、FP32、原生O2O、max_det=300、score>0.001，不加NMS、增强或检索。复制已有已用推理源`predict.py/native.py/reference_model.py/stage.py`原字节进`reference/`，只调用其无GT正常前向与Mask解码。单类nc=1、nm=32；Mask先由原系数和原型组合、双线性插值到640、阈值0并按各自预测框裁剪。保存完整640 RLE预测及raw/ordinal身份。

诊断评价在固定160格点采样`mask640[2::4,2::4]`，实GT为原独立160Mask；合成使用相同采样并限制于`owner_valid`。这是栅格诊断，不是COCO AP／官方Mask50召回或历史成绩parity。不同条件的候选集合可随正常前向变化，不强行当同一raw或检测行。

## 4. 单一主读数及必要对照

每条件在MaskIoU>=0.50边上求最大一对一匹配，确定该图能同时成功的实例数。用固定顺序的增广路算法；分配身份只用于核查，不从不同预测拼联合成功。

对真实图i，原成功数为n_i，两种gamma的成功数为b_i、d_i，主量为：

`L_real = sum_i max(0, n_i - min(b_i,d_i)) / sum_i n_i`。

这是两种预定干预中的实例成功数损失比例，逐图最坏条件在运行前指定，不是事后选剂量。原图完全不成功的图仍保留，分母0时不造0结果；同时报告各条件总成功数和全部GT数，避免只看净损失隐藏基线不足。该主量不解释具体哪头猪受损，也不是AP或部署损伤Gate。

区间按128图的原manifest group整簇重采样10000次，seed20261103，报2.5%／97.5%分位。group不等于独立农场，区间仅为当前来源构成下的探索读数。

唯一必要的合成对照量：`S_syn = sum_g abs(a_g-b_g) / sum_g max(a_g,b_g)`，a_g、b_g为A/B有效owner诊断成功数；几何组整簇bootstrap同次数、seed20261104。另保留两侧逐例结果核查，不能把真实和合成比例相加。

## 5. 有效性、判定与停止

工程Run先完成：输入和环境身份；2张固定真实图及1组A/B的无GT前向；重复同RGB输出一致（scores／boxes最大误差<=1e-6、raw和640Mask逐值一致）；gamma=1逐像素恒等／padding保持；IoU与一对一匹配的竞争、空集、增广路构造检查；A/B真实标签数组相等与record签名相等；模型参数／BN状态SHA前后不变。工程不公布科研效应，不作为正式样本挑选器。通过后才提交独立正式Run，并冻结工程Summary SHA。

正式Run恒等重复：真实选择前8图、按group哈希排序前4组合成A；相同RGB前向必须满足上述容差，否则本实验无效。真实资格为原成功数至少128、至少32图有成功、至少3个声明group有成功；合成资格为`sum max(a,b)>=64`且至少12个几何组有成功。资格不足分别记该侧证据不足，不称稳健。

- 真实敏感性支持：资格满足、L_real>=0.05且簇区间下界>0.02。5%是本首试用于选择投入方向的预定幅度，不是旧SPM采用Gate。
- 合成一致敏感性支持：资格满足、S_syn>=0.10且簇区间下界>0.02。
- 两侧支持：保留成像条件稳定性缺口，下一步设计匹配信息／预算的保持方法；本次不自动训练。
- 仅真实支持：保留对固定数字色调操作的敏感性，不宣布物理照明机制或合成发现迁移。
- 仅合成支持：当前只支持有限合成域敏感，不以此优先启动真实保持训练。
- 未达效应线：降低本范围的优先度；区间跨门槛时明确未决。低基线、输入身份／控制失败则分别记不足或无效，不能调阈值、换样本、挑另一模型追阳性。
