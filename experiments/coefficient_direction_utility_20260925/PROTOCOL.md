# Experiment 7E.1: direction accuracy versus mask utility

Reuse the frozen 7E validation bank, checkpoint selection and λ=0.003 GT-conditioned targets. Do not refit predictors. For each positive candidate, hold its original box, prototypes, class score and coefficient `c0` fixed. Compare the uncorrected mask with the two deployable 7E predictors (`h_only`, `true_local`).

For a controlled, **GT-assisted** direction test, define `G=P_box^T P_box/N` using the 640-grid pixels inside the original predicted box. Form a `G`-orthonormal plane from the oracle correction and the predictor direction's component perpendicular to it. At target functional cosine ρ in `{0,.2,.35,.5,.65,.8,1}`, combine those two axes with weights `ρ,sqrt(1-ρ²)`, then normalize the resulting coefficient vector to the **oracle Euclidean correction length**. Thus the only systematic change along each sample's curve is functional direction accuracy. Verify the achieved cosine. Also measure the actual predictor with both its learned radius and the oracle radius. The ρ=1 arm is the 7D oracle; every synthetic ρ arm and the predictor-with-oracle-radius arm use validation GT and are **not deployable**.

Evaluate original-image mask IoU and Mask75 crossing using official `process_mask` and `scale_masks` with the original COCO mask. Evaluate predicted-box 640-grid ROC AUC, coverage and FPR against the original instance raster. Use all 1,346 fixed val positives as the primary population; originally failed, originally successful and failed-with-Box-IoU≥.75 strata are secondary. Report image-clustered 95% bootstrap CIs. A utility threshold is descriptive for this constructed family only, not a universal cosine threshold or a COCO AP prediction. Keep predictor and oracle directions distinct from the coefficient-space cosine, and do not confuse the per-instance Mask75 crossing fraction with AP75.

The synthetic direction is oracle-informed even at ρ=0 because its perpendicular component is defined relative to the oracle. The actual predictor is an independent empirical anchor. Results cannot establish whether any learnable model can achieve a specified ρ without GT, and a scalar cosine need not fully determine mask quality across different error patterns.
