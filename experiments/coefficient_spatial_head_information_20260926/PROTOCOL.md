# Experiment 7J：投影前的局部空间特征能否预测修正方向？

复用 7I 冻结官方权重的同图前向与 7E 的 fit/dev/val 目标。原 `h` 是系数分支最后一层 1×1 Conv **所选位置的 64 维向量**；7J 从同一层的**完整 64 通道空间图**，按原候选预测框裁切并池化为 64×8×8。这比较单点压缩表示与其周围的真实空间证据；不修改 YOLO 权重，GT 只在训练目标和最终评价中出现。

四组使用同一 CNN+MLP 参数量、相同初始化、批次、训练损失与 dev 选模：`h_only`、`h+true ROI`、`h+wrong-instance ROI`、`h+wrong-image ROI`。错配实例优先选择同图、同 pyramid level、预测框同尺度的另一候选；无此对象则使用另一张图的同 level/尺度候选并计数。错图控制也优先匹配 level/尺度。匹配条件只取原预测，不取 GT。先检验 val GT 条件目标的**像素作用方向余弦**，特别是原 Mask75 失败与框好掩码差组；随后把预测方向放回原候选，看原图 Mask IoU、AUC、Mask75 救回与损伤。按图像聚类求配对区间。

真实 ROI 对 `h_only` 与两个错配对照都稳定有益，且下游分割改善时，才可说空间上下文提供了可用的修正信息。仅 true ROI 的 dev loss 下降、验证 direction 上升但掩码不升，只支持可预测性诊断。固定 1 粒种子是快速决策，不作为论文最终统计证据。
