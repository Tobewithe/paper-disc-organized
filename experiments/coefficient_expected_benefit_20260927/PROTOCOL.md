# Experiment 7L：跨折 Expected-Benefit / Repairability 预测

## 问题、对象、冻结方案

7K 证实高失败概率并不等于当前系数修正器可救回。因此此实验直接预测**应用某个冻结修正后**的净效果，而非预测原掩码是否失败。第一阶段保持与 7K 可比的官方 YOLO26m-seg（Ultralytics 8.4.100、COCO 预训练）one-to-one 正样本候选；其**候选入组依赖 GT**，用于机制诊断而非部署。所有 gate 特征均来自原图、模型输出和准备执行的 correction，不使用测试 GT。完整推理候选及 COCOeval 留给 7M。

训练池固定为已缓存的 10,000 张 COCO train2017 图像；按图像 ID 的固定 SHA256 顺序等量划分 5 折。与此前 200 张开发图像严格不重叠。每一折的 h-only 系数方向头只用另外四折的 GT 条件 λ=.003 有限 oracle target 训练；checkpoint 使用既有独立开发图像选定，绝不使用被预测折的标签或收益。对被留出的折仅推断一次，记录修正前后**同一候选、原图尺寸的 Mask IoU**（并行记录 640 网格 IoU 作审计）、框内 AUC、Mask75 crossing 和 GT-free 预测特征。所有 OOF 行必须记录 fold、修正器 checkpoint、图像和实例标识，并验证每个图像恰出现一次、生成标签的修正器未训练该图。

标签预先固定为 `B_IoU = IoU(c0+Δc_hat)-IoU(c0)`、`B_AUC`，以及 `R = 1[B_IoU>0.01]`。另报告 Mask75 由失败转成功/由成功转失败，不能只以跨阈值作为可修复标签。`B_IoU>0.01` 只按改善定义；损伤 `B_IoU<−0.01` 单列。原成功与原失败分层报告，但这两个 GT 标签绝不进入 gate 输入。

`B_IoU` 使用官方 `process_mask` 与 `scale_masks` 还原到 COCO 原图尺寸后的二值 mask。`B_AUC` 使用预测框内原型原生 160×160 网格的连续 logit 与按最近邻缩放的官方训练所有权标签；这项辅助指标的网格与 7A 的 640 网格不能混用。评分时重新以 FP32 跑原模型，且逐候选断言原始 IoU 与目标构建阶段完全相同。

容量从简：X1=预测框/类别/分数，X2=X1+h+raw detection，X3=X2+**此次修正**的 GT-free 统计（系数位移范数、与原系数夹角、prototype 像素作用范数、预测框内原/修正后 logit 的分位数、前景比例与变化），X4=X3+系数分支 64 通道局部空间图的轻量池化描述。先用标准化 Ridge/Huber 和固定正则 Logistic Regression；参数或阈值只在 train2017 OOF 内部分图像开发集选定。检验 Spearman、R²、AUROC、AUPRC、Brier/ECE、top 10% 实际平均 B、repair/damage 及按图像聚类的区间。必须比较 X1–X4 增量；“benefit score 高”不等于已通过最终方法验证。

内部 gate 拆分预先固定为 8,000 图训练 / 2,000 图选择与校准，按图像 ID 哈希排序；四组输入与三种简单估计器均在独立测试前训练。开发集只按 top 10% 平均 `B_IoU` 选一个主模型，再冻结并评价 2,000 张独立图像；同时报告其余所有模型，不能根据测试结果换主模型。X1 的“类别”是模型最高分预测类别，不是 GT 类别；X2 才加入完整 80 类 logits。测试集中按图像聚类重采样，重新选每个样本的 top 10% 估计主指标区间。

独立测试图像从 COCO val2017 的 5,000 张中剔除此前已审阅的 200 张，固定 SHA256 选择 2,000 张，在建模前封存 ID。最终测试不用于选特征、阈值或修正头。最终修正器由完整 10,000 张训练图像拟合，需记录其与 OOF 五折修正的位移及收益分布差异；若分布明显漂移，不能直接把 OOF gate 的表现外推到全量重训修正器。测试仍先作同候选诊断，7M 再检验所有推理候选与 COCO AP。

## 先验样本量与判定

使用 **7K 的逐图结果**在不读取新测试图像标签前估计候选加权均值的 image-cluster 方差。双侧 α=.05、power=.90；最小关注差值预设为净 Mask75 **1 个百分点**或平均 Mask IoU **.005**。要求的图像数取各相关 7K 条件的最大值，再以 2,000 作为独立测试下限；这仅是候选级均值的前瞻性估算，**不保证完整 COCO AP 的功效**。如果 7K 的方差不能代表新测试，应如实报告，不能在看结果后回填“预注册”阈值。

这是资源较大的单次研究。先用短程运行检查缓存、官方候选/GT 对齐、oracle 数值收敛、OOM 和日志恢复，再启动全 10,000 图目标构造与 5 折训练；失败运行及部分分片保留。已经冻结的 7K/7I/7J/7J-N 结果不可因本实验而覆盖。
