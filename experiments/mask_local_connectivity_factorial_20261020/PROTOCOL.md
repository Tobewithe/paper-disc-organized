# LCF-v1：实例局部解码×连接监督的四臂实际训练

V2：2026-10-20，全部smoke/正式优化前修订。原V1 freeze及源码在preflight保留；取消会锁住高置信错误的残差硬截幅，预算/数据/对照不变。2026-10-20，用户“试试”授权承接四臂方案，在笔记本YANGLEI执行冻结、smoke和训练/评价。新Study，不恢复SSR或PLF，不修改旧Gate，不预设零拓扑错误，不自动提交/推送，不设定时任务或目标模式。

## 1. 命题与科学准入

STA-v1固定256条发现：C已达Mask75的159条仍有58条实质分裂/邻居混入候选，C未达的97条中47条有告警；混入多于分裂，局部连接控制是有依据的研究对象。该面板已暴露，只作既有动机/额外描述，不作新验证集。其跨实例混入不是全部经人工确认的拓扑桥，不能事先称结构不可达。

H_local：同样输入和有效参数，放开逐实例掩码在原型线性空间外的局部残差，可减少连接错误；H_supervision：显式在连接/分离路径的关键位置监督，比同类同难度的像素监督更能保持连接。竞争解释：只是增加难像素权重/训练算力，或收益来自幅度与数值条件而非空间自由度。

四个M：M1由STA及旧LEA/LRP具体失效支撑；M2以D−C/D−B、完整原生拓扑与损伤分母作预声明预测；M3四臂是**逐张量相同的一个网络**、同输入/初始化/预算，只改最终输出约束及监督位置；M4训练中去除连接位置对应的同类/难度控制，并作同D checkpoint投影回系数空间及等功能幅度干预。不能完全排除有限精度读出条件及非凸优化差异，因此不将阳性扩写成固定P数学不可表达定理。

## 2. 四臂与输出边界

| 臂 | 输出 | 额外监督位置 |
|---|---|---|
| A | 同网络标量空间场经固定ridge读出32维Δc，c0+Δc与P原生组合 | 与路径关键点同GT类别、同预测logit难度的非关键点 |
| B | 与A相同 | GT一致的连接/分离路径关键点 |
| C | 同网络空间场直接作实例局部δz | 与A相同规则的匹配非关键点 |
| **D唯一主方法** | 与C相同 | 与B相同路径关键点 |

普通像素训练目标、额外监督权重与数量归约四臂相同。A/C不仅是弱化的无额外loss参照，能够控制额外监督与难样本加权。四臂同seed0、全新同一state_dict；不把旧G初始权重套到新架构。

共有网络：原检测头三层F(256/512/512)分别1×1投影到16，再双线性对齐原P网格；保留P32、完整N×32 GEMM所得z0、相对预测框x/y、c0线性32→16、类别80→8与score，共108通道。实例原型ROI外扩2个原型像素只供上下文；3层3×3卷积108→32→32→32、GELU，1×1标量头零初始化，g=raw，无硬截幅。只在固定预测框原型网格支持内输出。无低置信域限制、无9216面积门控，全部原最终输出均处理，空ROI原样保留。新架构提供空间邻域上下文，区别于旧LRP的68维逐点MLP和低置信硬域。

A/B读出：Φ为ROI内冻结P的32×像素矩阵，Δc=(ΦΦᵀ+λI)⁻¹Φg，λ=max(1e-4*trace(ΦΦᵀ)/32,1e-12)，固定FP64解线性系统、FP32系数与原生完整N×32 GEMM。ridge是明示有限数值读出，不能拿它的失败证明所有系数预测器失败。C/D在同一原生完整GEMM低分辨率logit上加独立g，P和c0不更新。两种输出的功能差异是干预对象，不是参数量贡献。

共同解码：原8.4.100 FP32 P/c0、原最终行/Box/Class/score/排序、batch16/rect几何；低分辨率logit→原生scale_masks到输入尺寸→>0二值→固定预测框crop→二值scale_masks回原图→byte/RLE。global低分辨率必须从(c0+Δc)@P重算；不得以Δc@P替代。zero-delta各臂完整RLE必须与原生完全一致。cudnn TF32=True、matmul TF32=False等均从baseline_profile逐项恢复并记录，不能笼统说全部TF32关闭。

## 3. 连接目标及匹配控制

只在train2017通过原类别/score/BoxIoU>=.5贪心一对一join监督；GT不进入网络、解码或推理门控。普通非crowd/ignore GT投影到原生第一次阈值的输入网格，保留原最近邻/letterbox规则。损失在这个输入网格计算，不能以原P低分辨率标签掩盖细连接；最终评价原图原始COCO GT。

GT自身真实8连通部件分别处理。每个匹配实例最多8对同部件前景锚点（部件中心与确定性抽取的其它前景点），鼓励连通；最多8对目标独占前景/邻居独占区或不同可见GT部件锚点，鼓励分离。GT合法重叠不当负例，没有独占核心者跳过此类负对并记录。不得强制每个COCO实例只有一个部件。

对真实mask sigmoid概率的8邻接图，边值=min(两端概率)，MST获取maximin路径。正对只在GT前景图内找路径，选最弱前景点；负对在完整ROI找路径，选路径中最弱的**GT背景**点，绝不压低真实前景。动态离散选择detach，梯度直接进入实际掩码logit。此为GT一致的maximin路径关键像素监督，借鉴[MALIS](https://proceedings.neurips.cc/paper_files/paper/2009/hash/68d30a9594728bc39aa24be94b319d21-Abstract.html)原则，但不是声称完整实现原MALIS或拓扑形式保证；没有可绕过最终mask的独立辅助头。

A/C也先计算对应关键点数量，再替换为同GT类别、同logit固定分箱[-4,-2,-1,0,1,2,4]中最近logit的非关键像素，确定性同值破同分；若不存在同箱则同类最近，若无非关键同类则保留并记录fallback。配对数量、类别和loss权重相同。全训练非关键难度成功匹配率须>=90%才支持“排除普通难像素权重解释”；否则该归因未决，不改控制追结果。

每图loss：GT soft-IoU +0.25 GT BCE +0.1所有非空ROI实例原生概率BCE保护 +0.25关键/匹配像素BCE。关键点项正负类各先均值、再类均值、再有候选路径的匹配实例均值；无候选贡献0且保留计数。GT项匹配实例均值，保护项所有输出实例均值，最后有效batch4均值。8输出以内分块及纯tensor loss激活重算必须与整图分母相同，不得通过分块改权重。

## 4. 数据、冻结与预算

沿用已下载的历史G_budget原20k训练清单及三轮顺序，原生sourcebatch16、训练有效batch4，每臂3轮15000步，四臂总60000步。每轮每图一次，不追加seed/训练。20k中有历史2k，明示开发沿用；验证为原生完整5000 val图，使用历史TRACE逐batch成员/位置/rect_shape，不重新按宽高比重排同形图。5000图也已多次开发，不称独立盲测。原256面板只作事后可追溯描述，不替代完整评价。

笔记本通用data/annotations训练JSON仅993图，禁止使用。完整训练标注来自本机assets/datasets/coco/annotations原文件，SHA必须等于历史合同 `610fce4944abdeb15354cc765333805529359d12d88f2f711393ca586901d01d`，复制到本Study独立data/annotations，保留原子集。20k/5k每张图均核历史合同SHA，缺图不得换图/缩小分母；复用SSR下载图只读取，不恢复SSR。

冻结CONFIG所有优化参数：AdamW lr1e-4,betas(.9,.999),eps1e-8,wd1e-4，其余flags false，无AMP/EMA/scheduler/clip/增强/早停/最佳checkpoint选择；仅last15000用于评价。每臂独立模型/优化器，原生输入在线每sourcebatch只提取一次、四臂共享，保存跨轮张量身份与GT join。无GT图仍计预算。每轮非选择checkpoint保留；任何已开始正式优化的Run不得自动重开以重置预算。

合成控制：GT多部件、合法重叠、maximin路径弱点/切断、负点GT一致、匹配控制同数量/类别、目标完全不进入forward、四臂同参数/初始state、zero-delta/有限梯度、分块分母及padding隔离。真实smoke：最大rect训练sourcebatch16图每臂4步，丢弃smoke权重；历史val首16图P/c0/图像张量/全部原生及旧G RLE精确核验。预测余量25%的四臂总训练估时<=96小时才正式执行。输入准备3小时、smoke2小时、训练96小时、全评价48小时、统计24小时；CUDAallocated/reserved<=6GiB、RSS<=8GiB、可用RAM>=.75GiB、D盘保留12GiB。本Study不保存dense F长期缓存，新产物<=22GiB；不动其它会话服务。

## 5. 冻结评价、机制与效用判据

完整5000图保存N/旧G/A/B/C/D预测及逐普通GT的独立bbox/segm匹配。N与旧G必须逐行重放历史全量JSON；非Mask字段、输出身份和Box匹配严格不变。旧G指原2k soft-IoU+9216门控（原checkpoint SHA），不是缺失的服务器G_budget；D−旧G是当前方法实际比较，训练预算不同不能作架构因果对照；D−B/D−C才是匹配比较。

GT锚定面板由**N唯一固定Box75配对**决定，不因新方法成功/失败更换；真实GT损伤仍在全量原成功普通GT上计算，不是仅该配对面板。拓扑主指标沿用STA的8连通实质分裂/邻居独占区混入>=GT面积1%，二者分别和并集报告，未知独占核心单列；主并集率仅在N预先定义的有独占核心固定配对上比较，其余对象的分裂与完整计数仍保留；4连通为敏感性。跨实例混入仍称候选，不冒称已人工确认桥接。GT多部件、漏整个部件、覆盖率与孤岛另列，不能缩小mask骗拓扑分数。

预指定主方法D，所有比较用2000次按图配对bootstrap，seed1729，先图内再图等权：

- 拓扑效用：D相对N的实质分裂/混入并集率相对下降>=20%且下降CI下界>0，D相对旧G下降CI下界>0；分裂/混入各自报告，任一显著恶化则不支持通用改善。
- 监督机制：D相对C并集率相对下降>=10%且下降CI下界>0，同时A/C难度匹配>=90%；否则不宣称拓扑选择超越难像素权重。
- 局部表达：D相对B下降CI下界>0；同D强制ridge投影回系数空间及与D等实际输入ROI响应RMS的双向缩小干预，预期局部优势仍在。等幅rtol1e-4/atol1e-7，未匹配保留无效，不改容差；若无优势不宣称局部自由度独立效应。
- 像素/任务护栏：完整固定配对IoU D−N图宏>=−.001；全量原成功GT任务损伤<=1%；Box身份不变。全量Mask AP与旧G的增量/区间及算力代价单独报告；宣称综合效用通过还需D−N及D−旧G的AP区间下界均>=0，否则保留“AP非劣未证/已证退化”的实际状态。若AP或损伤有明确退化，不以拓扑改善称实用方法成功。旧S3 +.30AP判据不追溯更改，本Study通过也不自动放行旧S3/S4。

仅A/B显效而D无额外收益，优先监督；D同时超过B/C且护栏通过，支持当前实例局部解码+连接监督复合配置；仅拓扑数值改善但漏覆盖/损伤增加，关闭当前配置；区间跨0或控制失效则机制未决，预算结束，不自动追加训练。所有结案均按完整实验展示范式交付相对N与旧G收益/损伤、机制边界及有依据的唯一下一步。任何新训练/扩量另行授权。
