# 预测尺度条件化的掩码边界校准

更新时间：2026-09-15。当前：train2017 拟合的响应条件化门控已完成冻结评价，4500图 Mask AP=43.9395，比原基线 +0.5607 点、比旧连续规则 +0.1113 点；误伤由576降至445，同时少修复106个。最佳网格全局阈值对照和真实推理接口验证均完成。

## 从失败对象出发

本路线研究“框定位较好、掩码已覆盖目标，却因非目标像素过多而未达到严格 IoU”的失败。诊断对象固定为同类 Box IoU ≥ 0.75、基线实际掩码目标覆盖率 ≥ 0.95、Mask IoU < 0.75。**实际掩码覆盖率与预测框的几何支持率不同**，本轮分别记录。

对这类对象，继续增加前景不一定有帮助。我们直接检验模型已经输出的连续 mask logits：在原型、系数、检测框与类别分数不变时，调整二值化等值面能否以较少自身覆盖损失去掉更多错误像素。该干预可以定位“现有响应的读出仍有改进空间”，不能据此断言特征、原型或系数训练已找到唯一根因。

## 方法与本轮完善

设 L 为原型与系数线性组合后，上采样到输入尺寸、按预测框裁切的 logits；A 为用阈值 0 生成并导出至原图的预测掩码面积。A 完全来自预测。

分段版本：A < 2304 时取阈值 0.75，否则取 0。新增连续版本：

\[
\tau(A)=\frac{0.75}{1+(A/2304)^2},\qquad M(x)=\mathbf 1[L(x)>\tau(A)].
\]

连续规则避免在 48² 面积附近突然跳变，并使大实例的校正幅度逐渐接近零。它是本轮预先固定的对照函数，尚未证明此函数族或指数 2 最优。分段规则仅修改小预测实例；连续规则也可能轻微影响更大的实例，不能沿用“大目标完全不变”的表述。

两种版本均无需训练，不在推理时读取 GT，不添加 mask head。保持官方顺序：**先在输入网格二值化，再按官方缩放逻辑导出二值掩码**。部署代码是 [mask_calibration.py](scripts/mask_calibration.py)，实际预测入口是 [predict_calibrated.py](scripts/predict_calibrated.py)。

本轮同时比较统一提高阈值、对小掩码做一次 3×3 腐蚀、按输入网格面积门控，以及历史连续 logits 缩放顺序。所有方法共享一次前向及明确的候选索引；空掩码统一剔除并计数。

## 对失败机制的具体解释

开发集有 201 个满足“框好、实际覆盖充分、掩码失败”的目标。连续规则将这组的平均 IoU 从 0.6567 提高到 0.6940，纯度从 0.6661 提高到 0.7175，覆盖率从 0.9802 降至 0.9574；其中 63 个跨过 IoU=0.75。整个开发集仍损伤 61 个原成功实例，须同时报告。

精确的收益条件如下。GT 面积为 G，基线 TP=T、FP=F；收紧删除 TP=u、FP=v，则：

\[
J=\frac{T}{G+F},\quad J'=\frac{T-u}{G+F-v},\quad J'>J\iff Tv>(G+F)u.
\]

因此，删除错误像素的收益必须超过丢失自身像素的代价。公式是集合运算恒等式，不能单独作为因果机制证据；每个固定实例的 u、v、IoU 和转移已记录在 CSV 中。

为避免只展示最好看的案例，在“覆盖充分的修复”“其他修复”“损伤”三组中各选绝对 IoU 变化的中位实例，并重新推理核对指标。下图第三行清楚显示：基线已较纯、但覆盖不足时，继续收紧会加重漏分。图像仅作解释，不替代全体统计。

## 解码顺序与历史结果的关系

历史脚本先将连续 logits 缩放至原图再二值化；官方 predict 在输入网格先二值化，8.4.100 JSON validator 再缩放二值掩码并转 byte。两种顺序不可直接视为等价。

在相同 500 图上，历史顺序的基线为 46.853 AP、分段规则为 47.556 AP，内部增益 +0.703；官方顺序的对应增益为 +0.368。历史增益应按其真实解码流程解释，不能直接称为未改动官方 model.val 的提升。新基线已在 3 张真实图的 602 个掩码上与官方 process_mask 逐像素一致，在同一输入尺寸与 process_mask_native 也无差异；这不等于已经验证完整 model.val 的所有预处理和导出路径。

## 实际部署与开销

原生 predictor 适配器已在一张真实图上运行：阈值设为 0 时，框、分数和掩码与官方 predict 完全一致；启用校准后正常输出。当前适配 `retina_masks=False`，不把未测的 retina 路径列入支持范围。

单个真实张量形状的 CUDA 同步微测：24 个掩码、输入 448×640，原 decoder 中位 1.007 ms，分段校准 1.866 ms。面积计算与额外缩放有代价；这不是全模型端到端延迟，也不能声称零开销。

候选论文的论证链为：**明确外溢型失败对象 → 冻结网络干预二值化读出 → 量化尺度相关的修复/损伤平衡 → 提出轻量尺度条件化校准 → 用正常 COCO 指标和迁移实验检验**。目前能够主张的是有实证支撑的方法候选，尚未完成独立校准集、跨权重/数据集迁移和端到端速度评价。

自适应阈值已有相关研究，例如 [supervised adptive threshold network for instance segmentation](https://arxiv.org/abs/2106.03450) 在 Mask R-CNN 框架中研究自适应二值化。因此不能主张“首次自适应阈值”；需要进一步证明实时原型式模型中的具体失配、简单尺度规则的有效性和实用成本优势。下一阶段应在 COCO train2017 的独立校准子集确定规则，再评价标准 val2017；当前反复探索的验证集不承担最终泛化证明。

## 预测收紧收益的校准器（2026-09-15 已完成）

本轮冻结 YOLO 权重，只学习是否采用既有连续收紧结果。令 ΔJ=IoU(M_smooth,G)−IoU(M_base,G)，用所有基线固定匹配实例的 ΔJ 作监督，分别拟合面积、面积+形状、面积+形状+收紧响应三个小回归器。部署时输入来自预测；仅当预测 ΔJ>0 时采用收紧掩码，其他情况保留基线，校准后为空也保留基线。三个回归器使用相同的模型容量与训练参数，不根据 val2017 结果改变阈值。

在平方损失下，回归目标对应条件期望 IoU 收益；零阈值决策针对期望实例 IoU，不保证 COCO AP 最优。因此同时评价正常 AP 与修复/损伤，不能只看回归误差。新机制仅控制已有掩码的收紧，不会扩大掩码以修复原先欠覆盖的像素。

## 论文写作定位（2026-09-15）

当前证据足以开始撰写完整初稿，研究主张限定为：对已覆盖目标但包含过量非目标像素的失败，固定网络改变掩码二值化读出可以修复一部分错误；进一步根据预测面积、形状和收紧响应学习连续IoU收益，决定是否采用校准，可改善修复与损伤的平衡。GT用于train2017校准监督，推理特征均来自预测。已有m/s权重结果和冻结迁移支持方法候选，不将阈值调整本身或跨权重后处理作为首次贡献。

相关工作初查：[supervised adptive threshold network for instance segmentation](https://arxiv.org/abs/2106.03450)已研究自适应二值化；[Boundary Patch Refinement](https://arxiv.org/abs/2104.05239)已研究后处理边界细化，其CVPR论文包含从一个分割模型向其他模型迁移的实验。正式论文仍需有针对性地核对这些方向与质量评分/收益预测的区别，并补最接近且可复现的对照，不能仅凭当前初查宣称新颖性。

建议正文围绕失败对象、受控读出干预、收益预测门控、冻结迁移和计算代价组织。投稿前优先补全正常COCO val5000报告（探索历史如实披露）、AP配对不确定性、校准器不同抽样/seed的稳定性，以及与主张匹配的独立模型或数据验证。全量5000不是新的盲测；反复探索的验证图不能通过改名恢复独立性。若强调高效部署，则必须先处理当前响应门控比固定连续规则多约21.8ms、仅多约0.10AP的代价问题；否则作为精度与代价的取舍报告。

这是一篇有实证基础的掩码读出校准方法初稿，尚不能据此保证录用或宣称顶级会议所需的新颖性与泛化证据已充分。
