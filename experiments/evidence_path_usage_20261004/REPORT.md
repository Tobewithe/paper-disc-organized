# 证据通路使用审计：作用存在，但当前增益主要不来自细致空间修正

冻结同一个均匀64点模型的末轮参数后，额外证据路径相对关闭路径，开发集正常原图macro IoU增加 **0.0096个百分点**；保留完整空间变化相对仅保留实例内证据均值，增加 **0.0026个百分点**。两项区间均落在预先固定的±0.1个百分点内。当前检查点没有实用量级的新增空间效用，停止此配置，不据此追加训练或修改权重。

这是已有模型的零训练构件检查，不是新方法。原模型与完整U路径在1816个官方候选上的六项历史指标逐值复现（最大误差0），参数与运行状态未变。正式运行105.02秒，两个Run的60份文件已SHA256核验回传。

## 幅度与损益是否抵消

开发集残差r的候选平均RMS为0.01297，远未达到±4的输出限幅，饱和率为0。额外路径在固定16×16响应上的RMS为0.01105，原生分支更新的响应RMS为0.31063；均值之比约3.56%，只是一项描述，不能推断训练不足或梯度竞争。

在640输入网格、固定预测框支持内，完整额外修正RMS为0.01123，均值项0.00992，空间中心化项0.00522。中心化能量占r总能量的候选均值为27.92%：空间变化确实存在，不能说网络只输出常数。

关闭额外路径后，逐候选绝对IoU差先图内平均再图间平均为0.0601个百分点，而有符号净收益为0.0096个百分点；空间变化相对MEAN的绝对差为0.0159个百分点，净收益为0.0026个百分点。存在正负抵消，但绝对变化本身也较小，不能只用抵消解释没有净收益。未保存FULL与NATIVE二值掩码的直接逐像素异或数；现有像素变化计数均以A为参照，不将它们相减冒充路径独立改变的像素数。

只读复核还显示：FULL相对NATIVE有1407/1816个候选IoU发生变化。均值项与空间中心化项在640网格的内积虽有1670/1816为负，但相对两项能量和仅抵消约6.50%；原生与额外路径在16格域的平均内积为正。不支持“强烈相互抵消把本来很大的信号压没”这一解释。统计复核保存在[RESULT_REVIEW.json](RESULT_REVIEW.json)。

## 决策

1. 本轮填补了同一参数下证据路径使用程度的缺口，原历史结果不重跑、不覆盖。
2. 当前额外路径有微小非零贡献，也有覆盖损失；其空间变化没有达到本轮实用量级。没有证据支持沿此配置增加epoch、扫描权重或添加gate。
3. 这不证明原型信息不存在、所有框读出无效，或唯一根因就是特征不足。当前表示来源、求解器及训练预算共同限定结果。
4. 本Study结束，研究总Goal仍未达到。下一方法需提供历史未覆盖的新信息/计算及判别对照；笔记本工作由另一线程负责。
