# 已训练证据通路的实际使用：固定U参数的零训练审计

2026-10-04，服务器执行。笔记本属于另一线程，不访问、不修改、不跟进其任务。

## 新问题及依据

fast-screen五种选点在三轮后相对同预算N仅约0.004–0.007pp区别，没有实用收益。smoke证明梯度连通，但正式记录只有总loss、总梯度，尚未分开同一个U参数下的原生分支变化与额外证据通路作用。不能直接据此说新增空间信息没用，也不能仅凭梯度小断言预算不够。

本轮只问：当前U的额外残差是否实际改变原图掩码？其空间变化部分是否贡献效用，还是均值成分已解释目前作用？不同于已经完成的选点方法比较，本轮不改变选择器、不重训、不新增信息输入。

复用[原报告](../prototype_readout_fast_screen_20261003/REPORT.md)、point_head与joint_head的真实forward_details；U是固定均匀64点参照，选择它不是因为跑后效果最好。文献只提供输出依赖读取的研究背景，旧[机制笔记](../../project/research_notes/PROTOTYPE_READOUT_MECHANISM_FOLLOWUPS_20261003.md)已有K-Net等原文；本轮是已有模型的构件消融，不主张新方法或新颖性。

## 固定对象及五条路径

固定官方8.4.100/YOLO26m-seg，原P、neck F、候选、框、类别与标签；U固定epoch3 checkpoint `RUN_715e40686dbe45d8ab12ffa83040211a/final.pt`，不改变任何权重、BN状态、算子或阈值。相同当前cv4输出记作c_U，原模型输出为c0。64点signed residual记作r，冻结projection为K。

| 臂 | 系数 | 检查 |
|---|---|---|
| A | c0 | 原始参照 |
| FULL | c_U + K r | 原训练模型完整输出 |
| NATIVE | c_U | 同一参数关闭额外路径，不是另训N组 |
| MEAN | c_U + K(mean(r)·1) | 仅保留每实例证据均值 |
| ROLL | c_U + K roll(r) | 保留r值多重集但改变空间对应 |

U索引必须逐项等于(0,2,4,6,9,11,13,15)两轴笛卡尔积的行优先顺序。只有经过这项核验才将r变为8×8，沿两轴roll4格。Q/P的任意点不能这样处理，本轮不运行Q/P。

数学限制：`P K(mean(r)·1)`通常仍有空间变化，MEAN不能叫全局bias/阈值校准。ROLL保持r均值及范数，却不保持Kr或PKr的幅度；不能将FULL优于ROLL单独归因为正确空间信息。记录r的均值、空间标准差、RMS和中心化能量，以及原生/额外/均值/中心/roll在系数和冻结A_full响应中的幅度。`Δz_full=Δz_mean+Δz_center`可在连续响应上验证，但IoU不可相加分解。

## 数据、检查与预算

复用服务器1024/256官方候选缓存，不复制大缓存。只评fit清单前128张计划图（拟合诊断）及全部256计划dev图；无正样本图列出，所有已有候选保留。dev原A与FULL逐永久7键复现历史A/U的IoU、Mask75、coverage、AUC、FPR和参考BCE，容差1e-12；结构重建FULL=c_U+Kr按3e-5绝对/相对容差。超界停止查执行原因，不放宽容差求通过。所有臂保持相同解码，原COCO GT用于原图指标，官方overlap标签用于参考BCE。

## 评价与结束

主比较dev FULL−NATIVE、FULL−MEAN，ROLL为对应敏感性辅助比较。五臂分别与A对比；报告图片macro及候选平均IoU、Mask75修复损伤、coverage、连续logit AUC/FPR、官方BCE。按整图配对bootstrap1000次、seed20261004，区间为探索描述；成功/失败和框好掩码差由A固定，不挑子组替换整体。

若FULL−NATIVE及FULL−MEAN的dev macro IoU区间都包含在±0.1pp内，称当前检查点上新增路径及其空间变化没有达到这个预设实用量级；不是数学零作用或信息不存在。只要区间不够窄，保留不确定；不以点估计近零证明等价。

若功能变化存在但任务指标无益，说明此参数下已产生的改变没兑现任务收益；不把它扩大为所有信息源无效。若任一冻结路径相对A达到整体+0.2pp且区间下界>0，或主失败组+0.5pp且区间下界>0且整体不低于−0.1pp，保留探索信号，之后另行独立确认，不能立即称方法成功。

无论结果如何本轮到此结束，不以本审计自动授权更长训练、新loss、gate或更大输入。弱作用不能自动解释为梯度竞争，均值作用也不能归为只需阈值。本轮只填补已有模型使用程度的证据缺口，研究总Goal仍需实际收益及独立确认。
