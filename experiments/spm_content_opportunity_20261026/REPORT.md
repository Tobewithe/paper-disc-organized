# 固定内容候选的真实修复机会

本实验完成已训练V23固定模型的432张真实图、12899条正常检测和全部26动作核验，训练更新为0。GT辅助的可行组合Mask AP达到63.461560，较原生+6.118060，框不变、原Mask75损伤0，且与本候选池乐观上界逐值一致；只在N/C21选择的上界仅60.956351。因此现有新候选已包含+5所需修复，应优先学习实际动作空间的质量判断。正常无GT模型仍为60.753278，整个goal尚未达到目标。

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | V23真实Mask AP60.753278、对N+3.409778、对C21+.336752，仍差1.590222点达到+5。训练成本只兑现31.48%机会，同时源部位IoU38.699%、实际真实包络过宽和规范字段binary变化0，不能据此直接选“改风险器”或“重做库”。 |
| **机制假说** | H为正常选择器未兑现已有有益候选；H_alt为当前正常匹配生成的候选本身不足以达到目标。前者预测固定候选中存在通过+5及护栏的可行GT见证；后者若连放松原成功保护、阈值和前缀一致性的乐观上界都不足，即得到当前有限池的否定证书。 |
| **针对性方法** | 原模型/N/C21/Box/Class/score/顺序/身份/top1/26动作均固定，完整正常RGB后才读GT计IoU。预先固定Mask owner和Box owner两个有限选择规则，分别给全动作与N/C21两动作的配对见证；原N自身Mask75保护只作有限见证约束，最终损伤用完整官方匹配核验。每分数前缀最大匹配构造上界，避免把贪心配对误当上界。单A6000一次性467，0优化，不扫描权重或动作。 |
| **整体结果** | 全动作Mask/Box owner见证AP63.461560/63.447724，分别对N+6.118060/+6.104224、对C21+3.045034/+3.031198，原Mask75成功2126中损伤0、修复138，三尺度和定位护栏通过。两锚配对见证均60.956351、对N+3.612851，未到+5；其乐观上界同值。全池上界63.461560与最佳可行见证相差约1e−14，有限池上下界实际闭合。原三输出逐行精确重放；独立96统计误差0，257980个前缀经另一种匹配算法及等大小顶点覆盖证书核验，损伤/修复计数也精确。 |
| **研究决策** | 优先训练读取实际动作Mask空间形状的质量决策，固定现有对象候选，停止只在N/C21切换、扩大库或重复训练V23。选择依据是新候选提供了两锚无法达到的可行机会，正常策略仍距最优有限组合2.708282点。下一步为新版本的实际动作条件质量残差：以原策略为精确保留初值，仅用train学习实际640成本的相对值，再正常完整评价。该结果支持“选择存在未兑现机会”，没有唯一证明旧8个统计量是根因；新增空间输入/参数/监督的混杂须披露，按新协议做输入干预。尚未启动新训练；未达正常+5前goal继续。 |
