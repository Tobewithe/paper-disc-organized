# 实现细节冻结（模型拟合前）

2026-10-18，前端缓存已生成，身份模型与收益门尚未拟合，保留集尚未评价。

- 基础更新公式沿用 Deep OC-SORT 的置信度 EMA：`beta=(1-.95)*max(0,(score-.3)/.7)`，`M'=normalize((1-beta)M+beta*f)`。收益标签和部署写入完全一致。config 中旧预备字段 `utility.write_weight=.1` 不被任何计算使用，留存以审计，不代表实际更新系数。
- 收益标签在训练序列 t+3、t+6、t+12 的有效对应帧上计算平均区分度改变量；无未来同身份或竞争对象时不构造标签，不补零。
- 身份投影采用监督对比损失；收益预测采用放大 100 倍的目标与 SmoothL1，推理结果除以 100，门槛仍为 0。
- 收益门输入共 8 项：分数、框重叠、掩码冲突、掩码面积平方根、当前与旧记忆相似度、相对其它旧记忆差距、历史长度、距上次观测间隔。训练数据来自基线实际关联，包含错误关联，不用 GT 强制改轨迹。
- 重新确认只针对基础跟踪器新产生且在缺失身份附近的短轨迹；连续运行的既有轨迹仍由基础关联负责。本原型不具备任意串号回溯纠正能力。
- 恢复候选限在相对框对角线 2 倍距离内；短轨迹至少 3 个观测；相似度减去 .05×归一化距离，阈值 .75，行列竞争差距均至少 .05，最多延迟 6 帧后新建 ID。所有消融使用相同配置。
- 评价输出只用原检测框。暂不确认帧不输出最终 ID，计入严格 MOT 的漏检代价；可视化单独显示待确认状态。
- TrackEval 源码固定 commit `12c8791b303e0a0b50f753af204249e622d0281a`；仅兼容 NumPy 已移除的类型别名，不改指标算法。完美轨迹与一次身份切换用例应分别满足 IDF1=100/低于100、IDSW=0/1。

这些细节不增加训练步数，不使用保留测试结果选参。后续如有工程错误，记录失败 Run 与修复内容后重跑对应阶段。
