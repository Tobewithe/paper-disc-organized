# 密集视频身份保持与遮挡恢复：小样本原型协议 v1

冻结日期：2026-10-18。执行环境：用户指定的 28358lan / RTX 4060 Laptop 8 GB。
本线独立于原型—系数小论文；不改变其权重、Run、训练或 Gate。

## 研究问题与证据

历史 `EV-E7-BYTETRACK-SAM2` 在 105 帧密集片段产生 18 个临时 ID，且没有身份 GT，故只支持“输出碎片值得研究”，不能给出 IDF1 或声称 18 次错误。
Deep OC-SORT 已采用置信度自适应外观更新；MASA-OA 已有重叠冻结，不能把“加外观特征”或“遮挡时冻结”单独当作新贡献。

H：遮挡期间错误/混杂的外观写入，以及重现第一帧的过早绑定，会降低后续身份区分能力；用**对未来身份区分的预期收益**选择记忆写入，并用**短轨迹的竞争证据**确认重现身份，有机会减少误接。
H_alt：主要限制是检测漏检和个体外观不可区分；保护记忆/延迟关联无法弥补，甚至造成更多身份碎片。
可区分预测：固定检测与身份表示后，新方法应提高 IDF1；若仅增加等待/普通重叠冻结即可获得相同改善，不能归因于收益学习或竞争确认。

## 数据和阶段

采用官方 AnimalTrack：pig_3、pig_5、horse_4、horse_6 为训练；pig_4、horse_5 为开发；pig_1、pig_2、horse_1、horse_2、horse_3 为一次性小规模保留测试。
按完整视频划分，遵守官方 train/test；horse_7 本轮不用，不因结果再选入。每个选定视频使用全部原生帧；不得依据结果挑帧。
训练与测试的个体编号只在各自序列内有意义；正例不跨视频。测试 GT 只供评价器，不能进入特征、门控和关联。
自采视频取两个预先确定片段：VID20260511133439 的 15–30 秒、6650–6665 秒，旋转到正常方向、缩放至 960×540、采样 15 fps。没有 ID GT，仅作现场可视化，不计算准确率。
既有 2019 年标注视频暂不混入：标注时间轴和完整性仍需单独核实。

## 冻结前端与小样本模型

猪：既有 PigLife 微调 `yolo26_task05_final.pt`；马：COCO `yolo26m-seg.pt`。同一视频各臂严格复用同一输出缓存。
Ultralytics 8.4.100、真实 end2end=True、agnostic_nms=False；imgsz=960、conf=.1、iou=.7、max_det=200、retina_masks=False、FP32、batch=1。
推理不读取 GT。实例身份原特征为预测掩码在 P3/P4 上的加权均值与 P3 标准差；所有外观方法共享。
输入视频/GT/权重/代码 SHA 在 input_manifest、source_manifest 与 Run 合同中冻结。源码若修工程错误，新 Run 并保留失败记录。

身份投影：标准化后的固定特征 → Linear(128) → ReLU → Linear(64) → L2；只训练此头，随机种子 20261018、AdamW lr=.001、weight_decay=.0001、300 步、每步 16 个身份×4 样本、监督对比温度 .12。标签来自训练帧预测与 GT 的 IoU≥.5 一对一匹配；最后一步为固定 checkpoint，不按测试选模。
收益门：当前得分、框重叠、掩码冲突、掩码面积、与既有记忆相似度、相对其它身份的差距、历史长度等当前/过去信息 → Linear(32) → ReLU → Linear(1)。训练 200 步，种子相同，AdamW lr=.001；训练目标为更新前后对未来同身份与竞争身份的相似度差变化。未来仅用于训练标签，绝不作为部署输入。
先完成前端 2×8 帧 smoke：输出有限、候选/掩码/特征对应、显存可用，通过后全量缓存；不以 smoke 宣称方法有效。

## 对照和创新边界

N：同检测的 Ultralytics ByteTrack。
R：同检测、同身份投影的 Ultralytics Deep OC-SORT 实现；不是官方论文成绩复现。
C：R + 普通重叠冻结（最大框 IoU>.35 或掩码冲突>.25 时不更新）。
U：R + 学习的收益写入，不做短轨迹确认。
M：U + 有限时长的重现竞争确认。
消融 D：C + 与 M 同样的重现确认；用于判断收益学习是否优于简单冻结。
缓冲区全臂最多 60 帧；每身份一个记忆向量，预遮挡受保护快照与短片段空间上限须对相关消融完全相同。M/D 的确认最多 6 帧（30 fps 时 .2 s）；计算与延迟单列，不冒充零延迟。对已输出历史帧不事后回写 ID。
所有臂输出实际匹配的原始检测框，不用 Kalman 框改善定位，不添加虚构不可见掩码；保留待确认输出和遗漏代价。

## 评价、归因与停止

主指标：官方 TrackEval Identity 的 IDF1，0–100 点；各序列结果及官方 combine_sequences 合并值均报告。补充 HOTA/AssA/DetA、IDSW、漏检/误检和推理耗时用于辨别关联收益及代价。
AnimalTrack 第九列可见度为 -1，不能假装有人工遮挡标签。自然“间断后重现”事件按 GT 同一 ID 在 ≥2 且 ≤60 帧空缺后再次出现定义；称重现事件，不直接称已核实遮挡。分母包含全部符合规则事件，无检测也计入未恢复；前后可见帧不足 3 的记边界事件，单列不删除。
恢复结果：恢复原 ID、错误复用其它既有 ID、新 ID、未恢复；同时报告确认延迟。若自然事件太少，结果为证据不足，不通过挑片补充为阳性。可做明确标识的人工遮挡/检测间断功能检查，但不能混入自然测试成绩。

小样本推进门槛：M 相对 N 与 R 的合并 IDF1 均至少 +1 点，任一保留视频不低于 R 超过 3 点；误恢复率不比 R 增加超过 5 个百分点（分母不足 20 事件则该条证据不足）；D 对照用于区分收益学习贡献。只到最后固定模型完整测一次保留集，不因结果换阈值/数据或补训。
跨 5 个视频的区间只作描述性序列 bootstrap，不把少量视频当作充分泛化证明。

阳性：保留原型，下一步扩大独立场景与人工遮挡事件标注；阴性：保留完整系统与失败证据，停止本配置，优先转向身份表示可分性；信息不足：保留工程原型，唯一下一步为补充独立身份/遮挡标注，而非继续堆模块。
只允许声称本样本和本配置下的可运行性/实测效用；方法独创性、机制因果和普适性需要更多研究。可展示研究设计，不把候选方案包装成已解决全部遮挡。
