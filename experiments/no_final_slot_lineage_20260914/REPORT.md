# 无最终槽位实例候选生命周期溯源

在完整 COCO val2017 的 36,335 个普通 GT 上，当前 8.4.100 one-to-many+NMS 路径有 3,699 个无匹配最终槽位；历史分类的对应数量为 3,704，二者基本一致。当前无槽位对象第一次失败的位置为：原始几何 1,459（39.44%）、正确类别 1,033（27.93%）、0.001 分数门槛 745（20.14%）、NMS 184（4.97%）、评估前 100 个 135（3.65%）、前 300 个 93（2.51%）、分配竞争 50（1.35%）。

87.5% 的无槽位对象在 NMS 之前已经失败，因此候选筛选不是主因。原始几何失败中 1,429/1,459 是 COCO small，后续定位应优先追查小目标的目标局部表征和定位头。
