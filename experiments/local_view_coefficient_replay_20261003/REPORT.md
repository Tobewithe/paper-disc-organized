# 局部视图空间证据回投原图原型：快速筛选结论

**本轮没有得到有价值的净掩码收益，停止当前1.5倍上下文局部视图及固定OGPS投影方案，不追加倍率/阈值/solver搜索或训练头。** 原模型局部放大直接输出已经劣于原图；投影保留了一部分相对粗网格的质量，但没有挽回原模型的正常掩码质量。

2张图smoke约19.1秒，正式评价约190.75秒。二者已完整回传，transfer.json与manifest.sha256逐文件核验通过。正式Run为[RUN_a031448ed55d4f6db620122bb4d2014d](runs/RUN_a031448ed55d4f6db620122bb4d2014d/run.json)。这些dev图已参与研究，不是独立确认，不代表COCO AP变化。

## 主要结果

以下均为百分点，IoU为图片级macro；95%区间按图片配对bootstrap 1000次，多个探索对比的区间用于描述。

| 比较 | 原图IoU差值 [95% CI] | Mask75修复/损伤 | 净Mask75 |
|---|---:|---:|---:|
| 局部视图直接输出 − 原模型 | −2.7052 [−3.4047, −2.0579] | 81 / 148 | −67 |
| 局部视图→原P投影 − 原模型 | −3.6204 [−4.3176, −2.9848] | 42 / 169 | −127 |
| 局部视图→原P投影 − 原图同规则重选→投影 | −2.2147 [−2.8839, −1.5801] | 81 / 115 | −34 |
| 局部视图直接输出 − 原图同规则重选 | −2.6212 [−3.3224, −1.9688] | 82 / 149 | −67 |
| 局部视图→原P投影 − 相同8×8目标直接输出 | +3.3802 [+2.7795, +3.9883] | 121 / 79 | +42 |
| 局部视图→原P投影 − 局部视图完整直接输出 | −0.9153 [−1.1952, −0.6512] | 34 / 94 | −60 |

原图同规则重选本身相对原模型为−0.0840pp，区间跨零，1修复/1损伤。因此局部视图劣化不是简单拿不同raw候选作不对等比较的结果；原图重选控制同样使用top300和预测框IoU/分数/raw身份规则。

在框好掩码差的353个候选上，投影相对原模型macro IoU为−5.0138pp，局部视图完整直接输出为−3.1572pp。该组虽有33个/59个Mask75修复，但组内原本全是失败对象，损伤计数天然为0；不能用跨阈值修复数掩盖大量未跨阈值对象的平均质量下降。

投影全体coverage下降3.8185pp、AUC下降2.5631pp、FPR增加1.8892pp。局部视图直接输出FPR下降2.8232pp，但coverage下降4.7082pp、AUC下降2.3946pp；没有形成值得扩大投入的收益组合。

## 结论边界与决定

执行复核：1816个永久身份全部唯一且保留；A指标重放误差和原图P重放最大误差均为0。1771/1816（97.52%）的原图重选回到原raw，其余45个原raw不在top300。局部来源预测框对应IoU均值0.8713、中位0.9221，仅7个低于0.5；这只是预测框间对应质量，不证明对应实例语义必然正确。全部来源读取成功，30个候选的部分目标支持按协议使用原响应回填，各臂均2个AUC未定义但保留其IoU。solver最大相对后向误差约1.85×10⁻¹⁶，没有发现候选遗漏、原P漂移或求解故障。

1. 在此固定模型、1.5倍上下文、640输入、预测框对应方案中，局部放大没有给出更有用的总体掩码证据；不将其推广成“所有多视图方法无用”。
2. 原P投影优于相同8×8目标直接渲染，但差于完整局部视图且明显差于原模型。这是对粗目标的部分恢复，不是方法超过原模型的证据。
3. 原图概率先池化再截断/投影本身也有损失，ORIG_RESELECT_SOLVE−A为−1.4057pp，BASE_SOLVE−A为−0.3285pp。不得因为GT8 oracle曾强，就把该近似投影称为对任意预测信号无损。
4. 当前方案结案；不追加上下文倍率、solver正则、gate或新网络。总研究目标仍未完成，后续应选择不同的可检验机制，先查历史避免重复。
