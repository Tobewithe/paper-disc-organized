# S2 执行协议：2000图新增系数残差 pilot

2026-10-13。用户授权笔记本按总控执行；仅在 S1 正式机会 Gate 通过后进入。与 POSTTRAIN_RESCOPE、EXECUTION_CONTRACT、MECHANISM_AND_DEFAULTS 共同冻结；S1 和旧 Run 不改写。B 为唯一主要方法，C 为预定空间对照。

## 输入与配置

- 基础模型、推理和评价沿用 S0 的权重 SHA、Ultralytics 8.4.100、原生 fused FP32、batch=16、rect=True、imgsz=640及全部实际数值开关、检测行与解码。训练有效 batch 独立为4图。S0 全5000图缓存直接用于方法评价，保留原始几何，不重组矩形批次。
- fit2000 从笔记本实际可用、原始完整 COCO train2017 标注包含的图片中，排除已核实的历史 selection/dev 清单后，按 SHA256(`s2-fit-v1:0:image_id`) 取前2000图。旧 fit 重叠如实披露，允许同一训练数据对新方法作配对比较；不冒称训练图是历史未见。源标注、排除清单、图片及最后 ID 表均锁 SHA，不自动替换缺图。
- 效果开发集按 SHA256(`s2-dev-v1:0:image_id`) 从 S0 取前512图；若其中 T 少于200，仅按同一顺序补图到200个 T，完全依据基线标签。它是研发集，非盲测。拟合与评价图 ID 严格不重叠。
- 训练缓存使用同一原生 validator 及原有观察器捕获 P/c0/F。固定版本用文件名识别 COCO：隔离数据目录内的 `val2017.txt` 与 `annotations/instances_val2017.json` 仅为原生 API 兼容别名，实际内容明确登记为所选 **train2017** 图及其原始标注子集。目录、清单和合同显式记录别名；训练缓存指标不作为 val2017 基线结果。GT 不影响检测选择。
- 每图基线输出与零残差 RLE 在缓存时原样核验。训练在只读缓存上进行，网络特征、P/c0 和所有基础权重无优化路径；前后校验权重及缓存 SHA。原训练头、Proto 和 BN 不更新。

## 模型和训练

结构、8×8预测框空间采样、C联合置换和分组 loss 完全按 MECHANISM_AND_DEFAULTS：F 各层投影64，c0投影32，类别embedding16，空间两层64通道卷积后池化，拼接181→128→32；最后一层全零初始化。预测框几何采用 xyxy 分别除以实际 input W/H。真实 F 通道须与 S0 已观测的256/512/512一致。

B/C seed=0、相同初始参数和训练图片顺序，各3 epoch、AdamW lr=.001、weight_decay=.0001、无scheduler/early stopping、只用最后一轮checkpoint。FP32、无AMP、无新数据增强。有效batch=4，预定逐图microbatch=1梯度累积4图，最后不足4图按实际图数平均；2000图时每epoch500步，共1500步/臂。

GT join 按最终输出 JSON 的 score 降序、同分按原行序，正确类别和 BoxIoU≥.50；选尚未占用的最高IoU普通GT，同IoU按annotation_id。忽略/crowd不监督，未匹配输出仅保留基线。训练目标采用与 S1 相同的原始 COCO RLE 和实际 resize/pad 投影；损失按每实例预测框ROI像素平均，GT监督与全部输出保持项分别按实例数归一化，再按图片平均，保持权重=.1。GT/原成功失败标签均不进入forward。

## 验收与预算

- 缓存 smoke 最多8张fit图；训练工程 smoke 用同一8图做至多两个优化步，并用8张S0开发图验证零残差原生RLE、梯度/白名单、B/C初始化与空间对照。smoke模型丢弃，不参与正式选模。
- 正式缓存限2000图、16GiB、3600秒；每训练臂最多7200秒；工程smoke最多900秒。资源不足或错误留下独立Run，不运行中修改有效batch、精度或训练预算。
- S2效果：目标 T 的 image-macro ΔIoU≥.005，配对图像簇bootstrap 2000次、seed=1729、percentile/linear双侧95%下界>0；全部基线bbox75固定配对普通GT的image-macro ΔIoU≥−.001。B/C配对差同法报告，未支持B>C时限制空间机制主张。
- 损伤：预算在训练前固定为min(1024,|S|)。B最后checkpoint及推理合同冻结后、任何方法效果评价前，按 DAMAGE_ACCEPTANCE 一次无放回GT抽签，保存随机seed和清单；评估抽中GT所在图片的全部输出/GT。B单侧95%损伤上界≤1%才放行；C仅作预定对照，不根据两者结果挑赢家。
- S2失败即停止当前配置；通过才用同一B checkpoint进入 S3 全5000图 AP/损伤验收，另冻结该阶段重采样预算。20k/多seed不由本协议自动启动。
- 每次实验结束后先输出 CONFIG_AUDIT，核对冻结配置、实际生效参数及产物；核验未通过不得进入下一阶段。训练另核 B/C 初始化、样本顺序、有效batch、实际优化步数、参数白名单、权重与缓存前后SHA。

成本和边界：2k×3epoch是既定初筛预算，B/C仅各一次；使用缓存消除反复基础前向与矩形几何漂移。S1的47.66%是256个固定目标上的已找到机会，不能作为S2可部署恢复率。
