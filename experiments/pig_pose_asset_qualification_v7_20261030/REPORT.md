# 源猪体局部修复资格

本轮完成4个冻结候选和6张原/修复同视角图的实际审核。**2轮局部修复通过数值与有限外观准入，可作为后继姿态库的基础资产；自然姿态与正式合成数据仍未通过。**

| 维度 | 本次实验的整体研究链路 |
|---|---|
| 问题 | V6已证明原rest头部/尾根存在20组非相邻自交，尾根随机旋转又增加自交，不能直接扩大姿态随机化。 |
| 机制假说 | 工程主张：缺陷局限在小范围源表面折叠，可以在保持源身份时小幅修复；竞争解释是局部连接/内外表面结构使小幅平滑不足或造成新的翻面。不是模型泛化机制实验。 |
| 针对性方法 | 锁定同源网格与20见证，取两环及左右对称ROI，保护五个鼻/眼/耳anchor，固定0.2步长的2/8/24/64轮候选；全网格重查交叉、位移、面面积/法向和身份，不只复查原20组。对唯一通过者渲染full/head/tail×原/修复6图，并全部实际查看。 |
| 整体结果 | 2轮：20→0自交、196顶点变化、最大位移0.00271646体长；面面积比0.3683..2.9338，最小法向余弦0.4864，对称误差0，5anchor不动，11239顶点/22446面/9源部位与骨架蒙皮身份保持。8轮虽交叉0但翻面，24/64轮还超位移等门槛，全部拒绝。六图未见新增口鼻塌陷、尖刺、尾根断裂或明显轮廓损伤；保留原平滑人工外观，不称写实通过。相对原生模型/已有方法的AP收益及损伤未测，本轮无训练。 |
| 研究决策 | **准入2轮变体用于下一阶段合法姿态库建设；停止更强平滑。** 依据是最小改动者同时通过预冻结数值和实际图像核验，更强处理已产生损伤。唯一下一步是用修复rest建立有头耳肢蹄尾与地面支撑检查的站/腹卧/侧卧姿态，优先解决原来重复侧卧的构造；尚未在本轮完成。若后继姿态在该变体上仍产生穿体，按实际姿态失效修rig/关节范围，不把rest准入当所有关节自由度都已合格。 |

实际Run：本地 `RUN_V7_LOCAL_SURFACE_REPAIR_82a62d8b7fa1`，36.688秒；Slurm801/`RUN_V7_ASSET_COMPARISON_aa7c6a7ae472`，0GPU、6张640×480/32samples。37份远端原文件逐SHA回传，原始资产未覆盖。候选NPZ、原命令、源码、失败与全部见证保留。

这项修复使用自写均匀图邻接Laplacian，不是调用libigl或其cotangent/质量矩阵实现。[libigl原始教程](https://libigl.github.io/tutorial/#laplacian)仅作为离散表面算子与平滑的基础参考，不能据此宣称自交一定消除。原32边界边不自动闭合，零非共面交叉不是闭合体积/生物力学证书。

修复并没有扩充体型，也没有消除材质/小部位像素支持的缺口。两后腿源part最低点在整体落地后为0.002567体长，前腿为0；这是几何描述，不是步态/稳定支撑标定。实际看图只准入口鼻与尾根局部修复，不准入自然姿态或训练release。
