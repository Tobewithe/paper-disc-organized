## 这一轮测了什么

原官方COCO YOLO26m-seg/Ultralytics8.4.100不变。把原缓存完整640画布水平翻转，再把翻转模型的完整连续mask响应翻回来，保持原候选、原框和原图解码几何。原图和翻转图的P/c始终成对使用，不直接平均跨视图系数。

| 臂 | 实际操作 |
|---|---|
| A | 原模型 |
| ORIG_MATCH | 原图按相同预测框对应规则重选系数，控制重选行为 |
| MIRROR | 同尺度镜像raw位置的完整翻转响应 |
| MATCH | 翻转后同尺度、同原预测类别、预测框IoU最大的raw响应 |
| MIX | A与MATCH完整连续logit各占一半 |
| PROJ | 将MIX同一半幅增量以固定λ=.003的FP64 Ridge投影回原P，只改变原c |

来源选择不输入GT、不做TAL重分配或top-k/conf/NMS过滤；候选入组仍来自既有GT条件官方正样本。这不是全推理部署评估。镜像raw只代表对应网格中心，预测框匹配也不保证实例身份。

PROJ使用完整640预测框支持，没有旧OGPS的8×8概率池化/截断。旧local-view曾改变裁切上下文和尺度，本轮保持它们，因而不是同一负结果的改名重跑。预算、源选法、六组及阈值均见[启动前协议](PROTOCOL.md)。普通翻转集成及分割等变一致性有[SAC等先例](https://openaccess.thecvf.com/content/CVPR2021/papers/Araslanov_Self-Supervised_Augmentation_Consistency_for_Adapting_Semantic_Segmentation_CVPR_2021_paper.pdf)，不据此宣称原创。

## 正常原图效用

以下IoU为图片macro，单位百分点，95%区间为1000次整图配对bootstrap。多个探索比较未经独立确认；开发图像此前被使用过。

| MIX−A | +0.0852 [−0.0621,+0.2356] | 29 / 20 | **+0.5483 [+0.0998,+1.0515]** |
| PROJ−A | +0.0346 [−0.1193,+0.1835] | 27 / 20 | +0.4636 [+0.0547,+0.9457] |

| MATCH−A | −2.7680 [−3.7565,−1.9124] | 35 / 110 | −0.6418 [−1.7339,+0.4819] |
| MIRROR−A | −0.4920 [−1.0089,−0.1425] | 35 / 45 | +0.1567 [−0.4803,+0.7473] |
| ORIG_MATCH−A | 0，区间[0,0] | 0 / 0 | 0，区间[0,0] |

主失败组固定为A的BoxIoU≥.75、MaskIoU<.75，共141图353候选。MIX候选平均IoU同样增加0.3564pp，CI[+0.0118,+0.7097]，不是只有图片加权口径才为正；MIX救回23个，PROJ救回21个。该组原本全失败，因此0个Mask75损伤不能说明其他实例没有恶化。

具体而言，该组MIX有181个候选IoU升高、156个下降；其中101个提高超过1pp、90个下降超过1pp。这是有平均收益但不稳定的修正，不是只修不伤。

MIX达到协议中的**主失败组初筛条件**：macro IoU≥0.5pp且区间排零，全体未低于−0.1pp。它没有达到全体≥0.2pp的条件。PROJ主失败组虽有正向区间，但效应低于0.5pp，且其全体IoU可靠地低于更简单的MIX，不能因“也有救回”宣称投影有额外价值。

## 对位置读取和实现的判断

MATCH的掩码比MIRROR平均更差，尽管它按预测框IoU选位；原图同规则重选则完全复现A。**更接近原框不意味着该位置具有更好的实例掩码。** 这只是本轮预测位置对应的观测，不等于发现了官方训练错误或所有几何匹配均无效。

来源审计：MIRROR有1494/1816与原预测类一致，框对应IoU均值0.9055；MATCH有1815/1816同类、1例无同类回退，框对应IoU均值0.9147。MATCH与MIRROR同raw仅846个；MATCH有699个来源分数低于.001（MIRROR为494个）。这是预定全raw取源的一部分，不能把源位置当作最终保留输出，也不能事后过滤它们改善数字。ORIG_MATCH全部1816个都回到原raw、框IoU为1。

原c0/P/框、正常原图baseline、两次翻转、原模型冻结状态以及投影正规方程检查通过。所有1816个身份保留，空输出或变差实例未剔除；未定义AUC/FPR不移除其IoU。FP64完整支持求解及两种插值次序误差按预定阈值检查，self零增量保持原系数；未调容差、融合权重或ridge。

最大正规方程相对后向误差1.33×10⁻¹⁶，最大插值次序差1.91×10⁻⁵；无空支持。投影增量RMS/目标增量RMS中位数0.8374、系数位移范数中位1.7304，说明投影实际执行且包含可见的缩幅。独立只读复算600项分组/指标/臂的候选与图片均值，最大差4.37×10⁻¹⁶，永久身份唯一，原A五指标回放差为0。
