# CGS-T：有限后续轨迹收益的监督核验 v1

冻结日期：2026-10-19；在轨迹标签生成、拟合和新增 zebra 数据评价之前。
不修改 CGS-v1 结果和 Gate。horse_7 已完成一次确认，后续复用须称已见复核。

## 依据与主张

CGS-v1 的单帧净收益模型在 horse_7 相对运动基线 +1.524 IDF1，但远低于同容量正确性对照（62.312）和全部外观（68.200）；horse_3 仍较运动 -2.712。原净收益监督未体现预期额外效用，关闭该固定配置的增训。

H：仅监督当前关联，遗漏了一次决策对随后轨迹状态的持续影响；应学习相对保留运动方案的有限轨迹收益。竞争解释：有限后续收益与单帧标签基本一致，问题主要是现有特征无法识别场景差异。当前差距只是检验 H 的动机，尚不是 H 已成立的证明。

## 零训练准入

仍只用原四个 train 视频。对未干预运动基线遇到的、GT 关联可知的冲突组，复制同一个帧前状态；B 保持原方案，A 只强制当前一个组采用外观，随后两臂均按运动关联连续运行12帧（含当前帧）。不改分数、检测、寿命或其它组。局部目标身份由干预前每条轨迹最后一次 GT 匹配固定，未来GT只给离线标签。

收益为12帧内这些既存轨迹的正确身份观测数 A−B。未知 GT、轨迹漏输计0正确观测；视频尾部不足12帧的组不拟合。单帧标签与12帧标签符号不同的比例≥10%，且长程有益/有害组各≥20，才允许新头训练。否则停止此目标，保留单帧假说未受支持的事实，优先解决跨场景关联可观测性。必须验证未强制的分支重放与原 motion 精确一致，分支不污染原追踪状态/全局 ID 计数。

## 预算、控制与决定

若准入通过，只训练一个相同21→32→3、803参数的头，400步、batch128、AdamW lr=.001、weight_decay=.0001、seed20261018；与 CGS-v1 同初始化、同特征归一化、同 train/calibration 视频；只改变收益监督时域。阈值仍在 {.5,.6,.7,.8,.9,.95}，校准采纳≥10组、长程有害比例≤10%，最大化长程净收益；无合格阈值设1.1。

比较 N运动、A全部外观、C差距规则、M单帧净收益、L正确性、T轨迹收益。原 dev/历史五视频/horse_7/现场均完整复核。新类别确认固定用官方 zebra.zip 中按名称排序前两个完整序列，类别22、原官方YOLO26m-seg权重与原身份投影，无新增身份训练。下载可先进行，特征/评价在头和阈值冻结后；若不足两条则保留全部并说明。不能根据检测/跟踪成绩更换序列。

研发支持要求：原历史五视频 T−N≥1点、T−A>0、T−M>0，单视频下降>3必须披露。新 zebra 确认 T−N≥1、T−A>0、HOTA下降不超过.5，才支持本配置有限独立效用；否则关闭本配置，不按确认结果改阈值。不将预先已有对照的收益算成新方法贡献，不把一个类别两段视频称为通用泛化证明。
