# CGS 实现合同（拟合前冻结）

输入 21 维，顺序为源码 `FEATURES`：组规模、两方案匹配数、两方案运动 cost 均值、两方案余弦均值、外观最差余弦、行/列竞争差距均值与最小值、外观方案框 IoU 均值/最小值、分数均值/最小值、缺失间隔均值/最大值、轨迹年龄、当前特征与历史记忆相似度均值/最小值。
MLP 21→32→3，共803参数。三个类别为有害/无变化/有益；同容量正确性对照用0/2类别，保留相同网络与全部有效 softmax 梯度。两者同种子、同样本顺序、相同初始化、优化器与400步预算。
ByteTrack 外观状态沿用固定的置信度 EMA，任何未干预的输出必须与 v1 ByteTrack 完全相同。新增状态不进入运动滤波器。
只改第一高分关联。候选外观需余弦≥.8且预测框IoU≥.1；低分、未确认、新建、淘汰各阶段沿用基线。
标签引用轨迹此前最近一次有合法 GT 配对的实际观测，与当前训练检测的一对一 GT 匹配比较；只用于离线收益标签，不把该映射带入推理。跳过任何一边身份未知的冲突组。
收益为外观方案正确边数减运动方案正确边数，不用未来帧标签。此前协议的“净收益”在本版指即时身份对应净收益，不能宣称已优化完整未来 IDF1。
冲突组由两方案边并集的连通分量定义，包括增删匹配的路径与交换环；以完整组替换保证一对一。无差异的组保持运动方案。
校准的损伤比例为被采纳组中 gain<0 的比例，阈值从冻结集合选；该选择不保证新视频损伤比例。
