# 同源UV和关节回归数据接回资格；蹄部材质映射存在具体缺口

只读核验已完成，原作者4个文本文件均与固定commit的Git blob SHA一致。UV逐面身份和关节回归的本次必要条件通过，但没有获得现成皮肤纹理、新体型或细部位标签。事后复用源网格指出：内部脚关节Gaussian不能代表最低蹄表面，优先修表面映射已有具体依据。

| 维度 | 本次实验的整体研究链路 |
|---|---|
| 问题 | V15材质未解决涂层感，但近景已有分趾/耳内几何；此前源资产接入没有利用作者UV/J_regressor，也没有经过核验的鼻耳蹄表面组。先核已有资产能力，避免把弱外观直接归因于不存在的几何或盲换模型。 |
| 机制假说 | 不适用（工程必要条件）。核同源逐面映射是否身份一致、关节回归能否近似恢复作者rest；额外检查现有脚关节Gaussian是否在最低脚表面有足够覆盖。该覆盖检查不是解剖标签或材质自然度实验。 |
| 针对性方法 | 连接GitHub读取同commit目录/原文本，4文件共1,035,095原始字节逐Git blob SHA/SHA256、格式、索引核验；原faces_vert数组精确等于既有源面。UV图只用9源部位着色。原始8079稀疏回归权重保留，不归一化追阳性，比较A*V与作者62个rest关节。事后复用同一源网格，测原脚Gaussian在每腿最低.02体长几何探针上的权重。未执行作者代码/pickle、未读示例图或真实标签。 |
| 整体结果 | UV12208点/22446面、无未映射顶点，915点有多个UV索引；14个退化UV三角形保留，UV重叠和细语义未验证。关节权重和0.999976–1.000003，最大rest误差0.003056体长，过预冻结≤.005门槛；无形状blend basis，不当成自然体型库。脚关节高于最低表面.05665/.06204体长，最低.02探针每前腿275点/后腿220点的原Gaussian平均权重仅.08346/.05143，>0.5覆盖0；证明该关节附近高权重不保证最低脚表面覆盖，不能把探针本身叫作蹄GT。对模型/已有方法AP收益不适用。 |
| 研究决策 | **优先校准现有鼻、眼、耳、蹄的源表面组与着色映射**，保留原几何/9父部位/owner、未知区域归父部位，不把点距离代理直接升级成细语义GT。已有细几何、合法UV面映射及具体Gaussian偏上证据支持此方向，比新增3D模型或继续材质扫描优先。唯一下一步是冻结一次源面ID候选分组与固定多视角审核，分清可接受/unknown/需补几何区域，尚未执行该渲染；关节回归只保留为后续有限体型更新工具，不立即扩体型/姿态范围。 |
