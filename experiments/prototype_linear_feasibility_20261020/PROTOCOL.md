## 4. 可行性与不可行证书

设A_i=(2y_i-1)B_i，b_i=y_i。检查 A c >= b：前景Bc>=1，背景Bc<=0；由于c不受范数约束，这与前景严格>0/背景<=0的实数可分性等价。背景允许恰好0，不把要求负间隔的另一系统冒充原系统。

HiGHS双单纯形，单次30秒，原/对偶可行精度1e-9；确定性初始512行，最多12轮、每轮加入512个最违反约束，最终扫描全ROI。有限轮数/超时不是不可行。

不可行必须保存Farkas向量：w>=0、A^T w=0、b^T w=1。先由对偶LP提议稀疏支持，再用SymPy有理运算求权重，独立从原P与几何重建全部支持行、逐项精确验证。只有精确等式成立才标CERTIFIED_INFEASIBLE_REAL_LINEAR_GT_GRID。HiGHS status=2或浮点残差小均不足以认证；无证书记NUMERICALLY_UNRESOLVED。

可行系数保存FP32候选并作完整原生解码，核全N×32 GEMM和zero-delta。原图IoU>=.75是新的任务可修见证，优先于旧有限oracle失败分组。数学可行状态和原生FP32像素一致性分别登记；两者不同标REAL_NATIVE_GAP，不更改解码或精度。

## 5. 尺度固定的最大间隔

GT标签与C实际输入掩码分别求 max gamma，约束 A_i c >= gamma s_i、||c||_1<=1，其中s_i=sum_j|B_ij|。零行前景单列；零行背景不限制间隔。此量对c整体缩放和单行特征缩放不变，仍依赖冻结的原型通道坐标，不宣称任意基变换不变，也不等于历史RSM功能白化间隔。

不要求对偶精确平衡：对任意非负w，U=||sum_i w_i A_i||_infinity / sum_i w_i s_i 是严格的间隔上界。将LP对偶权重按其真实浮点值解释为精确二进制有理数，从原P精确计算U。下界由候选全ROI扫描给出保守浮点误差包络；若不能严格验证符号则记未决，另交原生重放。保存上下界，不仅保存solver success。

预冻结“小间隔”为0<gamma*<=1e-4：需要有效可行/原生标签见证与经有理验证的U<=1e-4；这是本量纲的操作阈值，不是普适结构常数。区间跨阈值列未决。GT不可行与C可实现掩码小间隔分别统计，不把不相同的掩码标签混为一项证据。间隔大于阈值的完整扫描下界削弱“小间隔”解释。

## 6. 预算、有效性与决策

合成控制必须覆盖：可分、同特征相反标签不可分、背景零响应合法、真小间隔、伪Farkas被拒、原P插值有理重建。之后4条独立smoke：全原生N及C精确重放；证书独立核验；资源通过。smoke权重不用于选阈值。本轮零网络训练/零模型forward，仅缓存解码和有限LP。

正式256条按image_id/annotation_id排序，逐条保存结果/证书/系数/原生RLE/耗时/错误；单标签求解总预算120秒，证书支持最多64行，有理重建最多30秒（超限未决）；正式总墙钟12小时、smoke30分钟，RSS<=6GiB、GPUallocated<=3GiB、可用RAM>=1GiB、D盘保留>=12GiB，新产物<=2GiB。每实例异常保留为未决继续，身份/zero-delta/冻结哈希失败则立即中止。训练步始终0。无定时任务或目标模式。

正式输出为各旧分组中认证不可行数、已证可分数、小间隔数、较大间隔数、数值未决数、原生解码不一致数；给出各自分母及交叉表。原134/97失败者中新增Mask75见证单列。结果描述此固定面板，不外推COCO总体。

方向裁决：认证精确标签冲突若占C失败97条至少一半，支持“高精度像素控制受固定P约束”这一限定命题，论文优先讨论表示/独立局部解码；仍不宣布这些对象到不了.75，后继需任务级可达上界。若至少一半有经验证的GT可分原生重放，优先解释为旧有限目标/学习困难；不因而恢复SSR训练。若未决超过20%，不能选结构根因，唯一下一步针对证书覆盖缺口作最小工程核验。C目标小间隔只提供关联证据；未加入本次不同扰动实验，不据此宣布它导致学习失败。所有分支均不自动启动新方法训练。
