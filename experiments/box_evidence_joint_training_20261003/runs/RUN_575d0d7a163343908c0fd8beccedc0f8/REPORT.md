# 原生系数分支与框内空间证据联合训练：固定候选评价

本轮未同时通过固定收益与全体性能守护条件，按有限协议停止。

主对象为val中原Box IoU≥0.75且原图Mask IoU<0.75，共1115张有效图片、3059个候选。主比较S−N图片macro IoU差为-0.2922 [-0.4582, -0.1374]个百分点。
主对象S−N的95%CI下界>0，同时该组S−A下界>0；+0.5 IoU百分点只报告实用量级是否达到，不作为硬否决；全val S−A的95%CI下界须>−0.1百分点，排除更差于预设margin才称守护通过。其它指标全部报告，不要求全部改善。失败即停止，不自动调参或扩训。

|组|含义|
|---|---|
|A|原始冻结模型|
|N|原生one-to-one系数分支普通微调|
|D|原生系数分支与空间证据直接残差联合训练|
|S|原生系数分支与空间证据原型投影残差联合训练|
|SF|历史冻结原生系数头的投影S；只复用同身份逐候选指标，不重放模型|
|SW|同一冻结S参数，仅替换空间证据读取框；自身当前native query/c、A/K/G及最终解码框保持原样|

冻结官方one-to-one TAL候选、neck输出、原型、预测框、类别、分数及解码。N/S/D均重新运行并训练原生系数分支；S/D再联合训练新增框证据分支。固定最后第12轮checkpoint；smoke使用零初始化而非训练checkpoint。本评价不是完整推理COCO AP，也不声称新的盲测。
