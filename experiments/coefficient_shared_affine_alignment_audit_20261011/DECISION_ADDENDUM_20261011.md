# 交叉审计判定补充协议（2026-10-11）

本补充协议在读取 dev/val 评估结果前固定判定规则。原协议的收敛门槛保持不变；本文件只规定如何把已完成的评估转成唯一决策。

主指标是固定官方 TAL 候选上的 image-macro IoU。先在 dev 选择 `B=old160 map` 与 `C=official640 map` 中相对 native `A` 的点增益较大者；点增益完全相同则选 B。选中的 map 只有在 dev 和 val 的 image-cluster bootstrap 95% CI 下界都大于 0 时，才判定为“存在跨图像可迁移的共享修正”，下一步启动与该目标严格对齐的固定候选/固定特征系数头训练小实验。否则判定当前共享仿射方法线未获得官方 TAL 上的正向泛化证据，下一步停止方法扩展并整理机制报告。

候选均值 CI 只作辅助，不改变 image-macro 主判定。B 与 C 的比较属于目标 bundle 比较（网格、标签、support、gain 同时变化），不写成单一监督因素的因果结论。

若任一 map 未达到 `gradient_inf < 1e-6`、fit/dev/val 数量不符、评估输出不完整，判定为“输入未达判定状态”，唯一下一步是完成当前交叉审计，不作科学结论。
