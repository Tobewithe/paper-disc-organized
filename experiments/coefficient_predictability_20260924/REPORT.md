## 当前判断

继续采用用户提出的“独立系数 oracle → 固定特征预测能力 → 原型条件作用”的研究问题，但首轮几何匹配训练不能用来定位官方系数头的训练机制。用户指出应复用官方 assigner，这是必要的对照修正。

首轮为了观察不受分数截断的 raw 候选能力，以框几何关系绑定 GT；随后又用这些绑定训练 probe，改变了接受掩码监督的位置。另外，首轮在原生 160 网格上计算 BCE，而当前权重的 mask_ratio=1；官方损失会先把原型上采样到监督掩码尺寸。位置和监督目标两项同时不同，不能把所得增益单独归因为官方预测函数能力不足。

## 官方分配审计：已完成

直接调用 Ultralytics 8.4.100 中模型 init_criterion 创建的两个分支损失及 get_assigned_targets_and_loss，没有另外手写 TAL 近似实现。冻结同一权重、同一无增强 640 方形输入，使用原始 COCO 类别和框，验证前向系数与缓存一致。

200 张 val2017 图片有 1,354 个非 crowd/非 ignore GT。官方 one2one 回放产生 1,346 个正样本位置，覆盖 1,346 个 GT；one2many 产生 11,736 个正样本位置，覆盖 1,336 个 GT。

对首轮几何绑定的 1,301 个位置，逐项对照 one2one：

| 本次官方分配回放中的身份 | 数量 | 占几何绑定位置 |
| --- | ---: | ---: |
| 分配给同一 GT 的正样本 | 311 | 23.90% |
| 非正样本 | 985 | 75.71% |
| 分配给另一个 GT 的正样本 | 5 | 0.38% |

这些数字证明两套监督位置不等价。985 个位置只能称为“本次冻结模型回放中不是正样本”，不能推断它们在预训练历史上从未受过监督；审计也没有证明官方分配器本身有缺陷。

## 首轮探索结果保留及边界

训练使用 train2017 的 800 张 fit / 200 张 dev，验证使用独立 200 张 val2017；seed=0。以下均为几何绑定位置上的掩码评价，不是 COCO AP，也不是正式输出的 GT 匹配结果。

| 系数预测方式 | 1,301 个位置的平均最终 Mask IoU | Mask75 达标数 | 修复 / 误伤 |
| --- | ---: | ---: | ---: |
| 原系数 | 72.960% | 760 | — |
| h 线性残差 | 76.360% | 833 | 134 / 61 |
| h 小 MLP | 76.536% | 839 | 128 / 49 |
| h 大 MLP | 76.381% | 833 | 133 / 60 |
| 条件网络，固定平均 P | 76.751% | 844 | 131 / 47 |
| 条件网络，真实 P | 76.375% | 834 | 132 / 58 |
| 条件网络，错配 P | 76.288% | 840 | 133 / 53 |

真实 P 条件是全图各通道 4×4 池化，未优于 h-only 对照：与小 MLP 的 IoU 差为 −0.161 个百分点，图像配对 bootstrap 95% CI 为 [−0.626, +0.264]。这个结果既不支持当前 P 条件设计有增益，也不能据此排除更合适的局部原型信息。

特别是，几何绑定位置中同时以 GT 类别进入 top300 且分数超过 0.001 的 405 个位置，原系数平均 IoU 为 68.369%，小 MLP 为 67.486%，真实 P 为 67.165%。全体几何位置上的提升没有直接转化为这一保留子集的 IoU 提升。该保留子集仍不是官方 COCO 匹配，不能当作 AP。

来源：[合并分析](runs/RUN_6a9a45c9f1b64e3191a03e57b1fb5798/SUMMARY.json)。上述结果因监督位置和目标不同，只作探索记录。

独立系数 oracle 选取原生网格失败与成功各 100 个实例，经过最终解码后实际有 81 个未达 Mask75：其平均 IoU 从 54.927% 到 71.814%，40 个达到 Mask75。原来达标的 119 个中有 19 个降为不达标。81 个失败里，同时满足上述输出保留条件的仅 32 个，其平均 IoU 从 56.888% 到 59.237%，5 个达到 Mask75。因此不能把选定 raw 候选的恢复量等同于现实输出的恢复量。优化是有限步 BCE 优化，不是已证明的 IoU 上界。

20 对同图实例的联合/独立系数优化在同一初值处梯度差为 0；固定 P 且系数相互独立时，目标可分离。该事实排除这一定义下的直接代数竞争，不能排除共享预测网络参数的优化冲突。来源：[oracle 运行](runs/RUN_ca26e0e27195431a89a5cddbd6467d14/run.json)。

## 修正后的下一实验

1. 以官方数据处理后的实例身份、overlap_mask 排序和监督掩码为准，直接复用官方分配器选出的正样本及 GT 索引；保存分支与 raw_id。
2. 冻结相同框、分数和原型，在相同官方正样本、相同实际分割损失上比较原系数、独立优化系数、h-only 与 P-conditioned probe。改变系数不改变 TAL 所用的框/分数，因此这一阶段可固定分配，隔离系数问题。
3. 保留无置信阈值的几何诊断作为旁路，同时用原输出协议评价实际收益。训练 assigner 内部的分类质量项与推理筛选阈值是两件事，不能因评价解耦而删掉前者。
4. 在这些控制成立之后，才判断差距来自预测容量、显式原型条件，还是监督/输出筛选。官方监督版 probe 尚未训练，不能把此次审计称作已完成修正复现。
