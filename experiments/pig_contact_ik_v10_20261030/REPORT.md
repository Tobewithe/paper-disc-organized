# 卧姿接触可行性与承重部位验收

本轮完成4个接触目标腹卧求解、右侧轻卧重放，以及躯干/耳接地的8候选核验；803/804/805共18张图全部实际查看。**腹卧求解未过；新左右固定侧卧通过躯干支撑与有限外观审核，替代旧“耳尖先落地”的构造。完整目标和正式数据版本仍未完成。**

| 维度 | 本次实验的整体研究链路 |
|---|---|
| 问题 | V8/V9直接角度和同角度DQS没有合格腹卧；原侧卧虽无自交，全身最低点落地是否真的代表躯干承重尚未核。 |
| 机制假说 | 接触目标/关节范围可能比直接大角度更适合构造卧姿；竞争解释是源rig缺少姿态相关表面纠正，关节求解仍无法同时支撑且不损伤。补视另暴露“最低顶点=支撑”错误：耳尖可先触地，骨架旋转矩阵合法仍不能证明躯干承重。 |
| 针对性方法 | V10锁LBS与修复rest，2脚目标布局×2初值、7个对称角参数，有限投影LM后完整网格硬验收；右轻卧固定1例重放并补腹侧2视角。V11独立新协议将MAIN_BODY最低点置地，只改变接地耳根0/10/20/30度共8候选，0度负对照保留，最小通过角度再做6图资格/对照。所有原身份与失败保持，不逐点压地，不改旧Gate。 |
| 整体结果 | 4腹卧全部失败：落地后腹侧间隙0.04562..0.09914体长，脚目标误差0.21917..0.25946，边长比越界，2例还有90/92自交。图像仍悬腹/伸腿蹲姿，损失下降不是成功。原右轻卧补视显示耳尖支撑，躯干间隙0.01036。V11左右各0度在躯干落地后耳穿地−0.01036；各10/20/30度零自交且不穿地，按冻结规则各选最小10度，躯干最低0、接地耳最低0.00107488体长。6图未见新耳根断裂、尖刺或肢体熔化，固定新侧卧准入。真实下游AP收益/损伤未测，无模型训练。 |
| 研究决策 | **保留站立3项及新版左右侧卧2项，接下来优先验证固定腹卧候选的关节局部姿态纠正资产。** 累计直接角度、DQS、有限接触求解都未给出腹卧，因此关闭这些固定大角度/脚目标配置，不再盲扫角度或换插值。已有V7局部几何修复成功与姿态相关变形文献支持“修局部表面能力”作为下一优先假说，不称已有效。唯一下一步是在已满足腹侧落地的固定V8 prone70上，保持骨架/脚接触锚点和源部位身份，做有位移/形状/碰撞护栏的局部关节纠正，再实际看图；尚未启动。若无法在护栏内去交叉或仍像蜷蹲，拒绝，补真正姿态资产，不把失败用其它姿态补数。 |

V10只是有限7角参数/4初值布局的投影LM原型，不是关节构型数学不可行证明；碰撞是终态硬拒绝，没有虚构可微碰撞求解器。自然关节范围也未生物标定。原始Run不覆盖、不事后增加初值或放宽支撑/边长阈值。

V11新支撑规则只改变当前构造准入。V8的原数值/有限外观结果保留，但操作白名单由[新版固定姿态目录](../pig_torso_support_v11_20261030/POSE_CATALOG_V2.json)替代；旧最低顶点落地的侧卧不用于正式数据。源耳不是承重物，耳角应由接触约束决定，不能在这些姿态里独立任意随机。头仍抬起，不能标为熟睡或头部贴地。没有软组织压力、重力稳定性或闭合体积验证；32源边界边保留。

身体部位在此不仅用于输出Mask，还决定生成约束：站立检查脚，侧卧检查躯干和接地耳，腹卧同时检查腹侧与肢体目标。仅设置root高度或让模型给出一个姿态词，不足以证明条件成立。
