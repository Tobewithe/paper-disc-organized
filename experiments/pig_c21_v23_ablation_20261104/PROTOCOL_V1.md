# C21／V23固定权重功能消融 V1

用户2026-11-04要求先消融收益较高的C21与V23。本Study独立检验已训练模型对组件的功能依赖，不恢复旧训练、未决分配矩阵或test426；原实验、权重、Gate和阴性保留。

## 模型与问题

N为多阶段训练与分支组合后的项目保留YOLO26m-seg，SHA `0e40602f1dbf0697fd49fa8e9f887c068970e3c5c39bd618f66e483c8712c8d6`，不是COCO初始模型。C21为8000更新候选＋2568更新策略的固定末模型，SHA `4b8f85a4602ca62b11941c8ac95d8ba67e3e3d8bfaa387aa81afc4ece1ed1d9a`；V23同样完成8000＋2568更新且内含冻结C21锚，SHA `b7927c602288ffa48589cf1d7808b932fcfc7339a04758a3a329e9f328e7ca1e`。训练履历与历史效果分别见[C21报告](../spm_spatial_object_memory_20261025/REPORT.md)、[V23报告](../spm_content_constrained_memory_20261026/REPORT.md)及[基线身份](../../project/research_notes/PIG_YOLO_BASELINE_LINEAGE_20261104.md)。

既有受控错配／空间打乱在固定动作及修正量后影响很小，V23旧内容控制覆盖又不足；这些不能回答组件移除后正常路径会怎样。本次重新计算正常动作／风险选择，保留原特征、RGB、其他组件、输出身份与全部样本；不再增加质量匹配或GT选择。

## 固定消融

| 输出名 | 唯一指定干预 |
|---|---|
| N／C21／V23 | 原固定模型控制，逐行重现原正常输出；不是新训练基线 |
| C21_NO_CONTENT_INPUT | 在粗／细重建器输入中将完整部位、自可见部位及whole空间内容通道置零；检索、图像、邻居、原Mask和决策器保留。只声称移除重建器的内容输入，不声称删除所有记忆作用。 |
| C21_NO_FINE_RESIDUAL | 细尺度fine_refiner输出置零；粗尺度修正、细图像的风险上下文和正常动作选择保留。 |
| C21_TOP1_FULL | 不用学习型动作选择，固定检索top1、正负强度均1、直接应用对应候选。它合并改变模板选择与保护强度，仅解释该选择组件的复合作用。 |
| V23_NO_FLOW | shared_flow输出置零，候选／检索／风险按正常路径重算。 |
| V23_NO_APPEARANCE_CODES | 部位及背景外观码在计算中置零，使外观语义相似度退出可见性和部位匹配；其余权重不变，结束后精确恢复。 |

| V23_FULL_CANDIDATE | 直接采用正常匹配槽的正负强度1／1候选，移除学习型风险选择；不以GT选实例或强度。 |

采用固定末权重和同一chunk2、FP32／TF32关闭、640画布。正常原生特征可复用冻结缓存，前提是完整N／C21／V23二值Mask及所有检测字段与原正常RGB产物精确一致；逐图核RGB和缓存SHA。推理输入清单只保留RGB、正常缓存和身份字段，不把索引中的GT字段送入模型。

## 工程与正式评价

首次科学执行前冻结协议、实现、依赖源码、环境和输入SHA。工程仅用按RGB SHA排序前2张dev检查全部干预有效、N／C21／V23精确重放、原权重恢复以及真实耗时，不计算AP或据结果改消融。

工程通过后一次性完整432dev／2863GT，预计每输出12899条正常检测；不得缩图、剔除空Mask或改变score、类别、框、排序和decoder。GT只在预测保存后的CPU评价读取；完整bbox＋segmentation记录交给固定pycocotools，bbox／segm各自匹配、maxDets=[1,10,100]、IoU=.50:.05:.95。

主量是各消融相对所属完整C21／V23的Mask AP差，兼报相对N、原N及各完整模型Mask75成功损伤、尺度和共同Box AP。AP下降至少0.5点只作明显功能敏感的预定描述线；输出分布外干预、单个固定模型和反复使用的开发集，不证明该模块独立训练贡献或跨场景必要性。观察改善也不自动采用消融输出或调参追分；没有重新训练的结果明确记未测。
