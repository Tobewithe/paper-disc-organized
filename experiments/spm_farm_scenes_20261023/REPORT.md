# SPM-FARM工程样例与保存报告

2026-10-23已生成站卧混合的猪栏工程样例，Slurm189/`RUN_SPM_FARM_SMOKE_c065813560a6`正常结束。实际完成8个独立场景、16张外观图和原生可见实例标签；用户随后要求保存，正式生成与新原型更新没有启动。

| 维度 | 本次完整工程实验的研究链路 |
|---|---|
| **问题** | 旧P1训练输入中的384合成帧只来自12个旧场景，标签128×192；用户要求生成更多真实猪场姿态、群体和设施情境。当前需要交付可重复的场景与正确可见实例标签。 |
| **机制假说** | 不适用方法机制验证。本次工程目标是核实同一资产能否通过真实骨骼姿态、布局/设施和相机组合生成标签一致的多样场景；跨域原型效用仍是假说。 |
| **针对性方法** | 固定Pig.blend SHA、Blender4.2.1，程序骨骼生成腹卧/左右侧卧并使用站立、行走、进食姿态；3至20头、4布局/地面、2相机，每几何2外观。实际姿态接地，XY凸包无交叠，RGB与对象ID同网格渲染；独立BVH相机射线及RLE往返核验。3次前置失败保留，R2使用大凸包优先摆放及高数量设计猪栏尺寸。 |
| **整体结果** | 8场景、16图，90头独立几何实例均有≥16像素可见区域，产生180条外观标注；32,768条射线ID一致、两外观标签相等、RLE逐像素往返一致。接地点最大绝对偏差6.71e-8米。Box长边比例预览中位.109，真实train参考.195；来源组成不同，属于构图改进提示。相对原生YOLO/已有方法的AP增益、损伤与机制增量均未测，不能从工程核验推断。 |
| **研究决策** | **优先完善真实猪体尺度下的相机取景，再生成正式猪栏训练数据。** 依据是新姿态/群体/标签链路已真实成立，而总拍全栏仍偏小目标；优先补近景/局部群体比继续增加相同全栏图更直接回应当前缺口。用户要求先保存，下一动作尚未启动；不扩大预算或宣称已支持分割机制。 |
