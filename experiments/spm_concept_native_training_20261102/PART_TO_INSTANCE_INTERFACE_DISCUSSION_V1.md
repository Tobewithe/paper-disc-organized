# 部位监督怎样服务实例分割：连接形式讨论V1

2026-11-02，响应用户提出的“直接概念监督与实例分割之间可能存在gap”。本页为**候选设计讨论**，不是冻结训练协议、科学准入或执行记录。当前路由仍由[ACTIVE_PLAN](../../project/ACTIVE_PLAN.md)管理，原Goal、失败、资源及test边界不改。

## 1. Gap不是只差一个更高的部位分数

1. **语义与实例粒度不同。** 全图“所有猪头”同属一类，但实例Mask须区分猪A的头和猪B的头；当前猪头与躯干虽部位不同，在同一实例Mask中却都应保留。全图语义目标并不直接要求解决这种身份绑定。这不是说所有语义与实例任务必然冲突。
2. **可解码与任务使用不同。** `F→part`和`F→P,c→Mask`并行时，共享特征可让部位头准确，但正常Mask读出未必利用对应变化。V1辅助梯度进入原生参数是事实，不能改称无梯度；它没有直接通过实际`c_i`形成部位预测，也是事实。
3. **监督语义及域不同。** 合成的物理可见部位不等于所有真实任务Mask像素，后者保留既有重叠/设施填入语义。不能把真实未知部位或遮挡处当负例，也不能由合成部位成绩推断真实知识已经迁移。

## 2. 四种连接形式及取舍

| 形式 | 连接方式 | 当前判断 |
|---|---|---|
| 全图语义辅助 | 共享F分别预测全图部位与实例Mask | V1已实测，关闭原配置；单纯加权重不解决实例粒度/读出差异 |
| **共享原生实例读出的部位监督** | 正常实例变量同时承担原生Mask和“该实例的具名部位”辅助预测 | **优先讨论的最小候选**；缩短监督到实际实例读出的路径，可保留原生推理形式，但仍待匹配训练证实 |
| 部位先分、硬组合为Mask | 最终实例Mask只能由各部位概率组合得到 | 输出约束强，但概念错误可能直接限制任务，unknown和真实标注语义须处理；也可能改变推理头与容量，不作为当前第一选择 |
| 用部位划分任务损失/关系约束 | 在原Mask上按部位平衡误差，或监督部位间关系/跨条件一致性 | 更贴近任务但可能仅是重加权/额外监督；不能独自证明学到专属解剖，旧RLPL等失败不改名重开 |

硬并集也不是语义必要性的数学证明：若`M_i=sum_k p_ik`，部位通道重命名或置换本来就不改变和，不能用“交换通道AP不降”否定该设计，也不能用这个等式宣称解剖已发挥作用。正确部位与同容量非解剖分区的匹配训练仍不可省。

## 3. 优先候选：同一个实例变量，承担整体与部位两种监督

原生实例Mask的正常形式为

`M_i(u) = sigmoid(c_i^T P(u))`。

一个待检验的最小实现为，仅训练期增设共享的小映射`g_k`：

`A_ik(u) = sigmoid(g_k(c_i)^T P(u))`，`k=头/躯干/前肢/后肢/尾`。

- `i`是实际正常检测/实例读出，不是人为GT框或另造的实例query。匹配仅用于训练监督身份，GT/owner/Recipe不进入正常前向。
- 合成辅助目标在可靠有效域为`Y_ik(u)=1[owner(u)=pi(i) AND part(u)=k]`，其中`pi(i)`是训练时正常检测i关联的可靠GT实例身份，不是检测行号或raw_id；关联未知的查询不给该监督。猪A头是A-head的正例，猪B头不是；猪A躯干对A-head为负，但对A的整体任务Mask为正。未知/隐藏/不可靠域忽略。
- `g_k`跨实例共享，不能每头猪独立记标签；不另开自由RGB/像素编码器，也不把部位结果只送到与原生输出无关的外挂query。
- 正常部署依然只计算`c_i^T P`，可以删除`g_k`。**这种结构是训练期实例条件多任务监督，不是概念瓶颈；删除辅助头不会构成机制消融。**
- 合成标签继续作为辅助目标；真实任务沿原GT和原decoder，不把五部位并集硬写成真实标注，也不新增合成正常分割targets的权限。
- 原O2O detach和训练分支合同不因公式改变。`c_i`与`P`实际哪些参数接收梯度、是否可同时表达这些部位、是否需使用同一原生系数分支的前级实例表示，均须另做资格并预冻结；目前没有承诺梯度穿过被detach的P，也没有承诺固定32维空间一定充分。

主要预期是部位辅助的压力落到**承载本实例Mask的原生表示**，而不只是公共语义图。它仍可能被辅助映射吸收、仅充当一般正则，或因域差损伤任务，故不是结构一写出就证明“Mask已用概念”。

### 与旧V32及V23不同，但不靠区别自动准入

[V32实现](../spm_registered_object_head_20261027/registered_head.py)冻结原生模型，从正常系数/图像另造whole与part tokens，经自由readout输出原基残差及新基系数；whole路径可以不依赖具名part顺序。新候选拟让**原生实例读出本身**接收实例条件部位监督，不重建一个外挂whole/part竞争系统。V32的错位近乎无损仍是重要反证，不能因此假设新候选已解决。

V23的`sum S*rho`虽然形式上组合部位，旧48ROI核验显示宽包络内相同`rho=p/A`可重建同一输出，部位可见性不被目标唯一识别。新候选不恢复这一几何包络/可见性重建，也不把“组合形式”自动认作机制。详见[原审计](../spm_content_constrained_memory_20261026/POSTTRAIN_CONTENT_AUDIT.json)。

## 4. 支持依据、主张与关键对照

新近邻[TAPPS审查](../../literature_search/pig-part-instance-bridge_2026-11-02/README.md)明确比较全图部位与同实例共享query的对象—部位预测；在PPS中观察到thing PQ改善而实例无关mIoU基本不变。这为“监督身份与实例读出对齐”提供正面实测先例，不只是由V1失败猜新模块。它使用真实部位标签、Mask2Former和不同参数量，不能把其分数当猪AP或严密的等容量因果证明。

**H：**同实例、同原生读出的正确部位监督，能使解剖对应提供超过一般空间分区的真实任务增量。

**H_alt：**收益只来自实例条件分组/额外像素监督/容量，或合成部位不能转移到正常真实读出。V1的C≈Q、细部QA偏弱及V32结果为这些竞争解释提供依据。

最关键对照不是“新增头 vs 无新增头”，而是：

- 同样的原生实例读出接口、输入、有效辅助容量、初始化、数据/有效域、优化时钟，正确部位与非解剖空间分区对照；Q也保留相同实例身份条件。
- 必要几何/仅真实训练参照；旧V1只能作历史，不把不同白名单/预算的旧结果直接充当新的因果对照。
- 若同时比较全图与实例条件接口，须在同一新合同里匹配其余因素。只有正确部位在实例条件接口中产生额外收益，才支持所主张的桥接；所有接口同涨则可能只是一般适配。
- 合成实例部位质量与正常真实Mask效用分别报告。高部位分数而C不胜Q，只能说明可解码/可学习，不能说任务已受益。定向训练对照破坏语义对应而保留有效监督与幅度；不能仅全局重命名部位类别，因为那是等价标签体系。

阳性预测是正确部位的可学习性及相对匹配控制的真实效用/损伤护栏同时成立；在有效控制下无增量则关闭该接口配置，不追加权重/步数。控制不可学、输入或梯度合同不合法则是无效/信息不足，先关闭科学判定，不算方法阴性或阳性。具体数值阈值、统计单位、训练预算和完整定向干预计划仍待新版本冻结，本页不准正式训练。
