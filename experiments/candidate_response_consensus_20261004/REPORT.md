# 原模型候选响应共识：本轮结束

**本轮没有取得实用掩码收益，按预定规则停止当前配置。** 在253张有效开发图、1816个固定官方one-to-one TAL候选上，共识组合相对原模型的图片macro原图IoU为−0.0144个百分点，95%配对区间[−0.0946,+0.0637]；Mask75修复16、损伤17。共识未超过普通分类分数加权。该结果不能证明整个多候选路线不可行，但没有依据在这套配置上继续扫参数或训练选择器。

## 对象与新增问题

本轮零训练，原模型、原型、target框、类别分数、阈值和正常原图解码固定。原模型两分支全部8400 raw按预测类别及与target预测框IoU≥0.75分组，最多取8个。GT不参与donor或权重选择，只用于固定历史target身份及评价。新增问题是同池响应一致性是否比单donor和普通分数加权提供额外有效证据。

历史S071已经做过3×3无条件系数平均，不能再当新想法；官方跨头小样本曾做单donor替换，但不是本轮预测对应共识。FCIS已有mask voting先例，不宣称投票或加权系数是原创机制。依据和具体规则见[预先协议](PROTOCOL.md)。

## 对照给出的判断

- CONS−TOP为+0.0787pp，描述性区间[+0.0031,+0.1684]：当前聚合比这个最高分类分数单donor稳一些，但TOP本身弱于A，不能据此宣布方法成功。
- CONS−SCORE为−0.0021pp，区间[−0.0059,+0.0009]；二者Mask75转移完全一致。未建立响应共识权重的独立价值。
- many与one共同K对照差值−0.0326pp，区间[−0.1104,+0.0504]，没有建立many来源优势。ONE_MATCH对A的小幅+0.0250pp区间仍跨零，也低于实用门槛，不据此开启参数搜索。
- CONS的coverage点估计微升，但FPR也升、AUC微降；没有出现oracle式显著像素排序恢复。各完整区间保留于SUMMARY，不能补写显著性。

## 为什么共识权重与普通平均几乎相同

这是一条实测描述，不是事后根因认定：many选中donor在160网格target框支持内的平均其它mask IoU为0.9769，中位数0.9934（单donor按协议记1）。该池响应高度一致，分数与共识加权的有效权重数均约6.65，因此响应权重实际改变很小。它与“本配置的共识增量不足”相容，不能推出所有raw信息都冗余、所有图像视图都无互补，或当前错误必为共同错误。

1816个target中1727个有many donor，89个无donor回A并保留总体。many池可用数均值17.16，最多取8；共同K中759个取8、89个取0。选中many donor与target框IoU均值0.9551。ONE_MATCH有效权重数均值1.1586，而many共同K为5.3918：数量匹配并不等于权重集中度、位置或质量匹配，因此不把分支对照归因到TAL训练方式。无空支持删样；AUC两例未定义仍计入IoU。

## 执行与证据有效性

- 正式评价101.82秒，GPU冻结前向6.73秒、组合算子17.45秒、指标44.86秒，其余主要为加载与汇总。这是诊断批次耗时，不是部署延迟基准。
- 与历史原输出逐候选核对：c0、预测框、P、分数及A的全部指标最大差均为0；加权系数与加权logit最大绝对差4.29e−6，预定1e−5绝对/相对检查通过。完整原型正常原图解码；没有重跑TAL，没有用GT换位置。
- 256计划图、253有效图、1816候选；3张无正样本图ID保留在AUDIT。每个候选的donor、分数、IoU、权重、回退与完整身份保留在DONORS。
- smoke及正式Run均独立登记、完成、回传SHA256核验，共44个文件。原Run的快照、英文自动报告和日志保持不改。
- 这些是已查看过的开发图及GT条件监督target，既不是新盲测，也不是全部正常输出候选或COCO AP。候选上的阴性不等于完整部署收益的严格上界，但当前没有值得投入部署确认的实用信号。

## 决定与重新考虑条件

结束本轮，不调K/框门槛/权重、不增加gate、不训练新选择器补救。只有新的独立证据显示一个不同来源能提供有价值且可辨别的互补响应，才重新考虑融合；不以本轮CONS胜TOP的微小差值作为放行理由。研究总目标未完成，后续选择其他机制前仍须历史去重、数学与实现核对、文献比较和固定预算。
