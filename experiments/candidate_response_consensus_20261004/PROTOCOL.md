# 同图多候选响应共识：一次零训练决策短测

## 新问题、依据与反方

同图同一原型P下，原预测框与类别约束得到的one-to-many候选组，能否提供超过单donor、普通分数加权平均的有效掩码证据？本轮检查实际GT-free兑现，不训练新的选择器或蒸馏头。

历史S071的3×3无条件raw系数均值已失败，不能重命名再跑；official_coco_task_alignment_20260916只有小样本GT辅助单donor替换，不能支持部署共识。这里改变的是GT-free实例对应及同组响应可靠性，不是线性求和本身。固定P时 `P sum(w*c)=sum(w*P*c)`；不会增加原型表达空间，BCE凸性也不保证超过最佳donor或提高IoU。

文献：[FCIS/CVPR2017](https://arxiv.org/pdf/1611.07709)已使用同类高框重叠的mask voting和分数权重，所以不把框分组/投票称为创新；[YOLOv10](https://arxiv.org/html/2405.14458v2)的一致双分配并不证明两个mask头误差互补。本轮只检验当前YOLO26m-seg原模型是否有可利用的候选间信息。共同错误可能被共识强化，是主要反例。

## 固定对象与唯一规则

官方Ultralytics8.4.100、COCO预训练YOLO26m-seg。复用1024/256缓存的256开发图、253有效、1816固定one-to-one TAL候选；不运行新TAL，不替换target身份。原P、target预测框、分数、类别、阈值和解码冻结；GT仅评价与事后诊断。

用同次FP32前向读取两头NMS/top-k之前的全部8400 raw。每个target沿用原预测类别，donor必须argmax类别相同且与target预测框BoxIoU≥0.75；按该类别分数降序、raw_id升序取最多8个。无绝对置信阈值，不用GT类别/GT框选donor。所有组裁原target预测框。无donor保留A并计入总体。不能将这些预测对应donor称为该GT的官方正样本。

共识在原生160×160 P网格、target box/4的整数像素支持内计算同池donor零logit二值mask两两IoU；排除自身，空并集IoU=0，单donor可靠度1。标量权重 `score * (0.05+0.95*mean_pairwise_IoU)`，归一后直接组合32维系数；不平均概率、不引入solver、阈值或新网络。系数与logit加权的数值一致性使用预定1e-5绝对/相对容差核验。

| 臂 | 操作 | 所区分的问题 |
|---|---|---|
| A | 原one-to-one c0 | 原模型 |
| SAME | 同raw的one-to-many系数 | 只换分支 |
| TOP | 对应many池最高分类分数单donor | 只选一个位置 |
| SCORE | 同池按分类分数加权系数 | 普通聚合 |
| CONS | 同池分数×响应共识加权 | 响应一致性是否额外有用 |
| CONS_MATCH | many池截到共同K后同规则共识 | 数量匹配 |
| ONE_MATCH | one池截到同一K后同规则共识 | 跨分支来源参照 |

共同K=min(n_many,n_one,8)，按同一target配对；K=0两臂都回A，不删除target。空target原型支持则全臂回A。数量匹配仍不等于位置/质量匹配，不能据CONS_MATCH>ONE_MATCH直接归因为多正样本训练。

## 评价、预算与预定决定

正常原图MaskIoU为主，同时报告Mask75修复/损伤、coverage、AUC/FPR、像素变化及耗时。A逐候选复现旧指标，绝对误差≤1e-12；来源c0/box/P与缓存按预定FP32 3e-5绝对/相对容差核验。全体及A定义的成功/失败、框好掩码差分别列出；主表不得按donor可用性删对象。另报池大小、共同K、fallback、有效权重数、池内IoU与donor几何。统计候选均值和图片macro，1000次整图配对bootstrap，seed20261004。该开发集已被查看，不称独立确认或COCO AP。

只执行两张有效图smoke（180秒上限）及全部256图一次冻结评价（900秒上限），服务器GPU，无训练、无重复种子、无参数搜索；桌面只代码记录和传输。先核已有Run/PID，smoke失败不启动正式Run。

继续信号：CONS相对A图片macro IoU≥0.2pp且区间下界>0；或预定框好掩码差组≥0.5pp且区间下界>0、全体损失不超过0.1pp。进一步只有CONS胜过TOP与SCORE，才能支持共识权重的独立价值；否则按结果保留单donor/普通聚合线索，不包装为共识机制。跨分支特有性由同数量比较单独判断。Mask75、coverage及AUC的代价必须一起解释，不要求全涨，但不能把已有成功实例的大幅损伤藏在失败组中。

未达到任务实用量级或净效果明显为负则结束当前配置，不扫K、IoU门槛、权重、不立即训练新head补救。短测阳性也只放行独立确认，不代表新颖性、唯一根因或最终方法成立。整个研究目标继续，当前Run完成后不自动扩展本配置。
