# V23.3：64对象身份有没有可学的漏选机会

本实验已完成全部1272张既有真实训练图/13来源、每图前8个已知正常正查询，共8390查询、536960个候选IoU。即使用GT从64候选选最好，图均IoU只从.941335到.944117（+.002782），低于预冻结.01阴性线，故停止只改top1匹配器的扩训；原V23正收益权重继续保留。

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | V23.2候选更新在R0下+.093200未过+.1，风险器更新抵消，新增质量头V25/26均阴性。原训练为64候选边缘化、部署为top1，有必要先判定“有好对象却选错”是否有足够幅度，而非继续加训猜测。 |
| **机制假说** | H_match为有系统性更优身份且原能量可识别；H_content为当前身份选择在任务质量上没有足够剩余机会。旧48真实ROI宽包络等支持后者竞争解释，数学形式只给前者可能性，未预设实际错配。两者由全部候选GT质量及能量选择差区分，阴性直接停止匹配扩训。 |
| **针对性方法** | 固定实际V23 b792、原C21/R0、原全部参数/64候选/损失及正常chunk2，0优化。全部原real/train、13组，按正常ordinal取前8个已知正查询，所有图保留；在原128 task-known域计算正常top1、GT最佳、GT能量最小和责任后验众数。完整64矩阵/bit-packed masks/身份/owner索引保存，独立CPU从mask及原能量项重算，不读dev/test评价。 |
| **整体结果** | 图均正常/GT最佳/能量/责任IoU为.941335/.944117/.943248/.941335，最佳增量.002782、能量.001914、责任6.92e−7；只有8/8390查询的最佳增量>=.05，13组无一组能量增量>=.01。约59.82个不同二值候选并不等于有实用身份切换收益。全部IoU/四种选择精确，能量加和误差0；最大聚合误差4.4144e−9。没有新正常AP或相对原生/已有方法的效用增量，不以ROI高分冒充部署结果。 |
| **研究决策** | 原H_match的可投入必要幅度被否定，停止当前64身份top1匹配扩训及原能量teacher追加，保留V23。我选定真实对象空间记忆与跨实例对应：为记忆写入有真实出处的空间特征/任务标签，在V23候选入口生成内容，保留原读出。依据本次身份机会不足、旧真实内容退化和一手对应学习研究。唯一下一步是实现零门控精确V23初态，并冻结正确对应与等容量/输入/预算打乱对应的两臂训练；过实际工程后执行训练及完整正常验收。新机制尚未证实，须按正常AP/全部护栏与匹配删除臂裁决，整个goal仍active。 |
