# Stage 1 位置 × 目标补格结果

## 结论

在固定原型、冻结检测框和固定候选身份后，两个缺失格给出了清晰的分离：**官方 TAL raw 位置上的 O-GB 修正不能迁移到正常原图掩码，几何匹配位置上的修正则稳定改善正常原图掩码**。因此，本轮支持“位置因素主导历史两轮共享末层结果差异”的解释；不能把几何候选上的收益归因于官方 TAL 位置的原生训练不足。

这支持进入协议中预登记的 Stage 2 donor-readout 判别实验，但不直接证明 donor 方案可部署，也不改变既有几何候选结果的适用范围。

## 固定对象与执行

- 服务器：`connect.bjb2.seetacloud.com:33953`，YOLO26m-seg、Ultralytics 8.4.100，冻结原模型。
- fit/dev/val 官方候选：796/197/196 图，6058/1402/1346 个 one-to-one TAL 候选。
- 几何候选：5872/1375/1301 个固定 BoxIoU≥0.50 最大基数候选。
- 只重新求解每个尺度的共享仿射系数读出，`lambda=0.003`；G-BIAS 为每层常数 32 维偏置对照。
- val 正常原图解码使用完整 prototype、原预测框、真实 letterbox 逆变换和 COCO 原始实例 mask；图片级指标用 5000 次整图 bootstrap。

## 允许的判断

1. **位置证据成立。** 同一类共享末层修正，在官方 TAL 位置上为负，在几何匹配位置上为强正；单纯把两轮差异解释为损失口径不一致已不再合理。
2. **几何收益不能改写为官方主线收益。** G-OFF/G-BIAS 的 1301 个几何候选与官方 TAL 候选不是同一研究对象；本轮证明的是位置条件下的可恢复差异。
3. **下一步只做预登记 Stage 2 donor-readout。** 由模型正常输出框选择同图 donor raw 位置，再使用冻结的几何共享修正；不扫描 K、不训练 selector、不加 gate 或新 loss。若 donor 方案没有正向净收益，停止位置读出路线。

## 限制

- G-OFF 为流式有限迭代数值解，不是已认证的最优解；G-BIAS 是充分收敛的 secondary control。
- 这是固定候选的定位性诊断，不是完整 COCO AP 或端到端部署评价。
- 正常输出候选保留、NMS 和置信度链路尚未在本轮替换；不把本轮结果扩展为全模型 AP 主张。
