# 位置条件共享仿射筛选

在固定几何候选和 native GT-box 目标上，把归一化 raw-grid 坐标及低阶项 `[1,x,y,x²,y²,xy]` 加入共享仿射读出，检验二维位置项是否超出已冻结的 G-BIAS。

几何 val（196 图、1301 候选）结果：

- 原输出：0.75371
- 位置条件仿射：0.80925
- 相对原输出：**+5.554 pp**，95% CI `[+4.076,+7.179]`
- 修复/损伤：137/49
- 已冻结 G-BIAS：+5.483 pp
- 相对 G-BIAS 的增量：约 **+0.071 pp**，低于预设 0.2 pp 实用门槛。

结论：位置分布确实决定可修正空间，但低阶坐标条件本身没有带来足够的额外效用；停止简单坐标项、donor 和无条件偏置变体。
