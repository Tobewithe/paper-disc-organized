# Position × objective complement for shared prototype-to-coefficient readout

- Study ID：`STUDY_4e6f5ea1-6d98-4c33-b1b3-b60ab4b8ed9`
- 类型：诊断；状态：已完成，停止当前配置
- 研究对象：固定 YOLO26m-seg 的原型、特征与候选，分别交换“官方 TAL 位置／几何匹配位置”和“官方 ROI 目标／原生目标”，判断此前相反结果来自位置、目标还是两者交互。

## 结论

这组 2×2 补格支持“位置因素”是主要差异来源，但尚未证明存在可部署的 GT-free 修复方法。官方 TAL 位置上的共享修正不能迁移到正常原图输出；几何匹配位置上的共享修正可以获得较大收益，说明几何位置包含原生 TAL 位置没有兑现的可修正空间。把几何位置训练得到的修正直接迁移到官方位置后，收益接近于零，因而不能把几何候选结果写成官方监督链已经被修复。

G-OFF 使用 25 步流式 L-BFGS，终止时 stationarity 约 0.045，因此它是诊断性数值解，不是精确最优性证书。G-BIAS 的 fit 求解 stationarity 约 `5.48e-8`，但它仍只证明几何候选协议下的结果。

## donor 与空间项的补充检验

`RUN_stage2_donor_20261004` 在同图不同实例预测框之间交换 donor：纯 donor 为 −1.144 pp（95% CI [−1.671, −0.676]），加入 affine 校正后为 −0.249 pp（[−0.644, +0.071]），均未达到预设继续门槛（+0.5 pp 且区间下界大于 0）。这说明“换一个附近实例的位置”不能直接替代目标实例的系数信息。

`RUN_spatial_affine_screen_20261004` 在几何位置上加入低阶归一化空间坐标后为 +5.554 pp（[+4.076, +7.179]），相对 G-BIAS 只增加 +0.071 pp，低于预设的 +0.2 pp 实用增量，因此停止简单坐标读出支线。

## 允许的研究判断

1. 位置与目标不是可互换的标签细节；同一类共享末层修正，在官方 TAL 位置和几何匹配位置上的可兑现程度不同。
2. 这支持继续研究“原型到系数链路中的位置条件化读出”，但不能把几何位置上的 GT 辅助收益称为部署收益。
3. donor 交换和低阶空间 affine 没有建立额外实用收益；不继续扫 donor、框阈值、权重或低阶坐标项。
4. 仍未知：能否仅利用预测框和无 GT 特征，稳定识别并读取那个有利位置；当前 Run 没有证明这一点。
