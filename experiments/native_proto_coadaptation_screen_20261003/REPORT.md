# 原生原型—系数适配快速对照：结果

**在本轮固定官方对象、3轮预算下，仅更新原型或原型与系数联合更新，都没有得到优于原模型及只更新系数的正常掩码收益。当前配置停止，不追加epoch或调参。** 这不证明任何形式的原型适配都无效，也不把官方detach宣布为已排除或已成立的历史根因。

## 做了什么

P：原始预训练初始化，固定c0，仅训练原生Proto26实际mask路径。PC：同时训练Proto26与原生one2one_cv4。二者保持backbone/neck/框/分类/assignment及BN运行统计不变，使用同一官方mask BCE，无新网络或loss。显式允许固定one-to-one监督梯度进入P，属于梯度路由干预；不是官方完整双分支训练复现。

同数据1024计划fit图（1012有效、7172候选），256计划dev图（253有效、1816候选），seed0、每组3轮、固定epoch3评价，N=cv4-only直接复用fast-screen同预算记录。P训练181.5秒、PC187.6秒，评价79.1秒；从两个smoke启动到完成合计约8分钟，均已回传并通过文件清单核验，checkpoint保留远端并记录SHA256。

框好掩码差组中P−A macro IoU为+0.0131pp（区间[−0.6068,+0.7462]），PC为−0.1960pp（区间[−0.9248,+0.6072]），不能选这个宽区间的子组代替全体判断。

训练第1至第3轮的轨迹BCE在P从2.4827降到2.2142，PC从2.4906降到2.1476。这是训练过程中不同参数点的轨迹平均，不是固定参数的fit/dev目标对照；它不构成实际掩码改善。

## 有效性与边界

两个独立smoke：初始化P/c0与原缓存最大差0；官方损失值与dL/dc差0；分块dL/dP与完整直接autograd最大差约2.98e−8。指定分支实际更新，原source及固定buffers保持不变。评价P/PC使用其各自当前完整P；原A单独重放，内部新P下的伪“A”指标全部舍弃；N以全部七个身份字段关联，未重新训练或重匹配。

本轮只说明当前小规模、固定归一化状态和训练预算下开放原型更新未兑现收益。它不区分所有数据/优化/监督作用，也不能把更新P的结果与旧固定P可达性证书直接比较。停止该配置，保留checkpoint及原始记录，后续先复用历史证据查清有判别力的不同机制。
