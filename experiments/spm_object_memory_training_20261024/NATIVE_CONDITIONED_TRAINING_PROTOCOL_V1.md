# V18 原生实例条件下的原型分割适配

2026-10-24。V17的A30和B15均已完成；B重遮挡能力失败，同框参考检查也未达到原.65要求。本版本保留全部旧Run、Gate和阴性，停止只训练查询器。原V17 C因B失败未启动；它的后继执行依赖由本协议显式取代，**不将原B改判通过**。本轮在同一SPM完整实验中执行V18任务适配，目标仍为同配置原生Mask AP至少提高5个绝对百分点、框身份精确不变及全部损伤护栏。

## 证据与主张

Slurm331完成B15、每轮77697例、18225次更新。8895匹配开发例的特征误差/同框A参考为1.020909、可见IoU为.835277；159/256重遮挡匹配例IoU为.487747，未达.65。Slurm335独立复核训练覆盖、127产物SHA、原生/PCA、B冻结内容和decoder精确一致，结论相同。

按预冻结判别，Slurm339在全部8895匹配案例上只重放固定A参考查询，逐例参考特征误差差0。159个同框重遮挡例的参考/当前IoU为.486532/.487747，配对差为−.001215，四来源重采样2.5/97.5百分位为[−.030495,.017739]。这是特权输入诊断，不是部署成绩；它否定“原内容和读出已足够，只需把正常查询追到参考即可达到.65”的当前配置预测，尚不能区分内容和decoder各自原因。

本轮H：以已学持久对象/边界/遮挡内容提供实例上下文，联合训练细节读出并显式输入该检测的原生Mask，可针对真实可见边界纠错。竞争解释为当前内容/信息与目标不足，联合适配仍不能胜过原生或造成过删。优先级高于继续查询专训，依据是上述同框结果、A已测完整形状.923019及特征改善43.4266%的保留能力、V16过删风险，以及[ShapeMask](https://arxiv.org/html/1904.03239)、[PointRend §3.2](https://arxiv.org/html/1912.08193#S3.SS2)、[RefineMask](https://arxiv.org/html/2104.08569)的实例上下文和细节互补原则。文献不保证本项目阳性或+5可达。

对像素BCE，原生起点的梯度为`sigmoid(z_native)−y`。输入原生概率使细化网络能在图像细特征及重建内容之外观察本检测当前的前景判断；同一位置被多框覆盖时，这一条件具有检测行身份。增加条件扩大了可用信息，不构成必然改进定理。

## 固定输入与模型

- 父模型是B15末EMA，Run `RUN_SPM_V17_FORMAL_B_d53fa8aa06c8`，SHA `7359d50bef6512fe8cc9a5b5c979cc214d83a8466ecce904f148667f2de83725`。A30来源和PCA均保留，不继承工程优化状态。
- 原生V13 FP32权重SHA `0e40602f1dbf0697fd49fa8e9f887c068970e3c5c39bd618f66e483c8712c8d6`，PCA SHA `50c8076847adaf34eb339c7063681d8b14eace68bef72d30d6fa5bf0124fc350`。基础YOLO、BN、Box/Class/score/排序、P/c0及raw/output身份冻结。
- 仍用全部1272原始真实train图的21455正常检测训练案例（20250正例、1205背景，1574模糊关联不当背景；4个GT未覆盖如实记录）。同原C的关联、家族权重、画布组内打乱及完整覆盖，不添加开发图、再遮挡图或合成到本阶段训练。
- 对象128×128×8²、边界/遮挡各64×128×4²，查询器、共享投影和重建器沿B。每条正常检测输入自己的160²原生logit，按同640像素中心坐标采样64²后sigmoid，接入原512通道细特征，1×1入口增加64权重，初始化0。总参数4981165。残差最终输出头仍为0，初始正常Mask精确等于原生。
- 推理只用当前RGB、冻结正常检测/特征和本模型，无GT或参考图。新类、缓存评价、RGB重载、独立验收均显式标记`native_mask_conditioned_v1`。

## 固定训练和预算

30完整轮，每轮21455例，batch32，4A6000每卡8例，共20130更新；固定第30轮EMA，不按中间AP选模型。AdamW、lr1e-4、betas(.9,.999)、eps1e-8、普通矩阵wd1e-4、norm/bias/role/记忆内容不衰减、clip1、warmup1轮、cosine最低1/30、EMA.999沿原C。

第1–5轮固定记忆内容/投影，训练查询器、重建器及细节头；第6轮添加记忆组，lr1e-5、预热1轮，保留其它Adam状态。原structure辅助头在本阶段不作独立能力结论。损失仍是640坐标BCE＋Dice＋.1边界＋.1记忆特征＋.05原生正确内部logit保持，不新增loss或调整系数。显式每副本BF16、检索和损失FP32、TF32 false。

仍遵守资源v10总80GPU小时、合计≤4卡、C含工程/验收18GPU小时；已完成A/B/图/同框诊断合计约39.358889GPU小时。新GPU工程最多4卡15分钟、0正式优化；正式作业4卡/24CPU/96GiB、4小时，内部训练3.5小时，末评价预留时间。若工程不通过不启动；若实际完整轮速度不能在预算内完成，保留实际Run并按原规则另冻资源接续，不能偷减轮次。

## 科学判据与归因

完整432旧dev/2863GT/12899正常输出，同Slurm291 FP32原生评价器和配置：Box AP66.884503、Mask AP57.343500、Mask AP75 69.009822、小目标20.623411、原Mask75成功2126。GT的bbox/segm各自官方匹配；同检测Box75诊断另存，不混用。
