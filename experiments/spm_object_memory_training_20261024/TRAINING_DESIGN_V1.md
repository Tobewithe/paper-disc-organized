## 一 依据与研究主张

V15在合成GT框条件下身体对应PCK@0.10为89.8878%，完整实例归属IoU为57.2013%。V16在432开发图、2863GT上Mask AP下降4.7165个百分点；同一Box75匹配的2388个检测中，多余前景像素减少42.66%，遗漏真实前景增加97.09%。这些证据支持优先研究实例归属与正确区域保护，没有证明全部失败源于某一种原型定义。

证据：[V15报告](../spm_canonical_object_training_20261023/REPORT.md)、[V16报告](../spm_instance_body_readout_20261024/REPORT.md)。V16实际训练为20955条可抽记录上的32000次有放回抽样，不能据4000步称充分覆盖。

**H：**通过跨样本记忆和同对象不同遮挡的成对训练，模型可以在不可靠局部证据下，利用可复用的对象结构及边界归属模式，重建更可靠的实例特征；真实掩码训练再将其变为可见像素归属。

**H_alt：**既有YOLO特征与训练数据没有提供足够的区分信息，或新增训练主要改变掩码收缩偏好；重建器即使拟合训练样本，也不能在未见对象与遮挡组合上改善归属。V16的监督尺度和覆盖不足是有具体依据的竞争解释，本设计同时修正这些工程因素，因此新旧AP差不能单独归因记忆机制。

正面方法依据：ShapeMask使用检测实例查询形状先验并细化掩码；VQ形状码研究采用先学习可解码记忆、再从图像预测编码的训练顺序；BCNet与多对象遮挡研究说明边界归属需要遮挡双方的关系。它们支持设计原则，不提供猪群数据上的收益保证。[ShapeMask](https://arxiv.org/html/1904.03239)、[VQ形状码](https://arxiv.org/abs/2012.00985)、[BCNet](https://arxiv.org/abs/2103.12340)、[多对象遮挡推理](https://arxiv.org/abs/2012.02107)。

本版取代V16结案后尚未执行的“先单独核验F/T像素归属”作为唯一前置建议；其问题纳入本版数据与重建验收。V4至V16的冻结协议、失败、权重与Gate全部保留，不重新解释为新方法结果。

## 二 YOLO如何参与

采用V13原生候选作为固定基础，其已有开发Box/Mask AP为66.889276/57.358486。来源权重SHA为`0e40602f1dbf0697fd49fa8e9f887c068970e3c5c39bd618f66e483c8712c8d6`，来自[V16输入登记](../spm_instance_body_readout_20261024/CONFIG.json)。正式执行前重新校验文件与实际环境，不把旧登记当作本轮已完成的设备核验。

| 阶段 | YOLO的角色 | 实际更新的参数 |
|---|---|---|
| A 对象记忆训练 | 冻结P2/P3特征提取器和特征教师 | 训练期编码器、原型内容与检索键、对象/边界/遮挡重建器 |
| B 实例匹配训练 | 冻结特征和检测器，提供实际框及邻近实例上下文 | 部署查询器与匹配器；A的记忆和解码器先冻结 |
| C 真实分割适配 | 冻结全部原生路径，包括Box/Class/P/c0/BN | 匹配器、实例掩码解码器及低学习率的原型内容/键 |

首版不解冻Backbone或Neck：一方面保持检测能力，另一方面避免构库与查询的视觉坐标漂移。YOLO的前向计算可以处于无梯度模式；新增模块有自己的训练目标及梯度，不依赖修改原生O2O的detach。

是否使用YOLO由三个条件决定：下游是否固定YOLO、是否需要跨检测器迁移、现有特征是否支持所需重建。本任务下游明确且已有可复用的冻结接口，因此选用YOLO。若以后要求跨检测器通用对象模型，或完整输入下的重建仍暴露特征不足，再单独比较独立视觉教师；本轮不同时引入第二个大模型，也不宣称同一特征空间自动消除域差异。

## 三 原型表示与解码

使用同一冻结YOLO的P2/P3特征，按已有实际接口拼接为512维、160×160网格；特征标准化和128维PCA仅由真实train拟合并冻结。实例ROI统一采到32×32×128，训练与部署均从完整640图像特征采样，保存像素中心、ROI范围和插值合同。

首版规模选择如下，数值是可修改但须在正式Run前冻结的设计值：

| 记忆 | 条目数 | 每条内容 | 查询与作用 |
|---|---:|---|---|
| 对象记忆 | 128 | 8×8×128有序空间特征，及128维检索键 | 用实例全局与空间特征检索Top-4，组合成对象结构表示 |
| 边界记忆 | 64 | 4×4×128局部特征，及128维检索键 | 在固定ROI网格查询Top-2，重建局部边界形态与两侧归属 |
| 遮挡关系记忆 | 64 | 4×4×128关系特征，及128维检索键 | 查询包含本实例、最多3个相交邻框及剩余场景上下文，重建局部可见性/归属 |

三类键值共约5.125MiB FP32，不含编码器、解码器与优化器。实际可训练参数量在实现后计算，不把该存储量当完整模型大小。边界查询覆盖固定空间网格，不用GT边界选推理位置；邻框按正常预测框IoU排序，缺邻居用显式缺失标记，栏杆等未被检测的遮挡物由场景上下文表示。

检索使用归一化查询与键的余弦相似度，温度固定0.1，Top-k内softmax后组合空间内容。A前2轮用全库软检索，随后固定稀疏Top-k；允许通过共享解码器产生连续形态，不要求一条记忆对应一种人工姿态标签。初始化仅使用train特征和固定种子。

记忆主解码路径只能读取被检索的内容及规范网格坐标，不接收原始ROI特征的跳接或任意连续查询向量，避免把重建完全交给绕过记忆的通路。C阶段另接图像细节分支，并保留独立的记忆重建辅助输出。原型和解码器共同保存对象知识；一个局部条目不宣称等于一头完整猪。

主要输出为：重建的对象特征、可见掩码、已知区域内的完整对象形状、边界距离/类型、像素归属与局部遮挡关系。最后四类是训练约束；跨对象前后关系按局部区域表达，不强迫复杂接触场景满足单一全局前后顺序。

## 四 数据构建与真实性边界

既有登记资产：1272真实train图、432反复使用的dev图；全部1704图有17505个GT，扣除2863个dev GT后真实train为14642个实例；旧cutout流程登记9039个合格train donor。另有3584合成train图、512合成dev图，来自2048组几何/4096外观的同一基础猪资产。来源：[真实数据摘要](../spm_v4_scale_20261023/runs/RUN_SPM_SCALE_PREPARE_REAL_8ca79047bd79/SUMMARY.json)、[donor摘要](../spm_v4_scale_20261023/runs/RUN_SPM_SCALE_CUTOUT_6b92f3da87eb/SUMMARY.json)、[合成拆分](../spm_v4_scale_20261023/runs/RUN_SPM_SCALE_SYNTHETIC_f19b148b353a/SUMMARY.json)、[资产合同](../spm_v4_scale_20261023/CONFIG.json)。这些是已存记录，本轮尚未重新读取服务器原图。

数据分三种权限，全部保留来源和有效监督区域：

1. **原始真实实例。** 使用全部真实train GT，保留小猪、接触、灰度/低照与难例。真实可见Mask可监督当前可见性和边界；未经标注的隐藏身体、深度顺序没有真值权限。
2. **真实成对再遮挡。** 9039个既有合格donor各构造3种新增遮挡，覆盖0–20%、20–45%、45–70%的新增遮挡比例；来源、遮挡者与布局只来自train。干净参照指“新增遮挡之前的原始可见区域”，不能称整头猪完整真值。每种版本在完整640画布中实际提取YOLO特征，不把特征图剪贴当作RGB重编码等价。
3. **可控合成对象与关系。** 从合成train产生同姿态同相机的无遮挡/有遮挡配对，记录对象ID、完整投影、可见Mask和局部前后关系。只在确有完整标注的样本上监督完整形状。旧图缺少配对或关系记录时需补生成，不能编造标签；同一低多边形资产仍记单资产局限。

主真实对象案例共有`14642 + 3×9039 = 41759`条，其中27117条是新设计的再遮挡版本，尚未生成。每轮所有案例恰好遍历一次；所有合成train实例同样完整遍历。真实与合成的损失贡献按域内均值3:1归约，避免凭重复某些样本凑比例。原始真实GT仍全部参与，不能让donor过滤替代真实训练集。

增强包含真实范围内的尺度、朝向、亮度、灰度、模糊及邻猪/栏杆遮挡；参数分布由train统计，所有形变同步变换标签。对象表示一致性只施加于几何和相机相同、仅背景/外观/遮挡变化的配对；跨姿态样本不强迫使用同一个空间原型。

保持真实train/dev隔离，合成同几何的不同外观及遮挡版本只能位于同一拆分。开发再遮挡从dev donor独立构建；既有dev已经使用，结果只能作开发证据。预先保留未在训练中出现的对象来源×遮挡布局组合；不将同资产新随机种子称跨资产泛化。独立test在确认计划冻结前保持未读。

## 五 三阶段训练

### A 先学记忆与重建

训练期编码器从较完整参考或当前关系区域得到检索分布，联合更新原型与解码器。对象目标为冻结YOLO在参照图上的特征；边界和关系目标由其对应区域特征与合法标签组成。GT仅用于训练目标、对象关联与训练期参考构造，不成为部署输入。

损失采用`L_A = L_feature + 0.25 L_mask + 0.25 L_boundary + 0.25 L_ownership + 0.10 L_pair + 0.01 L_usage`作为首版设计值。

- `L_feature`：有效目标对象区域上的归一化Smooth-L1和余弦误差，各占一半，按实例归约。目标特征及PCA固定，防止目标和预测共同塌缩。
- `L_mask`：有标签的可见/完整形状BCE与Dice；完整部分仅在标注有效区域计算，缺项不补伪真值。
- `L_boundary`：截断归一化符号距离误差与边界类型分类，区分真实轮廓和已知遮挡截断；真实未知类型不参与类型项。
- `L_ownership`：本猪/其他对象/背景的像素分类和已知局部遮挡次序；未知位置忽略监督，不把未知当背景。
- `L_pair`：同对象同姿态同相机不同遮挡的对象检索分布一致性；边界和遮挡分布允许并应随场景变化。
- `L_usage`：约束全训练分布的记忆使用，记录有效条目数和使用熵；不要求每个样本均匀使用全部条目。

主学习对象是可重建的空间视觉知识，掩码及关系提供结构约束。损失各自按有效元素和实例归一化；上述权重不代表文献已证明的最优比例。

预算建议：30完整轮、有效batch64，AdamW lr3e-4、weight_decay1e-4，前1轮预热后余弦至1e-5，EMA0.999。最后一轮EMA为固定候选。仅真实案例产生1252770次曝光，每条30次；合成曝光另外报告。每轮计数断言禁止静默漏样。

### B 再学从当前图像匹配记忆

冻结A的记忆、训练期编码器和解码器，训练部署查询器。其输入仅为当前遮挡图像特征、正常预测框/邻框及相对位置；输出原型检索分布。对象目标来自同一对象参考分支，边界和关系目标来自当前场景参考分支。配对参考与当前图使用相同的当前预测框及ROI坐标，只改变新增遮挡，避免把两个不同裁剪位置的特征直接作恢复目标；GT框参考成绩另列，不冒充正常预测框能力。

使用`L_B = L_feature + 0.25 L_mask + 0.25 L_ownership + 0.10 KL(p_reference || p_query)`，KL在Top-k之前的全库软分布计算，避免稀疏支持不相交产生无穷值。分布蒸馏同时结合解码质量，避免只优化一个原型ID分类准确率。真实自然遮挡没有完整参照时，只在已知可见区域计算重建；受控再遮挡允许在被新遮住的原可见部分计算恢复。

建议15完整轮、有效batch64、lr3e-4，其余优化器/EMA日程同A。GT扰动框与实际预测框按前5轮过渡、后10轮全部实际预测框；扰动中心偏移以框尺寸的5%为标准差，宽高在对数空间以0.05为标准差，均截断到2倍标准差。实际检测按类别和Box IoU≥0.5关联训练GT，同一GT多检测在一个轮次内循环并作GT等权；模糊关联不能当背景。关联有效GT逐轮完整覆盖，未匹配GT单列为检测覆盖缺口，不冒称匹配器已训练该正常检测。

正常输出背景按原始频率和固定轮转表参加损失，不将稀少背景扩为25%采样。新轮次使用新的图像增强必须重新做RGB前向；固定缓存只对应其记录的实际增强版本。

### C 最后适配真实实例分割

新掩码解码器接收重建对象/边界/遮挡特征、当前细节特征及原生logit，输出实例空间修正。记忆分支持续接受重建辅助监督，防止在任务训练中被绕开。真实掩码以原生输出为起点；新增输出层零初始化，工程阶段验证零修正解码和原生完全一致。

首5轮冻结记忆、训练匹配器与掩码解码器；后25轮原型内容与键以解码器学习率的0.1倍更新，并保持参考样本重建。YOLO和PCA全程冻结。

主监督在实际部署输出坐标计算：将修正logit按冻结插值变换到640并执行同样的预测框裁剪，随后对原始640可见GT计算BCE、Dice和边界项。禁止把平均池化到160的覆盖率损失作为唯一主监督。训练中原生预测正确且距GT边界大于3像素的区域增加原生logit保持项，GT错误区域仍接受纠错监督；部署不读取GT。保持项约束的是当前函数，不仅是冻结基础参数。

首版`L_C = BCE_640 + Dice_640 + 0.10 L_boundary + 0.10 L_memory_reconstruction + 0.05 L_preserve`；保持项为原生与新logit的Smooth-L1。所有像素项先按有效像素归约，再按GT/图像归约；边界3像素以640坐标定义。原生判错的像素不进入保持项。A中的合法参考目标在其对应训练案例上提供记忆辅助监督，实际自然遮挡的未知区域仍不补标签。

建议30完整真实训练轮、有效batch32，解码器lr1e-4、记忆解冻后lr1e-5；其余优化器/EMA及选模规则同A，最低学习率按各自初始学习率的1/30设置。所有正常训练输出通过固定轮转完整曝光，以GT归约消除多预测重复权重。部署使用全部正常输出检测，不使用GT选择实例或应用修正。

这些是首版设计门槛，须在正式数据清单和代码冻结时一并登记，运行后不调整。每阶段使用固定末轮候选。工程失败或预算未覆盖全部轮次记未完成，不改称科学阴性或充分收敛。

## 七 比较范围与机制归因

主效用比较仅包含同配置原生YOLO与完整方法，遵守用户两臂范围。原生参照使用V13固定候选，不增加原生训练或其它训练臂；额外数据、参数、训练预算、监督及高分辨率读出属于整套方法的混杂，不能据两臂AP差宣称原型独立因果贡献。

M1由V15归属不足与V16同检测过删提供；M2由A/B重建与归属及C真实效用给出。M3明确保持共同输出与披露未匹配容量/预算。本设计为方法效用探索，正式机制证明需要另行冻结匹配训练对照。
