## 唯一方法变化与无 GT 实现

对每条正常最终输出i，原图原生二值掩码为m0，原soft-IoU方法掩码为m1：

```
a_i = 原生m0的前景像素数（compressed RLE area，原图坐标）
g_i = 1 if a_i >= 9216 else 0
c_i = c0_i + g_i * Δc_i
输出掩码 = m1_i if g_i == 1 else m0_i
```
