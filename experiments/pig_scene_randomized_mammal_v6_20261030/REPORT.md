# 原始 MAMMAL 随机合成与接触验收

已经接通原始11239顶点猪体、独立参数抽样、有限软体接触、Blender RGB与几何标签，以及实际看图审核。本次共审核19张随机/场景族/纠错样例、92个合成实例；另查看7张原始预检与2张接触代理对照。**当前结论：工程链路可继续使用，正式训练数据质量未通过，批准训练图数为0。完整数据交付目标未完成。**

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | 旧低模不能满足猪体细节；接回现有MAMMAL后，仍需证明随机化、互相接近/遮挡、接触形变与标签可以同时成立。4张白名单无标签TRAIN RGB实际可见相邻栏位、大小体型混合、灰度成像及广角边界，旧开放猪栏未覆盖。不能只增加随机参数或图数就称完成。 |
| **机制假说** | 不适用：本轮为工程资格验收，不是模型机制/迁移实验。工作主张是“独立基础抽样＋显式几何/物理条件＋最终像素/看图验收”可以构造可追溯样例；竞争解释是单模板和未资格化姿态继续限制画质，背景/相机变化不能解除这些限制。 |
| **针对性方法** | 锁原资产/rig/9源部位与Blender4.2.1，禁止真实既有标注、旧GT拟合和dev/test。先8例预检，再2例粗代理接触；1024独立提案核随机流；12随机图与8槽场景族有限CPU生成；两份原失败输入只修位置中心与尾根锁定后重放。全部RGB真实查看，使用独立三角形与射线核验，保留拒绝、异常及原Run。9B只对4张无标签RGB做全局语义候选，32字段逐项审核。 |
| **整体结果** | 793全密度软体控制出现1880/11239非有限顶点，原设置关闭；794以112顶点闭合粗笼驱动原渲染网格稳定，最大位移1.88156%体长、2070顶点变化，独立交叉检查负对照111、接触0，1024射线一致。797生成12图，但外观/姿态未过；798仅5/8槽出图，36个栏位提案拒绝。799按相同两份失败输入修正后2/2出图：512条独立场景射线身份0差、新增非相邻自交0、猪间/设施交叉0；原源头/尾20组局部自交仍保留。19图合计2560条场景、2944条孤立猪、6600条部位投影独立射线及全部V⊆S⊆P一致。800保存场景重渲染的几何、相机、native和最终RGB逐像素完全一致。相对原生任务模型及已有方法的AP增益/损伤均**未测**，没有模型训练或效用对照，不能归为方法收益。 |
| **研究决策** | **当前优先建设有身体部位与支撑检查的合法姿态资产库。** 依据是原网格/标签/随机流已可运行，增加材质/灰度/畸变后仍有明显重复侧卧、单一体型与细部位像素不足，且尾根角度实际增加自交。保留原适配器、碰撞/投影与接触代理；停止当前配置的批量扩增。唯一下一步是建立源保真的站立/腹卧/侧卧姿态资格表，先处理源尾根/口部缺陷并验证头耳肢蹄尾和地面支撑；尚未启动这一新资产版本。若该资产资格通过而同条件图仍明显不自然，再重评材质/体型主导解释；不因重放或数值通过宣布训练数据合格。 |

当前可执行链路为：无标签RGB可见条件审核 → 注册参数独立提案 → 姿态/合法布局与接触库 → 原精度猪体渲染 → 同一最终几何导出标签 → 独立检查与Agent实际看图。2B不是这轮的强制环节；9B不生成坐标真值或任意执行脚本。移除的对抗/判别器/特征参数反馈没有恢复。

物理求解的粗笼只作变形驱动，最终RGB、实例与部位标签仍来自原11239顶点/22446面的猪体。当前实际稳定结果主要是单向接触；双侧共享项是对称半位移近似，**不是双向耦合猪群软组织动力学**。猪间和设施穿透通过三角形检查拒绝，地面通过整体平移支撑与躯干间隙核验；没有逐顶点压平，也没有重力稳定性或生物材料标定的结论。

上述两个场景没有通过正式外观质量标准。主要问题是皮肤仍像平滑模型、卧姿与小体型行列过于规则、体型没有独立资产变化，橙色地板图案也不能替代真实磨损材质。几何有效不等于写实或泛化有效。

9B/796的4次模型调用全部schema合法，但32字段只有13项直接准入，14项部分准入、3项拒绝、2项未知。侧卧/俯卧混淆、从灰度图断定肤色、漏报栏杆遮挡等已由实际RGB审核修正；这些数字不是独立人工标注准确率，也不支持估计真实场景频率。4张画面存在相同场景/机位关联。

肤色图由**内置ImageGen**生成，只接Base Color，未接位移、透明度或几何。资产：[PNG](assets/materials/pig_skin_albedo_imagegen_v1.png)；完整提示词、生成来源和SHA：[TEXTURE_PROVENANCE_V1.json](TEXTURE_PROVENANCE_V1.json)。新图未证明该纹理已消除外观差距。灰度、径向变形、橙色穿孔地面纹理和大小缩放也均明确标为代理。连续逆向像素映射采用[OpenCV原始说明](https://docs.opencv.org/4.x/d1/da0/tutorial_remap.html)的定义；标签在相同连续坐标的射线上重算，没有对实例/部位Mask作线性插值。相机尚未真实标定。
