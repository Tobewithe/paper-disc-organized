# COCO 图片级严格框覆盖与精确计数诊断

复用官方 raw 能力实验的正常输出、逐预测分数和 COCO Box75 匹配审计。只统计含普通 GT 的 4,952 张图片，排除无普通 GT 的图片。

对每张图片设普通 GT 数为 `n`，固定一个置信度阈值 `t`，保留 score≥t 且非 COCO ignore 的框：

- `coverage_all`：n 个 GT 都至少被一个 Box75 预测匹配；允许额外误报；
- `exact_n`：恰有 n 个保留框，且 n 个框一对一匹配 n 个 GT，所有框都 Box75 正确。

主报告使用 Box75；阈值 0.7006148696 是既有全局 Box75 precision=90% 的数据驱动阈值，同时给出 0.5、0.7、0.8 对照。该分析回答图片级输出能力，不等同 COCO AP。
