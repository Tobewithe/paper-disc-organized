# 图片级严格框覆盖与精确计数

## 结论

对每张含普通 GT 的图片，设 GT 数为 `n`，只保留分数达到阈值的正常输出框，并用 COCO Box75 匹配审计判断：

- `coverage_all`：全部 n 个 GT 都有 Box75 匹配，允许多余误报；
- `exact_n`：恰好保留 n 个框，并且 n 个框全部一对一 Box75 正确。

在最有解释力的全局 Box75 precision=90% 阈值 `score≥0.7006148696` 下，4,952 张含普通 GT 的图片中：

- **1,086 张（21.93%）**覆盖了全部 GT，但允许存在额外框；
- **1,051 张（21.22%）**恰好有 n 个高分框，且全部 Box75 正确。

因此，“图片里有 n 个 GT，模型给出 n 个高置信且全部正确的框”是一个严格条件，当前约占五分之一图片。

在这个主阈值下，非 exact 图片的失败构成是：3,846 张只有漏框，35 张只有额外框，20 张同时漏框和多框。也就是说，21.22% 的 exact 率主要受高置信召回不足限制，而不是额外误报单独造成的。

这解释了两个数字看起来矛盾的原因：score≥0.700615 时平均每张图保留约 2.90 个框，而每张含 GT 图片平均有约 7.34 个普通 GT；score≥0.001 时可以覆盖更多 GT，但低分额外框使 exact-n 率降到 1.01%。当前模型没有找到一个全局分数阈值，能同时满足完整召回和精确计数。

## 不同分数阈值

| score阈值 | 全部 GT 被覆盖 | 恰好 n 个且全部 Box75 正确 |
|---:|---:|---:|
| 0.001 | 2,580 / 4,952 = 52.10% | 50 / 4,952 = 1.01% |
| 0.5 | 1,327 / 4,952 = 26.80% | 1,203 / 4,952 = 24.29% |
| 0.7 | 1,087 / 4,952 = 21.95% | 1,052 / 4,952 = 21.24% |
| 0.700615 | 1,086 / 4,952 = **21.93%** | 1,051 / 4,952 = **21.22%** |
| 0.8 | 913 / 4,952 = 18.44% | 901 / 4,952 = 18.19% |
| 0.845184 | 792 / 4,952 = 15.99% | 786 / 4,952 = 15.87% |

0.001 是原始输出保留阈值，包含大量低分框，因此“全 GT 覆盖”达到 52.10%，但精确 n 框只有 1.01%。提高阈值后，覆盖率下降，精确框数量的含义更接近“高置信、低误报”的严格图片级成功。

## 和 raw 候选能力的关系

这是最终正常输出层的图片级统计，不能与 raw 候选池的 GT 级存在性混同：

- raw argmax-correct 候选池中存在 Box75：29,956 / 36,335 GT；
- 正常输出中按 score≥0.700615 且 Box75 正确的图片只有 1,051 / 4,952；
- 说明“每个 GT 都有一个可用候选”与“同一张图恰好保留 n 个正确框”之间还有候选排序、分数、top-k、NMS 和误报控制问题。

因此后续评价应同时保留 GT 级 raw 能力和图片级最终输出两个层次。图片级 exact-n 适合作为检测输出护栏，不能单独作为 prototype→coefficient 机制指标。

## 限制

- 本次主阈值来自既有全局 Box75 P90 统计；未根据本次图片计数结果重新挑阈值。
- 匹配使用既有 COCO Box75 审计；这是严格诊断，不是 COCO AP 的替代品。
- 含普通 GT 的图片为 4,952 张，另外 48 张没有普通 GT，未纳入 exact-n 分母。
