# 猪专用YOLO训练候选：合成概念监督，原生模型部署

2026-11-01。**设计讨论，不是冻结执行协议；没有新渲染、模型前向或训练。** 用户明确保留原型研究中的“概念监督”核心，用合成数据教会模型猪的特征，研究目标转为有效的猪专用YOLO训练方法，不再强求改变YOLO架构。

范围版本见[训练方法目标v5](../../paper/manuscripts/spm_yoloseg/TRAINING_METHOD_GOAL_V5_20261101.md)，唯一动作仍由[总控](../../project/ACTIVE_PLAN.md)登记。本文所有样本规模、阶段、学习率、权重和新筛选线均为候选；不继承RLPL已用完的授权/预算。

## 1. 主判断：教会可辨认的身体结构，而不是强迫存在一个原型库

**我主张优先研究：可见粗部位监督，能否在普通合成几何辅助训练之上，提高原生YOLO的真实猪群实例分割。** 配套边界归属监督区分猪—背景、猪—猪、猪—设施；可见性首先决定哪些标签可用，不另堆一个预测不可见细节的任务。姿态、体型、成像和拥挤度首先用于生成覆盖和分层评价，不在首版全部加成loss。

核心链路：

```text
真实TRAIN RGB + 原始Box/实例Mask ──> 原生YOLO正常任务损失
                                       ↑
合成RGB ──> 同一个YOLO的可训练特征 ──> 训练期小读出头
                                       ├─ 几何前景/边界归属
几何/最终表面/首命中 ──> 合成标签 ────────└─ 五类可见粗部位

训练结束：删辅助头；正常RGB → 原生YOLO Box/Class/Mask
```

“猪专用”来自任务相关的监督和训练分布，而非仅把类别数改为1，也不要求发明新网络。原生Proto26的32个逐图掩码基不等于语义原型；不把其中某一通道强行命名为“头/腿”。命名语义落在可删除的读出监督上，允许原生P保留自己的基表示。

## 2. 为什么值得优先，又为什么不是旧方法改名

| [RLPL](../spm_rlpl_pipeline_20261101/FINAL_REPORT.md)：N/B2/C2/D2=57.343500/56.222099/52.357215/54.481384 | 停止无语义聚类/局部一致性配置的扩训；新路线必须检验明确标签的增量，并设真正real-only对照 | B2有合成前向/BN，不能称纯真实对照；D2>C2不等于原型有效；BN因果未证 |
| [V29错误复核](../spm_object_binding_admission_20261026/REPORT.md)：307个固定Box75失败实例，错误像素54.7747%位于4px GT边界带，邻居相关5.2801% | 选择贴近像素证据的部位与边界，不把全局排他/隐藏完整形状作为首要任务 | 后验、特定定义；边界带对小对象较宽，不能宣称54.8%的错误必可由新监督修复 |
| [SAP/SynRealPart](../../literature_search/pig-concept-supervision_2026-11-01/README.md)用合成虎/马部位学习并迁移到真实四足动物 | 合成解剖标签有实际跨域研究依据；简单合成训练并不够，必须测真实效用 | 不是猪群YOLO的结果；其真实关键点/轮廓拟合与本项目生成禁读GT合同不同 |

新候选相对V20的实质变化是**原有视觉/分割计算直接接受概念梯度，不另训练常驻对象库/新检测器**；相对RLPL是**几何锚定的部位标签取代匿名原型分配**，不用相同局部颜色/纹理就必有相同语义的假设。正面依据是已有动物部位迁移研究及可用的源部位映射，不是“旧路线失败，所以新路线必成”。

## 3. 概念词表：首版只启用能教、能看、与任务有关的内容

| 特征/概念 | 第一版用途 | 可靠标签来源及处理 |
|---|---|---|
| 头部（含耳）、躯干、前肢、后肢、尾部 | **主新增监督：五类可见粗部位**，加背景为6类 | 原MAMMAL九类源区合并：HEAD/L_EAR/R_EAR→头；MAIN_BODY→躯干；左右前腿→前肢；左右后腿→后肢；TAIL→尾。须核到当前变形后的最终表面，不能拿旧低模标签直接覆盖 |
| 猪体前景；猪—背景、猪—猪、猪—设施边界 | **共同几何辅助监督/强基线**，不是全记作部位创新 | 实际首命中owner、环境语义和有效域；边界按两侧实体类型派生，不把内部头—躯干线当实例边界。三种边界可用独立通道，交汇处可多标签 |
| 可见、外物遮挡、自遮挡、出画、像素不可读 | 首版作为**监督有效域、覆盖和分组字段** | 已知首表面只教可见部分；完全不可见/过小部位不是不存在，不补硬负例。自遮/外遮完整区分若没有隔离渲染证据则记unknown，不猜 |
| 站立、左右侧卧，头尾方向、身体主轴 | 生成分层/留出，第二版才考虑姿态辅助目标 | 用实际几何和投影定义；旧prone代理不是合格腹卧，单帧不能把侧卧直接标为“睡觉”。方向不可辨时unknown |
| 体长宽、腿粗细、大小、肤色/污渍/光照 | 变化覆盖、成对外观控制，**不是第一版回归目标** | 同语义应跨合法外观变化；不要求RGB反推出精确体重、年龄或不可辨材料参数 |
| 细口鼻、蹄、乳头、左右细分、稠密规范坐标、完整隐藏身体 | 暂缓 | 源资产、自然形态或最终任务分辨率支持不足；几何存在≠图上可辨。耳合并进头、左右腿合并是降低歧义，不是宣称它们不重要 |

五类语义是起点，不是“五类全部已具备训练标签”的事实。任一必需类缺少可读支持时，先在资格阶段记录不足并阻断该版本，不训练后再偷偷删难类。无法映射的表面保留`unknown_part`与owner；不能当背景或漏掉整个实例。

**可见性不等于补全命令。** 合成物理可见标签与真实独立实例GT的重叠/设施语义已知不同。本版合成不进入原生Box/Mask任务target；物理标签只训练独立辅助读出。真实GT仍完整保留，不互斥化、不重画、不据几幅样例宣布全体amodal。分开读出减少了直接标签冲突，但共享特征仍可能受不利梯度影响，必须靠对照与真实护栏判定。

## 4. 已有标签能力与真正缺口

实际源九部位记录见[原始MAMMAL资产记录](../pig_scene_full_corpus_design_20261029/EXISTING_MAMMAL_ASSET_RECORD_V1.json)。当前合成构建代码保留`parts`和`source_face_id`；已发布RLPL数据通过的是owner/coverage/共视射线资格，**不是当前五部位像素GT资格**。

- `experiments/spm_rlpl_pipeline_20261101/labels.py`只汇总owner/body/设施coverage，没有五部位导出。
- 相邻仓库`blender/build_farm_individuals.py`在`BODY.npz`保存最终vertices/faces/parts/source_face_id；这是标签适配的来源线索，不等于已核所有顶点/三角面/附件对应。
- 需对实际body面及眼/毛附件建立owner/part映射；不能按坐标最近邻任意贴部位。材料/UV噪声不能被编码成标签颜色捷径。
- 新部位标签必须与实际RGB共用相机、畸变/重采样、`valid_rect`和最终尺度，按保存场景及独立射线抽样复核。
- 部位内部可用高置信标签；边界不能简单复用RLPL腐蚀后的body-core点集，否则会把目标边界全部删掉。边界带正例、负例和无效面积须单列；抗锯齿/混合coverage处保留unknown，邻近可靠像素的有限带才可监督。
- 当前200组/600图、4–7猪、单身体/环境家族可作适配资格来源，但不能自动认证拥挤域/独立资产泛化。猪—猪投影遮挡与设施边界必须实际有支持；数量多、物理距离小或看起来拥挤均不替代证据。
- 训练前另隔离TRAIN-only原标注与真实640栅格合同，不能把旧160缓存插值后冒称原640GT。仅有混合train/dev标注文件时先阻断，不先整文件解析再声称未读dev。

下一小批只验证这些必要条件，不以再次海量生产为前置，不读取旧真实GT拟合来补姿态或布局。本轮未修改相邻合成仓库。

## 5. 监督接在哪里：梯度进入原生特征，而非只把外挂头训练好

选择原生`model.23.proto.cv2`的**输出**作为辅助特征F。在已存8.4.100源码中，Proto为`cv1 → upsample → cv2 → cv3`，Proto26前面另有多尺度融合。已存实际参数表显示cv2为256通道，640输入对应的160×160空间形状仍须在新真实图资格中核验。

拟使用两个不含BN的1×1线性卷积读出：

- 几何头：1个前景logit＋3种边界logit，共4×(256+1)=1028参数。
- 粗部位头：6类logit，共6×(256+1)=1542参数。
- C/Q总共2570个训练期辅助参数；这是由结构计算的候选值，未实例化/训练。头不能看GT框、owner、相机、姿态或Recipe输入；GT只在损失选取/归约中使用。

辅助头从F分叉，**不把预测拼回P/系数/检测分支**；不改原生32维P/c、匹配器、Top-K或decoder。使用可微插值把辅助logit对应到冻结的标签栅格；插值不是凭空增加边界信息。

### 参数与梯度范围

为让概念改变模型的可复用视觉表示，本候选不继承上一版“固定P/仅6240参数”限制：

1. 从同一原生N权重起步，拟更新原生Backbone/Neck/检测与Mask分支中原本可训练的非BN参数；原生固定常量仍固定。精确名称/数量需在新合同列白名单，不能简单把所有`requires_grad`置true。
2. **全部BN的affine、running mean/var及计数固定**，所有组相同。模型训练分支仍按原生合同输出；不能全局`.eval()`后误以为还有训练criterion，也不能递归`.train()`重新打开BN。
3. 保留原生O2O detach；辅助从P之前的非detach F取梯度，正常O2M任务仍承担共享视觉/P训练，O2O自身头照原生方式训练。
4. 必须实测概念loss对F和至少一个获准上游原生参数有非零有限梯度，主loss也到达这些参数；只更新辅助头视为无效实现。
5. **Box/Class/score/排序可随训练改变。** 冻结BN或检测卷积都不能保证共享特征改变后检测输出不变。此处不用旧固定检测身份合同，也不得在新导出写`native_scores_preserved=true`。正常输出和GT成功集分别评价。

FrozenBN用于减少统计更新混杂，不是已证实修复RLPL退化的方法。全网络适配本身有历史损伤风险，所以R对照、低学习率和定位护栏必须保留；它们也不保证无损。

## 6. 损失与训练组织：真实任务从第一步到最后一步都在场

候选形式：

\[
L(t)=L_{\mathrm{native,real}}(t)
+w_{\mathrm{O2M}}(t)\,[\lambda_g L_{\mathrm{geometry,syn}}+\lambda_p L_{\mathrm{part,syn}}].
\]

- 正常Box/Class/DFL/Mask及原有语义项，只接原真实TRAIN标签；原criterion未被几个手写BCE替代。
- 几何项为前景和三类边界BCE，粗部位为6类CE；按图→owner/背景单元→可用类/边界型→有效像素分层平均，空项用连接图零并记分母。部位背景单独受限，不让大背景或躯干淹没尾/肢；权重及空项归约另冻。
- 辅助乘原任务O2M权重，是为了不重复“P的任务项随日程衰减、辅助系数不变”的确定性相对加重。实际梯度大小仍会变化，不由此推导夹角、贡献百分比或安全保证。必须记录原生参数上的两类梯度范数，而非只量不同batch行的P梯度。
- 真实图没有部位标签时，不做部位CE、不做reject/背景监督，也不调用Qwen伪造细部位GT。首版不加V23蒸馏、自训练、对比聚类、隐藏形状补全等额外变量。
- 同一几何的合法光照/材质变化保持部位标签，先作为共同数据增强；不把另一条一致性loss也塞进首版。

**建议一轮有限2000更新筛选，而不是新建长合成预训练：**

| 阶段 | 建议安排 | 目的与边界 |
|---|---|---|
| 标签/梯度资格 | 小批固定场景和合法TRAIN；工程优化另账、权重丢弃 | 查实际监督/原生参数梯度/BN冻结/aux删除与导出；非科学阳性 |
| 前1500更新 | 每步4真实＋2合成，分开前向后合并loss一次更新；R仅4真实；所有臂真实日程一致 | 保持真实任务主导，同时教合成几何/部位；不是4:2比例必然有效的结论 |
| 后500更新 | 所有臂只用相同4真实，辅助关闭，固定学习率收尾 | 以真实标签校准最终任务；固定末点，不以dev挑checkpoint |
| 一次完整dev | 所有臂完成后统一评价432图 | 合成分数/概念头可解码性不能替代正常AP与损伤 |

每臂建议8000真实曝光；G/Q/C各3000合成曝光，R没有合成曝光。曝光不是独立图数。所有臂相同N初始化、真实采样、增强、步数、优化器和原生参数范围；候选AdamW非BN原生lr=1e−5、辅助头1e−4，warmup/衰减及λ须在TRAIN-only工程资格后一次冻结，不做dev搜索或失败后临时调λ。首版不加Mosaic/MixUp，避免破坏owner/边界合同；允许的翻转/几何变换须同时作用于标签和所有相应元数据。

**这些不是可直接运行的命令。** 原生完整训练与旧Mask-only的显存/时长不可类推；正式GPU上限、样本清单、两个λ、归约、原生loss时钟及资源预算均待资格测量后另立合同。峰值建议1GPU，上限仍受用户≤6GPU约束；无后台接续、参数搜索或自动扩训。

## 7. 最小有解释力的对照，而不是只比新方法与未训练N

| 臂 | 正常真实任务 | 同一合成RGB与几何辅助 | 部位读出监督 | 回答的问题 |
|---|---|---|---|---|
| N | 固定历史原生，不更新 | 无 | 无 | 相对当前可用模型是否真有收益 |
| R | 同预算原生适配 | 无 | 无 | 普通真实续训是否已经足够/自身是否损伤 |
| G | 同R | 前景＋三类边界 | 无 | 普通合成几何辅助训练的收益 |
| Q | 同R | 与C完全相同 | 等容量、等支持的非解剖空间分区 | 只是更丰富的多类稠密监督/额外训练参数就足够吗 |
| C（主候选） | 同R | 与G/Q相同 | 正确五部位＋背景 | 跨姿态解剖分组是否有额外价值 |

Q/C的辅助网络、参数初始化、全部图片、有效像素、任务项、loss形式、更新和推理完全相同。Q的候选构造：每个可用owner内，按图像x再y固定排序有效前景像素，按同实例五部位像素计数切成五段，背景/unknown不变；这样逐类支持数与C精确相同，但不保留解剖区域对应。计数来自同合成标签，额外信息已披露；Q不是“完全没有身体信息”。

Q仍有形状先验，C/Q标签可预测性、边缘位置和梯度方向不可能完全匹配；报告这些混杂及梯度幅度，**不能仅凭C>Q宣称神经网络已形成解剖因果模型**。禁止把全局统一类别改名当破坏语义，也不使用每步随机不可学习标签作为唯一弱对照。G与C名义/有效辅助容量不同，所以Q不可在声称部位独立贡献时省掉；若只做R/G/C，则至多报告复合训练配方效应。

M4的主要干预是**重新训练时移除正确解剖对应（Q）或部位目标（G）**。推理时删除辅助头按设计不应有任何变化，只是部署资格，不是机制消融。不能用一张热力图或合成分类准确率代替干预。

## 8. 可证伪主张、效用与停止出口

**H：**在真实任务持续约束、合成物理标签和真实任务标签分开、相同原生可训练范围下，稳定的可见部位语义能使原生高分辨率特征保留更可迁移的身体结构，从而比同数据几何监督及非解剖分区更好地分割真实猪。

**H_alt：**已有原生特征足够，新增收益若存在主要来自普通真实适配/合成前景边界/一般多类稠密正则；或新增概念只拟合渲染域，不产生真实效用。V20合成强/真实弱、RLPL共同退化和普通续训阴性均支持必须严肃比较这些解释。

### 待冻结的最小预测与主读数

- 唯一主效用指标：**完整432 dev正常Mask AP**；建议投入筛选要求C−N≥0.5pp且C−max(R,G,Q)≥0.3pp。
