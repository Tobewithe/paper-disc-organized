# V19：已核资产到联合场景、像素标签与全场景重放

新编译器已真实生成6张候选图、17个实例，接通固定姿态、双猪接触形变、设施、成像和9父部位标签；全部6个保存场景重放通过。**这是可复用候选版，不是合格训练数据：逐图审核批准0张，多体型、腹卧、幼体和物理孔地板等覆盖仍未完成。**

相对原生/已有方法：本实验不训练、不测AP；旧V6的资产、配方和场景集合不匹配，不报告数量增长或主观观感为同配置收益。已支持的工程条件与真实分布泛化效用分开，后者尚无证据。接触为V14已核的耦合准静态表面形变，经V18整体刚体变换进入新场景；不称压力、摩擦或组织动力学的生物力学校准。

标签仅含9源父部位；细表面候选不作为精确鼻孔、眼球、内耳、全蹄或副趾GT。实体T取物理可见V，S为隔离实例后部位可见，P为部位完整投影；无效传感器像素不产生目标。橙色网格为实心地板颜色代理；幼体、腹卧、物理孔洞明确unsupported。共同接触对只允许统一缩放/平面旋转/平移，不能独立挪动或改变体型继承旧接触资格。
