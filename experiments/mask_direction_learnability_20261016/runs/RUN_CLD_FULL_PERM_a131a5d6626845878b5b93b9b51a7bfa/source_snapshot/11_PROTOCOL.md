## 1. 整体问题、主张与科学准入

**问题：已有可修方向，现有Adapter多数没有预测出来。** [方向—幅度审计](../mask_adapter_ray_audit_20261016/REPORT.md)正式Run `RUN_ADAPTER_RAY_FULL_362251e449e3493396e69c56562af96b` 在固定256条/243图上，即使借GT沿现有方向调幅，修复也仅22→32条；C的159条见证只捕获20.13%，收益缺口捕获26.08%，两项95%上界均低于50%。因此不把单独调幅作为优先方法；这些结果不证明现有输入信息必然不足。

**H：**在现有冻结P/c0/F与检测条件中，存在可被原Adapter在短预算内利用的、实例与有益空间修正方向之间的对应关系；直接监督固定P上的归一化修正响应，并保留正确实例对应关系，应比打乱该对应关系产生更好的留出图实际掩码修复。**计算依据：**掩码logit变化是 `P·Δc`；以该响应而非32维系数坐标的距离定义方向，直接约束会改变像素的功能量。原训练集已有3091条经过原图解码核验的教师，构成可学习目标的正向来源；目标存在不等于可预测。

**H_alt：**在当前输入、模型与短预算下，教师方向不能形成有效的留出实例预测；改用显式方向监督也可能只拟合训练对象，或得到共享于图像的平均响应。旧AMT教师合格但学生较原G退化，且[旧原生分支方向回归](../coefficient_oracle_alignment_20261009/REPORT.md)未产生有效增量，支持认真检验这个竞争解释。若拟合侧本身失败，只能定位为本配置/预算未学成，不能宣布输入不含信息。

本实验可归因的变量是**实例条件与修正目标的对应关系**，不是“新loss单独优于旧loss”，也不是“空间度量是历史失败的唯一根因”。

## 3. 两个训练臂和一个同checkpoint干预

- **REAL：**原 `CoefficientAdapter('B')` 从对应实例的空间ROI、原始F/c0、框、score、类别预测32维向量d。
- **PERM：**网络、输入集合、计算量、初始化与目标完全相同；在同图中把预测行的d按固定映射转交给另一实例，再用**接收实例**的P、c0、ROI、教师和decoder计算loss。等价于破坏实例条件与该修正目标的对应，不改变GT或输出身份。
- **J：**训练结束后，对REAL的d应用同一固定映射；不训练第三个模型。它与PERM分别控制同预算学习和同checkpoint的信息使用，二者的优化/分布改变限制分别报告。

映射已冻结为 [CONDITION_MAP](CONDITION_MAP.json)：每图按 `sha256("direction-condition-v1|image_id=<id>|global_index=<index>")` 排列原输出rank，循环取下一rank为donor；n≥2时无自配，所有行一一对应；n≤1保持原样并保留在分母。留出有7张单输出图。三轮和J使用同一映射；不使用GT、教师、修复结果、mask面积或类别匹配选donor。置换全部条件包，不能只换一个score或仅打乱8×8格子；实现可直接重排行预测向量以避免改变原网络。

置换在**同图**内进行，保留图像级P及上下文分布，避免跨图原型基底不同引入额外混杂。因此检验的是**同图实例对应信息**，不声称去掉了全部条件信息。空图/无教师图均保留；不为改善控制效果删行。GT/teacher/success标签不得进入任何forward输入。

## 4. 功能方向目标、幅度处理与loss

用原 `loss_grids` 半开预测框proto ROI，记其像素集合为Ω_i。P、c0、ROI均为接收实例的缓存值。教师系数c*取已保存FP32值，定义：

`r*_i = (c*_i − c0_i) @ P`；`s_i = sqrt(mean_Ω(r*_i²))`；`t_i = r*_i / s_i`。

方向用ROI上logit变化定义，不用跨原型基底的系数余弦。派生s_i用FP64和缓存FP32值计算，无优化；若任何接受教师非有限、ROI为空或s_i≤1e−6，阻断输入有效性，不能事后丢弃。目标t_i转FP32、detach。c*原图RLE与原生c0的重放必须通过；不将教师掩码重新缩放来构建方向。

学生原始输出d_i对应 `r_i=d_i@P`。唯一新监督项是：

`L_direction(image) = mean_accepted_instances(mean_Ω((r_i − t_i)²))`。

无接受教师的图该项为连接图的0；全部图照常遍历。每个实例先按自身ROI像素均值、图内教师再等权；不按面积、教师增益或gate-on额外加权。未接受实例不伪造方向标签。

正常无GT候选采用共同幅度算法：只由拟合2510条教师求 `a = median(s_i)`（普通实例中位数，偶数时中间两值均值，无面积筛选）。该值在训练前写入两臂相同的执行合同，不能用留出数据重新标定。设 `v_i = d_i / max(1, RMS_Ω(r_i))`，空ROI令v=0，则未门控候选为 `c0_i + a·v_i`。上界截断保留小幅输出的弃修能力，不把接近0的预测强制放大为单位幅度。

保护项沿用原全输出native-probability BCE及权重0.1：在同图所有非空ROI上，使用 `c0+a·v` 的proto logits拟合原c0 logits的sigmoid，逐实例均值再图内均值。训练总目标 `L_direction + 0.1·L_preserve`；训练保护对所有输出生效，不按面积门控，只在实际推理候选使用原9216面积门控。该保护项不保证任务损伤为0，最终检查全体原成功GT。

这与原soft-IoU相比同时改变了监督形式和尺度处理，是新复合候选。**唯一严格单变量训练比较是REAL对PERM**；不得将旧G差值全部归因为某个loss成分。两臂使用同样的a、目标和保护项，范数控制相同。d=0时方向MSE具有有效梯度，不在训练loss中直接归一化d，避免零初始化余弦的奇异性。

## 5. 预算与冻结配置

每臂原B架构167872参数、同initial、seed0、1600图×3轮=4800图访问、microbatch1/累积4、**1200次AdamW更新**；两臂合计2400次。为保留真正的内部留出，不再称“每臂原2000图/1500步”。无补齐重复采样、早停、挑轮、追加seed或搜索。仅最后一轮checkpoint参与结论。两臂依次运行，不并发占用GPU。

AdamW lr=.001、betas=(.9,.999)、eps=1e−8、weight_decay=.0001，其他flags按继承合同；FP32、AMP关闭、无增强/调度/EMA/额外可训练参数。训练仅允许原17个Adapter参数名，基础模型参数不载入优化器。保留原环境：Python3.12.3、torch2.5.1、CUDA12.4、Ultralytics8.4.100及全部源码/包pins；矩阵精度、TF32、cuDNN、随机性环境逐项按继承合同核验，不依赖当前安装默认值。

`actual_cached_native_args` 中还保存了框架val入口未使用的训练默认键（例如epochs100、optimizer=auto、amp=True）；它们不是本Adapter训练的实际参数。Adapter以本节、原训练合同及显式overrides为准，AMP仍关闭、AdamW仍显式指定。原始train2017标注SHA `610fce4944abdeb15354cc765333805529359d12d88f2f711393ca586901d01d` 与实际2000图评价子集SHA `51477c03144651f01f941991661da85df0df17b6048a148feca0b7dad6bce26c` 分别登记；实际评价必须读取缓存Run的 `dataset/training_annotations.json`，不能混淆两个路径。

## 6. 两种评价权限，不能混用

### 6.1 等幅方向终点（GT辅助，不是部署）

在留出**全部581条/208图**接受教师上，对REAL、PERM、J分别计算：若 `RMS_Ω(d@P)>1e−6`，用 `c_probe=c0+s_i·d/RMS_Ω(d@P)`；否则用原生c0、仍计入原分母。每条都使用同一已保存教师的s_i，不扫alpha、不挑最佳尺度，不使用新oracle。幅度来自该对象GT辅助教师，必须标注 `GT_ASSISTED_EQUAL_AMPLITUDE`。

在完整原行矩阵中写入这些探测系数，用固定decoder计算同一GT的原图IoU；不对这些教师行应用面积门控。比较N、保存教师C*、REAL探测D_R、PERM探测D_P、REAL置换探测D_J；报告修复数及训练拟合侧的同定义描述读数。C*是已知有益参考，不能算作学生收益。主要差值为D_R−D_P，同时要求D_R−D_J与D_R−N符合第7节；附功能方向余弦、零方向比例、拟合/留出差异用于解释，不据这些副指标救回失败Gate。

### 6.2 正常无GT候选与历史方法比较

REAL的候选M在全部留出400图、42167行上采用第4节共同a及截断v；只对**原生原图mask面积≥9216**行应用修正，其余直接复用原生RLE。PERM同规则生成候选S用于控制说明；J无需额外正常候选选择。面积永远取原生mask，不依赖新输出或GT。无门控输出不作备选候选；不得因M失败改选S/J。

主要效用分母是历史原生账本确定的T490/203图；整体护栏为Box75固定配对2246/394图；同一最终检测原图IoU逐实例计算。双参照明确报告M−N、M−G_old、以及M−S，比较原图IoU，不混为AP。G_old的既有IoU/任务账本按同一400图直接复用；其训练内优势和不同训练预算明示，差值只说明本对象的输出效用，不作同预算泛化因果结论。

损伤对400图中全部**1808个原生Mask75成功GT**作census：使用完整混合预测重新运行相同COCO匹配，bbox与segm分别处理；不能只看固定Box75配对、教师行或gate-on行。记录损伤数、修复数、bbox身份/匹配不变。1808是这个内部留出有限总体的全查，无需以抽样区间伪装更大总体风险；本比例不代替COCO val22957总体的原S2抽样上界或S3全查。G_old成功账本也在同一分母报告。

当前不计算新全量AP，不启动原dev512评价或新的损伤抽样，不自动进入S2/S3。内部筛查阳性后，才建议对同checkpoint按原正式S2全口径另行执行，不能将本门槛写为S2已过。

## 7. 冻结统计、门槛和三种出口

所有配对IoU差值先图内实例均值再图等权，IoU单位0—1。每个预定分母取有该分母实例的图，按升序image_id构造向量，`numpy.random.default_rng(1729)`有放回抽图2000次，percentile `[2.5,97.5]`、`method='linear'`。同一分母的所有臂复用同一抽样矩阵。报告点值和双侧95%区间；不挑子组、不改归约或补抽。重复开发数据上的区间是条件性开发读数，不冒充独立确认。

**机制筛查K_dir：**D_R−D_P的图像宏均值≥.005且95%下界>0；同时D_R−D_J≥.005且95%下界>0；D_R−N≥.005且95%下界>0。三项为交集，不能挑一个阳性宣布通过。.005是预注册的最小实际IoU效应尺度，借用原S2的最低实用幅度，不是由本次未运行的结果调出，也不是原S2 Gate。

**无GT内部效用K_use：**M−N在T490均值≥.005且下界>0；全部2246配对均值≥−.001；M−G_old在同T490的95%下界>0；原成功GT损伤≤1%（1808全查即≤18个）；Box/Class/score/ID及原生非门控行身份护栏全部通过。M−S必须报告，但不靠控制臂较差替代对历史方法的新增收益。教师gate-on62条只作预先声明的描述子组，不能缩小主分母。
