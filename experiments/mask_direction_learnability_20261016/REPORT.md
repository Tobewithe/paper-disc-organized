# CLD-v1：有益修正方向的实例条件可学习性

**结案：主评价、笔记本独立重放、本机统计复算及1352项回传哈希全部通过；机制与无GT效用均为`NEGATIVE_AT_BUDGET`，关闭CLD-v1，不晋级S2。** 研究线：原型—系数链路。实验协议和全部模型计算代码在运行前冻结；本报告包括两组匹配训练及同checkpoint留出评价组成的完整实验。

通俗说，网络“看对实例”确实比把修正交给别的实例更好，但它产生的修正仍没有超过原生结果。正常输出的损伤控制在预定上限内，却没有获得所要求的修复收益，而且弱于已有soft-IoU+面积门控方法。两地复核已确认这些结果。

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | 此前[方向—幅度审计](../mask_adapter_ray_audit_20261016/REPORT.md)在159条已知可修见证中，即使借GT调幅也只兑现32条，说明单独调幅不能覆盖多数机会。训练集已有合格可达教师，值得直接检验：现有P/c0/F及检测条件，能否让原Adapter预测出有用的修正方向？ |
| **机制假说** | H认为实例条件和有益功能响应`P·Δc`之间存在可利用的对应；保持对应并直接监督功能方向，应比打乱对应获得更好的留出修复，并超过原生掩码。竞争解释是当前输入、架构与预算只拟合训练对象或学到图像平均响应。正确对应优于打乱，只回答了对应关系是否有作用；超过原生且满足正常输出效用才说明这种作用有修复价值。 |
| **针对性方法** | 原2000图固定拆成1600拟合/400留出。REAL/PERM同原initial、167872参数、2510拟合教师、方向MSE+.1全输出保护、相同图序，各3轮1200步；唯一匹配变量是同图实例对应。两个last冻结后，对全部581条留出教师配对作GT辅助等幅R/P/J对照；对400图42167行生成无GT候选M/S，使用同一拟合幅度a和原生面积≥9216门控，以固定配对及完整COCO任务账本评价修复与损伤。J只置换REAL方向，不训练第三个模型。 |
| **整体结果** | 留出GT辅助方向：R−P **+.045044**、R−J **+.021467**均达到对应对照要求，但R−N **−.101720**，机制三项交集未通过。正常候选M在T490上相对原生 **−.000178**，相对已有G **−.009738**；全部2246配对相对原生 **−.001846**，总体护栏失败。原1808成功GT损伤 **14/1808=.7743%**，通过≤18的内部全查门槛；旧G损伤7个。M救回6个、损伤14个，旧G救回16个、损伤7个。按原门槛，两轴均为预算内阴性；不是“未发现差别”或单纯区间太宽。 |
| **研究决策** | 结果支持“实例对应带来相对置换的优势”，但削弱“本配置的直接方向监督能形成有益修复”的主张；拟合侧R−N也为负，不能把失败单独归结为留出泛化或小样本。**正向研究重点收束到已有G的低损伤实际修复及固定P机会的兑现边界**：保留G作为已有实证方法和有限Oracle的可修见证，停止CLD-v1追加训练，不进入S2。**唯一下一步是复用已有S3、机会核对、方向审计与本实验逐实例产物，整理“可修机会—实际兑现—损伤代价”的论文证据与主张表**；不再启动一轮loss/幅度/阈值试错。只有独立新证据支持新的具体机制，才重新立项；该整理尚未启动。 |

## 2. 方向机制及竞争解释

R/P/J为GT辅助等幅方向探测，分别来自REAL、PERM、REAL同checkpoint置换；每条使用其已保存教师的尺度。它们不应用面积门控，不能当作无GT部署结果。三个必要比较取全部581条／208图，共同门槛均为均值≥.005且95%下界>0。

| GT辅助比较 | 平均ΔIoU | 95%区间 | 判定 |
|---|---:|---|---|
| R−P：同预算匹配训练对照 | +.045044 | [+.027335, +.063754] | 通过此单项 |
| R−J：同REAL checkpoint置换 | +.021467 | [+.002100, +.042465] | 通过此单项 |
| R−N：相对原生 | −.101720 | [−.122429, −.083801] | 明确失败；K_dir交集不通过 |
| R−C*：相对保存教师 | −.237877 | [−.260859, −.215691] | 描述修复缺口，不另设补救Gate |

同一581条配对中，原生达到MaskIoU≥.75为0条，保存教师为255条，R/P/J分别59/48/40条。**存在59条修复与全分母平均IoU下降可以同时成立**：不能只看修好数、漏掉其它配对的退化，也不能把教师的255条算成学生贡献。它们使用训练教师join的对象身份，不能与旧S1的256条Box75配对直接比较数量。

拟合侧2510条／867图的R−N为−.056781，95%区间[−.066750,−.046370]。REAL在训练内也没有达到等幅有益修复，故“只是留出数据不够／泛化掉点”不能充分解释当前结果。功能余弦拟合/留出为.448963/.327781、gate-on留出62条R修好9条等只作预声明描述，不据此挑子组救回主Gate。

对照共同支持的范围是：在本功能监督和预算下，同图实例对应能改善相对置换的方向结果；它尚不足以产生超过原生的有效方向。对应置换保留图像级信息，并改变优化对应关系/同checkpoint输入输出对应，不能夸大成信息论意义上“条件全部无用”或“永远不可学”。本实验也没有把损伤定位到新的解码缺陷，不能据本阴性直接推出新的结构必然有效。
