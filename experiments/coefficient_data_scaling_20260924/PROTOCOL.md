# 数据量—泛化曲线

继承 coefficient_predictability_20260924 已验证的官方 one2one 分配与掩码监督。研究问题是：冻结 YOLO26m-seg 后，h-only 大 MLP 对系数残差的学习能否靠更多 COCO train2017 图像迁移到未见图像。

- 模型/版本：官方 COCO YOLO26m-seg，Ultralytics 8.4.100；原 backbone、框/类别/原型/原系数冻结。probe 为前一实验的 P3/P4/P5 独立大 MLP，输出 32 维系数残差。
- 数据：从完整 COCO train2017 标注的118,287张图像中排除旧dev的200张，固定 seed 20260924 无放回抽取10,000张，并按抽样顺序取嵌套的 N=16、64、256、800、3200、10000。新前16张重新计算有限步oracle；dev=train2017原200张、val=val2017原200张固定不变。此前以本机有限图池缓存执行的16/64/256/800组只作为试跑，不与正式曲线混为一组。
- 训练：同一官方 GT 分配、mask_ratio=1、overlap_mask=true、640 方形、FP32；同一优化器 AdamW(lr=.001, weight_decay=.0001)、每更新8图、seed0。训练轮数随数据规模保证足够的训练更新（16/64/256/800/3200/10000图分别最多200/80/40/30/20/15轮）；dev patience10。归一化统计只由各规模训练样本计算。开发集选择时包含不修正的第0轮，避免为了填表强制启用不如原模型的 probe。既评价dev所选检查点，也评价最后训练检查点，区分能否拟合与能否泛化。
- G_train(N) 以嵌套于所有规模内的固定16张训练图、164个官方正样本为锚，分母是其原系数到有限步 oracle 的BCE差距；这是训练锚表现，不能冒充整个N训练集的平均。G_val(N) 在固定200个验证oracle实例上使用同样定义。报告dev总损失、全val同候选Mask IoU/Mask75与修复/误伤，防止只看oracle选中子集。
- 主判定：曲线是否随N出现稳定的未见图像收益。若 G_val 尚不提高，不能仅凭单个N断言表示歧义；还需看训练收敛、缓存精度和多个seed。若随N上升，优先解释为数据量敏感的线索，仍不能单因归因。

正式缓存为磁盘预算使用FP16存原型，只允许缓存阶段量化；h、c和loss计算仍FP32。对同一张图即时计算FP32与FP16原型下的分割损失误差，写入缓存运行记录。其它运行不可回写旧实验。
