## 1. 主张、依据与会改变决策的结果

检验：**原生大掩码选择性应用既有系数残差，是否同时带来具有实用量级的全量Mask AP收益和受控的任务损伤。** 已有`RUN_LARGE_MASK_FULL_6a2709ae1cd24429b29a3c6d6f1600b8`通过原S2开发三项数值门槛，目标ΔIoU +.010024、总体+.000891、原成功损伤2/1024。E4两臂目标改善却伤及原成功实例，进一步支持优先检验选择性修复；它不替代本候选自己的正证据。

竞争解释是：收益仅集中于有限开发目标，扩大到完整检测集合后，AP改善不足或损伤增加。S2固定配对IoU与全量任务AP不是同一统计量。本实验直接决定该候选是否晋级；结果不会用于临时改损失、门控或训练预算。

## 4. AP不确定性：2000次配对图像bootstrap

- 图像总体为按image_id升序排列的全部5000图，包含无GT或无输出图片。固定NumPy2.4.3 `default_rng(1729)`/PCG64；每次有放回抽5000次，A/B使用完全相同的有序抽样索引。2000次，双侧95%，`quantile([.025,.975], method='linear')`。AP按0–100点表示。
- 重复图片不交给COCO的原始ID去重。每个抽中出现位置赋新image ID=位置+1，GT和检测ID按出现位置×1000000000000加原ID（并强制所有生成ID<2^53，保证float64整数精确）重新分配；0无匹配标志保持0。所有复制GT、检测和匹配数组均保持同图对应。
- 工程等价加速：COCO的每图/类别匹配与其它图无关，因此一次保存完整`evaluate()`结果；每次抽样复制相应area=all/maxDets100匹配项并重编号，再调用**原版COCOeval.accumulate**重算全局稳定score排序、TP/FP累计、101点插值及类别均值。这仍是每次完整数据集AP，不是逐图AP均值，不复用总AP、不用加权近似。其它面积层/maxDets不影响主AP的all/100切片。
- 等价性为硬工程Gate：包含重复图、crowd、无GT图、同score、超过100检测的合成测试；真实8图A/B在固定重复序列`[0,1,1,2,4,4,4,7]`上，与**实际复制原始COCO GT/完整预测并重新evaluate+accumulate**得到的precision/recall/scores数组逐元素完全相等。无重复全量重算也须与标准全量AP一致。
- 正式Run后独立核对2000条记录及随机抽样哈希、分位数；预先固定第0/999/1999次用另一份向量化precision envelope实现复算完整数据集AP，误差≤1e-10 AP点。该核验不修改主评价器或门槛。

## 5. 损伤总体与唯一G3 Gate

按原生完整segm@.75匹配定义S，全部22957个原成功普通GT都评价。不抽样、不筛选面积、不只计算与bbox同时成功的GT。方法全部预测重新进行独立segm匹配，S中不再成功的数量为K；精确损伤=K/22957，有限总体单侧95%上界退化为同一精确比例。不把这一有限总体事实推广成新图片风险保证。另保存从原任务失败变为成功的GT，避免与同检测IoU达标混用。

三个数值条件及身份护栏必须同时通过：

1. 方法−基线Mask AP≥+0.3 AP点。
2. 2000次配对图像bootstrap双侧95% ΔAP区间下界严格>0。
3. 全S精确任务损伤≤1%。
4. Box指标/匹配和所有非Mask输出身份不变；配置和等价性核验通过。

数值失败即关闭本候选的S3实用性晋级，保留局部收益与全部阴性；不追加训练、不挑阈值或重新筛样本挽救。工程/身份/资源失败记blocked，不伪装为科学失败或通过。全部通过才建议另立S4独立确认计划；本次不执行S4或20k。
