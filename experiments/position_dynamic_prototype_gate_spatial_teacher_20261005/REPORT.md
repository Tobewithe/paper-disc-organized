# 空间 logit 教师监督：动态 prototype→coefficient 链路验证报告

## 结论

本轮检验一个具体假设：位置相关动态读出没有效果，是否因为位置分支只有最终 mask BCE 的间接监督，没有直接学习“应该怎样改变像素 logit”。

训练期加入固定的有限 oracle 像素目标：

\[
\Delta z_i^*=P_i(c_{\lambda,i}^*-c_{0,i}),\quad \lambda=0.003
\]

\[
L=L_{\mathrm{mask}}+
0.1\,\operatorname{Huber}_{\tau=1}
((z_i^{\mathrm{dynamic}}-z_i^{\mathrm{native}})-\Delta z_i^*)
\]

教师项只用于 1,024 张 fit 图，评价阶段不使用 GT 或 oracle。G-T、P-T 与上一轮同结构、同预算的 G、P 对照比较。

**结果：教师项确实进入了位置分支并使训练目标下降，但没有产生有实际意义的正常掩码收益。** 在 253 张有效 dev 图、1,816 个官方候选上，P-T 相对 P 的图片级 macro IoU 为 **+0.01297 个百分点**，95% CI **[+0.00513,+0.02101]**；主要失败组（BoxIoU≥0.75 且原 MaskIoU<0.75，353 个候选）为 **+0.01592 个百分点**，CI **[−0.01101,+0.04716]**，没有可靠的 Mask75 跨越。P-T 相对原模型 A 仍为 **−0.01685 个百分点**，CI 跨零，coverage、FPR 有代价。

预注册的继续条件（目标组至少 +0.5 pp、全体无明显负迁移、且 P-T 优于 P）未满足。本配置停止，不继续扫 beta、学习率、温度或训练轮数。

## 研究对象与对照

- **A**：原始 native coefficient 输出。
- **N**：上一轮 native-only 同预算微调。
- **G/P**：上一轮 position/prototype dynamic readout 的 BCE-only warm-start 控制。
- **G-T/P-T**：同一动态结构和训练预算，增加 spatial logit teacher。
- 原型、框、候选身份、冻结前级特征和正常原图解码保持固定。
- 动态残差为 \(\ z_{dynamic}-z_{native}\)，教师项不把 native 分支变化误计为位置教师作用。

smoke 核验通过：7172 个 fit 候选全部有唯一 oracle；初始 G/P 输出与 native 一致；教师目标有限；教师梯度非零；缓存和 prototype 未被修改。

## 对“监督是否不足”的判断

本轮不能说“监督完全没有作用”：

1. P-T 的 teacher Huber 从 0.847580 降到 0.831945；
2. P-T 相对 P 的全体 IoU 差值为正，且图片级 bootstrap 区间排除零；
3. P-T 相比 P 的 AUC 有极小正向变化。

但作用很小，且没有转化为目标失败组的稳定修复；P-T 仍低于 A，coverage 和 FPR 还出现代价。因此更准确的判断是：

- 监督信号能进入并改变动态分支；
- 当前 dynamic readout 的表达/训练路径没有把信号稳定转换为可泛化 mask；
- “只因为没有直接位置监督，所以加教师就能解决”被本轮否定。

这不排除更换动态结构、提高读取分辨率或改变训练目标可能有效，但这些都不是本轮测过的结论，也不允许把本轮阴性外推为 prototype→coefficient 链路不存在可改进空间。

## 结束决定

按协议停止本配置：

- 不扫 beta、Huber 阈值、学习率或训练轮数；
- 不增加 gate、反馈、跨实例交互或新的 loss 组合；
- 不把 P-T 的 +0.013 pp 写成有效方法收益；
- 保留该 Run 作为“空间 logit 教师对现有动态读出的判别性阴性结果”。

下一轮若继续，只能提出不同的机制问题，并先说明它与本轮的可区分性；当前证据不支持在同一结构上继续补丁式训练。
