# V29：正常对象代码是否提供原生模型缺少的空间知识

实际完成432张开发图、2863个GT、12899条原生输出的身份复核，以及其中2389条官方Box75同检测配对的固定模型检查，0优化更新。当前ROI对象代码能压缩可见内容，但在最需要修复的实例上几乎没有超过均值形状，按原冻结第三出口关闭其直接空间先验路线。该检查不生成新AP模型，V23仍是已验收首选；整个N+5目标未完成。

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | V28的GT辅助对象重建有信息，正常分割却低于原生2.768305点，且正确记忆比等幅错配低1.748166点。需判断是正常实例绑定显著不足，还是已有代码不足以给原生读出提供有用空间知识。 |
| **机制假说** | H_binding预测：保持同特征、同实际检测框和同编码—重建器，只将正常前景换为同框GT前景后，会出现足够大的整体重建改善。竞争解释H_use：代码虽能压缩内容，但当前表示/读出对原生失败缺少实用增量。预先冻结三种科学出口及信息不足出口，未见结果后换分组或门槛。 |
| **针对性方法** | 以官方bbox COCOeval@.75配对2389个输出/GT，固定output_detection_id、raw_id、annotation_id、正常框和V28固定8000步权重。比较正常前景代码、GT前景代码、训练均值和实际原生二值mask采样的16格IoU；同预测完整640 IoU定义成功/失败。GT条件只用于诊断，不进入正常推理。另保留whole/片段准入与旧可见率代理的语义限制。 |
| **整体结果** | 全2389例正常/GT辅助/均值/原生粗参照为.753704/.780805/.591714/.847203；307个原同预测Mask75失败对应.564704/.700807/.561220/.676458。正常较均值整体+.161991，但失败组较原生−.111755，未达+.03；GT辅助相对正常整体仅+.027100，未达+.10。两个训练准入均未过，分母充分，裁决为close_current_ROI_code_spatial_prior。全部2389条原生mask/身份精确，模型state不变。该粗重建分数不是AP，也没有新增相对V23的部署收益。 |
| **研究决策** | 停止当前ROI码作为直接分割空间先验的投入，保留V23。正向重点改为**由真实分割任务塑造对象表示，并利用当前图像的高分辨率证据进行条件掩码重建**。它针对“代码重建弱于已有读出”的实际缺口，比扩词表、继续跨对象平均形状或优先硬排他分群更有支持；唯一下一步是实现任务驱动的条件对象重建最小模型并冻结首轮有限训练合同。新架构仍待实现/训练，后续正常全量效用若不增益或损伤超限则关闭该配置，不以可视化像猪代替验收。 |

## 既有原生错误的后验描述性复核

另在本地复用原2389条配对及全部GT，不运行模型或优化，按[预写复核范围](NATIVE_ERROR_REVIEW_SCOPE.md)检查新方向是否有正面依据。307个失败实例共274824个错误像素：按该固定定义与邻居相关的14511个，占5.2801%；150534个（54.7747%）在GT四邻接4像素边界带，203650个（74.1020%）在8像素带。逐例邻居相关比例的平均为20.1754%，说明实例有异质性，不能说邻居从不重要。

这些是GT定位的描述性统计，边界带对小目标可能覆盖较大区域；没有证明RGB中可观察、没有排除标注边界误差，也不是放行训练的新Gate。整套GT前景交叠仅3371/11629917=.028986%，仍保留重叠标注，不擅自压成唯一标签。失败组原mask腐蚀4像素后的内部像素正确率为88.1371%，不支持盲目把内部标签平移到所有边界。上述结果降低“全局邻居排他是首要瓶颈”的优先级，支持先以高分辨率、图像条件的任务读出作为具体研究对象。
