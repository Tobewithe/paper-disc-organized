# V20 语义原型与密集任务训练：完整结案

2026-10-25。正式训练、完整推理、验收、独立复算、模型导出及本地回传均已完成。双卡实际完成10000次更新、160000次图像曝光，固定使用末EMA；**真实Box AP下降8.653点、Mask AP下降5.382点，未达到正收益或+5目标。** 规范对象能复现训练参考形状，但正常检索与真实前景调用均未达到要求。

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | 旧V17对象使用集中，V18/V19真实Mask AP分别退化9.646/2.705点；用户要求可命名、可解码的部位/整体/遮挡/边界词表，并在至少15头实际互遮的场景中直接预训练检测与实例分割能力。当前需要同时回答“存了什么、能否正确找到、是否帮助真实任务”。 |
| **机制假说** | 预冻结H：语义身份、规范解码与密集任务监督可使正常实例查询正确调用对象词条并支持可见归属。竞争解释是任务头/额外监督承担主要能力，词条本身未形成可靠对应，且资产与成像差异可能限制迁移。必要检索条件与真实效用分别判定，不以形状解码成功替代检索或AP。 |
| **针对性方法** | 冻结强原生YOLO视觉网络及128维投影，训练2264094个新参数：四类512×128词条、分型Top-2检索、部位—整体组合、规范解码与64查询检测/Mask头。1272真实train+1600合成train；672个密集几何族均有≥15头实际像素深度互遮连通群。2张A6000、有效batch16、AdamW 3e-4、10000步固定末EMA。正常前向不输入GT框、数量、部位、姿态或参考图。完整432真实dev/2863GT与320合成dev/5552GT，官方bbox/segm独立匹配；仅与同配置原生模型作效用参照。 |
| **整体结果** | 真实Box AP66.884503→58.231517，Mask AP57.343500→51.961884；原Box75成功损伤254/2389、Mask75损伤172/2126，均超1%。合成Mask AP43.420565→59.278028（+15.857点），密集Mask50召回84.735%通过。合成正常部位+姿态45.514%、整体姿态65.787%，未过80%；即使仅看成功Box50关联，仍只有50.430%/73.052%。训练参考部位形状IoU97.581%、整体98.086%，不能转写为未见对象识别率。真实正常预测整体/部位平均读入质量仅1.401%/0.128%，合成分别93.000%/30.369%。发现旧prone资产实为屈腿代理，未据此宣称真实腹卧能力。所有阴性与失败样例保留。 |
| **研究决策** | **停止扩大当前配置训练；保留规范形状词条、解码器与强原生模型，优先研究真实前景与规范词条的正向绑定。** 直接依据是“参考形状可复现、匹配仍不准、真实整体/部位检索多数被拒绝”，且真实前景缺少正向语义项，边界分支有真实监督而保持调用。该监督缺口是优先验证的解释，尚未由匹配消融证明全部退化的因果来源。**唯一下一步建议：先冻结一份真实前景兼容集合检索监督的v2合同，保留未知细标签、固定原生框/分数，并预登记同容量监督对照和等幅错词条干预；通过正常检索与真实效用要求后再讨论扩大。新训练尚未启动。** 若该监督仅提高调用而不提高正确对应/真实Mask，或等幅错词同样获益，则放弃其“语义对象帮助分割”解释。 |

AP单位为百分制点；差值为V20减原生。两者检测集合不同，不能把GT成功变化解释为同一预测的掩码修复。

|---|---:|---:|---:|
| 真实432图 Box AP | 66.884503 | 58.231517 | −8.652986 |
| 真实 Box AP75 | 76.357169 | 65.381744 | −10.975425 |
| 真实 Mask AP | 57.343500 | 51.961884 | −5.381616 |
| 真实 Mask AP75 | 69.009822 | 60.727823 | −8.281999 |
| 合成320图 Box AP | 51.000544 | 51.144871 | +0.144327 |
| 合成 Mask AP | 43.420565 | 59.278028 | +15.857463 |
| 真实≥15实例31图 Mask AP | 16.783189 | 11.424951 | −5.358237 |
| 合成实际互遮224图 Mask AP | 41.095488 | 57.830606 | +16.735118 |

真实原Box75成功GT2389个，损伤254、恢复2；原Mask75成功2126个，损伤172、恢复100。Mask损伤8.090%、Box损伤10.632%；+5及联合护栏均未通过。四个真实来源中一个48图来源Mask AP+7.921，其余三个为负；不以该子组替代完整结果。按4来源重采样的描述性Mask增量2.5/97.5分位为[−11.019,+6.046]，Box为[−11.015,−2.555]，不是独立确认区间。

固定score≥.25时，真实Box漏检522→576、误报356→692；Mask漏检572→654、误报406→770。计数MAE1.0093→1.0926。重叠未匹配误报与普通误报分别保留，定义见[报告合同](NORMAL_ERROR_REPORTING_V1.json)。AP使用完整score>.001预测，没有事后选阈值或中间权重。

## 原型到底学到什么

容量256/128/64/64，各128维。实际有训练支持的条目为238/128/63/64，共493；19条未启用，独立检查确认其词向量没有被更新。规范解码只读取词条及类型；以下是**固定训练参考内容的复现**，不代表未见对象能力：

| 类型 | 参考通道1 IoU | 参考通道2 IoU | 内容 |
|---|---:|---:|---|
| 部位 | 97.581% | 99.070% | 局部部位轮廓 / 同源完整身体 |
| 整体 | 98.086% | 98.239% | 同源完整身体 / 完整身体 |
| 遮挡 | 98.939% | 73.167% | 身体 / 指定遮挡区域 |
| 边界 | 100.000% | 100.000% | 局部前景 / 局部边界 |

在有合法标签的5418个合成GT、158个非空几何族上，正常查询按score≥.25、辅助Box50一对一关联，未关联的合法GT记错，然后按实例、几何族归约。部位身份55.552%、部位+姿态45.514%、精细部位词条40.956%；整体主姿态65.787%、精细整体词条31.159%。4794个关联成功实例中，部位+姿态仍仅50.430%、整体主姿态73.052%，因此不能把所有低分归咎于未检出。

遮挡/边界的19.596%/19.317%是**关联成功且存在正样本的条件准确率**，分母4310/4821实例、153/158族；不是把未关联GT计零的全GT准确率。原SUMMARY通用`reduction`文字在这两项过于宽泛，实际计算和该口径保留，见[口径说明](EVALUATION_SCOPE_NOTE.json)。真实图缺少部位/主姿态/完整遮挡真值，未伪造相应真实准确率。

## 关键发现：真实输入多数拒绝读取部位与整体词条

模型中两条Top-2权重之和满足

\[
m=\sum_{k\in\mathrm{Top2}}w_k=1-p(\mathrm{reject}).
\]

对正常score≥.25输出，实际读入如下。整体按查询归约，其他类型按查询16×16局部位置归约，包含ROI背景；数值不是识别置信度。

| 类型 | 真实平均读入质量 | 合成平均读入质量 |
|---|---:|---:|
| 部位 | 0.1280% | 30.3692% |
| 整体 | 1.4013% | 92.9997% |
| 遮挡 | 6.8490% | 27.2485% |
| 边界 | 48.7386% | 47.9691% |

真实2979条正常查询中有2287条官方Box50真阳性。由于读入质量非负，即使把全部整体读入质量都归给真阳性，其平均也至多1.8253%；这不是仅靠误报数量解释的现象。真实出现过显著读入的部位/整体条目分别62/16条，但“出现过”不能替代调用强度，参见[现有输出推导](DERIVED_READOUT_AUDIT.json)和[补图](figures/memory_read_mass_by_domain.png)。

代码层面的支持依据是：真实GT整体/部位细标签为未知而被忽略，未匹配查询及背景却有reject监督。因此存在“真实域拒绝对象词表、由图像与任务分支承担预测”的低语义损失路线。合成有正向细标签，边界也有真实Mask导出的监督，与两者较高调用一致。**这是有直接现象和目标函数支持的解释，不是已完成独立因果归因。** 额外容量、RGB细节和新检测头均为混杂；本轮不能把AP变化单独记作原型机制贡献。

## 数据与解释边界

800训练/160开发几何族各2种外观；672密集族均满足实际互遮连通群≥15，非单纯计数。独立射线每族512次，单族最大不一致1/512，低于冻结.005；相机最大误差.000199像素。训练侧真实外观统计、限幅高频细节、三种地面及设施、光照、单色近似与相机噪声已实际使用。单一源资产及4种体形仍不足以声明真实资产或母猪—仔猪尺度泛化。

旧`prone`源代码只有屈腿近蹲形态，不能解释为腹部接地的真实趴卧；[实际侧视图与复核](formal_preview/POSE_ASSET_REVIEW.json)保留。冻结后未偷偷换标签或数据，图中使用代理姿态说明，数字Gate不改。真实训练1272图，原Mask不修改；未知部位/姿态不伪造，重叠处的归属/边界歧义屏蔽。合成设施遮挡处的任务Mask监督标未知，物理可见GT独立保留。13/4来源视频组无交集，但真实dev多次用于研究，426张test未读。
