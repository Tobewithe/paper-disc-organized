# V4.1规模实验：固定检查点评价与交付合同

本合同仅把TASK_PROTOCOL_V3已经冻结的评价/干预具体落地，不改变训练、选优、432 real-dev、指标、+5pp目标或.1pp使用阈值。全部方法正式训练前冻结；没有额外训练步、网格、seed或测试集调参。

- 使用全量B*和continued/G/R/F四臂各自按既有合同选定的best.pt，重新运行同一FP32原生O2O解码和COCOeval，核对训练摘要选优AP。保存每个最终检测的RLE、分数、框和图像身份。
- 同一F检查点分别正常、额外基底归零、基底通道单侧循环错配、空间循环平移、固定随机字典；不重新训练、不同时置换系数。记录正常减干预的Mask AP差值。原型特异性须结合F−G和F−R，不单凭破坏后掉点认定。
- 主目标为F−continued的Mask mAP50–95至少5绝对百分点；另报告相对B*、G、R、Mask AP75、Box AP。开发集选优属于开发证据，不称独立test。四个文件名family仅作损伤描述，不冒称物理猪栏。
- 对每个family复用已有预测评分；不根据分组结果重选模型或样本。选图按score≥.25下GT最佳Mask IoU均值差，固定展示增益最高3例与损伤最大3例；这是解释用诊断，不替代官方AP。没有接触时明确使用可见边界crop。
- 技术图来自真实已训练中心、exemplar来源、域/层支持、PCA、检索相似度、额外基底、对应检测的原生/新增Mask logit、真实loss/AP曲线。不得把不存在的门控、alpha或注意力画成已实现机制。
- 计时使用前24个真实dev图，预热3次，CUDA同步，FP32同设备/输入；记录推理加原生Mask解码的中位数/P90，不混入磁盘读取和COCOeval。额外logit幅度仅描述有效输出贡献，不作效用指标。
- 在全部四臂成功且完成后，用一次有限单卡Slurm评价/制图作业；训练步数0。交付5个best.pt、独立memory.pt和投影状态、加载接口、技术图、结果、Run/协议/源码/产物SHA。大特征、缓存和渲染留服务器，按清单关联。

达到+5且实际原型使用和相应对照成立，才认定本目标实现。小幅收益、G/R相当、原型删除无影响、损伤、失败均保留并按V3取舍。代码/作业完成本身不等于科学目标完成。
