# V4.1任务监督原型与高分辨率Mask读出（V3，+5pp目标）

本V3在任何方法正式训练前取代V2草案；已完成cutout/排队synthetic数据工程仍按其V2冻结输入，不改数据结果。具体修订：原型query使用冻结P2细节与上采样P3语义拼接，512维、160×160网格；与原生Mask训练网格同分辨率。G/R获得相同输入与预训练信息，不把额外高分辨率特征本身归给原型中心。旧P3门控近零且AP75损伤，以及80×80 query到160×160 Mask的信息瓶颈，为此候选提供计算动机；其因果效用仍待控制实验。


2026-10-23用户明确要求“优化和完善原型生成、训练过程，让原型真正能帮助分割任务，设定为目标，至少正收益提升5个点”。目标解释为同432张真实开发图的Mask mAP50–95，相对同数据/同8000步预算continued至少+5绝对百分点；不是相对百分比或AP50。该目标是待达成目标，不是结果或保证。本版本取代尚未启动的旧P3门控规模化训练；数据渲染194/195仍按原PROTOCOL，基线198/199仍按BASELINE_PROTOCOL，不改它们的冻结输入。

## 具体失效、主张和竞争解释（M1/M2）

旧Run RUN_V4_SPM_2f2740fc801a：54图Mask AP50.9267、alpha−.0026001；关闭检索AP50.9272，错配/空间打乱改变<.002pp；对原B*仅+.2306pp且AP75下降1.1407pp。原型预训练仅有fg/contact二分类与增强对应/防塌缩，没有实例ID区分/实例掩码匹配监督，冻结P3门控最终近零。**已有实测否定“旧部署门控已带来可用增量”**，不将它原样扩大后宣称解决问题。

H：同类猪之间的实例归属信息未被原型目标充分学习，且间接P3零alpha通路容易被原生head绕开；实例级跨外观原型匹配监督，加上直接受原生Mask误差训练的额外Mask基底，可能把这些信息变成有效输出。H_alt1：原型只是原生特征的冗余，充分训练后仍被忽略；H_alt2：任何额外基底/参数/辅助预训练都同样有效。支持此候选的是上述真实失效与监督—任务的不匹配，另有实例判别嵌入和原型匹配分割的研究依据；尚不是本数据上的机制阳性。

主预测F−continued≥5pp；检查F是否高于共享预训练信息的G/随机库R。若原型被实际使用，同F checkpoint关闭额外记忆贡献、错配原型基底—系数对应或打乱空间应有超过.1pp的定向损伤。若F虽然涨点却与G/R同效、关闭无损，不称原型特异性贡献。

## 原型生成与监督

在同一个全量B*冻结Backbone/Neck及BN的P2+P3坐标内，采用512→256→128共享投影，输出单位嵌入。归一化mean/std仅由real-train reservoir确定；不使用dev/test特征学习坐标。背景和每实例在160×160网格按原始可见ID标注，低纯度、重叠/不可靠边界ignore；最多8实例/图，每实例最多12 token，背景最多32，最多128 token/图，接触/边界优先而非只取大内部区域。

同图两种外观/光度视图共享实例ID。以B视图每实例masked-pooling嵌入作为临时训练原型，A视图像素通过余弦/温度.1匹配所属实例，A/B双向交叉熵；不同图的实例编号不要求互异，也不输入推理。补充fg/contact BCE、对应一致性、实例内pull、接触邻实例push及方差/协方差。权重在TASK_CONFIG_V3中冻结；De Brabandere式实例判别与PANet式原型对齐仅作方法依据，不把语义few-shot结果移植为本研究证据。

训练总20000步、最多2048 token/步（16 source episodes）。先5000步real+cutout、随后10000 mixed、最后5000 real adaptation；分两次有限作业，携带同一投影/辅助头/优化器状态，第二段新增15000真实更新，不重复记warmup。real/cutout特征可在合成渲染期间缓存，最终训练与构库只使用完整合法train来源。

最终从train-only嵌入中按域和C/B/I平衡reservoir，球面K-means fg16/bg16，共32；每中心保存exemplar、来源、实例/接触支持、用率、单位范数、坐标与B*SHA。中心不预命名为头/腿/背，不强迫每头猪使用专属库槽。query投影/归一化/中心构库后冻结。

## 直接Mask任务链路

保留32个原生Proto26基底，新增32个由冻结原型响应产生的空间基底：高分辨率query与fg/bg key比较，形成前景—背景对比相似度图，tanh温度缩放，双线性上采样到原Mask基底分辨率。32→32可训练混合器初始单位映射。原生O2M/O2O mask coefficient输出各新增32维，**新增系数层从0初始化**，原始32维和原生Box/Class/score路径原样继承。初始可见mask/box/score应复现B*；新增系数从真实实例Mask loss收到直接梯度，不引入强制正alpha或伪造贡献。

此为明确的V4.1方法变更：Mask基底/系数由32扩为64；原生process_mask/COCOeval算法不改，不把其结构变化冒充原V4 P3门控。原生O2O detach保留，新增O2O系数仍接受原生实例损失梯度。GT只参与训练目标/评价，部署query与系数均只来自RGB。

## 公平训练与定向干预（M3/M4）

四臂各8000步，batch12=8real+4synthetic/cutout，同一B*、同抽样/增强/优化器/选优。上游与所有原型坐标冻结。前1000步所有臂只训练Mask路径（原生proto/cv4及新增Mask路径），后7000步开放完整原生最终head；不解冻Neck。

- B continued：原生32基底，无记忆。
- G普通Adapter：同预训练投影/辅助信息，128→64→32普通可训练Mask基底，与F相同新增32系数及训练规则；实际额外参数差如实披露，不能仅凭F−G作严格归因。
- R随机字典：同F计算与完全相同可训练参数，将训练得到的32中心替换成固定单位随机方向，区分学习记忆和额外基底。
- F任务原型：学习得到的冻结32中心+额外基底。

同F checkpoint保存正常、额外记忆贡献归零、基底—系数通道错配、空间打乱；R/G训练控制共同解释，破坏测试不能单独证明机制。记录额外mask logit幅度、系数梯度、原型/坐标SHA不变、参数和延时。

## 冻结评价与取舍

同432 real-dev、640画布、FP32评价、原生O2O/conf.001/maxdet300/原生mask解码/COCOmaxDets1,10,100；每1000步及最后评价，最大dev Mask AP选优、平分取早，保留last与阴性。主目标F−同预算B≥5pp；额外报告F−G/R、相对原B*、AP75/Box AP/分组损伤、部署开销。不能弱化baseline、换验证集/指标、反复选样本来追5点。

若达到+5且原型使用证据符合预测，交付并推荐该方向；若仅有小幅正收益，明确未达目标，依据三控制和损伤决定是否有支持继续；若F≤G/R或删除仍无影响，停止扩大该原型机制，保留实际最佳原生/Adapter权重，下一方向必须有新实测支持而非换loss碰运气。工程不足只修工程。未达到5点不标记goal完成。首轮仅seed0，不自动追加种子/网格；后续改变需新版本合同。

方法依据：[实例判别损失原论文](https://arxiv.org/abs/1708.02551)、[PANet原型对齐原论文](https://arxiv.org/abs/1908.06391)。本方法及+5目标的成立均待本Study实际训练/评价。
