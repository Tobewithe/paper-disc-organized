# V21：ARAP改善局部畸变，实际形状审核仍拒绝

实际完成固定体型制作、15格姿态核验和9张固定多视角原图审核。**13格几何通过、全部9图像素标签通过，但两种新体型的完整轮廓不自然，新增资产准入0、训练批准图0。** 这次结果说明最终RGB审核会拦住只在数学护栏上合格的形状。

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | V19单体型重复；V20固定围度场产生局部边/面过度压缩拉伸。需要验证保细节的约束网格编辑能否在同控制目标下改善局部表面，进而得到可用体型。 |
| **机制假说** | 工程资产资格，不是论文新机制归因。ARAP局部旋转/全局位置求解应比直接指定全部点位移更好分配局部变形；竞争解释是几何护栏通过仍会因控制目标缺少完整身体轮廓约束而出现不自然凹凸。实际多视角是必要独立出口。 |
| **针对性方法** | 原型和同±18%有限控制目标，158个中心带控制点、1467自由点、9614源锚，固定40次。V1源edge镜像前提不成立时中止保留；A1按原能量与镜像能量平均，新增184条仅算子虚边，不改变源三角面或碰撞/标签身份。先过零/刚体/错误控制夹具，核全部15格及原V20表面/rig/支撑门槛；过的非零stand再独立三角核验，随后原型/两新站姿各3固定视角。Agent查看全部9原PNG，独立复算源数组及像素射线。 |

| **研究决策** | 保留ARAP工具/身份/rig/像素正面事实，关闭当前固定中段控制构造，不扫控制点/权重/迭代；不把数学通过升级成形状或数据集合格。正向重点选择保留完整纵向轮廓、让身体部位协调变化的源形状制作，依据是实际凹凸集中在控制带，而原型轮廓与拓扑可核。唯一下一步冻结原型及全身一致Y比例有限对照、对应rest关节/各部位/姿态与RGB护栏后执行；与旧非body固定假设明确分开，不静默覆盖。新协议尚未启动，若完整比例仍不自然则停止该代理并优先完整有来源形状参考。完整合格数据目标未完成。 |

对比边界：相对原型，本次新增体型有可观察变化，但未通过外观，不能称最终收益。相对V20，同源面和控制点目标保持，但自由点求法与有效全躯干改变幅度不同，只报告工程能力差异，不作独立因果机制或真实泛化/AP结论；两者均无可准入新体型。当前标注仍仅9源父级，候选组不是精确器官叶GT，新shape不能继承旧contact资格。
