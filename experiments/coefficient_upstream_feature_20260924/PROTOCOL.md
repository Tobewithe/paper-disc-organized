# 系数头信息瓶颈探针

固定官方COCO预训练YOLO26m-seg、Ultralytics 8.4.100，使用`coefficient_predictability_20260924`官方one2one正样本缓存中的同一800fit/200dev/200val图像、预测位置、原系数、原型、GT标签及640分辨率分割损失。重新前向同一图像，仅用hook读取系数分支输入特征`z_in`（P3/4/5分别256/512/512维）在这些位置的向量，逐位置比对原系数输出，确保缓存对齐。

在fit正样本上**逐尺度**学习PCA投影到64维，固定后用于dev/val；对照使用原系数头末层64维特征h。两者分别训练相同的P3/P4/P5分立大MLP系数残差头、相同参数量、同一优化器/图序/预算、仅官方掩码损失。开发集选择包含原系数第0轮；验证结果还看原预测框解码后的掩码IoU/Mask75。

PCA是训练图像上的无监督投影，不读取GT作为特征。若上游PCA64在未见图像稳定胜过h64与原系数，可支持末层特征压缩/变换丢失可用信息；若同样失败，则不能声称系数分支的信息瓶颈。PCA选择本身可能影响结论，出现优势后需做随机投影和更大样本复核。仅此探针不重训主网络，也不是COCO AP。
