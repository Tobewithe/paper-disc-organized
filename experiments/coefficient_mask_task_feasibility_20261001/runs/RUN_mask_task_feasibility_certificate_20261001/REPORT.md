# 固定原型下掩码任务可行性对照（官方原始 COCO GT）

## 结论

在固定官方 one-to-one TAL 候选、原始 h/P/c0、预测框和正常解码下，E1 质量安全内集的共享仿射读出得到条件数值超预算证书。P3 的 15,119 条确定性初始锁定约束子集已经给出保守下界 **72.042775450**，全局固定预算为 **45.673507054**，裕量 **26.369268396**。由于活动约束子集是完整约束集的子集，这个下界同样适用于完整 E1 任务；因此无需继续求 P4/P5。

这回答的是：在本轮声明的质量包络、0.10 logit margin 和 4 倍参考位移预算下，固定特征上的同尺度共享仿射映射不能同时把全部官方 fit 候选送入该内集。它不等于所有 Mask75 解都不可达，也不等于无限制移动时不可行，更不能单独说明某个网络模块是唯一根因。

## 固定对象与数据

- fit：796 张图、6,058 个官方 one-to-one TAL 候选；P3/P4/P5=2,000/2,298/1,760。
- 质量门槛：原始 COCO `instances_train2017.json` 掩码，Mask IoU 阈值 0.75，容差 0.01。
- 分组：R/S/F_other=885/3,637/1,536；数值未决候选 0。
- 参考位移均值 `v_ref=11.418376763`，预算 `4*v_ref=45.673507054`。

## 证书核对

- 证书行数：15119；所有对偶权重非负且有限。
- P3 设计矩阵 65×65 最小特征值：0.00911360909；使用 FP64 直接线性求解。
- 逐行重算对偶值：72.042776450；保守数值余量：1e-06。
- 原始活动集 QP 因内存/时间退出的日志保留在历史 Run；本结论只使用本文件记录的独立对偶证书，不把 QP 超时当成证据。

## 范围限制

这是 `QUALITY_SAFE_INNER_SET` 的固定 fit 可行性判断，不是 COCO AP、部署收益或新图泛化实验。E0 因为嵌套于 E1，不能在同一预算内恢复 E1 的超预算结论。dev/val 原图回放未执行，因为 E1 已由保守下界判定超预算。

完整复核见 `DUAL_CERT_VERIFICATION.json`、`SHARED_PRIMAL_DUAL.json`、`ACTIVE_CONSTRAINTS.npz`、`REFERENCE_SUMMARY.json`、`INDEPENDENT_SUMMARY.json`。
