# 固定原型下的任务可行域与共享读出：受控研究协议

版本：design-v1，2026-10-01  
性质：拟执行设计；尚未运行本协议对应的 YOLO/COCO 计算。  
本文件同时区分：历史证据、针对模型的数学推导、建议的执行默认值。默认值是本轮设计选择，不是官方规范或已证明的最优参数。

## 0. 本轮只回答一个问题

**固定原型、官方候选、原始特征和解码后，是否存在一套共享仿射系数读出，能够进入“已经保证掩码质量的系数区域”，而不必复制逐实例 oracle 的系数或精确 logit？如果不能在预定有限移动预算内做到，究竟有哪些任务约束共同要求过大的输出移动？**

这是大命题 A 中“损失目标差距是否对应任务可达差距”的连接环节，不是整个大命题 A 已经解决，也不是新的部署方法已成立。

单一流程：

已有 c0、c*、h、P、框与正常解码
→ 构造参考掩码与质量保证包络
→ 独立可行性 / 共享可行性及距离界限
→ 只对已定位的约束群做稳健性和最小特征干预
→ 结案，给出允许和不允许的解释。

不再做 raw5000、7N 近邻、普通 Huber 教师、VarPro、边界头、gate 或新增网络。允许离线求解临时系数与共享仿射参数，作为 GT 辅助可行性见证；这在数学上仍是标签条件拟合，不能称“完全没有拟合”。不覆盖原权重，不将见证参数直接发布为部署模型。

## 2. 冻结对象与权限

### 2.1 固定

- 原始 COCO 预训练 YOLO26m-seg，实际 Ultralytics 8.4.100。
- one-to-one 分支；官方原权重 TAL 分配，固定 raw 身份。
- 原输入几何、原型、特征、框、分数、标签、解码与原始系数锚点。
- 原始模型 SHA256 参照已有报告：`16b636f04e8fb6a325b3370f22dc5e5535ff473e384f4d041fd28d788f6ee9f5`；执行仍需核对实际文件。
- fit 为主要可行性总体；不把 dev/val 也混入一个“训练集共享头”。

完整键：split/image_id/annotation_id/branch/raw_id/pyramid_level/target_gt_idx/input_geometry_hash。

### 2.2 允许

读取缓存；必要时用原始冻结模型补提原型或特征；构造约束；求解小型或按尺度共享 QP/SOCP；重放临时系数；生成界限与诊断图；修改本次离线分析代码。

### 2.3 禁止

梯度训练新网络；修改候选、框、分数或标签；重求旧 BCE oracle；调整旧证书；重跑全 raw；根据结果更换质量门槛；只保留有利候选；自动追加神经模块或完整 AP。

## 3. 三种数学对象必须分开

1. 旧目标最优点：c*，来自官方参考 BCE 加位移正则。
2. 同参考二值模式的区域：K_exact，通常包含许多不同系数。
3. 保证原图质量的保守区域：K_safe，它是“所有能达标系数”的一个内子集。

不能因为 K_safe 不可行，就宣布所有 IoU 达标系数都不可行；也不能因为 K_exact 与 oracle 点很接近，就认为必须逐维蒸馏 c*。

本轮的主问题是 K_safe 中的共享可行性与有限移动成本。精确复制参考模式只作一个更严格的对照。

## 4. 建立可核验的线性解码接口

在第一次二值化之前，定义每个像素的实数 logit：

`z_iu = a_iu^T c_i`。

`a_iu` 包含固定原型插值；预测框外的固定零区域不作为可学习自由像素。第一次二值化遵循本地冻结实现（原路径为严格 `>0`）。随后用已经冻结的确定性映射 D_i，把二值画布还原为原图二值掩码。

### 4.1 不混同两类精度

- 线性约束与证书：记录在 FP64 中构建的确定矩阵及误差模型。
- 实际掩码有效性：最终系数必须在原生 FP32 正常解码路径重新检查。

有限精度下 `interpolate(P c)` 和 `interpolate(P) c` 不必逐位一样。对 c0、c*、固定随机向量和最终见证比较中间 logit 和二值输出。数学证书只约束声明的线性模型，不能借此省略实际原图复核。

如果参考系数的数学符号与原生参考二值位在少量像素不一致，标记为数值模糊像素，强制纳入后述自由集合 U，不通过重新给 oracle 求解或改变阈值解决。若这些自由像素已使质量下界不足，该实例标记 `NUMERIC_UNRESOLVED`，不静默删除，不给出覆盖全 6058 候选的结论。

无论线性求解多成功，原生解码未达到质量要求的临时解都不能标记为有效任务见证。

### 4.2 D_i 的单调性

质量包络只在以下条件通过后使用：固定裁剪、非负权重插值/缩放、固定逐像素单调阈值。需要列出实际顺序、阈值和 align_corners 等参数。不得把二值 `process_mask` 输出当连续 logit。

若实际 D_i 包含非单调形态学或实例依赖后处理，本协议的包络证明不自动适用。停止包络阶段，而不是擅自替换解码。等效正系数插值可稀疏组合，不改变实际顺序。

## 5. 参考策略：只要求已经证实的修复，不强迫所有实例模仿 oracle

以同一正常解码取得：

- `Q0_i = IoU(M(c0_i), Y_i)`；
- `Q*_i = IoU(M(c*_i), Y_i)`。

主修复组：

`R = {i: Q0_i < 0.75 and Q*_i >= 0.75}`。

原成功组：`S = {i: Q0_i >= 0.75}`；其他失败组：`F_other`。

参考系数：

- i 属于 R：`c_ref_i = c*_i`；
- 其余：`c_ref_i = c0_i`。

这样只试图救回已有 oracle 确认可以跨 Mask75 的对象；没有要求已经成功的实例继续追 oracle，也不删除不可恢复对象。

固定质量容差 `epsilon_Q = 0.01`（IoU 数值，即 1 个百分点），定义：

- R：`q_i = max(0.75, Q*_i - 0.01)`；
- S：`q_i = max(0.75, Q0_i - 0.01)`；
- F_other：`q_i = max(0, Q0_i - 0.01)`。

这不是 COCO AP 目标，也不是“零损伤”承诺。它允许最多指定幅度的单候选 IoU 损失，但原成功组不能跨到 Mask75 以下。报告全体、R、S、F_other 的实际数量。若 R 为空，本轮没有适合的主修复对象，停止任务而不调阈值挑样。

这是一项新的 GT 辅助目标政策，不得与旧 6058 候选平均 BCE 证书混称同一优化目标。

## 6. 核心技巧：构造有原图 IoU 保证的自由像素包络

### 6.1 为什么需要它

强制逐像素复制 oracle 过强；直接把原图 IoU 约束当成凸条件也不正确。本协议采用一个可验证的充分条件，在不牺牲质量保证的前提下，释放一部分像素选择自由。

### 6.2 构造与证明

在第一次二值化画布中，以参考位图 b_ref 为中心，选择自由像素集合 U。其余位置保持参考的 0/1。

- b_minus：U 内全部填 0，其他保持参考。
- b_plus：U 内全部填 1，其他保持参考。
- M_minus = D_i(b_minus)，M_plus = D_i(b_plus)。

任何满足锁定像素的画布 b 都满足 b_minus <= b <= b_plus。由 D_i 单调，得到：

`M_minus subseteq D_i(b) subseteq M_plus`。

因此：

`IoU(D_i(b), Y_i) >= |M_minus ∩ Y_i| / (|Y_i| + |M_plus \ Y_i|)`。

记右侧为 `Q_lower(U)`。只接收 `Q_lower(U) >= q_i` 的 U。这个结论不需要在 U 中枚举全部 2^|U| 种填充。

它是新设计的保守质量保证，不是既有报告已经验证的公式应用。合成测试先核验全部完成情况，再应用真实解码。

### 6.3 U 的选法固定，不能事后挑更容易成功的

先纳入全部数值模糊像素，再按参考点到像素判别超平面的距离：

`d_iu = |a_iu^T c_ref_i| / ||a_iu||_2`

从小到大排序，稳定相同值以像素 ID 排序。响应恒为零的像素按实际固定规则处理，不能用任意 epsilon 造出活跃约束。

用单调前缀及二分搜索选择最大的前缀 U，使 `Q_lower(U) >= q_i`。这是对这一个固定排序的最大前缀，不是宣称求出了全局最大自由像素集合。

保留两套嵌套配置：

- E0：只释放不可避免的数值模糊位；无模糊时即精确参考模式。
- E1：再按上述前缀释放像素，同时保证 q_i。**E1是主配置**。

不用 16×16 ROI 替代原图质量，也不永久抽样像素。各候选保存 U、锁定位、上下包络和 q_i。

## 7. 把锁定像素变成凸约束

对每个锁定位，令 `t_iu = +1/-1` 表示参考前景/背景，定义：

`m_iu = kappa * |z_ref_iu|`, 主配置 `kappa=0.10`。

约束：

`t_iu a_iu^T c_i >= m_iu`。

参考 c_ref 必须满足。参考负位恰好为零时 m=0，使用非正背景规则；正位必须有严格正的实际符号余量。零行不提供正半径，不参与除法。

这是保留参考符号及一部分 logit margin 的区域。它避免用 c=0 伪装成任意正前景，也控制正比例缩放导致的集合距离退化。

重要限制：kappa固定了一个额外margin要求。不可行结论只针对声明的margin与质量包络。主配置不得在看到结果后改为零margin以获得“成功”。不把它称为所有同质量mask的精确全集。

同一框和 P 下，允许区域内所有满足条件的系数；不要求它们接近某个唯一 oracle 点。

## 8. 同一接口下比较独立与共享，不用神经网络试错

### 8.1 独立控制

每个候选独立解：

`min 0.5 ||delta_i||²  subject to c0_i + delta_i ∈ K_i`。

c_ref-c0 是已知可行见证，因此独立问题被返回不可行时优先检查接口。未改变参考的候选若 delta=0 已可行，则最优值就是0，无需调用求解器。

仅对需要改变的候选求解，复用约束生成及全像素验证。得到“达到指定任务条件的最近系数”，不称为全体 IoU 达标系数中的全局最近点。

### 8.2 共享控制

使用证书的固定设计矩阵 `X_l = [standardized h, 1]`，

`delta_i = x_i^T A_l`。

这是同尺度共享仿射增量，不允许每个实例单独学一个头，也不能把同一原型图片内多个实例的系数强制相同。

求解：

`v_shared = min_A (1/(2N)) sum_i ||x_i^T A_l||²`

`s.t. c0_i + x_i^T A_l ∈ K_i, for all official fit candidates`。

所有6058个对象均保留，参考非修复组不被删除。E0、E1采用同一目标和同一移动预算。可按三尺度分块求解，最终目标按全局 N 聚合；不能将三个局部平均简单等权相加。

临时 A 只是 fit 的 GT 条件可行性见证。保存副本，不覆盖原权重，不宣称泛化或AP。

### 8.3 预先固定有限移动预算

`v_ref = (1/(2N)) sum_i ||c_ref_i-c0_i||²`。

主预算：`B = 4 * v_ref`，等价于共享输出增量的RMS不超过参考增量RMS的2倍。参考独立解本身位于预算内。

2倍是本轮建议的有限移动约束，不是官方常数。它必须在求解前冻结。不得看到结果后不断扩大B；记录不受B限制的已有可行见证成本也允许，但必须称“预算外”。

研究问题因此被精确定义为：这些保证质量的区域，是否能由原生共享映射在这一有限移动预算内同时进入？

## 9. 求解的真正技巧：原始见证与对偶下界同时推进

### 9.1 约束生成

起始每候选最多8个确定性锁定位（正/负各至多4；按归一化margin最小及像素ID选取）。已验证无约束的候选无需加入。

每轮：

1. 求解当前活动约束的QP；
2. 用完整原型和全部锁定像素检查得到的临时系数；
3. 每候选最多加入8个最严重的新违反约束，不重复加入同一键；
4. 如果全量满足并且原生解码也达到所有q_i，得到任务可行见证；
5. 同时保存当前活动问题的对偶下界，它也是完整问题的下界。

不能以随机抽样不再违反为全量通过；不能用正负像素均值代替逐像素约束。

### 9.2 目标上下界

将共享参数向量化为 theta，目标写为：

`0.5 theta^T H theta`。

当前固定X每尺度满列秩时，H为正定；其块为 `(X_l^T X_l/N) ⊗ I32`，实际Kronecker顺序按向量化约定核验。

活动不等式记为 `G theta >= b`。任意 `y >= 0` 给出对偶下界：

`L(y) = b^T y - 0.5 (G^T y)^T H^{-1}(G^T y)`。

活动约束是全问题的子集，所以该下界也下界完整问题的最小移动成本。无需等所有像素都加入，也无需仅凭求解器“infeasible”状态作结论。

若解 Hv=q 得到近似v，r=q-Hv，并有经过核验的 `mu_H <= lambda_min(H)`，则：

`q^T H^{-1}q <= 2q^T v - v^T H v + ||r||²/mu_H`。

将右侧代入负的二次项并扣除计算误差余量，得到保守 L。不能反转上下界方向。对偶负分量若裁成0，必须基于裁后y重新计算整个界限。

全量验证通过的见证给出上界U。因而：

- `U <= B`：在预算内构造成功；
- `L > B`：在声明的质量包络、margin及有限移动预算下，已证明不能实现；
- `L <= B < U`或没有完整U：仍未知。

若各尺度均有界，可相加；缺少尺度的安全下界只能用0或已验证值，不抄旧结果。

这比强行给无界参数的近似Farkas向量作严格证书更安全：`G^T y`“很小”本身不足以证明无界参数系统不可行。

### 9.3 无预算的不可行性

可选记录求解器给出的对偶射线，但只有精确/有验证误差模型的Farkas证书才可使用“线性约束本身不可行”。不能从L>B推出无论移动多远都不可行。

主问题只需要预算内判断，不要求每个QP求到机器极限。时间到达即用已成立的U/L结案。

## 10. 从数值结论走向机制：只分析证据已经指向的实例

不得再次做全库近邻或泛泛的梯度负余弦统计。

### 10.1 如果共享见证在预算内存在

记录其对所有组的正常原图质量，报告：原系数—oracle点—独立最近区域解—共享任务见证。

允许的判断：旧BCE最优差距不必转化为这套任务门槛的不可达；共享映射在此fit集上能完成指定修复。不是新图泛化。

作为本协议的固定末尾检查，可以把这一套已冻结共享参数只应用到原dev/val，无重新求解、无阈值选择。记录任务效用，标为既有图片上的迁移检查，不是新盲测或完整AP。若预算不足就明确没有进行，不拿fit替代。

### 10.2 如果对偶下界超过预算

从正对偶权重的约束中，按预定顺序进行最多50次删除检查，保持全体X、N、目标H和预算B不变，寻找仍使 L>B 的更小证据集合。

称为“预算冲突证据集”，不称全局最小冲突集。对偶权重受约束行缩放影响，不能直接按权重大小给模块作因果排名。

将证据映射回图像、实例、像素、前/背景与框内位置。重点检查是否同一尺度的实例提出不兼容需求，而不是只展示最极端的特征余弦。

证据集来自优化选择，只供机制案例，不用于估计全COCO发生率。

### 10.3 最小特征干预：仅对最多24个机制案例

样本固定为证据集中的前12个唯一候选（按稳定hash取），再从其余候选中按层级/基线状态匹配12个对照。若证据不足，保留实际数量。不因效果不好换案例。

固定原末层W，解：

`min 0.5 ||diag(1/s_h) delta_h||²`

`s.t. c0 + W delta_h ∈ K_i`。

s_h来自原fit特征尺度，固定不重新估计。保持同一任务可行域，不强迫等于delta_c*。

检查三条输入干预：

1. 最小有效delta_h；
2. 相同上述特征范数的随机方向，固定20次；
3. 相同范数、落在W零空间的方向。

记录每种变化的实际系数/像素效应和原图IoU，不把“特征距离大”直接解释成有用。W满行秩时无界delta_h一般可实现任意delta_c，因此存在delta_h本身不是新发现；有意义的是所需幅度、稳定性与对照。

本步骤只证明人工干预的功能充分性，不证明可由图像预测、特征仍在数据流形上、或能泛化。不得由此自动增加对比损失。

### 10.4 稳健中心：复用同一K，不再抽一批新任务

对上述最多24个案例，在固定半径 `R_i = 2 max(||c_ref-c0||, 0.05*median_fit ||c0||)` 内，解最大安全球SOCP：

`maximize rho >= 0`

`t_u a_u^T c_bar >= m_u + rho ||a_u|| for locked u`

`||c_bar-c0|| + rho <= R_i`。

它认证的是K_safe内的安全球；由于K_safe保证q_i，该球在理想固定解码模型下也保证该任务质量。

若oracle点安全半径小、区域内存在更稳中心，说明oracle点不是唯一合适教师。若该内子集没有大球，不能推出所有达标mask区域都很窄。

## 12. 数值验收与资源预算

### 12.1 新增检查限定在必要部分

已有身份、原图解码、P/h重放能按hash复用就不重做全量网络前向。新检查包括：

- 几个合成问题的已知解、同点不同解集、仿射可分/不可分、包络穷举、对偶界。
- a_iu^T c与实际预阈值logit路径的误差；
- 参考c_ref在其自身K中的可行性；
- E0嵌套E1，E1的原图质量下界不低于q_i；
- 独立预算见证存在；
- 每个共享见证在全量锁定像素与原生解码上检查；
- 求解器模型中没有额外非负权重约束、额外weight decay或错误的局部平均。

建议FP64缩放行残差检查为 `1e-8*(1+|b|+|Gtheta|)`；这不是正位可容忍翻到负位的许可，正位仍需严格正且原生解码满足质量。对偶界使用保守误差预算，默认宣称“条件数值界”而非无条件形式证明。
