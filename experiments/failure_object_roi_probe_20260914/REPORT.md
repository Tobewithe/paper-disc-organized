# 失败对象局部重推理诊断

对六类失败/成功对象各抽取 48 例，比较 640 全图、1280 全图以及两种带上下文的 GT 区域重推理。只有“无最终槽位”对象出现稳定正效应：1280 全图的 Mask IoU 平均增加 0.1721（95% bootstrap CI 0.0736--0.2637），恢复 7/48 个 Mask75；四倍上下文 ROI 增加 0.1024（0.0282--0.1818），恢复 8/48。其他失败类没有稳定改善，成功对照在 1280 下平均下降 0.0548。

这排除了“所有失败都可用局部重推理修复”的路线。由于当前预测顺序无法与历史 `prediction_slot` 精确对齐，本实验按当前同类最佳框候选配对，不能解释为历史固定槽位的逐例重放。
