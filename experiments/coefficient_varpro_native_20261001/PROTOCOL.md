# 变量投影式原生系数表示训练

## Goal

验证“让原生系数分支的表示针对最佳共享末层学习”是否比普通联合微调更能降低官方 TAL 同域目标，并在冻结后的新图像掩码评价中兑现。

## 固定对象

- YOLO26m-seg、Ultralytics 8.4.100、COCO 官方 one-to-one TAL 候选；
- 官方缓存中的候选身份、prototype、GT 支持、原始系数锚点 `c0` 和参考损失；
- backbone、neck、prototype、框分支、分类分支和推理解码保持原生定义；
- `lambda_eval=0.003`，评价目标为候选平均的参考 mask BCE 加系数输出位移正则。

## 比较组

1. `C+readout`: 固定 Phase I C 组原生系数分支特征，只重新求每尺度共享 64→32 末层；
2. `joint`: 从同一 C 起点、相同训练预算联合更新系数分支与末层，训练后再用相同精度适配末层；
3. `varpro`: 内层跨全部官方 fit 候选求共享末层，外层只更新产生特征的原生系数卷积，循环 warm-start；每轮记录内层目标和驻点误差。

内层只在训练期使用 GT；最终冻结后的前向不包含内层求解、不使用 GT，也不增加推理分支。

## 预注册判断

- 先完成 `C+readout`，不把旧固定表示证书套到新表示；
- 只有 VarPro 在同等读出适配后优于 joint，且在未参与新增训练和方案选择的图像上改善原图 Mask IoU/Mask75，才继续完整输出验证；
- fit 目标下降而新图不改善，记为泛化失败；不把它写成方法成功；
- 任何结果都不把上一轮 Huber 教师方案改写为通过。

## 运行与记录

运行在 28358lan 笔记本 GPU；本地只保存协议、代码快照和结果。每个 Run 独立记录实际 GPU 时间、内层求解次数、目标轨迹、参数哈希、输入清单和转移校验。缓存传输完成后先核对文件数与关键文件，再做单图 GPU smoke test，之后才进入正式训练。
