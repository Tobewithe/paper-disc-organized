# 身体部位优先规格：实例—部位—属性—证据

2026-10-28，用户进一步强调“猪的各个身体部位要特别关注”。本补充把**身体部位设为主要输出**：先建立部位的可见证据和实例归属，再由它们解释姿态、遮挡及合成资产需求。全程只读RGB，不恢复任何已有标注。

## 1. 不能只列“头/身体/腿/尾巴”四个标签

| 身体组 | 需要区分的可见部位与锚点 | 优先记录的部位属性 | 特别容易错的地方 |
|---|---|---|---|
| 头面部 | 头部范围、吻鼻/鼻端、口部/下颌；可分辨时记录眼与鼻孔 | 形状/朝向、开闭候选、局部色斑/污渍、遮挡、实际像素支持 | 把鼻端当整头中心；把鼻孔/眼的暗点与污渍混淆；小目标强行补五官 |
| 耳部 | 每只可见耳的耳根/耳廓/耳尖、可见耳标 | 竖/垂/折叠候选、可见轮廓、侧别依据、附着于哪个头 | 图像左耳不等于解剖左耳；借邻猪耳朵凑成双耳；耳标读不清仍编号码 |
| 颈与前躯连接 | 头—颈—前躯的可见连接区域、肩背表面锚点 | 连接连续性、头身相对方向、颈部弯曲候选 | 连接处被遮时，不能按最近头与最近躯干自动拼接 |
| 躯干 | 胸侧、腹侧、背部/腰背、身体侧面 | 表面可见区域、弯曲、图像长宽、胸腹/侧面支撑候选、色斑与遮挡边界 | 只凭一个大框推完整身体；把栏杆/阴影像素当皮肤；背侧与腹侧混淆 |
| 臀与尾部 | 臀/后躯、后臀背线表面锚点、真实尾根、尾段、尾尖 | 尾部弯曲/卷曲、方向、附着、可见长度、截断 | 有论文的“tail”点实际指两后臀间背线锚点，**不等于尾根或尾尖**；三者必须各自定义 |
| 前肢 | 可见前肢的近端连接、肘/腕表面位置候选、远端、蹄 | 前/后角色依据、解剖侧别、伸屈、支撑/悬空候选、局部遮挡 | 猪体细长且交错，最近距离配对会错；没有肩/连接证据时不强称前肢 |
| 后肢 | 后躯连接、膝/跗关节表面位置候选、远端、蹄 | 伸屈、支撑、卧姿下折叠、实例归属 | 人类“膝盖”直觉可能把后肢跗关节认错；不把不可见关节位置当已观察点 |
| 蹄与接地 | 每只可见蹄、可见接地处；细趾结构仅在原像素确实可分时启用 | 支撑面、接地证据、图像朝向、轮廓与遮挡 | 蹄被地板缝遮挡、邻猪腿穿过身体框；不因常见四肢结构补出四个蹄点 |

本目录是可观察身体的工程分层，不声称所有图都能分出全部细节。外部可见细节可扩展`other_visible_subpart`并引用来源；内部骨骼/器官不是单RGB已知输出。靠缩放复制一个原始像素，不能把“分辨不出”变成“已观察”。

**细部位按原像素条件启用。** 腹侧可辨时，记录乳头/乳房、脐部、外生殖器的可见表面候选；口部张开且确实可辨时，才展开舌/牙；蹄部足够大时，才展开分趾或副蹄。每项仍要有owner、定义与证据，不据此强填性别/繁殖阶段/疾病。通常远景下这些字段是unobservable或unknown，不把不存在可用像素误作器官不存在。

## 2. 主要输出单元

`image_id → instance_id → part_id → attribute`。同名部位跨猪绝不能共享无owner的记录。每个part至少有：

- `parent_part_id / owner_instance_id / ownership_state`：属于哪个身体层级与哪头猪，是否存在竞争归属；
- `anatomical_role / anatomical_side / landmark_definition`：部位是什么、哪一侧、点到底表示哪个表面位置；
- `visibility_state / source_regions_or_points`：可见/部分可见/未见/出框候选/未决，以及同一原图坐标系中的证据；
- `shape / image_orientation / attachment_refs / articulation_candidate`：局部形态、图像方向、连接与屈伸证据；
- `surface_appearance / local_image_quality / uncertainty / alternatives / evidence_refs`：外观和不确定性不被粗姿态覆盖。

`not_visible`不等于缺失解剖；`unresolved_owner`不等于没有这个部位；`out_of_frame`与`occluded`不互换。左右归属不能从屏幕左右自动填入。角色/侧别不清的肢体先叫`visible_limb_1`，可保留前/后/左/右备选，不把备选当已确认四肢。

肩背表面点、后臀表面点、耳根、尾根等均需要文字定义和对应点/区域证据。T18的四锚点是一种顶视任务选择，不是全身体目录；T12隐藏侧关键点使用对称性估计的做法也不能在本版伪装成可见真值。完整定义与支持集中在理论D46。

## 3. 原图观察与归属流程

1. **粗实例发现与部位发现协同。** 全图/网格既找猪体候选，也保留独立头/耳/尾/腿片段；不要求先有完整猪框才能记录可见部位。
2. **实例/部位双账本。** 稳定实例ID和部位ID分别分配；部位可暂不归属。由9B对联合上下文检查可见连续性与遮挡边界，不能按欧氏最近邻/框内包含自动绑定。
3. **身体上下文与局部细节成对看。** 原始干净上下文＋标明目标的副本＋局部原图裁剪分别保留。只给一个离体蹄裁剪会丢owner证据；只给整图又可能看不清，所以记录每次补看所解决的具体问题。
4. **分组解析。** 头面/耳组、躯干/颈/臀组、肢体/蹄组、尾部组各有短结构化任务。预算允许时按可读性继续细化；不能把一次长JSON截断后缺失的组记作阴性。
5. **坐标粗到细。** 先原图大区域定位，再在原图裁剪中定位细部位；裁剪内0..1000量化映回较小原图区间，可降低坐标参数的量化步长，但不会增加原始图像信息。所有view/变换和原像素支持留存。
6. **竞争归属检查。** 若一个腿/耳片段被分给两猪，或一头猪的头尾连接跨越邻猪，输出争议组并请求联合裁剪；允许“目前无法归属”。若引用的部位在当前框外，提出框修订，而不是把部位删掉来过校验。
7. **由部位解释整体。** 站立、胸腹卧、侧卧等由支撑部位与躯干表面证据解释。顶视下不能辨认支撑的，姿态可以是inferred_candidate或unknown；不要强说“看到离地高度”。

## 4. 身体约束不是隐藏标签

常见四肢、成对耳/眼等解剖结构用于提示检查是否错归属，不能要求模型无论可见性如何都输出4腿2眼2耳。远近侧遮挡、邻猪重叠、畸变和截断都可能改变可见部位数。外观异常也不能为了符合模板而删除。

不同part的前后遮挡可交错，不能要求所有部位都服从一个全身深度排序。先标局部遮挡边界与发生部位；真实3D接触/关节角/隐藏骨架另为不可识别量。可见肢体的二维折线夹角如被计算，须写明是图像投影角，不命名为真实三维关节角。

不沿用某论文“只标本栏猪、邻栏可见猪忽略”的数据政策：本版先记录画幅内所有有猪证据的候选，栏位归属是另一个候选关系。不能以旧标注覆盖范围决定新实例是否存在。

## 5. 部位验收必须单独交付

按身体组分别报告：已发现实例的部位输出覆盖、可判部位定位/owner正确率、解剖侧别未知率、关系与属性错误、局部原始像素支持和未完成组。定位评价只可来自新RGB独立审阅，不使用原数据标签；未有审阅前只称候选与一致性。

全身姿态正确不能抵消耳/腿归属错误；全图猪数正确也可能有两猪互换部位。像素部位Mask、部位点、部位框、文字可见性各有精度和身份，不以其中一项冒充另一项。部分细部位不能可靠解析时，保留证据/未知和全量失败账本，优先修该身体组，不自动扩大图数或换更大模型。

**优先裁决：** 先实现“部位发现与owner归属可追溯”，再完善细部位属性和姿态。它同时回应猪场原研里的错归属、断片和重复问题，以及用户强调的身体细节；比先堆整体类别或更多表面形容词更直接。实际9B验证仍未执行。

## 6. 一个归属反例（人工示意，不是模型推理）

猪A与猪B身体相贴，画面中有一段腿从A的身体框下方露出，但与躯干的连接被遮住。正确记录是`part_id=leg_fragment_1, owner=null, owner_alternatives=[A,B], anatomical_side=unknown`，附原图联合裁剪及片段坐标；不能因腿在A框内就归A，也不能以“每猪四腿”分配给缺腿的那头。补看仍不可辨时保留未决。站卧结论引用其余支撑证据，同时注明这一片段未解决。
