# V14结案：局部身体对应可学，但现有字段的全身定位不可靠

已完成576张既有合成留出、147456个可见身体点及96张受控双猪拼合的零优化验收。**当前字段未通过预冻结身体对应能力要求；下一研究重点选定为跨姿态规范身体对应训练，优先抑制侧卧与跨部位大错配。** 原型并非完全没有学到东西：学习度量比初始度量明显改善，紧阈值定位也超过特权部位参照；这些局部优势没有形成可靠的全身对应。当前未新训练模型，原型真实Mask+5目标仍未完成。

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | V9字段的视觉MSE下降11.169%，却无框/Mask联合增益；V12类前景约束使Mask AP−0.0795pp。缺口是实际身体点身份能否跨姿态、视角和邻猪干扰保持，而非继续确认前景响应或loss下降。 |
| **机制假说** | H：当前视觉平均字段及共享度量仍有大量身体身份错配，限制其作为形状先验的可靠性；H_alt：已有几何对应足够好，主要缺实例归属/读出。若H_alt成立，固定模型应在规范表面定位及姿态分组通过要求；失败则下一投入应放在身体对应表征。 |
| **针对性方法** | 固定既有YOLO编码器、P2/P3坐标、PCA、283顶点字段与V9末3000步度量，576图各256点、图像等权；评价规范网格离散测地距离。初始度量为现有参照，另给真值部位并用train-only统计确定部位medoid作特权粗定位参照。96张双猪补集对192实例各256个保留点，与孤立图相同点严格配对。预测不读GT；GT仅定义评价对象和特权参照。 |
| **整体结果** | 当前PCK@0.10为38.7465%（初始19.1779%、要求≥70%），平均误差0.21519规范网格直径（要求≤0.10）。站立51.5991%，左右侧卧16.5527%/19.9422%，姿态护栏失败。对特权部位参照平均误差未改善，反而高82.7699%；但PCK@0.05为28.1440%，高于该参照15.2072%，说明局部细对应存在，不能一概称“只有前景”。双猪同点39.0930%→30.3406%，下降8.7524pp，≤10pp护栏通过，但绝对对应能力仍不足。原生YOLO及已有V13的Box/Mask AP本项未评价，不能从这些合成对应指标声称部署收益。 |
| **研究决策** | **优先训练跨姿态规范身体对应，保留已学局部信息并抑制大错配。** 当前字段整体不宜继续作为“对象已学好”的前提扩展融合；实例条件接口也确实未实现。唯一下一步是按[下一训练设计](NEXT_TRAINING_PLAN.md)准备固定几何身份目标的对应预测训练，YOLO检测及强Mask保留。新训练尚未启动；只有新模型通过预冻结的全覆盖对应/姿态要求，才转到实例归属与可见Mask读出。 |

| 已有字段＋实际学习度量（预定主对象） | 38.7465% | 28.1440% | 0.215185 |
| 真值部位＋训练点部位medoid（特权参照） | 45.4563% | 15.2072% | 0.117736 |

学习度量比初始PCK@0.10提高19.5685绝对百分点，平均误差降低30.9614%；这是固定字段的度量状态差异，不把混合训练中某一个loss单独归因为原因。相对特权部位参照PCK@0.10低6.7098pp、PCK@0.05高12.9367pp，优势集中在一部分精确点，平均大误差仍突出。特权参照额外得到真值部位，不能作为同信息部署方法胜负；它用于判断当前身体身份读出是否足够可靠。没有增加新的训练对照臂。

## 边界、运行与交付

- PCK分母是已知可见身体像素，主体检索在283身体顶点内argmax，属于有利条件下的身体定位测试。不是前景检测、实际实例分离、真实Mask AP或完整3D重建评价。
- GT身体点离散为三角面最大重心权重顶点；距离为边长加权图最短路/图直径，不称连续曲面精确测地。实际图直径1.304376规范坐标单位。8家族synthetic-dev曾用于字段重建评价，故非全新独立测试。
- 双猪由两张单体cutout固定平移/层叠而成，明确为2D受控干扰。实例ID只用于后验评分；当前接口无实例查询，归属记`not_implemented`，没有借GT提示制造实例能力。
- Slurm265：COMPLETED/exit0/37秒，1张A6000；smoke真实9次前向、正式672次，优化0，参数/BN状态哈希前后相同。Slurm266：COMPLETED/exit0/2秒，CPU独立核验，GPU0、前向0、优化0。
- CPU用独立全顶点Dijkstra重算距离、逐图/姿态/双猪统计和裁决，共10648项，最大绝对差1.11e−16；smoke重心回放坐标误差0.0001362以内。91项返回文件SHA通过，查询特征缓存留服务器；8组PNG/SVG已逐图检查。没有新训练、推送、目标模式、定时器或遗留作业。
