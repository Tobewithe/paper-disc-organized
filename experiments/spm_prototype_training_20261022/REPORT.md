# SPM-P1：双源猪群视觉原型已训练并交付

**正式训练完成：Slurm184，2000步，Run `RUN_SPM_PROTO_TRAIN_2e46d0049349`，exit0。** 已产出可重载的128维局部投影和256个冻结原型（猪体128、背景128），正式产物已回传本地并逐项核SHA。完成的是原型训练与构库，不是增强版YOLO的AP验证。

| 维度 | 本次完整实验的研究链路 |
|---|---|
| **问题** | 用户要求先实际训练出可用原型。此前S1的同类接触覆盖诊断没有训练投影/原型；其4<8组结果不回答普通猪体/背景原型能否学习。现有真实数据与已渲染Pig场景具备本轮外观原型所需输入与标签。 |
| **机制假说** | 同一冻结P3中的跨图重复局部模式可以经对应视图一致性、非塌缩和fg/bg监督形成可检索记忆；竞争解释是普通投影/二分类足够、记忆只学域纹理。本轮只验证训练产物与接口，不声称已排除这些竞争解释或取得分割机制收益。 |
| **针对性方法** | 226张真实原train图＋12个既有Blender Pig场景的384帧，共610图；固定COCO预训练YOLO26m-Seg提取P3，32,896参数的256→128投影＋129参数辅助头，正式2000步。train按四个domain×fg/bg桶各128对采样，dev不训练/构库；随后固定球面距离.5、fg/bg各最多128中心、两轮重分配。单A6000；没有等待新渲染或先训练猪群YOLO B。 |
| **整体结果** | 从610图两种同几何视图取得37,981对局部token，其中train30,717、dev7,264；真实2000步完成，总训练loss首/末采样12.3533→0.9709。正式256个128维中心及projector已保存；模型编码器state SHA不变、单位范数和有限值通过，独立重放512条实际dev特征的检索误差0。26项回传文件SHA一致。相对原生/已有方法的Mask AP、损伤与独立因果效益均未测，不能从分类准确率代替推断。 |
| **研究决策** | **已达成“训练出原型并可查询”的本轮目标。当前优先方向是把这份已验证记忆接入同一编码器的YOLO P3，唯一下一步为零残差等价与真实检索响应的接入smoke，尚未启动。** 依据是训练权重、双源中心与重载接口均已真实成立，比继续把接触诊断当构库前提更直接连接用户目标；AP是否改善留待后续同数据/同容量对照。容量触限和中等量化相似度须保留，不能称已学得最优语义原型。 |

## 原型来源、容量与边界

- 猪体原型由14,973个train token构建：真实5,504、合成9,469；背景15,744：真实5,504、合成10,240。
- 每分区108/128个中心同时分配到真实与合成token；这表示来源混合，不证明语义一致或跨域因果有效。
- 两分区均触及128容量上限；在线发现阶段超过距离阈值却触限的次数分别14,471/14,160。故256是**本轮容量约束下的实际K**，不是自动发现最优K或猪体部位数。
- 训练token到最后最近中心的平均余弦为fg .545028、bg .558806；可加载不等于高保真压缩，也不能据此直接扩大K或换loss。
- 旧Blender Pig RGB384×256、可见标签128×192；最近邻映射保留其原有分辨率限制，不称重新渲染640细节。没有使用真实高频迁移。
- 固定官方COCO预训练编码器，不是已训练猪群YOLO B；后续换Neck或投影器必须重建库，禁止把本库直接用于失配坐标。
