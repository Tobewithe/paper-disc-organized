## 1. 整体问题、假说和权限

固定 P 的同检测系数 Oracle 已找到修复见证，而已有 Adapter 及 CLD 未充分兑现。检验一个不同的必要条件：**仅由拟合图估计的真实系数误差结构，移到未参与估计的图上，在相同功能幅度下是否比无结构和通道错配误差更损伤可达掩码。**

H：原生读出误差除系统均值外，存在跨图可迁移、与当前原型通道对应的危险方向；若成立，去均值的真实误差压力 S 应比随机 R、通道错配 M 造成更大的原图 IoU 下降。H_alt：主要由误差大小、一般扰动或系统均值解释；等功能幅度并去均值后，S 不再稳定超过两种对照。均值压力与未中心化经验误差单列，不用来挽救中心化主假说。

本实验是 **GT 辅助压力诊断**，不是训练、可部署方法、全量 AP、原成功 GT 损伤验收，也不能证明原型训练一定有效。只裁决是否值得设计后继定向原型容错训练对照；本轮不训练 P/c/Adapter，不新求 Oracle，不新增网络前向，不扫压力强度、阈值、seed 或子组。

## 3. 只在拟合部分构造误差库

对拟合 accepted 教师定义 `e_j = c0_j - c*_j`（已有有限教师的误差，不是唯一真系数误差）。先图内平均再图间平均得到 μ；保存图像等权的中心化协方差及全部 e_j。系数误差使用固定原生通道坐标；不旋转 P、不重求教师。

功能幅度定义在**原生第一次二值化前的输入尺寸 logit、预测框裁剪支持内**：先按当前 `ops.scale_masks` 将 `d @ P` 从原型网格恢复到 `native_decode_hw`，再在当前检测的原生 crop 支持内求 RMS。这样控制的是直接参与零阈值判定的响应，而非系数 L2 或仅 proto 网格范数。

唯一压力强度 a 为拟合样本功能 RMS(e_j) 的图像等权加权中位数（每图总权重相同，图内教师等权，排序后累计权重首次达到 0.5）。不用留出 c0−c* 的幅度、方向、IoU 或损伤设 a。拟合库及 a 在任何留出压力重放前保存并 SHA 冻结。

## 4. 留出干预与对照

每个留出教师使用 8 个固定伪随机拟合供体，先均匀抽拟合图，再均匀抽该图 accepted 教师（可重复），种子由 CONFIG 的 seed 与 image_id/rank 经 SHA256 派生。供体与留出图必定不同。各方向在**接收图 P 和预测框**上归一到相同 a；这里不读取接收图 GT。

- S：`±(e_j−μ)`，8 对、16 个压力；正负配对消除方向符号均值。
- R：8 个 32D 标准高斯方向及其负方向。仅作为各向同性系数方向对照，归一后不称功能空间均匀。
- M：同一个 S 向量施加本次抽样固定的 32 通道无自映射置换，再取 ±。保持原系数向量数值集合/范数，破坏它与 P 通道的对应，随后重新匹配功能 RMS。
- E：8 个未中心化供体 e_j，保持实际符号；描述总体经验误差。
- MU+、MU−：±μ，各 1 个；描述系统均值与符号不对称。不是主 Gate。

错配明确定义为**通道对应错配**。对全局误差池仅洗牌实例并不改变分布，因此不使用那个无判别力的伪对照。M 不是特征条件下实例错配的因果证明。

以已有 c* 为共同锚点，生成 `c* + normalized_direction`；所有臂走同一冻结 native decoder。C 和 N 必须逐条精确重放原 RLE；G 读取已有对应预测并核非 mask 字段。保存每个压力的供体、置换、实际 FP32 系数、RLE、原图交/并和 IoU、功能 RMS。留出自身误差不进入压力构造；不以它指向自身失败的必然事实作为证据。

## 5. 统计、门槛和唯一决策

主要分母为全部 581 留出教师/208 图；每条先平均该臂固定重复，再图内平均、图间等权。`D_A = IoU(C)−mean IoU(A)`，单位为 0–1 IoU。主比较为 `D_S−D_R`、`D_S−D_M`，正值表示真实中心化结构更危险。

冻结 2000 次成对整图 bootstrap，PCG64 seed=20261017；保存实际抽样索引。区间为 percentile 双侧 95%。需要同时满足的两个主比较构成交并检验，不从多个对照择优；CI 条件于固定拟合库、固定压力抽样和已暴露开发面板，不覆盖模型随机性或拟合库抽样误差。

**值得进入训练设计**必须同时满足：① D_S 的 95% 下界>0；② 两个主比较均值均≥0.005，且各自 95% 下界>0；③ 所有身份/防泄漏/配置/数值/独立核验通过。0.005 是本次预设的实质性方向差（0.5 IoU 百分点），不是旧 S2 或 AP Gate 的替换。

- 阳性：`TRANSFERABLE_DIRECTIONAL_RISK`；唯一下一步为设计“定向容错 P vs 普通 P 微调 vs 等强度随机压力”的同预算训练对照，仍需新协议和训练授权。
- 阴性：若任一主比较 95% 上界<0.005，或 D_S 上界≤0，则 `NO_MATERIAL_TRANSFER_AT_SCOPE`；不进入当前真实误差结构容错训练，不因个别子组/均值臂阳性改判。
- 精度不足：其余未过阳性条件为 `INCONCLUSIVE_NOT_READY`；不进入训练，不自动扩样或加压力次数。科学重点回到当前已证的实际修复与保护缺口，先按完整证据决定方法，不能连续续诊断追阳性。
- 工程无效：`INVALID_ENGINEERING`；保留错误，只修可验证实现问题，新 Run 重试，不改变科学规则。

附带报告：C/E/S/R/M/MU 相对 N 和 G 的同面板 IoU差（GT辅助权限明确）；C中 IoU≥.75 子集的固定同检测跨阈值损伤、原像素 TP→FN/FP→TN（不是全原成功GT任务损伤）。这些不改变主决策，不新算 AP。
