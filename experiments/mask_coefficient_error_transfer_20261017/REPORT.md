# 真实系数误差的迁移性核验：CET-v1

已在笔记本完成全部2510条拟合教师、581条留出教师的零训练核验，并完成两机独立复核。**当前不进入原型容错训练。** 冻结判定是 `INCONCLUSIVE_NOT_READY`：真实中心化误差的额外危险性未达到预设要求，但区间仍容许0.005的实质差异，因此不能写成“已证明没有迁移性”。

正向发现是：**在这一固定功能幅度下，可达教师掩码对真实、随机和错配三类扰动都明显敏感**，平均损失约0.147–0.149 IoU。这支持优先研究“怎样保住已找到的修复解”，尚不支持把训练压力专门对准拟合误差结构。

## 实验展示范式

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | 固定P已经存在系数修复见证，但已有Adapter未充分兑现。准备考虑原型容错前，先核对必要前提：真实系数误差是否具有跨图迁移的特殊危险方向，足以支持区别于一般扰动训练的设计。 |
| **机制假说** | H：除系统均值外，真实误差中存在与P通道对应、可迁移的危险结构；等功能幅度后，它应比随机和通道错配误差多造成至少0.005 IoU损失。竞争解释：主要是一般扰动敏感、幅度或均值效应，中心化结构没有达到所需的额外作用。 |
| **针对性方法** | 原2000图沿用1600/400划分；只用拟合部分2510条/867图估计图像等权均值、协方差、误差库和唯一强度。581条/208图留出以已有教师c*为共同起点，比较中心化真实方向S、随机R、通道错配M，另保留经验误差E及±均值描述臂。S/R/M均8对正负方向，匹配接收图原生二值化前、预测框内的功能RMS；2000次配对整图bootstrap。P、c0、检测身份、decoder均冻结，网络训练/forward/Oracle求解均0。 |
| **整体结果** | S相对C损失0.149152，R为0.147179，M为0.146860。S比R额外损失0.001973，95%区间[−0.001149,0.005096]；比M多0.002291，[−0.000305,0.005035]：均值不足0.005且区间跨零。参考教师C相对原生N为+0.136157、相对已有G为+0.126858；G相对N为+0.009298。这些是同面板IoU，C及压力输出使用GT辅助教师，不能记作新增可部署方法/AP收益。 |
| **研究决策** | 不放行当前“按真实误差结构进行定向原型容错训练”的主张，保留一般扰动敏感和有限可修机会。**我选择的正向重点是：在保持原生输出与可达修复端点的条件下，提高修复解对功能扰动的稳定性。唯一下一步是先冻结这一最小可行性对照的设计，明确端点保护、排除整体logit放大/缩小扰动等伪增益，并比较一般随机压力。尚未启动。** 它比直接按真实协方差训练更值得优先审查，因为三类方向的共同损失已有实测，而结构专属增量未获支持；只有受控条件下出现实质稳定性增益，才重新讨论原型训练。不能用均值臂、追加样本或扫强度改判本次Gate。 |

## 损伤与描述性结果

C在581条中有255条达到同检测IoU≥0.75。以这255条为固定分母，S/R/M各有4080个压力重复，跌破0.75的次数分别为2803/2801/2789（68.701%/68.652%/68.358%）。这是**教师成功掩码的压力损伤**，不是原生成功GT任务损伤，不能与S3的90/22957直接比较；重复压力也不是4080个独立样本。

未中心化经验误差E导致C平均下降0.140015；正均值MU+下降0.085032，负均值MU−下降0.228112，显示本压力设计下的符号非对称。MU+受压输出相对N仍为+0.051125、相对G为+0.041826；它仍依赖接收图GT教师，**不能据此宣称全局偏置修正可部署，不能挽救中心化结构主Gate**。
