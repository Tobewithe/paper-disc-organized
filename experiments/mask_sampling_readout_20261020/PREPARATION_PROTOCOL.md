# SSR-v1 输入准备合同

2026-10-20。用户授权：设计能够检验效果的合适预算并开始。执行端为既有笔记本 28358lan / YANGLEI，不使用服务器、定时任务或目标模式。

本阶段仅准备新实验输入，不训练、不产生方法效果。选用已完成联合掩码实验的原 20000 个 train2017 ID、原 batch16 矩形分组和三轮更新顺序；验证使用原 5000 图及原生历史分组。选择和图像 SHA 直接取已保存的 PARENT_DATA_CONTRACT / PARENT_IMAGE_ORDERS，不按结果或现有文件可用性另选图片。

先核对本地已有图片 SHA。缺失图片只从官方 images.cocodataset.org 的 train2017 路径下载到本 Study 的 data/train_images，最多 8 并发、每文件 3 次传输尝试，使用父合同的 SHA 和原始尺寸核验。笔记本外网不可达时允许本机从官方 HTTP 地址代取，再通过既有 SSH 传输并逐项核对父合同 SHA；不关闭 TLS 校验、不改变系统网络设置。错误或传输不完整保留记录；不换图、缩分母、覆盖历史图片或清理其他 Study。下载和校验总时限 3 小时，新增原图最多 8 GiB，D 盘余量低于 12 GiB 停止。

准备 Run 保存原始输入合同及脚本 SHA、实际输入路径、图像 SHA、下载收据、缺失/失败列表、环境与资源快照。全部输入完成后才能进行正式配置冻结及工程 smoke。准备完成不等于训练已经开始。
