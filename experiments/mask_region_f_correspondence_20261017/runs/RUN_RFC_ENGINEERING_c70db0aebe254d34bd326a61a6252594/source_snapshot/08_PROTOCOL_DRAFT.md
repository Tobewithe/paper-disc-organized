# 实例区域 F 空间对应匹配对照：方案 v1

2026-10-17。Study：`STUDY_MASK_REGION_F_CORRESPONDENCE_20261017`；简称 RFC-v1。

**本轮只完成设计。没有导出新缓存、实现新模型、执行 smoke 或启动训练。** 本文件是待执行审阅方案，不是执行冻结或运行授权。后续若获授权，须将本方案、实现、真实输入与环境一并登记为执行冻结；不能拿文档 SHA 代替运行条件已满足。本方案不修改任何历史 Run 的 Gate。

## 1. 整项实验的研究链路

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | 固定 P 已有系数修复机会，但旧 Adapter 兑现不足。代码查实它只拿到最终检测对应 raw 位置的单点 F，P/z0 则取框内 8×8 网格，经卷积与全局平均后输出一个 32 维 Δc。要检验的缺口是：是否缺少“框内哪里有什么视觉响应、它和 P/z0 在哪里对应”的条件信息。 |
| **机制假说** | H：在既有 P/z0 条件下，保留区域 F 的空间排列，能够提供更有用的系数修正方向。H_alt：额外的区域特征统计或不同的修正幅度已足以产生收益，空间排列本身无可用增量；旧损失到原图二值效用的偏差也可能使两组都不能兑现。若 H 成立，保留组应胜过同输入数值、同参数和同预算的打乱组，等功能幅度后优势仍在，并能超越现有 G。 |
| **针对性方法** | 两个新训练臂 A（保留 F 布局）与 Q（仅置换 F 的位置），共用原初始化、2000 图、soft-IoU 与保护项，各 3 轮/1500 步。原 P/z0、单点 F 和最终输出身份不变。复用旧投影和卷积，均为 167872 个可训练参数。固定最后 checkpoint；评价时加同 checkpoint 置换及等功能幅度对照，训练次数仍为两次。 |
| **整体结果** | **尚未运行，效用和机制均待检验。** 预先同时报告 A−N（原生）、A−G（已有方法）、A−Q（匹配对照），以及定向置换与等幅度差值；不把额外 F、更多计算或较小扰动带来的收益全部记为空间对应贡献。 |
| **研究决策** | 优先检验这一有具体代码缺口和旧布局对照支持的因素，暂停旧输入上的 loss/教师/轮数试错。当前唯一下一步是实现并审查这份确定的对照及输入重放合同，需后续执行授权；本轮到方案为止。将来有实用增量才考虑同 checkpoint 全量 AP 验收；没有增量则停止这版扩展，把已有机会、G 收益及损伤边界写入论文，不续开无依据的调参循环。 |

### 依据与可宣称范围

- [空间信息审查](../../project/audits/repair_information_20261017/REPORT.md)：旧 F 是 head 输入在 raw 的 level/row/column 处的单向量，不是预测框中心采样；原缓存没有完整 F 图。P 和单点 F 都带图像上下文，不能说旧修正器“完全没有空间信息”。
- [原 B/C 对照](../mask_readout_mechanism_v2_20261012/S2_REPORT_20261013.md)，`RUN_S2_EVAL_a24a564568c943eab362784abfbe2c54`：保留 P/z0 布局相对打乱，T 上图宏 ΔIoU +0.009342，95% CI [0.005933, 0.013305]；两组当时仍差于原生。它支持布局值得检验，不证明区域 F 有效，也不证明全局平均是唯一根因。
- [G 的 S3](../mask_gate_s3r_20261015/REPORT.md)，`RUN_S3_FULL_670fffd010664a648e096572fc7c476d`：5000 图 Mask AP 44.014175→44.155748，+0.141573 点；损伤 90/22957。存在真实但不足原 +0.30 AP 门槛的效用。
- [原拟合诊断](../mask_readout_fit_diagnostic_20261014/REPORT.md)：BCE 降低且原图 IoU 降低的 3950 条实例，及[逐尺度核验](../mask_readout_proto_consistency_20261014/REPORT.md)中 2159 条已在 proto 二值化时恶化，支持监督/优化与最终效用不一致这一竞争解释。新 F 不保证消除它。
- [LRP 结果](../mask_local_residual_pilot_20261017/REPORT.md)：有小幅原生收益，但弱于 G；其输入没有 F。不能把该结果当作区域 F 已被否定或已获支持。

此实验检验**固定层级、8×8 区域 F 在现有读出器中的有序使用**。随机置换同时改变 F 的内部邻接与 F 对 P/z0 的位置关系；通过也只能归因于这组“有序空间对应”，不能进一步拆成纯跨模态对齐、纯局部纹理或独立证明 GAP 是瓶颈。F stride 为 8/16/32，P stride 为 4，本方案没有新增更高分辨率图像观测。

## 3. 输入和新的 F 采样合同

所有组保持同一预训练权重、原生 P、c0、框、类别、score、排序、输出数量和逐行身份。A/Q/G 推理只应用原生原图二值掩码面积 `>=96²=9216` 的行；其余行直接采用原生 RLE。门控不依赖 GT、框面积或修正后面积。**训练仍对原全部输出计算原损失**，不把训练改成门控内监督。

共同原输入保留：P/c0、预测框内 P/z0 的 33×8×8 采样、旧 raw 位置 F 向量、4维归一化框、score、class embedding。GT、任务成败、配对标签、教师和图像 ID 不进入可学习 forward。

拟新增输入只为每条检测的 `F_roi[C_l,8,8]`：

1. 来源固定为与原 `raw_locations.level` 一致的 **head 输入层**：来源层 [16,19,22]、通道 [256,512,512]、stride [8,16,32]。不自动拼接三尺度、不换更早主干层，不用已有检测的零散 F 拼成伪稠密图。
2. 在该条原预测框 `boxes_input` 中，按 `x=x1+(j+0.5)(x2−x1)/8`、`y=y1+(k+0.5)(y2−y1)/8` 取64个点。按原实际 `input_hw` 化为 `2x/W−1, 2y/H−1`，`grid_sample(mode=bilinear,padding_mode=zeros,align_corners=False)`。与 P/z0 使用**同一物理网格**；不称为面积平均 ROIAlign。
3. FP32 原始通道值，禁止量化、先用某个训练后投影压成64维或把8×8均值缓存为输入。空输出图照常保留；退化框遵循原合法性检查，遇到新的无效几何工程阻断，不静默丢行。
4. 新 F 属于未来需要真实原生重放才能获得的产物。训练需全部218209行的 F_roi；评价只需门控内行的 F_roi，门控外完整原生行仍进入匹配和分母。评价Adapter仍按整图全部检测行组成矩阵，门控外 F_roi 使用原单点 f 的广播（使新增分支为0），这些行的最终掩码直接采用原生RLE；不得在A/Q之间改变矩阵分组。缓存按原 `image_id/output_detection_id/raw_id/level` 联结；图像 ID 只用于缓存联结和固定置换，不作为网络特征。
5. 基础网络采用原 batch16、rect=True 的**原批次成员、顺序、batch_position、input_hw、ratio_pad**。必要时重放包含目标图片的原完整 batch；其他图片仅为维持批次上下文，不能加入训练或评价分母。`imgsz=640` 不意味着640方图：既有缓存实际最长边672，必须逐图核对输入张量 SHA。
6. 重放须确认原 P/c0/旧单点 F、原输出字段及 raw 映射不变；零 Δc 的完整 RLE 精确相等。张量与原缓存按原生 dtype 逐元素相等，禁止为适配新版导出临时放宽容差。新 F 的 raw 位置向量须与旧 F 精确相等。旧缓存只读，新字段另存独立 manifest；不覆盖原缓存。

来源配置为 [baseline_profile](../../paper/manuscripts/neighbor_sensitive_p3/baseline_profile.json) 及实际 G 训练合同，不依赖框架隐含默认值：Ultralytics8.4.100、固定权重 SHA `16b636f04e8fb6a325b3370f22dc5e5535ff473e384f4d041fd28d788f6ee9f5`；O2O `end2end=True`、conf=.001、iou=.7、max_det=300、FP32 fused、mask_ratio=4、overlap_mask=True、retina_masks=False。全部实际导入模块路径/源码与依赖须在未来执行冻结时核对，不能仅核权重文件。

## 4. 两臂结构：复用参数，改变区域 F 的排列

原 `CoefficientAdapter` 权重形状完全保留。记 X 为原33通道 P/z0 网格，f 为原单点 F，`phi_l` 为既有 Linear(C_l,64)。

```text
v = phi_l(f)                                 # 原64维单点分支保留
u[p] = W_l @ (F_roi[p] - f)                   # phi_l的同一weight，无bias，64×8×8
h1 = GELU(Conv3x3_33_to_64(X))
h2 = GELU(Conv3x3_64_to_64(h1 + u))
s = mean_spatial(h2)
delta_c = 原readout(concat(s, v, 原c0投影, box4, score1, class16))
```

数学上 u 等于 `phi_l(F_roi)−phi_l(f)`，实现规定先减原始F再做无bias线性投影，以保证广播f时精确为0；原投影bias仍用于v分支。注入系数固定1；不新增可学习标量、归一化层、位置 embedding、注意力或额外邻域分支。不扫描注入比例。保留原 GELU、padding、GAP 和32维全局 Δc。**F_roi 全部等于旧单点 f 时，u 精确为0，前向退化为旧 G 的无门控 Adapter**；这是可核验的嵌套参照，不用无梯度参数凑容量。

- **A：**原位置 F_roi。
- **Q：**每条检测对64个**完整通道向量**做一次固定置换，P/z0、单点 f、框和其它字段不动。用 `SHA256("rfc-f-order-v1:314159:{image_id}:{output_rank}:{j}")` 的 digest、再以 j 打破平局排序，得到 gather 索引。训练各 epoch 与评价使用相同规则；不每步另抽，不用 GT 或数值选择置换。每条检测的64个向量多重集合逐字节不变。不同实例通常是不同排列，不能让网络学一个全局逆排列。输出中不提供逆排列或原位置标签。
- 两组都走相同 gather 路径，A 使用恒等索引。仅输入 F 排列不同，其余代码一致。置换固定点和恒定特征行完整记录，不删除“打乱无影响”的实例。

| 参数部分 | 参数数 |
|---|---:|
| 两个原空间卷积（33→64、64→64，均3×3含bias） | 56000 |
| 原三个F投影（256/512/512→64，含bias；网格和单点共享） | 82112 |
| 原c0投影（32→32含bias） | 1056 |
| 原类别embedding（80×16） | 1280 |
| 原readout（181→128→32含bias） | 27424 |
| **合计：A、Q、G均相同** | **167872，17个参数张量** |

有效参数数、初始化和更新次数匹配；**计算量不与 G 相等**，网格需要64次共享投影并有额外读写。A/Q 的算子形状及计算量一致。将来报告 F 导出成本、缓存量、训练总时间、每图/每行 Adapter 时间和峰值内存，不称“相同FLOPs”或把缓存推理时间当完整端到端速度。A−G 是增加区域信息与改变融合路径的复合配置增量；A−Q 才是本设计内有序布局的增量。

## 6. 定向干预与等功能幅度对照（不增训练臂）

除正常 A/Q 外，在原512开发图上预登记以下支撑读数；门控及所有评价分母不变，不选择更好的推理模式替代 A。

1. **J：同一个 A last checkpoint，只把区域F改为Q的固定置换。** 检验学到的读出是否实际使用空间对应。J存在测试分布变化，所以不能单独替代从头训练的Q；只有A/Q和A/J一致才加强机制判断。
2. **A/Q等幅对照与A/J等幅对照，分别计算。** 对一条门控内输出，令 `q(d)=sqrt(mean_R((Pᵀd)²))`；R为原预测框在完整proto网格的半开ROI。使用FP64归约，P冻结，无GT参与。对两个方向d1,d2取 `r=min(q1,q2)`，各缩放为 `(r/qk)*dk`。若ROI为空或任一q≤1e−12，两者均回到原生，并保留该行/配对在分母。只缩小、不放大，无阈值搜索，不用系数L2冒充功能幅度。缩放后以FP32原decoder生成完整输出，实际功能RMS须在 `atol=1e−7, rtol=1e−5` 内相等；否则记工程无效，不在结果后调容差。
3. 两组原始 q、等幅后 q、置零原因和覆盖数全部保存。A/Q等幅产生 `AeqQ,QeqA`，A/J等幅产生 `AeqJ,JeqA`，不能混用两个不同的 Aeq。全部7种A衍生/对照输出（A、Q、J及四种等幅）都在开发512图保持完整预测；新损伤样本额外图片只要求正常A/Q/N/G。

等功能RMS相等没有保证二值变化像素数相等；后者是待观察的结果，不应再按变化像素数挑选子集或调幅。等幅比较能排除“只是总体logit扰动更小”这一特定解释，不能排除所有输出分布差异。若两臂都胜G而A/Q无优势，支持的是区域信息/融合的复合效用，不能宣称排列必要。

## 7. 公平评价与门槛

### 7.1 正常无GT输出与效用主指标

N/G/A/Q均在**同一完整图集合**上导出/读取全部正常预测，所有非Mask字段逐行相同。G复用已核验S3全量预测或同checkpoint重放，不改门控；新G子集须和旧全量逐行RLE一致。N也从同原生全量结果筛出；不可拿官方44.1或全5000的44.155748直接减512图新AP。

decoder完整沿用原生顺序：`c@P → 双线性上采样到实际input_hw → logits>0二值化 → 原预测框裁剪 → 按ratio_pad缩放二值图到原图 → .byte() → RLE`，不额外加0.5阈值，不引入可微近似解码作最终评价。各方法完整预测重新执行原 COCOeval bbox/segm，useCats=1、maxDets=[1,10,100]、ignore/crowd/area规则均固定。

固定T和全部bbox75配对上的差值，先在每张有对应配对的图内取均值，再在同一有效图集合宏平均。复用原 `run_s2_evaluation.image_effects/bootstrap` 的数值定义：有效image_id升序、FP64、`numpy.random.default_rng(1729)`，2000次配对图bootstrap，linear百分位[.025,.975]；各比较用同一重采样索引，直接重采样差值，不把两个CI相减。零改动实例仍在原分母。必要区间用于共同要求，不挑任一显著比较冒充总体成立。

原G开发端点可作复核：T图宏G−N=`0.010024491543988425`，全部配对=`0.0008909711434980322`（来源 `RUN_SOFT_FIT_FULL_14971e618ba8498a9fa8efcd19d21770`）。未来须先证明源RLE及逐配对数值重放一致；这两个已知均值仅用于检查口径，不能倒推调整A/Q。新抽损伤面板的G计数可能不同于历史2/1024或开发census8/2355，不能要求凑回旧数字。

**唯一主要效用增量指标是 T 上 A−G。** 其他主结果列齐 A−N、Q−N、Q−G、A−Q，以及原成功任务修复/损伤数。512图整集AP仅辅助；若计算则N/G/A/Q全部重算同512图的AP，不与不同图集合混比。AP点与0–1 IoU分开。

### 7.2 原成功任务损伤：沿用原S2统计设计，重新一次抽签

采用 [DAMAGE_ACCEPTANCE](../../shared/evaluation/DAMAGE_ACCEPTANCE.md)：总体为原S0的22957个普通segm75成功GT。A/Q最终checkpoint、推理合同和各方法源文件都固定后，**首次读取本次方法效果/损伤之前**，用系统随机源产生一次seed并简单随机无放回抽1024个GT，N/G/A/Q共用这个新面板。

不沿用已参与多次选择的旧1024面板来声称新95%覆盖率；不使用512图内2355成功GT冒充从22957总体的简单随机样本。评价图片为 dev512 与新面板图片并集，最多1536张；需新F的评价批次在抽签后确定，先封存清单，再导出F和预测。每图所有GT/预测参与重新匹配；只在面板内数损伤。checkpoint若因工程恢复改变，旧面板仍保留，任何重新选择须回到新版本方案，不能多抽一张。

A 是唯一主要受验方法，不能根据面板在A/Q/J/等幅版本择优。对A报告超几何反演精确单侧95%上界U；G/Q同面板配对计数用于比较，不据此更换主方法。A−G损伤计数差完整报告，但本方案不额外提出“损伤显著低于G”主张。开发集内2355个成功GT的census可随完整账本给出，范围单独注明，不替代主上界。

### 7.3 预设通过要求

| 层面 | 数值规则 | 用途 |
|---|---|---|
| **新方法额外效用：主指标** | T上 A−G 图宏IoU **≥0.005且95%下界>0** | 新增投入必须带来实际增量；.005沿用原修复最小量级，作为本Study新增投资标准，不追溯重判G或旧Run |
| 原S2修复 | T上 A−N **≥0.005且95%下界>0** | 保留原修复门槛 |
| 原S2整体护栏 | 全2925配对 A−N 图宏IoU **≥−0.001** | 不因门控内效果好而缩小分母 |
| 原S2损伤 | 新1024样本、N=22957的A损伤上界 **U≤1%** | 观察比例>1%为失败；比例≤1%而U>1%为精度不足，不追加抽样 |
| 身份/配置 | 全部非Mask字段、bbox匹配身份、decoder、实际配置与来源校验通过 | 任一失败先工程阻断 |
| **空间机制支持** | T上正常 **A−Q与A−J的95%下界均>0**；等幅 **AeqQ−QeqA与AeqJ−JeqA的95%下界也均>0** | 共同支持布局增量、实际使用及超出总体扰动幅度的贡献；四项全报，不择优 |

效用与机制分开裁决。方法晋级要求主指标和原S2三项及身份全部通过；“有序区域F机制获开发证据支持”还要求最后一行。不能因为A赢了Q却没有超过G，宣布研究成功；不能因为超过G，就把全部增益归于空间排列。Q/J无需自身通过S2才能作为机制对照，低损伤也不能弥补A没有实用增量。

| 输入/原生重放不一致、GT泄漏、某臂缺失、预算超限、梯度路径无效、非有限数或统计工程错误 | 保留失败Run，科学判断无效或不完整。唯一下一步仅为定位并修复可验证工程阻断；不得改科学配置追阳性。两臂均完成且配置审核通过前不作相对机制裁决。 |
