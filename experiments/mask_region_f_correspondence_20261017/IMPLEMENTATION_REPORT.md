# RFC-v1：实例区域 F 对应对照的实现与工程核验

2026-10-17。本轮把已设计的 A/Q 空间对应对照实现为可测试组件，在当前工作站完成了 **25 项 CPU 合成测试**。原参数量、旧权重兼容性、区域采样、布局干预、梯度路径及配置拒绝条件均通过；真实数据上的修复收益和损伤仍未评价。

## 整体研究链路

| 维度 | 本次实现与核验的整体研究链路 |
|---|---|
| **问题** | [空间信息审查](../../project/audits/repair_information_20261017/REPORT.md)发现现有修正器使用单点 F，而没有保留实例区域 F 的空间布局。[已写方案](PROTOCOL_DRAFT.md)拟比较保留与打乱布局，但必须先确认代码真的实现了该干预，且没有偷偷增加参数、改训练对象或混淆检测身份。 |
| **机制假说** | 待检验的科学假说是：区域 F 与 P/z0 的空间对应有助于预测有效修正方向；竞争解释包括新增区域信息或功能幅度本身带来效果。**本轮是工程核验，尚不检验这些科学解释。** 工程要求是 A/Q 除布局外一致，同 A 权重的 J 干预与 Q 使用相同排列，广播原单点 F 时精确退化为旧 Adapter。 |
| **针对性方法** | 复用原 17 个参数张量/167872 参数，加入同层 8×8 区域 F 采样、共享投影融合、固定逐实例置换、面积门控混合及等功能 RMS 对照。只用合成张量和已有初始化/G 权重做前向、反向与合同检查；不更新权重。用可解析空间场检查坐标，用非零 G 权重检查退化与干预，主动注入配置/身份错误检查是否拒绝。 |
| **整体结果** | 最终 **25/25 通过**：广播 F 精确恢复旧 G 的 Δc；原初始化两臂均为零 Δc；非零读出时布局干预有效，J 与同权重 Q 一致；原 17 张量梯度路径有效，冻结输入无梯度；训练不按面积筛行，评价只改门控内掩码；配置漂移与无效运行收据被拒绝。**相对原生 N 的科研收益、相对已有 G 的额外收益、真实损伤及机制 Gate 均未测。** |
| **研究决策** | 优先把区域 F 与原生检测/P/c0 的真实对应关系接入并核验，再决定是否进入 A/Q 正式训练。依据是原审查给出了具体输入缺口，本轮证明所需对照在代码上可实现；还不足以判断它能提高分割质量。**唯一下一步是补齐原生输入重放集成，在笔记本冻结环境完成既定小规模 smoke**；要求原批次/张量/输出身份及 zero-delta RLE 精确一致，参数/梯度和资源检查通过。未通过则保留工程失败并修定位明确的问题，不更改科学门槛或训练预算。该下一步尚未启动。 |

检测身份采用 `原 predictions.json SHA:全局预测行号`，不以 raw_id 或 COCO 内部 dt_id 替代。一条 raw 可对应多条最终检测。当前测试的“旧 G 精确退化”指 Adapter 输出 Δc；**不冒称已经新完成真实原图 RLE 重放**。
