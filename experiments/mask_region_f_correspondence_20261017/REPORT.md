# RFC-v1：实例区域F空间对应匹配对照结案

2026-10-17。A（保留区域F空间对应）和Q（固定打乱对应）均已在笔记本完成原2000图、3轮、各1500步训练；固定最终checkpoint的1294图评价及两机独立复核完成。本轮追加训练0步。

**主判断：A相对原生有明确开发收益，但相对已有G的实用增量不足，空间对应机制未获支持；损伤上界为精度不足。按冻结协议关闭RFC-v1，不进入S3。** 通俗说，在512张开发图中，A比G多修好2个GT，也多损伤2个，净恢复同为14；打乱空间顺序后没有出现预期的收益下降。

| 维度 | 本次完整实验的研究链路 |
|---|---|
| **问题** | 已有G（soft-IoU＋原生掩码面积≥9216门控）能产生真实修复，但没有充分兑现固定P下的系数可修机会。此前空间信息审查发现：旧网络已有P/z0的空间格网，但F只取原输出raw位置的单点。需要检验缺少与P/z0对应的区域F，是否是值得优先解决的修复瓶颈。依据见[原空间信息审查](../../project/audits/repair_information_20261017/REPORT.md)及[冻结方案](PROTOCOL_DRAFT.md)。 |
| **机制假说** | 若有序区域F帮助预测更好的系数方向，A应超过同容量、同输入内容但乱序的Q；将同一A权重的F打乱为J，应削弱收益；把双方扰动的功能幅度匹配后，方向优势仍应保留。竞争解释是区域内容/扰动幅度本身，而不是空间对应。还必须相对G取得预设的实用增量，才能支持继续投入。 |
| **针对性方法** | 保留旧单点F，用共享投影向原卷积注入同层8×8区域F；A/Q均167872参数、同初始化/数据/优化器/loss/3轮1500步，仅F排列不同。冻结基础模型、P/c0和检测身份；所有方法仅对原生掩码面积≥9216的输出应用Δc，其余原样保留。原dev512上固定655条T及全部2925条bbox75配对；另一次抽取1024原成功GT，与开发图合并1294图，完整预测/GT重新匹配。预设J及两组成对等功能幅度控制，比较N/G/A/Q，不按结果更换主方法A。 |
| **整体结果** | A−N目标图宏IoU **+0.012408**，95% CI **[+0.004031,+0.021759]**，原S2修复和全配对均值护栏通过。A−G只有 **+0.002384**，CI **[−0.000092,+0.004873]**：均值未达+.005、下界未>0，且本次区间上界低于预设实用幅度。A/Q对原生都有收益，但四项布局/等幅机制CI均跨0。A损伤6/1024=0.585938%，精确单侧95%上界1.136908%>1%，属于保护精度不足，并非已证明总体损伤超过1%。配置、Box身份、原生重放、81图工程恢复重放和独立复核均通过。 |
| **研究决策** | 关闭本版有序区域F路线的新增投入，不加epoch/seed/网格/loss，不选Q/J/等幅版本替代A，不以全量评价补救未过的S2。**我主张把研究重点收束到已有G所支持的保守系数修复效用及“可修机会—实际兑现—损伤代价”的边界。** 依据是G已有全量低损伤收益，而本次有效空间干预没有给出足够的额外效用或机制证据。唯一下一步：把RFC结案并入论文证据表、结果与讨论，保留G为最好已验全量方法；这项写作尚未启动。重启空间布局训练须有独立的新支持证据和新方案。 |
