# V23 连续随机参数→源网格构造：算法预检通过

用户明确要求保留生成算法而非几个固定派生资产。本次实际从原rest/J/蒙皮与stand矩阵生成24个连续随机参数实例并精确重放；没有从V22两份width mesh中抽样。用户随后指定外观先行，后续姿态/场景/接触接入暂不执行。

| 维度 | 本次实验的整体研究链路 |
|---|---|
| **问题** | V22离散目录虽能准入两份样例，仍只是在几个固定形状间选ID，不能代表用户要求的可变化生成算法。 |
| **机制假说** | 工程算法必要条件：固定stand的全部rotation与全局Y映射可交换、offset_y=0，故源rest与同一J映射后LBS能产生连续幅度，并保持原拓扑/自交和支撑；竞争解释是骨架不一致或隐藏派生mesh输入使重放/约束失败。不能以端点通过直接替代区间依据。 |
| **针对性方法** | 冻结seed301030、12scene×2owner=24实例，独立key采样width Uniform(.82,1.18)、scale/yaw/XY。从源rest/J每次重建；5固定探针核交换关系与posed仿射等价，实际24样本核重放/独立key/身份/支撑/ipctk及8负控，CPU≤180秒/0GPU。组合布局仅登记，不称其已验收。 |
| **整体结果** | RUN_V23_PROCEDURAL_PREFLIGHT_23a622352cfe约2.734秒，24个连续width及24个mesh fingerprint均不同；同配方/新对象重放逐数组一致，修改width范围不改变其它key。交换误差0，5探针重建误差≤1e−10，所有样本源面/9父级/owner/支撑与自交核过；8非法输入均拒绝。源身体家族仍1，无新RGB、布局/场景或泛化通过结论。 |
| **研究决策** | 保留源生成算法/采样配置与recipe重放接口，固定输出仅本次验收产物；不把24随机mesh称24自然个体家族。最新用户要求先猪本体外观，再姿态、场景、碰撞，因此唯一下一步为V24固定单猪外观制作；本算法的进一步场景接入保留待办，不启动后续阶段。 |

相对旧source，增加连续可复现的几何变化；相对V22，摆脱有限派生width目录输入。但本阶段无同场景RGB/AP/真实效用比较，随机性本身不证明泛化。连续性质只对当前stand映射成立，不转移到任意姿态/接触；contact请求会明确拒绝。
