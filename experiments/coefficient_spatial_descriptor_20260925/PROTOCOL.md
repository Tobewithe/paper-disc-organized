# Experiment 7F-B: does local prototype spatial detail help predict a finite correction?

Reuse 7E's 800 fit / 200 dev train2017 target bank, λ=.003, frozen official YOLO26m-seg one-to-one candidates, and 200 val2017 images. For each candidate crop the 32-channel prototype **inside its predicted box** and adaptive-pool to 8×8; no GT or annotation is used in the descriptor. Keep the existing 4×4 descriptor as a resolution control. The five input arms are `h` only, true local 4×4 resized to 8×8, true local 8×8, wrong-instance 8×8, and wrong-image 8×8. All arms use the same CNN encoder/predictor architecture, initial weights, batch order, target, loss, and dev checkpointing rule. Wrong-instance singletons fall back to wrong-image and are counted. The matched 4×4/8×8 architecture isolates added spatial detail; the mismatched 8×8 controls test whether any gain depends on the correct instance.

The primary held-out metric is predicted-box pixel-logit-effect cosine with the GT-conditioned 7D target; coefficient cosine and radius error are supporting. Decode selected checkpoints on original validation images and report mask IoU, Mask75 repair/damage, and in-box AUC. Preserve the full fixed-positive population as guardrail and analyze original Mask75 failures/successes separately. Validation target files and descriptors are read only after checkpoint selection. A gain over wrong-instance/wrong-image without gain over `h` or matched 4×4 does **not** establish that the extra spatial information improves the method.

The target uses GT and is only a supervised training label; inference-time descriptors use frozen model outputs. This is a frozen-head diagnostic, not full model COCOeval AP.
