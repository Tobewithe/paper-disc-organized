# 干预与反事实术语边界（按实验声明启用）

> 只有实验或论文明确声明采用这组术语时才适用；其他研究线按自身对象和协议命名，不自动继承。

当前项目对输入、特征或输出进行人为修改并观察模型响应时，默认使用 **perturbation（扰动）** 或 **controlled intervention（受控干预）**。将这种响应用于选择训练位置或构造监督时，方法称为 **intervention-guided learning（干预引导学习）**。

只有当研究明确给出结构因果模型或潜在结果定义、干预变量、需要保持不变的变量、可识别条件与效应估计时，才使用 **causal learning** 或严格的 **counterfactual learning**。将同一图像中的邻居弱化、背景替换或目标对比增强，本身不满足这一要求。

历史目录名、脚本函数名和运行 ID 中的 `counterfactual` 为实验溯源标识，不自动构成论文理论主张。论文和当前研究结论统一称为：

> **Controlled-intervention-guided P3 rescue / 受控干预引导的 P3 救援**

当前允许的结论是：在固定模型上，受控输入修改改变了指定失败对象的 P3 几何输出；该响应可被转化为训练期特权教师信号。它不等同于识别自然场景中邻居或低对比的严格因果效应。
