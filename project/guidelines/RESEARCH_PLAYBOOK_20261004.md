# 研究设计卡（可选）

> 仅用于提出新机制、正式对照或研究路线复盘。普通代码修改、文件整理、报告写作、诊断回传和已有协议执行不需要读取或执行本卡。本卡不增加审批或固定实验数量。

开始新机制时，用一段话或小表记录：

1. **问题与依据**：要解释的现象、已有正负结果、源代码/文献依据，以及尚未确定的部分。
2. **竞争解释**：至少列出一个可能的替代解释；说明本轮对照能排除什么，不能排除什么。
3. **变量与对照**：只改变研究变量；固定或明确数据、模型、评价协议、预算、seed、checkpoint 和运行环境。
4. **结果口径**：分别报告训练拟合、机制指标、候选诊断和正常推理收益；机制改善不等于任务收益。
5. **停止与继续**：预先写出继续条件、停止条件和阴性结果的解释范围。短预算不足以判断时保留未知，不把结果包装成普遍结论。
6. **记录**：保留 Study/Run ID、源文件版本、适用范围、限制和下一步；不复制已有结论。

研究线程可以并行，但共享数据、代码和评价协议必须写明版本。远端执行只回传到对应 Run；失败和部分产物照样保留。论文按需引用实验，实验不为论文复制。

本卡不能替代条件规范：涉及 COCO 转换、训练/解冻、raw 候选或专项指标时，读取 `EXPERIMENT_SPEC_STANDARD.md` 的对应章节；术语问题读取术语表。历史手册内容只作为当时研究记录，不自动约束新实验。
