# 训练规模与科研结论边界

**2026-10-13 统一规则：训练预算由科学命题和已冻结 Gate 决定，不是“规模越大越必须立即运行”。** 当前 [执行总控](../ACTIVE_PLAN.md) 的主线是**已训练模型固定权重后的局部后训练**，并非从零训练完整 YOLO。

| 阶段/目的 | 规模与权限 | 不能说成什么 |
|---|---|---|
| 数据/权重/源码/decoder 预检 | 可读本地文件、零训练 | 已完成研究 Run |
| 小规模工程 smoke | 由 Study 冻结，例如 ≤16 图 GT 账本样例、32/8 张真前向 | 完整 COCO AP、有效泛化、论文显著性 |
| **无训练有限 oracle** | 只在**正常最终预测固定身份**上用 GT 求可恢复机会；先冻 ROI/decoder/优化器和有效分母 | 新部署方法或原型能力绝对上界 |
| **新后训练单种子初筛** | 在机会 Gate 通过后，当前 proposal 固定 **2000 张 train2017 fit**，同预算/同预测候选的对照和成功保护；不更新 YOLO 基础权重 | 独立确认、前瞻泛化 |
| **扩大训练/多 seed** | 2k 初筛与同一 pilot checkpoint 的全量 AP/损伤验收 **均成立后**，才进入当前 proposal 的 20000 张 train2017 与多 seed；训练时长按协议，不见结果临时追加 | 从论文方向本身推导出“必须现在跑” |
| 正式外部/新图确认 | 需要与已调参和研究开发图片、相近视频场景按协议分组隔离的保留集/新采集图；COCO val2017 已反复被项目用作研发 | 把旧 val 图“重新命名”为盲测 |

**执行规则**：本地或服务器任务真实状态必须先审计；未经当前环境授权不自动连接/启动/恢复。模型、数据、下载依赖、可训练参数、冻结 buffers/BN、真实 Loss、显存/磁盘和完整输出路径先预检，smoke 通过后才进入已授权规模。新训练、重试、失败各自独立 Run，保留 SHA、参数与运行终态；不能运行后换数据、跳 Gate、为追正增益扫超参、追加 seed。

**结论范围**：2k 单种子筛查通过只允许进入该 checkpoint 的全量验证；全量效用验收再通过才允许规划受控扩量；20k/多 seed 通过后再讨论性能确认。反复用 val2017 选择方法得到的 CI 不能当开发外严格证据；GT oracle 仅说明存在可找到的修正，COCO 正常输出 AP 和原成功实例损伤才是部署价值。

**例外原则**：其它论文线若已有**先前冻结且有效**的训练预算，仍按那个 Study 执行，不由当前后训练建议静默改写其数字。新命题与旧配置不同需新版本协议和主线总控记录，严禁沿用旧门槛名称偷偷启动新训练。
