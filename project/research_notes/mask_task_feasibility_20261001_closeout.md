# 固定原型下掩码任务可行性对照：结案记录

- **Study**：`STUDY_08c0415b-7dc9-462e-bb13-8783d7713bf5`（`coefficient_mask_task_feasibility_20261001`）
- **Run**：`RUN_mask_task_feasibility_certificate_20261001`，笔记本 `28358lan`，官方 one-to-one TAL 候选，原始 COCO `instances_train2017.json`。
- **对象**：796 张 fit 图、6,058 个官方候选；固定 `h/P/c0`、预测框、标签支持和原生系数读出；E1 质量安全内集；正则化诊断目标的全局位移预算为 `45.673507054`。

## 结论

P3 的 15,119 条确定性初始锁定约束子集给出保守对偶下界 `72.042775450`，高于全局预算 `45.673507054`，裕量 `26.369268396`。该子集是完整约束集的子集，因此在本轮固定对象、固定有限预算和声明的质量包络下，固定同尺度共享仿射系数读出不能把全部 E1 候选同时送入内集。

这支持“逐实例目标与固定共享仿射映射之间存在可量化的可达性差距”，但范围仅限于本轮 E1 质量安全内集和数值证书。它不等于所有 Mask75 解都不可达，不等于无限制移动时不可行，也不单独证明整个网络或某个模块是唯一根因；没有 COCO AP、部署收益或新图泛化结论。

## 证据与限制

独立目标侧的证据、原始候选身份、参考损失、证书复算和运行日志保存在实验 Run 目录。共享侧使用非负对偶权重的条件数值证书；直接 FP64 复算与原值差约 `2.1e-13`，数值保守余量为 `1e-6`。完整工作台仍有历史 Study 冲突和覆盖范围未知项；本 Run 的唯一剩余校验提示是远端完整依赖覆盖范围未知，远端大缓存位置与传输情况记录在 `transfer.json`。
