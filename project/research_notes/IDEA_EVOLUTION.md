# 主要 Idea 演变轨迹

只记录主要想法，以及促使想法变化的认识。按问题域保留主线和开放分支，不把演变强行写成一条所有前案都被否定的直线。经过判断的排除范围和开放问题直接反馈到对应纲要；此处帮助追溯变化，不替代纲要积累知识。

## 猪实例分割

**2026-11-05三组检验后的取舍：** [夜间Study完整报告](../../experiments/pig_multi_idea_night_20261105/REPORT_V1.md)补齐了[同COCO起点联合学习](../ideas/IDEA_PIG_COCO_JOINT_V1.md)：C−Q平均−0.513151且异号，一般辅助仍优于R，单改起点没有得到稳定语义增量，训练曲线共同衰退成为需要解释的现象。[V23功能约束重训](../ideas/IDEA_PIG_V23_SIMPLIFIED_RETRAIN_V1.md)则把低敏感性推进为重训可维持的证据，共享保留图三seed均小幅提高，优先进入真实结构精简。[C21细尺度保持](../ideas/IDEA_PIG_C21_FINE_PRESERVATION_V1.md)仅+0.024948、状态变化0／−1／+1，本版扩训结束。A、C具体版本关闭，B支持功能简化；内容正确对应仍开放。这些取舍进入来源问题、中心纲要和主线，保留一般辅助及局部稳定性的有效认识。

本节先保留SPM既有主线的知识问题：**怎样让模型获得并利用关于猪的知识，从而更好地区分接触、遮挡中的不同实例？** “知识保存在哪里、怎样学到、怎样用于任务”不断变化。它只是猪实例分割中心命题的一个切入；后续开放分支可以改变输入、监督、表示或任务理解，不由这条历史决定范围。

| 主要想法 | 核心变化与推动它的认识 |
|---|---|
| **跨图像的视觉原型字典** | 将反复出现的猪体与场景模式压缩成可检索记忆，为当前图像补充知识。随后发现，仅有相似特征中心，未必能够表达一头猪的身体结构和实例差异。[来源](../../paper/manuscripts/spm_yoloseg/RESEARCH_CHARTER.md) |
| **有身体结构的对象模型** | 从“存一组特征”转向“保存一个可变形、可摆姿态、能解释不同观察的对象”，引入规范身体位置与可见性。进一步意识到，几何结构存在与图像中的身体对应可靠，是两回事。[来源](../../paper/manuscripts/spm_yoloseg/OBJECT_PROTOTYPE_DESIGN_V5_20261023.md) |
| **具名的对象与部位记忆** | 希望知识具有明确内容：整体、部位、遮挡、边界，并直接服务检测与分割。问题随之变为：知道词条表达什么，并不保证当前实例能够找到、用对它。[来源](../../experiments/spm_semantic_dense_task_20261025/REPORT.md) |
| **让被匹配的内容真正参与重建** | 从“检索后交给自由任务头”转向“由实际匹配的整体—部位内容组合出掩码”。新的认识是，形式上的组合约束仍可能留下绕过语义的自由度，结构看起来合理不等于概念发挥了作用。[来源](../../experiments/spm_content_constrained_memory_20261026/REPORT.md) |
| **在共同坐标中组织对象与部位** | 将关注点移向当前图像内的实例归属，让对象与部位在同一图像坐标中读取、交互或竞争。需要区分：一般实例条件处理的价值，与具名部位关系的额外价值。[来源](../../experiments/spm_registered_object_head_20261027/PROTOCOL_V1.md) |
| **把知识写入训练，而非依赖部署时检索** | 改为利用合成的同实例、同表面对应，在训练期施加原型约束，让知识留在原生模型中。知识不必表现为一个常驻记忆库；但正确的局部对应，也未必就是最终任务需要的知识。[来源](../../experiments/spm_rlpl_pipeline_20261101/FINAL_REPORT.md) |
| **用明确的猪体概念监督原生表示** | 从匿名原型分配转向头、躯干、前肢、后肢、尾等明确标签，利用合成数据直接教概念。逐渐分清：部位能够被预测，与部位知识改善实例分割之间，还隔着任务使用这一层。[来源](../../experiments/spm_pig_concept_training_design_20261101/DESIGN.md) |
| **让概念监督对齐实际实例读出** | 从全图“哪里是猪头”转向“这是哪一头猪的头”，让承载实例Mask的原生表示同时承担所属部位预测。重点由增加概念种类转为连接概念身份、实例归属与任务输出。[来源](../../experiments/spm_concept_native_training_20261102/PART_TO_INSTANCE_INTERFACE_DISCUSSION_V1.md) |
| **把分配、概念监督和Mask读出一起考虑** | 进一步追问：哪些候选获得哪个实例的监督，会不会限制概念的作用？将普通Mask质量与正确部位对应的作用分开考虑，避免把所有改变都归为“学会了猪知识”。[来源](../../experiments/spm_concept_native_training_20261102/ASSIGNMENT_AND_PART_SUPERVISION_DISCUSSION_V1.md) |

这条主线之外，还出现过两个重要分支：

**直接迁移已有任务知识。** 将已有较好掩码中的纠错知识传给原生读出，优先学习已经体现任务价值的内容。这与“先学概念，再期待任务受益”具有不同出发点；它没有取代用户希望保留的概念学习目标。[来源](../../experiments/spm_task_aligned_head_transfer_design_20261101/REVIEW_AND_ROUTE.md)

**暂时放下模型和概念预设，重新理解实例可分性。** 将问题开放为三种解释：实例关系没有被有效组织、相关条件覆盖和迁移不足、单帧观察本身缺少信息。由此重新比较普通实例训练、概念知识和额外观察，而非默认继续修改同一模型。[来源](literature/pig-instance-open-analysis_2026-11-02/summary.md)

### 2026-11-02：从知识可读转向知识与真实任务责任的交互（历史局部候选，未训练）

已有证据进一步收紧了论文问题：V21/V23有正常收益，却未充分证明正确内容必要；V32竞争较独立读图有小增量，但部位错位几乎无损；概念V1/RLPL的局部相对作用未形成安全净效用。新叙事将“标签资格、概念可读、归属使用、正常效用”分开，不将跨版本结果拼成唯一因果。

据此形成一个具体方法候选：保留合成C/Q概念学习，在真实TRAIN的可靠互斥区域，对实际原生实例读出施加相对归属约束；用C/Q×独立点监督/相对监督，辨别正确语义与一般owner重权的交互。它不声称过去没有负例，也不把排名loss或实例竞争本身作为创新。真实错误和有效支持不足时不训练；覆盖对语义价值的调节为备选，不并行铺开。

当前M臂实际分配变化稀少、旧多位置强变动又无净收益，还要求区分可用信息、实际干预与效用。新想法和论文贡献仍待验证，原Goal、Gate及暂停不改。[论文叙事与候选](../../paper/manuscripts/spm_yoloseg/PAPER_NARRATIVE_AND_IDEAS_20261102.md) · [已有证据和下一步判断](PIG_NEXT_RESEARCH_PRIORITIES_20261102.md)。

### 2026-11-02：用户纠正——中心命题不能缩为知识主线或论文

用户明确要围绕中心纲要打开思路，现有主线只是起点；此前把结构监督问题和论文叙事提升为总体边界，是任务理解错误。旧局部候选及实验认识保留，其A/B排序不限制大命题，也不要求先完成原矩阵才继续构思。

由此打开的主要想法包括：可见片段怎样组成实例；少量看清过的观察怎样提供当前归属证据；受控合成怎样帮助发现模型依赖；少量关系型标注怎样提供真正缺失的任务信息；怎样区分可见、推断与未知；个体能力怎样迁移而场景信息可以更新；困难区域是否值得获取更多视觉细节。

新的联系也改变优先思考对象：关系型标注与片段表示可以共同设计，历史可见证据可以与可信归属结合，合成能力则可先用于获得认识而不必以训练增益为前提。这些方向触及不同的信息来源与研究对象，当前优先继续推敲前三种交叉／用途；真实成本、序列可用性和错误分布仍未知，选择可以改变。

具体联系与价值见[开放探索图](../outlines/OUTLINE_PIG_HYPOTHESES.md)及[本次认识修订](PIG_OPEN_EXPLORATION_20261102.md)。它们不是同一网络的模块清单，没有新方法结果或运行授权。

### 2026-11-04：先厘清“原生”指哪一个模型，再判断方法与训练整合
