## A. 直接猪领域证据

### [#39] Evaluation of Deep Learning Instance Segmentation Models for Pig Precision Livestock Farming（2021）

原文：https://doi.org/10.52825/bis.v1i.59

- **问题与对象：**比较通用实例分割范式是否适合猪场，而不是预选单一模型。作者报告731张多来源图像、每图3–30头，75%/25%训练/测试。
- **方法与比较：**DetectoRS、SOLOv2、DETR、Mask R-CNN，共同ResNet50/COCO预训练，各30epoch；框架和各自默认配置有差异，不能称完全相同优化条件。
- **结果：**其测试Mask AP分别84.8、83.1、83.0、82.2；DetectoRS约131.6M参数，其他约42.6–46.2M。作者的定性分析指出四类模型都存在遮挡时肢体归属问题，较高总分与尾部细节最好不由同一模型同时获得。
- **能支持：**骨干大小与总体AP不是细部归属能力的充分代理；不同实例表示值得开放比较。
- **不能支持：**不能由这四个配置断言模型规模永远无效；作者将部分漏检归于NMS，但未在此给出隔离NMS的因果对照。多场景混合测试也不等于未见猪场测试。
- **对创造的约束：**先区分漏目标、错误分组、局部边界问题。仅换骨干或总体涨分，不说明解决了哪一种猪场困难。

### [#29] Occlusion-Resistant Instance Segmentation of Piglets in Farrowing Pens Using Center Clustering Network（2023；arXiv:2206.01942）

原文：https://arxiv.org/abs/2206.01942

- **实测问题：**6段俯视视频、4600帧；身体被遮挡物分成多片的BSO出现在95.4%图像，末端部位缺失PMO出现在92.3%，两类可重叠。不是把所有遮挡当一种错误。
- **机制与实现：**像素预测语义和指向物体中心的偏移，DBSCAN聚类中心，再将组身份回传到像素。RC2M把未分组像素按预测中心重新归组，使不连通可见区域仍可属于同一实例。
- **结果：**相同数据划分内，完整方法mAP84.1，CondInst80.6、YOLACT++80.9、Mask R-CNN74.4；中心聚类82.8→加RC2M84.1。完整推理约0.234秒/图，明显慢于其Mask R-CNN约0.06秒/图。
- **关键条件：**使用额外猪仔中心标注；每图只有一头母猪，母猪语义Mask直接当实例；全部帧随机按60/20/20划分，不能当视频来源隔离。跟踪只是半分钟示例，不是完整长时验证。
- **能支持：**断片归组是有直接猪领域依据的问题，中心/投票表示是有效候选。
- **不能支持：**相对基线的差值不能全归架构，因为中心监督、算法与计算同时变化；物体中心不等于完整身体形状，也不能解决完全不可见对象的单帧辨识。
- **可发展空间：**比较“关系监督的额外信息”与“使用中心作为编码形式”哪个真正必要；不把重新实现中心投票当新贡献。

### [#13] Weakly supervised learning through box annotations for pig instance segmentation（2025）

原文：https://doi.org/10.1038/s41598-025-05113-x

- **问题与数据：**标注成本；一个韩国猪场、多相机昼夜数据，13,383图，8:1:1拆分。正常评价有Mask GT，但目标域弱监督训练只用框。
- **方法：**基于BoxTeacher的两个CondInst教师/学生，EMA更新教师；框投影/颜色关系约束，加教师伪Mask的Dice监督。不是完全无监督，更不是从未见过Mask的模型：使用COCO预训练CondInst。
- **结果：**作者报告Mask AP85.29，原BoxTeacher损失82.66；全监督CondInst86.32、SOLOv2 88.51。实际部署仅用学生。其差值是同一论文内的目标域标注效率证据。
- **证据限制：**单类化和伪Mask损失简化一起变化，不能把全部收益归为某种猪形态知识；已读拆分段未交代来源/时间隔离，不能宣称跨场泛化，也不能据此直接判定测试泄漏。标注时间应区分引用估计与本项目实测总人工成本。
- **对创造的影响：**“缺更多精细标签”不是默认前提；少量真实框+强先验/伪Mask可能是生成大量合成精细标签的有力竞争路线。是否更优取决于目标、预算和错误结构。

### [#25] Attention-Guided Instance Segmentation for Group-Raised Pigs（2023）

原文：https://doi.org/10.3390/ani13132181

- **方法：**在Mask R-CNN/Cascade Mask R-CNN的FPN中加入分组通道/空间注意力；另比较数据增强、骨干注意力和可变形卷积。
- **数据：**45头、8栏、1917图，959/192/766拆分。作者有同框架注意力比较，但不同配置的收益不能混为单一机制效应。
- **有价值的反例：**正文承认严重模糊/粘连场景下四类注意力仍不能把猪分开，只能得到更完整的合并前景。
- **泛化证据的实际层级：**第三方俯视昼夜数据没有实例级标注，展示的是可视化，不是独立Mask AP确认；热力图也不是实例归属机制的直接证明。
- **对创造的影响：**“看起来关注猪”“前景更完整”“更能分清每头猪”是不同目标。普通特征增强是合理基线，但不应成为未经问题分析的默认创新。

### [#45] MGB-Former: An Enhanced Mask2Former for Pig Instance Segmentation in Complex Pig-House Environments（2026）

原文：https://doi.org/10.3390/agriengineering8100447

公开PDF获取自出版社静态附件；原常规入口失败记录保留。

- **问题与设计：**在Mask2Former上结合来自MP-Former的Mask引导辅助训练、LSKBlock空间增强和训练期前景CNN辅助。额外监督主要来自已有实例Mask，不是动物部位标签。
- **比较条件：**PigLife筛选后2533图，1711/411/411，明确按原视频分割；基线和方法共同R50、1024²、100queries、30k更新及选点。训练期两辅助分支删除，LSKBlock仍在推理，不能称整套方法零新增推理开销。
- **结果：**单配置Mask2Former67.13→完整72.54 AP，+5.41点；三seed均值67.10±0.21→72.50±0.22。Mask引导分支单独71.62（+4.49），前景CNN单独67.47（+0.34），LSKBlock单独70.06。不同因素并非等容量，组合效应不完全等于独立机制证明。
- **有意义的判断：**其消融给“实例对应/训练组织”提供了比“额外前景头即可”更强的支持。与此同时，它已经是“将MP-Former用于猪”的直接前作，不能再以此本身包装新意。
- **边界：**视频隔离比随机抽帧更可靠，但仍是一个数据集；数据先剔除了难以可靠标注的严重模糊图。没有由这项研究证明所有猪场都应选Transformer，也没有识别本项目旧失败的根因。
- **可发展空间：**区分通用去噪/匹配稳定化、特定遮挡关系和额外语义各自贡献，而不是立刻换成它的模型作为唯一底座。

### [#495] Livestock Monitoring with Transformer / STARFORMER（2021）

原文：https://arxiv.org/abs/2111.00801

- **方法：**DETR式实例表示联合分割、跟踪、动作和重识别，加入同帧区分、跨帧同身份一致等监督。
- **数据与条件：**训练280段×15帧，验证84段×15帧，另有Pigtrace；评估DETR与STARFORMER时，把输出数固定为视频中已知猪数。这是有用场景先验，不是未知数量自动分割。
- **结果：**Pigtrace表3分割AP约DETR63.9、STARFORMER69.0；多任务效果是完整配置比较。
- **关键消融：**作者指出删除时空对比头不损伤分割，却影响跟踪。这说明“视频系统更好”不自动证明时间损失改善了逐帧Mask。
- **对创造的影响：**如果采用视频，先决定增加的是输入证据、训练对应、已知数量还是状态记忆。它们是不同作用，不应共用一个“时序帮助分割”的故事。

### [#122] Automated Segmentation and Tracking of Group Housed Pigs Using Foundation Models（2026预印本）

原文：https://arxiv.org/abs/2604.03426

- **方法：**Grounding-DINO文本检测→SAM2视频传播，配初始化、匹配、几何Mask修正、ReID及后验质量控制。并非只把SAM2接上相机。
- **条件：**长期演示来自单相机约132分钟、特定栏位区域，初始化寻找10头高置信不重叠猪；后续可按可见状态调整。可以从片段中间参考帧做双向传播，属于可利用未来帧的处理。
- **评价：**132个均匀抽样GT帧；摘要报告J&F0.87和无ID切换。正文说明不可靠片段可重算或排除，QC输出还由人工评估。
- **能支持：**大模型预训练+视频+明确场景约束是实用的另一条路线，不必先设计猪专用网络。
- **不能支持：**不能把抽样132帧等同全时段密集身份核验，或把带场景信息和QC的结果转成未知数量、无人工、严格在线、任意猪场性能保证。
- **可发展空间：**无GT的自动初始化、错误恢复及不确定性处理；研究时须把额外输入信息与模型参数贡献分开。

## B. 数据与迁移：合成并非只有3D渲染一种角色

### [#261] Pig Detection Using Computer Vision Models Trained on Synthetic Datasets（2025）

原文：https://doi.org/10.5753/eniac.2025.14272

- **方法：**从少量真实图中用SAM2抽取猪模板，几何/外观变换后粘贴到背景；这是2D重组，不是新3D个体生成。评价对象是检测框，不是实例Mask。
- **结果：**自然图COCO背景合成得到检测mAP50–95为61.6，随机噪声背景24；说明外观/背景选择可能非常关键。作者报告混合训练有收益，但严格IoU下纯合成仍明显弱于真实数据。
- **重要比较条件：**模板包含原训练和验证录像的帧；合成图再拆分，并非供体独立验证，不能据此宣称测试泄漏。混合实验固定7200真实图、增加合成图且epoch固定，训练总曝光/步数也变化。
- **不能照搬的结论：**“40%–50%合成最好”不是普适比例；表2标的是相对百分比，不能直接抄成AP点。该设计也不是固定标注预算、固定计算下的严格样本效率验证。
- **对创造的影响：**应先比较低成本2D重组与3D/生成式方案；合成的价值是增加了什么有效变化，不能以图像数量或精美程度替代。

### [#550] Simple Copy-Paste is a Strong Data Augmentation Method for Instance Segmentation（CVPR 2021）

原文：https://arxiv.org/abs/2012.07177

- **方法：**从两张训练图选真实实例粘贴，按遮挡更新可见Mask和Box、删除全遮挡目标；不要求上下文逼真，融合边缘也非必需。
- **结果：**多骨干/尺度下有增量，表1作者总结平均约+0.8 Mask AP；有不同日程的曲线支持，不能仅因最终训练很长就否认作用。
- **边界：**最强配方含强尺度增强、长训练、部分额外伪标签数据；576epoch与96epoch的完整配置不能直接当等预算单因素比较。依赖源实例Mask，不能凭空增加新的身体几何或正确的隐藏形状。
- **启示：**视觉真实性不是任务收益的充分或必要条件；但“COCO中随机粘贴有效”也不意味着猪场中的非法尺度/接触关系无害。
- **公平参照：**若复杂合成方法没有超出同预算Copy-Paste，应承认新增生成复杂度尚无效用证据。

### [#4] Learning Part Segmentation from Synthetic Animals / SAP（WACV Workshops 2024）

原文：https://arxiv.org/abs/2311.18661

- **方法：**虎/马合成部位数据，结合真实无标签图，傅里叶混合与少数部位伪标签重加权；这里的学习目标本来就是部位分割。
- **结果与条件：**23,520合成图、5942真实无标签训练图、1213真实测试图，三seed均值。纯合成42.21mIoU；DAFormer48.08→加CB-FDM58.04；真实部位监督74.71，真实+合成75.08，仅+0.37。
- **关键知识：**合成收益依赖真实监督的强弱和迁移方式。更多样SMAL数据改善总分，却可能损伤尾部，作者将其与尾部拟合误差联系为解释而非已证唯一原因。
- **能支持：**合成动物结构标签有可迁移价值，并非只有写实图像才有用。
- **不能支持：**不能从真实部位mIoU的改善推出猪实例AP必增，也不能把“没有真实部位标签时收益大”迁移为“已有大量真实Mask监督时同样收益大”。
- **创造方向：**选择真正缺失的信息；明确额外标签究竟填补了何种监督缺口，不预设所有部位概念都有用。

### [#407] Dataset Diffusion（arXiv:2309.14303）

原文：https://arxiv.org/abs/2309.14303

- **方法：**Stable Diffusion生成图像，从类文本的交叉注意力与自注意力提取语义伪Mask，以双阈值忽略不确定像素，再自训练。
- **结果：**例如DeepLabV3-R101的VOC合成64.8mIoU对真实79.9；COCO合成34.2对真实54.9。作者明确承认复杂、多小目标和交织物体是困难。
- **关键区别：**图像和标签都由学习系统推断，标签不是几何真值；按类提取语义图，不自动提供同类多头猪的独立owner。生成效果好与实例标签正确是两个问题。
- **可借用：**不确定区域不硬监督、利用生成模型视觉先验。
- **不能冒认：**它没有解决猪群实例身份，也没有证明用风格编辑后保留原Mask必然合法。开放讨论生成式方案不等于本轮授权恢复历史生成任务。

### [#505] DAFormer（CVPR 2022）

原文：https://arxiv.org/abs/2111.14887

- **比较设计：**分别比较源域训练、UDA与目标域全监督，交换编码器/解码器，并分析warmup、稀有类采样及ImageNet特征保持。
- **实际证据：**正文表1里较好的目标域全监督模型不必有较好的UDA表现；表4的warmup改变也能显著影响训练表现。架构和优化组织共同决定迁移。
- **边界：**道路多类语义分割不是单类猪实例分割；稀有“类别”不等同稀有“遮挡关系”，将其推广到猪条件采样属于新假说。
- **对创造的影响：**先区分合成内容不够、域差过大、已有预训练知识被适配侵蚀。不能把三者都归为缺某个部位模块，也不能由一个域适配算法的名字判断适用性。

## C. 通用机制前作：防止把已有结构重新命名

### [#569] Masked-attention Mask Transformer for Universal Image Segmentation / Mask2Former（CVPR 2022）

原文：https://arxiv.org/abs/2112.01527

- **本轮阅读范围：**架构和训练效率段，不据此追加新的效果数值。
- **表示：**固定数量可学习queries，经集合目标表示可变数量分割对象；像素特征与query解码Mask。masked attention用前一层预测Mask限制关注范围，交替利用多尺度特征。
- **意义：**实例不必先用框裁剪定义；但局部关注依赖先前预测，不能由“不用常规NMS”推导“天然不会混淆相邻猪”。
- **候选变量：**实例表示与匹配方式、高分辨率代价、监督路径，不是“Transformer”名称本身。

### [#408] MP-Former（CVPR 2023）

原文：https://arxiv.org/abs/2303.07336

- **本轮重点：**预测在解码层间不一致、query利用率低的计算问题；训练中增加已知对应的GT类query和带噪Mask，原匹配分支保留，辅助分支直接与对应GT计算损失。
- **机制区别：**额外信息是训练时明确的实例对应和受扰Mask，不是新的动物解剖标签；推理删除该路径。
- **已有直接迁移：**MGB-Former已将其用于猪，所以“用Mask引导稳定猪query”本身不能再声称新颖。
- **潜在空间：**若提出新型遮挡/关系监督，须与普通Mask引导、一般噪声正则及相同输入容量的控制比较，不能把GT训练辅助的公共收益归为新语义。

### [#18] Deep Occlusion-Aware Instance Segmentation with Overlapping BiLayers / BCNet（CVPR 2021）

原文：https://arxiv.org/abs/2103.12340

- **方法：**在ROI内分开表示遮挡者和被遮挡目标；第一GCN预测遮挡轮廓/Mask，其特征引导第二GCN预测目标，避免把遮挡轮廓和真实物体轮廓混为一类。
- **结果：**作者同检测器对比在COCO-OCC上FCOS基线28.43→30.68，Faster R-CNN基线29.67→31.71；额外参数分别约3.0M和3.2M，非严格等容量。
- **对象边界：**COCO-OCC以框重叠≥0.2筛图，是遮挡代理，不能等同逐像素物理遮挡真值；论文还分别评价amodal数据，不能混成同一任务成绩。
- **可借用：**监督关系和边界类型，而非把所有边缘同等处理。
- **新颖性边界：**遮挡者/被遮挡者双层读出已有直接先例；若在猪上使用，价值须来自新失败机制、标签组织或可靠迁移，而非换物种名称。

### [#308] TAPPS：Task-aligned Part-aware Panoptic Segmentation（2024）

原文：https://arxiv.org/abs/2406.10114

- **机制主张：**全图部位目标把不同对象的同名部位归成一类，而实例目标要求区分对象；共享对象query派生该对象的部位queries，绑定对象与部位。
- **结果：**Pascal-PP的thing PQ62.0→65.6，而忽略实例后的thing mIoU69.8→69.9；Cityscapes-PP对应PQ53.8→55.6，mIoU77.6→78.2。与实例分离改善相容，不能仅凭这个统计差异证明唯一内部因果。
- **条件：**目标本来是part-aware panoptic，有真实部位标签、多类别及类别—部位兼容性；不等于仅合成概念训练后删头的猪实例任务。结构和参数也变化。
- **对创造的意义：**部位路线有正面相关依据，但其对象—部位共享query已被做过；它应与中心归组、普通实例匹配稳定化等竞争，而不是未经比较就成为唯一主线。
