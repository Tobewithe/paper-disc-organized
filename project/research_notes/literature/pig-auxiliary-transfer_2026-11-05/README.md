## 1. 从真实未解决问题定义缺口

证据来自[夜间实验报告](../../../../experiments/pig_multi_idea_night_20261105/REPORT_V1.md)，以下都是已有结果，没有新模型实验：

1. 正确部位C相对无辅助R有收益，但非解剖Q更强，三个预定点C−Q均差都负。缺少的能力是**判断一个辅助目标提供了什么可迁移的价值，怎样根据主任务决定学习它的强度与时机**。
2. R、Q、C都随训练退化。缺少的是**区分训练优化、泛化与辅助增量**。负梯度内积不能单独识别负迁移，方法低于成熟N也不能代替匹配R对照。
3. 合成部位曾经可学，但真实迁移及正常实例读出的利用仍未分开。缺少的是**选择具体域迁移技术，以及判断监督能否辨认对象归属错误**。只会泛称“域差”“融合”不足以形成新方案。

## 2. 外部方法比较与取舍

| 学到的方法 | 相比已有Skill新增的能力 | 当前选择 |
|---|---|---|
| TAG，NeurIPS 2021 | 通过共享参数的一步作用测方向性任务亲和性，比单看loss大小更接近任务交互 | 借其更新效用观测；原同批训练指标不是跨域验证结论 |
| Auto-Lambda，TMLR 2022 | 用主任务meta-loss学习动态辅助权重，区分主任务与辅助的价值 | 若进入辅助调度新版本，作为首个算法候选；当前只选低维权重，不默认另加复杂网络 |
| AuxiLearn，ICLR 2021 | 学习非线性／像素损失组合，隐式微分考虑训练解对辅助参数的依赖 | 当前优先级较低：真实主任务和合成部位不在对应像素上，小规模meta数据也限制额外网络；保留其曲率与泛化分析能力 |
| ForkMerge，NeurIPS 2023 | 以有限训练后的目标表现选择主任务／联合分支的参数合并，并提供梯度冲突不必有害的实验 | 是短期代理不可靠时的替代，不因有8卡历史授权就自动多分支训练；保留分叉成本及优化器状态问题 |
| SAP／CB-FDM，复用并深入读附录 | 源目标混合、目标伪标签；只给高精度低召回部位增权；物体级特征保持未必适合部位 | 若证据指向真实迁移，按部位可靠性选自训练／混合；不把所有小部位统一增权 |
| TAPPS，复用并核正式CVPR入口 | 共享对象query生成对象及所属部位，匹配先绑定对象；对象Mask不是部位硬并集 | 提供对象绑定设计依据；旧实例条件头的阴性必须纳入比较，不能仅以新增实例头当改进理由 |

算法不是根据论文名排序。Auto-Lambda解决“是否／何时借用辅助梯度”；SAP处理“部位知识能否迁入真实域”；TAPPS处理“部位是否与所需实例关联”。选择取决于缺口所在，不能用一种方法替所有失败解释。

## 3. 具体学到并能应用的内容

### 3.1 按主任务效用学习辅助权重

将原生主任务记为L_main，辅助部位为L_part。简化SGD下一步为

`θ' = θ − α∇[L_main(B_train)+λ L_part(B_synthetic)]`。

在另一批真实TRAIN数据上计算`L_main(B_meta;θ')`，再更新λ，这是Auto-Lambda的目标导向思路。本文所述“主任务权重固定为1、仅更新辅助权重”是项目候选适配；原方法可学全部任务权重。主任务meta-loss仍需覆盖原正常任务，避免只降Mask代理而损伤检测；最终COCO AP与损伤合同保持。

原文实际采用同TRAIN不同batch，不要求必然牺牲一个永久独立验证集。若我们要检验跨来源泛化，应在TRAIN内按来源另定meta分配，并明确它已参与学习，432dev和封存test不用于权重更新。

代码核对也揭示一个实用限制：官方虚拟更新是SGD式，并使用第一组优化器配置。当前工程若有分组学习率、Adam状态、冻结参数或合法detach，需按实际更新重写展开；直接复制源码不构成算法接入。完整公式、条件与实现注意项已进入多任务Skill。

### 3.2 优化冲突与泛化效用不能共用一个判断

ForkMerge以L2正则与跨域实验反驳“冲突必有害”的简单判断。我们用解析例子核对：训练目标`½(θ−2)²`、目标验证`½θ²`，θ=1、步长0.1。主任务更新得到1.1，验证loss升至0.605；加权2的`½θ²`辅助与主梯度方向完全相反，却得到0.9、验证loss降至0.405。该例是方法性质演示，不是猪模型结果。

因此不再把“测到冲突→加PCGrad”作为默认接续。TAG的一步作用、Auto-Lambda的目标批次超梯度和ForkMerge的有限训练选择提供不同强度的效用观测；长期AP仍需真实检验。

### 3.3 迁移与对象绑定需要不同的数据关系

SAP附录给出了此前只读摘要式总结时没有用起来的内容：头部伪标签精度高、召回低，因此增权；尾部精度和召回都低，因此不增权。作者还关闭了面向物体类别的ImageNet特征距离。它们使迁移设计落实到**保留什么语义、信任哪些目标、强化什么错误**，而不是笼统增加域对齐和保持项。

TAPPS的对象绑定则让损失看见owner错误。两个相邻对象的部位语义图保持不变时，把一个腿部区域分给错误对象，纯全图部位loss不变；对象条件的部位loss能辨认这个变化。但这只证明监督区别，不能由此断言当前A失败必由实例接口引起。旧V32等实例条件方案和暂停分配矩阵仍保留各自状态。
