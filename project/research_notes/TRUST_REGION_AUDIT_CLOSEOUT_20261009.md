# 信赖域读出审计结案：未达放行门槛，路线停止（2026-10-09）

Study：`experiments/coefficient_trust_region_audit_20261009`（笔记本 `28358lan`，零训练、零新前向，
面板与 oracle 复用 `coefficient_oracle_alignment_20261009` 的 dev 导出）。协议与门槛执行前冻结，
独立核验 7/7 通过。

## 决定

`STOP_ROUTE`。1,375 个候选（1,239 个 oracle 增益为正）：

- **G1 保留未过**：信赖域投影只保留 oracle IoU 增益的 **30.2%**（门槛 80%；最宽松 λ_R=1 也只有 49.1%）。
- **G3 结构对照未过**：随机同规模支持投影保留 58.8%，显著高于信赖域 30.2%——
  按当前掩码不确定性选证据像素不携带可测优势（无保护证据区拟合 55.5% ≈ 随机 58.8%）。
- **G2 保护通过**：保护区 logit 改动压到 oracle 自身改动的 6.2%（无保护投影 79.3%）——保护极其有效，
  但每单位保护的保留代价大；保护与保留在该参数化下不可兼得。
- **G4 通过**：原生成功候选无损伤（+0.011 IoU）；原生失败候选上 T 仍有 +0.109 IoU 的受保护增益。

## 对主线的意义

- 10-05 笔记中“功能空间信赖域读出”的**放行前审计未通过**：不进入短预算训练，不追加扫描/调参追阳性。
- 与该线已记录的其他配置级阴性并列：oracle 目标蒸进原生分支不迁移（10-09 可学性分解）、
  空间 teacher +0.013pp、QCR 阴性、ACD 门槛失败、TriFlow valid_negative。
- 至此，`neighbor_sensitive_p3` 线上“固定 P 下可恢复（66%/62%）但原生不实现”的排除链已覆盖：
  候选选择、监督量、ownership 求解、外挂全局修正、oracle 目标蒸馏、受约束功能投影。
  剩余有依据的方向是表示层（固定 P/解码内不可达的约 33.58% 对象）或该线诊断证据的成稿。
- 研究线总目标未完成；本结论为配置级，不证明所有功能空间方法无效。
