## 3. YOLO26核心机制是否遗漏

| 核查项 | 实际代码及判断 |
|---|---|
| O2O特征／原型detach | `head.py:157`和`:404`为该版本原生实现：O2O输入特征及其Proto detach，主干／Proto经O2M学习。保留它是兼容原生训练，不是接入失败的直接证据。 |
| 两分支原生loss | `SegmentationModel.init_criterion`实际返回`E2ELoss(...,v8SegmentationLoss)`。检测、实例Mask及YOLO26原生语义辅助loss仍存在，没有只留下新增loss。 |
| TAL | 原生O2M topk10；O2O先topk7再topk2=1，并非照搬旧版简单topk1。当前桥接器复制这些属性并保留原软标签归约，未发现把必要分支删掉的证据。 |
| 语义Mask全0 | 单类猪的0是类别索引。`loss.py:529`起还会按独立实例Mask生成`present`并scatter，前景目标不是全0；原生语义分支末点实际更新。不能把这行loader代码判为背景标签错误。 |
| DFL为0 | 实际模型reg_max=1，DFL模块为Identity，原生loss也按此关闭DFL；不是漏算必要loss。 |
| O2M/O2O时钟 | 手工循环逐update推进，epochs字段在这里作为更新总长度；原生Trainer按epoch推进。当前代码显式匹配0.8→0.1全程，而不是忘记更新。RLPL构造器虽初设epochs4，正式`initialize_criterion:40`在建loss前改为2000，不能把初设4误判为正式错误。 |
| 分配干预剂量 | CM/QM真实O2O累计状态变化4／2，CP/QP为8／0，均跨2000训练事件累计；不是唯一动物数或独立替换概率。当前真实作用很弱，不能用它充分否定一般的分配思想；效用评价仍未恢复。 |

当前概念V1的辅助信息主要读Proto中间特征，真实任务与合成辅助是两个前向共享权重，并非把部位真值直接送给正常检测；末500步不再使用辅助。桥接版才进一步将部位读出与实例系数和分配结合。后者训练完成不等于已经证明任务增量。**核心计算接通与信息被部署任务有效利用，必须分开。**

## 4. 主要训练整合差异与证据等级

当前自写循环调用原生模型／criterion，但没有走完整原生Trainer；这不自动意味着实现无效。普通R和方法使用相同手工流程的比较仍有价值，缺的是对“标准YOLO任务训练方案”的直接比较。

- **已确认：阶段起点不同于通用预训练。** 当前N已经是多阶段目标域权重，所有新训练均重新建立优化器和loss时钟，并非恢复原optimizer／EMA的resume。完整state加载、共同初值和导出重载有证据，没有发现权重漏加载或只恢复少数层。强checkpoint继续适配时改变了参数范围与训练输入；是否产生有害分布变化仍需对照。
- **已确认：训练策略有重要差别。** 后期全BN冻结，真实图除局部实验外没有在线增强；自写AdamW、小有效batch、无累积／EMA、固定末点。原生Trainer包含按有效batch组织优化、正常增强及关闭阶段、EMA等；8.4.100的auto优化还可能选择MuSGD，并为特定head／语义参数设较高LR。这些不是YOLO结构运行的硬性条件，不能直接认定某个开关就是根因；也不能拿默认yaml里的值当手工循环实际生效值。
- **已确认：训练规模选择缺乏保真曲线。** 夜间16500步主要由运行速度决定，约52次真实源遍历，并非16500个数据epoch；R训练loss从前100步均值0.764降到末100步0.126，但dev低于N4.61 AP。上游同Run已有中期优于末期的记录。我上一轮用夜间时长决定步数、没有先建立保真准入，是设计缺口；不应以更多训练自然会好作为继续依据。
- **已确认：局部实验改变了多个重要条件。** 裁剪边长中位数148、最小128，输入仍来自640缓存；标签由原160栅格放大。R/L/D/P梯度裁剪比例约0.67%／54.05%／33.99%／45.78%，D与P的派生实例曝光525782，R为759736。局部组测试时仍走完整图。该配置同时改变视野、尺度、目标分布、梯度强度；无结果能证明单纯“细节多了所以更差”。L与D标签／几何匹配，D−L仍是有价值但限定范围的比较。
- **已确认：保持loss不等于保持任务。** P只约束每步前2张完整图的教师top32 raw Mask／类别响应，不直接保持Box，也不覆盖所有对象和裁剪图。它相对D的AP和损伤改善真实存在，但不能从surrogate loss有效推出COCO Mask75损伤必然受控。

**优先待验证假设：**共同适配流程／训练阶段已使保留N退化；辅助或裁剪进一步改变了有效任务学习；分阶段晚接入可能不如从同一通用预训练起点联合学习。**证据不足的判断：**方法整体必然无效、BN是统一根因、取消detach即可解决、只要换MuSGD或加大LR就会转正、从零训练更合适、辅助头没有被联合优化。这些目前都不成立为确定结论。

## 6. 按优先级的最小必要对照（仅设计，未启动）

不要求每个细小超参精确相等；必须匹配会改变结论的**模型起点、模块开放范围、真实任务数据和主要曝光／更新预算、额外信息权限、评价与选点规则**。

| 优先级 | 验证的假设与最小范围 | 控制变量与指标 | 结果如何决定后续 |
|---|---|---|---|
| P0：先把基线叫清、验清 | 从已登记COCO预训练和已有早期任务基线中核定YOLO-only基线身份，复用可用权重；8–16张TRAIN做无更新接口核验 | 同RGB／独立Mask送入标准模型loss及当前适配接口，核两分支输出、TAL关联、5项loss及分组梯度；特别避免将已归一化tensor再除255。零优化，不以此声称方法有效 | 有实现差异先修接口；无差异则停止“必然漏了loss／梯度断开”的猜测，不为格式一致重做全训练 |
| P1：真正公平的主对照 | **同一COCO预训练起点，YOLO-only与一个冻结方法M，直接在目标任务联合训练。**两个训练组即可回答主要效用问题；可先以短程资格，正式预算按目标域学习曲线设计 | 两组均正常开放backbone／neck／head，类别头共同初始化，使用同真实任务数据和大体相同训练策略／有效预算；不把经过选择和分支组合的N当这一对的普通训练组。原N仅作历史强参照。固定完整Mask AP、Box AP/AP75、原成功损伤和成本 | M−YOLO-only为方法增量。若M没有增量，不能靠“N起点不合适”继续解释；若两组均退化，先处理目标任务训练流程，暂不扩大新方法 |
| P2：需要区分阶段作用时才补 | 前一同起点对照与现N起点的YOLO-only／M组成“方法×起点”四格。已有N起点结果只有在主要条件可比时才复用，否则明示限制；不把不同实验硬拼 | 比较Δpretrain=M_pretrain−YOLO_pretrain与ΔN=M_N−R_N；每个起点内部保持同数据、同主要训练规模与共同评价，新增模块共同初始化。看正常效用及辅助概念质量／真实任务使用，不能只看辅助loss | 仅早期联合有增量，支持晚接入／适配条件解释；两处均无增量且普通训练正常，降低方法假说优先度；两处都差则仍是训练适用性未解 |

若要宣称“正确部位／原型”而非一般额外监督，应在主方法有净增量后补同容量、同辅助数据的非语义／普通控制；已有C/Q证据不能忽略。若方法必须冻结一部分YOLO以维持记忆坐标，须另配同冻结范围的YOLO-only，不能与完全端到端基线直接声称纯模块贡献。局部路线若继续，先用已有权重核全图／无GT局部推理的配对表现，避免再次只训练裁剪却用完整图测试后就否定局部信息。以上均为条件性设计，不自动重开旧配置、旧矩阵或追加训练。

“从YOLO最开始训练”在本项目应明确为**加载同一COCO预训练权重后，基线和方法各自开展目标任务联合训练**。随机初始化从零训练尚无依据，也不应把调用一次`model.train()`或运行更多步误称为从头训练。先复用已有原始基线资产和记录，再决定最小新增比较。
