# 机制实验提案：原型更新的原生响应漂移是否抵消新增修复

2026-10-20。状态：**设计草案，未冻结、未实现、无新Run、未授权执行**。本提案响应用户要求提出直接决定方法设计的机制实验，不启动训练、下载、缓存导出或服务器连接，不替代任何旧Run/Gate。

## 1. 具体问题和支持依据

同服务器20k三臂已完成：PC救回320个原失败GT、损伤198个原成功GT，Mask AP44.017703；C_native救回268、损伤120，AP44.253024；G_budget救回250、损伤81，AP44.265173。来源：[三臂报告](../../experiments/mask_branch_joint_replay_20261018/REPORT.md)。这些总体计数不说明PC额外救回的是C的超集，也不能直接作逐实例因果归因。

值得解释的现象是**允许P更新确实改变了更多任务状态，却没有兑现净AP优势**。既有P更新不是毫无作用，但如何作用尚未拆开。相比之下，RSM的任意压力重新居中没有解释真实PC/G的损伤来源；继续复查该压力不是当前提案。

旧线S022不支持将多数失败归因于原最后层局部梯度冲突，S039选择性梯度投影也未取得完整掩码收益：[S022](refinements/coco-structure/SHARED_HEAD_GRADIENT_RESULTS_20260912.md)、[S039](refinements/coco-structure/SELECTIVE_DIRECTION_RESULTS_20260912.md)。因此不把通用PCGrad更名为本项目新机制。

## 2. 可检验的计算机制

固定原模型P0、c0，令PC学习后P1=P0+ΔP、c1=c0+Δc。在阈值之前：

`z_PC = P1*c1 = P0*c0 + ΔP*c0 + P0*Δc + ΔP*Δc`。

- `ΔP*c0`：即便系数完全不改，P变化仍改变原生响应。
- `P1*Δc`：新基底对新增系数修正的作用。

**H（待检验）：**在当前PC后训练中，`ΔP*c0`携带了会损伤原成功实例的变化；如果把原生响应P0*c0固定，只让可训练P参与新增修复，能减少损伤，同时保留有意义的失败修复。

**竞争解释H_alt：**损伤主要来自Δc或两分支有益的相互补偿；删去`ΔP*c0`会同时损失修复，或者任何等量缩小/改动都能产生同样效果。

这里的分解是代数事实，H不是事实。不同P/c坐标可以表达同一logit；某项幅度大不等于其因果责任大。必须通过定向删除、假干预、幅度控制和同预算训练判断。

## 3. 同一个实验的因果干预和方法训练

### 3.1 同一checkpoint的定向删除：定位实际损伤来自哪项

使用同一PC checkpoint、同图P0/P1/c0/c1、同最终输出身份，预登记全部原成功及原失败GT，不只挑198个被损伤的GT：

1. **PC原输出**：`z_A=P1*c1`。
2. **定向删除**：`z_B=P0*c0+P1*(c1-c0)`，只删除`ΔP*c0`，其余学习结果不动。
3. **假删除**：`z_C=z_A-permute_ROI(ΔP*c0)`。在首阈值前实际输入尺度的固定预测框ROI内，用固定非恒等排列，保持被删除项的RMS，破坏它与像素的对应；框外按原裁剪处理。所有方法取得相同张量，不增加可训练容量。
4. **单纯缩小对照**：`z_D=z0+a*(z_A-z0)`，a只由B的实际响应变化RMS解析确定，不读取GT、不按IoU选a。

主要比较B与A/C/D；逐项查看修复保留和成功损伤，不以logit范数或连续loss替代正常原图掩码。若假删除变成一般随机破坏，不能单凭B优于C归因，仍需同时超过无噪声的D，并保留修复。

为排除仅仅去掉更多改动，另把A/B/C在**训练拟合部分**按共同响应幅度规则校准，评价时规则冻结；幅度基于完整正常输出、无GT，原生decoder不改。实际硬阈值前变化的RMS及分组分布必须报告，不能只配参数范数。若控制不能有效匹配则只记设计未完成，不静默放宽或删样。

对分解的坐标敏感性做必要审查：只在训练拟合图估计P1向P0的通道配准，并将c1作逆变换，先证明联合PC输出不变，再复查定向删除结论。若结论只存在于一个任意通道表示，不得称“P漂移机制”成立。配准残差与非可逆性不能靠验证GT修补。

### 3.2 同预算重新训练：检验机制约束能否成为正常方法

四臂是一个完整实验，不是四轮顺序试错：

| 臂 | 原生响应与学习响应 | 用途 |
|---|---|---|
| C | P0*(c0+Δc) | 固定P原生系数头参照，参数较少，不承担纯容量归因 |
| PC | P1*(c0+Δc) | 无额外约束的共同适配 |
| PC-anchor | P0*c0+P1*Δc | 原生响应固定，P仅为新增系数修正服务 |
| PC-sham | PC减去固定空间错配的ΔP*c0 | 与anchor相同P/c参数、输入及额外计算，检验删对位置是否关键 |

PC三臂使用相同可训练P/c路径与参数数目、同一官方初始化、同数据/顺序/监督/原生保护loss/AdamW/更新数。**不改loss、门控、训练样本选择或基础模型其余部分。** 两者起点均ΔP=Δc=0；anchor的P梯度在Δc=0时为零是设计性质，须预登记、核对后续P能获得梯度，不把首步零梯度当实现故障。

建议首轮原2000训练图、3轮、1500步/臂，共6000步；仅是拟议预算，正式冻结前核笔记本完整F/缓存和资源。首轮采用2k不等于复现原20k PC失败条件；若该范围不出现所针对的取舍，只能说本次范围未复现机制前提，不能替旧Run下结论。

已有G作为同设备实际效用参照；G_budget同面板比较须有原checkpoint，缺失继续null，不能拿旧G冒充。主机制归因来自PC三臂的匹配比较，而不是不同容量的C或不同配方G差值。

## 4. 要得到什么结果，才会改变决定

机制阳性须同时出现：

1. 同checkpoint删除真实项比假删除和单纯缩小更能保护成功实例，且保住PC的大部分修复；不能只在训练点连续loss上获益。
2. PC-anchor在未参与拟合/校准的整图评价上，比PC及PC-sham形成更好的“修复—损伤”取舍；必要匹配比较用配对图像bootstrap，不能只比AP点估计。
3. 正常方法相对同配置原生及已有G的修复、全配对均值、原成功GT保护分别报告；损伤全体身份和bbox/segm匹配分开。

拟议的任务读数是原失败GT修复数、原成功GT损伤数/负向IoU变化，辅以正常完整AP。保护改善必须带修复非劣约束，防止通过零修正获得“安全”。**最低保护效应、修复非劣界、区间要求、样本/成本上限须在执行前依据已有未变更分布做功效审查并冻结；本文未假称已完成数值协议。** 原S2/S3门槛不追溯修改，新机制判断不替代效用门槛。

- **定向删除及匹配训练均阳性：**支持在此范围内“原生响应与修复响应分离”这一方法原则，进一步确认正常方法效用；不是证明所有PC失败都来自它。
- **定向删除有效、正常训练无增量：**只得到离线因果干预证据，方法未成立，停止本anchor训练配置，不直接扩量。
- **假删除/缩小同样有效：**不支持项特异机制，优先解释为幅度/正则效应，不包装为P漂移发现。
- **保护依赖丢掉修复，或真实项删除无效：**关闭本H的当前投入，不继续以P漂移解释PC失败。
- **输入/配准/幅度/统计精度无效：**明确证据不足；不能记机制阳性或阴性，按预冻结成本停止，不追加一串诊断。
