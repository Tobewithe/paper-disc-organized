# 主要 Idea 演变轨迹

只记录主要想法，以及促使想法变化的认识。按研究线续写，保留分支与回转，不把演变强行写成一条所有前案都被否定的直线。

## 猪实例分割

这条研究线围绕一个问题展开：**怎样让模型获得并利用关于猪的知识，从而更好地区分接触、遮挡中的不同实例？** “知识保存在哪里、怎样学到、怎样用于任务”不断变化。

| 主要想法 | 核心变化与推动它的认识 |
|---|---|
| **跨图像的视觉原型字典** | 将反复出现的猪体与场景模式压缩成可检索记忆，为当前图像补充知识。随后发现，仅有相似特征中心，未必能够表达一头猪的身体结构和实例差异。[来源](../../paper/manuscripts/spm_yoloseg/RESEARCH_CHARTER.md) |
| **有身体结构的对象模型** | 从“存一组特征”转向“保存一个可变形、可摆姿态、能解释不同观察的对象”，引入规范身体位置与可见性。进一步意识到，几何结构存在与图像中的身体对应可靠，是两回事。[来源](../../paper/manuscripts/spm_yoloseg/OBJECT_PROTOTYPE_DESIGN_V5_20261023.md) |
| **具名的对象与部位记忆** | 希望知识具有明确内容：整体、部位、遮挡、边界，并直接服务检测与分割。问题随之变为：知道词条表达什么，并不保证当前实例能够找到、用对它。[来源](../../experiments/spm_semantic_dense_task_20261025/REPORT.md) |
| **让被匹配的内容真正参与重建** | 从“检索后交给自由任务头”转向“由实际匹配的整体—部位内容组合出掩码”。新的认识是，形式上的组合约束仍可能留下绕过语义的自由度，结构看起来合理不等于概念发挥了作用。[来源](../../experiments/spm_content_constrained_memory_20261026/REPORT.md) |
| **在共同坐标中组织对象与部位** | 将关注点移向当前图像内的实例归属，让对象与部位在同一图像坐标中读取、交互或竞争。需要区分：一般实例条件处理的价值，与具名部位关系的额外价值。[来源](../../experiments/spm_registered_object_head_20261027/PROTOCOL_V1.md) |
| **把知识写入训练，而非依赖部署时检索** | 改为利用合成的同实例、同表面对应，在训练期施加原型约束，让知识留在原生模型中。知识不必表现为一个常驻记忆库；但正确的局部对应，也未必就是最终任务需要的知识。[来源](../../experiments/spm_rlpl_pipeline_20261101/FINAL_REPORT.md) |
| **用明确的猪体概念监督原生表示** | 从匿名原型分配转向头、躯干、前肢、后肢、尾等明确标签，利用合成数据直接教概念。逐渐分清：部位能够被预测，与部位知识改善实例分割之间，还隔着任务使用这一层。[来源](../../experiments/spm_pig_concept_training_design_20261101/DESIGN.md) |
| **让概念监督对齐实际实例读出** | 从全图“哪里是猪头”转向“这是哪一头猪的头”，让承载实例Mask的原生表示同时承担所属部位预测。重点由增加概念种类转为连接概念身份、实例归属与任务输出。[来源](../../experiments/spm_concept_native_training_20261102/PART_TO_INSTANCE_INTERFACE_DISCUSSION_V1.md) |
| **把分配、概念监督和Mask读出一起考虑** | 进一步追问：哪些候选获得哪个实例的监督，会不会限制概念的作用？将普通Mask质量与正确部位对应的作用分开考虑，避免把所有改变都归为“学会了猪知识”。[来源](../../experiments/spm_concept_native_training_20261102/ASSIGNMENT_AND_PART_SUPERVISION_DISCUSSION_V1.md) |

这条主线之外，还出现过两个重要分支：

**直接迁移已有任务知识。** 将已有较好掩码中的纠错知识传给原生读出，优先学习已经体现任务价值的内容。这与“先学概念，再期待任务受益”具有不同出发点；它没有取代用户希望保留的概念学习目标。[来源](../../experiments/spm_task_aligned_head_transfer_design_20261101/REVIEW_AND_ROUTE.md)

**暂时放下模型和概念预设，重新理解实例可分性。** 将问题开放为三种解释：实例关系没有被有效组织、相关条件覆盖和迁移不足、单帧观察本身缺少信息。由此重新比较普通实例训练、概念知识和额外观察，而非默认继续修改同一模型。[来源](../../literature_search/pig-instance-open-analysis_2026-11-02/summary.md)
