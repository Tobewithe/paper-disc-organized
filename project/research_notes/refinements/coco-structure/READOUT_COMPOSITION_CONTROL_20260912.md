# 类别、大小及框质量共同分层后的错误对照

2026-09-12。状态：COMPLETE，纯统计续作，未训练新模型。复用S024的300张留出train2017图片、1,815个原框匹配目标；它们是开发诊断数据，不是最终确认集。

## 结果

按类别×COCO大小分层，仅保留高/非高两组各至少3个目标的格子，再用两组较小样本数作为共同权重。共有23个格子，保留高230/266、非高680/1549个目标。进一步加入原预测框IoU区间[.5,.75)、[.75,.9)、[.9,1]，共有22个格子，保留高175/266、非高523/1549。下表为高减非高，数值单位为百分点，区间为2,000次图像簇重采样。

| 指标 | 类别×大小 | 类别×大小×原框IoU |
|---|---:|---:|
| 固定归属Mask IoU | −5.39 [−8.26,−2.23] | **−3.24 [−6.54,−0.60]** |
| 同类邻居误分 / 自身GT面积 | +12.26 [+8.03,+16.18] | **+9.67 [+5.48,+14.08]** |
| 背景误分 / 自身GT面积 | +3.54 [−1.91,+10.99] | +4.87 [−1.68,+13.47] |
| 自身覆盖率 | −2.30 [−4.08,+0.05] | −1.40 [−3.78,+0.81] |
| 框内同类邻居可用面积 / 自身GT面积 | +60.39 [+50.54,+66.81] | +58.03 [+49.37,+65.88] |
| 已匹配目标中的官方Mask75失败率 | +8.28 [−0.76,+14.63] | −0.62 [−8.49,+7.37] |

邻居条件误判率需只看存在邻居像素的目标，因而使用自己的共同支持：类别×大小下高185/非高290，差+1.29[−5.17,+6.84]点；再加框IoU后高144/非高215，差−3.07[−9.41,+5.22]点。没有建立高组条件误判率更高，也没有证明两组等价。

## 对主线的含义

在这套粗组成控制下，高组依然有更多同类邻居误分和更低固定归属IoU。因此“预测框内的实例归属错误”仍有直接研究依据，不能仅归为高组包含更多小目标或某些类别。

但尚不能说已经解释全部高拥挤召回缺口：加入框质量分层后，当前共同支持子集的官方失败率差没有正证据。两列目标集合和权重均不同，不能把8.28→−0.62解读成框质量解释了8.90点，更不能以此宣称框是唯一根因。框质量可能处于拥挤影响的路径上，对它条件化本身也不是随机干预。当前结果支持保留掩码与框的联合影响，避免把“有bbox50匹配”写成“框问题已排除”。

最稳妥的工作表述是：**高拥挤实例在相近类别、大小和粗框质量条件下仍承受更大的同类邻居误分负担；错误量上升与邻居像素暴露增加相容，条件辨别难度是否更高尚未建立。**这是实证定位，不是新颖性或严格因果证明。

## 执行与限制

原注释数据由既有缓存中的官方JSON子集读取，其SHA与缓存回执一致；另外核对完整官方JSON SHA。保持原框50身份并计算实际框IoU。统计只操作保存的预测，不更新模型。各bootstrap按原300图配对抽样并重新计算共同权重，原始入选格子固定。
