# S056：固定失败实例的错误修复收益与自动竞争

2026-09-13。本地 conda pytorch，复用官方权重 one-to-many+NMS 路径的完整 COCO val2017 预测。5,000图、36,335普通GT、446,097最终预测，运行385.641秒；没有训练、新模型前向或依赖安装。官方基线Mask AP重放至1e-12以内。

## 1. 直接结论

**同类邻居误报是有针对性的密集改进目标：给定GT的精确删除在全val只增加0.378 AP，但使高E(4)组R75增加5.035点，高低差距缩小5.026点。背景修复的整体AP空间更大，却没有显示缩小拥挤差距。**

这说明选择研究对象不能仅看错误像素总量。它是输出层的干预证据，尚未定位错误由哪一网络模块产生，也不是训练方法已经取得的收益。

## 2. 协议与范围

- GT修复只针对S048固定的一对一bbox50归属中，同一预测槽位Box IoU>=0.75、Mask IoU<0.75的5,575个GT。其他所有预测保持原样，原框、分数、类别、排序和候选数量不变。
- 将错误像素分成自身遗漏、同类独占、异类独占、同时被同/异类邻居标注覆盖、背景五个互斥分区。自身GT优先，crowd不计普通错误。误报各区可加回总误报；比率统一用有效自身GT面积归一化。
- 同类删除包含同/异类歧义区，异类删除只处理异类独占区；另存歧义区原始计数。自身补全可能超出原裁切支持，完整GT替换也不是当前decoder可实现的保证。
- 两个自动对照在原预测score>=0.10的同类正掩码交叠处竞争，分别用类别分数优先或预测框归一化中心距离。没有GT、ICI或失败标签输入，没有用评价集挑阈值；低分槽位保持原样。自动臂作用范围比GT修复广，不能把差值直接解释成单一信息差。
- 所有臂用官方COCOeval在完整GT上重新匹配，之后按预先固定的GT边界接近度E(4)分层。高组9,453、低组21,391、中组5,342、不可定义149。E(4)不是ICI；两套结果不混用。

GT同类删除共改变1,781个槽位；它包括“并非主导错误，但仍有部分同类误报”的目标。高组净恢复476个Mask75匹配；低组净恢复2个。按图片簇2,000次配对bootstrap，高组变化CI为[4.582,5.488]点，低−高差距变化CI为[-5.478,-4.571]点。背景修复的差距变化为+0.261[-0.444,1.042]点，未确认差距缩小。

六种GT干预的数值不是可相加的AP分解。它们是当前固定归属/修改规则下的诊断收益，不能预期实际方法复制这些数字；AP区间没有计算，不从R75区间推断AP显著性。COCO val已用于探索，不称盲测。

## 4. 失败分类更正

S055用整个连通分量的预测并集对单个GT计算泄漏，会把邻居自己的正确输出算成目标错误，且混用了分母；旧错误表面结论撤回。O子型还错查了GT–预测IoU表，duplicate_like数量撤回。拓扑本身的M/X计数保留。

接回S048固定槽位后，高组2,073个M/X中有546个Mask75已经成功。其389个框好掩码差目标里，按S048同类优先分区：同类误报主导186、背景131、自身遗漏60、异类12。全高组框好掩码差1,526个的主导错误为背景714、自身遗漏379、同类371、异类62。因此M/X只是一项候选关系特征，不能直接当失败标签或全体密集失败机制。

## 5. 方法决策

1. 保留“纠正同类像素归属”作为缩小拥挤差距的候选主线。当前证据定位了值得解决的输出错误，尚未证明系数相似、某个特征层或监督方式为自然根因。
2. 停止将全局分数抢占或框中心硬切分直接作为方法。这两种具体规则在完整COCO退化；不据此否定所有可学习竞争。
3. 后续学习需要识别竞争者是否可信，并保护目标自身像素，尤其不能把同类正掩码重叠一律判为错误。训练可使用GT归属标签，最终推理只能使用预测候选与特征。已有S013排序损失、旧同容量邻居MLP没有建立优势，不能重复同一配方再命名创新。
4. 现有整套数值来自显式one-to-many+NMS。S057单独比较同权重的原生one-to-one路径，避免把某一路径问题外推为整个YOLO26架构结论。该项运行状态以自己的COMPLETE回执为准。
