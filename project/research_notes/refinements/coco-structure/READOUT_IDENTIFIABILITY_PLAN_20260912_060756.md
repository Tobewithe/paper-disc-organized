# 区分读出利用不足与实例空间条件不足：S023—S025

日期：2026-09-12。状态：PLAN，未启动拟合或正式训练。本方案继续S021/S022，采用experiment-plan；用户要求先解释如何区分，不把实验计划写成已证明的新机制。

## 1. 待检验的两个解释

原预测写为 c_i=W h_i+b，z_i(x)=c_i^T P(x)。h_i是实际执行的系数分支最后1×1卷积之前、候选位置上的特征；P和整张特征图H都是同一个冻结模型的输出。S022已经验证该线性关系和候选身份。h_i已有上游感受野，不能断言它没有接收周围信息。

- H1：给定现有h_i，存在比当前W更好的共享映射，能够跨图提高掩码质量。若同输入读出在留出图上有效，至少部分信息可被利用；不意味着原训练操作错误。
- H2：在预算相当的读出下，显式提供与该实例对齐的周围空间特征，比仅有h_i更有效。这里的“缺少”是当前接口下的任务可用信息不足，不是信息论上证明h_i完全不含实例身份。
- 反向解释必须排除：多参数、额外拟合、普通区域内容、更大观测范围、标签/框改变、仅调阈值、只记住开发图。H1和H2可以同时成立。

S021的oracle只证明固定P/框下存在更好的系数组合，没有证明该组合能被共享函数预测。S022的单图最后层梯度结果不支持立刻改为梯度冲突主线，亦未排除历史跨批次/更深层问题。官方权重的train_args已记录mask_ratio=1；本实验不再假设低分辨率预训练导致缺口。

## 2. 最小实验矩阵

所有臂冻结主干、neck、系数分支最后层之前的特征H、原型P、候选来源、框、类别与分数；输出仍是单个32维系数和原官方解码。新增空间输入只从同一个H抽取，不混入新主干、高分辨率图像或额外原型通道。训练GT只进入匹配/损失，不能进入任何部署特征。

| ID | 改动 | 用来回答 |
|---|---|---|
| A | 原系数c_i | 冻结基准 |
| B | 仅重拟合最后线性层W,b；输入仍为h_i | 原映射是否尚有可学习余地 |
| C | 同h_i的非线性残差读出；h_i重复填入区域输入槽 | 更灵活的读出能否利用现有信息；是后续的强同容量对照 |
| D | 同C的网络，加入区域内空间特征的平均值，重复到所有区域槽 | 收益是否只来自额外区域内容 |
| E | 同C/D的网络，加入正确排列的区域特征格 | 实例对齐的空间内容/排列是否进一步有用 |
| F | 与E同一批区域特征值，但每实例独立随机打乱内容与位置的对应；训练、评估均使用该分布 | 去掉可靠位置对应后，收益是否消失 |
| G，条件执行 | 与E结构相同，将整组区域特征替换为同图其他相似预测目标的区域特征 | 收益是否依赖内容属于当前实例，而非通用额外上下文 |

基础位置编码若使用，必须所有C—G相同；不得只给E坐标/预测框信息。先完成不额外添加预测框元信息的h-only/B/C检查；若后续共享元信息包含预测框几何，必须补C_h与C_h+geometry对照，避免把框几何收益称为原h可读出性。所有结构从零残差恢复原预测。

C—F使用完全相同输入槽数、隐藏宽度、输出维数、可训练参数、初始化、损失像素、优化器、训练顺序和更新步数。输入处理带来的采样/内存/FLOPs差异单列；参数相同不等于有效函数复杂度完全相同，不作过强等价断言。C至少采用不弱于已完成S013的普通BCE+Dice残差容量，并保留S013同输入73维普通监督为上下文基线；跨数据/标签配方成绩不直接相减。

固定区域设计：预测框中心不变，宽高乘1.2，按固定3×3格从同尺度H双线性采样，网格相对位置固定；最终掩码仍裁切原预测框。区域扩张只是输入观测范围，不是外扩评价。D/E/F读取完全相同的9个向量；D使用均值，F使用内容随机置换。不要按GT邻居位置挑采样点。区域大小/格数本轮不扫参。G只作有其他预测目标者的次级对照，报告缺少替换对象的分母。

F不能只用全数据同一个固定置换，固定置换可被网络重新学习。F的训练置换按seed/epoch/image/source哈希，评估使用预注册的多个确定性置换并报告方差；不得将E训练好的模型只在测试时打乱后下降，当作空间机制的唯一证据。若F仍能从内容重新推断布局，E≈F也不能证明位置无用。

## 3. S023：先检查同输入可拟合性，避免无效阴性

先32张COCO train图完成数据/解码和小样本拟合检查，仅作开发。包括全部符合原固定训练匹配的目标，不只选低IoU目标；不把这32图的结果叫泛化。

对B额外做一个受控凸探针：冻结h、P、原生640标签、损失支持、每实例权重，最小化

L(W,b)=Σ_{i,x} w_ix [softplus(z_ix)−y_ix z_ix] + λ||[W,b]−[W0,b0]||²,
z_ix=P(x)^T(W h_i+b)，w_ix≥0，λ>0。

对W,b而言z线性，BCE对z凸，正二次项严格凸。该事实只适用于冻结特征/支持的此探针；正式Dice/非线性网络不享有这个结论。双精度优化记录梯度范数、相对目标变化、迭代上限；从原W和预设扰动初值核对目标值，触上限标未收敛而非“信息不足”。λ必须开发阶段预注册并附一个预定较弱正则敏感性，不能用任意强正则制造不可拟合。

并行比较逐目标自由系数、B共享线性、C同输入非线性在相同图/像素的损失与固定目标IoU。自由系数只作为已找到的解，不称全局IoU上界。拟合损失改善而IoU不改善时，优先解释为目标与评价差异，不能直接归因信息不足。不存在通过有限几个探针的失败严格证明信息不存在的方法。

## 4. S024：跨图输入对照

数据来自远端原COCO train2017。预注册哈希选取1,200拟合图和不相交300开发图；首先核对实际可用图片和历史暴露ID，写不可变清单及SHA，不按ICI或模型失败筛图。同一图全部实例必须在同一split，多polygon仍为一个annotation ID。

COCO val2017全部5,000图作为冻结设置后的探索评价。它已在项目中多次被查看，不能叫全新独立确认集。独立图片指没有参与新增读出的训练/调参；官方预训练见过COCO train，必须如实披露。未来论文确认需要另外冻结的验证安排，不能通过重命名已探索val解决。

仅训练小型读出，三个配对随机种子0/1/2，初始预算15轮、每轮checkpoint、固定最后轮；普通监督对照和空间臂相同预算。优化器Adam，候选初始lr=1e-4、batch images=8；先由同输入32图检查有限性/可下降性，若失败只在开发集调整且所有臂共同重跑，修改协议版本。原型保持640网格原生监督的一致解码；不得为了省显存回退到160再重引入已排查混杂。

训练目标沿用同一官方原生640监督/面积归一化BCE；为超过现有强普通监督，再共同加入Dice形成主可部署读出比较，不能把损失变化只给E。开发后若选主目标，C—F必须一致。S023纯BCE机制探针和S024 BCE+Dice方法比较是两张表，不能直接将其差值解释为输入贡献。禁止监督oracle系数的逐维MSE作为主目标，系数不唯一、尺度亦不唯一，应监督输出掩码。

若采用像素采样，必须来自同一原生640支持、各臂/种子配对固定相同样本；记录分布及权重，32图与完整像素目标核对。不能把有偏前景过采样称完全官方目标。未匹配/空监督目标的数量单列，不从整图任务评价删除。

## 5. 决定性指标与密集范围

主任务：原JSON官方COCOeval Mask AP/AP75；先对完整预测/GT做官方匹配，再按GT实例ICI统计Mask R75和同类相邻对同时恢复率。不要裁掉低拥挤GT后重新匹配，也不要把单目标oracle的IoU≥.75比例叫COCO Recall。固定框/类别/分数应使Box AP完全相同，是实现见证。

空间定位：用原始预测的一次固定类别内1对1框匹配，不随新mask重新挑目标；平均Mask IoU、自身coverage、独占同类邻居错误/自身GT面积、背景错误/自身GT面积、有效域own-v-neighbor AUC。分别报告匹配分母、所有任务GT分母、缺少邻居像素的AUC分母、crowd排除规则。正常原预测框是主结果，外扩曲线不作成败依据。

ICI_same=sum同类GT框相交面积/自身框面积；取0、(0,.5]、>.5，保留1e-10边界容差。它不是实际mask接触或物理遮挡率。病例低/高差异须同时报告类别、面积、stride、原始框IoU、原始mask质量分层。只有高组收益为正不等于“密集特有”：须比较高低增益差及共同组成标准化后的交互。

三种子逐种子报告，先计算配对臂差。主要预注册比较E−C（超过同输入强读出）和E−F（可靠位置对应的额外价值），D帮助解释区域内容；2,000次图像簇配对bootstrap、主要比较作Holm校正并披露探索性。种子样本标准差与图像CI分别报告，3种子不是独立训练随机性的完整置信保证。

机制推进门槛：E相对C、F在高组固定匹配IoU的配对区间支持正改善，且高组R75同向、邻居错误减少，自身coverage没有靠缩小mask换收益；coverage预注册非劣界0.5百分点。全量AP不能只看原模型对比，须看E相对最强同预算对照。若用于方法路线，再要求每个种子Mask AP增量同向并报告AP配对图像重采样；计算成本另行测量。未过此门槛保留诊断，不包装成功方法或在val筛类别补救。

## 6. 结果应怎样解释

| 观察 | 支持什么 | 不能说什么 |
|---|---|---|
| B相对A在留出图改善 | 同h线性映射仍有可利用余地 | 原训练有操作错误；全部失败都是优化问题 |
| B有限、C改善 | 所测非线性读出/容量可利用更多现有h | 已证明信息论瓶颈；只需无限增大头 |
| C和E都改善，E还有增益 | 读出利用和额外空间条件可以并存 | 两假说非此即彼 |
| D≈E且都超过C，F也有效 | 额外区域内容有帮助，排列贡献未立住 | 相对位置是核心机制 |
| E超过C/D/F，正确实例内容也优于G | 支持实例对齐的空间证据提升读出 | 严格证明原h不含空间信息或已有新颖方法 |
| E只超过较弱B，不能超过C | 可由普通读出能力解释 | 空间创新成立 |
| C训练拟合好、留出失败 | 该读出/预算下泛化问题 | 特征一定没信息 |
| C训练拟合差、E好 | 空间接口更利于拟合，继续排优化/容量 | 仅一次失败证明h不可分 |
| 全部共享头都差，但自由系数好 | 逐目标oracle尚不能由这些共享映射实现；定位未完成 | 原型完美、系数头就是确定根因 |
