# 邻居替换为背景：区分检测、裁切与掩码响应的配对诊断

## 核心问题

保持目标 A 的可见外观和标签不变，去除邻居 B 的可见外观后，A 是否被更准确恢复？改善发生在候选/分类、预测框、掩码响应，还是它们的相互作用？同类相邻是否比异类相邻、同类不相邻具有更强的影响？

这是冻结网络的输入和内部计算干预，不是再次用 A 的 GT 优化系数。GT 用于限定修改区域、原始候选归属和评价。尚无证据把“删除后变好”直接写成自然拥挤的因果效应或新方法成绩。

## 1. 输入、样本及不变项

- 模型先用已有固定官方 yolo26m-seg.pt、本地已验证私有 Ultralytics 8.4.143 运行路径，FP32、TF32 关闭。固定输入尺寸及预处理；不更新权重/BN。保存原始候选 source index，不能用每次 NMS 后行号冒充相同候选。
- 首批计划最多64张 COCO train2017图片，按确定性哈希选择，优先排除此前新增适配与探索使用的图片。实际可用池、排除清单、图像及 annotation ID 先写 manifest；在它生成前不声称队列已锁定。官方预训练本身使用过 train2017，不把这批图称为预训练未见。
- 三组关系：同类相邻、异类相邻、同类不相邻。每组按预定几何规则取最多一对/图，不按干预后的改善选样。相邻可沿用 GT bbox IoU>0.05，但额外报告实际掩码距离和目标/邻居可修改面积；ICI 保持原图的逐实例值。
- 初始分析同时保留原本成功与失败目标。主要掩码诊断子组：原图同类一对一归属候选 Box IoU>=0.75 而 Mask IoU<0.75；Box IoU>=0.90为更严格辅助读数。另列原图框不佳/无匹配及框掩码都好的目标，禁止按修改后的框质量重分组。
- Box IoU门槛不等于框完美；另报原预测框对目标GT的覆盖比例。原图宽松bbox50匹配只做已有归属，不作为“框很好”的判据。
- A自身所有可见GT像素、GT框、GT掩码不变；只编辑B中不属于A、其他普通实例或crowd的可见像素。保护全部其他已标注实例，报告B被编辑比例和因共享标注不能编辑的比例，不重建A被遮挡但未标注的部分。

## 2. 最小输入对照

| 输入 | 用途 |
|---|---|
| 原图 | 所有目标的固定基准 |
| 邻居独占区域替换为背景 | 主干预；目标自身像素保持逐值相同 |
| 原图背景区域的同预算修改 | 控制修改面积、边缘和距离造成的一般敏感性 |
| 原区域原样回填 | 路径与合成过程零修改见证，应与原输入完全一致 |

主替换预先固定两种填充：图内已标注对象外纹理供体、基于局部背景颜色/纹理的非生成填充；各固定3个填充种子，不按模型分数挑最好图。它们用于检查填充依赖，不是3次训练种子。首批不使用生成模型重绘整图。若将来确需生成式编辑，应另立方案并保存模型/提示与图像。

不能将“未标注普通实例区域”无条件称为绝对纯背景；供体区域检查、候选供体数和失败原因均记录。融合只允许在编辑区域内部，不能羽化改动A。黑块/模糊只能作附加敏感性测试，不能作为移除邻居语义的唯一证据。

背景修改对照优先同图、同形状、同面积并接近原目标距离；无法同时满足时标明匹配差及缺失，不伪称严格等价。图像输入的像素变化支持、面积及A上最大绝对像素差写入回执。

不同邻居类别/距离组仍可能有面积、可见率、纹理和场景组成差异。对目标类别、大小、原框质量、目标—邻居距离、编辑像素量进行共同支持比较，报告保留数量。组间干预效应差是有条件比较，不是纯语义类别的随机干预。

## 3. 先把框和掩码响应分开

原图固定候选的框为 b0，完整未裁切响应为 z0；编辑后同一原始source位置的预测为 b1、z1。所有解码遵循同一已验证官方顺序和阈值。四格评价固定 A 的原始GT：

| 组合 | 要回答的问题 |
|---|---|
| z0，b0 | 原预测 |
| z0，b1 | 只更换裁切框的影响 |
| z1，b0 | 固定原框，响应本身是否改善 |
| z1，b1 | 同一源位置的联合变化 |

这四格仅分离固定候选的裁切与响应作用，不能把两个增量相加称总因果贡献；记录交互。z1包含原型、系数及上游特征共同变化，不等同于仅系数效应。

同时跑每幅图完整正常预测，单列A是否被正常分类/保留/恢复及Box/Mask匹配身份。固定source诊断即使有好mask也不能当作真实检出：编辑后分数、类别、NMS竞争可能变化。无原始归属目标留在正常预测分析和失败计数，不能强制选修改后最好候选进入固定source表。

编辑改变了B的真实内容，所以首轮只评价未被编辑的A及已明确保留目标，不将原图完整COCO标注直接用于编辑后全图AP。最终方法成绩仍须回到未经编辑的自然COCO图片。

## 4. 主读数及误差区域

- 首要：正常预测A的Box IoU、Mask IoU、Box75/Mask75恢复；固定source四格的原始COCO域Mask IoU。
- 分开看自身覆盖、原邻居位置误报、原背景位置误报及原框覆盖上限。所有误差区域沿用原图几何；被擦掉的B原位置仍统计为“原邻居位置误报”，不因名字变成背景而自动制造泄漏下降。
- 所有对照共用原A的GT、像素分母及原ICI分组。统计原图good-box/bad-mask、bad-box和good-both状态的转移；保留受损实例，不只报救回者。
- 配对差先按固定填充种子平均，再以图片为簇计算区间；三组关系的差分同时报告原始和共同支持样本结果。小pilot用于筛选路径，不附密集特有根因或正式AP声明。

## 5. 只有任务读数有信号，才向内部追踪

在目标A固定空间/原source读取早中层特征、neck、cv4最后层前h、系数c、原型P以及最终z。记录相对范数变化和方向变化，但不把变化大或余弦下降当作“更可分/更好”。同类分类相似本身不是错误。

先回答“固定b0时z1是否真正增加自身响应并减少原邻居/背景误报”。若成立，再进行小规模模块输出替换：在原图前向中注入编辑图指定模块输出，重新计算下游，同时做反向恢复及同面积背景替换对照。仅替换一个预先指定模块；零替换和全替换应分别重放原图及编辑图路径。

若额外检查 c0/c1 与 P0/P1 的四格组合，需要明确它是同模型跨输入的混合状态干预，可能出现本来不会产生的组合，不能作为可部署输出或唯一模块归因。优先要求作用与完整响应及模块替换一致；禁止只看 c 的余弦就复活CCL叙事。

## 6. 一次实验后必须作出的路线决定

| 主要结果 | 路线取舍 |
|---|---|
| 改善主要来自正常检测/候选保留，固定source响应未改善 | 查检测与候选竞争，不继续称系数根因 |
| z0/b1改善明显，z1/b0不改善 | 优先定位框/裁切支持与定位鲁棒性 |
| 原框足够好且z1/b0改善，超过背景修改对照 | 值得追掩码响应所受的邻居干扰 |
| 上述效应在同类相邻强于匹配的异类/远邻，并经填充控制仍成立 | 形成同类近邻干扰的候选机制，再做内部路径定位 |
| 改善在所有关系组类似，或主要随编辑量/填充方式变化 | 不支持密集同类特异性，停止对应主张 |
| 原图掩码本来失败，合理替换邻居也不改善 | 停止以邻居外观存在为该子组主要解释，转原生分支训练/一般读出问题 |

不能凭一次图像移除实验决定最终结构。可行方法须与定位出的路径对应，例如目标条件特征提取或训练时的受控上下文一致性；它们在本文件中只是条件候选，不是已证明新颖的方法。训练可正常使用完整GT；测试自然图像不需要人为去掉邻居。

## 与既有实验的区别和边界

S014是从同张原图候选池中选择已有框/系数；S022是固定图像最后层mask梯度；S024/S026/S045是固定已有特征的共享头学习；S046是使用GT点临时优化系数。本方案改变输入中的邻居，同时锁定A外观和原候选身份，针对前向影响路径，不重复逐实例GT优化。

没有承诺自然背景真实还原，也不将操作称为完整场景的真实反事实。背景填充带来的分布变化、移除多物体时的场景关系变化、保护掩码边界残留、上游感受野重叠均应保留为限制。
