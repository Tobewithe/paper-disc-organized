# S014之后：从GT辅助交换到无GT候选选择

2026-09-12。性质：方法设计，尚未实施本文件实验、未启动训练。不将S014诊断收益写作方法成绩。

2026-09-12 优先级更新：S015 已完成（NO_CANDIDATE_READOUT_RESULTS_20260912.md），无合格候选子组中固定P和框的自由系数可恢复大量目标，故本候选选择设计暂保留为次要分支；下一步优先追实际监督分配与系数头条件输入，不按本文件直接启动选择器训练。

## 所解决的具体问题

在当前one-to-many＋NMS运行分支，保留原预测框、类别、分数及实例数量，为每个保留预测选择更适合该实例的掩码系数。第一版只选择现有系数，不生成自由残差系数，便于将收益定位到候选选择。

关键区别：S014用GT框IoU≥0.5定义候选池，再用GT mask IoU选最优；而且选择依据是替代系数＋替代框的完整掩码。实际方法必须消除候选池和选择器这两处推理GT，并把学习标签改成替代系数＋原框的实际质量。

## 第一步：验证真实可用的候选池

对于每个最终保留候选i，G_i={i}∪{k: first_suppressor(k)=i}。全部信息来自实际NMS重放，不使用GT、ICI、GT匹配或正确类别标签。训练和推理采用同一规则。候选k本身的argmax类别由NMS分组决定。候选池只是相关预测组，不预先称为同一GT。

第一项无训练检查同时报告全直接压制池和资源受限池：保留原候选，再取该池分数最高的最多7个被压制候选，共最多8个。8为工程起点，须在train开发数据上固定最终预算；同时报告候选数量和推理耗时。池之间按首个压制者互斥，避免同一raw来源被多个最终实例重复借用，但不同来源仍可能画成同一目标，任务重复FP不能省略。

固定同图P与原框B_i，定义M_ik=官方解码(P,c_k,B_i)。不可用替代框B_k的mask IoU训练选择器，却在推理时裁回B_i。

只在诊断评估阶段用真实G_i对应的目标GT计算池中最优M_ik，和原M_ii做差；混入相邻GT的候选原样保留，不能用GT提前去掉。报告原固定匹配/未匹配状态、可恢复GT数、GT辅助四组整图AP/R75、像素与重复FP，并统计S014原最优替代的池内保留率。若该池机会很小，停止该池上的学习，不因S014大池oracle收益而默认可行。

## 第二步：让评分与最终使用方式一致

训练图按完整COCO标注确定原保留候选i的固定bbox50目标a(i)，只用于监督，不能作为预测输入。训练标签为：

q_ik=IoU(M_ik,GT_a(i)); delta_ik=q_ik-q_ii。

固定a(i)对于所有k不变，不为每个替代候选重新寻找最有利GT，否则会奖励换成邻居。crowd/无有效GT、未匹配预测单列；未匹配预测也进入训练和推理流程，首版以保留原预测为监督，不能只对测试时已知匹配的预测启用方法。bbox50匹配只定义诊断/选择监督，不冒称原模型的训练assigner。

轻量预测器输出预期改善delta_hat_ik。第一版用平滑L1回归真实delta，按父候选/图像平衡，避免多候选目标支配训练。是否增加排序项由开发集证据决定，不一开始叠加损失。q目标和真实像素域应固定；全图IoU与去crowd后的空间IoU分别记录。

输入仅来自预测与图像特征：

1. 原框内的backbone/neck局部特征，提供被保留实例的条件信息；不能只给候选分类分数。
2. 原系数和替代系数在同一原框下形成的logit/概率小图，以及二者差异；使用由P实际解码的响应，使输入包含当前原型的意义。
3. 原候选与替代候选的相对框位置、源点坐标、尺度层和分数。
4. 周围其他保留实例的预测框/掩码上下文，可作为单独消融条件；不得用GT邻居、GT拥挤度或GT泄漏区域替代。

“原型响应有意义”不等于完整跨图可辨识保证；冻结模型的输入分布和训练泛化仍需测。新方案与旧冻结残差头的主要差别是学习既有多个候选间的条件选择，并显式观察候选响应差异；不是把旧系数MLP改名。是否需要更强条件输入由消融决定。

## 第三步：允许保留原候选

在G_i内选预测改善最大的候选k*；只有delta_hat_ik*>tau才替换，否则使用原c_i。阈值tau在独立的train校准图上选定并冻结，保留原系数作为候选/无操作项。校准目标包括实际错误替换率、AP/R75及空间代价，不能声称tau自动保证不恶化。

主实验只替换系数，原框、类别、分数、预测槽位数固定。空掩码按既定官方约定处理并计数。这样Box AP应完全一致，可检查收益是否仅源于mask改变；评价仍须全图重新匹配、计重复FP，不能仅报告原目标IoU。

硬选择优先于复杂加权融合，便于看出是否选到了正确候选。简单均值、分数加权系数作为基线；线性系数平均对应logit平均，但阈值后的二值掩码质量没有单调改善保证。学习加权融合只能是后续分支，不能预先认定优于选择。

## 最小公平对照

所有选择器使用同一预测定义候选池、相同原框和输出预算。无GT评估应用于所有最终保留预测。

| 对照 | 要回答什么 |
|---|---|
| 原保留系数 | 原模型是否已足够好 |
| 池内系数均值、分类分数加权 | 能否仅靠简单聚合获得同等收益 |
| 普通mask质量回归头 | 是否只是已有质量评分的直接应用；同样预测固定原框下的质量 |
| 条件增量选择器，不看邻居 | 父候选条件与替换收益学习是否有价值 |
| 同容量条件增量选择器，看预测邻居 | 拥挤上下文是否带来可重复的额外收益 |
| 预测定义池中的GT最优替代 | 仅标为诊断参考，量化学习还未利用的空间 |

普通质量头须获得合理的图像特征和mask输入，不能故意削弱为只看分类分数。若增量选择器比质量头多信息，做输入/容量匹配比较，区分信息和训练目标贡献。若最后只有普通质量头有效，报告有用基线，不宣布新机制方法。

NMS阈值/Soft-NMS类对照放在第二组候选筛选实验，同样限制输出数量并报告速度；它们允许检测候选变化，不能与固定框的系数实验混为一种因果隔离。

## 数据与停止规则

第一步复用远端COCO现有缓存做无训练机会检查。实际训练数据从完整train2017按固定ID哈希选取，并保留按图像互斥的拟合/开发/校准集合；不按GT高拥挤筛掉其他图。所有组共享数据、候选预算、训练预算，三个训练随机种子。当前300图及已反复查看的val只能作为探索复核；不得重新划分后叫从未使用的确认集。独立确认需另行冻结未用于方法选择的评价资源。

启动训练前锁定一项主比较和实际效应门槛。主指标：高组正常Mask R75、整图Mask AP；同时报告低组、成对恢复、固定归属像素IoU/覆盖/邻居/背景、可接触邻居区域FPR、重复FP、实际运行时间。高/低组交互需考虑类别、面积与框质量；非劣门槛和阈值均在开发阶段确定。

停止条件：预测定义池缺少可用改善；学习不能超过均值/普通质量头；改善主要来自前景扩大导致邻居/背景增加；三种子方向不稳定。逐图oracle相关或回归误差小不能替代真实任务效果。

如果选择器成功，再沿raw source ID查更好候选的原网络监督分配、尺度及局部条件信息，决定将质量指导放在候选选择阶段还是原系数预测头。当前不将“分类头与mask头优化不一致”宣布为已证实根因。

已核对本地 papers/1903.00241.pdf 首页：Mask Scoring R-CNN（Huang et al., 2019, arXiv:1903.00241）已用实例特征和预测mask回归IoU。因此“学习质量评分”本身不足以主张新颖。学习抑制、mask候选融合等路线仍需系统查新；当前网页检索未返回可用内容，不据此宣布无人做过。

待验证的研究价值是：在共享原型架构中，检测候选选择连带决定了实例的mask读出；固定检测结果，通过实例条件评估从原本被丢弃的候选中恢复更合适的读出，是否特别有助于同类拥挤场景。需要实测、强对照、跨图泛化及进一步查新，当前仅是具体可实现假设。
