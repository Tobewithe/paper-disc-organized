## 1. 当前判断：需要换对评估单位，再决定论文主张

**当前图片分层结果没有显示高拥挤图片上的严格 Mask AP 优势；但它没有直接检验高拥挤实例是否改善。** 这两句话可以同时成立。

本次从原始 COCO GT 重新计算每个有效非 crowd 实例的同类别 ICI，得到了以下结构性证据。ICI 是同类别其他框与自身框交集面积之和除以自身框面积；它是框拥挤代理，不等于可见掩码重叠、真实遮挡率或因果变量。

| 集合 | 非 crowd 有效实例 | 自身 ICI≤0.5 | 比例 |
| --- | ---: | ---: | ---: |
| COCO val2017 全部 5,000 图 | 36,335 | 31,090 | 85.56% |
| 现有 COCO-Dense 1,576 图 | 20,827 | 15,621 | 75.00% |
| Q4 最拥挤 394 图 | 6,395 | 3,924 | 61.36% |

因此，Q4 仍有大量自身不太拥挤的实例。**这是存在稀释可能性的证据，不是 CCL 收益被稀释的证据。** COCO AP 还受类别平均、分数排序、误检与匹配影响，不能把上述实例占比直接当作 AP 的混合权重。

最新同一套导出预测与 COCOeval 下，CCL 0.1 相对 Baseline 的现有观测如下，差值统一为 AP 点，即数值差乘 100：

| 集合 | Δ Mask AP50–95 | Δ Mask AP50 |
| --- | ---: | ---: |
| COCO-Dense 全部 1,576 图 | −0.062 | +1.092 |
| Q1 | +0.030 | +1.533 |
| Q2 | −0.698 | −1.127 |
| Q3 | +0.211 | +0.844 |
| Q4 | −0.421 | −0.296 |
| Top 100 | −0.213 | −0.094 |

这些观测值得保留。它们既不能证明“高拥挤实例无收益”，也不能证明“只是被稀释”。下一轮实验要在这两个解释之间作出区分。

## 2. 只保留两个待检验主张

**H1：CCL 改善高拥挤实例的准确检出，且改善幅度超过低拥挤实例。** 主要看实例级 Mask Recall@0.75、高低拥挤之间的处理效应差，并用同等 Precision 下的 Recall 和标准 AP 检查代价。若只能提高 AP50，主张限定为较宽松 IoU 下的性能变化，不推断边界更准确。

**H2：在共享原型解码器内，相邻实例的系数几何是空间混淆的一个可干预因素，CCL 能利用这一因素改善 GT 定义的分离。** 需要 COCO 上的关联、受控系数干预和训练方法对照；不能仅由两模型的平均系数余弦和原生掩码互相重叠率推出。

ICI 在本方案中是 GT 分层变量，不作为独立算法贡献。论文重点放在“失败发生在哪些实例、通过哪个网络环节干预、对哪些任务错误有效”。

- 新 GT 子集逐条核验与原始标注完全一致：20,827 非 crowd + 344 crowd，含 2,100 个多多边形非 crowd 实例。原始单个 annotation 的多个多边形始终合并为一个实例，不能拆成多个 GT。
- 本次生成全 5,000 图实例清单 `COCO_INSTANCE_MANIFEST_20260911_032703.csv`，按 annotation ID 保存 ICI、类别、原始面积和现有图片组。清单未读取模型性能。
- 现有 val 曾参与检查点选择，且本计划已看过 seed 0 结果；后续分析应如实标记探索性。新种子复现能衡量训练波动，不能消除验证集选择偏差。最终若要严格独立确认，应另外固定不参与选模的 COCO 开发/评估划分，或使用可用的官方测试评估途径。

### 3.2 实例级主分层

对有效、非 crowd GT 实例 i，定义

\[
d_i=\sum_{j\ne i,\ y_j=y_i}\frac{|B_i\cap B_j|}{|B_i|}.
\]

使用固定边界，逐组完整报告：

| 实例组 | 定义 | val5000 实例数 | Dense1576 实例数 |
| --- | --- | ---: | ---: |
| I0 | d=0 | 20,981 | 8,672 |
| I1 | 0<d≤0.5 | 10,109 | 6,949 |
| I2 | 0.5<d≤1 | 3,537 | 3,507 |
| I3 | d>1 | 1,708 | 1,699 |

主要高低比较预先固定为 **H=I2∪I3（d>0.5），L=I0∪I1（d≤0.5）**；I3 作为极高拥挤次分析，不按效果挑选阈值。

历史图片筛选在计算最大 ICI 时跳过 bbox 面积<100 的参考实例，新实例分层保留这些 GT，并单独报告 tiny 计数。因此少量很小的高 ICI 实例会出现在历史低拥挤图片组或 Dense1576 以外，这不是清单矛盾。标准 AP 不丢弃这些小目标。

同时记录去掉同类别限制的全类别 ICI，作为预先声明的次分析：现有 CCL 的配对条件可能跨类别，不能默认训练配对与同类别 ICI 完全一致。`iscrowd=1` 区域保留官方 ignore 语义，不作为可一对一评分的普通实例，也不计入上述分母。

### 3.3 排除组成差异

每组输出类别、mask area 的 small/medium/large 分布、图片数和实例数。主结果报告全部 GT 的实例加权值；另做类别宏平均和类别×尺度标准化敏感性分析。

标准化时，只用 GT 预先确定 H、L 都有样本的类别×尺度单元及固定权重，所有模型共享。建议将两组各≥20 GT 且各≥10 图的单元作为稳定支持集，权重按两组混合 GT 频率归一化；列出纳入单元及其覆盖比例，报告全部数据的原始结果。支持不足时仅作描述，不通过不断合并/删除单元找正结果。权重与支持集在 bootstrap 中固定，不随模型或抽样重选。

## 4. 推荐指标：标准 AP + 实例检出 + 分离诊断

### 4.1 标准 benchmark 保留

对全 val5000 和现有 Dense1576 报告 Mask AP、AP50、AP75、APs/m/l、Box AP；现有图片 Q1–Q4 作为场景层次的补充结果。这里全部使用官方 COCOeval，不能把定制指标称为官方 COCO AP。

使用同一推断设置，冻结代码、包版本、权重哈希、输入尺寸、padding、mask 插值/阈值和预测排序。已有导出设置为 imgsz640、conf0.001、iou0.7、每图最多300个输出；是否实际经过 NMS 由该版本 YOLO26 路径确认，不能仅凭 iou 参数推断。官方 evaluator 使用 maxDets=[1,10,100]；启用类别评估时匹配与截断按 image/category 执行，导出端每图300的限制另行存在。

### 4.2 新增主要指标：按 GT 拥挤度分层的 Mask Recall@0.75

**先保留一张图里的全部 GT 完成官方匹配，再按每个 GT 的 d_i 汇总，不能先删除低拥挤 GT。** 不给低拥挤 GT 对应的正常预测制造假阳性，也不允许同一预测服务两个普通实例。

从 COCOeval 的 area=all、IoU=0.75、maxDets=100 匹配记录取 `gtIds / gtMatches / gtIgnore`。非忽略 GT 的命中指示变量为

\[
h_i^{(m)}=\mathbf{1}\{\text{模型 m 有同类别预测按官方规则匹配 GT i，Mask IoU}\ge0.75\}.
\]

定义

\[
R_{75}^{(m)}(b)=\frac{\sum_{i\in b}h_i^{(m)}}{N_b},\quad
\Delta R_{75}(b)=R_{75}^{CCL}(b)-R_{75}^{Base}(b).
\]

**漏检计0，不能只在双方成功匹配的实例上计算主指标。** 固定 IoU75 可直接回答“该拥挤实例有没有被足够准确地分割出来”。同时给出 IoU50、全部0.50:0.05:0.95阈值的 recall 曲线和阈值平均值；后者明确命名为 GT 分层平均召回，不冒充 COCO 官方类别平均 AR。

高拥挤是否更受益的关键比较是

\[
D=\Delta R_{75}(H)-\Delta R_{75}(L).
\]

在实例加权指标下，全量差值还可以准确分解为

\[
\Delta R_{75}(All)=\frac{N_H}{N}\Delta R_{75}(H)+\frac{N_L}{N}\Delta R_{75}(L).
\]

这才是直接检验“稀释”的可计算方式。**上述分解适用于该 recall，不适用于 AP。** 若高拥挤为正、低拥挤近零且全量较小，才有该指标下的稀释证据；若两组一正一负，应报告收益与代价的抵消。

### 4.3 配套约束：同等 Precision 下的 Recall

Recall@固定预算可能因多报候选而提高，因此同时画全图、全类别的 Precision–Recall 曲线，并给出 IoU75、目标 Precision=0.90 的拥挤分层 Recall。0.80和0.95只作预定敏感性分析。

描述性评估时，每个模型从全量全局 PR 曲线选取满足 Precision≥0.90且总体 Recall 最大的操作点，阈值对所有拥挤组共用；同分处理固定，报告实际 Precision、阈值、TP/FP和所有分组 Recall。没有非空可达点则记不可达，不能悄悄降低目标。该操作点由评估曲线取得，不能声称是部署时预先校准的阈值。若要部署，另在 COCO 开发集上校准后固定到评估集，报告实际达成的 Precision。

对描述性操作点作 bootstrap 时需在每个配对样本内重新执行相同全局阈值选择；对开发集固定阈值则只重采样评估集。两种估计目标不能混用。

### 4.4 更贴近“粘连”的成对恢复率

GT 定义相邻对：同类别、Box IoU>0.05，与方法的局部邻接阈值对齐；跨类别对单列。固定 pair ID=(image_id,min_ann_id,max_ann_id)，不按预测好坏选择。

统计两个 GT 是否都被**不同预测**以 Mask IoU≥0.75匹配：

\[
PairRecall_{75}=\frac1{|\mathcal E|}\sum_{(i,j)\in\mathcal E}h_i h_j.
\]

这是区分“只分出一头”和“两头都分出来”的次指标。仍使用完整 GT 匹配结果；成对漏检计0。配对的非独立性由图片级重采样处理，并另报每图平均，避免大图贡献大量边对主导结论。它不能单独区分合并、漏检或定位不准，需配合空间诊断。

### 4.5 GT 空间错误：区分少泄漏与少覆盖

主性能指标保留全部 GT。机制诊断另用全图同类别、一对一的 bbox IoU≥0.5匹配建立归属，禁止按 Mask IoU≥0.75挑出好掩码再研究漏泄。双方共同匹配的 GT 用于配对变化，同时报告各自全部匹配和匹配覆盖率；共同匹配结果属于条件诊断，不能外推至漏检实例。

在原图坐标下，令自身 GT 为 G_i、其他非 crowd 实例并集为 U_{-i}、crowd 区域并集为 C、预测二值掩码为 M_i。评价区域排除 C，独占邻居为 N_i=(U_{-i}\\G_i)\\C。报告：

- 自身覆盖率：|M_i∩(G_i\\C)| / |G_i\\C|。
- 邻居错误量：|M_i∩N_i| / |G_i\\C|；同时保存像素数及按邻居区域面积归一化的值，分母为0记NA。
- 背景错误量：|M_i\\(G_i∪U_{-i}∪C)| / |G_i\\C|。
- Purity：自身正确像素/排除 crowd 后的预测像素；空预测另记，不把它当成零泄漏的优胜结果。

正常 cropped、固定外扩 cropped、raw 分开报告。外扩系数统一定义为**每一侧增加 α×原框宽/高**，α=.2即宽高乘1.4，不写成“宽高增加20%”。对机制比较增加双方相同的 GT 框裁切诊断，明确属于 oracle 条件，不与标准预测 AP 混为一谈。

## 5. 五个核心实验块，按信息收益推进

### E0 — 修正并锁定评估实现（优先，CPU，无训练）

目的：确保后续正负结论来源于同一有效协议。

已完成：原始GT逐字段一致性、实例清单、预测ID/缺mask核验、bootstrap最小反例。剩余：

1. 修正两份 bootstrap accumulator：GT数量>0但没有任何检测时，该类别 precision 应为0；仅无有效GT时保留−1。旧实现将其排除。
2. 分开构建 segm 和 bbox 的 `loadRes` 输入。segm只传 image_id/category_id/score/segmentation；bbox传真实预测bbox。混合字段会使 loadRes 按bbox面积标记检测，影响分尺度 segm 评估及忽略规则。不能据此直接说 area=all 的已有AP全部无效。
3. 保存完整分数精度和稳定 detection ID。旧预测每图/类别内有约9,300–9,400个重复分数，四舍五入可能引入额外并列排序；旧缓存可先做探索，最终导出取消舍入。用权重+GT+配置哈希验证缓存，不用“文件>1000字节”作为有效性检查。
4. 小型 fixture 与官方 COCOeval 对齐：无检测、有GT无对应类别检测、无GT的误检、重复检测、多多边形GT、crowd忽略和重复采样图片；断言AP/AP50/AP75及match flags一致。重复抽样的oracle版本复制图和标注为新ID，并采用与加速版本一致的稳定同分顺序。
5. 进行原图mask坐标叠加抽查，确认 letterbox、缩放、crop、阈值顺序一致。现有各模型均在约455–459张图达到每图300输出上限；主协议固定同一预算，再用较高预算的小规模敏感性检查判断候选截断是否改变高低拥挤差值。提高预算的结果单列，不能替换官方主结果。

完成条件：固定样本加速与官方实现差值≤1e−10；保存测试结果、全部输入哈希及版本。回归失败时停止正式统计，修好后重算，不靠改文字跳过。

### E1 — 标准性能 + 实例分层（H1；先复用预测）

设置：Baseline Stage2、CCL0.1 Stage2为主对照；0.5为剂量敏感性，不逐组挑最优权重。

第一步在Dense1576运行E0通过的匹配并缓存每GT命中；输出I0–I3的R75、同Precision Recall、PairRecall、类别/尺度组成及D。第二步补齐统一设置下全val5000预测后重复，并保留全部标准AP。

统计：图片为重采样单位，至少2,000次配对bootstrap；每次两模型用相同图片抽样。计算H和L、以及D时使用**同一次全图抽样**，因为一张图可能同时含H/L实例，不能把两组当成独立样本。主表显示原始点估计+95%区间，保存抽样索引和每次差值。bootstrap类别无GT的处理严格跟随所声明估计量，记录有效类别覆盖。

支持H1的证据：ΔR75(H)>0、D>0，且对应配对区间支持正向；同Precision诊断方向一致，类别尺度调整后仍可见，多个训练种子复现。单seed的图片CI只反映该检查点在图片抽样下的不确定性。

失败解释：H不提高，就不把“稀释”写成已发生；H提高但D不提高，只能说高拥挤实例也受益；R75提高而同Precision不提高，优先检查候选数/分数，而非宣称分离更好。

成本：先CPU评测已有RLE；全量阶段需要每个主模型5,000图统一推断或经同配置哈希确认后补齐3,424图。GPU时间用100图实测吞吐估算，不预报未经测量的分钟数。

### E2 — COCO 系数相似度与错误的关联（H2的诊断前提）

设置：在COCO固定GT配对清单上hook模型，记录对应coeff、prototype、原框、类别分数和预测ID；正式推断输出保持不变。第一轮用GT清单按拥挤组/尺度抽取固定200图作管线验证，再按支持量扩展，不能看效果挑图。

指标：系数余弦、系数范数、prototype Gram矩阵谱/条件信息、logit空间归一化相似度、正激活乘积、邻居错误、覆盖率、raw重叠和cropped IoU。记录匹配不到GT的比例；系数诊断只能覆盖有可归属输出的实例，不能代表全部漏检。

对z_i=P^T c_i，G=PP^T，有z_i^T z_j=c_i^T G c_j。系数余弦不能独立决定logit相似度。一般可逆基变换P'=AP、c'=A^{-T}c保持logits不变，却能改变系数角度，因此跨模型直接比较系数余弦需要配合G和输出空间观测。

按GT拥挤、类别、尺度、box IoU和置信度报告分层关联/回归，做图片级区间；同时呈现原始和控制后关系。置信度和box IoU是模型输出，控制它们只用于条件诊断，不据此估计CCL的总因果效应。

成功条件：COCO上相似度与GT邻居错误存在可重复关联，且并非仅由掩码面积或覆盖减少解释。失败则将“系数相似是根因”降为尚未得到支持的机制假设。

### E3 — 固定解码器的双向系数干预（H2的直接干预证据）

对同一模型、同一图、同一GT对，固定prototype张量、预测框、分数、排序和mask解码。对系数执行保范数的最小平面旋转，分别提高/降低其相似度；加入等角度随机方向和零扰动对照。角度幅度预先固定小范围，例如2°/5°/10°，报告实际Δcos及不可行/退化向量处理，不强迫所有样本达到某个全局终点。

按GT pair ID做paired比较，同一模型每次只干预一个指定对；同一图有多对时各自从未修改的原始张量重新开始。不能累加修改后还声称单对干预。两个模型可使用共同可匹配GT对对照，但不把一个模型的系数直接放进另一个模型的prototype基底。

主观察：降低相似度是否降低**GT独占邻居错误**、保持目标覆盖，并提高cropped IoU或IoU75通过率；反向提高相似度是否产生相反作用。raw互相重叠减少只作辅助。随机干预用于区分方向效应和一般扰动损伤，另记录logit变化幅度避免只比较极不等强度的扰动。

若想把结果连接到AP，还需预先规定每图所有可干预实例的统一、无顺序歧义处理规则，重建整图预测、保留其他全部预测再跑标准AP。逐对条件诊断不能直接相加成AP提升。

成功：小幅、双向、相对随机对照的空间错误响应成立。只出现raw overlap下降而GT IoU下降，说明改变了表示，并未证明改善分割。离开训练流形的强旋转失败也不能证明联合训练“必然必要”。

本块能支持固定decoder内的局部干预效应；仍不能单独证明“训练CCL→系数→泄漏→AP”的完整中介链。

### E4 — 方法替代与训练复现（H1稳健性、H2方法证据）

不扩成大量架构对比，基线家族最多三个：

| 家族 | 目的 | 配置 |
| --- | --- | --- |
| 原版YOLO26 | 训练干预参考 | λ=0 |
| CCL | 系数几何正则 | 主λ=.1；.5仅剂量检查；同类配对版本为有针对性的内部消融 |
| GT邻居排斥正则 | 输出空间的替代机制 | 同样GT邻接对，直接惩罚邻居独占区域的正激活，保留相同的原有分割监督 |

输出空间替代方法可用 L_nei=mean_i mean_{x∈N_i} sigmoid(z_i(x))；N_i由训练GT定义并排除自身和crowd。保持原有自身GT的分割loss，监控覆盖率防止缩小掩码取巧。它是待检验的替代方案，不能在未经查新时称为全新算法。

所有方法共享初始化、数据、增广、batch、优化器、学习率日程、实际训练轮数和检查点选择规则。只执行6轮不等于设置epochs=6：原先配置15轮的日程和真正6轮日程可能不同，必须匹配实际schedule。现有两阶段从各自Stage1 best启动，只能解释为完整训练路径对照，不能隔离Stage2独立效应。

先用匹配的seed0探索，再以0/1/2三种子复现最终配置，报告逐seed结果和均值/标准差；图像bootstrap与训练seed波动分开。不要把3×2,000次bootstrap当成6,000次独立训练。既有6轮baseline可作为固定6轮协议的结果，不能与预算不同的CCL直接构成最终方法比较。

若仍要宣称“原型适应是必要原因”，才增加成对的固定特征+prototype生成路径、仅训练coeff分支的λ=0/CCL实验，并与联合训练对照。只冻结prototype头权重而让共享backbone变化并不能固定P。该实验属于CCL内部消融，成本明显高于E3，不作首轮必跑。

推进条件：E0首先通过；E1先确定收益位置；E2/E3决定机制叙述；再投入E4复现和替代方法。若E1没有高拥挤收益，仍可用E2/E3改方法，但不要为了保住结论反复换分组。
