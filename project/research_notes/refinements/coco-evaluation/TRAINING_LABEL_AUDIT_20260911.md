# COCO 训练标签取证：多多边形被拆为多个实例

日期：2026-09-11。结论：发现实际面向train2017和val2017的错误手写转换器，原始标注重建与训练日志高度吻合。当前COCO训练对照应视为存在实例粒度污染，先修复标签并从共同干净初始化重训Baseline/CCL，再判断方法是否有效。

## 证据及强度

1. 明确代码缺陷：remote_scripts/write_labels.py 第37行遍历 ann['segmentation']，第46行每个片段append一条标签。第53、54行明确同时转换train2017和val2017；第56、59行写入并执行远端manual_convert.py，第65行启动训练。不是后来Top100脚本的推测。
2. 独立执行见证：只提取旧脚本中的转换函数，在临时合成数据上运行，1个annotation含2个polygon，实际生成2行标签；未执行SSH外壳、原数据写入或训练命令。原转换函数快照不包含连接凭据，保存在manual_converter_source_snapshot_20260911.py.txt。
3. 验证日志指纹：run_cluster_fixed.log、run_stage2.log、Baseline Stage2日志共47条汇总行均显示1576图、23832个实例。原始同一图像清单为20827个非crowd annotation；23832恰好等于逐polygon拆分后的片段总数。
4. 训练日志指纹：依据旧函数的六位小数归一化及加载器的类别+片段框去重规则，独立重建图片99844、201706、214087，分别得到4、1、1条重复标签，与三份训练日志一致。仅靠某个标准转换器文件存在，不能排除后续手写脚本覆盖标签；该指纹支持手写路径确实进入训练数据。
5. 限制：远端只读连接在SSH握手阶段失败，尚未逐文件读取当年train2017.cache/val2017.cache。以下统计是原始标注和已保存转换代码的重建，不冒充直接读取远端缓存。另一个旧导出包截断；可用export_light包只含代码、日志、配置和结果，没有完整训练标签。

## 重建影响范围

| 项目 | 训练集 | 验证集 |
| --- | ---: | ---: |
| 固定图像数 | 37,433 | 1,576 |
| 原始普通非crowd实例 | 488,877 | 20,827 |
| 旧转换器输出标签行（加载器去重前） | 560,747 | 23,832 |
| 被拆分的原始实例 | 50,616 | 2,100 |
| 额外片段行 | 71,870 | 3,005 |
| 含被拆实例的图像 | 23,443 | 987 |

训练集中约10.35%的实例被拆分，标签行膨胀约14.70%。不能把560747当成加载器最终缓存实例数，加载器还执行去重。

同一真实实例内部，重建得到8241对片段框满足Box IoU>0.05，涉及6851个原实例。这些几何候选可能被CCL误当为不同GT的负对；实际施加损失还要求两片段都获得训练候选分配，因此8241不等于观测到的错误loss次数。

## 对研究结论的影响

- Baseline和CCL共用错误标签并不能自动消除偏差。两者的基础分割目标都被改成片段级目标，而CCL还依赖不同GT之间的配对身份。
- 训练阶段验证标签也被拆分，旧AP、early stopping及best.pt的选择受影响。仅修复最终评估不能撤销训练梯度和历史选模的影响。
- 已修正的官方JSON评估仍是这些具体检查点的有效测量，不能改成假数据。但它不再支持“正确COCO训练协议下CCL无效/有效”的方法结论。
- 最近的固定decoder干预仍描述旧权重的局部响应，不能直接用它决定干净监督下的方法根因。原有METHOD_DECISION中的空间正则建议暂留为假设，优先级让位于数据修复。
- 本证据范围是这条COCO训练链路，没有审计Faro训练标签，不能外推说所有数据集训练都错了。

## 最小修复与复用边界

1. 保留旧代码、标签、缓存、权重和日志作证据，不覆盖原目录；新标签写入独立版本目录。
2. 以COCO annotation_id为实例单位生成标签，保存源annotation_id到训练标签行的映射。同一annotation的可见片段保持同一个实例身份；空/无效/crowd与重复标注处理显式记录。采用YOLO多段合并时还要核对其栅格化掩码与原始RLE的差异，不能只检查标签行数。
3. 在实际dataloader后复核每图实例数、类别和掩码，专门覆盖多片段GT，确保没有沿用旧.cache或错误标签路径。记录新标签、清单、代码及缓存hash。
4. 先用小样本通过转换、实际加载和前反向验证，再从相同干净预训练权重成对训练Baseline和原CCL；两组保持同样数据、增广、优化器、学习率日程、预算和选模规则。不要从已污染的Stage1/Stage2 best继续训练后声称重建了干净主对照。
5. 原有ICI选图清单可复用作受控修复实验，不必同时换训练分布。修好身份错误后，以正确GT进行逐实例评估，再按计划拓展全val。第一轮优先复现原CCL，不同时引入新损失，否则无法区分数据修复和方法修改的作用。
6. 可复用：原始COCO数据、图片ID清单、正确的实例级评估器、GT空间诊断器、bootstrap/验证代码和旧权重的诊断缓存。需重建：训练标签及加载缓存、正式Baseline/CCL训练对照、依赖该对照的性能和机制结论。
