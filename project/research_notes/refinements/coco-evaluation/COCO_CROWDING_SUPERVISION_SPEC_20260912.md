## 1. ICI 的定义与职责

对有效的非 crowd 实例 i，使用原始 GT 框：

\[
ICI_i=\frac{\sum_{j\ne i,\;y_j=y_i}|B_i\cap B_j|}{|B_i|}.
\]

- ICI 是**实例指标**，图片筛选需另外聚合实例 ICI。
- 仅统计同类别、非 crowd 邻居；多个邻框可重复覆盖同一区域，因此数值可超过 1。
- 它描述框的累计几何交叠，不直接表示可见掩码遮挡率、邻居数量、分割难度或模型失败概率。
- 无同类邻居时为 0；无有效框面积时记为未定义并记录原因，不能填 0。
- 图片级保存最大 ICI、平均 ICI、高 ICI 实例数和占比。图片入选不能使其中所有实例都被称为高拥挤实例。

ICI 的职责如下：

| 用途 | 操作 | 解释边界 |
|---|---|---|
| 训练图片筛选 | 选择含高 ICI 实例的图片，保留图内全部有效 GT | 子集内仍包含普通实例 |
| 实例级评估分层 | 完整图像匹配后，根据每个 GT 的 ICI 汇总 | 不能以子集整体 AP 代替高 ICI 实例效果 |
| 机制诊断分组 | 对照候选、NMS、系数、原型和空间错误 | 分组关联不等于因果机制 |
| 数据组成描述 | 报告每图高 ICI 数量、占比及类别和尺度分布 | 高低组可能存在构成差异 |

### 1.1 固定的实例分层

沿用四档：`ICI=0`、`0<ICI≤0.5`、`0.5<ICI≤1`、`ICI>1`。二分对照中的高组为 `ICI>0.5`，低组为其余有效实例。

沿用已有统计的边界处理：距 0.5 或 1 不超过 `1e-10` 的值归到该精确边界；保留原始值和分组用值，避免不同脚本的浮点分层不一致。

### 1.2 历史子集的口径

已有统计记录：训练子集 37,433 张图、488,875 个框有效普通实例，其中高 ICI 实例 120,032 个；覆盖全 train 的高 ICI 实例约 99.26%，子集内部高 ICI 占比约 24.55%。这些是**历史统计口径**，不等于所有后续训练的实际样本计数。

历史图片规则是在框面积≥100像素的参考目标中判断最大 ICI>0.5，邻居仍可为小目标；新实例级评估不应因此排除全部小目标。若改变筛选规则，建立新清单，记录源标注哈希、阈值、参考目标面积条件，以及新旧图片和实例 ID 的差异。

## 2. 数据和标签原则

1. 一个 annotation ID 对应一个实例。同一 annotation 的全部 polygon 联合为该实例掩码，不能拆成多个实例，也不能将自身的另一块 polygon 当成邻居。
2. 训练保留图内全部有效普通 GT。**不通过删除低 ICI 标签实现忽略或强化。** 删除标签可能改变分配和背景监督，不能当作单纯损失加权。
3. crowd、无效框、空掩码、重复标签处理分别记录；区分原始标注数、指标有效实例数和实际训练标签数。
4. 对照组使用相同图片、有效标签、数据变换和分配路径，不按方法效果重新选择数据。
5. 明确拥挤度用于训练加权时来自原图还是增强后的布局。Mosaic、裁切等改变布局时需定义 annotation 身份追踪与 ICI 更新规则；本文件不替实现默认选择。

## 3. 高 ICI 实例的监督强化

**优先方案：所有实例保持正常监督，仅高 ICI 实例增加额外掩码损失。** 不预设 CCL 或系数正交机制成立；先检验拥挤实例的监督权重是否不足。

第一轮候选设计保持官方分类、框回归和其他基础损失不变，只增加掩码项。令 \(A_i\) 为官方分配给 GT i 的有效掩码正样本集合，定义：

\[
\bar\ell_i^{mask}=\frac{1}{|A_i|}\sum_{a\in A_i}\ell_{ia}^{mask},
\qquad
H=\{i:ICI_i>0.5,\;|A_i|>0\}.
\]

\[
L=L_{\mathrm{official}}+
\lambda\frac{\sum_{i\in H}\bar\ell_i^{mask}}{\max(1,|H|)}.
\]

上述集合在实际训练批次中计算；附加项先按 GT 汇总，再按 GT 平均，避免 one-to-many 中分配候选数多的目标自动获得更多附加权重。H 为空时附加项为 0。

实现必须复用实际模型分支的官方分配结果及 GT 索引，不另造一套预测—GT 归属。每个候选掩码损失的像素域、裁切、面积归一化及基础 gain 是否纳入附加项均须记录，避免重复缩放。

该项不是已确认存在的官方开关。实现前检查所安装版本的分配和损失路径，并记录分支、版本及代码哈希。

### 3.1 必需对照与解释

| 组别 | 训练方式 | 回答的问题 |
|---|---|---|
| A | 官方 Baseline | 基准 |
| B | 全部有有效分配的 GT 额外增加同定义掩码监督 | 是否只是增加分割任务权重有效？ |
| C | 仅高 ICI、有有效分配的 GT 增加掩码监督 | 针对拥挤实例分配额外监督是否更有效？ |
| D（按需补充） | 每批随机选与高组数量相同的已分配 GT 加权 | 是否仅由附加项覆盖的实例数量或采样方式造成？ |

B、C 使用相同附加项定义、按所选 GT 平均的归一化方式、预定 lambda、训练预算及种子 0/1/2。主要比较为 **C−B**，同时报告 C−A，不能只与未增加监督的基线比较。

相同 lambda 并不保证相同梯度量级。记录所选 GT 数、无高组批次比例、附加损失值和梯度量级；C 在无高组批次为 0，而 B 可能非零。D 可用于进一步控制这种差异；这些记录不能被表述为已证明等梯度预算。

额外记录有/无有效正样本分配的高 ICI GT 数量和比例。无分配目标不会被本附加项直接监督，不能宣称该加权覆盖了所有密集失败。

## 4. 补充指标：掩码边界邻接比例

这是**拟定的 GT 几何诊断指标**，不是已验证的通用标准，也不预先作为独立算法贡献。先用于描述与评估；是否用于损失加权，取决于后续诊断结果。

对实例 i，令：

- \(G_i\)：原始 COCO GT 栅格掩码；
- \(\partial G_i^{valid}\)：按固定规则保留的有效边界；
- \(N_i\)：同图中其他同类别、非 crowd 实例的 GT 掩码并集；
- \(r_i\)：预先确定的邻接距离。

\[
C_i(r_i)=\frac{\left|\{p\in\partial G_i^{valid}:\operatorname{dist}(p,N_i)\le r_i\}\right|}
{|\partial G_i^{valid}|}.
\]

含义：目标的有效边界中，有多少比例靠近其他同类实例。例如200个有效边界像素中有80个满足距离条件，指标为0.4。

候选尺度规则为：

\[
r_i=\max(r_{min},\alpha\sqrt{|G_i|}).
\]

`alpha`、`r_min` 尚未确定。只能通过训练集几何分布和样例检查确定并锁定，再报告预定半径的敏感性分析；不能按哪个半径下方法优势最大反向选择。

### 4.1 计算和例外处理

- 使用原始 GT 和原图像素坐标，不依赖预测框、预测掩码或模型置信度。
- 距离指到邻居**掩码集合**的欧氏距离，不能在实现中悄悄替换成到邻居边界的距离。边界点位于邻居GT内部时距离为0。
- 对邻居并集的补集进行欧氏距离变换，再在自身边界上读取距离；必须单独处理没有邻居的情形。
- 自身有效边界非空、无同类邻居时记0；无有效边界时记缺失并注明原因，不填0。
- 图像裁边产生的边界、crowd附近不可靠的区域须按预先固定的规则排除。记录排除的边界量，不能将排除后的人工切口当成真实轮廓。
- 实现前固定边界提取方法、像素连通性、边界厚度、图像边缘排除距离、crowd排除距离及空/无效邻居掩码处理；目前这些参数未锁定。
- 掩码孔洞、细长结构、小目标和栅格分辨率会影响边界比例。保留类别、GT面积、有效边界像素数和实际半径，按类别与尺度分层解释。

### 4.2 与 ICI 联合分组

| ICI | 边界邻接比例 | 几何场景描述 |
|---|---|---|
| 低 | 低 | 相对独立 |
| 高 | 低 | 框交叠明显，轮廓邻接范围较少 |
| 低 | 高 | 框交叠不强，轮廓仍有较多近距离接触 |
| 高 | 高 | 框交叠与轮廓接近同时存在 |

边界邻接比例的高低阈值尚待训练集预定义。四组首先是场景描述，不预先宣布哪组最难，也不强求 ICI 越高、系数就越相似。

Boundary IoU 评价预测与 GT 的边界一致性，本指标描述不同 GT 实例之间的邻接；二者用途不同，不可混称。

## 5. 评估指标与统计口径

1. **总体任务**：保留完整 COCO val2017 的官方 Mask AP；必要时同时报告 AP50、AP75、Box AP，说明评价配置。
2. **实例恢复**：先在完整图片、全部有效 GT 和完整预测集上执行官方匹配，再按 GT 的 ICI 四档报告 Mask Recall@0.75。不要先删低 ICI GT 再匹配。明确 maxDets、置信度门槛和该指标的微/宏平均定义；不要把逐GT恢复率改称 AP。
3. **相邻对恢复**：预先固定 GT 相邻规则、类别范围及配对分母，统计两个不同实例都被正确分割的比例；不得把同一预测重复用于恢复两个GT。
4. **空间错误**：在固定归属的同一批目标上联合报告同类邻居误分、自身覆盖、背景误分和 Mask IoU。主比率使用有效自身GT面积作分母，逐目标计算后平均；记录 crowd 排除及未匹配目标。该条件性像素表不能代替包含漏检的任务指标。
5. **拥挤特异增益**：对同定义、同单位的性能指标，计算

\[
\Delta_{specific}=(M_{method}-M_{baseline})_{high}-(M_{method}-M_{baseline})_{low}.
\]

对监督加权实验优先使用 C−B；该量是高低组增益的交互对照，不是拥挤的因果效应。报告其直接配对区间，不能只凭“高组显著、低组不显著”宣布二者差异显著。

6. **组成控制**：报告类别和目标尺度构成，优先在共同类别×尺度层比较或标准化；ICI与边界邻接比例分别及联合分析。只在双方有可比样本的范围内解释，报告无共同支持的样本量。
7. **不确定性**：保留三个训练种子的逐种子结果；图像簇配对重采样用于反映同图目标相关性，明确区间条件与多重比较限制。半径、分组阈值和方法超参不能按val优势选择。
8. 若采用固定 Precision 下的 Recall，另行锁定 Precision 目标及置信度阈值选择数据；该指标不能与前述固定IoU恢复率混用。

不能仅以邻居误分下降判定成功。对 C−B，需同时检查高组实例恢复、相邻对恢复、自身覆盖、低组表现和总体AP；覆盖容忍幅度及继续/停止阈值在正式实验协议中预先确定。

## 6. 本地离线记录格式

每个普通 GT 一行，以 `(split, image_id, annotation_id)` 为身份键。建议至少保存：

```text
split, image_id, annotation_id, category_id,
bbox_area, gt_mask_area, ici_raw, ici_for_group, ici_group,
boundary_adjacency, boundary_radius_px,
boundary_pixels_total, boundary_pixels_valid, boundary_pixels_near,
same_category_neighbor_count, status, exclusion_reason
```

`boundary_adjacency` 未定义时留空并填状态。多半径分析采用明确的半径配置列或独立长表，不能覆盖主半径结果。另保存标注哈希、图片选择清单哈希、代码版本、协议参数及各阶段排除计数；训练分配统计单独存放，不将模型分配结果混入静态GT拥挤度定义。
