# 修正器空间信息与路线投入审查：范围

日期：2026-10-17。用户授权：复用现有代码和产物，核对修正器实际获得的空间信息、提取和汇聚损失，区分信息不足、架构限制和优化问题，并裁决是否继续。**不追加训练或新实验。**

本次为静态代码与既有证据审查，不创建科学 Study/Run，不调用模型 forward、求解器、COCO 重评价、bootstrap 或新干预。允许读取保存的源码、合同、缓存元数据、训练日志、checkpoint 身份和既有核验回执，计算文件 SHA、已有日志的描述性汇总并保存审查报告。优先使用本机已回传产物；缺失证据如实登记，不为填补它重跑实验。

审查链路：实际原生导出 → 缓存内容 → B/soft-IoU/AMT/CLD 修正器输入 → ROI 采样/特征投影/空间汇聚 → Δc/解码；另核对 LRP 的逐像素输入、编辑域与训练采样。跨方法结果保持原对象、单位、预算和比较限制。

待区分解释：

1. 信息入口受限：原始图像/完整 F 未被输入，或已有空间线索在提取中被丢弃。静态代码可以证明限制存在，不能单凭限制证明其导致多少效用损失。
2. 架构读出受限：已保留的信息经过下采样、投影、汇聚或受限输出空间后不能充分表达条件修正。用已有空间置换、方向对应和局部/统一偏移对照界定证据强度。
3. 优化或监督不足：学习目标与最终二值效用不一致，或预算内未充分拟合。核查真实梯度、更新、日志和训练内评价；损失下降不作为收敛或可部署效用证明。

裁决规则：继续推荐须有本路线的正面证据及区别于旧试错的具体机制理由；缺乏证据时停止现有配置追加投入。未隔离原因时明确“尚未归因”，不以此无限续开诊断，也不把现有输入限制直接写成信息论不可学。旧 Gate、源码、checkpoint、缓存与原始 Run 均保留。

交付：完整实验展示范式的审查报告、输入/压缩链路表、证据归因表、带 SHA 的来源与复核收据、明确的路线投入判断和唯一下一步。仅更新本审查目录、总控路由和计划目录；论文正文不在本轮自动改写。
