# 来源与使用范围

这是一组方法／理论Skill，内容为依据论文编写的学习问题分析、方法原理、适用条件、公式和组合建议。它不是官方框架Skill或经实测认证的YOLOSeg配方。

原2.0来源集引用6篇，逐项见[论文卡片](references/papers.md)，结构化信息见[sources.json](sources.json)，其中package_version保留该来源集身份。2.1新增TAG、Auto-Lambda、AuxiLearn与ForkMerge，阅读范围、正式／作者入口、PDF指纹和官方代码固定版本集中见[辅助效用方法](references/auxiliary-transfer.md#6-已读外部来源与范围)。原PDF是阅读材料，不随Skill分发；如需重新核查可按对应版本获取。

这些候选以已有发表的经典方法和明确论文机制为主要依据，也保留技术报告／综述的身份。没有把引用数量或论文发表直接当适合当前任务的证据，没有宣称覆盖最新或全部相关工作。

Skill可直接阅读，无Python依赖、代码模板、专用加载工具、工作台协议或固定路径。技能间通过名称发现；内部文档使用相对链接。Agent暴露由宿主管理，本次不创建连接或扩展。

原理与公式的迁移仍需当前任务证据。定量论文收益未被移植成当前猪场结果，旧项目的训练、评价和暂停状态不因阅读这些方法改变。

文件版本见[CHANGELOG.md](CHANGELOG.md)，交付哈希见[MANIFEST.json](MANIFEST.json)。
