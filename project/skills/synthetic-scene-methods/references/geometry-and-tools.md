# 几何、工具与有边界的工程经验

## 表面身份与姿态

LBS将多个刚体变换线性混合，一般不再是刚体变换，较大角度可塌缩。DQS改善旋转混合的一些失真，却不保证关节目标、表面或碰撞可行。项目同五矩阵对照中，四个失败大屈曲没有因换DQS准入；该结果收窄“仅换插值就能解决”的解释，不证明所有卧姿不可表达。

支撑和无穿透不同。全身最低点落地可能是软耳先触地、躯干仍悬空；脚距地小于容差也不等于严格接触。刚体修复要同时作用于网格、骨架、根旋转中心、相机相关状态和同场景其它实例，不能只改顶点后称rig一致。

零形变身份也需明确。用raw关节回归J=AV会带入源回归偏差；增量形式`J_new=J_source+A(V_new−V_source)`在零形变时保持原关节。数学零与浮点逐字节零不同，工程重放若要求exact应显式保留恒等分支。

正可逆仿射保持自交关系与拓扑；变换后的蒙皮是否等于整体仿射，还依姿态旋转与缩放算子交换、offset和同一关节映射。项目的特定stand宽度算法核过这些条件，不能扩为任意pose/contact保证。全身比例变化可维持纵向轮廓，也不等于自然年龄、品种或统计体型模型。

## 编辑目标、平滑与约束

Laplacian平滑倾向局部平均，可能去交也可能损伤形状。ARAP交替局部旋转和顶点位置，保护某种局部刚性，却不保证完整身体自然。项目ARAP改善边长/面积后，实际图仍出现中段夹凹和尖突。局部几何门槛与全身外观是不同判断。

更强算法不能满足互相矛盾的固定约束。历史纠正例中，两端均固定的6条边已长于原上限，任何只移动其余顶点的平滑都不可能修复这些边。这个局部不可行性有明确见证，不能扩为整个猪rig或所有腹卧方案不可能。有限优化损失下降和有限搜索失败也分别不等于合格或全局不可行。

部位控制应定义在源表面再随pose/contact传递。世界Z最低区域在换姿态后不再是同一只蹄；内部脚关节周围的Gaussian也未必覆盖真正脚端表面。UV坐标可以接缝复制、重叠或退化；不能从UV颜色唯一反查解剖身份。

Hunyuan-Paint的已读pipeline含remesh，UV处理的vmapping也会重排/复制顶点。关remesh仍不足以保证原面、蒙皮和part身份；可烘回原网格，或显式转移后复核。材质贴出眼睛不等于已有眼球几何，源面候选眼周也不等于精确器官GT。

## 接触与独立核验

AABB重叠只是粗筛；静态无交不保证两个终态之间不穿越。连续碰撞检测CCD可以限制安全步，局部势能梯度的数值差分可核实现，但IPC Toolkit本身不是完整组织模拟器。

项目的两实例耦合Newton＋CCD在一个固定站姿接触例中，相对刚性放置负对照去掉穿透，双方都有位移。它没有验证摩擦、惯性、闭合压力、体积守恒或真实组织参数；原源边界仍存在。旧单向粗笼后对称半位移与该耦合方法也不是同输入匹配比较。

独立射线实现可核几何/距离/owner，但如果两实现共享错误源part映射，就无法独立证明解剖语义。保存blend重渲染像素一致只证明该环境的场景重放，不是跨硬件、物理解算、真实外观或数据集质量证明。

## 工具的具体能力边界

| 工具／模型 | 已知接口或用途 | 限制 |
|---|---|---|
| OpenCV GrabCut | RGB、ROI和前背景状态生成分割候选 | 不认识猪／部位owner，候选非真值 |
| Blender／BlenderProc／Kubric | 场景、渲染和丰富几何通道 | 默认对象不等于逻辑猪；需自定义part映射和标签政策 |
| Open3D射线／距离 | geometry、triangle、t_hit及几何查询 | signed distance等依封闭／无交条件；不认证解剖 |
| SciPy DE／MILP | 有界参数搜索、有限候选覆盖 | 搜索不创造缺资产；默认polish会追加评价 |
| Trimesh／PyMeshLab | 碰撞与网格处理候选 | 改拓扑后旧face ID、part与蒙皮不可直接沿用 |
| SAM2／SAM3 | 点框提示或概念条件的实例候选 | 提示条件要明示；不提供隐藏真值或正确owner保证 |
| MAMMAL猪PointRend／HRNet | 专门轮廓与关键点接口 | 数据来源可能重叠；23表面点不等于62rig关节 |
| DINOv2／DINOv3 | CLS与稠密patch表示 | 全局近似不等于部位接近；先区分背景／抠图捷径 |
| GeoCalib／DepthAnythingV2 | 相机/重力先验、相对深度候选 | 不是目标域标定或公制猪几何 |
| PartField及动物姿态模型 | 表面聚类或姿态候选 | 聚类不是解剖命名，隐藏姿态仍是多解估计 |

维护者文档、论文介绍、已有权重、加载成功、真实接口通过和下游效用是不同层级。旧工具来源记录只读指定接口；未据27份来源声称27篇全文精读或全部工具部署。

## 外观反馈的边界

实例/部位特征比较要统一ROI、分辨率和前景政策。真实SAM抠图、合成GT抠图的边缘差可成为捷径；非配对场景不应强迫每只猪向一只平均猪靠拢。固定编码器对关键部位缺损是否敏感，是其能否作为该比较代理的相关证据。

WGAN/WGAN-GP约束critic的分布差异，SimGAN使用局部对抗与自正则；它们不保证几何标签原封不动。nvdiffrast提供可微光栅化组件，不自带完整相机/PBR/灯光系统，预览也需在最终渲染链核对。这些是保留的文献知识；本项目对抗/判别器及自动特征反馈方向已按用户范围撤销，此页不重新授权执行。

项目材质与短毛对照确认像素改变，却未达到当时外观要求。该阴性不证明所有程序化制作无效，也不能单独归因几何缺失：后续源面核查确实看见鼻盘、耳内和分趾。用明确表面支持、实际成像和竞争解释收窄结论，比从一种失败跳到“必须换资产”更可靠。

具体来源与原实验范围见`CURATION_SOURCES.json`；旧行动顺序、预算及未运行候选未迁移。
