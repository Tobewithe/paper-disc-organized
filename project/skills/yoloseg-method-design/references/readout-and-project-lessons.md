# 原型—系数读出与实例分割经验

## 架构概念

YOLO版本编号不是单一团队逐版串行的理论继承链。YOLACT的共享原型＋实例系数、SipMask的局部空间读出、YOLOv10的双分配等是可比较的思想，不应无证据写成直接祖先关系。

YOLO26对应版本已经包含多尺度Proto26与辅助语义，不宜将再次加入它们描述为补齐未知缺陷。TAL的类别/框对齐不等于Mask质量对齐；P3经颈部已有多尺度信息，也不代表每个实例获得了正确归属。

一个高IoU框不能保证同一raw的Mask好；别的raw上有好Mask，也不保证正常排序和容量保留它。原生32维基底不能直接硬命名为身体部位。基底可换性、函数依赖和信息边界见[数学说明](object-representation-math.md)。

## 成熟方法应按解决对象比较

| 方法思想 | 提供的能力 | 需要保留的限制 |
|---|---|---|
| YOLACT／CondInst／SOLOv2 | 共享空间特征与实例条件读出 | 线性系数、动态卷积及动态核表达不同 |
| Mask R-CNN／ShapeMask | 实例裁剪、形状先验与细化 | ShapeMask已有先验用于粗Mask并结合图像细化，不等于任意猪形状可迁移 |
| PointRend／RefineMask | 粗预测与细特征、选点或多阶段细化 | 标签上采样不等于细图像特征；额外成本及owner仍需评价 |
| Mask2Former／Mask DINO | Mask条件注意、联合检测/分割读出 | 原模型容量、预训练与查询机制不同，不能只移植名称 |
| Mask Transfiner | 不确定区域的层次稀疏细化 | 不意味着所有边界误差由分辨率解释 |
| STN／可变形采样 | 对齐和自适应取样 | 逆映射、可见框与完整框及源坐标必须区分 |
| Pictorial Structures／Capsules／CompositionalNets | 部位几何、组成与对象条件 | 分类/检测实证不能直接充当实例AP增益 |
| Slot Attention | 竞争式对象分解和置换等变 | slot不是天然可识别身份，重建不保证任务使用 |
| TAPPS／Panoptic-PartFormer | 对象与部位的联合推理 | 同对象query绑定与分离query不同，TAPPS对象Mask不是部位硬并集 |

表中只迁移已有阅读的关键思想；精确来源层级见`CURATION_SOURCES.json`及既有论文卡片。没有新读所有原文或复现这些模型。

## 对象知识与当前状态

长期可复用部位证据、空间组合和形状先验，与当前图像的实例身份、位置、姿态、可见性和数量不同。多实例可以复用同一知识，一实例也可调用多个原型；库容量、激活次数、slot数量和有效对象数不可互换。

ProtoPNet的训练块投影给分类原型样本依据；Deformable ProtoPNet学习可变形部位组合。PixPNet提醒最强命中裁图可能受像素映射和感受野影响，一张漂亮图不足以证明纯部位语义。InstanceCut的边界分组、空间嵌入的像素聚类和Slot Attention的竞争绑定分别处理当前实例；DINOSAUR的特征重建已有对象发现实证，不能笼统否定特征重建。

隐变量取名为形状/外观/姿态不证明已解耦。Locatello等的不可辨识性研究强调模型/数据假设；本地只核摘要与贡献，不据其断言全部弱监督分离不可能。MagicPony提供规范空间、关节和视图投影的具体建模；SPOT观察强自回归解码器减少slot依赖，不能直接当成本项目卷积解码器的已证失效。

边缘强度与边属于哪个对象不同。Border Ownership研究提供视觉神经生理的上下文证据，原本地阅读限摘要/摘录，不能据此宣称复现人脑处理流程。隐藏部位的整体假说也不应直接补进任务可见Mask。

## 冻结P的可表达性与共享学习

逐实例GT优化c给出存在性见证，共享头`c=Wh+b`则要同时满足所有实例，二者函数类不同。固定有限预算的对偶证书可排除特定共享仿射目标内集，却不能排除其它Mask75解、无限制更新或整个网络。

历史796图／6058候选的质量内集审计中，P3固定约束子集的保守下界72.042775高于声明预算45.673507。这是对应对象和质量包络的有限数值证书，不是普遍“固定P不能学”。后续原生系数头在另一训练配方取得增益，两者并不矛盾。

在功能空间中，系数距离需通过P及有效支持解释。不同P可给相同系数位移完全不同Mask变化；无权重欧氏范数不是统一效用度量。线性池化与sigmoid不交换，GT框/预测框、proto格/原图裁剪也会改变目标。

## 失败识别、收益和安全应用

旧7I可从检测输出识别部分Mask75失败，7K却发现该分数对当前修正器能救回者的AUROC仅.261（该原失败组及图像聚类区间[.186,.351]）。识别困难实例与预测修正净收益不是同一任务。

7H已加入当前原Mask条件，7J/BGCR已有空间ROI，PCDCR已有Mask加权原型和动态低秩；早期投影与冻结训练已尝试空间证据→基底算子→系数，少量GT像素及2×2分区也已有记录。重新命名不产生新的信息条件；这些阴性仍只限具体输入、参数化与预算。

外部SAM提示已有检测框→实例Mask先例。它增加独立预训练空间先验，成功也不直接证明YOLO内生能力、轻量化或可蒸馏性；完整teacher、压缩teacher与回投P的对照可区分损失发生的位置。

## 修复—损伤取舍的实证

历史固定256个失败检测面板：原有限系数求解找到122个Mask75见证，另一BCE对照找到159个。对原122个见证，100个连无门控Adapter也未修好，10个修好后被门控撤回，12个保留。它支持当前预测缺口大于单纯撤回，不表示这些实例永远不可学或解释全部COCO损失。

旧G完整5k相对同配置N提高.141573 Mask AP点，损伤90/22957；未达当时.30点要求。另一个同服务器新配方中，G_budget/C_native/PC为44.265173/44.253024/44.017703 AP，相对Ns=44.013836；成功损伤81/120/198（同分母22958），恢复250/268/320。PC恢复最多而AP没有额外收益。新G同时改变数据、更新数、学习率和源批组，不能只归因样本量。

旧信赖域投影保留oracle增益30.2%，同规模随机支持58.8%；保护区logit改动确实较小，但牺牲更多修复。因此保护有效不等于整体有用，也不能将当前不确定性选点当已证优于随机。可达teacher替换、直接方向监督和调幅也分别有配置级阴性，不能把任何一种当已解决问题反复提出。

## 猪实例语义的累计认识

N是多阶段训练形成的强模型，不是官方COCO裸起点；N/C21/V23约为57.343500/60.416526/60.753278 AP，原+5目标未达。原型重建、参考分类好、合成部位可学、真实域读入与实例正常使用是不同能力。

RLPL的D2优于C2却低B2和N；概念V1的C−Q平均+.088211且seed异号；2026-11-05共同COCO起点的C−Q平均−.513151且异号，R/Q/C后期共同退化。它们共同削弱已测语义版本的实用增量，不能全部归为BN、梯度冲突或没训练原生分支。全图前景语义不识别标签不变的owner错配，仍可能有一般正则收益。

V32已有对象—部位实例头、相对N约+2.908485，却低V23且未建立有序部位依赖。不能写成从未尝试实例绑定，也不能外推所有对象条件部位方法不可能。V21/V23的实际收益与正确内容的必要性也分开；功能旁路可表示性、空间破坏掉分与自然部署效用不是同一主张。
