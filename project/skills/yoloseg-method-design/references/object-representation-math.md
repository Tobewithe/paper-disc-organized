# 对象表示、检索与读出的数学边界

本页从已有数学审查中抽取成立的关系、反例和适用条件。历史V2.2/V21等候选结构、动作数、超参数和下一步安排属于原研究设计，不作为本Skill认可的新方法。原22项核验是代数与构造例子，不是模型效用实验；本次整理没有重新运行模型。

## 表示坐标不等于语义身份

对共享基底读出`z=Pc`，任意可逆矩阵A给出`P'=PA, c'=A⁻¹c`，仍有`P'c'=Pc`。因此单个原型通道、系数坐标或向量范数不是天然的身体部位／实例身份。同一网络内通道可能因共同训练形成稳定作用；代数可换基并不证明实际发生跨图通道漂移，也不证明应强制任意换基等变。

对K个d维单位向量，Gram矩阵秩至多d且迹为K，由迹的Cauchy不等式可得，当K>d时：

\[
\frac{1}{K(K-1)}\sum_{i\ne j}\langle e_i,e_j\rangle^2
\ge\frac{K-d}{d(K-1)}.
\]

K=256、d=128时下界为1/255。要求全部词条正交在这个设置下不可能；低相关也不是语义解耦证明。不同库若不共享比较空间，不应把条目数机械相加使用此界。

固定记忆V，若检索结果Z=f(F,V)由图像特征F确定，则`I(Y;Z|F,V)=0`。它没有新增该图像的观测，但训练得到的结构可以改变归纳偏置、有限样本估计与计算效率；这不否定记忆有用。反之，表征空间更大也不能保证解决不可辨状态。

Locatello等无监督不可识别定理有生成模型与先验假设，不能直接当有监督部位模型失败的定理。遮挡通常不可逆，不能把可逆生成假设下的弱监督解耦结论外推为唯一恢复隐藏身体。

## 监督可能只约束集合，未约束集合内身份

若`p(k|x)=p_fg(x)π_k(x)`且`Σπ_k=1`，只监督前景集合时：

\[
-\log\sum_kp(k|x)=-\log p_{fg}(x).
\]

不同细词条分布可获得同一目标值。它说明细身份缺少区分条件，不说明任意共享logit参数化下每个条件梯度都恒为零。

参考重建`L_ref=Σ_k L(D(v_k),y_ref,k)`若完全不经过当前query，则对仅属于query的参数有`∂L_ref/∂θ_q=0`；共享值或编码器仍可能产生其它间接作用。规范模板重建好、query有梯度和正常输入能正确调用是不同事实。

语义正例与实例正例也不同：两头猪的头可在语义空间互为正例，在owner任务里仍须区分。前景、部位、实例和物理可见性不是同一标签空间。

## 有限候选能量的责任分配

给定归一化候选先验π和能量E，令

\[
Z=\sum_k\pi_ke^{-E_k},\quad L=-\log Z,\quad
r_k^*=\pi_ke^{-E_k}/Z.
\]

对任意责任分布r，在相应支持上有

\[
\sum_kr_kE_k+KL(r\|\pi)=L+KL(r\|r^*)\ge L.
\]

若π由softmax logits a产生，且求偏导时E固定，`∂L/∂a_k=π_k−r*_k`。完整参数梯度还包含能量路径`Σ r*_k dE_k`，不能省掉共享参数的作用。使用稳定log-sum-exp；能量的像素平均、已知区域、实例权重和温度共同决定实际责任。

此代数对有限复合能量成立。只有能量确为恰当归一化的负对数似然时，才能进一步赋予对应概率模型解释；Dice+BCE组合不能仅因写成指数就称为真实生成似然。它也不提供非凸神经网络的全局收敛保证。

若E≥0、π在全候选集归一，截断集合S且不对π重新归一，`Z_S=Σ_{k∈S}π_ke⁻ᴱᵏ`满足

\[
0\le-\log Z_S+\log Z
\le\log\left(1+\frac{1-\sum_{k\in S}\pi_k}{Z_S}\right).
\]

保留99%先验质量仍可能删掉唯一解释正确、先验只有1%的候选。训练中GT补入候选的表现不能冒充正常top-k能力。多种互斥姿态的概率混合可表达不确定性；把它们的Mask平均后当一个完整身体，会改变对象语义。

## 连续采样、对象框与可见框

双线性采样使坐标变换局部可微，但不能保证越界区、常值区或大错位时存在有效梯度。变换要分清forward与inverse mapping。若`u_target=A u_source+b`，采样源位置是`A⁻¹(u_target−b)`。

ROI边界`[x0,x1]`对应S个像素中心`x=x0+(u+0.5)(x1−x0)/S`；宽W画布在`align_corners=False`约定下使用`2x/W−1`。这一约定不能与像素边缘、`align_corners=True`或未计入letterbox的坐标混用。

完整对象框与可见检测框可能不同。完整身体在重遮挡时会伸出可见ROI；扩大局部形变容量不能自动补足整对象坐标框的变化。图像裁切、鱼眼有效域和出画也可截断所谓amodal框，因此“可见像素/画内完整像素比高”不证明完整对象已被观察。

同一轮廓先缩到ROI网格再贴回原图，通常不保持原始二值输出。残差为零时若要求精确保留原生Mask，应保留原生解码路径并只叠加修正，不能重新采样整个基线再宣称恒等。

## 幅度、几何和功能依赖

局部光滑隐式场`φ=0`的扰动满足一阶法向位移近似`δn≈−δφ/‖∇φ‖`。只有梯度有正下界且局部线性近似成立，小logit变化才约束小轮廓位移。任意分割logit不是SDF；很小的logit范数仍可能翻转大量近零像素。

对修正d，`p=max(d,0), m=max(−d,0)`满足`p−m=d, pm=0`，并在非负分解中最小化`p+m=|d|`。两个独立softplus加减分支可以互相抵消，缩放后又暴露大改动。唯一符号分解有助于解释动作，但不证明任务收益。

若融合路径允许把内容通道权重置零，函数类就包含不依赖内容的解。这是可表示性结论，不能直接断定实际模型绕过了内容。非零梯度、注意力或槽使用率也不能反过来证明功能依赖。

置换值、破坏几何或替换邻居可以检验依赖，但也会引入分布外输入、幅度和置信变化。固定原动作与允许重新选择动作回答不同问题。对于非负线性原图采样算子L，若`q=ΣL(r), q'=ΣL(r')>0`，则`r''=(q/q')r'`匹配总质量；这只控制总量，不控制所有局部统计。很小分母、过大比例和回退覆盖必须公开。

## 与成熟方法的对应关系

- VQ-VAE区分重建、字典与编码器的梯度目的地；Task-Driven Dictionary Learning把任务目标放在实际输入产生的表示上。它们支持检查训练路径，不要求所有记忆都采用硬VQ。
- ShapeMask区分形状先验与实例图像证据；STN提供可微变换／采样；Deformable ProtoPNet展示可变部件位置的原型。各自任务和插值假设不同。
- Matrix Capsules以部位状态经关系变换向整体投票；Pictorial Structures将部位外观与配置建模分开。它们不证明一张刚性矩阵足以描述非刚体动物。
- CompositionalNets把对象与遮挡者的局部解释区分；在明确的二成分模型中，`r_obj=ρℓ_obj/[ρℓ_obj+(1−ρ)ℓ_occ]`。低对象似然不自动意味着应删除任务Mask像素，仍取决于标注语义。
- Slot Attention提供竞争分配；它不授权对允许重叠的实例Mask施加全局互斥，也不要求把所有遮挡关系压成一个整实例DAG。
