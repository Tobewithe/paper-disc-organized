# 方法选择案例

以下为综合论文机制形成的设计建议，不是这些论文已经测过的YOLOSeg实验。

## 两种预训练表示融合

**情境：** CNN局部纹理与Transformer上下文需要共同服务实例Mask。

**首选思路：** 用任务可学习的投影建立消费接口，保留两种信息，再选拼接＋轻量变换或残差融合。若某一路在特定条件更可靠，使用条件门控／注意力；门控输入必须提供与可靠性有关的信息。

**什么时候加蒸馏：** 教师在所需空间关系上有可信能力，并且希望学生继承这一能力。FitNets式匹配限制具体表示，Attention Transfer限制空间激活分布，RKD限制关系；选择所需不变量，而不是让所有特征都相同。[FITNETS] [AT] [RKD]

**应保留的替代：** 单纯加容量也可能解释改善；归一化可能丢失幅度中携带的内容。没有源域／目标域学习问题时，不把DANN当通用模块胶水。

## 新模块很强，接入后整体退化

区分“模块没有目标信息”和“学习新能力时损害旧表征”。若预训练表示已经较好，新头先适应、再联合微调有LP-FT的机制支持；残差适配器、L2-SP、输出保持分别限制结构增量、参数移动和函数变化。[LPFT] [ADAPTERS] [L2SP] [LWF]

它们约束的对象不同。保持项过强可能把原模型的错误也保留下来，完全冻结可能让新任务不可达。先选择主要想保留的内容，保留足够新学习自由度。

## 想改善漏掉的腿或尾巴

如果小部位在输入／特征中可辨但权重不足，可考虑区域重叠项、适当漏分代价或更关注困难位置的目标。若部位已在下采样中消失，优先考虑高分辨率特征与细读出；PointRend表明粗对象预测与精细特征的组合是一条已存在路线。[POINTREND]

Tversky的FN惩罚可能同时带来邻猪侵入；Focal会强调困难噪声；部位辅助任务需要论证其信息怎样帮助实例归属。不要把降低辅助loss等同于改善最终Mask。

## 想解决多个loss“打架”

先区分目标尺度、学习速度、方向冲突和任务重要性。固定加权是合理起点；GradNorm调学习速度与梯度大小，PCGrad处理局部负内积，MGDA处理多目标折衷。主任务优先与所有任务平等是不同问题。[GRADNORM] [PCGRAD] [MGDA]

如果辅助任务本身与部署目标不相关，优化技巧不能赋予它缺失的价值。若两任务需要不兼容的表征，也可考虑共享／专用表示的划分，而不只调整权重。[MTLSURVEY]
