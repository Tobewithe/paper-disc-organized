# 对应、不变性与原型学习

## 信息对象先于表示名称

类语义、同一实例、同一表面点和同一完整对象是不同正例关系。同owner不能保证同表面对应；同一表面在不同图像中的感受野仍会包含不同背景、邻猪或遮挡者。几何对应正确不自动证明将其表示拉近对正常任务有益。

遮挡变化时，身份特征可能需要稳定，可见Mask、可见性与遮挡状态却应改变。把整个Mask或系数都强制不变会与任务冲突。跨姿态、相机、部位和实例对应各有自己的条件，不能从固定相机成对外观推广。

## 原型与连续对应的已有思想

SwAV使用原型分配及跨视图预测，并以平衡约束防止简单塌缩；其原阅读所含固定随机原型对照提醒，分配训练有效不等于学到的原型内容必要。DenseCL、PixPro提供局部对应/稠密预测相关学习，Cross-Image Pixel Contrast和PPAR提供训练期辅助先例。训练后删除辅助头只能验证部署接口，不是训练信息机制消融。

词表的一致重排通常保留损失：原型和分配列一起置换只是重命名，不构成破坏内容的对照。对固定目标y_j，平均逐目标MSE与拟合其均值的MSE相差一个不依赖学生预测的常数，因此学生梯度相同；不能把“先平均”本身当新增学习信号。

代码向量、空间Mask基底、具名部位、对象身份和完整三维模型不能因都叫prototype就互换。VQ压缩、任务驱动字典、检索对应与语义概念监督各有目标；参考重建低误差不保证正常query能检索、真实域可迁移或最终Mask利用其内容。

## 域差异不能只用一个距离概括

真实/合成标签政策不相容时，特征边缘分布相同也可能对应相反目标。图像更真实、全图embedding接近和部位条件可迁移分别判断。逐实例或部位局部比较应统一前景提取方式；真实预测Mask与合成GT抠图的边缘差可能成为域捷径。

无共享有效通道时相似度未定义；全unknown文本编码不是结构特征。不同已知字段集合的相似度不一定可比较。属性缺失与遮挡有关时，只对有答案的样本做归一化会改变目标分布。

SAP的实际合成部位迁移包括ClassMix、傅里叶混合与目标伪标签等条件；原任务有部位mIoU证据，不等于本项目已改善实例AP。其详细迁移与可靠性边界见`yoloseg-method-design`的`references/synthetic-part-transfer.md`。

## 项目中的解释边界

旧局部原型辅助D2比连续辅助C2高2.124169 AP点，却低于无辅助B2 1.740715点，亦低N。这个例子说明相对更差辅助的排序优势与正迁移不同。相关原生参数确实收到梯度并完成更新，不能统一解释为“只有外挂头学了”。

同一任务中，query有非零梯度、内容张量变化、正确内容优于破坏内容、正常任务收益分别提供不同证据。把干预差全归为所命名机制也可能忽略对齐、幅度和分布移位；无效共同重排更不能充当必要性证据。
