# Skill主份与维护

**全部知识以Skill存储和维护。** 本目录是本项目的完整知识主份；`C:/Users/Administrator/.pi/agent/skills/`是当前机器供Pi加载的副本。理论、成熟思想、方法、经验、反例，以及阅读和实验形成的认识均在此维护，不以可复用程度或当前有效为保存门槛。研究Idea和纲要不是知识，不纳入迁移；目标、候选方案、预算与下一步留在原研究组织中。原阅读、实验报告和历史分析保留证据身份与时点，通过链接引用Skill。

按主题查已有知识见[知识入口](../research_notes/README.md)。每个Skill以`SKILL.md`说明覆盖什么问题和何时读取，较长的理论、公式、反例和比较放在`references/`；来源与实际阅读范围保留在`SOURCES.md`、`sources.json`或对应正文中。基础思想也可用Skill保存，无须附带程序或当前实验收益；优先补充已有主题，形成独立知识主题时再新建。

## 更新方式

1. **只编辑主份。** 获得新知识时更新相关Skill正文、依据和适用边界；实质内容变化时更新已采用的版本与变更记录。实验原事实与研究安排回到所属报告／Idea，知识继续由Skill维护；原阅读记录保留当时范围。
2. **生成清单，再同步副本。** 内容审阅后执行下方刷新命令，核对变化，再把受影响的完整Skill目录复制到加载位置。若加载副本出现额外修改，先合并差异。清单只记录文件一致性，不证明方法质量或已经掌握。
3. **更新知识入口的实质变化。** 补充新主题、当前覆盖和重要缺口的链接，不复制Skill正文。调用时读取相关Skill与来源；当前未验证的效果仍按项目证据表述。

```bash
python3.12 -X utf8 project/check_skills.py --refresh-manifests
python3.12 -X utf8 project/check_skills.py --installed-root "C:/Users/Administrator/.pi/agent/skills"
```

只做核验时运行`python3.12 -X utf8 project/check_skills.py`，默认只读。该脚本检查清单、文件集合、版本及内容，带`--installed-root`时还比较部署或恢复目录；不会执行Skill代码或连接服务。

还原时复制完整Skill子目录，保留`references/`、来源、脚本和清单，随后比较哈希。恢复到已有同名目录前先核差异，不覆盖未合并的修改。

## Agent怎样知道有什么知识

Pi在启动时提供已发现Skill的名称、描述与位置，正文按需读取。本项目的[知识入口](../research_notes/README.md)补充主题、依据和缺口；AGENTS要求在方法任务中查阅它。文件已经保存、正文已实际阅读、能够解释并使用，以及当前对象上的效果，是不同事实，不能从安装目录推断全部掌握。

当前项目主份位于`project/skills/`，没有加入第二套自动加载路径，同名Skill仍通过用户目录发现；新增Skill在宿主重载资源或下次会话启动后进入自动发现，本会话可直接按项目路径读取。查询不足时继续向外学习，已有目录不构成知识搜索的边界。
