# 坐标、条件融合与功能依赖

## 在什么空间交互

通道投影解决表示接口，几何对齐解决位置关系；二者不能互代。不同框的同一ROI索引一般不是同一个原图像素，邻实例互斥、覆盖或竞争必须在共同图像坐标定义。物理上两个独立任务Mask可能合法重叠，不能未经标签政策核对就做全局softmax排他。

FiLM按条件调制特征；SPADE保留空间条件；Mask2Former用Mask限制注意范围；CondInst、SOLOv2用实例动态参数消费共享特征。它们分别改变条件表达、读出或支持，不能仅按“都融合对象信息”视为等价。空间几何候选、外观码、部位与实例身份也需要不同输入和监督。

## 门控、残差与梯度

若`y=y0+g r`且g=0，残差参数的梯度可为0，门自身的梯度仍可由r产生；若末级权重为0，较早层也可能暂时无梯度。这是起点的链式法则，不自动表示永久断路。有效非零分支被刻意置零的单步检查，亦不能代替正常优化后的功能利用。

`(P0+ΔP)(c0+Δc)=P0c0+ΔPc0+P0Δc+ΔPΔc`是代数事实。改变P影响旧系数响应，但各项依基底坐标；项幅度大不证明其承担损伤因果。去掉某项、做范数匹配、换坐标与同预算重新训练回答不同问题。旧原生响应漂移文档是未执行提案，只提炼该代数和解释限制，不将假说当已证机制。

门权重、注意力和检索熵受前后尺度影响，不能直接当重要性。函数类能忽略内容，也不意味着训练实际忽略了内容；正确内容被破坏后掉分，仍要解释破坏是否同时改了几何、对齐或分布。

## 空间信息与数值操作

线性池化A与sigmoid一般不交换：`sigmoid(Az)≠A sigmoid(z)`。外部teacher和原生自投影若用不同顺序，会把预处理差误作知识收益。ROIAlign、floor/ceil裁剪后平均池化、原图缩放贴回也非同一算子。

局部RGB、P2细特征、多尺度P3与外部编码器提供不同证据和成本。P3经过颈部已有多尺度信息；从P3取特征不意味着完全没有高层语义。增大输出格或插值P不能创造原生细特征。精细分支的价值需要正常任务输出支持，不能只看张量分辨率。

## 功能简化与计算简化

把逐部位保留图替换成共享图，可能改善或保持任务效果；若原卷积仍执行，只在输出端平均，实际算子成本并未消失。功能消融支持的是输出依赖和可简化性，部署时延还要在删去实际算子后独立测量。

项目V23相关消融中，去形变的AP差很小，外观码与完整候选变化较大；之后共享保留图三seed平均比完整+.148434 AP点。这支持该条件下的功能简化候选，不证明形变普遍无用、共享图拥有全部原有语义或速度已提高。参数量、FLOPs、Slurm时长与预热端到端时延不同。
