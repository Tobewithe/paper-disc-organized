# 独立研究问题：实例尺度条件化的掩码边界校准

本条保留研究问题与入口，不重复维护实验数字和执行计划。

研究对象是框定位较好、目标覆盖充分但包含过多非目标像素的掩码失败。检验模型已有连续 logits 的读出规则能否改善这类失败，并减少对原成功实例的损伤。该路线与邻居敏感 P3 路线独立，实验及论文关联继续按原 Study ID 保存。

当前设计、结果、范围、限制及下一步统一见 [实验报告](../../experiments/mask_boundary_route_20260914/REPORT.md)。代码、输入位置和历史来源见 [目录入口](../../experiments/mask_boundary_route_20260914/LOCAL_USAGE.md)。本条早期版本保存在本次迁移的文档归档中。
