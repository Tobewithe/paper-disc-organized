# 当前失败溯源主线

更新时间：2026-09-15

## 研究对象

当前对象不是笼统的“密集场景”，而是 COCO val2017 中 **one-to-many + NMS 路径没有最终槽位的小目标原始几何失败**。在 3,699 个无最终槽位 GT 中，1,459 个首先失败于原始候选几何，其中 1,429 个是 small。密集、同类近邻、低对比和小尺度是对象属性；只有在对照或干预支持时，才把某一属性写成原因。

## 已建立的证据链

1. **生命周期定位**：87.5% 的无槽位目标在 NMS 前失败，原始几何是最大单类；因此不能把该对象主要归因于 NMS 或最终掩码系数。
2. **配对表型**：384 个类别相同、面积最近匹配且图像互斥的失败/控制对中，失败目标在 P3 局部同时表现为更低正确类证据、更差框 IoU 和更大中心误差，并伴随更低目标/背景对比和更多邻近实例暴露。
3. **像素级受控干预**：提高目标局部对比、移除/模糊/均值化近邻都能恢复失败框；联合干预使最佳原始框 IoU 提高约 0.102、恢复 146/384 个 Box50。软边界和位移伪干预排除了仅由锐利粘贴边缘造成结果的解释。进一步按输入几何预选暴露近邻后，近邻平坦化相对等形、等面积背景对照使 raw P3 Box IoU 净提高 13.864 点 [11.674,16.141]；相对等像素远端实例为 13.493 点，近邻模糊相对背景模糊为 10.438 点。214 个完整失败/成功匹配对的失败减成功交互为 14.604 点。故恢复依赖特定近邻内容，不是任意等量图像简化。
4. **层内干预定位**：只把编辑图的局部 P3 检测头输入移植给原图即可复现几乎全部几何收益；P4、P5 贡献小。故当前可干预对象是局部 stride-8 定位表示。该结果定位模型对人为修改的响应路径，不等同于自然场景的严格因果效应。
5. **训练转换已通过三种子短程确认**：训练期 GT 通过受控输入干预构造特权教师视图，学生仍看原图。宽门控改善目标组但损伤约 0.48 全量 AP；只保留“原图低于 Box50、干预视图跨过 Box50”的救援门控后，固定第 3 轮的 Mask AP 在三个种子分别提高 +0.326、+0.576、+0.247 点。使用各臂 `best.pt` 的固定失败组中，raw Box IoU、raw Box50 和最终 Mask IoU 三个种子均为正向。但各臂独立最佳 Mask AP 只在 seed 0 为正，且尚无 Mask75 恢复，因此是可复现的机制到训练证据，不是最终 COCO 主结果。

## 当前方法假设

对脆弱小目标，普通监督只约束最终分配到的预测，未显式告诉网络“在哪些受控输入修改下，哪个 P3 位置会恢复正确定位”。特权教师利用受控干预后的模型响应提供这一训练信号；救援门控只在干预视图真正跨越几何失败边界时，将位置监督迁回原图学生。

这是一个 **失败条件化的 P3 定位监督机制**。它目前不是 CCL、通用密集正则、推理 ROI 或测试时 GT 方法。

## 已停止路线

- 系数余弦相似作为失败根因：相关链条不足。
- Proto26 多尺度融合或 P4/P5 原型分支作为该失败对象的主要原因：固定候选消融不支持。
- Proto26 语义峰自动找回或跨头类别纠错：选择性不足。
- 对全部目标使用宽泛的干预教师监督：会损害全量 AP。

## 主线状态与下一闸门

机制证据支持：一类 small 原始几何失败与局部 P3 表征中的弱目标证据及**特定近邻内容干扰**有关，并能被相应受控干预稳定恢复。异类和同类近邻均能产生该效应，因而不能把主因限定为同类混淆、系数相似或高 ICI。受控干预引导的 P3 救援监督作为方法候选通过了机制端点：raw P3 Box IoU、raw center error、raw Box50 及失败减控制交互在三个种子均改善；最终 Box IoU、连续 Mask IoU、预测纯度和背景泄漏提供下游支持。原始 COCO 标注上的 `best.pt` 官方 Mask AP 三种子为 +0.205/-0.063/-0.176 点，均值接近零，说明总体效果在当前短程 pilot 中近似中性，而不是否定指定失败对象上的改善。

下一次筛选从开始就使用 `EVALUATION_PROTOCOL.md` 的完整指标组，但按“机制主指标—支持指标—总体护栏”解释，不要求所有指标同时提高。当前失败链与定向评价属于 one-to-many + NMS，标准任务评价属于默认 one-to-one；两条分支分别报告。若充分预算下 raw P3 主指标继续稳定提高且总体 AP 不出现实质下降，即可把 rescue-only 写成论文主方法。
