# 本研究线运行规范

本文件只适用于 `mask_boundary_calibration` 研究线，不是项目全局规范。用户当前线程指定其他研究目录时，以其他目录的规则为准。

- 研究对象：冻结 COCO 预训练 YOLO26m-seg/YOLO26s-seg 的选择性掩码读出校准。
- 主要运行环境：conda `pytorch`；当前已核对的 Ultralytics 版本为 `8.4.100`。
- 默认评价范围：COCO `val2017` 的 4,500 图研究范围；m/s 模型、图片清单、校准划分、checkpoint、seed 和指标以单个实验 `PROTOCOL.md` 为准。
- 当前已记录的默认执行口径为 one-to-one、640 输入、`conf=0.001`、`max_det=300`、FP32；改变口径时在对应实验协议中声明。
- 训练、冻结读出、阈值诊断和迁移确认分别按 Run 记录，不把固定诊断收益当作部署方法结论。
- 论文目录保存研究线文件；实验仍独立放在 `experiments/`，不因论文复制。

研究线入口：`README.md`、`EVIDENCE_MAP.md`、`MECHANISM_EXPLORATION_PLAN_20260920.md`。线程关联以项目 `research_lines.json` 的 `owner_thread_id` 为来源信息，不决定科学结论。

## 评价指标与 GT—预测映射

2026-10-06 按用户指示纳入本主线。依据[《实例分割科研实验规范标准》v1.9 第 6 节](https://github.com/Tobewithe/paper-disc-organized/blob/ab1ea27271087e91b05dd7519b85c0e8d33c399c/project/guidelines/EXPERIMENT_SPEC_STANDARD.md#6-gt预测映射与实例指标)（更新于 2026-10-05，来源 commit `ab1ea27271087e91b05dd7519b85c0e8d33c399c`；原文 UTF-8 SHA256 `970d950b59568887316ff6fc7423b3529833d3f7658abcba60e9cf0a95c761a6`）。本节规定后续实验的评价定义；指标选择、评价图片、阈值、匹配规则和统计单位须在所属实验协议中预先说明。未计算或不满足输入条件的指标保持未知。

### 1. 三种视图及完整身份

先评价固定 raw 候选的几何能力，再追踪这些候选的分类、置信度及输出筛选；追查学习机制时增加当次训练分配视图。三种视图的关联分别保存，不能用 COCOeval 成功对或 TAL 分配替代 raw 几何关联。分数解耦是评价上的约束，不表示网络训练时分类与回归互不影响。

- GT 以原始 COCO `annotation_id` 为实例身份；同一 annotation 的多个 polygon 合为一个 mask。保存其 `image_id`、原始类别、bbox、mask 和 crowd/ignore 状态。原图像素评价使用原始标注解码的 GT。
- raw 候选须在 head top-k、conf 过滤及适用分支的 NMS 之前读取。保存 Run/权重、图片、实际分支、raw index、预测 bbox、系数、共享原型、完整类别分数，以及输入、预处理和解码信息；也可保存足以重建同一候选的冻结输入与源码快照。
- 一个 raw index 的 bbox、系数、mask 是同一候选。最终 `prediction_id` 另存，并能追溯 raw 来源；类别展开出的多条输出不能算作多个独立几何候选。
- 框和 mask 对齐到原图。几何基准沿正常解码流程，用该候选自己的预测框裁切；“raw”不表示关闭裁切。使用 GT 框、关闭裁切或更换系数都属于另一个干预条件。预测 bbox 不能由 mask 外接框替代。
- 主评价使用实际正常推理分支；另一分支独立记录，不混合取最好结果。空 mask 保留候选身份及框，NaN/Inf、缺失数据和不完整候选集合单独记录异常或未知。

### 2. 第一层：分数与类别无关的几何能力

固定完整 raw 集合，对每个普通 GT 计算候选的实际 Box IoU 和 Mask IoU。候选资格、关联、匹配顺序和并列处理不能依赖置信分数、预测类别、类别排名或是否进入最终输出。预测类别正确与否留到第二层检查。

对 GT `g`、候选 `j`，记 `b_jg = BoxIoU(j,g)`、`m_jg = MaskIoU(j,g)`：

| 候选集合指标 | 定义与用途 |
|---|---|
| `B_g` | `max_j b_jg`，保存取得最大值的 raw ID。 |
| `M_g` | `max_j m_jg`，保存取得最大值的 raw ID；其候选可能不同于 `B_g` 的候选。 |
| `M_B75(g)` | 在 `b_jg >= 0.75` 的候选中取最高 Mask IoU，保存该完整候选及两个 IoU；无 Box75 候选时为 null。 |
| `J_g` | 是否存在同一个候选同时满足 `b_jg >= 0.75` 与 `m_jg >= 0.75`；等价于 `M_B75(g) >= 0.75`，无 Box75 候选时为 false。 |

`B_g` 与 `M_g` 不能拼成一条预测的成绩。完整有效 raw 集合按以下五类给 GT 分类：

| GT 级几何状态 | 判据 |
|---|---|
| 存在同候选框、掩码双达标 | `J_g = true` |
| 有达标框，没有达标掩码 | `B_g >= 0.75` 且 `M_g < 0.75` |
| 有达标掩码，没有达标框 | `B_g < 0.75` 且 `M_g >= 0.75` |
| 好框、好掩码分属不同候选 | `B_g >= 0.75`、`M_g >= 0.75` 且 `J_g = false` |
| 框、掩码均没有达标候选 | `B_g < 0.75` 且 `M_g < 0.75` |

五类对完整有效集合互斥且穷尽；异常或缺失不能塞进第五类。若 A 为 `(Box .90, Mask .60)`、B 为 `(Box .60, Mask .90)`，该 GT 属第四类。代表候选只用于可视化和同候选像素诊断，不能掩盖其它候选已达标的事实，也不能决定主分类。

逐 GT 候选存在性与同时可恢复数量分别报告。同一候选可能对多个 GT 达标，但不能重复计入同时恢复数：例如在 Mask IoU >= 0.75 的边上作一对一最大基数二分匹配，得到分数无关的 Mask75 几何可恢复数。这里最大化达标匹配数，不以贪心配对或先最大化 IoU 总和再过滤代替。最大匹配若有多个等规模解，某 GT 未被其中一个解选中不等于它固有失败。

连续质量或失败代表关联须预先登记几何代价、空间关联门槛和稳定 raw ID 并列规则；分割代表优先依据 mask 几何，定位诊断可另用 box 几何，两种关联不能混成一行。无关联保持 null。Box75/Mask75 是诊断阈值，同时报告连续 IoU，可补充 0.50；阈值两侧的微小差异不能直接命名为不同物理根因。crowd/ignore 不作为普通独立 GT。

实现需验证：只改变或打乱类别分数、预测类别及候选遍历顺序，固定 bbox/mask/raw ID 下的第一层范围、关联和几何指标应不变。这层依赖 GT 的存在性或最大匹配是能力诊断，不能称为正常推理召回、COCO AP 或无 GT 方法效果。

### 3. 第二层：分类、保留过程与正常任务性能

沿第一层 raw 身份追踪类别判断、GT 类别得分、输出类别得分、排名、head top-k、conf 过滤、适用分支的 NMS、最终导出及 COCOeval 计数状态。没有该阶段或没有记录时注明不适用或未知，不把所有未输出都归因为低分或 NMS。不能只追踪几何最优候选就宣布漏检，还要检查其它候选是否已正确输出同一 GT。

比较前冻结阈值与数量预算；可以在同一 raw 集合上比较 PR 曲线或相同 Precision 下的 Recall。改变置信阈值后只重算保留与输出评价，不重定义几何质量。

| 正常任务指标 | 口径 |
|---|---|
| Box / Mask AP | 所声明评价图片内的全部原始 COCO GT 上分别运行 COCOeval，保留 crowd/ignore 语义；主 AP 为 IoU 0.50:0.05:0.95 的平均。 |
| AP50 / AP75 | 对应 IoU 阈值 0.50 / 0.75 的 COCO AP。 |
| APsmall / APmedium / APlarge | 沿用 COCO 官方目标面积范围，不能按预测框面积自定义 mask 分组。 |
| AR / Precision / Recall | 若报告，注明评价器、IoU 阈值、面积范围、数量预算、关联方式和分母；固定关联诊断召回不冒称 COCO AR。 |

实际模型输出预算与 COCOeval 计数预算分别记录，例如推理 `max_det=300` 与 COCOeval `maxDets=[1,10,100]`。Box 与 Mask 各自使用正确结果字段：segm 评估不能让 `loadRes` 误用 bbox 面积，bbox 评估也不以 mask 外接框替代预测框。AP 表可用 0–100，底层 AP 通常为 0–1；增益写成 AP 点/百分点并声明量纲，不能把 `0.003` 与 `0.3` 混用。

每个 GT 保存最终对应的 `prediction_id` 及任务成功状态；它不必是几何最优的 raw ID。另保留预测级补表，包含重复、误报、ignore 和预算外输出，避免只看 GT 表漏掉多报。

### 4. 同候选像素质量、裁切支持与配对变化

以下 `G` 为原始 GT mask，`P` 为同一候选按指定流程解码后的预测 mask；表中的 TP/FP/FN 是像素数，须与检测级计数区分：

| 指标 | 定义 |
|---|---|
| TP / FP / FN | `TP=\|P∩G\|`，`FP=\|P\G\|`，`FN=\|G\P\|`。 |
| Mask IoU | `TP/(TP+FP+FN)`。 |
| 覆盖率 / coverage | `TP/\|G\|`，反映自身前景保留比例。 |
| 纯度 / purity | `TP/\|P\|`，反映预测前景中自身 GT 的比例。 |
| `FP/G` / `FN/G` | `FP/\|G\|`、`FN/\|G\|`，分别按 GT 面积归一多画与漏画。 |
| `U_crop(j,g)` | `\|G∩S_j\|/\|G\|`；`S_j` 是该候选真实裁切、缩放、插值及二值化流程允许覆盖的输出像素集合。 |

对有效 GT，`FN/G = 1 - coverage`；`FP/G` 可以大于 1，不能按概率截断。Box IoU 为预测 bbox 与原始 GT bbox 的交集面积除以并集面积，须沿用声明的原图坐标和边界约定。

无关联时，连续质量为 null；有关联且 GT 有效时，空预测 mask 的 IoU、coverage 为 0，purity 为 null。零分母不得填成 0 或参与有效均值；报告样本数、有效分母和缺失/异常数量。诊断召回分母保留全部普通 GT，并明确无关联如何计入；质量均值的有效关联队列另行声明。

对固定候选，`P⊆S_j`，因此 `MaskIoU(j,g) <= U_crop(j,g)`。`U_crop<0.75` 表示仅改变该固定支持内的像素不可能达到 Mask75；`U_crop>=0.75` 只表示支持未排除达标可能，原型空间未必能达到此上界。连续矩形的包含率不能代替真实解码支持，上述结论也不能从一个候选推广到整图候选集合。

像素错误可分自身遗漏、邻居误报和背景误报。邻居区域先排除自身，重叠归属规则提前声明，crowd/ignore 单列。TP/FP/FN 与 IoU、coverage、purity、FP/G、FN/G 是同一像素记账的派生量，不当成多份独立机制证据。

若研究像素区分能力，额外定义诊断像素域 `Ω`，在该域内用本实例 GT 前景/背景作为标签：FPR 为 `FP_Ω/(FP_Ω+TN_Ω)`，TPR 为 `TP_Ω/(TP_Ω+FN_Ω)`，ROC AUC 为连续像素分数的 TPR–FPR 曲线下面积。原 mask 的全图像素计数与取样域内计数分开记录；`FP/G` 不等于 FPR。协议说明域、采样/加权、连续分数、阈值及统计单位；缺少正类或负类时 AUC 为 null，零分母的对应比率为 null，不从一个硬二值 mask 虚构完整排序能力。AUC/FPR 改善不替代原图 IoU 或正常输出 AP。

模型或干预按固定 GT 队列和 `annotation_id` 对齐，不能各自只取成功关联实例再比较均值。同一 raw/detection 身份上的固定关联变化，与改变输出后重新匹配所得的任务收益分别报告。修复/损伤须提前定义成功阈值、基线成功/失败分母、重复匹配规则；净修复数、条件修复率及相对误伤减少比例不能替代 AP 增益。旧 RCMC 固定槽位和 ACD 允许重复 detection 匹配的诊断保留各自协议标签，不合并成第一层最大匹配。

### 5. 训练分配与损失视图

追查训练机制时，额外读取同一前向、同一增强和标签批次中的官方 assigner 结果。TAL 依赖类别分数与框质量，表示当次监督责任，不能作为分数无关的几何身份。

- 分支分别保存 `fg_mask`、`target_gt_idx`、`target_scores`，沿增强及实例排序后的标签索引追溯原始 `annotation_id`；仅 `fg_mask=True` 时的 GT 索引是有效正样本归属，负样本占位索引不能当作 GT。
- 每个 GT 保留全部正样本的数量、raw ID、尺度、实际软目标权重及 box/mask 质量；几何合格候选分别检查是自身正样本、其它 GT 正样本还是负样本，不能只保留一个最佳正样本。数量不能替代监督权重。
- 记录实际训练 mask、GT 框 crop、分辨率及有效像素，分别保存 overlap-mask 排序和原始 GT/训练 GT 的差异。原始 GT 评价效果，训练目标解释梯度。
- 全候选分类、正样本框回归、实例 mask 和辅助语义损失分别记录；依据实际 detach 与梯度路径判断哪些模块更新，不能仅凭 loss 名称推断原型或共享特征得到了监督。
- 固定权重下重算 assigner 只能称当前分配回放，不能冒充官方预训练历史。几何差不等于零正样本；没有专属 box/mask 正样本也不等于共享特征及语义监督全部消失。

### 6. 历史实现、统计与报告边界

- 旧 `shared/evaluation/gt_prediction_mapping.py::associate_instances` 先锁 COCOeval 成功对，再按分数关联余项，只适用于已导出结果的第二层追踪；旧验证不能证明它实现了第一层分数解耦。
- 覆盖全 5,000 张图片的缓存，不等于完整 raw 缓存。存在 head top-k、conf 或 max_det 筛选、空 mask 删除、实际 bbox 缺失时，应注明局限；降低阈值不能找回未保存候选，不能猜测缺失框。旧计数上限和配对竞争记录只支持其原输出层事实。
- 原 RCMC 的 4,500 图确认、其它旧协议的 5,000 图结果及各自固定槽位统计保留原评价范围；本次规范更新不表示历史 Run 已重算为完整 raw 五类评价。
- 报告注明 macro/micro、按图/GT/detection/像素的统计单位，均值的固定队列与分母。涉及同图多个候选的配对区间应说明图像簇抽样；IoU/损伤 bootstrap 区间不能冒称 AP 区间，单次拟合或一个 seed 不能量化训练 seed 不确定性。
- 参照[官方 COCOeval 实现](https://github.com/cocodataset/cocoapi/blob/master/PythonAPI/pycocotools/cocoeval.py)；几何存在性、最大匹配、代表候选、修复/损伤和训练分配均以本实验诊断协议标识，不冒称 COCO 原生指标。
