# 世界模型的行动时间分辨率与可辨识性

本线研究：世界模型在固定采样间隔及区间内恒定动作下预测准确时，是否有依据比较区间内切换的动作？离散端点可能对应多个连续动力学，候选思路是用有限区分性动作获取新证据，改善决策。主张见[行动时间可辨识性Idea](../../../project/ideas/IDEA_ACTION_TIME_IDENTIFIABILITY.md)。

## 当前认识与阶段

目前为问题与实验草案。解析构造提供研究依据，神经世界模型中的发生条件、主动探测效用和相对前作的贡献仍待检验。优先未决项是端点相等、切换控制分离及控制语义的解析复核；该研究顺序由原章程与草案说明，实际执行安排见[当前安排](../../../project/ACTIVE_PLAN.md)。
