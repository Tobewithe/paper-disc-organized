# 世界模型的行动时间分辨率盲区与可辨识性

**英文工作题目：** Action-Time Resolution Identifiability in World Models（ATRI，暂定名称）  
**身份：** 独立科研主线，2026-10-20用户明确要求在 GitHub 登记。  
**研究状态：** 已登记／问题与实验草案阶段；**尚无真实科研 Run、模型训练、GPU 消耗、方法效用或发表意义上的创新性认证**。

## 核心问题

一个世界模型在固定采样间隔、区间内保持不变的控制指令下，能够准确预测所有观测端点，**是否就有依据为采样间隔内会切换的控制动作排序？**

我们的候选解释是：离散端点监督可能无法识别连续时间的唯一动力学；即使在原训练协议下预测充分准确，模型对更短时间尺度或分段动作的决策也可能发生无依据的外推。随机种子集成的一致性未必能排除这种结构歧义；这项经验后果仍须实测，不能提前宣称为事实。

**拟研究的机制原则：** 寻找既符合已有数据又会对某个动作给出冲突判断的「相容反对模型」，再用有限的、受控的区间内切换动作获取区分性证据，检查是否改善真实决策，而不是仅改善训练 MSE。
