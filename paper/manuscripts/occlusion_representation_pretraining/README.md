# 视频遮挡表征预训练

本主线研究如何利用自建三维连续视频的物理监督，学习遮挡发生、持续和解除过程中的可见证据、跨帧对应与不确定性。内容身份需要保持，可见状态却必须随遮挡改变；模型应在证据足够时恢复对应，在证据不足时保留不确定性。研究成果以可迁移的视频预训练表征为中心，动物跟踪是应用案例。

2026-10-19 建立独立研究线；2026-10-20 按用户要求改为视频优先，并已在算力服务器实现和执行最小事件生成、自动标签及模型接口核验。四臂正式任务通过一次性 Slurm 依赖链提交，真实状态看 Study 及执行端 run.json；未完成的训练和评价不计作成果。研究 key、旧草案和历史 Run 保留。

## 研究问题

识别“目标受到遮挡”并不充分约束模型保持目标对应。训练要直接覆盖“可见→部分遮挡→完全隐藏→重新出现”，还要区分出画、模糊、自遮挡与相似目标交叉。视频历史提供额外信息，但完全不可辨的交换不能被训练成必然正确的 ID 恢复。

本线的核心问题是：**在常规视频监督之上，用同一物理事件的可控干预约束内容保持与可见证据变化，能否额外改善未见场景的遮挡后对应，并迁移到实际实例关联？**

这是一项待检验假说。损失函数、数据配对和评价拆分共同决定学习约束；一个公式不能保证对任意类别、环境或任务泛化。

## 三个研究模块

| 模块 | 研究内容 | 计划产物 |
|---|---|---|
| 视频生成与物理监督 | 完整遮挡事件、非刚体表面轨迹、同事件干预、反捷径拆分 | 可复核的视频、自动标签与对照面板 |
| 视频表征预训练 | 对应和无对应、可见状态、条件反事实与可信度，联合训练空间适配和因果时序模块 | 可复用权重、有效梯度与同预算机制对照 |
| 冻结迁移与实际恢复 | 丢弃训练头，验证真实点对应和实例关联，再接入固定 YOLO 前端 | 同一权重的迁移、恢复/误接成绩及可视化 |

后两项的科学效用仍待验证。第一版从训练开始使用视频，当前输出只读取当前及过去；合成真值可用于监督，不能进入学生输入。未知且完全隐藏的内容不要求唯一确定恢复。

## 已有依据与局限

此前独立的[可见性学习实验](../../../experiments/dense_video_occlusion_transfer_20261019/REPORT.md)完成了 72 段场景、2,304 帧和 9,216 条几何标签。合成独立资产测试 macro-F1 为 0.904537；真实 11 段历史留出上 FULL 相对原策略 C 的 IDF1 增量为 0.262926 点，95% 区间为 [0, 0.499987]，打乱对象权重不更差，且整体低于 BoT-SORT。

该实验支持当前合成分布内的状态可学习性，未建立可见性加权的稳定真实任务增益。原视觉骨干及下游身份编码器冻结，新增训练主要作用于状态预测和权重。不能据此断言分类损失、冻结编码器或合成数据必然无效，也不能将新表征机制视为已证原因。

本线的正面依据还包括：已有三维场景可自动提供物理监督，TCOW、CoTracker3 与 TAPNext 系列已建立视频对应和遮挡训练的相关基础。新增贡献必须超过“合成视频＋时序网络”这一已有范式。既有方法范围及来源见[v0.2 证据清单](../../../experiments/occlusion_representation_pretraining_20261019/SOURCE_EVIDENCE_VIDEO_V02.json)。

## 候选模型与训练目标

实际首轮为公开 DINOv2 ViT-S/14＋空间残差适配＋两层因果时序模块；DINOv3 未有可用访问权重，执行前已登记替换。保留初始可见锚点、最近 8 帧观测与递归摘要记忆。基础权重先冻结，适配层和时序表征可训练；权重 SHA、有效参数和运行依赖已通过 E0 核验并冻结。YOLO 先通过旁路表征接口接入，不假定模型权重能直接互换。

模型输出空间特征、时序查询表征、可见对应/无对应分布、遮挡状态与可信度。第一版目标为：

\[
\mathcal L=\mathcal L_{\mathrm{对应与无对应}}
+\lambda_1\mathcal L_{\mathrm{可见证据}}
+\lambda_2\mathcal L_{\mathrm{条件反事实}}
+\lambda_3\mathcal L_{\mathrm{校准}}.
\]

相同物理区域在不同遮挡环境中仍可见时，内容应保持可对应；可见性变化时状态必须响应；重现帧直接监督恢复；证据不足时允许无对应或多候选。校准头只学习正确性概率，不用遮挡比例冒充置信度。

采用已有监督和对比学习构件。候选贡献是完整视频中物理干预与证据条件化约束的增量；不保证数学首创，也不把注意力、正交、因果命名或大模型初始化当作有效性的证明。

## 第一轮如何区分贡献

| 对照 | 目的 |
|---|---|
| P 对普通视频训练 B | 同容量、同视频和预算，只改变内容配对方式，判断新增机制 |
| P 对初始锚点＋当前帧 I | 判断中间视频历史与摘要记忆有没有实际价值 |
| P 对加入隐藏位置监督的 Hpos | 检验已有运动位置先验是否更有用 |
| 原生底座与 TAPNext++ 等成熟参照 | 分别报告总收益和相对已有方法的差距 |
| 丢弃训练头后的冻结迁移 | 判断能力是否保留在可复用表征中 |

主读数为重现后的正确对应；错误补接、拒接覆盖和无遮挡能力同时评价。最小事件合同核验已通过，四臂各 2,000 步预算已冻结并提交；当前完整数据准备运行，正式训练尚未开始。见[E0实际报告](../../../experiments/occlusion_representation_pretraining_20261019/E0_REPORT.md)。

## 论文主张边界

需要同一个预训练 checkpoint 在独立资产与场景上接受检验，并分别报告相对未适配底座、同预算视频训练和成熟方法的收益与损伤。真实点对应与实例关联两类任务的正向证据，是本线提出跨任务视频迁移主张的最低范围。静态检测分割、跨渲染器和长视频泛化另立实验，不能由本轮结果自动推出。

对“因果记忆、关系蒸馏、频域鲁棒性、正交算子”四类建议的具体取舍，见[研究方案第 8 节](../../../experiments/occlusion_representation_pretraining_20261019/PROTOCOL_VIDEO_V02_DRAFT.md#8-对四类创新建议的取舍)。当前优先解决历史证据与可见性变化之间的矛盾，后续方法由真实对照决定。
