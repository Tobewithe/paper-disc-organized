# 论文候选 RLPL：可见对应约束的局部原型学习

日期：2026-11-01。`design_review_complete / hypothesis_only / training_not_started`。

**本次完成的是研究方案，不是模型训练或论文实验。** 用户“多思考完善下，交给你了，你现在把它做完”承接论文主张与最小对照设计；本次只做文献、既有结果复核、设计及本地抽象核验。当前执行路由只见[总控](../../../project/ACTIVE_PLAN.md)；[Study](../../../experiments/spm_registered_prototype_learning_20261101/study.json)不开放训练。旧 +5 目标、损伤规则、V23结果及 test426 封存保持。

## 一页主张：我选择什么，为什么

**我主张优先研究：可控合成的“同一可见局部”对应关系，能否通过训练期原型分配，提升原生 YOLO 分割分支的真实泛化；而不是再增加推理时的记忆检索和掩码修正网络。** 暂名 Registered Local Prototype Learning（RLPL），只是工作名称。

保留“从合成数据学习可复用猪体视觉知识”的 idea，但明确调整原型角色：**跨样本共享的局部特征原型只参加训练，知识最终进入原生分割权重。** 不再要求正常部署必须检索外部库。它不是具名解剖部位、完整三维对象或隐藏轮廓模型；如用户仍要求部署时持久对象记忆，此候选不能冒称满足那一不同目标。

| 维度 | 这一个完整研究候选 |
|---|---|
| **问题** | 旧系统 V23 对原生 +3.409778 Mask AP，但对 C21 仅 +0.336752；内容破坏的有效覆盖不足，后继正确/错配记忆未体现稳定优势。问题不是“还能不能加模块”，而是**原型学习是否能在相同新数据与预算下，比普通表征训练多带来真实可见分割收益**。 |
| **机制假说** | H：用渲染器核实的同实例、同投影位置、双方可见局部约束共享原型分配，能减少局部表示对材质、光照、背景及外围遮挡的依赖，同时由正常实例 Mask 监督保留归属/细节。竞争解释 H_data：只是合成覆盖与普通一致性有效；H_reg：一般聚类正则即可，准确对应或学习到的原型内容并不重要。 |

| **整体结果** | **尚无 RLPL 模型或 AP 结果。** 正面依据来自旧快速试验“免检索仍保留训练收益”、可控外观对读出的实际影响，以及 DenseCL/PixPro/SwAV 的表征学习依据；它们支持检验训练期表示，不证明 RLPL 已有效。V45只解决一个场景的实例标签闭环，成对关系与多场景数据还未验收。 |
| **研究决策** | 保留原型作为有明确去留条件的训练方法候选，停止把常驻原型库当作必需结构。下一行动仍是总控中的变量场景接入 V45 标签出口；本设计给出其后成对数据所需字段，不在本轮启动生成或训练。D若不超过同信息 C，就优先保留普通对应学习/数据收益，不继续加槽、换门控或延长此配置。 |

**拟议论文主张（只有实验通过后才能用陈述句写入摘要）：** 在检测路径与推理结构不变的条件下，几何与可见性登记的局部原型分配训练，比同数据普通分割训练、同信息连续对应学习及近邻原型训练获得更可靠的真实猪群可见实例分割。新增价值应是**监督关系如何构造、如何传入原生任务特征及其受控效用**，不是“首次使用原型/合成/无额外推理开销”。

**创新性主判断：值得作应用型训练方法候选，但目前不能声称独创机制或已具备投稿结果。** SwAV、像素对比和原型域泛化已覆盖大量基础做法。只有在同信息强对照之上仍有稳定增量，且正确对应确实必要，才值得以该训练方法为论文主贡献；否则转为合成数据/普通训练结论，不强造原型创新。完整近邻核查见[文献审查](../../../project/research_notes/literature/spm-prototype-candidate_2026-11-01/README.md)。

## 2. 原型是什么、怎样学习、如何关联实例

### 2.1 唯一最小架构

记 `Bθ(I)` 为原生 YOLO 的逐图空间Mask基底，`cθ,i(I)`为第i条真实输出的系数。知识原型记为 `U∈R^(K×d)`，**U与B不是同一种“prototype”**。

```text
RGB ──冻结共享主干/Neck──┬──冻结检测分支──固定Box/Class/score/检测行
                        └──可训练原生分割专用分支──Bθ、cθ──原生可见Mask
                                                   │
                                      仅训练：局部gφ→共享原型U→对应损失
                                      合成owner/映射只进损失，不进部署forward
```

- 首选辅助特征为**原生Mask基底张量Bθ**，取共同成像坐标上的局部向量，不读取已解码Mask、V23修正概率或GT裁剪作为网络输入。投影 `gφ:32→64→64`，ReLU，无新增共享BN；`d=64、K=32`为首个候选默认，禁止以不同K搜索追阳性。
- `U`存局部特征空间的共享单位向量，由训练更新；它不是一头猪的身份、一个命名器官、模板Mask或物理三维坐标。跨图重复模式可能存在，**不能仅凭聚类可视化宣称语义部位形成**。
- 只允许原生 `proto` 与 mask-coefficient 专用分支（包括该版本实际O2M/O2O专用参数）、`gφ/U`更新。冻结Backbone、Neck、Box/Class、共享BN统计；具体参数名与detach图须以正式环境的源码再列白名单。保留原生联合训练语义，不能为获得梯度删除O2O detach。
- 训练样本通过renderer的 `owner_id + correspondence_group_id + 成像映射`关联同一实例的可见点。**部署实例绑定仍由原生检测行及其系数完成，不新增对象ID输入或跨实例硬排他。** 因而本方法检验局部表征辅助，不声称解决了新的实例识别/绑定算法。
- 导出删除 `gφ/U`，不增加推理网络、检索或后处理，保留训练后的原生分割权重。结构上预计无新增推理算子；实际导出parity、显存和延时仍须测量，不能把预计当测得0开销。

### 2.2 训练目标：借鉴已有分配学习，不冒充新基础loss

对同一实例两视图的合格对应点 `u↔v`：

`z_a=normalize(gφ(Bθ(I_a)[u]))`，`p_a=softmax(U z_a/τ)`；b侧同理。

采用**SwAV式、stop-gradient的平衡软分配q**，对有效局部token池做Sinkhorn；目标为：

`L_proto = mean_by_group_then_owner [ mean_valid_points (CE(stopgrad(q_a),p_b)+CE(stopgrad(q_b),p_a))/2 ]`。

`L = L_native_instance + λ L_proto`。

候选默认：`τ=.1、Sinkhorn ε=.05/3次、λ=.1`，前100步原型向量不更新，其后行归一化；没有EMA教师、SAM/CLIP或额外预训练器。**这些是已有训练技术的起点，不是文献在猪任务上验证过的最优值。** 冻结前可以修数值/接口错误，正式Run后不因结果改loss、K、阈值或预算。

- 每owner每对最多32个合格token，先按独立组/owner均衡，再在局部采样；大猪不能靠面积获得更大损失权重。同一组的派生视图不当独立样本。
- 每步有效token池不足 `4K=128` 时该步辅助项明确为0并登记，不能复制同一点凑分母；正常分割监督仍运行。正式训练前的只读数据验收要求至少95%的预生成batch日程可满足此数，否则不启动本默认配置。
- q的均衡占用由算法强制产生，**均衡占用本身不能证明无坍缩**；同时检查样本间预测差异、原生特征有效梯度及真实效用。辅助loss下降不算机制阳性。
- 不要求两个不同遮挡视图的整个Mask、实例系数或整图特征相同。只匹配双方可见的同一点；被挡部分仍按该视图正常可见Mask监督为非目标。
- 不对跨图两头相似猪强行设置身份负对；实例分离仍由正常任务监督承担。
- 双方可见不等于卷积感受野的全部上下文相同。外围遮挡仍可能提供有用实例线索，过强不变性可能将它抹除；因此这只是有对照的假说，不是几何关系自动保证有益的定理。真实损伤或C优于D会改变方法选择。

### 2.3 两个必须排除的“看似创新”

**均值原型的MSE并不自动增加新信息。** 对固定目标`t_j`与均值`μ`：

`mean_j ||s−t_j||² = ||s−μ||² + mean_j ||t_j−μ||²`。

右侧第二项对s为常数，所以“先平均成原型再MSE蒸馏”与同权逐目标MSE给学生的梯度完全相同。本候选不以这件事包装原型创新；软分配训练虽不具有该简单等价，仍须胜过连续学习。

**无序原型库整体重排不是破坏。** 同时重排U、q和预测列，损失不变。训练期头在导出后删除亦按设计不改变输出，不是“模型没有利用原型”的反证。作用必须用匹配重训练对照证明，不能套用旧推理库的off消融。

## 3. 数据合同：现在最少需要补什么

**不等待精确器官GT、完整amodal、神经成像或新身体模型。** 首个候选只要求实例可见Mask与可核实的同投影局部对应。

每个独立几何组先生成三视图：

1. A：固定目标猪几何、姿态、相机及基础场景。
2. B：同一目标投影，仅改变材质/光照/背景外观；禁止借外观变更偷偷改变轮廓、位姿或成像映射。
3. C：保持目标猪和相机，改变已具资格的设施遮挡；目标的可见Mask随之改变。先不用会令目标产生接触形变的移动邻猪，以免把同owner误认成同表面对应。

A/B全域也只在高置信可见目标处匹配；A/C取双方可见交集。优先原生共同像素网格；应用monitor/crop等映射时显式保存并核重采样。**同owner相等只是必要条件**：目标mesh/pose/camera签名不同立即拒绝该配对，而不是假定同位置仍是同一点。若将来跨姿态/相机，需要新增源面/重心或深度重投影资格，不纳入本首轮。

最小发布字段：`geometry_group_id、view_id、owner_id、target_mesh_pose_hash、camera_hash、imaging_map_hash、changed_factors、RGB/instance_mask/validity的SHA、visibility_intersection、source_family_id、real_reference_source_group、split`。像素validity只屏蔽不确定边界，不把未知当背景；训练正常可见Mask与辅助对应的有效域分开。

- 现状：V45仅1独立场景，原图/monitor/crop是派生图，不是合格三视图组；没有宣布成对对应、部位GT或多场景release通过。
- 设计默认的有限数据规模为**200个独立几何组×3视图=600图，160组训练、40组合成QA**；同组及其所有派生只能在一个split。它是新候选的待批准数据预算，不改当前V1的100场景待冻结建议，也不声称多个随机种子是独立身体家族。
- 生成器对真实数据的使用继续限批准TRAIN RGB；禁止原真实Box/Mask/姿态或dev/test参与生成拟合。**未来正常监督训练若用1272 real/train原标注，须另行明确读取范围与授权；本次没有读取这些标注。** 两个合同不能混为“合成现在可以读真实GT”。
- 标注语义先核栏杆、遮挡、断片、细附件：物理可见性标签不自动等于真实数据标注惯例；无法统一时在release中明示并暂停以该批数据做效用归因，不篡改真实标注。
- 第一行动仍按总控做变量场景的V45出口集成；上述三视图生成与200组发布**均未启动**。数据签名、对应与覆盖不通过，就停在工程阶段，不换用旧合成充数。

## 4. 最小公平对照与机制删除

| 臂 | 数据与正常任务 | 辅助学习 | 回答的问题 |
|---|---|---|---|
| A | 同起点、真实训练，同总更新/图像槽预算 | 无 | 新混合训练方案是否优于真实训练；与B的真实/合成曝光差分别报告，不伪称完全相同数据。 |
| B | 真实+新合成，原生分割专用适配 | 无 | 新数据/正常训练能得到多少收益。 |
| C | 与D完全相同的RGB、标签、对应、batch日程和优化步数 | 同维连续对应学习 | D是否超出一般对应监督；**首轮最重要对照**。 |
| D | 同B/C | 本方案局部原型分配 | 完整候选。 |
| E | 同D，包括原型容量、owner有效域与像素预算 | SwAV式分配，但用DenseCL式局部特征匹配建立跨视图对应 | 准确登记对应是否超过最相关的已有技术组合。属于任务适配对照，不冒称复现原论文整套结果。 |

**首轮仅B/C/D三臂，各2000更新、同一个种子、固定末checkpoint；不先跑全部矩阵。** 每步2真实图+2合成组的6视图，共8图，每臂16000次、三臂合计48000次图曝光，三臂的输入日程完全相同；B仍见全部视图和可见Mask，不允许D独享额外图。C/D都从Bθ走同一`32→64→64→32`参数载体；D最后矩阵解释为U，C用于未归一化连续投影，采用VICReg式不变性/方差/协方差目标。不得在L2单位向量上强行要求逐维std≥1。C的三项权重预设25/25/1，乘统一辅助权重.1；C/D末矩阵均采用相同初始化、行归一化及前100步冻结日程。归约和梯度规模在资源预检固定，正式后不改。

C/D部署参数完全相同，辅助载体可训练参数数目相同且都有非零梯度；B的辅助参数为0，不能声称B与D有效训练容量完全相同。报告参数/实际FLOPs/训练时间；不靠堆未使用参数假装匹配。不同目标的归一化和优化偏置属于方法差异，单一对照不能排除所有训练正则解释。

D有实用增量后，论文确认才补A/E及以下必要干预，预算另冻，不自动20k/多seed：

- **D−correspondence：** 同数据、同owner、同有效点集合、同原型参数与更新，把对应点在同owner合格区域内作预固定的非恒等错配。保证不是仅重排token顺序、交换整对或改变valid点数；保留内容分布与幅度，移除空间对应。它是定向机制干预，不是公平强基线，不能用打坏的结果代替C/E。
- **D−learned-content：** 相同随机初始原型固定而不更新，其余同D。SwAV已发现随机固定原型也可能有效，所以必须区分“分配正则有效”与“学到了必要的猪体原型内容”。这一臂少了U的有效更新，存在训练容量/优化混杂；结合等参数C/E判断，不凭该臂单独作纯内容因果归因。
- 以上是**从共同起点的匹配重训练**，不是在部署时关闭已不存在的辅助头。没有通过这些证据，不把标题升级成“可解释部位记忆”或“完整对象知识形成”。

## 5. 主指标、统计与预写三出口
