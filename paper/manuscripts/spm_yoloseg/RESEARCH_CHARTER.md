# SPM-YOLO 研究章程（设计草案，2026-10-21）

**2026-10-22 基础实现补充：** 本章程保留最初研究构想；当前实施细节读[基础方案V0.1](BASE_IMPLEMENTATION_SPEC.md)。首版只用P3、单猪可见实例任务、共用RLE加载器、冻结查询来源，并保留原生O2M/O2O训练。真实高频、P4与完整效果矩阵为后续扩展；先完成必须的实现接口，再讨论效果。没有已冻结Run被替换。

## 1. 定位与科学假说

目标：以一篇可复现的农业视觉应用研究论文为先，研究从 Blender 与真实猪群数据学习**持久、可冻结、可检索的视觉原型**，能否为 YOLO26-Seg 的遮挡实例分割提供额外有效信息。

- **H（待验证）：** 若局部猪体/场景的重复视觉模式可压缩为跨图像原型，基于当前 P3/P4 特征选择性调用原型可在密集、部分遮挡时改善表征和可见区域分割。
- **H_alt1 数据量/合成增强解释：** 单纯用相同 Blender 图训练基础 YOLO 就可获得全部收益。
- **H_alt2 容量/优化解释：** 同参数的普通残差 MLP、注意力或增强训练已经能取得相同收益。
- **H_alt3 域错配解释：** Blender 原型主要捕获渲染器纹理/场景捷径，在真实测试域退化；真实原型或混合原型效果不同。
- **H_alt4 记忆无关解释：** 性能来自检索/门控参数，置乱/替换原型后结果不变。

支持 H 需相同训练图像、可训练参数和预算下的公平对照，以及同 checkpoint 的记忆干预；不得把结构接通或 AP 上升直接称为机制已证实。已有猪场遮挡观察仅为立项动机，本线具体困难子集和效应须由新的独立数据冻结定义。

## 2. 数据链：Blender + 公开/自采猪场

### 2.1 Blender 合成生成器

以用户已有的猪 3D 模型/步态动画为基础，随机化：个体形态与材质、体态/朝向/大小、相机位置与角度、场地纹理/栏杆/食槽、明暗/阴影、个体数量、邻接/遮挡程度。拟优先 BlenderProc 或等价可复现渲染脚本。

逐图导出：
- RGB、每猪 bbox、**可见** instance Mask（与目标 YOLO-Seg 训练口径一致）、实例 ID（仅图内）；
- **完整** amodal Mask、可见比例/遮挡程度、深度与姿态（仅合成数据的辅助分析信号，默认不作为检测头的额外监督）；
- seed、场景生成参数、模型资产版本、渲染脚本/Blender 版本、图像及标签 SHA。

**初始数据预算只是设计建议：** 3,000 张＝稀疏/中密度/高密度各约 1,000 张；先小规模画质/标注审计再扩大，不视为已采集。一个基础 3D 猪模型并不能自然产生真实种群的形态多样性，需要主动测域差并覆盖多个模型/材质或形变条件。

### 2.2 真实公开数据

候选 PigLife 与自采群养猪视频。验证每个来源的版权/使用限制、标注格式、可见 Mask 定义、影像分辨率、录制单元；PigDetect/PigBench 等只有 bbox 的来源可用于检测任务独立验证，但没有可见实例 Mask GT 时不能用于 Mask AP。

先按 **猪场/猪栏/拍摄视频/时间段**分组划分，后抽帧；同源相邻帧不可跨 train/val/test。渲染数据必须有独立场景/资产/随机种子簇；真实最终测试簇严格禁止进入原型提取、投影训练、阈值选择和模型选择。记录来源比例与模型是否见过对应猪栏。

### 2.3 混合信息公平性

- B：真实 + Blender 训练的原生 YOLO，与知识模型 E/F 见**完全一致的训练图、掩码和训练预算**。
- A：只有真实训练，识别合成数据本身的贡献。
- 合成特有的 amodal/深度/姿态标签第一版只用于分层分析，不直接作为改进模型额外训练信号；如引入必须增加同信息对照。

## 3. 原型特征空间与记忆发现

提取一个**已训练基线** YOLO26-Seg（明确精确 commit/version 与权重 SHA）的 Neck P3/P4 特征。各层用可学习线性/1×1 投影映射到共同 `d=128` 维并归一化：

\[
z_i=\mathrm{normalize}(W_e F_i),\quad z_i\in\mathbb R^{128}.
\]

训练投影器时冻结基线特征网络，使用：
1. 同一图像两种增强视图、**由可追踪几何变换建立的空间对应**，鼓励对应位置特征稳定；
2. 可见 Mask 的前景/背景监督，使图像特征至少对猪体/环境可分；
3. 可选的来源均衡/轻量域正则；不以不同猪个体为天然对比负例（它们属于同一检测类别，强行分离身份未必帮助检测）。

之后按前景/背景分成两个候选记忆库。在训练**数据**上均衡抽样局部 token，采用动态聚类：
- 对每个特征 z_i 找最近中心 p_k；
- 若平方距离大于预冻结阈值 λ，建立新簇；否则更新中心；
- 预冻结近重复合并、最低支持数清除、容量/内存保险上限及遍历顺序；
- λ 和其他原型规则只能用训练/开发数据定，不用最终测试集反调。

对应 DP-means 风格目标：
\[
\min_{P,K}\ \sum_i \min_{k\le K}\Vert z_i-p_k\Vert_2^2 + \lambda K.
\]

K 是**通过阈值和数据自适应确定**，而非语义原型数量先验；设置资源上限属于工程防护，须披露是否触及上限。主要比较自动 K 与固定 K-means/随机向量的匹配资源版本。可视化只提供解释证据，不宣称自动形成了猪头/背/蹄的语义部位。

保存 `pig_prototype_memory.pt`：`foreground_prototypes [Kp,128]`、`background_prototypes [Ks,128]`、投影器配置/权重、特征归一化规则、训练源分布、数据/基线/代码哈希和 K 选择日志。冻结原型向量，查询投影的更新策略必须单独登记，防止构库与查询空间漂移。

## 4. 注入：Neck P3/P4 → Segment26 之前

第一阶段仅改 P3；通过效果门槛后加入 P4；P5、原生 mask head、Proto26 和原有掩码系数保持形状/语义不变。640 输入下候选空间尺寸约为 P3 80×80、P4 40×40（以锁定源码和具体模型实际输出为准）。

给每个空间位置：
\[
q_i=\mathrm{normalize}(W_qF_i),\quad
s_{ik}=q_i^Tp_k/\tau.
\]
分别在猪体原型和场景原型中进行 Top-k 候选查询，检索原型响应与相似度统计进入门控网络。汇总：
\[
r_i=\sum_{k\in\mathrm{TopK}(s_i)}\mathrm{softmax}(s_{ik})p_k,
\quad F_i'=F_i + \alpha\,g_i W_o r_i.
\]
\[
g_i=\mathrm{sigmoid}\bigl(W_g[F_i,s_i^{fg},s_i^{bg}]\bigr).
\]

- `alpha` 为**可训练**残差幅度，初始 0，以确保第 0 步与原 YOLO 的 eval 输出一致；此时检索分支梯度初始可能为 0，必须检查后续 alpha 与投影器梯度都真正流动，若出现训练停滞需先列为工程问题。
- Top-k（初始候选 4）、温度、投影维度、背景库是否启用均是**待冻结的超参**，非验证结果。
- 在 `Segment26` 外围薄包装器中注入增强后的 P3/P4，再调用**精确锁定版本**的原生 `Segment26.forward`；注册到 `parse_model`、保持 end-to-end one-to-one/one-to-many 的合法输出/梯度、语义辅助头、推理后处理及 mask crop/upscale 口径。
- 推理只需当前真实 RGB 与打包在模型内的冻结记忆，不使用 Blender 输入、不调用测试 GT、不实时更新库。
- P3/P4 解冻后造成的查询空间漂移需要额外核验：优先保持冻结教师特征作为查询键，或显式约束新/旧投影一致；不得假设冻结库天然与已改变的 Neck 表征兼容。

**YOLO 内建 Mask Proto 与本方案记忆原型是不同定义**：前者为输入图像的空间 mask bases，后者是跨图像可查询特征向量。本文第一版**不修改实例 Mask 线性组合/32维系数机制**。Box 与 Mask 改善应单独检验；不得把历史系数 Oracle 当作本方法成立证据。

## 5. 分阶段最小研发路径

| 阶段 | 目标 | 成功及退出条件 |
|---|---|---|
| P0 数据/架构审计 | 数据可见 Mask 口径、来源分组防泄漏；锁定 YOLO26-Seg、代码版本、基线权重、Segment26 插入点、硬件及预算 | 标签可视化、划分清单 SHA、原生推理复算合法。失败先修数据/接口，不启动正式训练 |
| P1 公平基线 | A 真实-only、B 真实+Blender，同设置训练与真实独立测试 | 对合成数据的收益/负迁移给出事实；若 B 退化先解决域差，再决定是否构库 |
| P2 表征/原型 | 编码投影训练、前景/背景 token 平衡采样、动态发现 K、冻结库与诊断 | 两来源可检索，真实检索失败/覆盖问题有归因；如全为渲染器捷径则暂停知识注入 |
| P3 机械注入/短程 pilot | P3 query+gate，zero-alpha 等价、梯度/EMA/负载测试、少量图训练 | 首先要求合法、可复算且无大幅损伤；若无额外收益或开销不合理，停止扩展 P4 |
| P4 公平评估 | 固定数据、预算、等容量控制、真实/合成/混合原型与记忆置乱；独立评价 | 同配置主指标、遮挡子集、CI 与成本都完整，按预冻结标准判断论文价值 |
| P5 论文定稿 | 方法/数据/对照/跨场景、必要消融、推理效率和复现实验 | 结果无论阳性阴性如实存档；论文目标是应用价值，不承诺录用或分区 |

## 6. 贡献资格与论文定位

目标论文题目（暂定）：**Synthetic-to-Real Prototype Memory Guided YOLO for Pig Instance Segmentation**。

可争取的三项贡献：① 可重现的 Blender+真实双源知识采集；② 具有冻结/查询语义的自适应原型记忆与条件门控注入；③ 独立困难子集的性能—成本—归因评估。每一项只有在对应受控结果支持时才能写成实证贡献。合成、原型/记忆、对比学习、条件融合均已有前作，必须在论文冻结前核查相近方法，不能把模块拼接本身描述为全新理论。

最关键的对照是 **B vs E/F**（同样合成图训练）、再看等参数无记忆对照以及推理时记忆置乱。如果提升仅来自 B，停止宣称「原型记忆改善分割」的机制贡献，优先将精力转到真实域数据质量/遮挡采样这类有证据的有效因子。
