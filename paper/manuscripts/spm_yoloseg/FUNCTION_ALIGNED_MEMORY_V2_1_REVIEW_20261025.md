## 2. 第二轮：数据—表示—检索—重建逐接口对齐

### 2.1 两种数据各补自己有真值的能力

**合成支路**提供部位、规范坐标、姿态、完整/可见身体、局部深度和遮挡者身份。修正旧prone来源，增加实际体形/尺度角色与视角覆盖，保留至少15头真实互遮群；不能只增加同一个网格的随机渲染张数。清晰实例和空栏也保留，否则检索器没有干净对象与拒绝参照。

**真实支路**从原1272张训练来源学习实际可见实例，不再只给未知细语义−100、给背景reject。除原图外，构造训练来源内部的受控遮挡/Copy-Paste配对：同一实例被额外遮住前后，保留原可见像素对应、实例身份及新增遮挡关系。原图本来不可见的区域依然未知；“恢复遮挡前已知轮廓”不能叫恢复真实完整身体。相机噪声、光照、纹理来自train；dev复刻场景不进入训练。

真实配对连接了“实际成像—同对象—遮挡变化—重建”的监督链，但**相同的错误词条也能满足一致性**，所以配对一致性只是必要约束，不能替代已知语义和最终任务验收。Copy-Paste的既有分割研究只支持其作为数据手段，不保证本项目有效。[一手来源](https://openaccess.thecvf.com/content/CVPR2021/html/Ghiasi_Simple_Copy-Paste_Is_a_Strong_Data_Augmentation_Method_for_Instance_CVPR_2021_paper.html)

每次改变RGB、几何、遮挡或成像后，都重新提取相应冻结视觉特征；禁止新RGB搭配旧缓存。缓存以实际RGB、变换、冻结权重及投影SHA绑定。几何变换同步更新全部已知字段，非几何变化不得改变标签轮廓。小目标采用覆盖率监督，不能因最近邻缩图把细腿和仔猪删除。

### 2.2 四类对象以不同形式衔接

| 接口 | 本版选定形式 | 传给下游的内容 |
|---|---|---|
| 实例→整体 | 原生最终检测行、显式ROI坐标、内容证据→整体key检索 | 可变形身体对象、姿态假设、部位锚点、可见性未知域 |
| 整体↔部位 | 部位局部对象、规范位置、父子连接、同实例身份 | 约束整体的局部证据，以及整体对部位布局的限制 |
| 身体→遮挡 | 目标与邻实例/设施的局部有向关系 | 有实际遮挡者支持的可见归属；未知区域不当作背景 |
| 可见候选→边界 | 内外轮廓、两侧角色、高分辨率局部证据、边界模板 | 窄带内受限修正后的对象可见候选 |
| 对象候选→任务 | 与原生Mask比较，分成补充、删除、保持 | 同一原生检测的受限修正，全部检测保留评价 |

128维key只负责寻址；value及类型解码器保留v2的差异。初始容量仍为整体128、部位256、关系64、边界64，维度/容量不声称实测最优。无来源的槽位不强行激活，不用“每图均匀调用所有词条”的惩罚制造利用率。

**姿态先分假设，再组合相容条目。** 站立与侧卧不在latent里直接平均；有充分证据时站立候选排序最高，不充分时保留多个解释。每个候选独立重建后按正常输入证据选择，不能看GT选择。部位可同时调用多个相容词条，但不得混入邻猪的部位。

真实已知前景采用兼容集合正向目标；背景单独拒绝。细部位、左右侧、姿态未知时不编造标签。细语义正确率只能在有合法真值的对象上报告；真实遮挡配对可以提供实例绑定证据，不能冒充真实解剖标注。

**未匹配检测不等于没有猪。** 同一头猪的重复检测、邻猪部位落入ROI、关联歧义与真正背景分开。训练关联只按预冻结类别/框规则建立，多条检测关联同一GT时记录并处理重复权重；不因一对一名额用完就给其余真实猪查询reject。没有明确实例归属但含已知猪体的区域，保留前景与归属未知；只有合法已知背景才作无对象负例。这也避免将检测去重规则错误传递成对象词表语义。

### 2.3 三个容易漏掉的部署接口

- **实例数量与集合：** 遍历原生全部正常检测，分块处理；不沿用V20的64个learned queries或补网格候选。未检测到的猪不会由本版新增检测行，固定检测策略给Mask收益设定范围。
- **邻居与设施：** 密集关系按空间支持提取，记录溢出与未知遮挡者；不默默丢掉第9个邻居，不把漏检邻猪当“没有遮挡”。设施在真实域无标签的区域保持未知，不因一条暗纹就擦除猪体。
- **坐标与解码：** 图像letterbox、原生mask格心、ROI、规范坐标、最终paste/crop全过程显式转换。首个基线沿已选强原生SHA `0e40602f1dbf0697fd49fa8e9f887c068970e3c5c39bd618f66e483c8712c8d6`；实际输入、版本、分支、阈值及源码另核，不从历史文件推定。

## 3. 第三轮：把对象能力变成收益，避免覆盖正确答案

### 3.1 选定原生锚定的对象纠错读出

正常图像同时得到原生logit `z0` 和对象重建分支的可见候选 `zm`。后者必须经过整体/部位value解码、受限几何、遮挡归属与局部边界，不能由另一自由RGB分割头直接生成。

保留原生`z0`的原格点/精度，只把对象修正映射回去；不将原生Mask缩成64格再贴回。否则即使名义残差为0，也会因重采样损失细节。最终使用与原生相同的上采样、裁剪、阈值和RLE路径。

在相同格点和原生合法裁剪域内，定义：

\[
r=\operatorname{clip}(z_m-z_0,-B,B),\quad
r^+=\max(r,0),\quad r^-=\min(r,0),
\]
\[
z_{final}=z_0+g^+r^++g^-r^-,\qquad 0\leq g^+,g^-\leq1.
\]

`B`、候选支持域、gate粒度和全部数值在执行合同中一次冻结。幅度上限若小于原生错误像素的logit间隔，再正确的对象也不能改变其二值结果；须在train工程输入上核实可翻转范围及固定框裁剪机会，不能把表达受限误判为检索失败。该可达性核验不等于部署收益。首版gate采用**实例级的增/删两个标量**，依据相应区域的检索相容性、对象—原生差异和可见证据摘要；不使用一个自由像素gate重新完成分割。对象值与gate都要单独留图。

原生起点避免在训练第一步丢失已有能力；**它不保证训练后无损**。只有门关闭时严格回原生；门打开后的全部修复与损伤仍需真实验证。边界只修对象候选的窄带，包括合法内轮廓；大范围遗漏由身体/部位候选提出，不能把补身体任务塞给边界。

这里将“对象必经”的要求落实为：**每一次新增修正都依赖对象内容；正确的原生输出可以保留。** 若全部gate关闭，最终可能等于原生，但不能称原型有效。相反，强迫每个实例使用原型只是计算依赖，不能代替净效用。

### 3.2 增删的监督必须对应实际代价

训练GT与固定原生二值Mask确定四类区域：应补的FN、应删的FP、应保留的TP、应保持的TN。它们用来监督训练中的增/删接受及任务结果，GT不进入正常前向。对象提议方向错误时gate只能拒绝，不允许靠另一个分割器反向补偿。

gate是实例级，动作目标也必须按同一实例归约：在train上分别回放仅增、仅删的固定提议，按其真实增益/损伤监督条件gate；无合法归属、无实际提议或无有效标签的项保留无监督状态。该直接动作监督在全局幅度为0时仍训练`h±`，不能只通过最终Mask反传。完整方法仍评价增删同时作用的最终结果，训练GT接受器不进入部署。

对固定实例，原生TP为`t`、GT面积`G`、FP为`F`；误删TP `a`、补回FN `b`、删除FP `c`、新增FP `d`。则：

\[
IoU_{new}>IoU_0\iff (b-a)(G+F)+t(c-d)>0.
\]

这说明增删必须联合计价；不能只奖删除FP。该式是固定实例的判据，不是AP公式。损失以合法域内的可见Mask主任务为核心，附加明确的对象/匹配/动作目标；不为四类记忆复制四份完整Mask损失，也不把原生预测全当真值强迫复制其错误。

### 3.3 零起点与梯度不能互相抵消

首版幅度写成 `g± = alpha± × sigmoid(h±)`；两个全局`alpha`初值0、优化后投影到[0,1]。gate分支不再叠一个零初始化输出层。这样初始输出精确原生，非零对象提议可以给`alpha`梯度。

初始`alpha=0`时最终Mask梯度暂不到对象和条件gate，这必须承认并处理：对象依靠A/B直接监督，条件gate依靠上述直接动作监督；任务接通后让幅度获得梯度，再按冻结日程释放低学习率适配。不能让“gate=0、提议=0、两边又没有辅助目标”同时发生。梯度检查验证的是实际图像及白名单，不以toy梯度当真实有效性。

原生网络和BN/运行buffer全冻结。key投影一旦冻结，构库与查询都使用相同版本；后期若允许适配，key与query共同更新并重新核空间，不只更新其中一端。value/解码器在真实任务阶段先冻结，避免噪声监督把语义库改写成另一自由分割器。

### 3.4 三阶段接力，每阶段都接通正常输出

| 阶段 | 更新什么 | 如何交接 | 不能被下一阶段掩盖的失败 |
|---|---|---|---|
| A 内容与结构 | 类型value/解码器、有限几何；监督字段合法时学习局部关系与边界 | 多观察/留出来源解码；同一对象配对与部位连接；保存正常输入的初始完整结果 | 仅记住每个word第一张参考，或者姿态来源错误 |
| B 正常实例绑定 | 查询、相容匹配和有限实例状态；内容与共享视觉空间固定 | 用正常预测框；合成细语义＋真实前景集合/配对；检查真实调用与错配影响 | 只开门、错误对象始终被选中、真实全拒绝或实例间串部位 |
| C 实际净效用 | 增/删gate、已有合法可见关系/边界的低速适配；原生与对象内容先固定 | 从精确原生起点学习；全量正常输出；固定末checkpoint及选择规则 | 依靠过删、只在少数漂亮案例有效、Mask涨但原成功损伤超限 |

A阶段训练主对象内容时可以使用合法GT裁剪，但必须标明特权条件；B/C不将GT框、clean reference或GT姿态当输入。用于损失的GT关联规则在train固定，不由预测Mask好坏反复更换目标实例。未匹配/歧义检测完整保留在最终评价，不用训练筛选条件过滤部署输出。

C先固定提议来源训练接受，再按预定日程允许关系/边界低速适配；一旦提议来源改变，直接动作目标随当前提议重算，禁止沿用旧checkpoint的正确/错误标签。原生特征可按固定版本缓存，动态对象候选与效用目标默认当前前向计算。阶段转换、步数和白名单在正式运行前固定，不能看dev选转换时点。

优化的首个工程起点：AdamW，查询/条件gate学习率`1e−4`，内容预训练`3e−4`，任务阶段关系/边界`3e−5`，矩阵weight decay `1e−4`、norm/bias不衰减、clip norm 1；检索概率、距离/归属损失FP32，原生保持既有冻结精度。**这些是待工程核验的候选数值，不是已冻结最优超参。** 有效batch、阶段步数、数据曝光、调度与EMA由实际成本和样本清单在正式运行前一次冻结；不把旧10000步预算分配给新结构后自动运行，不按dev曲线临时延长。

真实与合成保持混合，分域、分类型记录损失及有效梯度，未知细标签不参与相应分母。按真实视频组/实例尺度/遮挡覆盖抽样，不能把大量同族合成图的像素数当独立知识规模。新几何/数据适配规则在训练前固定，禁止运行后追正收益改协议。

## 4. 第四轮：科学判断与最终验收接到同一目标

**H：** 有合法真实正向绑定的类型对象候选，可以为固定原生实例提供方向正确的增删信息，分开接受增删后获得真实净Mask收益。

**H_alt：** 合成对象与真实形状/语义仍不相容，或普通图像细化承担全部收益；打开对象调用会暴露更多错误，保留原生才更好。V20域间调用差及V16/V19实际损伤为此竞争解释提供依据。

区别预测：H要求正确value比等读入质量、同类型/相容条件的错误value产生更好的**正常任务**修正；门质量上涨同时对应检索/重建改善，而不是仅非拒绝质量上涨。H_alt预期错配不影响收益、对象提议在真实域大量被合理拒绝，或只有自由图像支路才能修复。

主要效用比较保持用户指定的**强原生N／完整方法M两臂**，不自动增加多组训练。纠错、绑定、类型表示一起改变时只报告复合配置效应。机制匹配训练对照与容量、输入、预算清单须先规划；未执行有效匹配控制时不宣称独立机制贡献。同checkpoint的等质量value置换、同语义替换和分类型删除优先复用，不把关闭任何必要计算后的退化当语义证据。

| 结果 | 冻结后的动作 |
|---|---|
| 工程输入、标签或坐标无效 | 修复确切工程错误并保留失败，不判方法阴性，也不扩大训练。 |
| 内容/绑定未通过必要条件 | 关闭当前实现的任务扩训；保留已成立的内容事实，聚焦失败的真实对象相容/同实例绑定，不叠新读出器。 |
| 净收益>0且护栏通过、但<5点 | 报告有限正收益及+5未达；是否扩大由新支持证据和下一合同决定，不将继续预算自动开放。 |
| 达到≥5点且护栏通过 | 固定整包后进入事先登记的未用确认集；确认通过后才交付相应泛化范围。 |
| 正常Mask无正收益或损伤超限 | 关闭该配置、保留原生；按已记录提议/接受证据选定具体失效环节，不事后调门、挑图、换seed追阳性。 |

主指标为完整真实正常输出Mask AP@[.50:.95]，+5为绝对百分点。Box/Class/score/排序/数量/检测行精确不变；Mask75原成功损伤≤1%、Mask AP75不降、小目标退化≤0.5点作为拟保留护栏，具体新合同一次冻结。全量、密集与尺度结果并列，不让局部子集替代全量。

原有432dev反复使用，只作开发证据。426既有test仍未读；须先从拆分元数据核实来源组隔离与合同合法性，不能只因文件名test就称盲测。最终确认按冻结规则只读一次，不把确认反馈回词表、门限或渲染设计。当前不打开test图像/标签。

评价必须保留原生全部检测、无GT选择、相同解码器与COCOeval。bbox/segm独立匹配，固定同检测的增删账本另列。保留调用覆盖、全关闭比例、提议正确但被拒绝/提议错误却接受两种失败，以及对象→候选→增删→最终结果的技术图；门全关而AP持平不能叫学会原型。

## 6. 本次补充的一手依据

- [ShapeMask，ICCV 2019](https://openaccess.thecvf.com/content_ICCV_2019/papers/Kuo_ShapeMask_Learning_to_Segment_Novel_Objects_by_Refining_Shape_Priors_ICCV_2019_paper.pdf)：形状先验参与逐步实例Mask重建，支持对象先验与实例细节分工；不证明本项目四库或原生锚定的最优性。
- [RefineMask，CVPR 2021](https://openaccess.thecvf.com/content/CVPR2021/papers/Zhang_RefineMask_Towards_High-Quality_Instance_Segmentation_With_Fine-Grained_Features_CVPR_2021_paper.pdf)：逐阶段加入细粒度特征，支持不能只用低分辨率形状修边界；不证明一定要边界记忆。
- [Mask Transfiner，CVPR 2022](https://openaccess.thecvf.com/content/CVPR2022/papers/Ke_Mask_Transfiner_for_High-Quality_Instance_Segmentation_CVPR_2022_paper.pdf)：聚焦易错高分辨率区域，支持分配局部细化计算；本稿的受限增删是独立待验证设计。
- [Simple Copy-Paste，CVPR 2021](https://openaccess.thecvf.com/content/CVPR2021/html/Ghiasi_Simple_Copy-Paste_Is_a_Strong_Data_Augmentation_Method_for_Instance_CVPR_2021_paper.html)：实例级真实图像合成的数据依据；不能将复制轮廓当真实完整形状或额外独立对象。

v2中的规范坐标、遮挡与原型内容来源继续按其原始适用边界引用。本次不把论文在其它数据上的提升迁移成本项目收益。
