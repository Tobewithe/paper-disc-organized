本线研究可见证据分散时怎样保持同体归属、区分相邻身体，以及原Mask或额外标注能够提供哪些关系。来自[实例组织问题](../../../project/outlines/OUTLINE_PIG_ORGANIZATION.md)，由[片段表示Idea](../../../project/ideas/IDEA_PIG_INSTANCE_INFORMATION_USE.md)连接具体探索。
