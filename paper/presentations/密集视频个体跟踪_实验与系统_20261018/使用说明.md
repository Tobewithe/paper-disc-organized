# 密集视频个体跟踪：展示与使用

已经完成一套可运行的离线原型。系统支持导入视频、检测分割、跨帧编号、短时轨迹、待确认身份、重现事件跳转和六组实验对照。

4. `architecture.svg`：可编辑模型架构；`metrics.png`、`sequence.png`、`training.png`：实际实验数据图。

## 演示顺序（约三分钟）

先展示“现场群体活动”，解释彩色编号、轮廓和轨迹。点击一个个体，观察身份信息；点击“重现确认记录”定位算法作出决定的时刻。说明 WAIT 表示证据不足，算法动作不等于恢复正确。

再切换公开马群案例，说明算法接口面向通用动物实例，当前实测类别为猪与马。进入“研究方法”解释三个环节：看清可见个体、只记住有用信息、重现时有限等待并比较候选身份。

最后进入“实验对照”，讲清这轮已完成 5 个完整保留视频、2,655 帧的六组实测。完整候选 IDF1 57.54，低于 ByteTrack 63.69 和 Deep OC-SORT 60.17。当前贡献是可复现原型、受控实验和明确问题定位；新增机制尚未证明有效。

## 导入新视频

选择 MP4，选对应猪或马检测模型，点“开始分析”。文件不超过 200 MB，最多处理前 60 秒。分析结束后自动切换结果，保留原视频与分析记录。此功能没有生成真实 ID 标注，不能自动给出准确率。
