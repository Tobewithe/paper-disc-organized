# 01_研究定位

各位老师好，本次汇报的题目是“面向密集场景的检测分割与持续跟踪方法及系统研究”。课题面向拥挤环境中的连续个体监测，希望把单张图像中的识别结果，进一步组织成可持续、可回查的个体记录。

汇报分为研究背景、研究方法、系统设计和研究安排四个部分。研究方法包括图像中的个体检测分割、视频中的身份保持，以及遮挡后的身份恢复。其中，图像部分已经有模型和实验基础，后两个模块目前是拟开展方案。

---

# 02_应用需求

动物群体、人员和车辆监测，都需要持续记录具体个体。实际使用时，需要了解当前能看到多少个体，每个个体出现在哪里，以及在某个区域停留了多久。

如果还需要分析个体的可见区域，就要进一步分开相邻个体的轮廓。数量基本正确，并不代表每个个体的区域记录也正确。只有这些记录持续稳定，后续的数量统计、位置分析和行为研究才有可靠基础。

---

# 03_技术进展

现有技术已经能够在图像中找到目标的位置，并描出个体轮廓。在视频中，也可以给目标分配编号，连续跟随其移动。因此，检测、分割和跟踪已经提供了比较明确的技术基础。

但是目前，在密集场景下保持稳定的个体记录仍有困难。个体挤在一起、彼此接触，或者被遮挡较长时间时，输出可能前后不一致，连续记录也可能中断。图像识别准确，并不能直接说明视频中的每个身份都能一直保持正确。本课题关注的就是这些具体条件下的可靠性。

视频关联能力及低置信度观测造成轨迹断裂的问题，可参见 [ByteTrack 原论文](https://arxiv.org/abs/2110.06864)；运动与外观联合关联可参见 [BoT-SORT 原论文](https://arxiv.org/abs/2206.14651)。这里概括研究背景，不将文献成绩视为本项目结果。

---

# 04_主要困难

这里把实际困难归纳为三种情况。第一是个体密集接触，同一个体可能被重复识别，也可能漏掉某个个体；即使检测框存在，相邻个体的轮廓仍可能混在一起。

第二是外观相似的个体交叉移动。每一帧都能找到它们，但前后编号可能互换，或者一段轨迹被分成几段。第三是个体被遮挡后重新出现，系统可能把它当成新个体，导致遮挡前后的记录接不上。

这三类问题分别对应后面的检测分割、身份保持和遮挡恢复。目标是提高个体识别、轮廓区分和连续记录的可靠性。

---

# 05_方法总览

研究方法按三个任务模块组织。模块一解决单张图像中能否找到个体、能否分清轮廓的问题，目前已经完成部分图像模型和探索实验。模块二研究连续视频中的身份关联，让持续可见的个体尽量保持原来的编号。模块三处理轨迹已经丢失的情况，判断目标重新出现后能否接回原编号。

模块二关注身份尽量不中断，模块三关注中断之后能否正确接回。两个视频模块目前都未开展，计划先限定在单摄像头、固定视角，并沿用同一套跟踪框架，控制实现和实验规模。最终将三个模块组织为通用系统，猪只只作为其中一个应用案例。

---

# 06_评价指标

模块一首先建立实例级评价口径。IoU 是预测区域和真实标注区域的交并比，越接近一表示越一致。这里将零点七五作为诊断阈值，基于已有的 IoU 和官方任务匹配定义几个研究口径，而不是重新发明 IoU 或 AP。

目标集合 T 包括原分割任务失败、但存在合格检测框，而且该同一条检测自身轮廓仍不合格的实例。固定同一条预测很重要，因为检测框匹配和分割匹配是独立的，不能从不同预测中各取一个好结果拼成成功。

轮廓增益是修正后减去原来的 IoU。先在每张图中求平均，再对图片等权平均，分别观察目标组和全部合格框配对。任务修复率统计目标组中重新获得分割任务匹配的比例；它与原固定检测自身达到阈值的比例分别报告。

成功损伤率则统计原来分割成功、修正后变成任务失败的比例。这样，评价既考察是否修好错误，也检查是否破坏原本正确的结果。最终完整方法效果还需要通过同配置的全量 AP 验证。

---

# 07_基础模型

目前使用的基础模型是固定预训练权重的 YOLO26m-seg，版本为 Ultralytics 八点四点一百，研究对象为正常推理保留的一对一分支最终输出。这里展示的是与本研究相关的推理结构。

输入图像经过主干网络和多尺度特征融合，提供检测所需的特征。模型一方面给出检测框、类别和分数，另一方面输出三十二通道的共享分割原型，以及每个实例对应的三十二维组合系数。可以把原型理解为共享的基础图案，把系数理解为每个实例组合这些图案的方式。二者组合后，再通过原生解码和预测框裁切，还原到图像中的实例轮廓。

当前方法固定基础网络、分割原型和检测结果，仅研究组合系数的修正。这样可以明确观察轮廓改变带来的影响。本地原生任务账本已经核验有效，但官方发布 AP 的复现要求尚未通过，因此所有实验都以本地同协议输出为基线。

---

# 08_修正器结构

新增模块是一个轻量系数修正器，输入全部来自模型自身的预测。上方的空间支路在预测框内，对三十二通道原型和原始轮廓响应共同进行八乘八采样，得到三十三通道输入。经过两层三乘三卷积、GELU 激活和全局平均后，得到六十四维空间描述。

下方是实例条件支路。原检测位置所属特征层的实际通道为二百五十六、五百一十二或五百一十二，分别投影成六十四维；原系数映射成三十二维，再加入框几何、分数和类别嵌入。两条支路拼接后一共是一百八十一维，经一百二十八维中间层，最终输出三十二维系数残差。

把残差加到原系数上，再与原型组合，得到修正轮廓。新增可训练参数共有十六万七千八百七十二个，输出层采用零初始化，基础网络和原预测保持冻结。训练可以使用标注作监督，但正常修正推理不读取真实标注或失败标签。模型维度和参数量来自实际代码与正式训练合同。

# 09_失败定位

首先检查正常推理中有哪些失败值得进入轮廓修正研究。对 COCO 验证集五千张图、三万六千三百三十五个普通标注实例逐一核对后，分割任务失败共有一万三千三百七十八个。

其中七千一百四十八个没有达到诊断要求的检测框配对；六千二百二十九个已经有合格框，但该同一条检测的轮廓仍不合格，构成目标集合 T；另有一个案例属于匹配竞争。目标集合占分割失败的百分之四十六点五六。

这个结果说明，部分失败可以在固定检测框后继续研究轮廓修正。它不是 AP，也不证明剩余失败都无法改善，只是明确了当前方法的研究对象。

---

# 10_修正空间

确定对象之后，先检验固定模型表示是否还有可利用的修正机会。实验固定原型、检测框、类别、分数和预测身份，只在真实标注指导下有限优化组合系数。这是用于探查机会的实验，并不是可部署的自动方法。

按冻结规则选取二百五十六个目标，全部完成数值收敛，其中一百二十二个在同一条检测上达到了轮廓 IoU 零点七五，比例为百分之四十七点六六。按真实标注面积分组，小目标为三十八除以一百四十八，中目标为四十四除以六十四，大目标为四十除以四十四。

这说明原有表示中仍能找到更准确的轮廓，但只是在固定样本和有限优化预算下找到的机会，不能作为全体失败的恢复比例或自动方法收益。下一步要检验修正器能否在不读取标注的情况下学到这些改善。

---

# 11_探索实验设计

探索实验按条件逐项展开。第一项将原型和原始轮廓响应的空间位置联合打乱，保留数值和通道，用来观察空间组织是否有帮助。第二项保留正常空间排列，使用原来的像素分类损失。第三项保持相同结构、初始状态和图像次序，只把真实标注监督项替换为 soft-IoU，观察损失目标的影响。

这三个训练配置都使用相同的两千张图、三轮训练、一千五百步，优化器为 AdamW，学习率零点零零一，有效图像批量为四，统一取最后一轮模型，没有按开发成绩挑选轮次。用于保持基线输出的损失项仍为 BCE，权重保持零点一。

在后续风险分析基础上，另做固定面积选择：使用同一个已训练模型，只在原生原图掩码面积至少为九十六的平方时应用已有修正。这项实验没有新增训练，并保留完整预测集合和全部原评价分母。开发目标为六百五十五个，全部合格框固定配对为二千九百二十五个。

# 12_自动修正探索

这张图比较三种训练配置相对原生输出的目标组轮廓变化，横线表示原协议的百分之九十五区间。空间打乱为负一点九三个百分点，正常空间加 BCE 为负零点九九六，正常空间加 soft-IoU 为正零点六八。

保留空间排列比打乱对照少损失约零点九三四个百分点，替换损失也比旧 BCE 配置有所改善。但优于一个失败配置，不等于方法已经有效。soft-IoU 的目标区间仍跨零，整体固定配对的 IoU 下降约零点二六二个百分点；一千零二十四个原成功实例中有五十三个受损，损伤上界为百分之六点四三，高于百分之一要求。

因此，当前三个无条件配置均未通过完整开发验收。这是在既定样本和预算下对这些具体配置的结论，不代表所有系数修正方法都无效。下一步需要解释损伤集中在哪些实例上。

# 13_面积分层

为了定位损伤，复用同一个 soft-IoU 模型的已有输出，按原生预测掩码面积分组。这里采用推理时直接可见的原图预测面积，区别于前面标注辅助实验使用的真实标注面积。

小掩码组是三十七除以二百七十，损伤率约百分之十三点七；中掩码组是十四除以四百二十四；大掩码组是二除以三百三十。小掩码仅占成功面板的百分之二十六点四，却占损伤案例的百分之六十九点八。

这一结果提示，当前修正器的风险并非平均分布，选择应用范围值得进一步检验。但大掩码组的低点估计不能直接替代完整策略验收，必须实际构造混合输出，重新计算任务匹配并保留原分母。面积与邻框重叠的进一步分层结果保存在实验依据中，当前证据支持面积相关的探索结论，尚不能等同于密集场景因果结论。

# 14_选择性修正结果

最新完成的实验采用固定面积条件：原生掩码面积达到九十六的平方才应用现有修正，其余保持原结果。使用相同 checkpoint，没有新增训练，对一千三百一十四张图的完整输出重新执行任务匹配。

左图仍以原生输出为参照。目标组平均增益从零点六八提高到一点零零二个百分点，对应区间约为正零点二八二到正一点八四五。整体固定配对由负零点二六二变为正零点零八九，但整体区间仍跨零，只能说通过整体保护要求，不能宣称整体显著提高。

右图使用完全相同的一千零二十四个原成功实例面板。无条件修正损伤五十三个，固定面积策略损伤两个，比例从约百分之五点一八降到零点二零。按原公式计算的名义上界约为百分之零点六。

原开发要求是目标增益至少零点五个百分点且区间下界大于零，整体平均下降不超过零点一百分点，损伤上界不超过百分之一。这次三项数值均通过。但面积策略由已经看过的开发结果选出，面板也被复用，区间和上界不具有新的独立覆盖保证。未应用修正的实例仍留在分母中；全五千图的 AP 改善和独立确认尚未完成。

# 15_模块一结论

模块一目前形成三点认识。第一，固定原有表示后仍有可利用的轮廓修正机会，标注辅助实验的一百二十二个达标案例为系数修正提供依据。第二，无条件修正会损伤原成功实例，而且小掩码风险更集中，不能只关注失败实例上的收益。第三，固定面积选择已经在复用的开发数据上兼顾目标改善和原成功保护，通过数值筛查。

这些结果保留了先前无条件配置的失败结论，也没有把开发筛查改写成全量 AP 或跨场景有效。该面积策略仍需完成的效用验证是：固定同一模型和面积条件，在全部五千张图上比较 AP，并对全部原成功实例统计精确损伤。

现有证据来自 COCO 图像开发实验，可以复用其模型、评价和探索经验。密集专项、动物场景和视频身份效果仍属于后续验证内容。

# 16_身份保持模型

模块二尚未开展，关注持续可见或短暂漏检时的身份保持。拟以 ByteTrack 为跟踪基线，利用当前检测和已有轨迹完成关联，再参照 BoT-SORT 的思路，引入外观与运动的联合判断。

当前帧提供位置、分数和个体轮廓，历史轨迹提供编号、移动位置和可靠外观。先预测个体可能的位置，再比较其外观，把当前观测关联到既有轨迹，输出连续编号。ByteTrack 本身已有运动关联，拟研究的增加项主要是外观信息如何参与，以及什么情况下应减少不可靠外观的影响。

模块一与模块二的连接点必须具体。只有将轮廓用于外观区域提取或显式关联，分割改变才可能影响身份结果。如果检测框和分数完全相同，纯框跟踪不会因为换了掩码就自动提升。外观编码器先考虑冻结的通用图像特征，仍需验证它在目标场景中能否区分相似个体，不能直接假定行人重识别模型适用于动物。

基线资料为 [ByteTrack 原论文](https://arxiv.org/abs/2110.06864)，联合关联参考 [BoT-SORT 原论文](https://arxiv.org/abs/2206.14651)。图中是本课题的拟研究框架，尚无实验结果。

# 17_身份保持实验

身份保持实验先固定完整视频和相同检测结果。第一组是原有检测框配合 ByteTrack，建立本场景的参考水平。第二组在基线上加入外观联合关联，观察交叉运动时是否减少换号。

第三组使用原生轮廓提取个体外观，检验减少邻近个体混入是否有帮助。第四组只把第三组中的轮廓换成模块一修正结果，其余关联设置保持一致，从而检验图像轮廓改善能否转化为身份收益。

需要补充跨帧真实编号标注，按完整场景或序列划分开发和测试，避免把相邻帧分到两侧。重点覆盖交叉运动、相似外观和短暂漏检。主要评价身份对应的准确与完整程度，也就是 IDF1，同时报告编号切换、轨迹断裂和端到端速度。以上都是设想，配置、预算和评价规则需在实际运行前固定。

统一评价工具参考 [TrackEval 官方仓库](https://github.com/JonathonLuiten/TrackEval)，目前尚未在本项目运行视频评价。

# 18_遮挡恢复模型

模块三同样尚未开展，处理轨迹已经进入丢失状态的情形。它沿用模块二的跟踪框架，增加丢失轨迹记忆与恢复判定。遮挡前保存可靠外观、最后位置和运动历史，重新出现候选后，先筛选可能对应的旧轨迹，再通过连续观测确认。

证据足够时恢复原编号，把记录接回遮挡之前。如果证据不足，保留未确认状态继续观察；达到固定时限后终止旧轨迹，避免为了保持编号而强行接错。这里同时需要控制错误续接和长时间无法作出判断。

遮挡期间的运动预测只能表示推测位置，不能作为实际观测到的轨迹。研究重点是重新出现之后身份是否正确恢复，以同一摄像头内的临时遮挡为主要范围。

---

# 19_遮挡恢复实验

遮挡恢复实验需要以事件为单位建立标注，记录遮挡开始、重新可见时间以及真实身份，按事前确定的遮挡时长分层分析。

拟比较四种配置：默认丢失保留、仅延长保留时间、在同样保留时限和候选预算下增加可靠外观记忆，以及进一步加入连续多帧确认。这样能够区分效果来自等待更久、记忆信息还是确认策略，也能观察降低误接是否增加恢复延迟。

对全部符合定义的重现事件共用同一个分母，报告正确恢复、错误续接和未恢复的比例。成功恢复延迟另行报告，同时给出超时率，避免只分析成功样本就声称整体更快。新目标进入和出画后重新进入作为单独干扰对照；只有身份可明确标定的重现才作为可恢复机会。阈值、时限和评价窗口均在运行前确定，目前没有任何视频实验结果。

# 20_系统功能

最终拟形成通用系统，将三个模块的输出组织成完整使用流程。用户首先选择图片或视频，并配置识别对象；随后查看个体的位置、轮廓和连续编号。

处理完成后，可以回看遮挡与恢复记录，并导出轨迹、数量变化和报表。对于身份尚不能确认的情况，系统应明确显示其状态，使用户能够区分已确认记录与待确认结果。

系统的重点是让分析结果可以查看、回看和保存，形成实际可用的个体记录。目前这里展示的是拟建功能。

# 21_应用案例

应用验证以猪只群体监测为例。密集聚集和外观相似使这个场景能够具体检验数量、个体区域以及连续身份记录。

使用者关心当前可见数量、每个个体的位置与停留，以及遮挡前后的记录能否接续。系统预期输出数量变化、位置与区域，以及可回查的连续记录。

猪只承担应用验证角色，方法和系统的组织不限定于猪只。面向其它识别对象时，可以配置相应模型与数据，但具体效果仍需在各场景分别验证，不能把一个案例的成绩直接外推。
