# GT 候选分类修订依据

本轮仅修订毕业论文汇报材料。用户明确撤下 C/I/L/S/O/M/X/MISS 关系分类，加入全原始候选能力五分类和类别 argmax 正确条件下的 GT 五分类。没有新训练、推理或科学评价运行。

## 1. 全原始候选五分类

对象：Ultralytics 8.4.100 官方 COCO yolo26m-seg 的历史 O2O 原始候选缓存，COCO val2017 5,000 图、36,335 普通 GT。检查该图该分支全部 raw，不先按类别、置信分数、Top-K 或最终匹配过滤。每个 GT 归入一个互斥状态，框、掩码阈值均为 0.75。

| 状态 | GT数 |
| --- | ---: |
| 同一 raw 框与掩码双达标 | 23,805 |
| 存在达标框，整个 raw 池没有达标掩码 | 6,688 |
| 存在达标掩码，整个 raw 池没有达标框 | 487 |
| 好框、好掩码分别存在，但无同一 raw 双达标 | 531 |
| 框和掩码都没有达标 raw | 4,824 |

来源：`experiments/coco_raw_capability_5000_20260916/REPORT.md`。原始运行 `RUN_180459232c434a8ebc385f51dec06f63`，汇总运行 `RUN_a7c840bb695d45b4b66bc346715ca1aa`；两份 run.json 状态均为 completed。数据图直接读汇总 SUMMARY.json 的 by_geometry[*].gt。

用途：区分模型尚未生成合格掩码、好框与好掩码不属于同一候选、以及已经具备联合达标能力。GT 帮助检查整个候选池，不代表部署时能选中，也不是最终任务召回或 AP。

## 2. 类别正确条件下的 GT 五分类

每个 GT 只检查 raw 的 80 类 score argmax 与 GT 类别一致的候选子集；该条件不等于最终类别分数通过门槛。分母仍为全部 36,335 个普通 GT；空子集进入语义候选缺失类。

| 状态 | GT数 |
| --- | ---: |
| Semantic fail：无类别 argmax 正确候选 | 44 |
| Box fail：子集非空，但无 Box75 | 6,335 |
| Mask fail：存在 Box75，但子集内无任何 Mask75 | 6,459 |
| Misaligned：子集内分别存在好框、好掩码，但无同 raw 双达标 | 484 |
| Success：同 raw 类别正确且 Box75、Mask75 均成立 | 23,013 |

来源：`experiments/coco_raw_argmax_conditioned_20261005/REPORT.md` 和 `runs/RUN_83e9f6f1f0de4d969868fd9a04321786/SUMMARY.json`，对应 run.json 为 completed。复用前述 raw cache，无新前向或训练。

用途：固定候选类别条件后，定位框不足、掩码不足与候选不同步。Mask fail 必须写成子集内无任何 Mask75，不能写成仅在好框候选上无 Mask75，否则与 Misaligned 重叠。不能把 44 个 Semantic fail 解读成最终分类错误只有 44 个。

## 3. 与当前最终输出分组的关系

当前原生 O2O 最终输出另有 6,229 个目标 T，定义为官方 segm75 任务失败、官方 bbox75 匹配存在、且该条最终检测自身 MaskIoU<0.75。来源为 `experiments/official_gt_failure_rebaseline_20261013/runs/RUN_NATIVE_FULL_7609b70db27a4989b8da814e51cbd170` 及对应原生诊断账本。

6,688 / 6,459 / 6,229 分别属于全 raw、类别条件 raw、原生最终检测三个观察口径。它们不是顺次筛选的漏斗，不能相减归因，也不能把旧自定义导出 AP 与新原生 AP 拼成同配置对照。

## 4. 示意图与公式

IoU=交集面积/并集面积；框与掩码分别计算。示意图只用于解释概念，不是实际推理案例。

像素错误沿用固定同一预测、有效自身 GT 优先、crowd 排除的定义。自身遗漏 FN=G\P；误报 FP=P\G 分为同类独占、异类独占、同/异类歧义、背景四个互斥区域。各面积比统一除以有效自身 GT 面积；四类 FP 比例之和等于总 FP 比例，自身遗漏单列。

ICI 为其它同类 GT 框与自身框交叠面积的累计值除以自身框面积；多个邻框分别累加，可超过 1，不是遮挡率。E(4) 为有效目标边界像素中距同类邻居区域不超过四个模型输入等效像素的比例，依据实际 letterbox 缩放转换距离。

像素与拥挤定义依据原 `failure_dimension_analysis_20260913/REPORT.md` 和 `COCO_CROWDING_SUPERVISION_SPEC_20260912.md`。关系字母分类及其旧 error_surface、duplicate_like 数据不进入本次汇报。
