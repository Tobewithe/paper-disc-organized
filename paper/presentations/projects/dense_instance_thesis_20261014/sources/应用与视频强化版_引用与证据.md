## 一、汇报中的核心判断

“检测框已经比较准确，但连续个体分析仍会失败”需要拆成可验证命题：单帧检测质量、实例区域质量、跨帧身份关联分别评价。COCO AP 并不定义跨帧身份，也不存在通用的“达到某个框 AP 就达到跟踪级别”的阈值。遮挡目标重新出现后，检测器再次找到目标，并不自动说明跟踪器恢复了遮挡前的同一身份。

现有方法已经能够处理部分低分观测、短时遮挡与视频传播困难。具体尚存困难是在长时无观测、相似外观、复杂运动或错误记忆条件下，能否持续保持正确关联。不能将其概括为“业界不会跟踪”，也不能宣称本课题两项帧内方法已经解决长期身份恢复。

## 三、方法与系统的因果边界

1. 候选判别可能改变输入跟踪器的检测集合、框或分数。其跟踪收益需在固定跟踪器和关联参数下评价；对低分候选的处理也可能伤害后续关联，不预设一定改善。
2. 固定框、分数、检测集合而仅修改掩码，不能直接改变标准 ByteTrack 的关联。掩码的首要评价是分割质量和可见区域统计；若采用掩码辅助关联，需要明确新增接口和独立消融。
3. 掩码修正可能改变个体区域而不改变前景并集；前景占用应对 ROI 内掩码求并集。像素在相邻实例间重新分配时，两类统计需分开观察。
4. 标准帧内 AP 提高不能自动证明时间稳定性提高。真实运动、可见性和姿态变化可以造成合理输出变化；不能将所有面积变化都称为抖动。
5. 完全不可见期间保留的预测轨迹不是当前检测结果。可见计数、预测存量和跨时段去重个体数需要分别定义；本版主要展示前两者的状态分离。

## 四、新增视频评价的实施要求

以下为研究方案，尚未执行，也不是文献已替本项目完成的实验。

- 数据需有序列与时间戳、跨帧身份、可见性以及遮挡和重现事件。现有静态图像、掩码和推理组件可复用，不能直接替代视频身份标注。
- 开发与评价至少按视频或采集序列分组；同一段相邻帧不能随意拆到不同集合。跨栏舍或跨采集条件的评价另行记录。
- 遮挡事件需预先规定起点、首次重现、观察窗口、成功续接的持续条件、模糊身份事件的处理和有效事件分母。不能只报告成功恢复的样例。
- 在规定窗口内，将可判定事件区分为正确续接、误接到其他历史身份、重新编号及持续未检出，避免“恢复率提高”掩盖误连增加。具体定义需在正式实验前冻结。
- 使用 Box/Mask AP 评价帧内质量；HOTA/AssA、IDF1 和 ID 切换评价跨帧身份。事件指标解释遮挡恢复行为，不能替代标准跟踪指标。
- 工程测量覆盖输入接收至结果输出的端到端时延、首次身份确认等待、吞吐、掉帧、并发与目标容量、资源占用和持续运行失败。测试需固定硬件、输入分辨率、帧率和并发条件。

## 五、复用结论与近期工作

现有实验可复用的是数据清单、诊断评价、修正规则与收益模型原型、推理及结果导出。附录 RCMC 数值保留原评价身份和开发性范围，不构成密集视频或身份恢复效果证据。原候选排序方案未达到预设要求，继续保留该阴性结论。

近期单个优先事项是确定视频标注与评价口径；随后在固定基础模型和跟踪器上建立可复查的基线。PPT 中的方法、跟踪集成和工程验证均按研究方案表述，不登记为已实现或已验证成果。
