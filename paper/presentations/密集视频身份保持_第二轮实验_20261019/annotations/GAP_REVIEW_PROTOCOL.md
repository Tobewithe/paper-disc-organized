# 公开序列间断事件的模型盲视觉核对

候选是历史五视频中 GT ID 的 2–60 帧标注间断，共36次。每个有候选的序列按开始帧、GT ID 排序，固定取前两次，共8次；不根据跟踪成绩选取。horse_7 无此类 GT 间断，不人为制造事件。

只看原视频、公开 GT 边界框及间断中间帧，补充原因标签：动物遮挡、场景物体遮挡、出画、GT 标注间断或无法确认。GT 不见本身不算物理遮挡。一次 AI 视觉复核，保留无法确认，不声称人工金标准。

模型选择与阈值已冻结。本辅助事件分析不改变主指标/Gate，不作为对确认集调参的理由。事件比较使用相同8个事件，原 ID 恢复、换新 ID、错误复用、无输出各自报告。
